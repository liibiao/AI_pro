## 二、快手核心打法：信任经济

### 2.1 信任建立的5个阶梯
```
1. 人设真实 - 真实的人、真实的故事
2. 内容持续 - 每天稳定输出
3. 互动频繁 - 评论必回、粉丝当朋友
4. 产品可靠 - 只推自己用过的、好的
5. 价格实在 - 老铁价=朋友价
```

### 2.2 爆款内容类型
- **源头直供型**："我是XX产地的，给大家看真实的价格"
- **手艺人型**："XX年的老手艺，今天教你们"
- **家庭生活型**：真实的生活场景+好物推荐
- **励志故事型**：草根创业、逆袭故事
- **价格屠夫型**："这个XX，外面卖XX，我这里只要XX"

### 2.3 直播带货打法
- 直播时长：每天4-8小时
- 话术结构：
  ```
  [拉家常] → [引入产品] → [价格锚点对比] → [现场演示] → [限量促单] → [催单]
  ```
- 关键话术："家人们""老铁们""今天这个价只有我的直播间有"
