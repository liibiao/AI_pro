## 一、广告素材诊断清单

### 1.1 视觉钩子诊断（前3秒）
| 检查项 | 通过标准 | 不通过典型问题 |
|--------|---------|---------------|
| 停留冲击力 | 3秒内制造"什么情况？"的反应 | 平淡开场、人物微笑、产品静态展示 |
| 反常识元素 | 画面中有违反日常认知的元素 | 所有元素都"正常" |
| 色彩冲击 | 色彩对比度≥中等 | 灰蒙蒙、无重点色 |
| 运动感 | 有镜头运动或主体运动 | 完全静止画面 |

### 1.2 叙事结构诊断
| 检查项 | 通过标准 |
|--------|---------|
| 七层完整性 | 7层中至少覆盖5层（短版可合并） |
| 情绪曲线 | 有明显起伏，不是一条直线 |
| 痛点共鸣 | 目标用户能说"我也有这个问题" |
| 产品登场感 | 产品出现有戏剧化转折 |
| 行动指令 | 有明确的CTA（Call To Action） |
| 传播任务一致性 | 全片是否围绕一个传播任务句 |

### 1.3 创意原则诊断（7条逐项）
| 原则 | 诊断问题 | 通过标准 |
|------|---------|---------|
| 真实可信 | 有几层证据支撑？ | ≥1层，理想3层 |
| 目标导向 | 传播任务是否明确且唯一？ | 能用一句话说清 |
| 洞察先行 | 洞察来自用户还是品牌？ | 来自用户视角 |
| 简单明确 | 核心卖点是否只有一个？ | 一条视频一个卖点 |
| 新鲜独特 | 用了哪种"换法"？ | 至少一种换法 |
| 情绪驱动 | 主情绪是什么？视听是否匹配？ | 情绪-视听一致 |
| 可执行 | 执行四问是否全过？ | 4问全过 |

### 1.4 平台适配诊断
| 检查项 | 通过标准 |
|--------|---------|
| 尺寸比例 | 匹配目标平台要求 |
| 内容调性 | 符合平台用户偏好 |
| 时长控制 | 在平台推荐时长范围内 |
| 违禁检查 | 无平台违禁内容 |

## 二、创意激发工具

### 2.1 基础创意公式

**反转公式**：
```
从[负面状态A] → 到[正面状态B]，靠的是[产品]
```
示例：从"冬天冻成狗" → 到"雪地里撒欢"，靠的是XX羽绒服

**隐喻公式**：
```
[产品] 就像 [喻体]，因为它们都能 [共同属性]
```
示例：这件羽绒服就像移动暖炉，因为它们都能让你在-20°C无感寒冷

**极端场景公式**：
```
在[极端环境]下，[产品]依然能[核心功能]
```
示例：在珠穆朗玛峰大本营，这件羽绒服依然能保持体感20°C

**用户证言公式**：
```
[身份标签]的[用户名]说："[真实感短句]"
```

**数据冲击公式**：
```
[大数字] + [时间单位] + [成果]
```
示例：327万人已穿过这件羽绒服度过3个冬天

### 2.2 卖点视觉化表（灵感来源1：产品本身）

| 卖点类型 | 视觉化方法 | 示例 | 适用行业 |
|---------|-----------|------|---------|
| 功能卖点 | 使用前后对比/极端测试 | 防水手机扔进水里 | 3C/家电/工具 |
| 成分卖点 | 微观放大/成分可视化 | 玻尿酸分子渗透皮肤动画 | 美妆/食品/保健 |
| 工艺卖点 | 制作过程/慢动作拆解 | 手工缝制皮具的每一针 | 服装/家居/食品 |
| 设计卖点 | 多角度展示/场景搭配 | 同一件衣服搭配7种风格 | 服装/家居/数码 |
| 体验卖点 | 用户使用瞬间/表情反应 | 第一口咬下去的满足表情 | 餐饮/美业/娱乐 |

### 2.3 用户原话库模板（灵感来源2：用户原话）

```
来源渠道：[电商评论/社交评论/私信/搜索词/客服记录]
原话摘录："[用户原话]"
表层诉求：[用户说想要什么]
真实阻碍：[用户做不到的原因]
情绪动机：[用户真正焦虑/期待/在乎什么]
可转化洞察：用户真正卡住的不是___，而是___
```

### 2.4 四种"换法"速查（灵感来源5：反差与冲突）

| 换法 | 操作 | 快速示例 |
|------|------|---------|
| 换场景 | 产品→意想不到的场景 | 防晒霜→火山口 |
| 换角色 | 非典型用户使用产品 | 直男→测评美妆 |
| 换比例 | 放大/缩小元素 | 维C→放大到一栋楼 |
| 换逻辑 | 反转因果/常识 | 因果倒置 |

## 四、广告类型→创意打法速查

| 广告类型 | 核心任务 | 推荐时长 | 七层侧重 | 创意重点 |
|---------|---------|---------|---------|---------|
| 品牌形象片 | 认知+记忆 | 30-60s | 1+4+7层 | 情绪、价值观、记忆符号 |
| 产品种草 | 兴趣+转化 | 15-30s | 1+3+4+6层 | 卖点视觉化、使用场景 |
| 促销活动 | 紧迫+行动 | 10-15s | 1+6层 | 时间感、优惠力度、CTA |
| 口碑传播 | 信任+分享 | 15-30s | 2+5层 | 用户证言、三层证据 |
| 新品发布 | 好奇+期待 | 30-60s | 1+3+4层 | 悬念、反差、新鲜感 |
| 节日营销 | 情感+行动 | 15-30s | 2+6+7层 | 社会情绪借势 |
| 拉新广告 | 抓注意力 | 10-20s | 1+2层 | 冲突、反差、前3秒hook |
| 转化广告 | 促成交 | 15-30s | 4+5+6层 | 利益点、证据堆叠、CTA |

## 六、AI提示词优化技巧

### 6.1 提升画面质感的关键词
```
cinematic, commercial style, premium feel, studio lighting,
shallow depth of field, golden hour, dramatic backlighting,
slow motion, high speed camera, macro lens, anamorphic lens
```

### 6.2 提升情绪感的关键词
```
ethereal atmosphere, moody lighting, warm ambient glow,
dramatic contrast, intimate close-up, documentary style,
raw and authentic, dreamy soft focus
```

### 6.3 常见问题修复
| 问题 | 修复方法 |
|------|---------|
| 画面太平淡 | 加 dramatic lighting / extreme angle |
| 人物不自然 | 加 candid moment / natural expression |
| 产品不突出 | 加 hero shot / isolated on clean background |
| 色彩不统一 | 指定 color grading / color palette |
| 节奏太慢 | 缩短每镜头时长，加 dynamic / energetic |
| 情绪不对 | 参照情绪-视听对应表调整画面手法和音乐 |
