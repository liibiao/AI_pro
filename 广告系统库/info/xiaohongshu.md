## 二、爆款内容公式

### 2.1 标题公式（高点击率）
```
公式1: [情绪钩子] + [反差/悬念] + [关键词]
  例: "姐妹们真的离谱！这个100块的面膜居然比1000块的好用"

公式2: [数字] + [场景] + [效果]
  例: "3天瘦5斤！上班族也能做到的懒人减肥法"

公式3: [身份认同] + [问题] + [解决方案]
  例: "宝妈必看！孩子不爱吃饭的10个妙招"

公式4: [价格锚点] + [价值对比]
  例: "不要299，不要99，这瓶精华只要59"
```

### 2.2 内容结构（高互动率）
```
[情绪钩子开头] - 3秒抓住注意力
    ↓
[痛点共鸣] - 让读者觉得"说的就是我"
    ↓
[产品/方法展示] - 真实使用过程/对比
    ↓
[效果证明] - Before/After / 数据/第三方背书
    ↓
[促动收藏/评论] - "赶紧码住""评论区告诉我你选哪个"
```

### 2.3 封面图要求
- 尺寸：3:4竖版（1080×1440）
- 大字报风格或精美实拍
- 色彩饱和度高、对比度强
- 必须有明确的视觉焦点
- 文字不超过20字

## 四、小红书违禁词/敏感词

### 绝对禁用
- 最、第一、唯一、首个、国家级、世界级
- 100%有效、绝对安全、零风险
- 包治百病、根治、药到病除
- 价格欺诈相关：原价XX现价XX（无法证明原价时）

### 高风险词（慎用）
- 瘦身、减肥、快速见效
- 医美相关：抗衰、除皱、美白针
- 金融相关：稳赚、保本、收益XX%

### 替代方案
- "最好" → "超爱/强烈推荐/按头安利"
- "第一" → "天花板级别/断层领先"
- "有效" → "真的有用/亲测有效"
- "便宜" → "性价比超高/学生党友好"

## 六、投放建议

### 自然流量
- 坚持日更或隔日更
- 前7篇内容测试赛道和风格
- 互动率 > 5% 有望进入流量池

### 付费流量（薯条/聚光）
- 笔记测试期：投100-300元测数据
- 内容加热期：选出互动率高的笔记加热
- 转化投放期：定向人群+搜索关键词

### 成本参考
- 自然内容：0元（时间成本）
- 薯条推广：100元起投，CPM约30-80元
- 聚光投放：5000元起投，CPC约0.5-3元
- KOC合作：200-2000元/篇
- KOL合作：5000-50000元/篇
