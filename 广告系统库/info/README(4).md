# 文案模板库

> 按用途分类的文案结构模板

---

## 通用文案结构
```
[情绪钩子] → [痛点/场景共鸣] → [产品卖点展开] → [信任背书] → [促动行动]
```

## 种草型文案（小红书/抖音）
```
[真实体验开头] → [使用场景] → [产品细节] → [效果展示] → [推荐理由]
```

## 促销型文案（快手/直播）
```
[价格锚点] → [产品展示] → [限时限量] → [催单话术]
```

## 深度型文案（头条/百度）
```
[行业痛点] → [问题分析] → [解决方案] → [产品介绍] → [行动引导]
```

## 私域型文案（微信/社群）
```
[亲切问候] → [价值内容] → [软性植入] → [互动引导]
```

## 信任背书话术库

| 类型 | 模板 | 适用场景 |
|------|------|---------|
| 数据型 | "已有XX万人选择""回购率XX%" | 电商、快消 |
| 权威型 | "XX机构认证""XX专家推荐" | 健康、教育 |
| 用户证言 | "买了3次了""给全家都买了" | 全行业 |
| 对比型 | "用过XX个品牌，最后留下这个" | 美妆、日用 |
| 场景型 | "连XX都在用" | 全行业 |

## CTA话术库

| 紧迫度 | 话术 | 适用 |
|--------|------|------|
| 强 | "最后XX件""倒计时XX小时" | 促销 |
| 中 | "点击下方链接""评论区留言" | 信息流 |
| 弱 | "感兴趣的可以看看""收藏备用" | 种草 |

## 七层广告文案结构（视频专用）

```
第1层 视觉钩子（0-2s）：用画面抓住注意力
第2层 痛点共鸣（2-4s）：说出用户没说出口的话
第3层 产品亮相（4-6s）：自然引出产品
第4层 核心卖点（6-9s）：只说1个最强卖点+证据
第5层 信任背书（9-11s）：数据/权威/用户证言
第6层 促动行动（11-13s）：制造紧迫感
第7层 品牌定格（13-15s）：logo+slogan+CTA
```
