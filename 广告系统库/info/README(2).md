## 使用规则

1. **每个知识条目**必须包含：来源、核心逻辑、适用场景、适配平台
2. **案例拆解**必须包含：行业、产品、卖点、受众、渠道、方法、成本、效果
3. **新知识入库**后必须检查是否与已有知识可以融会贯通，如有则更新 cross-references/index.md
4. **每日自动学习**的Top3书籍/案例放入 daily-learning/ 目录，定期整理归档到正式分类
