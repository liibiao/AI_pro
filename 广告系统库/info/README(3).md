---

## 渠道选择决策树

```
产品属性判断：
  ├─ 视觉驱动型（服装/美妆/食品/家居）
  │   → 小红书 + 抖音
  ├─ 信任驱动型（教育/健康/高客单价）
  │   → 微信私域 + 百度SEM
  ├─ 价格驱动型（日用/农产品/下沉市场）
  │   → 快手 + 拼多多
  ├─ 话题驱动型（品牌/新品/事件）
  │   → 微博 + 抖音
  └─ 搜索驱动型（B2B/本地服务/大宗消费）
      → 百度 + 今日头条
```

## 线上vs线下选择

```
纯线上：标品/全国发货/数字产品
纯线下：到店服务/体验型/高客单价面谈
线上+线下组合：本地服务/教育/零售门店
```
