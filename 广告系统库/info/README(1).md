# 每日工作日志（Memory）

> 用途：记录Agent每日工作内容、决策过程、用户反馈、经验教训
> 区别于 daily-learning/（学习记录），本目录记录实际工作执行

---

## 目录结构
```
memory/
├── README.md          # 本文件
├── work-log/          # 工作日志（按日期）
│   └── YYYY-MM-DD.md  # 每日工作记录
├── user-feedback/     # 用户反馈记录
│   └── YYYY-MM-DD.md  # 用户对方案的反馈
└── lessons/           # 经验教训
    └── lesson-XXX.md  # 编号经验
```
