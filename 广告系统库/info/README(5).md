## 视频广告前3秒视觉钩子

| 类型 | 手法 | 示例 | 适用行业 |
|------|------|------|---------|
| 感官冲击 | 微距特写+慢动作 | 巧克力融化滴落、面膜精华爆珠 | 食品、美妆 |
| 反常识画面 | 违反预期的视觉 | 把手机扔进水里、用锤子砸产品 | 3C、日用品 |
| 人物表情 | 夸张反应开场 | 惊讶→满足的表情变化 | 全行业 |
| 数字冲击 | 大数字+对比 | "3秒""10万人""省了2000" | 促销、教育 |
| 动作悬念 | 未完成动作 | 手伸向产品但不拿、拆箱只露一角 | 全行业 |
| 文字弹幕 | 模拟评论区 | 屏幕飘过"太好用了""求链接" | 种草类 |

## 钩子组合公式

1. **情绪+身份**："打工人谁懂啊，下班回家只想要这个"
2. **反差+悬念**："28块 vs 280块的巧克力，差距让我震惊"
3. **数字+痛点**："花了3万块才知道，其实只需要这一步"
4. **新闻+利益**："刚宣布的新政策，能帮你省XX钱"
