# 百度SEO/SEM方法论

> 最后更新：2026-04-14
> 核心定位：搜索引擎 → 精准意图截流

---

## 一、平台属性

| 维度 | 说明 |
|------|------|
| 用户画像 | 全年龄段，搜索行为=明确需求意图 |
| 内容调性 | 信息权威、解决问题、专业可信 |
| 消费链路 | 搜索关键词→点击结果→落地页→转化 |

---

## 二、两大打法

### SEM（搜索竞价广告）
- 品牌词：自家品牌名（防御性投放）
- 行业词：XX多少钱、XX哪家好
- 长尾词：XX城市+XX服务+价格
- 落地页：首屏核心卖点+信任背书+转化按钮

### SEO（自然搜索优化）
- 围绕长尾关键词创作高质量内容
- 百度百科/知道/贴吧/经验布局
- 官网+百家号+小程序三端联动

## 四、成本参考

- SEM竞价CPC：教育15-50元，本地服务3-15元，B2B 10-30元
- SEO外包：3000-10000元/月
- 百度信息流：CPM约10-30元

## 五、融会贯通

- 百度"搜索截流" + 抖音"兴趣推荐" → 搜索+推荐双漏斗
- 百度"落地页" + 微信"私域" → 公域获客+私域复购
- 百度"长尾词" + 小红书"种草" → SEO+种草双内容矩阵
