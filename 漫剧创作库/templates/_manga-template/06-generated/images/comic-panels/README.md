# Comic Panel Generation Notes — 漫剧格图生成说明

## 用途
本目录存放 AI 生成的漫剧分格图原始素材。

## 推荐命名

```text
chapter001_panel001_v01.png
chapter001_panel001_v02.png
chapter001_panel002_v01.png
```

## 版本说明

- `v01`：第一次生成
- `v02`：根据问题重做
- `final`：最终采用版本

## 筛选标准

- 角色脸是否一致
- 阅读方向是否正确
- 对白气泡区是否预留
- 场景与前后格是否连贯
- 动作是否清楚

## 不建议

不要把最终排版文件和原始生成图混放。最终排版应放在 `07-edit/`。
