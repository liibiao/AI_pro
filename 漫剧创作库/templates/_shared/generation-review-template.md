## 审核清单
### A. baseline 稳定性
- [ ] 主体清楚
- [ ] 关系表达清楚
- [ ] 关键动作 / 表演 / 事件可读
- [ ] 结果镜头成立
- [ ] 不依赖过强特效才成立

### B. 强化版有效性
- [ ] 强化后冲击力或速度感更强
- [ ] 强化后未破坏清晰度
- [ ] 强化后未吞掉关键信息
- [ ] 强化项收益可明确归因

### C. 回退策略有效性
- [ ] 能明确删掉最近一层强化
- [ ] 回退后关系重新清楚
- [ ] 回退后画面不再过乱 / 过糊
- [ ] 回退步骤可复用到相似镜头
