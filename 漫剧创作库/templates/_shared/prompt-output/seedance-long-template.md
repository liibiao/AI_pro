# Seedance 长版提示词母稿模板

> **默认语义（强制）**：以后用户或 Agent 说“长版提示词 / Seedance 长版 / 长版母稿”，默认都指本模板。  
> **核心结构**：`画面主体【完整】 + @Image 起手 + 逐条时间轴 + 六固定段名`。  
> **禁用旧版**：不再使用 `主体 / 空间 / 光影 / 镜头 / 台词 / 音效` 分字段块作为长版母稿结构；这些字段只能作为内部分析，不进入正式长版提示词。  
> **用途**：Seedance 长版母稿、全能参考 15 秒母稿、复杂动作拆解、跨平台派生源、QA 审稿基线。  
> **源头**：故事板生产包 / 分镜表 / 资产引用矩阵 / 参考图职责矩阵 / 视觉风格母版。  
> **派生**：即梦版、Seedance 字段版、叙事版、简版投喂稿都必须从本长版母稿压缩或转写。
> **对应规范**：`docs/dual-format-prompt-methodology.md` / `docs/prompt-standards.md` / `docs/seedance-prompt-engineering.md` / `docs/long-prompt-detail-gate.md`

## 标准片段格式

> 时间点数量不要照抄本示例。时间轴密度由剧情节奏、动作复杂度和画面呈现目标决定：普通空间建立、文戏、情绪压迫可以稀疏；闪现、瞬影杀、FPV 穿越、快切连击、瞬时换位等高复杂动作可以更密，但每个时间点都必须带来新的动作结果、空间关系、视角变化、声音变化或清晰结果帧。

```markdown
【第 X 段：0s - 15s】

画面主体【完整：[一句话概括本段全部任务：戏剧目的、主体关系、动作类型、镜头密度、第一读点、结果或钩子。]】
@Image@角色1 / @角色2 / @场景1 / @道具1——[站位/朝向/远近/强弱关系]，[空间关系]，[第一听感]。

0.0s（24fps / [景别] / [机位或运镜]）：[主体动作 + 微动作或受力反馈 + 环境反应 + 结果]——【音效：[环境音/拟音/特效音/状态音]】。
1.5s（24fps / [景别] / [机位或运镜]）：[动作继续推进，镜头运动绑定动作节点，补足空间关系或情绪变化]——【音效：[对应声画反馈]】。
3.0s（60fps 升格 / [景别] / [运镜]）：[升格服务的具体动作细节，如闪避、蓄力、擦身、命中边缘]——【音效：[骤静/抽声/材质声]】。
...
14.5s（24fps / [景别] / 稳定收束）：[结果帧、反转、收束或钩子，必须清晰可读]——【音效：[余波、呼吸、环境回稳或切点]】。

环境联动：[场景元素如何随动作、光线、风压、能量、情绪变化；必须具体到物件和结果。]

光线：[光源方向、色温、强弱、角色受光、武器/道具反光、环境反弹、关键帧清晰要求。]

对白配音：[只写人声层：台词 / 旁白 / 心声 / 气口 / 停顿 / 语速。无对白写“本段无对白配音”。]

音效设计：[环境层 + 动作层 + 材质层 + 特效层 + 状态层；按关键秒点绑定，不写泛泛 BGM。]

画质：[风格、分辨率、材质、光影质感、运动模糊边界、必须清晰的脸/手/武器/结果帧。内部风格库名必须展开为模型可执行描述。]

负面提示词：[针对本段风险定制：角色身份、服装、空间、动作连续性、关键道具、结果帧、光效、声音、字幕/水印。]
```

## 写作规则

1. **每段独立计时**：Seedance / 即梦等平台的片段生成不继承上一段时间轴，每段标题必须从 `0s` 开始，例如 `【第 1 段：0s - 15s】`。
2. **时间轴真实铺满**：标题写 15s，正文必须铺到 14.xs 或 15s 附近；不能只写到 8s 就收。
3. **`画面主体【完整】` 必须保留**：它是本段总纲，必须写清戏剧目的、主体关系、动作类型、镜头密度、第一读点、结果或钩子，不是宣传文案。
4. **`@Image` 起手必须紧跟**：写清资产锚点、站位、朝向、远近、强弱关系、主要空间参照和第一听感；已有资产必须使用直观中文 `@资产名`。
5. **逐条时间轴必须绑定动作**：每条都采用 `时间点（帧率 / 景别 / 机位或运镜）：动作 + 结果——【音效】`；禁止只有镜头参数没有动作，也禁止只写动作不写镜头、帧率和音效。
6. **时间点密度由剧情决定**：不得固定要求多少个时间点。只有当剧情节奏、动作阶段、主读点、空间位置、视角、帧率、声音或结果帧发生真实变化时，才新增时间点。激烈打戏、闪现、瞬影杀、快切、FPV 穿越可以更密；普通文戏、空间建立、慢压迫和结果余波应主动减少时间点，让模型有时间读懂。
7. **镜头语言不得独立成块**：帧率、运镜、景别必须嵌入具体动作节点；不得另起 `镜头：...` 字段块。
8. **六固定段名必须齐全**：`环境联动 / 光线 / 对白配音 / 音效设计 / 画质 / 负面提示词` 必须写在每一段里，简版只能压缩，不能删除。
9. **对白与音效分离**：`对白配音` 只负责人声层；`音效设计` 负责环境音、拟音、材质声、特效声、状态声；BGM 默认留给后期，不写进固定段名主结构。
10. **长版不是旧字段块**：不得把正式长版写成 `主体：/ 空间：/ 光影：/ 镜头：/ 台词：/ 音效：` 六字段分列。需要内部拆解时可先做工作底稿，但正式长版必须回到本模板。
11. **内部风格库名要展开**：不得裸写 `HZW 材质画质风格` 等内部代号；必须展开成材质、画质、光影、反射、空气介质、颗粒、清晰度和运动模糊边界。

## 长版与派生关系

- **长版母稿**：信息最完整，承担导演定稿、审稿基线、平台派生源。
- **简版投喂稿**：从长版压缩，只删解释层，不删动作链、结果帧和六固定段。
- **即梦版 / 叙事版 / Seedance 字段版**：只能从长版转写，不允许反向主导长版结构。
- **Seedance 2.5 连续叙事版**：是另一套连续叙事输出版本，采用 `生成任务 + 主要主体 + 场景与环境状态 + 情绪目标 + 视觉风格 + 分段脚本`；用户明确说 `seedance2.5` 时才使用该模板。用户只说“长版提示词”时，默认使用本模板。
