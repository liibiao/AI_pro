# seedance2.5-30s 输出模板

> **用途**：Seedance 2.5 的 30 秒连续叙事、一镜到底、电影感短片提示词。  
> **最大时长**：30s，不得超出。  
> **上游**：故事板生产包 / 30s 连续叙事 Shot 表 / 资产引用矩阵 / 视觉风格母版。  
> **核心公式**：生成任务 + 主要主体 + 场景与环境状态 + 情绪目标 + 视觉风格 + 分段脚本。  
> **对应规范**：`docs/seedance2.5-prompt-methodology.md` / `docs/prompt-standards.md` / `docs/storyboard-video-model-adaptation-standard.md`

---

## 【文件头】

```yaml
项目名：[项目标题]
集数段落：[如：第01集 第03段]
输出版本：seedance2.5-30s
适配模型：Seedance 2.5
总时长：30s
镜头形式：[一镜到底 / 多镜头 / 伪一镜到底]
影片类型：[悬疑 / 动作 / 情绪文戏 / 宣发 / 预告 / 奇观展示]
画面比例：[9:16 / 16:9 / 1:1]
主体切换次数：[0-3 次，越少越稳]
资产引用：[@人物 / @场景 / @道具 / @载具 / @视频 / @音频]
```

---

## 使用方式

本模板有三层：

- **工作底稿**：内部检查 30s 的主体全集、起点终点、空间过渡、情绪曲线与分段六步法。
- **正式流水线投喂稿**：默认交付形态，保留六大模块与六固定段名，供项目归档、Reviewer、自动化流水线和 Seedance 平台直接复制使用；分段镜头脚本必须是时间轴自然段，禁止表格。
- **平台极简投喂稿**：只在用户明确要求“直接复制到平台”时使用，可合并标题为自然段。

除非用户明确要求平台极简稿，默认交付 **正式流水线投喂稿**。

---

## A. 工作底稿（内部使用，不直接投喂）

```text
生成任务：[30s / 镜头形式 / 影片类型 / 音频规则]
主体全集：[@人物 / @载具 / @机械或怪物 / @道具 / @群众组 / @场景]
场景三层：基础空间 / 表层可视细节 / 隐性叙事氛围
起点终点：[镜头起点] → [镜头终点]
情绪目标：开篇 → 前中段 → 中段 → 后段 → 结尾
视觉风格：画面基调 / 光线与色彩 / 画面质感
过渡策略：主体接力 / 遮挡过渡 / 空间穿越 / 节奏停顿 / 末帧锁定
分段六步：每段检查跟随对象、运动路线、镜头解释空间、关系变化、停顿点、收尾信息变化
```

---

## B. 正式流水线投喂稿（默认交付）

时间轴数量和分段长度不固定，由剧情节奏、动作复杂度、主体切换、空间过渡和画面读点决定。30s 不是把 15s 模板机械翻倍；普通文戏、空间建立、慢压迫和结果余波应更疏，激烈打戏、闪现、瞬影杀、块切、FPV 穿越和多层斗法可以更密，但每个时间点都必须带来新的动作结果、空间关系、威胁变化、视角变化、声音变化或清晰结果帧。

```markdown
【生成任务】
生成一段 30 秒[一镜到底 / 多镜头 / 伪一镜到底]的[影片类型]短片，画面从 0s 独立开始，背景音乐轨道保持空白，只保留[环境音 / 动作声 / 人声气口 / 特效音]。

【主要主体】
全片只围绕 @人物1、@人物2、@载具1、@道具1、@场景1 展开，群众只作为背景循环，不抢主读点。镜头从[起点空间]开始，最终抵达[终点空间]；[表层可视细节]持续在画面里给出空间证据，[隐性叙事氛围]让观众比角色更早感到危险。视觉保持[画面基调]，[光线与色彩]随空间推进变化，[画面质感]稳定不漂。

【场景与环境状态】
[基础空间 / 表层可视细节 / 隐性叙事氛围，写清起点、终点和空间边界。]

【情绪目标】
[写真实段落推进方式，不机械套“开篇-中段-结尾”。动作段可采用追逃接力、骤停瞬杀、误导反杀、一镜穿越、空间压缩、结果余波等节奏。]

【视觉风格】
[画面基调 / 光线与色彩 / 画面质感。内部风格库名如 HZW 不得裸写给模型，必须展开为具体材质、画质、光影和氛围控制描述。]

【分段镜头脚本】
0-[按剧情决定的秒数]s，[自然导演口述开场：建立空间、主体、视觉锚点或直接进入危险，写清镜头从哪里进入，第一听感是什么]。

[按剧情决定的秒数]-[按剧情决定的秒数]s，[动作路线启动或关系突变：主体如何移动，镜头怎样解释方向、距离和空间边界，结尾新增什么目标、危险或误导]。

[按剧情决定的秒数]-[按剧情决定的秒数]s，[空间过渡、主读点接力或战术变化：镜头如何从一个高度、角度或景别过渡到新关系，主体位置和背景参照如何保持连续]。

[按剧情决定的秒数]-[按剧情决定的秒数]s，[主次切换、骤停、反杀、追逃接力或情绪放大：谁从主景变背景，谁成为新主读点，哪里需要停顿让观众读懂]。

[按剧情决定的秒数]-[按剧情决定的秒数]s，[后段蓄力、揭示、连续爆点或结果余波：危险如何逼近，误导如何被揭开，声音、光线、群众反应或环境反馈如何变化]。

[按剧情决定的秒数]-30s，[结果爆发、反转、收束或留钩子；末帧必须清楚读到主体关系、结果和下一段钩子]。

如果是一镜到底：用主体接力、遮挡过渡或空间穿越解释每次变化，不出现无理由硬切。

全片环境、光线与声音统一为：[把环境联动、光线、音效设计自然合成一段，按开篇/中段/结尾写变化]。

人声：[无对白则写“本段无完整对白，只保留...”；有对白则写清原文、语气和时间点]。

画质与负面约束：[画质要求 + 负面提示词。画质必须写具体材质、光影质感、清晰读点、可模糊对象与不可模糊对象，不要写内部风格库代号。重点约束主体丢失、空间跳变、后半段空转、结果帧不可读、群众抢主读点等 30s 风险]。
```

## C. 平台极简投喂稿（可选）

```markdown
把 B 稿压缩为自然段时，只能合并标题，不能删掉主体全集、场景三层、情绪目标、视觉风格、时间轴、环境联动、光线、人声、音效、画质和负面约束。平台极简稿也必须避免动作节奏同构。
```

## 【自检清单】

- [ ] 生成任务是第一项，并锁定 30s、镜头形式、影片类型、音频规则
- [ ] 时长不超过 30s，时间轴从 0s 开始并真实铺满
- [ ] 正式投喂稿的分段镜头脚本没有使用 Markdown 表格
- [ ] 所有主体、载具、机械、道具、群众组提前登记
- [ ] 场景三层完整，且写清起点、终点、空间过渡
- [ ] 情绪递进覆盖开篇、前中段、中段、后段、结尾
- [ ] 视觉风格包含画面基调、光线与色彩、画面质感
- [ ] 每段都有六步逻辑核对
- [ ] 一镜到底段落有主体接力、遮挡过渡或空间穿越说明
- [ ] 每段结尾都有信息变化
- [ ] 六固定段名齐全
- [ ] 无对白时写明“本段无对白配音”
- [ ] 30s 后半段没有重复氛围、主体漂移或空间断裂
- [ ] 正式流水线稿保留母板结构，没有把“去模板化”误处理为删结构
- [ ] 动作节奏没有机械复用“起势 → 推进 → 压制 → 反击 → 爆点 → 收势”
- [ ] 每段句式随镜头任务变化，没有六段同构复读
- [ ] 没有把 HZW 等内部风格库名称裸写给模型，已展开为材质、画质、光影和氛围描述
