# seedance2.5-15s 输出模板

> **用途**：Seedance 2.5 的 15 秒连续叙事提示词；同时兼容 Seedance 2.0 的 15s 规则。  
> **上游**：故事板生产包 / Shot 表 / 资产引用矩阵 / 视觉风格母版。  
> **核心公式**：生成任务 + 主要主体 + 场景与环境状态 + 情绪目标 + 视觉风格 + 分段脚本。  
> **对应规范**：`docs/seedance2.5-prompt-methodology.md` / `docs/prompt-standards.md` / `docs/dual-format-prompt-methodology.md`

---

## 使用方式

本模板有三层：

- **工作底稿**：内部检查六大模块与六步法，可以用表格。
- **正式流水线投喂稿**：默认交付形态，保留六大模块与六固定段名，供项目归档、Reviewer、自动化流水线和 Seedance 平台直接复制使用；分段镜头脚本必须是时间轴自然段，禁止表格。
- **平台极简投喂稿**：只在用户明确要求“直接复制到平台”时使用，可合并标题为自然段。

除非用户明确要求平台极简稿，默认交付 **正式流水线投喂稿**。

---

## A. 工作底稿（内部使用，不直接投喂）

```markdown
生成任务：[15s / 镜头形式 / 影片类型 / 音频规则]
主要主体：[@人物 / @场景 / @道具 / @载具，全集锁定]
场景三层：基础空间 / 表层可视细节 / 隐性叙事氛围
情绪目标：开篇 → 中段 → 结尾
视觉风格：画面基调 / 光线与色彩 / 画面质感
分段六步：每段检查跟随对象、运动路线、镜头解释空间、关系变化、停顿点、收尾信息变化
```

---

## B. 正式流水线投喂稿（默认交付）

时间轴数量和分段长度不固定，由剧情节奏、动作复杂度和画面读点决定。普通文戏、空间建立、慢压迫和结果余波应更疏；激烈打戏、闪现、瞬影杀、块切、FPV 穿越可以更密，但每个时间点都必须带来新的动作结果、空间关系、威胁变化、视角变化、声音变化或清晰结果帧。

```markdown
【生成任务】
生成一段 15 秒[一镜到底 / 多镜头 / 伪一镜到底]的[影片类型]短片，画面从 0s 独立开始，背景音乐轨道保持空白，只保留[环境音 / 动作声 / 人声气口 / 特效音]。

【主要主体】
@人物1、@人物2、@场景1、@道具1 是全片唯一关键主体。[写清角色年龄段、外貌锚点、服装、武器或道具职责，未登记主体不得中途新增。]

【场景与环境状态】
基础空间：[故事主发生地点、起始位置、空间边界。]
表层可视细节：[可见环境物件、天气、地面、光源、介质、破坏物。]
隐性叙事氛围：[本段危险、压迫、伏笔或误导。]

【情绪目标】
整体基调：[情绪关键词，但必须可视化。]
情绪递进：[不要机械写“开篇-中段-结尾”，要写本段真实推进方式，如冷开场截杀、追逃接力、骤停瞬杀、误导反杀、失重坠落、结果余波。]

【视觉风格】
1. 画面基调：[风格定位、动作阅读重点。]
2. 光线与色彩：[主光源、冷暖关系、能量色锚点。]
3. 画面质感：[材质、清晰度、速度线/颗粒/运动模糊边界。内部风格库名如 HZW 不得裸写给模型，必须展开为具体材质、画质、光影和氛围控制描述。]

【分段镜头脚本】
0-[按剧情决定的秒数]s：[按本段战术目的写画面，不套固定起势。可以从截杀、坠落、命中边缘、FPV 穿越、环境破坏或结果余波开场。写清主体位置、镜头进入方式、空间参照和本段新增危险。]

[按剧情决定的秒数]-[按剧情决定的秒数]s：[写动作因果和镜头绑定。不要机械“推进升级”，要说明角色为什么这样动、镜头为什么切到这个位置、观众读到什么关系变化。]

[按剧情决定的秒数]-[按剧情决定的秒数]s：[写空间变化或战术误导。可以是主读点接力、瞬杀失败、替身、反射、穿越介质、骤停抽声、失重翻滚等。关键命中/擦身/回避点必须清楚。]

[按剧情决定的秒数]-15s：[写结果或新危机。结果帧必须可读，允许留钩子，但不能只有光效和氛围。]

环境联动
[环境物件如何随每个动作节点变化。]

光线
[光源方向、色彩变化、角色脸部/武器/关键结果帧的受光要求。]

对白配音
[无对白则写“本段无对白配音，只保留呼吸、发力气口或短促反应”。]

音效设计
[环境底噪、近景拟音、武器/法术/材质声、爆点低频，按时间点绑定。]

画质
[画面风格、具体材质、光影质感、清晰读点、可模糊对象与不可模糊对象。不要写内部风格库代号，必须写模型可执行的视觉描述。]

负面提示词
[针对本段风险定制。]
```

---

## C. 平台极简投喂稿（可选）

```markdown
把 B 稿压缩为自然段时，只能合并标题，不能删掉主体全集、场景三层、情绪目标、视觉风格、时间轴、环境联动、光线、人声、音效、画质和负面约束。平台极简稿也必须避免动作节奏同构。
```

## 【自检清单】

- [ ] 生成任务是第一项，并锁定 15s、镜头形式、影片类型、音频规则
- [ ] 所有主体提前登记
- [ ] 场景三层完整
- [ ] 情绪递进有开篇、中段、结尾
- [ ] 视觉风格包含画面基调、光线与色彩、画面质感
- [ ] 时间轴从 0s 开始并铺满 15s
- [ ] 正式投喂稿的分段镜头脚本没有使用 Markdown 表格
- [ ] 每段都有六步逻辑核对，但正式稿不暴露六步标签
- [ ] 镜头运动与动作、空间揭示或情绪变化绑定
- [ ] 六固定段名齐全
- [ ] 无对白时写明“本段无对白配音”
- [ ] 正式流水线稿保留母板结构，没有把“去模板化”误处理为删结构
- [ ] 动作节奏没有机械复用“起势 → 推进 → 压制 → 反击 → 爆点 → 收势”
- [ ] 每段句式随镜头任务变化，没有同构复读
- [ ] 没有把 HZW 等内部风格库名称裸写给模型，已展开为材质、画质、光影和氛围描述
