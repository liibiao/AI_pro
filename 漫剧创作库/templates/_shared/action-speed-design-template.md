# action-speed-design-template.md — 公共动作速度方法母版

> 用途：作为短剧模板与漫剧模板共享的动作速度设计母版，避免两套模板重复维护。短剧 / 漫剧项目可在本母版基础上补充各自差异字段。

---

## 0. 使用原则
- 先判断对抗关系、身体受力、镜头节奏，再写速度与特效
- 外部视频只吸收关系、受力、节奏、结果，不照搬表面速度
- 倍速素材只作为节奏与镜头结构参考
- 提示词先写 baseline，再写强化版
- 生成漂移时优先回退 baseline，不继续堆词
- 动作节奏不能固定套“起势 → 爆发 → 命中 → 反应 → 收势”；这些只是可能出现的动作功能，不是默认顺序。强动作段应根据战术目的、空间变化和镜头视角选择截杀、失重、误导、穿越、骤停、接力、空间压缩或结果余波等结构。

## 7. 审核清单
- [ ] 看得懂谁压谁、谁在反扑
- [ ] 看得到重心、步伐、呼吸、肩背等受力信息
- [ ] 镜头停顿、推进、切近景、结果留拍已明确
- [ ] 快切没有破坏空间关系
- [ ] motion blur 没有吞掉命中点或表情
- [ ] 至少有一个清晰爽点帧
- [ ] 可进入生成 / 出图 / 出视频阶段

## 8. 短剧 / 漫剧差异提醒

### 短剧侧
- 更关注镜头连续性、表演节奏、剪辑点、声音与动作同步
- 强化版可更重视运镜、桥接与成片节奏

### 漫剧侧
- 更关注分格阅读顺序、静帧一致性、对白区 / 气泡区、页面节奏
- 强化版应避免特效吞掉阅读重点
