## @引用使用规范

在分镜提示词中使用场景引用时：
```
@scene-001 [废弃仓库场景]
@scene-001-720 [废弃仓库720度全景场景母图]
@scene-001-12view [废弃仓库12宫格固定视角图]
```
不要在提示词中凭空重构场景细节；分镜、导演故事板图和视频提示词必须优先引用 `720度全景场景母图` 与 `12宫格固定视角图`，并保持建筑、设施、道具、人物站位、群众/NPC/怪物/动物分布和光线方向一致。
