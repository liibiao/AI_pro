# 资产卡推演确认 UI 状态包

这组效果图用于补齐“文本节点生成剧本后推演资产卡”到“确认并创建分镜 + Seedance 提示词节点”的完整交互。

## 核心链路

文本节点生成剧本 -> 推演资产卡 -> 资产卡推演确认 -> 生成资产图 -> 确认资产图 -> 创建分镜 + Seedance 提示词节点。

## 状态说明

1. `00-full-corrected-workflow-overview.png`
   - 完整关系总览。
   - 明确文本节点、资产确认、资产提示词编辑、普通生图、MJ 四宫格、分镜提示词节点、Seedance 生视频节点之间的关系。

2. `01-empty-prompt-only-before-generation.png`
   - 刚从文本节点推演出来的资产确认页。
   - 此时没有任何生成图片。
   - 每个资产卡只有提示词摘要、分类、引用标签、上传参考图入口和生成状态。

3. `02b-prompt-editor-template-image-selector.png`
   - 双击资产 item 打开的提示词编辑弹窗。
   - 直接复用当前资产设计节点的编辑形态。
   - 顶部工具栏使用 `资产模板图片`，默认值为当前资产设计节点一致的 `三视图资产模板 / simple_three_view_sheet`。
   - 不使用“随机种子”字段。

4. `02c-template-image-dropdown-open.png`
   - `资产模板图片` 下拉展开态。
   - 用于选择不同资产模板图片。
   - 当前默认选中 `simple_three_view_sheet`。

5. `03-single-image-generated-confirm.png`
   - 普通生图模型生成后的资产确认页。
   - 生成结果为单张图，可直接作为资产图确认。
   - 确认后的引用标签必须变为带缩略图的 `@资源` clip。

6. `04-mj-four-grid-confirm.png`
   - Midjourney 生成后的资产确认页。
   - MJ 初始结果是四宫格，不是最终资产图。
   - 必须先选择四宫格中的一张，才能回填为真正资产图。

7. `05-mj-large-preview-backfill.png`
   - MJ 四宫格详情大图选择态。
   - 沿用当前查看大图逻辑和动画。
   - 点击四宫格 item 后查看大图，确认后回填到资产卡。

## 前端规则

- 资产确认页初始状态不能显示假图片；刚推演出来只有提示词和参考图上传入口。
- 双击资产卡 item 打开提示词编辑弹窗，弹窗应复用资产设计节点的参数和提示词编辑布局。
- 顶部工具栏字段应包含 `资产模板图片`，默认值对齐资产设计节点：`simple_three_view_sheet`。
- 普通生图结果是单图，确认后直接成为资产图。
- MJ 结果是四宫格，四宫格不能直接作为最终资产图；必须选择其中一张并回填。
- 所有 `@资源` 必须使用带图片的 clip 样式：缩略图 + 引用标签。
- `@资源` hover 时必须弹出大图预览卡，沿用当前图片大图查看逻辑。
- 只有资产卡全部确认后，`确认并创建分镜提示词节点` 才进入可执行状态。
