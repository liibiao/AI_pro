# hzw-master-style-skill — HZW大师风格统一技能

## 技能定位

本 skill 不是孤立生成技能，而是 HZW大师风格整剧总控系统的执行入口。它用于在每部剧开做之前，先确定整剧视觉风格、编剧师风格、导演风格和分镜师风格；再把用户持续提供的 HZW 风格学习资料，提炼成短剧 / 漫剧可复用的视觉方法论、规范与模板，并统一作用到最终提示词、资产图片、分镜图、视频和 QA。

核心规范文档：`docs/hzw-master-style-system.md`

---

## 适用任务

- 开剧前确定整剧视觉风格、编剧师风格、导演风格、分镜师风格
- 建立整部短剧 / 漫剧的统一视觉风格模板与 `hzw-style-bible.md`
- 让剧本、导演讲戏、资产图片、分镜图、视频提示词和最终成片统一参考本剧风格母版
- 生成 HZW大师风格角色定妆、场景氛围、封面、道具、静态分镜板提示词
- 把分镜表改写为 HZW大师风格镜头组
- 生成 HZW大师风格 Seedance / 即梦 / 图生视频提示词
- 吸收用户提供的新风格资料并更新方法论、模板和 skill

## HZW 风格输出总公式

```text
HZW大师风格 = 整剧视觉风格总控 + 编剧师风格 + 导演风格 + 分镜师风格 + 戏剧主读点 + 电影级空间层次 + 高控制光影色彩 + 可复用资产锚点 + 镜头动作融合 + 平台可执行参数
```

## 开剧前强制确认

每部剧正式进入剧本细化、资产生成、分镜或视频提示词生产前，必须先确认：

1. **整剧视觉风格**：这部剧看起来像什么，整体电影质感、题材气质、光色和材质是什么。
2. **编剧师风格**：故事节奏、冲突方式、台词气质、悬念和爽点组织方式是什么。
3. **导演风格**：场面调度、表演尺度、镜头意图、节奏和视听压迫方式是什么。
4. **分镜师风格**：镜头组、景别节奏、轴线、读点路径、爆点呈现方式是什么。

确认后必须形成 `hzw-style-bible.md` 或等效风格母版，后续提示词、资产图片、分镜图、视频都必须引用该母版。

任何输出必须锁定六类锚点：

1. 角色锚点：脸型、发型、服装、身体比例、标志物。
2. 场景锚点：空间结构、主材质、动线、尺度、世界观符号。
3. 光影锚点：主光方向、冷暖、明暗对比、轮廓光。
4. 色彩锚点：主色、辅色、点缀色、禁止色。
5. 氛围锚点：`high contrast` / `haze` / `semi metallic lighting` / `volumetric smoke or fog` / `sparks` 必须有叙事理由、空间位置、强度边界和与主体 / 光线 / 动作的关系。
6. 镜头锚点：景别偏好、视角身份、运镜方式、起幅落幅。

## 生图执行规则

生成 HZW 生图提示词时必须包含：

- 图像类型：角色定妆 / 场景氛围 / 封面 / 道具 / 静态分镜板 / 首帧 / 尾帧
- HZW大师风格标识
- 第一读点
- 主体锚点
- 前景 / 中景 / 背景空间层级
- 构图关系：可使用受控的 `voyeuristic framing` / `partial-body framing` / `asymmetrical balance` / `centered composition`，但必须写清主体与空间之间的关系、前景遮挡 / 裁切 / 视觉重量 / 居中秩序如何服务情绪
- 主光方向与色彩脚本
- 材质细节与环境介质互动
- 人物表演必须包含大动作之外的微动作真实感：微停顿、小肌肉反应、呼吸 / 视线 / 表情连锁和情绪理由；一个镜头只选 2-4 个关键微动作，禁止抽搐式堆叠
- 氛围控制必须写成“叙事理由 + 空间位置 + 强度 + 与主体 / 光线 / 动作的关系”；`high contrast` 必须服务第一读点并解决画面无重点，`haze` 只做轻到中度空气层且禁止达利园式假雾，`semi metallic lighting` 必须把画面照得有戏而不是照清楚，`volumetric smoke or fog` 必须有来源或位置，`sparks` 必须有焊接 / 摩擦 / 撞击 / 破损电路 / 能量释放等合理触发原因
- 若为机甲 / 装甲 / 载具 / 武器 / 金属道具，必须执行 HZW PBR 材质升级规则：只升级 PBR 材质，不新增几何；禁止只写“非常有金属质感”；必须写清材质与光线的真实物理互动；喷涂金属装甲 + clearcoat + Fresnel；粗糙度表示反光锐利或发散，现有面板 roughness variation 必须来自新旧、积灰、擦拭频率差异；微观纹理只允许摄影机近看可见的小纹理；脏旧必须有生活物理逻辑，污垢只在现有缝隙、关节、凹陷、积灰面或擦拭边界；边缘磨损只沿现有边缘；加强 AO、接触阴影、GI、高光滚降、电影化 HDR / 类 ACES；细微胶片颗粒和极轻微 halation 只用于去掉 AI / CG 过度干净感，不得风格化
- 输出比例与用途
- 禁止项：角色换脸、服装漂移、风格混杂、新增几何结构、随机裂纹、凭空战损、过度泛光、低清模糊、文字乱码、堆满氛围词、无来源烟雾、全屏雾化、火花过量、平亮无重点

复杂图、角色卡、分镜板、动作分解表优先采用 Prompt-as-Code JSON；单张海报、氛围图、首尾帧可采用自然语言设计说明。

提示词长度必须匹配目标复杂度：简单基础画面只保留核心目标，复杂电影画面才补齐空间、光影、材质、氛围和动作结果。禁止盲目抄长提示词，也禁止复杂目标只写极简词；每个描述都必须服务第一读点、主体、空间、光影、材质、氛围或结果。

提示词执行权重必须先校验：提示词没有固定执行顺序，只有多种信号的权重竞争。AI 会优先执行明确动作词、姿态词和对象词，不会自动补全隐含空间关系。必须检查词本身强度、是否容易视觉化、词之间是否冲突、训练数据高频组合和参考图视觉惯性。若结果看似符合提示词但与意图不一致，必须把隐性逻辑改成显性强权重词，如“身体朝向正前方”“头部正对目标”“目标位于画面正前方”，并删除会抢走构图、朝向或空间关系的高干扰动作词。

HZW 生图必须先做信息版（Readability Pass），再做情绪渲染版：信息版使用大屏光 / 高可读性光照，只锁定人物、道具、构图、主体行为、机位、静止项和允许运动项，禁止加入影调、氛围、PBR、体积光、雾、火花、胶片颗粒等效果；只有信息版内容正确后，才允许在其基础上添加 high contrast、haze、volumetric smoke or fog、PBR、AO、GI、电影化 HDR、细微胶片颗粒等情绪渲染词。若要更换完全不同的光影风格，必须回到信息版重做，禁止在情绪渲染版上反复补丁式修改。

## 场景执行规则

HZW 场景提示词必须写清：

1. 场景功能：文戏压迫 / 动作爆点 / 悬疑揭示 / 转场 / 觉醒仪式。
2. 空间结构：入口、主体活动区、纵深背景、可拍摄站位区。
3. 材质系统：主材质、磨损、裂痕、反光、湿度、年代感。
4. 光影色彩：主光方向、阴影范围、主色、辅色、点缀色。
5. 氛围控制：`high contrast`、`haze`、`semi metallic lighting`、`volumetric smoke or fog`、`sparks` 只能在有叙事理由、空间位置和强度边界时使用。
6. 镜头可读性：运动路径、前景遮挡、结果镜头落点。

禁止只写氛围词，不写空间结构；禁止用无来源雾气、过量火花或平亮布光替代场景设计。

## 分镜执行规则

HZW 分镜默认采用镜头组：

```text
建立镜头 → 推进镜头 → 爆点镜头 → 结果镜头 → 转场镜头
```

每个镜头必须包含：

- 镜头任务
- HZW 风格锚点
- 景别视角
- 起幅
- 动作 / 表演：必须包含大动作、微停顿、小肌肉反应、呼吸 / 视线 / 表情连锁和情绪理由
- 运镜绑定
- 落幅
- 光影变化
- 声音
- 禁止项

运镜必须绑定动作或情绪节点，禁止空泛写“电影感推镜”。

## 视频执行规则

生成 HZW 视频提示词时必须：

- 从故事板生产包派生平台生成说明，不允许每个平台各写各的
- 使用逐秒时间轴
- 保留固定段名：`环境联动 / 光线 / 对白配音 / 音效设计 / 画质 / 负面提示词`
- 明确起幅、动作推进、微动作节拍、光影变化、落幅和结果稳定帧
- 图生视频 / 即梦片段叠加 `jimeng-anti-collapse-core.md` 的防崩参数
- 氛围必须随动作、光线、危险源或环境变化而变化：雾气 / 烟尘 / 火花 / 高反差不能静态堆词，必须写清出现原因、位置、强度和与动作节点的关系

---

## 生成迭代与抽卡规则

HZW 允许抽卡，但必须先校正方向。生成失败时，禁止直接反复点生成，必须先检查主体定义是否过于笼统、镜头是否稳定、行为是否明确、场景中哪些元素允许运动、约束是否清晰。若“机甲 / 怪物 / 机器人 / 神秘装置”等词可能触发 AI 误解，必须替换为项目已登记资产名、参考图主体名或可识别的固定外观锚点。只有当主体、镜头、行为、场景和约束都正确后，再少量抽卡验证。

## 学习资料吸收规则

用户后续提供 HZW 学习资料时，必须按以下流程：

1. 判断资料归属：生图 / 分镜 / 场景 / 视频 / 光影 / 角色 / 材质 / 转场 / 后期。
2. 提炼稳定规则，不原样堆叠案例。
3. 判断是否与现有规范冲突。
4. 将规则归入 `docs/hzw-master-style-system.md` 对应章节。
5. 同步回填相关 skill、workflow、phase gate、README、pipeline sync log。
6. 若资料只影响风格说法为 L1；若新增模板为 L2；若改变输出字段或门禁为 L3。

## 失败信号

- 只写“HZW大师风格”，没有角色 / 场景 / 光影 / 镜头锚点。
- 每张图都好看，但整部短剧视觉不统一。
- 分镜阶段没有继承生图风格锚点。
- 视频提示词重写了角色、光线或场景结构。
- 运镜与人物动作脱节。
- 场景只有氛围，没有前中后景和可拍摄路径。
- 氛围词堆满画面，但没有叙事理由、空间位置和强度边界。
- 无来源烟雾、全屏假雾、火花过量、游戏技能特效感或平亮无重点。
