# Skill — project-doctor-skill (项目自诊)

## 技能描述
用于自动检测项目各阶段文档的完整性、一致性与逻辑冲突。它是 `Librarian` 的核心工具，确保项目在高速推进时不产生“文档债”。

## 执行逻辑
1. **结构审计**：
   - 检查 `01-09` 目录是否包含必要的 README 或索引文件。
   - 检查当前 Phase 对应的输出文件是否存在（如 Phase 1 必须有剧本）。
2. **资产链接审计**：
   - 扫描 `04-storyboard/` 中的 `@引用` 标签，核对 `03-assets/asset-index.md` 是否存在对应条目。
   - 核对 `06-generated/` 中的素材是否已在资产索引中登记。
3. **状态冲突审计**：
   - 比对 `project.json` 中的 `current_phase` 与实际文件产出。
   - 检测是否存在“分镜已完成但剧本被修改”的潜在冲突。

## 输出格式
输出一份《项目健康报告》，包含：
- **P0 (阻塞)**：缺失核心文档或严重索引错误。
- **P1 (风险)**：资产引用不一致或状态滞后。
- **P2 (建议)**：命名规范优化或文档补充。

## 适用 Agent
- `Librarian` (定期自检)
- `Producer` (门禁放行前检查)
