# script-writer-skill — 短剧编剧技能

## 技能定位
负责把灵感、标题、一句话设定、人物关系或小说原著，转化为适合 AI 短剧 / 漫剧生产的结构化故事内容。核心目标不是“写得像文学”，而是写出**可持续扩展、可分集推进、可分镜执行**的剧本系统。

## 适用任务
- 从 0 开始创作短剧项目
- 依据一句话灵感生成 logline
- 输出人物圣经、总大纲、分集剧本
- 优化台词与爽点密度
- 为导演讲戏和分镜阶段提供稳定文本基础

## 输入要求
开始前优先读取：
1. `project.json`
2. `01-story/inspiration.md`
3. `01-story/logline.md`（若已有）
4. `01-story/character-bible.md`（若已有）
5. `docs/style-guide.md`
6. `docs/episode-context.md`（若已有）
7. `docs/shortdrama-script-standard.md`

## 核心输出
- `01-story/logline.md`
- `01-story/character-bible.md`
- `01-story/outline-100ep.md`
- `01-story/structure-plan.md`
- `01-story/scripts/ep001.md` 等

## 工作方法
### 1. 先定题材与用户爽点
先明确：男频 / 女频 / 复仇 / 豪门 / 逆袭 / 灵异 / 动作 / 甜宠 / 悬疑。

### 2. 先一句话，再人物，再大纲
顺序不要乱：
- logline
- 人设
- 长线大纲
- 单集脚本

### 3. 单集必须有推进
短剧单集不能空转。至少满足：
- 一个冲突启动点
- 一个关系变化点或信息变化点
- 一个结尾钩子

### 4. 台词服务功能，不服务抒情
每句台词都应该承担：
- 推进剧情
- 反转关系
- 塑造人设
- 制造悬念
- 输出爽点

### 5. 先写事件，不写抽象总结
- 写谁对谁做了什么
- 写冲突如何发生
- 写打脸、逆袭、压制、反击的具体事件
- 不写“她开始布局”“他成功逆转”这种抽象句

## 短剧写作标准
- 前 3 秒尽量进入冲突
- 开场 30 秒内必须有吸睛点
- 节拍密度参考：每 2.5 秒 1 节拍
- 每集建议 500-800 字
- 每集至少 1 个强推进点
- 每集结尾必须留钩子
- 不写空泛情绪词，尽量转物理动作
- 主角不能一直憋屈，必须有阶段性胜利
- **严格执行《全品类武打动作戏设计规范》**：武戏必须写明胜负感与强弱变化，标出关键动作与物理破坏结果（使用 `△△`）。
- **严格执行《文戏与戏剧张力表现总规范》**：文戏禁止纯对白站桩。必须写出角色的“潜台词”，用 `△` 标出微表情或支点动作。

## 首集特别规则
- 0-30 秒：吸睛点 + 主角出场
- 30-90 秒：情绪递进 + 人设铺垫
- 90-120 秒：冲突爆发 + 悬念钩子

## 长线结构建议
- 1-10 集：身份隐藏 / 压制 / 建预期
- 11-30 集：小试牛刀 / 局部打脸
- 31-60 集：身份曝光 / 大规模反击
- 61-80 集：最终对决 / 情感与主线收束

## 漫剧写作标准
- 每话适合拆格
- 每 3-5 格有信息推进
- 对白不冗长
- 每话结尾留下翻页欲望

## 常用钩子类型
- 身份暴露
- 关系破裂
- 生死危机
- 新反派登场
- 新秘密出现
- 关键道具现身

## 失败信号
- 前 30 秒无冲突
- 主角目标不清晰
- 反派没有压迫感
- 一整集都在解释背景
- 台词像说明书
- 长篇独白过多
- 没有爽点或爽点来得过晚
