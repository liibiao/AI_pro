# art-design-skill — 服化道设计技能

## 技能定位
用于为短剧 / 漫剧项目建立可复用的视觉提示词资产，重点覆盖人物参考图、服装变体、化妆风格、场景参考图和道具视觉描述。

## 适用任务
- 生成人物面部特写提示词
- 生成人物三视图提示词
- 设计场景宫格图提示词
- 设计换装 / 战损 / 夜景等变体
- 建立 HZW大师风格角色、场景、道具、封面和静态分镜资产模板

## 核心输出
- `03-assets/style/visual-style-bible.md`
- `03-assets/characters/`
- `03-assets/scenes/`
- `03-assets/props/`

## 项目级风格母版硬规则
- 任何角色、场景、道具、封面、静态分镜板或导演故事板图资产生成前，必须先读取项目级 `visual-style-bible.md`；若项目尚未建立该文件，必须先按 `docs/film-style-bible-standard.md` 生成或补齐。
- `visual-style-bible.md` 必须继承 `docs/film-style-tone-system.md` 的主风格 / 副风格 / 光影 / 色彩 / 材质 / 画质 / 镜头 / 声音气质 / 禁止项结构。
- HZW大师风格不再被默认视为唯一风格；它可以作为主风格，也可以作为 PBR、构图、氛围、微动作、提示词权重控制等风格控制方法叠加到其他主风格上。
- 资产提示词不得临时混入未被 `visual-style-bible.md` 批准的新风格词；如需改风格，必须回到风格母版修订，而不是在单张图里补丁式改写。

## 人物资产要求
- 面部特写
- 正侧背多视图（正面 / 侧面 / 背面或背侧，比传统三视图增加背面视角）
- 服装主版
- 关键变体版
- 标识性外观锚点
- **硬性背景规则：所有角色资产必须使用纯白 / 干净浅色背景**，不加复杂场景、不加氛围背景、不用战斗现场背景，只允许极轻微地面接触阴影
- **硬性生成模型：角色设定稿统一使用 `gpt-image-2`**
- 写实人像 / 头像 / 写真必须采用"整体场景段 + 面部近距离特写锚点段"，补齐脸型、眉眼、鼻唇、肤质、妆容、服饰、姿态、机位和面部光影
- 角色设定 / 角色卡 / 官方参考卡必须明确版式分区：主立绘、多视图（正面/侧面/背面）、表情差分、服装道具细节（含纹样 zoom-in）、色卡、短标签；版面采用细黑线分栏、多宫格排版
- 多姿势 / 动作参考表必须保持同一角色、同一服装、同一比例，优先使用 4×4 网格、编号 1-16、动作标题、姿态说明、方向箭头或运动轨迹线
- 角色系列化资产（卡牌合集、阵营海报、成长弧线图）必须锁定角色视觉锚点，只允许改变状态、战损、服装阶段和光影氛围

## 场景资产要求
- 核心空间说明
- 光影版本
- 日 / 夜 / 雨 / 战损版
- @场景索引
- **硬性生成模型：核心场景设定交付物统一使用 `gpt-image-2`**
- **核心场景最终交付物：** 每个剧本核心大场景必须生成 `720度全景场景母图` 与 `12宫格固定视角图`，规范见 `docs/scene-design-sheet-spec.md`
- 场景图必须先从剧本提取大场景环境、空间结构、建筑物、设施、桌椅板凳、灯具、室外街道、群众、群演、NPC、怪物、动物、主角 / 反派 / 配角站位、入口出口、动作路径、可拍摄机位区和剧情关键道具
- `720度全景场景母图` 必须同时呈现水平方向 360° 环视、垂直 / 俯视空间信息、道具设施分布、人物与群众站位、NPC / 怪物 / 动物位置和动作路径，是后续分镜与镜头调度的空间母图
- `12宫格固定视角图` 必须基于同一张 720全景图派生，固定包含正前、前右45°、右侧、后右45°、正后、后左45°、左侧、前左45°、高机位俯视、低机位仰视、入口视角、出口 / 反向视角；建筑、设施、道具、人物站位、光线方向必须与全景图一致
- 微缩 / 树屋 / 古建 / 岛屿类场景必须明确产品类型为"3D微缩模型"或"场景概念图"，并写清等距视角、剖面层级、路径、人物尺度、材质与真实接触阴影
- 城市文化 / 节气 / 字体海报类场景必须明确主文字、地域符号、版式留白和禁止文字乱码
- 建筑 / 商业空间 / 室内外场景必须写清前景、中景、远景、功能区、动线、尺度参照和主光源位置
- 叙事场景 / 长卷场景必须明确主事件、冲突点、阅读顺序、人物位置、空间层级与视觉焦点，不得只写氛围词

## 道具资产要求
- **硬性背景规则：所有道具资产必须使用纯白 / 干净浅色背景**
- **硬性生成模型：道具设定稿统一使用 `gpt-image-2`**
- **独立出图门禁：** 只为重要的、独立承担叙事/动作/世界观功能的道具产出单独设定稿；角色随身武器、随身物品、头饰、配饰、鞋履、服装组件等已在角色卡中清晰展示的，不再单独出图，除非该道具后续独立承担关键剧情、特写、变形、激活、损毁或跨角色流转功能
- 道具设定稿必须采用多视角、多宫格排版：主视图 + 侧视图 + 背视图 + 俯视图 + 局部细节放大 + 材质/纹样 + 使用方式/比例参考
- 版面采用细黑线分栏排版，右侧为主展示图，左侧为多视角和细节拆解
- 道具细节必须包含圆形或方形 zoom-in callout（材质/纹样/发光点/接口/损伤）
- 所有道具必须能回填到 `@标签` 与资产索引

## 失败信号
- 人物脸每次不一样
- 资产无法复用
- 只有审美词，没有结构化信息

## HZW大师风格资产规则
- 当项目声明使用 HZW大师风格时，必须先加载 `docs/hzw-master-style-system.md` 与 `skills/hzw-master-style-skill.md`。
- 角色资产必须锁定角色锚点：脸型、发型、服装主色、身体比例、标志物和禁止漂移项。
- 场景资产必须锁定场景锚点：空间结构、主材质、世界观符号、可拍摄站位区和日夜 / 战损版本边界。
- 生图提示词必须写清第一读点、前景 / 中景 / 背景、主光方向、主色 / 辅色 / 点缀色、材质细节和禁止项。
- HZW 学习资料进入本技能时，只吸收可复用的角色、场景、道具、封面和静态分镜资产规则，不原样堆叠案例。

## 补充原则
- 参考图优先按 `docs/reference-image-analysis-standard.md` 拆成主体、表情、服装、场景、光影、构图和风格锚点
- 先提炼识别锚点，再写提示词，不直接照搬外部图像表面风格
- 角色 / 场景 / 道具设计都必须能回填到 `@标签` 与资产索引
