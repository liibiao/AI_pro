# seedance-action-skill — Seedance 动作武打戏设计技能

## 技能定位
专用于 Seedance 2.0 模型的动作戏设计与分镜拆解，融合港片与商业动作片七大体系：袁和平、洪金宝、成龙、李连杰、甄子丹、林正英、好莱坞动作节奏。

## 适用任务
- 设计动作链
- 设计动作分镜
- 编写 Seedance 动作提示词
- 控制动作节拍密度与镜头长度
- 为武打戏、追逐戏、法术戏提供专用模板
- 把抽象动作氛围拆成可执行镜头信息

## 七大风格速查
### 1. 袁和平
写实、短促、力学清晰、一招制敌。

### 2. 洪金宝
借力打力、环境互动、灵巧实战。

### 3. 成龙
幽默武打、险境化解、道具连锁。

### 4. 李连杰
飘逸写意、节奏留白、古风美感。

### 5. 甄子丹
高速压制、MMA 连招、不给喘息时间。

### 6. 林正英
道教仪式、符咒施法、僵尸受击逻辑、法术动作。

### 7. 好莱坞
极快切、重击反馈、大场面冲击力。

## Seedance 动作约束
- 每 2.5 秒 ≤ 1 个动作节拍
- 复杂连招必须拆镜
- 前后各留 0.5 秒安全区
- 独立动作片段必须从 `0s` 开始计时，标题时长必须被真实动作、关系动作、环境动作和结果镜头铺满
- 动作段必须先完成故事板生产包，动作投喂说明只能从故事板生产包压缩派生
- **Seedance 配套生成说明必须使用“画面主体【完整：...】 + @Image 起手 + 逐条时间轴 + 辅助段落”格式**
- **辅助段落 `环境联动 / 光线 / 对白配音 / 音效设计 / 画质 / 负面提示词` 必须写进配套生成说明，不允许省略**
- **对白配音只负责人声层；音效设计统一负责环境音 / 拟音 / 特效音 / 状态音；BGM 默认交给后期，不写进主固定段名**
- **动作故事板详细度门禁**：主体、动作、景别、镜头、帧率、画质、音效、人物/主体站位、朝向、距离、环境联动、光线和负面提示词必须写细；每条时间轴必须绑定具体动作、微动作/受力反馈、环境反应和音效，缺任一接口或过粗必须打回重写。
- **严禁无脑默认推镜头**：摄影机运动必须与角色的心理状态绑定（侵入、疏离、偷窥、迷失等），执行《摄影机运动与观众心理学规范》。
- **严禁跨时空硬切**：镜头之间必须使用高级转场（Match Cut, Action Match Cut 等），执行《视听转场与蒙太奇规范》。
- **物理互动**：动作必须明确物理介质（风、水、尘土）对人物的生理和物理影响，执行《环境氛围与物理互动规范》。
- **站位先行**：涉及围攻、追逐、压迫对峙、巨物登场时，必须先写清站位/朝向/距离，角色不得背对主要威胁源。
- **速度成段**：强打击段优先写成“蓄力→骤静→Hit Stop→爆裂释放→结果兑现”的链路。
- **视听同步**：关键命中点必须同步写清音效、特效与环境反馈，不得只写视觉炸点。
- 每条提示词控制 @引用数量
- 一条提示词尽量围绕一个核心镜头
- 复杂主体关系要拆分，不要让模型同时处理过多人、过多动作和过多高潮
- 快动作不等于多动作，速度感优先通过清晰动作链、短时爆发、明确受力和结果反馈来建立
- 必须区分起势、爆发、命中、反应、收势五个阶段，关键命中点与反转点优先保持清晰
- 涉及压制、反扑、失衡、再稳住等强对抗动作时，优先参照 `docs/action-case-opposition-force-camera.md`
- 编写动作提示词前，先明确“对抗关系 / 身体受力 / 镜头节奏”，再决定快切、motion blur 和镜头推进
- 外部视频参考优先吸收关系、受力、节奏与结果设计，不直接照搬表面速度和风格堆词
- 倍速视频只用于节奏与镜头组织参考，不作为原生动作质量标准
- 先写稳定 baseline，再做速度感与风格强化，生成漂移时先回退 baseline
- 强对抗长版时间轴必须逐秒写清：站位/朝向/距离、谁压谁、接触点、受力方向、被迫位移、止退/回稳、镜头停推切留拍、关键清晰点、环境与音效反馈
- motion blur、快切、前景掠过只能服务动作过程，不能覆盖命中点、结果帧和第一读点
- 涉及瞬移 / 闪现 / 残影 / 影分身 / 瞬杀快切时，必须额外写清空间锚点、消失点、再出现点、目标切换、残影层级、命中清晰帧、结果倒地与残影收束；残影只能表现速度路径，不能遮挡脸部、命中点和第一读点

### 场景触发规则
- **空中战斗** → 必加 `zero-gravity-parkour-standard.md` + `atmosphere-interaction-standard.md`（破风阻力+气流交互） + FPV 穿越（如有钻缝/穿越）
- **地面近战** → 必加 `perspective-system-emotional-mapping.md`（虫视角压迫+POV 受击代入） + `action-case-opposition-force-camera.md` + `environmental-destruction-standard.md`（地面碎裂）
- **追逐/逃逸** → 必加 FPV 穿越三段式 + `camera-psychology-movement-standard.md` §2.6 + `action-speed-design-standard.md`
- **法术/特效戏** → 必加 `vfx-design-standard.md`（光源绑定）+ `lighting-dynamics-prompt-guide.md`（光动态化）
- **唯美/高光动作** → 必加 `dance-rhythm-aesthetics-standard.md`（曲线美+呼吸感）
- **多人围攻/群战** → 必加 `crowd-choreography-standard.md` + `blocking-camera-geometry-methodology.md`（焦点让渡+坐标禁入区）
- **瞬移 / 影分身 / 闪现 / 残影瞬杀** → 必加 `action-speed-design-standard.md` §“瞬移影杀专项字段” + `action-case-opposition-force-camera.md` §“瞬移影杀：从高速位移到镜头瞬杀”，并按“围攻建立→骤静触发→消失→再出现→命中→结果→残影回收”拆段
- **任何强打击** → 必用 Hit Stop 机制（蓄力→骤静→爆裂释放→结果兑现）

## 动作设计顺序
1. 明确空间
2. 明确双方人数与强弱差
3. 先判断对抗关系（谁压谁 / 谁在硬撑 / 谁在反扑）
4. 再判断身体受力（重心 / 步伐 / 呼吸 / 落地 / 再稳住）
5. 确定风格（七大体系选一或组合）
6. **加载对应方法论 → 选择视角切换节奏流 → 规划运镜心理学绑定**
7. 拆动作链（起势→爆发→命中→反应→收势）
8. 若用于即梦 / 图生视频，继续拆为每秒关节步骤，并锁定参考强度75、seed、人物描述、光线、比例、运动速度6、采样步数40
9. 给镜头建议（每个镜头必须标注视角类型 + 运镜心理动机）
10. 编写提示词
11. 做易错检查（对照上方必读文档逐条核验）

## Seedance 2.0 提示词主结构
`主体 + 外观/服装 + 动作链 + 场景 + 景别/运镜 + 光线/天气 + 风格 + 细节限制`

### 动作提示词结构建议
- 主体是谁
- 主体穿什么 / 长什么样
- 对抗关系是什么
- 动作链如何发生
- 身体受力与受力方向
- 场景空间与地面/道具
- 景别与运镜
- 时长与节拍
- 停顿点 / 推进点 / 结果镜头
- 光影参数
- 风格关键词
- 材质与微动作细节

## 先稳后强迭代法
1. 稳定版：只写主体、动作（融合帧率）、场景
2. 镜头版：加入景别、机位、推拉摇移跟（与动作时刻绑定）
3. 氛围版：加入光线、天气、时间、色彩
4. 质感版：加入衣摆、发丝、倒影、灰尘、水珠等微细节
5. 节奏版：微调动作速度、停顿点和安全区
6. 三要素版：补足对抗关系、身体受力和结果镜头，让动作真正成立

## 失败信号
- 一镜多核心动作
- 动作受力逻辑不通
- 没有区分不同风格
- 施法戏没有仪式动作
- 打戏虽然花哨但模型生成不稳定
- 只写“激烈”“震撼”“电影感”，没有具体动作、镜头和受力
- 风格词过多导致模型输出漂移
