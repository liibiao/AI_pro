# director-skill — 导演讲戏技能

## 技能定位
将剧本中的抽象情节转换为可执行的画面说明。核心目标是把"故事文本"转成"物理动作 + 镜头调度 + 光影参数 + 表演指令"。

## 适用任务
- 把 `01-story/scripts/` 转成导演讲戏本
- 设计场次调度、人物走位、动作链
- 给分镜师提供可拆镜头的基础文稿
- 把情绪词转成可视动作
- 在需要时调用 `shot-design-skill`，先为重点段落做专项镜头方案设计

## 输入要求
1. `project.json`
2. `01-story/scripts/ep*.md` 或 `chapter*.md`
3. `01-story/character-bible.md`
4. `docs/style-guide.md`
5. `02-director/action-design/action-style-guide.md`（若已有）

## 输出位置
- `02-director/ep*-director-notes.md`
- `02-director/action-design/ep*-fight-scenes.md`
- `02-director/action-design/action-style-guide.md`

## 导演讲戏五原则
1. 动作具体：不用抽象情绪词代替动作（执行《文戏与戏剧张力表现总规范》与《环境氛围与物理互动规范》）
2. 动作连续：每一步都要有因果关系，武戏明确受力与强弱反转（执行《动作速度表现规范》与《全品类武打戏规范》）
3. 镜头有方向：推、拉、摇、移、跟要写清，将摄影机运动与观众心理学绑定，注意权力调度与空间屏障，标明跨场景转场方式（执行《摄影机运动与观众心理学规范》与《视听转场与蒙太奇规范》）
4. 光影有参数：明确主光源方向与色彩基调，确保人物视觉阶段与剧情成长匹配（执行《光影与色彩美学规范》与《角色视觉成长弧线规范》）
5. **镜头动作融合**：帧率切换、运镜、景别变化必须与人物的具体动作和表演绑定编写，禁止独立列出"镜头与构图"板块。每个时间戳必须紧跟具体动作，升格/降格必须说明为放大什么细节或释放什么冲击。文戏同理——镜头推近必须与角色微表情变化绑定，不能单独写"镜头缓慢推近"。（执行《提示词编写规范》「镜头动作融合原则」）

## 高张力段落附加原则
- 必须先交代站位、朝向、距离与主读点，再写爆点
- 巨物/怪物/多人围攻场景中，角色不能背对主要威胁源
- 优先把爆点写成“蓄力→骤静→Hit Stop→爆裂释放”的速度链路
- 音效、特效、环境反馈必须与命中点或压迫点同步
- 每个强爆点后都要给结果镜头，交代新的对峙关系
- 执行 `docs/staging-impact-audiovisual-methodology.md`

## 输出结构建议
每场至少包含：
- 场次目标
- 人物调度
- 动作链 / 情绪动作链
- 镜头建议
- 光影建议
- 给分镜师的提醒

## 故事板生产包总控职责（新增）
- 导演阶段默认先产出**可拆成故事板生产包的讲戏输入**，用于承接剧本、分镜、资产、导演故事板图与后续模型适配。
- 配套生成说明只能由故事板生产包派生，不能跳过故事板直接写平台投喂稿。
- 独立视频片段的时间必须从 `0s` 开始，并且标题时长必须在 Panel 与模型适配说明中真实铺满。
- 导演必须在讲戏阶段就决定该片段是 5s / 10s / 15s，并规划镜头密度、动作密度与结果镜头。
- 必须标记哪些信息属于“禁止压缩项”：关系建立镜头、关键动作链、结果镜头、速度反差链路、角色阶段与环境主状态。

## 特别提醒
- 不要只写"镜头切到"这种空话
- 不要把打戏写成概念词
- 不要设计 Seedance 难以执行的一镜多动作
- **禁止独立列出"镜头与构图"板块**——镜头信息必须与动作融合编写
- **帧率切换必须绑定具体动作时刻**，说明为放大什么细节或释放什么冲击
- **文戏镜头推近也必须与微表情变化/视线移动/姿态转变绑定**

## 失败信号
- 全篇仍是文学描述
- 缺少空间调度
- 镜头无方向
- 光影缺失
- 动作很酷但不可执行
- 镜头信息与动作分离列出
- 帧率切换未说明目的
