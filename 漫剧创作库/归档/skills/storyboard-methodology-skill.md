# storyboard-methodology-skill.md — 分镜方法论技能

## 技能定位
把导演讲戏、现有规范和平台约束，统一转化为**可执行的分镜系统**。本技能不是单纯“拆镜头”，而是负责把戏核、空间、节拍、镜头任务、衔接方式和平台执行性焊成一条链。

> 本技能负责段落级分镜组织；单镜级的镜头任务、视角身份、运镜与起落幅优化，可调用 `shot-design-skill` 作为专项能力补强。

## 适用任务
- 从导演讲戏本提炼分镜策略
- 把散乱镜头整理为镜头组
- 修复一镜多任务、关系不清、结果缺失、节拍失衡等问题
- 给 `Storyboard Artist` 和 `Director` 提供统一的分镜思维框架
- 为故事板生产包与下游配套生成说明提供分镜底层逻辑
- 为 D12-Sora2 / D15-Seedance2 专业导演故事板图提供格数、时长、镜头组、连续性和模型适配底层逻辑

## 核心方法
### 0. 基础影视规则优先
在进入五层模型之前，先执行基础影视分镜规则：
- 先判断轴线是否明确
- 先判断合法机位区是否稳定
- 对双人对话 / 采访 / 对手戏，优先套用**正反打五镜头公式**
- 若输入存在越轴、视线反向、左右互换，先修正再输出，并注明修正原因
- 景别与机位优先采用经典基础模板：主镜头 / OTS / 单打 / 侧机位
- 连续近似机位必须检查 **30°原则**，避免跳切
- 若必须越轴，只能通过：运动越轴 / 中性镜头越轴 / 全景重置越轴

### 0.5 老白实操 SOP 优先套骨架
在正式写分镜前，优先执行：
1. 按起承转合拆段落，再切动作单元
2. 每个动作单元先抓开始帧 / 高潮帧 / 结束帧
3. 只补必要过渡镜头，观众能脑补的镜头优先删除
4. 先按情绪与信息量标时长
5. 同步挂入台词 / 音效 / BGM 起止
6. 用动作匹配 / 视线匹配 / 方向匹配检查衔接
7. 最后再进入五层模型细化

### 0.6 主镜骨架优先
在细化镜头前，先找这一段**不可替代的核心画面**：
- 先浓缩一句话主镜
- 再拆 3-5 个关键主镜节点
- 再从主镜反推：机位区、景别、视高、插入镜头、过机位、反应镜头
- 多人 / 多轴场景时，先找核心互动轴，再决定其他轴线如何并入

### 0.7 合规校验模式（新增）
在输出分镜前，必须对关键空间规则执行四步校验：
1. **识别定义**：当前场景属于哪种互动结构、核心轴线是什么、主机位区在哪里。
2. **判定后果**：若违规，会导致左右关系反转、视线错乱、空间认知中断还是情绪割裂。
3. **命中红线**：检查是否出现跳轴硬切、无主镜直接拆镜、无全景直接进三人正反打、为好看乱跨轴等新手高频错误。
4. **执行修复**：按优先级选择补主镜 / 补全景 / 插中性镜头 / 插过机位 / 拆段处理 / 重排焦点。

### 0.8 高级叙事控制层
在基础空间规则成立后，继续检查五项：
1. **视觉焦点是否唯一且稳定**：用构图 / 光影 / 景深 / 运动控制观众第一眼读点。
2. **空间感是否成立**：是否有前中后景层次、方位锚定、透视与遮挡关系。
3. **运镜是否有动机**：推拉摇移跟升降甩晃都必须绑定叙事与情绪目标，并具备起幅 / 落幅。
4. **视角是否统一**：区分客观 / 主观 / 半主观，避免无来源 POV 和主视角乱跳。
5. **组接是否具备蒙太奇逻辑**：连续 / 平行 / 交叉 / 对比 / 隐喻 / 抒情是否服务当前段落。

### 2. 镜头组优先
优先输出镜头组，而不是直接罗列镜头。至少识别：
- 建立组
- 推进组
- 爆点组
- 结果组
- 转场组

### 3. 单镜检查
每镜必须回答：
- 这镜主任务是什么
- 首看点是什么
- 结果点是什么
- 为什么用这个视角
- 为什么在这里切
- 不成立时回退方案是什么

## 分镜四大硬门禁
1. **可读性门禁**：首看点 / 结果点明确
2. **空间门禁**：站位、轴线、屏幕方向稳定
3. **节拍门禁**：密度受控，爆点前后有进入与收尾
4. **平台门禁**：母稿格式统一，多平台同源

## 输出要求
输出的分镜表或分镜建议中，至少补齐以下字段：
- 镜头任务
- 位置关系
- 首看点
- 结果点
- 分镜衔接方式
- 风险 / 回退点
- 若发生越轴 / 视线反向 / 左右互换修正，必须补一行“修正说明”
- 对话类场景应优先标记当前镜头属于：主镜头 / OTS / 单打 / 侧机位
- 若输出 D12-Sora2 / D15-Seedance2 导演故事板图，必须补齐 Panel 编号、起止时间、每格时长、时长求和、视频模型适配包和连续性卡

## 失败信号
- 把分镜写成剧本文学改写
- 镜头只有炫技，没有叙事任务
- 没建立关系就直接爆点
- 只有过程没有结果
- 快切很多但没有看清点
- 平台稿能写但平台难执行
