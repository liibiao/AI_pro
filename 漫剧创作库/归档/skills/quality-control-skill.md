# quality-control-skill — 两步审核技能

## 技能定位
用于在每个阶段结束后，对项目产出进行业务审核与合规审核，并输出一次性、可执行的修改建议。目标是减少返工，提高阶段放行质量。

## 适用任务
- 审核剧本
- 审核导演讲戏
- 审核资产设计
- 审核故事板生产包
- 审核 D12-Sora2 / D15-Seedance2 专业导演故事板图、连续性卡、资产引用矩阵、参考图职责矩阵和视频模型适配包
- 审核 `05-prompts/` 配套生成说明是否忠实继承故事板生产包
- 审核平台合规风险

## 输入要求
1. 当前待审核文件
2. `project.json`
3. `docs/style-guide.md`
4. `docs/prompt-standards.md`
5. `docs/long-prompt-detail-gate.md`
6. 历史 QA 记录（若有）

## 两步审核法
### 第一步：业务审核
按阶段打分：
- 剧本：节奏 / 冲突 / 爽点 / 钩子 / 台词
- 导演讲戏：动作链 / 镜头逻辑 / 光影清晰度
- 资产：一致性 / 标签规范 / 可复用性
- 分镜：节拍密度 / @引用 / 安全区 / 衔接

#### 故事板生产包与配套生成说明加测项
- 是否明确当前中游主交付是故事板生产包，而不是长版提示词母稿或多平台派生稿。
- 分镜表、导演故事板图、Panel 时长、连续性卡、资产引用矩阵、参考图职责矩阵、视频模型适配说明是否完整。
- 每个镜头 / Panel 是否具备镜头任务、景别、机位、视角身份、起幅、过程、落幅和结果点。
- `对白配音 / 音效设计` 职责边界是否清楚，无对白段是否明确写出“本段无对白配音”。
- 动作、运镜、景别变化是否与人物动作和表演绑定，而非孤立列摄影项。
- 强对抗段落是否写清对抗关系、站位 / 朝向 / 距离、接触点、受力方向、重心变化、被迫位移、止退 / 回稳、命中反馈、结果帧、镜头停推切留拍、关键清晰点、环境与音效反馈；文戏段落是否写清微表情、呼吸、视线、手部细节和声音层次。
- 瞬移 / 影分身 / 闪现 / 残影瞬杀段落是否写清空间锚点、消失点、再出现点、目标切换、残影数量 / 透明度 / 持续时间、命中清晰帧、目标倒地结果、残影回收和收势落幅；若残影混乱、遮脸、遮命中点、空间跳点无逻辑或连续快切无结果，必须打回。
- 素材职责矩阵是否明确（形象/动作/运镜/节拍各归一处），是否命中“素材抢权”风险。
- 若存在 `05-prompts/` 配套生成说明，是否忠实继承故事板生产包的主动作链、结果镜头、声音结构、资产引用和参考图职责。
- 涉及 `FPV` 的段落是否写清：入口 / 穿越介质 / 擦身关系 / 出口 / 结果镜头，并具备速度参照物。
- 音效、特效、环境反馈是否与关键命中点同步。

#### 专业导演故事板图（D12-Sora2 / D15-Seedance2 加测项）
- D12-Sora2 故事板总时长是否 `≤ 12s`。
- D15-Seedance2 故事板总时长是否 `≤ 15s`。
- Panel 时长求和是否正确，是否存在无任务 Panel 或时长灌水。
- 每格是否具备镜头任务、景别、机位、视角身份、起幅、过程、落幅和结果点。
- 人物站位、朝向、距离、空间关系和运动方向是否清楚。
- 故事板图是否包含剧本、对白配音、音效设计、光影风格、导演批注、资产引用和连续性区。
- 板内、板间、集间连续性是否成立，连续性卡是否完整。
- Sora2 版本是否遵守“一张 D12 故事板图 + 简短动态风格叙事提示词”，且提示词没有变成长版提示词。
- Seedance2-Stable 是否限制在 `4图 + 1视频`，并按 `导演故事板图 > 关键角色图 > 场景图 > 关键道具图` 优先级裁剪。
- Seedance2-Extended 是否限制在 `9图 + 1视频 + 1音频`，且仅在稳定版不足时启用。
- 是否明确故事板图是视频生成前主交付物，提示词仅作为内部引擎和模型适配说明。

### 第二步：合规审核
重点查：
- 过度血腥
- 版权风险
- 明显真实人脸模仿
- 敏感政治/宗教/迷信表达
- 未成年人风险

### 第三步：台词锁定校验（最高优先级）
对分镜表执行台词锁定验证：
1. 从原始剧本提取所有台词（正则匹配引号内容）
2. 从分镜表中提取所有台词
3. 逐条比对：遗漏台词、改写台词（语序调整/省略后半句/意译）均标记为**严重错误**
4. 如发现差异，以原始剧本为准，要求逐条修正
5. 校验通过后输出"台词锁定验证通过"

### 第四步：故事板与配套生成说明一致性、否定句校验
当存在 `05-prompts/` 配套生成说明时：
1. **台词一致性**：生成说明中的台词必须逐条对比故事板 / 原剧本一致，以原剧本和故事板为准
2. **时间轴一致性**：生成说明总时长必须与故事板 Panel 时长一致
3. **核心动作语义一致**：主动作链、结果镜头、情绪基调不可脱离故事板生产包
4. **否定句排查**：自动替换否定表达为正向指令（如"不要移动"→"保持静止"，"不要BGM"→"仅自然环境音效"）
5. **@标签一致性**：生成说明中的 @标签必须追溯到故事板资产引用矩阵；若模型版本需要真名替换，必须保留映射记录

## 输出位置
- `08-qa/ep*-script-review.md`
- `08-qa/ep*-storyboard-review.md`
- `08-qa/ep*-prompt-review.md`
- `08-qa/compliance-log.md`
- `08-qa/phase-gate.md`

## 输出格式建议
- 审核结果：通过 / 不通过
- 分数：10 分制
- 业务问题：定位 + 建议
- 合规问题：风险等级 + 建议
- 结论：是否进入下一阶段

## 审核原则
- 一次性把问题提全
- 必须定位到文件 / 段落 / 镜头
- 建议必须可执行
- 合规优先级高于审美

## 失败信号
- 只说好坏，不说具体问题
- 没有是否通过结论
- 没有优先级
