# dialogue-voice-director-skill — 对白配音设计技能

## 技能定位
用于把剧情、分镜、角色设定里的**人声层信息**提炼成轻量可执行的 `对白配音` 要求，服务故事板生产包、配套生成说明与后期配音沟通。

## 适用任务
- 为分镜表、导演故事板图、视频模型适配说明和配套生成说明补写 `对白配音`
- 区分台词、旁白、心声、喘息、压气等人声层职责
- 为文戏、武戏、对峙戏、钩子戏设计简洁的人声表达
- 优化“台词能看懂但说不出来”的配音描述
- 为后期配音与字幕留出明确边界

## 核心原则
- 先判断剧情任务：信息推进 / 情绪转折 / 权力变化 / 留钩子。
- 先有人，再有声：对白配音必须服从角色年龄、身份、阶段与关系位置。
- 先气口，再台词：短剧与漫剧最怕台词写满却没有停顿、压气和嘴型落点。
- 无对白也要明确：没有台词时，直接写 `本段无对白配音`，不要用空白默认。
- BGM 不归本技能负责：默认交给后期，不写进主提示词固定段名。

## 执行方法
1. 先判断本段是否有对白 / 旁白 / 心声。
2. 再判断说话人是谁，当前处于什么情绪和身体状态。
3. 写清：台词内容（或无台词）、音色倾向、语速、停顿、气口、是否贴口型。
4. 若用于即梦文戏生成，补齐眼神方向、口型轻量化、结尾表情稳定0.3秒、首帧与上一段尾帧一致。
5. 只保留最关键的人声信息，不做冗长配音脚本。
6. 如人声只剩喘息、闷哼、压气，也归入 `对白配音` 段，不误并入音效总层。

## 长短版写法标准
- **长版**：写清说话人、台词任务、情绪、语速、停顿、气口。
- **简版**：只留“谁说 / 是否无对白 / 核心语气”。
- **即梦版**：用最短硬词锁住台词任务和气口。
- **Seedance版**：与动作、表演、口型节奏协同，不抢画面主任务。
- **叙事版**：保持导演口述顺读感，不写成配音表格。

## 常见失败信号
- 台词说明剧情，却不符合角色口气
- 只写“愤怒地说”，没有停顿和气口
- 把喘息、吼叫、心声、旁白混成一个层
- 明明无对白却默认沉默，导致后续执行口径不清
- 把 BGM 误写进对白配音要求

## 一句执行口令
**对白配音要服务角色、表演和口型，不要替剧情写解说词。**
