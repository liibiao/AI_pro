## HZW大师风格视频规则

当项目声明使用 HZW大师风格时，视频提示词必须加载 `docs/hzw-master-style-system.md`：

- 多模态素材职责必须继承角色锚点、场景锚点、光影锚点、色彩锚点和镜头锚点。
- `@Image` / `@Video` / `@Audio` 只负责对应控制维度，不能互相覆盖导致风格漂移。
- 时间轴中必须写清起幅、动作推进、光影变化、落幅和结果稳定帧。
- 固定段名 `环境联动 / 光线 / 对白配音 / 音效设计 / 画质 / 负面提示词` 不得删除。
- 若为即梦 / 图生视频 / 连续人物片段，必须叠加 `docs/jimeng-anti-collapse-core.md` 的防崩参数。
