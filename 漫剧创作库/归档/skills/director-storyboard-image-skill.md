## 1. 技能定位

本 Skill 负责把剧本、分镜表、导演讲戏、资产图和模型规格，转化为可由 `gpt-image-2` 图生图生成的专业导演故事板图方案，并为 Sora2 / Seedance2 输出视频生成适配包。

故事板图是视频生成前主交付物。提示词只作为内部引擎和模型适配说明，不默认输出。

---

## 2. 适用任务

当用户要求以下任务时必须调用本 Skill：

- 生成专业导演故事板图；
- 生成 D12-Sora2 故事板；
- 生成 D15-Seedance2 故事板；
- 将分镜表转为可生成视频的故事板图；
- 为 Sora2 / Seedance2 准备故事板视频生成输入包；
- 设计故事板格数、每格时长和镜头节奏；
- 检查故事板图连续性；
- 建立故事板图模板或规范。

## 4. 输入要求

必须收集：

- 剧本段落；
- 分镜表；
- 导演讲戏；
- 场景类型；
- 影片基调；
- 角色资产图；
- 场景资产图；
- 必要道具图；
- 上一板尾帧；
- 下一板首帧预期；
- 目标模型：Sora2 / Seedance2 / 双版本。

---

## 5. D12 / D15 判断

### D12-Sora2

- 总时长 `≤ 12s`；
- 使用一张 D12 导演故事板图作为视频主参考；
- 视频生成阶段只追加简短叙事风格提示词；
- 不默认追加角色、场景、道具多图。

### D15-Seedance2

- 总时长 `≤ 15s`；
- 使用 D15 导演故事板图 + 角色 / 场景 / 道具参考图；
- 必须输出稳定版或非稳定扩展版参考图规划。

---

## 6. 场景类型判断

必须先按 `docs/scene-type-style-library.md` 与 `wordlists/style/scene-type-presets.json` 判断故事板场景类型。基础覆盖包括但不限于：

- 动作 / 战斗：徒手打戏、武侠刀剑、仙侠法术、枪战、围攻、终结技；
- 速度 / 载具：赛车、追车、街头追逐、飞行、坠落、FPV 穿越；
- 文戏 / 情绪：双人对话、争吵、告白、诀别、独白、审讯；
- 悬疑 / 惊悚 / 灵异：揭示、凶案现场、鬼屋、灵异显现、僵尸围困；
- 喜剧 / 荒诞：误会、反差、群体闹剧、萌宠日常；
- 黑帮 / 警匪 / 犯罪：谈判、卧底、追捕、审讯、枪战；
- 奇幻 / 仙侠 / 国风：觉醒、宗门试炼、神话 CG、江湖压迫；
- 科幻 / 赛博 / 末日：霓虹雨夜、机甲、城市逃亡、废土；
- 文艺 / 青春 / 治愈：车站、雨夜、海边、校园、回忆。

场景类型决定格数、时长密度、镜头组结构、光影画质、声音复杂度和推荐 D12 / D15 Panel 数。

---

## 7. 格数与时长规划

输出前必须列出：

```markdown
| Panel | 时间码 | 时长 | 镜头任务 | 景别 | 机位 | 运镜 | 动作结果 |
|---|---|---:|---|---|---|---|---|
```

并执行求和：

```text
D12: Σ Panel Duration ≤ 12s
D15: Σ Panel Duration ≤ 15s
```

---

## 8. 版面设计

故事板图必须包含：

- 标题栏；
- 模型版本；
- 总时长；
- 主分镜区；
- 剧本 / 台词；
- 对白配音；
- 音效设计；
- 人物站位；
- 空间关系；
- 运镜箭头；
- 运动箭头；
- 光影风格；
- 导演批注；
- 资产引用；
- 连续性区；
- 视频模型适配区。

---

## 9. gpt-image-2 内部提示词构建

内部提示词结构：

```text
任务类型 + 故事板版本 + 剧情母段 + 资产引用 + 版面结构 + 分格数量 + 每格镜头内容 + 人物站位 + 空间关系 + 运动箭头 + 台词音效 + 光影风格 + 导演批注 + 连续性要求 + 禁止项
```

内部提示词用于生成故事板图，不默认交付给用户。

---

## 10. Sora2 适配包

Sora2 输出：

```markdown
## D12-Sora2 视频生成适配包

- 主输入：D12 导演故事板图
- 简短提示词：
  根据 @导演故事板图 生成视频。请遵循故事板中的镜头顺序、人物站位、动作路径、空间关系、光影方向、镜头运动和导演批注。
  [根据本项目影片基调动态生成的风格 / 光影 / 节奏 / 动作速度补充]
```

禁止把 Sora2 适配提示词写成长版提示词。

---

## 11. Seedance2 稳定版适配包

Seedance2 稳定版按 `4 图 + 1 视频`：

```markdown
## D15-Seedance2-Stable 视频生成适配包

- 图1：关键角色图
- 图2：场景全景 / 12宫格核心视角图
- 图3：关键道具图 / 第二角色图
- 图4：D15 导演故事板图
- 视频：动作 / 镜头节奏参考，可选
- 简短提示词：请根据导演故事板图生成视频，遵循故事板中的镜头顺序、人物站位、动作路径、空间关系、光影方向、对白音效标注和导演批注。[动态风格补充]
```

参考图优先级：

```text
导演故事板图 > 关键角色图 > 场景图 > 关键道具图
```

---

## 12. Seedance2 非稳定扩展版适配包

Seedance2 非稳定扩展版按 `9 图 + 1 视频 + 1 音频`：

```markdown
## D15-Seedance2-Extended 视频生成适配包

- 图1：主角标准图
- 图2：对手 / 配角标准图
- 图3：场景 12 宫格图
- 图4：人物站位图
- 图5：关键道具图
- 图6：战损 / 状态图
- 图7：光影 / 风格参考图
- 图8：上一板尾帧 / 连续性锚点
- 图9：D15 导演故事板图
- 视频：动作 / 镜头节奏参考，可选
- 音频：台词 / 氛围 / 节奏参考，可选
```

默认优先稳定版，只有稳定版不足时才启用扩展版。

---

## 13. 连续性卡

每张故事板必须输出连续性卡，记录：

- 上一板尾帧；
- 本板首格；
- 本板尾格；
- 下一板首格预期；
- 人物状态；
- 场景状态；
- 道具状态；
- 光影状态；
- 风险项。

---

## 14. QC 清单

必须检查：

- D12 是否 ≤ 12s；
- D15 是否 ≤ 15s；
- 每格时长求和是否正确；
- 格数是否符合场景类型；
- 资产引用是否真实；
- 人物、场景、道具、光影是否一致；
- 板内 / 板间 / 集间连续性是否成立；
- Sora2 / Seedance2 适配包是否符合模型限制；
- 提示词是否没有重新成为主交付物。

---

## 15. 输出格式

默认输出：

```text
D12-Sora2 导演故事板图
D15-Seedance2 导演故事板图
连续性卡
QC 记录
Sora2 视频适配包
Seedance2-Stable 视频适配包
Seedance2-Extended 视频适配包（按需）
交付索引
```

不默认输出长版提示词。
