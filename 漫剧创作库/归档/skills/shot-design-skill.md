# shot-design-skill — 运镜与镜头设计技能

## 技能定位
把“镜头怎么拍”从广义分镜中独立出来，专门负责**单镜成立、镜头设计、运镜策略、视角身份、起幅落幅与结果兑现**。它不是替代 `storyboard`，而是作为可复用的专项能力层，供 `Director`、`Storyboard Artist`、`Studio`、`Reviewer` 在需要时单独调用。

## 适用任务
- 只优化某一段的运镜与镜头方案
- 为已有分镜补做镜头设计与运镜重构
- 判断某段是否该静、该推、该拉、该跟、该环绕
- 给同一段内容提出 2-3 套不同的镜头身份方案
- 修复无任务运镜、视角漂移、结果镜头缺失、起幅落幅不成立等问题
- 为导演讲戏或分镜表提供专项镜头顾问意见
- 为 Seedance / 即梦提示词提供镜头级语言压缩模板
- 为 D12-Sora2 / D15-Seedance2 导演故事板图逐 Panel 校验镜头任务、景别、机位、运镜、起幅落幅、结果点与视频模型适配可执行性

## 不负责的事
- 不负责重写剧情、戏核、人物关系
- 不负责替代 `Storyboard Artist` 完成整场戏的完整分镜拆解
- 不负责资产设计与最终平台执行
- 不擅自改变导演已锁定的段落目标与戏剧结果

## 核心方法
### 0. 运镜能力建设路径（从 42 种提示词上提）
专项能力按四层逐级训练，不鼓励一上来就追求复杂花活：
1. **基础模板层**：固定、推、拉、摇、横移、升降，先会写标准起幅 / 落幅 / 时长。
2. **动态跟拍层**：背跟、侧跟、前跟、双主体跟拍、缓推跟拍，学会“跟着谁、保持多远、落在什么结果”。
3. **空间塑造层**：纵深推镜、前景遮挡横移、轴线上移镜、框架构图推镜，学会用运镜建立空间感。
4. **节奏与特殊层**：快切推镜组合、视线匹配、匹配剪辑、POV、希区柯克变焦、合法越轴、焦点转移等，学会让运镜服务于转场、高潮和主观体验。

### 0.1 42 种提示词的吸收方式
这批公开提示词不作为死记硬背词库，而是按三种方式调用：
- **模板调用**：直接作为单镜设计卡的起幅 / 过程 / 落幅骨架
- **方案调用**：给同一段内容提供稳定版 / 压迫版 / 冲击版等镜头方案
- **训练调用**：用于检查当前镜头语言是否覆盖基础通用、动态跟拍、空间塑造、节奏控制、特殊主观五大类能力

### 1. 单镜六连判定
每一镜按以下顺序判断：
1. **镜头任务**：空间建立 / 关系建立 / 情绪逼近 / 动作展示 / 命中确认 / 结果兑现 / 转场桥接 / 信息隐藏
2. **景别选择**：远景 / 全景 / 中景 / 中近景 / 近景 / 特写
3. **视角身份**：客观观察 / 半主观跟随 / 主观 POV / 窥视 / 命运视角
4. **角度机位**：平视 / 仰拍 / 俯拍 / 侧拍 / 背拍 / 遮挡拍 / 特殊角度
5. **运镜策略**：固定 / 推 / 拉 / 摇 / 俯仰 / 横移 / 跟拍 / 升降 / 环绕 / 甩 / 晃
6. **起幅落幅**：从哪里开始，运动中兑现什么，最后停在什么结果上

### 2. 三大硬规则
1. **先任务，后拍法**：禁止先想花活，再补叙事理由
2. **能静不乱动**：只有运动能多传一层信息时才动
3. **一镜一主目标**：一次运动优先只完成一个核心目的

### 3. 运镜专项红线
- 禁止无任务运镜
- 禁止多种运镜叠加失控
- 禁止只写运动，不写落幅结果
- 禁止视角身份不明
- 禁止镜头脱离动作和表演独立漂移
- 禁止没有关系建立就堆特写或炫技镜头

### 4. 回退修复顺序
当镜头不成立时，按以下顺序回退：
1. 先砍掉无必要运镜，回到固定镜头
2. 再检查任务是否过载，拆成两镜
3. 再检查视角身份是否混乱
4. 再检查空间关系与轴线是否被破坏
5. 最后才考虑替换更复杂的镜头语言

### 5. 运镜模板化输出规范
当用户要求“给我可直接套用的提示词”时，统一输出成：
- **标准提示词**：机位 + 运动方向 + 主体锁定方式 + 起幅落幅 + 时长
- **适配场景**：这类镜头最适合什么戏
- **叙事作用**：它具体帮观众获得什么信息 / 情绪
- **风险提醒**：最常见翻车点
- **回退版本**：如果太复杂，回退成哪种更稳的拍法

## 输出要求
输出镜头建议时，至少包含：
- 镜头任务
- 景别
- 视角身份
- 机位 / 角度
- 运镜策略
- 起幅
- 落幅 / 结果点
- 风险项
- 回退方案

### B. 多方案对比
当用户要求“换一套拍法”时，至少给 2 套：
- 稳定叙事版
- 情绪压迫版
- 动作冲击版（如适用）

## 失败信号
- 说了很多镜头术语，但没有回答“为什么这样拍”
- 只有运动，没有信息点或结果点
- 一镜承担太多目标
- 视角身份在同段内反复漂移
- 镜头动得很忙，但戏没更清楚
