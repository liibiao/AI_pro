# Prompt Standards — 提示词编写规范

## GPT 生图专项方法论

> 统一专项规范：`docs/gpt-image-prompt-methodology.md`

### 适用范围
- `gpt-image-2` 文生图
- GPT 图生图 / 精修
- 海报 / KV / UI / 信息图 / 商品广告 / 角色设定表 / 漫画页面 / 品牌周边合集

### 核心原则
GPT 生图提示词必须写成“结构化视觉设计说明书”，而不是关键词堆叠。复杂图优先采用：

```text
任务类型 + 主体锚点 + 画面结构 + 分区/数量 + 光影色彩 + 材质质感 + 文本版式 + 输出比例 + 禁止项
```

工业化模板必须遵守 `Prompt as Code` 三步法：先确定任务类型，再锁定结构约束，最后补充风格材质；可复用模板优先使用 `{argument name="..." default="..."}` 或 `[PRODUCT] / [BRAND] / [ASPECT RATIO]` 变量占位。

### 强制自检
- 复杂图必须写清分区、位置、数量和阅读层级。
- UI、信息图、电商、品牌、出版物等工业设计图必须先写结构模块，再写风格材质。
- 静态分镜板 / 动作分解参考表必须写清格数、编号、边框、阅读顺序、每格任务和角色一致性。
- 需要文字时必须写清文字内容、位置、字体气质与可读性限制。
- 参考图精修必须写清：保留项 / 可变项 / 增强项 / 禁止项。
- 写实人像、3D微缩、国风插画、科幻机械、自然风光等审美表达型任务，必须先判断“产品类型 / 风格类型 / 场景类型”，再采用 `画面风格 → 核心元素 → 具体内容 → 构图方式 → 相机参数 → 光影色彩 → 氛围结果` 的自然语言七段式。
- 人像摄影类必须使用“整体场景段 + 面部近距离特写锚点段”，补齐机位、姿态、脸型、眉眼、鼻唇、肤质、妆容、服饰、场景和面部光影。
- 禁止只写“高级感、电影感、好看、精致”等抽象词。

## 核心原则

提示词不要写抽象评价，要写可视化信息。

### 错误示例
- 他很愤怒
- 她很伤心
- 画面很有电影感

### 正确示例
- 他下颌绷紧，额头青筋鼓起，拳头越握越紧
- 她嘴唇发抖，眼眶发红，手指抓住桌边发白
- 冷白侧光从窗外射入，人物半边脸陷入阴影

## 推荐结构

```text
主体是谁
主体在做什么
动作如何发生
场景在哪里
镜头怎么拍
光影是什么
风格是什么
```

## 即梦 2.0 防崩核心写法

> 统一专项规范：`docs/jimeng-anti-collapse-core.md`

### 适用范围
- 即梦 2.0 图生视频
- 连续人物片段
- 动作、文戏、对白、微表情、首尾帧衔接片段

### 防崩硬参数
- 参考强度固定为75。
- seed 全程固定，优先复用底图种子号。
- 底图人物描述一字不改：年龄、脸型、发型、服装、光线不得漂移。
- 单段时长控制在2-3秒，长视频必须分段生成。
- 动作按秒拆成关节步骤，禁止只写笼统动词。
- 固定光线方向、底图比例与视频比例，运动速度6，采样步数40，开启清晰度增强。
- 多段拼接必须写“首帧与上一段尾帧一致”，后期叠化转场0.2秒。

### 强制反向词
```text
畸形手指, 多余手指, 坏手, 错误解剖, 丑陋, 模糊, 水印, 文字, 额外肢体, 不对称眼睛, 扭曲面部, 双重下巴
```

## Seedance 2.0 核心写法

### 最佳写法顺序
1. 主体是谁
2. 穿什么 / 长什么样
3. 在哪里
4. 做什么动作
5. 镜头怎么拍
6. 什么光线 / 时间 / 天气
7. 想要什么风格
8. 补充细节与质感词

### 简化公式
`主体 + 动作 + 场景 + 镜头 + 风格 + 光影 + 细节限制`

### 推荐原则
- 中文完整句子优先，先保证自然语义连贯
- 英文风格词只做末尾补充，不做主体结构
- 一条提示词尽量围绕一个核心镜头
- 先出稳定版，再逐步增加镜头、氛围、材质和节奏

## 抽象词拆解规则

### 不要只写
- 高级感
- 电影感
- 氛围感
- 震撼
- 好看

### 要拆成可执行信息
- 高级感 → 低饱和度、干净背景、柔和布光、精致材质、构图克制
- 电影感 → 镜头推进/跟拍、主体清楚、背景虚化、光影层次明显、色彩统一
- 氛围感 → 黄昏/雨夜/清晨、薄雾/下雪/雨后、风吹头发、灯光闪烁、倒影与环境微动

```markdown
镜头从中景缓慢推近到近景，时长4秒。

```

## 故事板生产包与配套生成说明方法论（新增总入口）

> 统一母规范：`docs/director-storyboard-deliverable-standard.md`、`docs/storyboard-video-model-adaptation-standard.md`

### 两套输出形态
- **故事板生产包**：中游主交付，用于导演定稿、分镜执行、资产引用、Panel 时长、连续性、审稿与 QA。
- **配套生成说明**：下游辅助交付，用于平台投喂、快速实验、长度受限场景，必须从故事板生产包压缩派生。

### 强制关系
- 故事板先行，生成说明派生。
- 即梦 / Seedance / 叙事类说明都必须可追溯回同一故事板生产包。
- 严禁从剧本一句话直接跳到平台投喂说明。

### 独立片段计时规则（强制）
- Seedance / 即梦 的每个片段都是独立视频段落。
- **每段提示词时间必须从 `0s` 开始写**，不能沿用整集总时间轴。
- 标题写 5s / 10s / 15s，就必须在内容中真实铺满对应时长，不能只写到一半时间。

### 配套生成说明格式规则（强制）
- Seedance / 即梦 / 叙事类说明必须从故事板生产包派生，默认采用：`画面主体【完整：...】 + @Image 起手（只写 @资产名） + 逐条时间轴 + 六个固定段名`。
- 六个固定段名固定为：`环境联动 / 光线 / 对白配音 / 音效设计 / 画质 / 负面提示词`。
- **所有配套生成说明都必须保留这六段**，只能压缩，不能删掉。
- `对白配音` 只负责人声层：台词 / 旁白 / 心声 / 气口 / 语速 / 停顿；无对白时必须直接写明“本段无对白配音”。
- `音效设计` 统一负责 **环境音 + 拟音 + 特效音 + 状态音**；`BGM` 默认不写进主提示词固定段名，交给后期人工精配，只有音乐驱动段落才额外声明。
- 提示词正文中凡是角色、场景、道具已有落盘资产映射时，**一律优先写成直观中文的 `@资产名`**，例如 `@林天 / @蛟龙 / @林家练武场 / @灵纹碑石`，不再直接写自然语言名词替代。

### 长版提示词详细度门禁（强制打回项）
- 长版提示词不是摘要稿，必须在输出前补齐并细化：`主体 / 动作 / 景别 / 镜头 / 帧率 / 画质 / 音效 / 人物或主体站位 / 朝向 / 距离 / 环境联动 / 光线 / 负面提示词`。
- `画面主体【完整：...】` 必须写清：戏剧目的、主体关系、第一读点、情绪或冲突目标、结果钩子；不能只写“激烈打斗 / 压抑氛围 / 电影感”。
- `@Image` 起手必须写清资产锚点、左右 / 前后 / 远近站位、身体朝向、强弱关系和主要空间参照；已有资产必须使用 `@资产名`。
- 每条时间轴必须使用 `时间点（帧率 / 景别 / 机位或运镜）`，并紧跟具体动作、微动作或受力反馈、环境反应和对应音效；禁止只有镜头参数没有动作。
- 动作逻辑必须连续，有起势、推进、命中 / 反应、结果收束；强对抗段必须写清谁压制谁、站位 / 朝向 / 距离、接触点、受力方向、重心变化、被迫位移、落脚 / 撑地 / 后退 / 稳住等物理反馈。
- 强对抗时间轴必须写清镜头停 / 推 / 跟 / 切 / 留拍绑定的具体动作节点，关键命中点、结果帧和第一读点不得被 motion blur、快切或特效吞掉。
- 景别、运镜、帧率变化必须绑定动作节点；不允许单独列“镜头很有电影感”“快速运镜”“升格慢动作”而不说明服务哪个动作细节。
- `环境联动` 必须写清场景元素如何随动作变化；`光线` 必须写清光源方向、颜色、强弱、主体受光和环境反弹；`音效设计` 必须拆分底噪、近景拟音、材质声、特效声、状态声。
- `画质` 必须写清可见细节和禁止糊掉的关键读点；`负面提示词` 必须针对本段核心风险定制，包含身份、站位、动作连续性、关键物件、结果帧和声音/特效风险。
- 输出前若缺少任一固定接口、时间轴未铺满标题时长、站位/动作/镜头/声音/画质任一关键字段过粗，必须打回重写，不得进入生成。

### 全版本构图补强最小增量规则
- **构图补强 = 稳定器升级，不是结构重写。**
- 只允许补三类信息：`主体锚点 / 层次锚点 / 结果帧锚点`。
- 补强目标是减少主体漂移、层次混乱、高潮读图失败；**不得改动作链、节拍、空间推进、结果钩子**。
- 禁止把构图补成新的主任务、禁止过度对称静态化、禁止在每条时间轴重复堆构图词。
- 各类配套生成说明都适用这条规则，只是表达密度按目标模型调整。

### 故事板生产包与配套生成说明的最低保留项
- 用户给出的示例级别（`画面主体【完整】 + @Image + 按秒时间轴 + 环境联动 / 光线 / 对白配音 / 音效设计 / 画质 / 负面提示词`）在本项目中只算**下游配套生成说明标准**，不是中游主交付标准。
- 故事板生产包必须保留并扩写：叙事目标、动作链、镜头语言、节拍、空间关系、视听反馈、连续性约束、站位朝向、镜头起幅落幅、微动作链、环境物理反馈、声音空间、光线来源变化、画质读点和负面风险约束。
- 配套生成说明压缩时必须保留：起势镜头、关键动作链、关键结果镜头、关键速度反差、关键稳定约束、六个固定段名。

## 镜头动作融合原则（核心红线）

> **这是本项目最核心的提示词编写原则，适用于所有类型场景（武戏、文戏、内心戏）。**

### 为什么必须融合？

AI 视频模型（Seedance 等）通过上下文的"同时出现"来理解因果关系。**镜头语言如果脱离动作单独列出，模型会把它当作独立的"画面风格建议"而非"与动作绑定的执行指令"，导致运镜与动作脱节、帧率切换与关键时刻错位。**

### 核心规则

1. **禁止独立镜头板块**：不要把"镜头与构图"作为独立段落罗列帧率、运镜、景别。镜头信息必须嵌入动作描述中，与具体动作时刻绑定。
2. **时间戳绑定动作**：每个时间戳必须紧跟一个具体动作，格式为 `[时间戳] 角色动作 → 镜头响应`。
3. **帧率切换服务动作**：升格/降格必须说明"为放大什么动作细节"或"为释放什么冲击感"。
4. **运镜服务表演**：推/拉/摇/移/跟/甩必须绑定角色的心理状态或物理动作变化。
5. **文戏同理**：文戏的镜头推近/景别切换也必须与角色的微表情变化、视线移动、身体姿态转变绑定，不能单独写"镜头缓慢推近"。

### 对比示例

#### ❌ 错误写法（镜头与动作分离）
```
画面主体：林天后空翻闪避怪物扑击，落地左拳横扫命中豹头。
镜头与构图：70.8s 升格至 120fps。71.6s 降格回 24fps。镜头跟随角色移动。
```
→ 模型不知道 120fps 是为了放大后空翻闪避的精确感，也不知道降格是为了释放打击冲击。

#### ✅ 正确写法（镜头与动作融合）
```
70.8s（120fps 升格）：面对正面怪物扑击，角色收腹仰身全力后空翻闪避，身体精准侧身躲开全部爪击，正面怪物扑空从身前掠过。
71.6s（24fps 降格）：角色翻转落地屈膝卸力稳住重心，立刻拧腰转体左臂横扫直拳，重拳正面命中第二只怪物头颅，暗金光芒爆发震散暗气碎片飞溅。
```
→ 帧率切换与具体动作一一绑定，模型精准理解"什么动作在什么速度下执行"。

### 文戏融合示例

#### ❌ 错误写法
```
画面主体：林天缓缓站起，双拳握紧暗金光芒渗出。
镜头与构图：正面中近景缓慢推近。构图从三分法过渡到中心对称。
```

#### ✅ 正确写法
```
林天单膝跪地全身颤抖，干裂嘴唇缓缓张开无声吐出"继续……"。镜头从全景极慢推至正脸特写，背景蛟龙虚化为暗影（浅景深），焦点锁定林天逐渐凝聚金光的瞳孔。他手指一根一根攥紧碎石指节咔咔作响，缓缓撑起上半身，构图从三分法自然过渡到中心对称——表现从动摇到坚定的转变。
```

### 负面提示词也要融合

把"必须出现"的元素写入负面提示词作为反向约束，确保模型不会遗漏关键画面内容：
```
负面提示词：……角色无应对还击，怪物未被击倒，扫腿无前置连招，构图偏移角色不在左1/3，腐蚀沟痕缺失，石柱未断裂。
```

## 动作提示词规则

- 一条提示词尽量只写 1 个核心动作
- 连招要拆镜头
- 少写静态词，多写连续动作链
- 明确受力方向：从左到右 / 从上到下 / 正面击中腹部
- 少写"激烈打斗"，多写具体动作
- **帧率切换必须与动作时刻绑定**（参见上方「镜头动作融合原则」）

### 连续动作链示例
- 缓慢转头 → 抬眼看向镜头 → 向前走两步后停下
- 伸手触碰玻璃 → 手指停顿 → 呼吸压住情绪

## 镜头与风格控制规则

- 每个镜头都尽量写清景别与运镜，**但必须与人物动作/表演绑定，禁止独立列出**（执行《镜头动作融合原则》）
- 风格词一次保留 1-2 个主风格，避免互相冲突
- 镜头语言必须服务剧情信息，不为炫技而炫技
- 光线、天气、材质是氛围的主要来源，不要只写"氛围感"

### 常用镜头词
- 远景 / 全景 / 中景 / 近景 / 特写
- 跟拍 / 环绕 / 固定镜头 / 缓慢推进 / 手持感 / FPV 穿越运镜
- 低机位 / 高机位 / 浅景深 / 三分构图

### 常用真实感补词
- 布料褶皱
- 发丝摆动
- 皮肤纹理
- 地面倒影
- 灰尘颗粒
- 水珠滑落
- 呼吸起伏
- 衣摆晃动

## FPV 镜头专项规则（新增硬门禁）

### 什么时候该用 FPV
满足以下任意两项时，必须显式判断是否启用 `FPV`：
- 本段核心是 `追逐 / 逃逸 / 坠落 / 钻缝 / 穿楼 / 穿洞 / 通道突破 / 异空间跃迁 / 贴地释放`
- 场景中存在明确路径：`洞口 / 门窗 / 裂缝 / 桥洞 / 走廊 / 管道 / 峡谷 / 赛道 / 街道中轴`
- 需要观众感到“马上要撞上去 / 掉下去 / 穿过去”
- 画面存在足够近的速度参照物：`窗框 / 栏杆 / 枝干 / 墙体 / 钢梁 / 地面纹理`

### 长版母稿中 FPV 的必写锚点
涉及 `FPV` 的时间轴描述，必须写齐以下五项：
1. **入口**：从哪里冲进去
2. **穿越介质**：穿过什么
3. **擦身关系**：贴着什么过去 / 险些撞到什么
4. **出口**：从哪里穿出来
5. **结果镜头**：出来后立即看到什么 / 落到什么状态

### 正确写法示例
- `0.0s 镜头贴着断裂钢梁高速前冲，沿废墟走廊中心线逼近前方破碎窗洞，边缘动态模糊持续成立。`
- `1.2s 镜头擦着两侧扭曲钢筋钻入破窗裂口，玻璃碎片从前景急速掠过，轻微广角畸变增强压迫感。`
- `2.4s 镜头穿出窗洞后俯冲改平飞，正面揭示下方燃烧街区与远处坠落中的主角，地面火光在画面底部极速后退。`

### 禁止写法
- 只写：`高速飞行 / 快速穿梭 / 很有冲击力`
- 只写速度，不写路径、擦身关系与结果镜头
- 在静态权力戏、纯对白戏里硬塞 `FPV`
- 用 `motion blur` 掩盖空间设计不足

### 图生 / 多帧工作流补充
- 若任务是**三张关键帧 + 两段视频连接词**，优先调用 `fpv-director-skill` 的 `Trinity` 三帧流模式。
- 静态关键帧阶段必须遵守“**隐形镜头规则**”：不用 `drone / POV / GoPro / 第一人称视角`，改用 `一点透视 / 放射状模糊 / 微距特写 / 超低角度 / 鱼眼畸变` 等构图词。
- 动态视频指令必须以“**镜头**”为主语描述动作，不要把载具身份写成主体。

## 人物提示词规则

- 固定年龄、气质、服装、特征
- 一旦设定，不要频繁改词
- 同角色换装时保留面部和身体特征不变
- 先稳角色一致性，再追求风格增强

## 场景提示词规则

- 先写空间，再写材质，再写光影
- 不要只写"豪宅"这种大词，要拆成客厅/楼梯/吊灯/落地窗
- 场景与情绪必须一致，不允许画面氛围互相打架
- 场景可复用时，优先用 @引用标签

## 漫剧额外规则

- 每格只表达一个清晰信息点
- 先保证阅读顺序，再追求画面炫酷
- 对白区和人物动作区不要打架
- 爽点页和情绪页都应有明确视觉重心

## 命名建议

- 角色：`char-001`
- 场景：`scene-001`
- 道具：`prop-001`
- 镜头：`shot-001`

## 迭代建议

1. 先写简单稳定版
2. 再增加镜头语言
3. 再增加氛围与材质
4. 最后微调动作节奏与风格补词

## 分镜五要素自检清单（每个 Shot 下笔前必过）

> 核心原则：**所有分镜构图和运镜都服务主体调度，不要为了切分镜而切分镜。**

写提示词前，用以下 5 个问题自检，缺一个补一个：

| # | 要素 | 自检问题 | 写法示例 |
|---|------|---------|---------|
| 1 | **叙事视角** | 摄像机以什么身份存在？观察/OTS/POV/上帝/鱼眼/动态/低处/窥视？ | `行为观察视角，侧拍，摄像机在右前方 45°` |
| 2 | **机位角度** | 摄像机在哪？平视/仰拍/俯拍/过肩/地面？高度？ | `低机位仰拍，镜头位于人物膝盖高度` |
| 3 | **焦段与景别** | 多近？远景/中景/近景/特写？广角还是长焦？ | `85mm 中近景，人物胸部以上，背景压缩虚化` |
| 4 | **前景层次** | 镜头和主体之间有没有遮挡物？前景虚不虚？ | `前景有模糊的铁栏杆，人物透过栏杆缝隙可见` |
| 5 | **运镜方式** | 摄像机怎么动？推/拉/跟/摇/环绕/静止？ | `镜头从中景缓慢推近到近景，跟随人物步伐` |
| 6 | **光线** | 主光从哪来？硬光/柔光？光在不在动？ | `暖色烛光从左侧照射，火焰随呼吸微微晃动，光线在人物脸上流动` |

### 易错提醒

- **视角决定叙事身份**：先想"摄像机以什么身份观察这场戏"，再决定角度和景别。行为观察是"主食"（占 50-60%），其他视角是"调味料"。详见 `docs/perspective-system-emotional-mapping.md`。
- **主体调度优先**：先想清楚"人物在这 3-5 秒内做了什么位移/转向/互动"，再决定机位和运镜。不是反过来。
- **焦段影响情绪**：广角（24-35mm）强化空间感与不安，标准（50mm）中性真实，中长焦（85-135mm）压缩空间强化亲密/压迫。
- **前景制造层次**：没有前景的画面容易"扁平"，加一个虚化前景（门框/栏杆/人群/树叶）立刻有纵深感。
- **运镜要有动机**：推 = 聚焦/施压，拉 = 揭示/疏离，跟 = 沉浸，环绕 = 英雄感/包围，静 = 压住情绪。不要无脑推镜。
- **光动态化**：光不是静态布景，它是活的——详见 `docs/lighting-dynamics-prompt-guide.md`。

### 判断：六要素够不够？

- 6 项全部写清 → **可执行**，模型有充分信息
- 缺 1-2 项 → **勉强可用**，但画面大概率缺少层次或方向感
- 缺 3+ 项 → **不合格**，回到这张表补完再投喂

## 小白避坑

- 不要一条提示词塞 6 个动作
- 不要频繁改关键词导致角色变脸
- 不要只写风格名，不写画面细节
- 不要让 AI 猜，你要把它当执行导演来写
- 不要让多个主体、多个关系和多个高潮同时抢一条提示词
- 不要为了"炫酷运镜"切镜头，运镜必须服务主体在这几秒内的动作与情绪变化
