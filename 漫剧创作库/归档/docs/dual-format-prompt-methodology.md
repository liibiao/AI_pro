# dual-format-prompt-methodology.md — 双格式提示词方法论与全链路闭环

## 文档定位

本文档把项目中已经验证有效的两类提示词沉淀为统一方法论：

- **长版提示词**：用于导演定稿、复杂动作拆解、全链路审稿、质量校验与多平台母稿。
- **简版提示词**：用于平台投喂、快速试片、短窗口验证、长度受限场景。

它不是替代既有规范，而是把以下规范收束为一个可执行母框架：

- `docs/prompt-standards.md`
- `docs/seedance-prompt-engineering.md`
- `docs/workflow.md`
- `docs/staging-impact-audiovisual-methodology.md`
- `docs/action-combat-design-standard.md`
- `docs/camera-psychology-movement-standard.md`
- `docs/transition-montage-standard.md`
- `docs/character-visual-arc-standard.md`

## 一、为什么要区分长版与简版

### 1. 长版不是啰嗦版

长版的职责不是堆词，而是承担 **母稿、导演执行稿、审稿稿、跨平台源稿** 的作用。它必须完整回答：

- 这 15 秒到底在讲什么事件？
- 对抗关系、强弱变化、命中结果是否成立？
- 角色、场景、战损、光线、声音、环境反馈是否连续？
- 这一段如果要改写成即梦版、Seedance 字段版、Seedance 叙事版，哪些信息能压缩，哪些信息绝不能丢？

### 2. 简版不是缩水版

简版的职责不是“随便缩短”，而是 **在不损失动作逻辑、镜头意图和结果兑现的前提下，压缩成平台友好表达**。它必须保住：

- 关键动作链
- 关键镜头语言
- 关键速度反差
- 关键结果镜头
- 关键角色/环境/光线约束

### 3. 双格式的关系

- **长版 = 母稿 / 总控稿 / QA 稿**
- **简版 = 投喂稿 / 实验稿 / 平台稿**
- 所有即梦版、Seedance 字段版、Seedance 叙事版，都必须从长版母稿派生。
- 严禁直接从剧本一句话跳到简版投喂稿，中间必须经过导演化与镜头化。

## 二、全链路闭环：从剧本到投喂的标准路径

```text
剧本正文
→ 导演讲戏本
→ 分镜表 / Shot 表
→ 长版提示词（母稿）
→ 简版提示词（压缩投喂稿）
→ 平台派生版（即梦 / Seedance 字段 / Seedance 叙事）
→ 生成结果
→ QA / 连续性 / 失败复盘
→ 反哺方法论与案例库
```

### Phase 1：剧本正文（Writer）
必须给出：
- 事件目标
- 人物强弱变化
- `△ / △△` 支点动作
- 环境介质
- 角色当前视觉阶段

### Phase 2：导演讲戏（Director）
必须把抽象剧情转成：
- 站位 / 朝向 / 距离
- 对抗关系
- 身体受力
- 动作链
- 运镜心理动机
- 光线与环境反馈

### Phase 3：分镜 / Shot 设计（Director + Storyboard）
必须决定：
- 片段总时长（5s / 10s / 15s）
- 镜头数与节拍密度
- 每个 Shot 的任务
- 哪些镜头必须保留清晰结果帧
- 哪些镜头允许快切 / blur / 荷兰角 / 手持 / ACT

### Phase 4：长版提示词（母稿）
长版必须成为“唯一真实源”，供后续所有版本派生。

### Phase 5：简版提示词（压缩稿）
从长版抽取必要信息进行压缩，不得重写核心动作逻辑。

### Phase 6：平台派生
- **即梦版**：适合更结构化、更短、更直接的投喂说明；同样保留固定结构，但时间轴要更少条、更硬朗、更偏“指令式压缩表达”。
- **Seedance 版**：唯一执行母稿，信息最完整；必须保留最细的动作—镜头—音效绑定，是审稿、迭代和正式生成的主版本。
- **Seedance 叙事版**：适合导演口述式连续投喂；仍保留固定结构，但正文句法更连贯、更像讲戏，不追求最细的字段化拆解。

### Phase 7：QA 反哺
生成后必须复盘：
- 哪些信息在长版里存在、在简版里丢失后导致翻车？
- 哪些动作密度超标？
- 哪些镜头语言对模型有明显提升？
- 哪些平台更吃长版、哪些更吃简版？

## 三、长版提示词方法论（母稿规范）

## 适用场景

长版适用于：
- 15 秒完整段落
- 复杂武戏 / 群戏 / 压迫对峙
- 需要多轮审稿和跨人协作的项目
- 需要同时输出即梦版、Seedance 版、叙事版的片段

## 长版的核心职责

一条合格长版提示词，必须同时承担 8 个职责：

1. **叙事职责**：说清这段发生了什么
2. **动作职责**：说清怎么打、怎么闪、怎么中、怎么反扑
3. **镜头职责**：说清哪些镜头语言服务哪些动作
4. **节拍职责**：说清快慢交替与停顿位置
5. **空间职责**：说清天地双线、远近高低、前中后景
6. **视听职责**：说清音效、环境反馈、光线变化
7. **连续性职责**：说清角色阶段、战损、场景破坏延续
8. **派生职责**：保证能稳定压缩为简版与平台版

## 长版推荐结构（全项目母模板）

> **重要升级：经项目实测验证，Seedance 最优格式不再以字段块为母模板，而是以“导演长版样本格式”作为唯一母模板。**
> 以后所有 `seedance` 长版提示词，必须优先使用下列结构；即梦版、叙事版、简版都从它压缩或转写，不允许反向主导母稿结构。

```markdown
【片段标题：0s - 15s】

画面主体【完整：一句话概括该段的全部任务】
@Image@林天 / @林家练武场 / @灵纹碑石——空间关系——第一听感

0.0s（帧率 / 机位 / 运镜）：动作——结果——【音效】
...
14.xs（帧率 / 机位 / 运镜）：动作——结果——【音效】

环境联动
...

光线
...

对白配音
...

音效设计
...

画质
...

负面提示词
...
```

## 长版硬性结构规则

### 1. `画面主体` 必须保留
- 必须用 `画面主体【完整：...】` 一句先锁定本段任务总和。
- 这里不是宣传文案，而是本段所有目标的压缩总纲：对抗关系、动作类型、镜头密度、是否终结/留钩子，都要在这里被概括。

### 2. `@Image` 起手必须保留
- 必须紧跟在 `画面主体` 后，用一句建立主角色、主空间、主朝向、第一层压迫关系。
- 不允许把角色建立信息散落到后文再补。

### 3. 时间轴必须逐条写
- 长版必须采用 `0.0s（帧率 + 机位 + 运镜）` 的逐条时间轴写法。
- 每条都要写清：**动作 + 结果 + 音效**。
- 镜头语言必须继续与动作绑定，不能把镜头板块独立出去。

### 4. 辅助信息必须内嵌在每一个版本里
- 以下六段属于**强制保留段落**，不再允许只挂在母设定外层：
  - `环境联动`
  - `光线`
  - `对白配音`
  - `音效设计`
  - `画质`
  - `负面提示词`
- **长版、简版、即梦版、Seedance版、叙事版，都必须各自拥有这六段。**
- 写法上**直接从 `环境联动` 开始展开**，**不需要额外写“辅助段落”这一行总标题**。
- 简版可以压缩这六段长度，但不能删除这些段落本身。

## 长版时间轴规则

### 1. 独立片段时间必须从 `0s` 开始
因为 Seedance / 即梦等平台的片段生成是独立片段，不继承上一段时间轴，所以：

- 每段都必须写成 `0s - 5s`、`0s - 10s`、`0s - 15s`
- 严禁把总片时间轴直接拷贝进单段提示词

### 2. 时间必须真实铺满
标题写 15s，就必须把动作、留白、收束真实铺到 15s 左右。

### 3. 时间分配建议

#### 15 秒长版推荐节奏
- `0s - 2s`：建立冲突 / 起势
- `2s - 6s`：组合技推进 / 对抗升级
- `6s - 10s`：反击 / 反压 / 环境变化
- `10s - 13s`：终结技前蓄力 / 压迫静止
- `13s - 15s`：命中 / 结果 / 收束或钩子

## 四、简版提示词方法论（压缩投喂稿）

## 适用场景

简版适用于：
- 平台输入长度有限
- 快速实验与 A/B test
- 先验证动作与镜头方向是否成立
- 作为叙事版或字段版的轻量替代稿

## 简版保留原则

简版允许删掉解释性文字，但绝不能删掉下面 6 类信息：

1. **起势镜头**
2. **关键动作链**
3. **关键镜头语言**
4. **关键结果镜头**
5. **关键速度反差**
6. **关键稳定约束**

## 简版压缩规则

### 可以压缩的内容
- 解释性说明
- 重复性的环境描写
- 重复性的音效展开
- 重复出现的风格形容词
- 已被参考图稳定锁定的静态事实

### 不能压缩的内容
- 命中点
- 对抗关系变化
- 速度反差节点
- Hit Stop / 结果兑现
- 空间关系与朝向逻辑
- 平台容易忽略的关键约束

## 简版推荐结构

```markdown
【片段标题】
@Image建立
0.xs（镜头类型）：核心动作——结果
...
环境联动：...
光线：...
对白配音：...
音效设计：...
画质：...
负面提示词：...
```

## 五、长版 → 简版的压缩算法

把长版压缩成简版时，按以下顺序操作：

### Step 1：保留骨架
先抽出：
- 开场建立
- 3-6 个关键动作节点
- 终结或钩子节点

### Step 2：合并同类镜头
例如：
- 连续三格 ACT 回冲可合并为一条
- 同一组对抗中的拳/膝/腿连打可合并为一条动作链

### Step 3：删除解释层
删除“为什么这样拍”“这样更有张力”等解释，只留下执行信息。

### Step 4：保留结果镜头
快切可以压缩，但结果镜头不能删。

### Step 5：保留稳定器
至少保留：
- 角色朝向
- 环境主状态
- 关键光线关系
- 负面约束

## 六、平台派生规则

## 1. 即梦版

### 目标
- 短、硬、直接、可投喂
- 更适合压缩表达与镜头清单化表达

### 写法
- 少解释，多动作
- 时间段可以保留，但更强调镜头块
- 长版中的“环境联动 / 光线 / 对白配音 / 音效设计”压成少量高权重约束

## 2. Seedance 字段版

### 目标
- 审稿友好
- 便于替换变量
- 便于与素材职责矩阵联动

### 写法
- 保留时间轴
- 保留镜头与动作融合写法
- 保留环境联动 / 光线 / 对白配音 / 音效设计 / 画质 / 负面提示词字段
- 是最适合团队协作的工程稿

## 3. Seedance 叙事版

### 目标
- 适合连续导演口述式投喂
- 节奏更顺、语言更自然

### 写法
- 时间段仍然存在
- 但用完整叙述串起动作与镜头
- 适合快速试片，不适合做唯一真实源

## 七、动作镜头的六条硬规则

### 1. 镜头动作融合
帧率、运镜、景别、角度必须写在动作发生时刻里，不能独立列板块。

### 2. 先关系后爆点
任何高张力动作前，先交代：
- 谁压谁
- 谁朝向谁
- 距离多少
- 主威胁源是谁

### 3. 结果兑现
每一个关键动作，都要有结果镜头。

### 4. 速度成段
高光武戏优先采用：
`蓄力 → 骤静 → Hit Stop → 爆裂释放 → 结果镜头`

### 5. 快切不等于乱切
快切只能增加冲击感，不能替代关系说明。

### 6. 动作不够时，优先补“场景动作”
如果 15 秒不够撑满，不要只加空形容词，优先增加：
- 站位变化
- 高低位切换
- 地面对空 / 空对地
- 破坏反馈
- 角色失衡 / 再稳住
- 怪物反击 / 追击 / 追压
- 环境介质变化

## 八、剧本、分镜、角色设计、导演讲戏如何接入

## 编剧阶段（Writer）
新增硬要求：
- 武戏段必须提前写出 `△△` 关键命中点
- 必须预埋“可镜头化”的支点动作
- 必须预埋环境介质和战损延续点

## 导演讲戏阶段（Director）
新增硬要求：
- 每个片段先决定：是做长版母稿还是简版实验稿
- 默认先出长版，再压简版
- 必须写清镜头密度与片段目标（5/10/15s）

## 分镜阶段（Storyboard）
新增硬要求：
- 每个片段必须标注“长版母稿 / 简版投喂稿 / 平台派生稿”三层关系
- 每个 15 秒片段必须重新从 `0s` 起算
- 分镜表要写出：哪些信息允许压缩、哪些信息禁止压缩

## 角色设计 / 资产阶段（Assets + Librarian）
新增硬要求：
- 角色阶段图必须与长版母稿绑定
- 简版不得擅自改角色阶段
- 资产索引里应能追溯：该片段调用的是哪一阶段的角色图、场景图、道具图

## Studio 执行阶段
新增硬要求：
- 实验必须记录：长版 / 简版 / 平台派生版 的效果差异
- 一旦简版效果显著劣化，回退到长版或半长版

## 九、QA 与失败复盘规范

## QA 必查 10 项
- 是否从 `0s` 开始
- 是否真实铺满标注时长
- 是否先建立关系再写爆点
- 是否有清晰结果镜头
- 是否有速度反差链路
- 是否有平台可执行的镜头密度
- 是否有环境与光线延续
- 是否能从长版稳定压出简版
- 是否能派生为即梦版 / Seedance 字段版 / 叙事版
- 是否与角色阶段、资产版本、战损状态一致

## 失败复盘格式

```markdown
### 失败类型
- 角色漂移 / 动作糊 / 节奏乱 / 爆点不成立 / 时长虚标 / 收束缺失

### 对应原因
- 长版缺关系
- 简版压缩过头
- 平台版删除了关键结果镜头
- 片段未从 0s 起写
- 时间没铺满，后半段空转

### 修复动作
- 补关系镜头
- 补结果镜头
- 回退到长版母稿
- 降低动作密度
- 增加场景动作与环境动作
```

## 十、统一执行结论（全项目强制）

从本次更新开始，项目内所有：

- 即梦版
- Seedance 字段版
- Seedance 叙事版
- 15 秒全能参考片段
- 10 秒与 5 秒动作片段

都必须遵循以下总原则：

1. **长版先行，简版派生**
2. **独立片段时间从 0s 起算**
3. **标题时长必须真实铺满**
4. **镜头语言必须与动作绑定**
5. **`Seedance` 长版母稿必须采用“画面主体 + @Image起手 + 逐条时间轴 + 六个固定段名”样本格式**
6. **所有版本都必须保留六个固定段名（环境联动 / 光线 / 对白配音 / 音效设计 / 画质 / 负面提示词）**
7. **快切、ACT、手持、荷兰角只是工具，不是目的**
8. **先保证叙事和结果成立，再追求炫技**
9. **所有平台稿都必须可追溯回长版母稿**

- `长版：母稿`
