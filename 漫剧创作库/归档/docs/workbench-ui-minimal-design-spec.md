# 工作台节点 UI 极简设计规范

本规范用于 `tools/workbench-web/image-studio-canvas.html` 及后续所有工作台节点、浮层、卡片类组件的 UI 设计。核心目标是与“生成图像”节点保持一致：弱边框、少分割、低噪音、内容优先。

## 1. 设计关键词

- 极简：不使用重边框、重底色、复杂分割线。
- 暗色玻璃：以深色半透明背景和轻微 blur 表现层级。
- 内容优先：图片、提示词、结果预览优先；控件退后。
- 轻交互：hover/focus 只做轻微亮度变化，不做强发光。
- 弱装饰：装饰线、面板框、内嵌框尽量取消或降到 5%–12% 透明度。

## 2. 节点容器

### 推荐

- 背景：`rgba(5,7,12,.72)` 到 `rgba(12,15,23,.68)` 的深色渐变。
- 边框：`1px solid rgba(255,255,255,.06-.08)`。
- 圆角：`16px–20px`。
- 阴影：只保留外层空间阴影，不使用强彩色 glow。
- 选中态：使用浅蓝灰弱描边，不使用大面积高亮。

### 禁止

- 多层嵌套面板边框。
- 每个字段外都包一层明显卡片。
- 大面积彩色高亮作为默认态。

## 3. 节点内部布局

- 优先采用单列纵向排布。
- 控件之间用 `gap` 留白，不用分割线。
- 信息分组通过空间距离表达，不通过边框框住。
- 图片预览区域可铺满节点上半部分，参考图缩略图放在独立轻量行。
- 非必要标题、说明文字要弱化到 `rgba(226,232,240,.4-.55)`。

## 4. 图片与预览区

- 预览图应优先铺满可用区域。
- 空状态使用轻量 icon，占位透明度低于 35%。
- 参考图区域只展示缩略图，不要重复在预览区展示。
- 上传按钮推荐“+ 虚线圆圈”样式：小、弱、靠近缩略图。
- 删除按钮可常显于小缩略图右上角，但尺寸要小、透明背景。

## 5. 表单控件

- 输入框、下拉框背景使用 `rgba(0,0,0,.16-.24)`。
- 默认边框使用 `rgba(255,255,255,.04-.07)`。
- focus 态仅轻微提亮，不使用大面积 glow。
- 控件高度尽量紧凑：普通节点 `28px–34px`，底部工具条 `22px–28px`。

## 6. 按钮

- 默认按钮：透明或极弱白底 `rgba(255,255,255,.03-.06)`。
- hover：提升到 `rgba(255,255,255,.06-.1)`。
- 主按钮：仅在关键执行动作使用，仍保持低饱和。
- 禁止默认态强渐变、强阴影、强发光。

## 7. 边框与分割线规则

- 一级容器可有弱边框。
- 二级容器原则上不加边框，除非需要表达可点击/可拖拽区域。
- 分割线透明度不超过 `rgba(255,255,255,.06)`。
- 同一区域内不要同时使用边框、背景、阴影三种分隔方式。

## 8. 状态表达

- 成功：弱绿色边框，不改变整体背景。
- 失败：弱红色边框 + 错误文本区域。
- 运行中：可使用轻量进度遮罩，不使用强闪烁。
- 链路活跃：连线呼吸即可，节点自身只轻微提亮。

## 9. 新节点实现检查表

新增或改造节点 UI 前必须检查：

1. 是否去掉了非必要边框和分割线？
2. 是否避免了多层面板嵌套？
3. 图片/结果/主要输入是否是视觉中心？
4. 控件是否足够轻、足够紧凑？
5. hover/focus 是否只是轻微反馈？
6. 是否与“生成图像”节点的参考图行、预览区、底部栏风格一致？
7. 是否没有影响节点拖拽、连线、上传、删除等交互？

## 10. 节点清单与架构

### 当前节点（6 个）

## 11. AIO 集成节点规范

从"生成图像"节点衍生出一套 AIO（All-In-One）集成布局模式。核心特征：
- **贴边预览**：预览区延伸到节点边缘，无边距（`.aio-edge`）
- **内嵌控件**：模型/参数/提示词全部集成在节点内部，不依赖上游节点
- **等比缩放**：预览图使用 `object-fit: contain`，不裁剪不拉伸

### txt2img 文生图布局

```
┌──────────────────────────┐
│ aio-preview (预览/空态)     │  ← 贴边，图片 contain 居中
├──────────────────────────┤
│ aio-style-tag (风格标签)    │  ← 只在接了 stylePreset 时显示
│ aio-textarea (提示词输入)   │  ← 内嵌编辑器，70px 起步
├──────────────────────────┤
│ aio-bar (模型|尺寸|质量|数量|▶)│  ← 一行排列，运行按钮靠右
└──────────────────────────┘
```

### img2imgAll 生成图像布局

```
┌──────────────────────────┐
│ aio-preview (预览/空态)     │  ← 贴边
├──────────────────────────┤
│ aio-chips-row (参考图行)    │  ← 缩略图 + 上传按钮
├──────────────────────────┤
│ aio-editor-wrap (图文编辑)  │  ← i2i-chips 混合编辑
├──────────────────────────┤
│ aio-bar (模型|尺寸|质量|...|▶)│
└──────────────────────────┘
```

### CSS 类名约定

| 类名 | 用途 |
|------|------|
| `.aio-layout` | AIO 根容器 |
| `.aio-edge` | 贴边模式（预览区/编辑区零 padding） |
| `.aio-preview` | 预览区（图片/空态/运行中/失败） |
| `.aio-editor-wrap` | 编辑区包裹 |
| `.aio-chips-row` | 参考图缩略图行 |
| `.aio-bar` | 底部工具栏 |
| `.aio-bar-top` | 上方参数栏 |
| `.aio-sel` | AIO 内 select |
| `.aio-num` | AIO 内 number |
| `.aio-go` | 运行按钮 |
| `.aio-textarea` | 纯文本输入 |
| `.aio-t2i-prompt` | txt2img 提示词（70px min-height） |
| `.aio-style-tag` | 风格预设标签 |
| `.aio-hint` | 提示文字 |
| `.aio-gap` | flex:1 弹性间距 |
| `.aio-multi` | 多图网格布局 |

## 13. 极简风格设计语言 v1（以 Seedance 视频节点为基准）

从 `seedanceVideo` 节点抽象出的长期通用语言：**大触点、弱边框、浅色冷灰渐变、内容优先、低噪音反馈**。后续所有工作台节点新增或改造时，以本节为默认基准。

### 13.1 视觉基调

- 背景：深色冷灰玻璃，不使用纯黑实底；推荐 `rgba(18,22,30,.78)` → `rgba(7,9,13,.9)` 的纵向浅渐变。
- 边框：只保留一级容器弱边框，透明度控制在 `rgba(255,255,255,.055-.11)`。
- 阴影：只表达空间层级，不使用强彩色 glow；hover 仅轻微提亮。
- 装饰：去掉多余分割线、重边框、嵌套面板线；优先用留白和层级表达结构。

### 13.2 交互触点

- 连接点 `.port`：基础尺寸提升到约 `16px × 28px`，默认已足够可点击；hover 只做轻微放大和弱发光。
- 节点关闭 / 创建下游按钮：基础尺寸提升到约 `34px × 34px`，使用低饱和深色玻璃按钮，不再默认使用高饱和红蓝渐变。
- 节点悬浮工具按钮：基础尺寸提升到约 `32px × 32px`，按钮之间使用 `6px` 左右间距。

### 13.3 字号层级

- 节点标签标题：约 `12.5px`。
- 节点状态：约 `9.5px`。
- 普通字段标签：约 `11px`。
- 普通输入 / 下拉 / 文本域：约 `13px`。
- 视频 / 图生图主提示词输入：约 `15px`，保证长提示词编辑可读性。

### 13.4 图片与内容区

- 图片、视频、提示词是视觉中心；外层容器退后。
- 预览区使用弱边框或无边框，背景使用同色系浅渐变。
- 多图预览默认 `object-fit: cover; object-position: center;`，保证网格视觉统一。
- 参考图行采用视频节点同款轻量纸片堆叠/缩略图语言，不再重复展示到结果预览区。

### 13.5 新节点落地要求

新增节点或改造旧节点时必须满足：

1. 连接点、关闭按钮、创建下游按钮达到上述最小可点击尺寸。
2. 默认态不出现高饱和大面积颜色。
3. 一级容器之外不新增重边框面板。
4. 文本字号不得低于当前 v1 字号层级。
5. 图片引用、参考图选择、缩略图堆叠优先复用视频节点与图生图节点的统一组件语言。
