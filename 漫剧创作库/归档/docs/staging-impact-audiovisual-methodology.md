# 视听打击与对峙调度方法论

> 本文档用于把近期在《无限强化·灵纹觉醒》项目中沉淀出的实战经验，升级为全项目可复用的方法论。
> 核心目标：让 **动作、镜头、速度、音效、特效、站位关系** 形成同一条可执行链路，而不是各写各的。

---

## 一、适用范围

适用于：
- 武戏
- 压迫对峙戏
- 反压文戏
- 内心爆发戏
- 需要强打击感、强压迫感、强体型差的 Seedance / 分镜 / 导演讲戏 / QA 场景

---

## 二、核心原则（五条红线）

### 1. 镜头必须服务动作与表演
- 禁止把帧率、运镜、景别、构图独立列成一个空的“镜头与构图”板块
- 必须写成：**具体动作发生时，镜头如何响应**
- 文戏同理：镜头推近必须绑定微表情、视线变化、呼吸变化、姿态变化

### 2. 站位关系必须可画出来
- 强对抗段落必须交代：谁在谁前方、左前方、右后方、相距多少米、朝向谁
- 至少回答以下问题：
  1. 谁压谁
  2. 谁面朝谁
  3. 谁是否被包围
  4. 谁在主读点
  5. 结果镜头后新的对峙关系是什么
- **禁止出现角色背对主要威胁源却仍在“正面对峙”叙事中的穿帮写法**

### 3. 速度对比必须成段设计
- 不要只有“快”或“慢”，而要写出 **慢 → 静 → 爆 → 余波** 的节奏弧线
- 推荐强打击段采用四段节奏：
  1. **蓄力**：重心压低、呼吸收住、肌肉绷紧、速度被拉慢
  2. **骤静**：命中前一瞬，外界声音或局部声音抽空
  3. **Hit Stop**：命中帧冻结 1-4 帧，突出受力接触点
  4. **爆裂释放**：极速恢复，冲击波、碎裂、惨叫、环境反馈同时炸开

### 4. 视听必须同步爆点
- 音效不能只做背景说明，必须跟动作命中点同步设计
- 特效不能只写“光很炸”，必须写清：
  - 爆点从哪里产生
  - 与哪种动作接触面绑定
  - 先炸亮还是先炸碎
  - 对环境造成什么反馈
- 推荐写法：
  - **蓄力声**：低频嗡鸣 / 金属绷紧 / 呼吸压缩
  - **骤静**：0.15s / 0.3s / 0.5s 的抽空
  - **命中**：骨裂 / 金属撞击 / 气爆 / 玻璃碎裂 / 喉骨闷响
  - **余波**：碎石落地 / 风压扩散 / 耳鸣 / 鸟鸣回归 / 空气回流

### 5. 结果兑现必须可读
- 每个爆点不只写“打中了”，必须写清：
  - 命中点
  - 受力方向
  - 受击后的身体变化
  - 环境变化
  - 下一轮关系变化
- 若观众看不清“谁赢了这一下、怎么赢的、空间关系如何变了”，就不算成立

## 三、标准结构

### A. 对峙建立
先建立：
- 人物站位
- 怪物/对手站位
- 距离
- 朝向
- 主视角身份（POV / OTS / 观察视角等）
- 主读点与体型差参照物

### B. 节奏推进
按以下链路书写：

`站位建立 → 蓄力 → 出击 / 压迫 → 命中 / 反制 → Hit Stop → 爆裂释放 → 结果镜头 → 新对峙关系`

### C. 视听挂载
每个关键节点同步写：
- 帧率 / 节奏变化
- 音效变化
- 特效变化
- 环境反馈

## 四、推荐写法模板

### 强对抗段落模板
```text
[时间点] 角色A与角色B的站位关系先建立清楚。角色A面朝角色B，位于其正前方X米；角色B位于左前方/高位/阴影中。
[时间点]（升格/放缓）：角色A压低重心蓄力，呼吸收住，肩背绷紧，镜头随其动作推进/压近。
[时间点]（骤静）：出手前0.15s-0.5s抽空主要声音，只保留心跳/低频/耳鸣。
[时间点]（Hit Stop）：命中瞬间冻结1-4帧，明确命中点、受力方向、接触界面、表情变化。
[时间点]（降格/释放）：冲击、碎裂、特效、惨叫、环境反应同时爆开。
[时间点]（结果镜头）：交代谁被击退、谁稳住、双方新站位如何变化。
```

### 压迫型巨物对峙模板
```text
先用前景中的角色身体作为比例尺，再让巨物从角色正前方升起。角色必须面朝威胁源，不能背对巨物。镜头通过肩后越肩、低角度仰拍、缓慢上摇等方式，逐步建立“人小 / 物巨 / 空间被压住”的体型差。
```

## 五、门禁自检清单

### 导演讲戏自检
- [ ] 是否写清主角与对手的站位、距离、朝向
- [ ] 是否明确谁压谁、谁撑、谁反扑
- [ ] 是否把镜头写进动作与表演，而不是独立列镜头板块
- [ ] 是否存在“蓄力→骤静→Hit Stop→爆裂释放”中的至少 2-4 段节奏设计
- [ ] 是否给出结果镜头与新对峙关系

### 分镜 / 提示词自检
- [ ] 每个关键时间点都绑定具体动作
- [ ] 强对抗镜头中站位与朝向可被画出来
- [ ] 关键命中点有清晰可读的受力结果
- [ ] 音效、特效、环境反馈与爆点同步
- [ ] 未出现背对威胁源、空间关系漂移、体型差不成立等穿帮问题

### QA 自检
- [ ] 静音看画面，是否仍能读出谁压谁、谁命中谁
- [ ] 闭眼只听声音，是否能听出蓄力、命中、爆裂、余波层次
- [ ] 去掉特效后，动作受力是否仍成立
- [ ] 去掉音效后，命中点是否仍清晰
- [ ] 爆点后是否有结果兑现镜头，而非只剩炫技

## 六、常见失败信号
- 只有“很炸”“很猛”“很震撼”，没有空间关系
- 只写镜头快慢，不写人物如何蓄力和命中
- 音效与画面分家，爆点不同步
- 巨物对峙时人物背对敌人
- 对抗成立前就乱切近景，导致观众不知道谁站哪
- 只有爆炸特效，没有命中点与结果镜头
- 只写情绪，不写身体反应、重心变化、呼吸变化
