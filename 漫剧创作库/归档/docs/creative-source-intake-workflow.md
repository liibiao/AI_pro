# 创作源输入与项目立项工作流

> 定位：所有项目的统一入口。用户不必先拥有剧本；系统必须能从故事梗概、小说原文、角色设定、世界观、一句话创意、已有剧本、已有分镜或从0到1原创需求开始。

---

## 1. 核心原则

旧入口“剧本输入”升级为：

```text
创作源输入 / 项目立项输入
↓
输入类型识别
↓
创作成熟度判断
↓
题材 / 情绪 / 受众 / 场景类型 / 视觉难度识别
↓
影片风格画质基调初筛
↓
故事开发 / 小说改编 / 剧本标准化 / 制作执行
```

任何项目在进入批量资产、分镜、导演故事板图或视频生成前，必须完成本阶段判断。

---

## 2. 创作源类型

| 输入类型 | 说明 | 默认下一步 |
|---|---|---|
| 一句话创意 | 只有概念、题材或一句卖点 | 立项孵化 |
| 故事梗概 | 有主角、目标、冲突雏形 | 扩展大纲 |
| 小说原文 | 有叙事文本但不是剧本 | 改编为短剧 / 漫剧剧本 |
| 已有剧本 | 有场次、对白、动作 | 剧本诊断与标准化 |
| 角色设定 | 有人物无完整故事 | 从人物弧线反推剧情 |
| 世界观设定 | 有规则体系无剧情 | 建立故事引擎 |
| 从0到1原创 | 用户只给方向或目标 | 立项问卷 + 风格初筛 |
| 已有分镜 / 资产 | 项目已进入制作中段 | 进入制作执行线并补做风格锁定检查 |

---

## 3. 创作成熟度 L0-L5

| 等级 | 名称 | 内容状态 | 必做动作 |
|---|---|---|---|
| L0 | 一句话创意 | 只有想法 | 立项孵化、题材与风格初筛 |
| L1 | 故事梗概 | 有人物和冲突雏形 | 扩展大纲、人物、世界观 |
| L2 | 小说 / 原文 | 有叙事文本 | 提炼戏核并改编剧本 |
| L3 | 剧本初稿 | 有场次对白但未定稿 | 剧本诊断、标准化、风格复核 |
| L4 | 剧本定稿 | 可进入导演讲戏 | 锁定影片风格画质母版 |
| L5 | 分镜 / 资产阶段 | 已有制作产物 | 检查风格母版与连续性，缺失则补齐 |

---

## 4. 双线工作流

### A线：故事开发线

适用于 L0-L2 或从0到1原创。

```text
创作源输入
→ 题材 / 受众 / 情绪 / 风格初筛
→ 故事核心卖点
→ 世界观 / 人物 / 冲突
→ 集数规划
→ 大纲
→ 分集梗概
→ 标准剧本
→ 风格锁定
→ 制作执行线
```

### B线：制作执行线

适用于 L3-L5。

```text
剧本 / 分镜 / 资产输入
→ 剧本诊断 / 产物一致性检查
→ 影片风格画质基调锁定
→ 导演讲戏
→ 角色 / 场景 / 道具资产
→ 分镜
→ 导演故事板图
→ 视频模型适配
```

---

## 5. 风格筛选介入规则

- L0-L2：生成 `style-filter-result.md`，作为可调整的风格初筛结果，用于辅助故事开发。
- L3-L5：必须生成或补齐 `visual-style-bible.md`，作为不可随意更改的风格锁定母版。
- 剧本定稿后、资产生成前，必须从初筛版升级为锁定版。

---

## 6. 输入分析字段

每次立项至少输出：

```markdown
- 创作源类型：
- 创作成熟度：L0-L5
- 主类型：
- 副类型：
- 情绪基调：
- 主角类型：
- 核心冲突：
- 核心场景：
- 目标受众：
- 视觉难度：低 / 中 / 高 / 极高
- 推荐下一步：故事开发线 / 制作执行线
- 风格初筛是否需要：是 / 否
- 风格锁定是否需要：是 / 否
```

---

## 7. 门禁

- 未完成创作源识别，不得直接进入剧本、资产或故事板批量生产。
- 未完成成熟度判断，不得把一句话创意误当剧本处理。
- L0-L2 不强制锁死风格，但必须有风格初筛。
- L3-L5 进入资产、分镜、故事板、视频生成前必须有风格锁定母版。
