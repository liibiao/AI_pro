# 动作戏镜头与受力词库

> 用途：编写分镜剧本（Storyboard）、提取 `epXXX-shots.md` 以及组装生成 Prompt 时的直接查阅字典。

---

## 1. 速度与节奏词库
动作戏的张力来自于“速度变化”，切忌全篇使用“快速”。

- **起势/蓄力**：压低重心、缓慢蓄力、微停半拍、肩背绷紧、手腕回扣、呼吸收住、力量内压、杀意凝住、起手极稳、先静后响。
- **突进/启动**：突然暴起、瞬间前冲、贴地突进、极速逼近、爆冲上前、闪身切入、一步欺近、猛然前压、掠地疾进、残影突袭。
- **出招/攻击**：极速挥出、直劈而下、横斩掠过、连环追击、快如闪电、如暴风骤雨、连续刺击、重拳轰出、鞭腿横扫、反手回斩。
- **对抗/碰撞**：硬接、硬撼、正面碰撞、当空对撞、瞬间交击、火花炸开、冲击波扩散、短暂停顿、轻微定格、力道顶死。
- **反击/追打**：毫无停顿立刻反击、借势反打、转守为攻、连招追身、回身补刀、抢进中线、反手追斩、二段爆发、再度加速。
- **结果/收势**：猛然砸落、重重落地、缓缓收势、稳稳落定、提刀俯视、收剑入鞘、气息回沉、气场压制、冷冷逼视、不给喘息。

## 2. 身体形变与受力词库
力量必须传递到角色身上，AI 才会有反馈。

- **发力部位**：重心转移、肩背带动、肘腕传导、指节/拳锋/脚掌落点、肌肉暴起。
- **命中防守**：瞬间格挡、仓促格挡、侧身闪避、滑步卸力、借力偏转、横兵封挡、抬臂硬架、后撤半步、险险避开、擦身而过。
- **躯干受损**：精准命中、正中胸口、命中侧肋、打穿防线、身体后仰、重心失控、离地倒飞、身体呈反弓状、空中滞空、胸腔震塌、脊背弓起。
- **细微反馈**：手臂无力摊开、手臂剧烈回弹、肌肉瞬间紧绷、后槽牙咬紧、面部痛苦扭曲、口角溢血/狂喷鲜血、眼底血丝暴突。
- **物品反馈**：衣料放射状炸裂、甲片崩碎飞散、发丝狂舞、墨镜/饰品震飞旋转。

## 3. 环境联动词库
环境是力量的放大镜，但注意不能遮挡角色读点。

- **地面反馈**：重重砸落、轰然坠地、翻滚滑出、嵌入地面、沿地拖行、石屑炸飞、地面崩裂出蛛网裂纹、青石板震出深坑、落点震开裂纹。
- **介质反馈**：尘土冲天炸开、大面积碎石飞溅、水花/气浪向四周排空、脚下竹叶被气流卷起纷飞。
- **周遭反馈**：周围树木/竹子被震得剧烈晃动、落叶纷飞、背后建筑涂鸦剥落、围观群众被气压推退半步。
- **光影特效**：紫电缠身如蛇群攀爬、雷光灵纹骤然炸亮、剑身迸出火花、高光冲击波刺眼、气流扭曲。

## 4. 镜头反应词库
赋予镜头物理属性，打破旁观者视角。

- **运镜**：低角度仰拍（赋予压迫感）、贴地快速推进、微仰跟拍、快速推近后突然拉开到全景（展示破坏范围）。
- **物理晃动**：全程手持摄影风格画面轻微晃动、碰撞瞬间画面轻微定格、命中瞬间镜头猛烈震动（仿佛摄影师被气浪波及）、镜头慢放特写受力瞬间。
- **视觉风格**：动态模糊（仅限过程，命中点禁用）、速度线、残影拖影。
- **门禁控制（必须带）**：严禁跳轴、地平线迅速回稳、不遮挡脸部与命中点。

## 5. 高张力构图与特效词库 (High-Tension Compositions & FX)
*适用场景：濒死、暴走、绝杀、力量碰撞。*
- **Dutch Angle (荷兰角/倾斜构图)**: 打破平衡，营造极度不安或力量压制感。
- **Extreme Foreshortening (极限透视/张力透视)**: 广角畸变，前景肢体/武器极度夸张放大，背景缩小，强化攻击的扑面而来感。
- **Speed Ramping / Bullet Time (变速升格/子弹时间)**: 撞击或交锋瞬间的极慢动作（能看清飞溅的血珠或碎裂的火花），随后瞬间快切。
- **Environmental Suspension (环境重力异常/滞空)**: 巨大的能量场导致重力失效，碎石、血珠、雨滴在空中悬浮缓降。
- **Chromatic Aberration (色散/边缘畸变)**: 巨大的冲击波撕裂空间，画面边缘出现红蓝色彩分离。
