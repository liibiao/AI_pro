# 影片风格画质基调系统

> 定位：开剧前的视觉总筛选器、全链路统一风格母版、小白自动推荐器。它不替代 HZW；HZW 是风格控制方法论和质感总控方法，影片风格画质基调库负责决定“这部片看起来像什么”。

---

## 1. 两层关系

```text
母版通用方法论
→ 风格控制方法论（如 HZW：信息版/情绪渲染版、权重、构图、PBR、氛围、微动作）
→ 影片风格画质基调（新海诚、龙珠、Trigger、国漫神话CG、赛博霓虹、黑帮冷峻、萌宠CG等）
→ 项目 visual-style-bible.md
→ 角色 / 场景 / 道具 / 分镜 / 导演故事板图 / 视频生成
```

HZW 可作为某些项目的主风格，也可作为质感升级方法叠加到其他风格，但不得把 HZW 当成唯一影片风格库。

---

## 2. 风格基调公式

```text
影片风格基调 =
题材类型
+ 视觉媒介
+ 参考风格方向
+ 光影系统
+ 色彩系统
+ 材质系统
+ 画质系统
+ 镜头系统
+ 声音气质
+ 禁止项
```

禁止只写“电影感 / 国漫感 / 高级感”。必须拆成可执行参数。

---

## 3. 筛选器流程

```text
创作源输入
→ 输入类型与成熟度识别
→ 题材 / 场景类型 / 情绪 / 受众 / 视觉难度识别
→ 从 film-style-tone-presets.json 推荐 Top3
→ 生成 style-filter-result.md
→ 故事开发或剧本标准化
→ 剧本定稿后生成 visual-style-bible.md
→ 全链路继承
```

---

## 4. 风格状态

### 4.1 初筛版

文件：`style-filter-result.md`

- 用于 L0-L2；
- 可比较 Top3；
- 可调整；
- 用于辅助故事开发、改编方向与受众定位。

### 4.2 锁定版

文件：`visual-style-bible.md`

- 用于 L3-L5；
- 剧本定稿后、资产生产前必须锁定；
- 不可在下游临时混入未登记风格；
- 所有角色、场景、道具、分镜、故事板、视频适配包都必须引用。

---

## 5. 推荐输入字段

```markdown
- 创作源类型：故事梗概 / 小说原文 / 剧本 / 角色设定 / 世界观 / 口头创意 / 从0到1
- 成熟度：L0-L5
- 主类型：动作 / 文戏 / 悬疑 / 喜剧 / 警匪 / 黑帮 / 灵异 / 僵尸 / 仙侠 / 赛博 / 萌宠 / 文艺 / 赛车等
- 副类型：热血 / 复仇 / 治愈 / 暗黑 / 轻喜 / 惊悚 / 史诗 / 日常等
- 情绪：压迫 / 爽感 / 浪漫 / 孤独 / 恐怖 / 荒诞等
- 核心场景：练武场 / 雨夜街头 / 凶宅 / 赛博城市 / 森林 / 宫殿等
- 目标受众：爽剧 / 漫剧 / 短视频 / 儿童 / 青春 / 男频 / 女频等
- 视觉难度：低 / 中 / 高 / 极高
```

## 6. Top3 推荐输出

```markdown
| 推荐 | 风格基调 | 命中原因 | 风险 | 修正建议 |
|---|---|---|---|---|
| 1 | cinematic-hzw-premium | 动作、压迫、逆袭、电影质感 | 特效可能遮动作 | 强制结果帧清晰 |
| 2 | donghua-nezha-mythic-cg | 少年反抗、神话热血 | 可能偏低龄 | 降低糖果色 |
| 3 | donghua-buliangren-dark-jianghu | 江湖压迫、复仇冷感 | 爽点可能不足 | 增加金色灵力点缀 |
```

## 7. 全链路继承规则

### 角色设定稿

继承脸部渲染方式、线条风格、服装材质、色彩锚点、禁止风格。

### 场景720全景图

继承空间材质、主色调、光源方向、建筑语言、世界观时代感。

### 12宫格视角图

所有视角必须与风格母版的光影、材质、色彩、空间气质一致。

### 分镜与导演故事板图

必须继承镜头语言、光影基调、动作节奏、声音气质、风格禁止项。

### 视频生成

Sora2 / Seedance2 适配包必须抽取 `visual-style-bible.md` 的一句话风格、光影、色彩、材质、画质和负面风格。

---

## 8. 混风格红线

- 新海诚青春天空系不得混入黑帮冷峻低光，除非风格母版明确是“青春 × 犯罪”复合基调。
- 赛博朋克不得随意混入古风木质庭院，除非是“赛博国风”项目且已定义材质融合规则。
- 萌宠治愈不得混入写实血腥恐怖材质。
- 国漫神话CG不得变成欧美奇幻城堡化。
- Trigger高张力动画不得加入写实毛孔/PBR皮肤作为主画质。
