# 场景类型 × 风格画质库

> 定位：为故事板图、分镜、提示词和视频生成提供足够多样的场景类型样本。场景类型决定 Panel 格数、镜头组、节奏密度、声音复杂度和推荐影片基调。

---

## 1. 字段标准

每个场景类型至少包含：

```text
场景类型 / 核心叙事任务 / 默认镜头组 / D12-D15格数 / 节奏密度 / 光影建议 / 声音建议 / 适配风格 / 禁止项
```
