## 使用建议
- 每次开始新一集 / 新一话前更新一次
- 每次暂停创作准备下次继续时更新一次
- 每次角色关系、伤势、道具归属发生重大变化时补充一次
- 不求写长，求可执行、可接力、可避免冲突
