# 动作戏方法论

> 适用范围：`04-storyboard` 分镜设计、`05-prompts` 提示词编写、Seedance / 即梦 动作戏镜头规划。

---

## 一句话总纲

动作戏不是“打得快”，而是“看得清、打得实、结果狠”。

---

## 核心目标

- 让观众一眼看懂：谁打谁、打到哪、结果如何
- 让 AI 明确理解：力从哪里来，打到哪里去，身体和环境怎么反馈
- 让镜头服务动作，而不是用镜头炫技掩盖动作逻辑

---

## 三条底层原则

### 1. 命中点清楚

- 每一镜必须有明确首看点
- 首看点优先级：命中部位 > 脸部表情 > 武器锋刃 > 特效
- 禁止用粒子、光效、运动模糊遮挡命中点

### 2. 力的传递闭环成立

- 动作必须写清：攻击者、方向、命中部位、受力形变、结果落点
- 力的闭环顺序：
  - 角色发力
  - 角色受力
  - 环境受力
  - 镜头受力
- 不允许只有“特效炸开”，没有身体反馈

### 3. 节奏必须有快慢变化

- 默认禁用“全程匀速”
- 推荐节奏：
  - 起势慢
  - 突进快
  - 碰撞停
  - 反击快
  - 结果慢半拍
- 所有强爆点优先使用“先静后响”

---

## 动作戏的标准信息顺序

### 1. 起势

- 交代空间关系、强弱关系、谁先压迫谁
- 交代重心、站位、视线、气息

### 2. 突进

- 明确动作方向
- 明确启动方式：突然暴起 / 压低重心 / 闪身切入 / 贴地突进

### 3. 接触

- 明确格挡、擦过、命中、对撞中的哪一种
- 接触瞬间优先给清晰帧，不要整段糊掉

### 4. 受力

- 写清受击后的躯干、肩背、手腕、步伐、重心变化
- 优先使用可见身体信息，而不是抽象词

### 5. 结果

- 命中后必须兑现结果
- 结果可落在：
  - 人物
  - 地面
  - 道具
  - 群体反应

### 6. 收势/钩子

- 收势镜头要说明关系有没有改变
- 命中后的一停、俯视、落地、喘息都可以作为钩子

---

## 对抗关系写法

- 不只写动作，要写当前谁压谁
- 常见关系：
  - 试探压迫
  - 正面硬撼
  - 被动防守
  - 借势反打
  - 反压节奏
  - 一击定局

### 推荐写法

- `@林傲天 主动压上，@林天 被迫后撤半步`
- `@林天 硬接一击后抢回中线，反守为攻`
- `这一击的目标不是击退，而是改变强弱关系`

---

## 身体受力写法

### 优先写这些

- 重心：前压 / 后移 / 失衡 / 站稳
- 步伐：滑退 / 绊住 / 踉跄 / 扎稳
- 上肢：肩背绷紧 / 手腕回弹 / 手臂摊开
- 躯干：后仰 / 侧扭 / 弓起 / 震塌
- 呼吸：气息被打断 / 胸口发闷 / 闷哼压住

### 禁止只写这些

- 很疼
- 很强
- 很有冲击力
- 很炸裂

---

## 环境受力写法

- 地面崩裂
- 碎石炸飞
- 尘土压低或冲天炸开
- 竹叶/树叶/衣摆/头发被拳风带动
- 道具震鸣、裂开、偏移、翻倒

### 原则

- 环境是力量的放大器，不是主角
- 所有环境反馈都不能盖住人脸和命中点

---

## 镜头方法

### 起势镜头

- 缓慢推进
- 低角度压迫
- 固定镜头保关系

### 爆发镜头

- 跟拍
- 快速推进
- 贴地突进
- **特殊强化（ACT主观视角）**：在极度激烈的近战连击或终结技时，使用 `ACT视角，镜头跟随出拳方向，打击时有停顿感`。

### 碰撞镜头

- 命中特写
- 轻微定格
- 瞬时震动后迅速回稳

### 结果镜头

- 拉开看破坏范围
- 近景看面部和呼吸
- 停半拍兑现重量感

### 4. 镜头闭环：时间轴微雕与导演级运镜
**目标：打破“旁观者”视角，用时间戳将长镜头像外科手术一样切碎。**
- **方法要求**：彻底抛弃写“打得很激烈”这种废话，要给具体的动作+机位。
  - **全景定场**：两人相距 8-10 米（8-10m apart）。低视角，保证剪影清晰。
  - **起手式**：角色A劈砍（slash），角色B侧步（sidestep）。机位：甩镜头（snap-pan）。
  - **物理交互**：格挡 ➔ 架剑 ➔ 推开（Parry ➔ bind ➔ shove-off）。
- **融合项目规范**：镜头可以震动，但绝对不能跳轴（必须保持 180° 轴线）。
- **【特殊构图突破门禁：荷兰角 (Dutch Angle)】**
  - **原则**：地平线通常保持绝对水平（roll=0）。
  - **破例条件**：在表现**极度危机（角色被重创倒地）**、**理智失控（暴走）**或**反派降维打击的极高压迫瞬间**时，允许使用`荷兰角构图 (Dutch angle, tilted frame)`。
  - **收束要求**：该构图会传达极强的心理失衡感，一旦脱离该情绪点，**下一镜必须立刻切回水平构图**以稳住空间，绝不可连续滥用。

---

## 动作戏 Prompt 最小闭环

每一个动作镜头，至少写清：

- 谁在主动
- 打到哪里
- 速度怎么变化
- 身体怎么受力
- 环境怎么响应
- 镜头怎么跟

---

## 最终检查

- [ ] 谁打谁清楚
- [ ] 命中点清楚
- [ ] 受力真实
- [ ] 环境有联动
- [ ] 节奏不是匀速
- [ ] 镜头不跳轴
- [ ] 爽点兑现
