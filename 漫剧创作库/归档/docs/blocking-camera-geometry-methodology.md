# blocking-camera-geometry-methodology.md — 站位/轴线/几何约束方法论（AI 视频）

## 用途
把“人物位置关系、摄像机空间关系、轴线连续性、读点保护、字幕安全区、群戏调度”这些控制元素，沉淀成一套可复制的导演方法论与工程规范，用于提升 AI 视频的稳定性与可控性（尤其是站位漂移、跳轴、读点丢失、群戏乱跑）。

## 核心目标
- 让镜头先建立空间，再推进动作与情绪（先定关系，再做变化）。
- 让跨镜头的左右/前后/高低/距离/视线保持一致（除非你明确执行一次“建立镜头→反打”）。
- 让首看点永远可读：不被特效/模糊/字幕遮挡。
- 让群戏的群众成为“可控的背景压力”，而不是“随机重排的噪声”。

## 统一坐标系（强制）
### 9:16 归一化屏幕坐标
- 坐标：x,y ∈ [0,1]（x：左→右，y：上→下）。
- 读点锁定：首看点默认锚定在 **中心偏上 1/3**（建议 `x0.50±0.05, y0.33±0.05`）。
- 字幕安全区：**y0.82-1.00 禁入**（关键读点/人物脸/手/命中点/道具字样禁止侵入）。

### 三层空间（强制）
- 前景：遮挡/压迫/材质/空间深度（允许轻微虚化，但不能遮主读点）。
- 中景：角色关系与动作主舞台（多数对话/对峙/交互发生在中景）。
- 后景：空间信息与群众压力（群戏必须“分组+循环”，不能随机走位穿插）。

## 轴线与屏幕方向（导演门禁）
### 180°轴线规则
- 轴线定义：以“核心对抗二人连线”为 180°轴线（或以“主体→首看点”为轴线）。
- 禁止跳轴：同一段落内不得跨过轴线切机位导致左右互换。
- 允许反打：必须先给一次建立镜头或显式写明“反打建立→再切”。

### 屏幕方向锁定
- 每个段落先写“屏幕方向锁定”：谁在画左/画右/画中，跨镜头不互换。
- 角色朝向要与屏幕方向一致：画右的人通常面朝画左（对手/读点方向），反之亦然。

## 几何约束（构图稳定）
### 画面几何门禁
- roll=0±1°（默认禁止 Dutch angle）。
- 同空间地平线稳定：建议 `地平线 y0.42±0.03`（没有地平线就用建筑水平线/柱线替代）。
- 对话/对峙眼线一致：建议 `眼线 y0.48±0.05`（特写可放宽到 ±0.06）。
- 消失点稳定：同一空间的透视消失点不乱漂移。

### 何时允许打破几何
只允许在以下情况且必须显式写明“理由与收束方式”：
- 强烈心理失衡：轻微 roll（≤3°）并在下一镜回正。
- 强冲击动作：背景可有速度感，但人物/武器边缘必须清晰，命中点固定可读。

## 位置关系（Blocking）写法规范
### 必写六要素
在每个 Shot 写清：
1. 空间：场景名 + 前/中/后景层级（以及字幕安全区留白）
2. 左右：谁在画左/画右/画中
3. 前后：谁在前景/中景/后景（谁压迫谁）
4. 距离：对峙 2-4m；拉拽 0.3-0.6m；近身 1-2m
5. 视线：视线互锁/看向道具/看向角落首看点
6. 命中点：固定在中心偏上 1/3（允许 ±5% 微调），结果帧清晰可读

### 站位模板（建议直接复用）
- **对峙模板**：A(画左) ↔ B(画右)，距离 2-4m，视线互锁，禁止跳轴。
- **上位压制模板**：上位者(画左前景/高位) ↔ 下位者(画右后景/低位)，高度差明确但左右不换。
- **一前一后模板**：压迫者前景遮挡边缘可接受但不遮脸，被压者后景眼神清晰。
- **三角站位模板**：三人形成稳定三角形（左右+后景），三点关系不互换。
- **环形围压模板（群戏）**：核心二人固定左右；群众分组锁定在左/右/后，形成压迫圈。

## 群戏调度（群众稳定方法论）
### 三组分区锁定（强制）
群众必须分三组并锁定屏幕方位，避免“随机重排”：
- 左侧起哄组：x0.05-0.30, y0.45-0.75（中景）
- 右侧窃笑组：x0.70-0.95, y0.45-0.75（中景）
- 后景围压组：x0.30-0.70, y0.15-0.45（后景）
- 主角活动区（群众禁入）：x0.40-0.60, y0.55-0.95
- 字幕安全区禁入：y0.82-1.00（任何群众/道具/特效禁入）

### 人数/动作循环/节拍频率（强制）
- 人数固定：每组固定人数（例如左3/右2/后5），镜头切换不变。
- 动作循环固定（A→B→A）：  
  - 左组：指指点点+起哄一拍→立刻收声  
  - 右组：交头接耳+压笑气音→停顿  
  - 后组：半步前压→停住→半步回弹
- 节拍频率固定：每 2 秒最多 1 次集体动作，其余仅微呼吸/头部微动。
- 位移上限：≤画面宽度的 3%/秒。
- 镜头切换连续性：群演保持上一镜结束姿态，禁止瞬间换站位/换人数。

### 群声的声像方位（强制）
- 左侧起哄声像偏左、右侧窃笑偏右、后景压迫偏后。
- 群声永远让位主台词与命中点，不可盖过关键句。

## 读点保护（Director Gate）
### 首看点规则
- 每镜头必须写“首看点是什么”，并给出坐标锚定。
- 文字读点：至少 1 秒稳定可读（不抖、不糊、不被闪光遮挡）。
- 眼神读点：必须有 catchlight；眨眼减少；视线落点稳定。
- 命中读点：结果帧必须清晰（裂血/回弹/碎裂），不能一团噪声糊过去。

### 遮挡与模糊门禁
- 任何特效光/烟尘/运动模糊不得遮挡首看点。
- 背景可做速度感，但人物与武器边缘必须清晰。

## 可执行落地模板（直接复制）
在每个 Shot 内追加这些行（按项目规范顺序）：

```text
【镜头参数】焦段倾向 35-50mm；中等景深；机位 眼平为主
【几何约束】地平线 y0.42±0.03；眼线 y0.48±0.05；roll=0±1°；禁止跳轴；同空间消失点稳定
【位置关系】空间: [场景]（前/中/后景层级清晰，保留字幕安全区） | 站位: A(画左)↔B(画右) | 距离 2-4m | 视线互锁 | 命中点=中心偏上 1/3
【读点保护】首看点=[读点]；坐标= x0.50±0.05, y0.33±0.05；禁止遮挡；禁止侵入字幕安全区 y0.82-1.00
```

群戏额外追加：

```text
群众分组锁定: 左组 x0.05-0.30 y0.45-0.75；右组 x0.70-0.95 y0.45-0.75；后组 x0.30-0.70 y0.15-0.45；主角活动区 x0.40-0.60 y0.55-0.95（群众禁入）；字幕安全区 y0.82-1.00 禁入
动作循环(节拍锁定): 每 2 秒最多 1 次集体动作；其余仅微呼吸/头部微动；位移≤3%画面宽度/秒；切镜不重排
```

## 常见失败与修复策略
- **站位漂移**：缺少坐标/禁入区/位移上限 → 补“坐标门禁+路径点+速度上限”。
- **跳轴左右互换**：未写轴线或反打建立 → 补“轴线=谁↔谁；反打需先建镜头”。
- **群戏乱跑**：没分组/没循环/没节拍 → 补“三组分区+人数固定+动作循环+节拍频率+切镜不重排”。
- **读点丢失**：没写首看点或写了但没门禁 → 补“读点坐标+可读时长+禁止遮挡+字幕安全区禁入”。

## 字段字典（与生成器输出一一对应）

> 目的：把模板字段变成“可复用的字段协议”，让后续项目不需要重新发明写法。  
> 适用对象：生成器输出行 `【几何约束】/【位置关系】/【读点保护】`。  
> 约定：同一行内用 `；` 表示子字段，用 `|` 表示并列模块（主要用于 `【位置关系】`）。

### 【几何约束】字段字典

- **GEO.HORIZON_Y（地平线）**
  - 输出位置：`【几何约束】`（以及全局的“空间锚定”）
  - 允许值：`y0.xx±0.xx`（建议范围 `y0.35-0.55`，误差 `±0.02-±0.06`）
  - 默认值：`y0.42±0.03`
  - 触发条件：默认启用；无地平线时用建筑水平线/柱线作为替代约束
  - 例：`地平线 y0.42±0.03（同一空间保持稳定）`

- **GEO.EYELINE_Y（眼线）**
  - 输出位置：`【几何约束】`
  - 允许值：`y0.xx±0.xx`（建议 `y0.42-0.58`）
  - 默认值：`y0.48±0.05`（特写可放宽到 `±0.06`）
  - 触发条件：对话/对峙/人物表演镜头必须开启
  - 例：`眼线 y0.46±0.05`

- **GEO.ROLL（画面水平/倾斜）**
  - 输出位置：`【几何约束】` + 全局“几何门禁”
  - 允许值：`roll=0±1°`（极限允许：`≤3°`，但必须写“理由与下一镜回正”）
  - 默认值：`roll=0±1°`
  - 触发条件：默认启用；强烈心理失衡才允许放宽
  - 例：`roll=0±1°`

- **GEO.AXIS_LOCK（轴线门禁）**
  - 输出位置：`【几何约束】`（以及 `【位置关系】` 的“轴线:”）
  - 允许值：`禁止跳轴` / `反打需先建镜头`（推荐组合）
  - 默认值：`禁止跳轴；同空间消失点稳定`
  - 触发条件：对峙/对话/群戏/打击交互镜头必须开启
  - 例：`禁止跳轴；同空间消失点稳定`

### 【位置关系】字段字典

> 结构：`模块 | 模块 | 模块`。每个模块内部用 `:` 定义键，用自然语言补充限定词。

- **BLK.SPACE（空间）**
  - 输出位置：`【位置关系】空间: ...`
  - 允许值：`空间: 场景名（前/中/后景层级清晰，保留字幕安全区）`
  - 默认值：若 Shot 没引用 @scene-，会沿用上一镜的场景提示（连续性）
  - 触发条件：强制（每镜头必须有）
  - 例：`空间: 林家练武场（前/中/后景层级清晰，保留字幕安全区）`

- **BLK.FORMATION（队形模板）**
  - 输出位置：`【位置关系】队形模板: ...`
  - 允许值：`对峙/上位俯视构图/一前一后/三角站位/环形围压`
  - 默认值：无；由镜头语义触发（群戏/俯拍/身后/人物数≥3 等）
  - 触发条件：
    - 群戏关键词（围观/人群/起哄/包围/环形）→ `环形围压`
    - 俯拍/居高临下/上位 → `上位俯视构图`
    - 身后/后方/背后 → `一前一后`
    - 人物≥3 → `三角站位`

- **BLK.SUBJECT（主体/核心站位）**
  - 输出位置：`【位置关系】主体:` 或 `核心站位:` 或 `站位:`
  - 允许值：角色名/道具名（带屏幕方位与坐标）
  - 默认值：人物存在时优先主角；纯道具镜头则用 `读点/道具` 充当主体
  - 触发条件：强制（每镜头必须能定位“谁是核心读点”）
  - 例：`主体: 林天觉醒前 位于画面右侧偏前景（坐标: x0.70 y0.70）`

- **BLK.SIDE（左右屏幕方向）**
  - 输出位置：主体/站位描述中的 `画面左侧/画面右侧/画面中心`
  - 允许值：`画面左侧/画面右侧/画面中心/画面左侧（上位）/画面左侧（上位/前景）` 等
  - 默认值：由“空间锚定/角色默认方位”提供基线（跨镜头不互换）
  - 触发条件：对话/对峙/打击/群戏强制

- **BLK.DEPTH（前中后景）**
  - 输出位置：`偏前景/中景/后景` 等字样
  - 允许值：`前景/中景/后景` + “遮挡不遮脸/脸可虚化但态度可读”等限定
  - 默认值：对峙：双人中景；压迫：上位前景、下位后景
  - 触发条件：对抗关系/群戏必须明确

- **BLK.DISTANCE（距离标尺）**
  - 输出位置：`相距 2-4m`、`0.3-0.6m`、`1-2m`
  - 允许值：`对峙 2-4m` / `拉拽 0.3-0.6m` / `近身 1-2m`
  - 默认值：对峙 2-4m
  - 触发条件：出现“对峙/拉住衣角/贴近/压迫”等语义时必须落值

- **BLK.GAZE（视线落点）**
  - 输出位置：`视线互锁/眼神落点明确/目光锁定...`
  - 允许值：互锁 / 指向道具读点 / 指向角落
  - 默认值：对峙互锁；道具镜头指向道具读点
  - 触发条件：出现“眼神/瞳孔/盯/锁定”等时强制

- **BLK.HITPOINT（命中点）**
  - 输出位置：`命中点固定在画面中心偏上 1/3`
  - 允许值：固定描述 + 结果帧可读
  - 默认值：中心偏上 1/3（允许 ±5%）
  - 触发条件：出现“命中/砰/对撞/裂血/受力”等时强制

- **BLK.CROWD.GROUPS（群众分组锁定）**
  - 输出位置：`群众分组锁定: ...`
  - 允许值：三组分区 + 固定人数 + 动作循环 + 节拍频率 + 位移上限 + 切镜连续性 + 声像方位
  - 默认值：左3/右2/后5（可改）；每2秒≤1次集体动作；位移≤3%画面宽度/秒
  - 触发条件：群戏关键词触发（围观/群众/人群/起哄/嘲笑/包围/环形等）

- **BLK.CROWD.NO_GO（禁入区）**
  - 输出位置：群众分组模块中的 `主角活动区（群众禁入）` 与 `字幕安全区禁入`
  - 允许值：
    - 主角活动区：`x0.40-0.60 y0.55-0.95（群众禁入）`（可按项目调整）
    - 字幕安全区：`y0.82-1.00 禁入`
  - 默认值：如上
  - 触发条件：群戏触发；字幕安全区永远生效

### 【读点保护】字段字典

- **FOCUS.NAME（首看点名称）**
  - 输出位置：`【读点保护】首看点=...`
  - 允许值：一个明确对象（眼神/字样/命中点/道具名/构图意图）
  - 默认值：优先使用 `【画面】` 内的“首看点：…”；否则回退到 `【位置关系】` 的 `读点/道具`
  - 触发条件：强制（每镜头必须有）

- **FOCUS.COORD（首看点坐标锚定）**
  - 输出位置：`坐标= x0.50±0.05, y0.33±0.05`
  - 允许值：`x0.xx±0.xx, y0.xx±0.xx`
  - 默认值：`x0.50±0.05, y0.33±0.05`
  - 触发条件：强制（每镜头必须有）

- **FOCUS.OCCLUSION_BAN（禁止遮挡）**
  - 输出位置：`任何特效光/运动模糊不得遮挡首看点`
  - 允许值：固定门禁句（可加“烟尘/雾化”）
  - 默认值：开启
  - 触发条件：强制

- **FOCUS.SUBTITLE_SAFE_BAN（字幕安全区禁入）**
  - 输出位置：`禁止侵入字幕安全区 y0.82-1.00`
  - 允许值：固定门禁句
  - 默认值：开启
  - 触发条件：强制

- **FOCUS.TEXT_READABLE（文字可读时长）**
  - 输出位置：当首看点包含“字样/文字”等时追加
  - 允许值：`至少 1 秒稳定呈现`
  - 默认值：开启（文字类读点自动触发）
  - 触发条件：首看点包含“字样/文字/牌匾/婚约”等关键词

- **FOCUS.EYE_CATCHLIGHT（眼神可读）**
  - 输出位置：当首看点为眼神/瞳孔时追加
  - 允许值：`必须有 catchlight；眨眼减少；视线落点稳定`
  - 默认值：开启（眼神类读点自动触发）
  - 触发条件：首看点包含“眼神/瞳孔/目光/眼睛”等

- **FOCUS.HIT_READABLE（命中结果可读）**
  - 输出位置：当首看点为命中/裂血等时追加
  - 允许值：`命中点固定...；结果帧清晰可读`
  - 默认值：开启（命中类读点自动触发）
  - 触发条件：首看点包含“命中/拳/砰/冲击/裂血/指节”等

- `【位置关系】`：由生成器根据 `【参考】` 的人物/场景/道具与镜头语义触发队形模板、群戏分组、坐标禁入区、路径点等。对应实现：[seedance_emit_omni_paste.py](file:///Users/billy/Documents/AI_pro/漫剧创作库/tools/seedance_emit_omni_paste.py#L360-L548)
- `【读点保护】`：优先抽取 `【画面】` 的“首看点：…”，否则回退到 `【位置关系】` 的读点/道具，并按类型追加文字/眼神/命中门禁。对应实现：[seedance_emit_omni_paste.py](file:///Users/billy/Documents/AI_pro/漫剧创作库/tools/seedance_emit_omni_paste.py#L550-L636)
