# shot-rhythm-casebook.md — 镜头节奏案例库

## 用途
沉淀开场钩子、爽点爆发、情绪停顿、反转揭示、打斗提速等高频镜头节奏组合，为导演、分镜、剪辑提供统一节奏参考。

## 节奏类型

### 1. 开场 3 秒钩子
公式：冲突画面 → 反应特写 → 问题抛出
适用：短视频短剧、漫剧首屏、预告开场

### 2. 打脸反转
公式：压制建立 → 羞辱升级 → 停顿一拍 → 反击爆发 → 结果定格
适用：逆袭、复仇、身份揭示

### 3. 情绪停顿
公式：动作中止 → 呼吸/眼神特写 → 环境音留白 → 缓推近
适用：告白、背叛、死亡、诀别

### 4. 动作提速
公式：建立空间 → 起手动作 → 两到三段连招 → 受击反应 → 收势定格
适用：Seedance 动作戏、群架、追逐

### 5. 悬念揭示
公式：遮挡信息 → 局部异常 → 人物反应 → 真相揭示
适用：恐怖、悬疑、身份反转

## 使用规则
- 一条节奏链只服务一个核心爽点
- 爽点前必须有压制，不能平地起高潮
- 情绪停顿不能过长，避免短剧节奏塌陷
- 平台不同，节奏长度必须重调
