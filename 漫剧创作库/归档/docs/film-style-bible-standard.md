# 影片风格画质母版标准

> 文件位置建议：`projects/<项目名>/03-assets/style/visual-style-bible.md`

---

## 1. 交付定位

`visual-style-bible.md` 是项目进入资产、分镜、导演故事板图和视频生成前必须锁定的整剧视觉母版。它负责约束：

- 角色设定稿；
- 场景720全景图；
- 场景12宫格视角图；
- 道具设定稿；
- 分镜表；
- D12 / D15 导演故事板图；
- Sora2 / Seedance2 适配包；
- 生图与视频提示词；
- 后期声音与画质包装。

## 3. 门禁

- 没有 `visual-style-bible.md`，不得进入批量角色 / 场景 / 道具资产生产。
- 没有 `visual-style-bible.md`，不得进入 D12 / D15 导演故事板图生成。
- 下游若需要改变主风格，必须回到本文件修订并重新执行 Pipeline Sync；不得在单个提示词里临时改风格。
- HZW 项目可使用 HZW 作为主风格；非 HZW 项目也可引用 HZW 的质感控制方法，但必须写清它是“控制方法”还是“主风格”。
