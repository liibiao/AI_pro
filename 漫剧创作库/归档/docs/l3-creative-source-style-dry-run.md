# L3 干跑：创作源输入 → 风格基调 → 场景类型 → D12/D15 故事板约束

> 日期：2026-05-07  
> 用途：验证“创作源输入 + 影片风格画质基调筛选 + 场景类型库 + visual-style-bible 锁定”能端到端服务 D12-Sora2 / D15-Seedance2 导演故事板图。

---

## 1. 创作源输入

**输入样例：**

> 少年林天在林家练武场被众人嘲笑为废物，灵纹碑石突然异动，他在压迫中觉醒灵纹，反手击退挑衅者。

**输入类型识别：** 故事梗概 / 场景梗概。  
**成熟度：** L1。  
**推荐工作流：** A线故事开发补齐人物关系与场景冲突；若已有项目剧本，则可作为 B线制作执行的单场景片段。

---

## 2. 题材与场景类型识别

- 题材：玄幻逆袭 / 少年觉醒 / 练武场对抗。
- 核心情绪：压迫 → 爆发 → 反压。
- 主要场景类型：`xianxia-magic-combat` / `fight-hand-to-hand` / 对峙压迫。
- D12 建议：4-6 Panel，压缩为“压迫建立 → 石碑异动 → 觉醒爆点 → 击退结果”。
- D15 建议：5-8 Panel，可加入群众反应、灵纹微动作、结果留钩子。

---

## 3. 风格推荐 Top3

| 排名 | style_id | 推荐理由 | 风险 |
|---|---|---|---|
| 1 | `cinematic-hzw-premium` | 适合玄幻逆袭、强压迫、动作受力、电影级高反差与 PBR 质感 | 若过度写实可能削弱国漫热血爽感 |
| 2 | `donghua-nezha-mythic-cg` | 适合少年觉醒、国风神话 CG、灵力爆发与热血情绪 | 特效过多会遮挡人物动作和第一读点 |
| 3 | `donghua-qin-wuxia-3d` | 适合练武场、宗门、武侠/玄幻空间和稳重 3D 国漫质感 | 动作速度可能不如 Trigger / 龙珠式夸张 |

**默认建议：** 主风格选择 `cinematic-hzw-premium`，副风格吸收 `donghua-nezha-mythic-cg` 的国风灵力爆发；HZW 在本项目中作为主风格 + 质感控制方法。

---

## 4. visual-style-bible 摘要草案

- 主风格：HZW电影专业质感。
- 副风格：国漫神话 CG 的灵力爆发与少年热血。
- 光影：high contrast，练武场主体亮、群众和看台压暗，灵纹碑石触发冷金色发光。
- 色彩：灰石、旧木、冷青阴影、金色灵纹点缀。
- 材质：石碑 PBR 粗糙度变化、AO 缝隙阴影、旧木武器架磨损、衣料非塑料化。
- 画质：电影化 HDR / 类 ACES、细微胶片颗粒、极轻微 halation。
- 镜头：先关系后爆点，低机位压迫 + 侧前方受力 + 结果镜头。
- 禁止项：禁止全屏光污染、禁止灵力遮脸、禁止只写“震撼觉醒”、禁止 HZW 与日漫夸张线条无控制混用。

## 5. D12 / D15 故事板约束验证

### D12-Sora2

- 总时长：12s。
- Panel 建议：4 格。
- 结构：
  1. 0-3s：低机位建立压迫，群众围观，林天被逼退。
  2. 3-6s：灵纹碑石异动，林天手背灵纹亮起，表情从忍耐到抬眼。
  3. 6-9s：侧前方机位，林天反击命中，接触点清晰。
  4. 9-12s：挑衅者后退撞上武器架，群众静默，林天稳住落幅。

### D15-Seedance2

- 总时长：15s。
- Panel 建议：6 格。
- 增加：石碑特写、群众反应、灵纹光线扫过地面、结果留钩子。
- Stable 参考优先级：D15 故事板图 > 林天角色设定稿 > 林家练武场 12 宫格图 > 灵纹碑石道具图。
