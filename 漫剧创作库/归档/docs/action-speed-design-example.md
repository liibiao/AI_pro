# 动作速度表现完整示例

> 示例用途：演示如何把《动作速度表现规范》真正落进导演讲戏、分镜拆解与动作提示词补充结构。  
> 示例类型：近身三连击 + 高速闪避反打  
> 适用：短剧 / 漫剧 / Seedance 动作设计参考

---

## 一、场景设定

- 场次：废弃仓库近身搏斗
- 人物：主角（主动进攻） / 反派（先守后反打）
- 段落目标：用短时间内的贴身三连击制造压迫，再用高速闪避反打完成优势逆转
- 主要观感：快、狠、压迫、清晰、打得实

---

## 二、导演讲戏版动作速度拆解

### 段落名称
- 场次：仓库二层平台近身交锋
- 段落目标：主角先发制人，三连击压住反派；反派在第三击后凭横向急闪脱离压制并反打
- 主动方：前半段主角，后半段反派
- 结果导向：主角压制成功但未终结，反派抓住空档完成一次干净反击

### 1. 动作意图
- 这一段主要传达：快、狠、压
- 观众最该看到的爽点：
  1. 主角第三击顶膝打实
  2. 反派横向急闪时的速度感
  3. 反派反手肘击命中主角肋侧

### 2. 动作链
- 起势：主角压低肩线逼近，右脚前踏抢入距离
- 发力：主角左直拳试探打开防线，立即衔接右肘横扫
- 位移：主角再向前贴一步，提膝顶向反派腹部
- 命中 / 接触：前两击压住反派防守，第三击顶膝打实
- 反应：反派身体后弓，借失衡瞬间向左急闪脱离正面压制
- 收势：反派落点后迅速回身，以短促肘击反打主角肋侧

### 3. 镜头与节奏
- 起势镜头怎么交代：中近景看清主角压肩逼近与脚下抢步
- 哪一段进入快切：从左直拳打出开始，到右肘横扫和顶膝连续进入快切
- 哪一段必须稳住看清：第三击顶膝命中、反派横移落点、反派肘击反打命中
- 命中镜头如何兑现：顶膝命中给半拍清晰镜头，主角肋侧受肘再给一个明确接触点
- 收尾镜头如何留余味：主角被肘击后半跪侧退，反派收肩站稳，形成短暂对峙

### 4. Motion Blur 使用策略
- 模糊对象：主角拳锋、右肘摆动、反派横向急闪时的身体边缘、whip pan 过程中的背景
- 模糊阶段：出拳中段、肘击摆动中段、反派急闪过程、镜头甩跟过程
- 模糊强度：主角连击轻到中度 blur；反派横闪中度 blur；命中帧保持清晰
- 必须保持清晰的内容：顶膝命中、反派落点、反派肘击接触主角肋侧、双方收势表情

### 5. 风险提醒
- 是否可能乱切：是，连击段若切点全压在同一动作层，会导致信息重复
- 是否可能过糊：是，反派横闪与镜头甩跟不能同时拉到重度 blur
- 是否存在动作逻辑不清：需确保反派先受压制再脱离，不能像突然瞬移
- 是否缺少结果反馈：必须加入主角肋侧受击后的呼吸停滞和侧退反应

## 五、动作提示词补充结构示例

### A. 动作速度描述
- 该段速度目标：近身抢攻的爆发快 + 闪避反打的位移快
- 爆发动作：左直拳、右肘横扫、贴步顶膝
- 连击节奏：由清晰起势进入短促快切，在顶膝命中处放清楚
- 是否使用快切感表达：是

### B. 镜头表达
- 起势镜头：中近景交代主角压肩逼近与脚下抢步
- 爆发镜头：快速切入左拳与右肘连续进攻
- 命中镜头：顶膝命中与反手肘击命中都必须明确清晰
- 反应镜头：反派后弓后横闪脱离，主角扑空前送
- 收势镜头：双方拉开半步形成新的对峙

### C. Motion Blur 表达
- 模糊对象：拳锋、肘部、反派横闪时身体边缘、甩镜背景
- 模糊强度：轻到中度
- 模糊阶段：出拳中段、肘击摆动中段、横闪过程、whip pan 过程
- 保持清晰的关键帧：顶膝命中腹部、反派落点、肘击肋侧接触点、双方收势表情

### D. 限制说明
- 不要全程持续重度模糊
- 不要把顶膝命中与肘击命中做糊
- 不要因为快切破坏人物左右方向关系
- 必须保留主角压制成功与反派反打成功这两个清晰爽点
