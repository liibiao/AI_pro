# shot-duration-and-density-standard.md — 镜头时长与节拍密度规范

> 适用范围：AI 短剧 / 漫剧 / Seedance 视频镜头 / 分镜设计 / 剪辑预判  
> 核心目标：让镜头时长、节拍密度、信息承载量与叙事任务匹配，避免“镜头很热闹但信息不清”。

---

## 1. 规范定位

镜头时长不是越短越刺激，也不是越长越高级。真正重要的是：

- 一个镜头承担什么任务
- 一个镜头能装下多少信息
- 观众能否在有限时间里读清主体、关系与结果

本规范强调三件事：
1. **镜头任务优先**
2. **节拍密度受控**
3. **安全区预留**

---

## 2. 基本概念

### 2.1 镜头任务
每个镜头应先明确承担哪一类任务：
- 建立空间
- 建立关系
- 建立压迫
- 爆发动作
- 命中确认
- 情绪变化
- 台词命中
- 结果兑现
- 钩子打断
- 身份确认

### 2.2 节拍密度
节拍密度指：
> 单个镜头内，观众需要完成多少次有效信息读取。

可读的节拍通常包括：
- 一次明确动作变化
- 一次关系翻转
- 一次表情落点
- 一次台词命中
- 一次结果确认

### 2.3 安全区
镜头前后应预留安全区，避免关键内容顶在切点上。

建议：
- 开头 0.5 秒：建立镜头 / 给观众进入时间
- 结尾 0.5 秒：动作收尾 / 为下镜留接口

> 实际有效内容 = 总时长 - 1 秒

---

## 3. 总原则

### 原则 1：一个镜头只承担一个主任务
可以附带次任务，但不能并列承担多个核心任务。

### 原则 2：节奏变化服务信息清晰，不服务花哨感
切得快不等于强，镜头稳也不等于弱，关键看是否放大了真正重要的信息。

### 原则 3：动作镜头要短，情绪镜头可长，台词镜头要稳
- 动作镜头：优先保动作阶段清楚
- 情绪镜头：优先保情绪变化读点
- 台词镜头：优先保口型、眼神、停顿

### 原则 4：镜头长度必须服从镜头任务
镜头时间不够时，先拆镜，不靠堆词硬塞。

### 原则 5：密度高的镜头必须有明确“看清点”
即使允许 blur、快切或甩镜，也必须给观众看清起手、命中、结果或站定之一。

## 4. 时长建议（方法型，不是铁律）

### 4.1 建立镜头
适合：空间建立、人物入场、秩序建立
- 建议时长：3s ~ 5s
- 节拍建议：0 ~ 1
- 重点：先读空间，再读主体

### 4.2 关系建立镜头
适合：压制、对峙、站位变化、主导权确认
- 建议时长：2.5s ~ 4s
- 节拍建议：1
- 重点：看清谁压谁、谁站住、谁后退

### 4.3 爆发动作镜头
适合：突袭、连击、冲刺、转身爆发
- 建议时长：1.5s ~ 3s
- 节拍建议：1
- 重点：起势或结果至少清楚一头

### 4.4 命中确认镜头
适合：打中、撞上、接触成立、结果落实
- 建议时长：1.5s ~ 2.5s
- 节拍建议：1
- 重点：命中点必须看清

### 4.5 情绪表演镜头
适合：轻笑、冷眼、迟疑、下定决心、站定
- 建议时长：2.5s ~ 5s
- 节拍建议：1
- 重点：变化幅度可以小，但落点必须准

### 4.6 台词命中镜头
适合：反问、反压、宣判、钩子句
- 建议时长：2.5s ~ 4s
- 节拍建议：1
- 重点：口型、眼神、停顿优先

### 4.7 结果兑现镜头
适合：全场静住、回头、环境反应、收势站定
- 建议时长：2s ~ 4s
- 节拍建议：1
- 重点：结果比过程更重要

### 4.8 钩子打断镜头
适合：门开、广播、外部闯入、身份揭晓
- 建议时长：2s ~ 4s
- 节拍建议：1
- 重点：打断事件与反应结果要清楚

## 5. 节拍密度建议

### 5.1 通用规则
- 每 2.5 秒建议不超过 1 个核心节拍
- 5 秒镜头建议最多 2 个核心节拍
- 若一个镜头里同时要讲动作、关系、台词、结果，通常应拆镜

### 5.2 动作段落规则
动作镜头常见节拍：
- 起势
- 爆发
- 命中
- 反应
- 收势

这些节拍不应强行塞进一个镜头。推荐拆成多个功能镜头。

### 5.3 台词段落规则
台词镜头通常只允许一个主命中点：
- 说出这句话
- 说完后的停顿
- 对方反应

若三者都重要，至少拆成两镜。

### 5.4 情绪段落规则
情绪镜头常见结构：
- 情绪前锁住
- 情绪变化
- 结果停住

若三步都需要明确，建议主镜 + 结果镜拆开。

---

## 6. 短剧适用建议

### 6.1 爽点镜头
- 爽点不是靠镜头更快，而是靠结果更清楚
- 尤其是打脸、反压、逆转，必须优先保结果命中

### 6.2 群像镜头
- 群像镜头优先保事件清楚，不先保热闹
- 人多时，节拍密度必须主动降下来

### 6.3 台词钩子镜头
- 不要同时追求台词、运镜、环境大变化、群像反应全都成立
- 钩子句优先保口型与停顿

---

## 7. 漫剧适用建议

漫剧虽然没有视频时长，但同样有“阅读节拍密度”问题。

### 7.1 单格任务建议
每格优先只承担：
- 一个关系变化
- 一个表情落点
- 一个动作结果
- 一个空间建立

### 7.2 阅读顺序建议
- 先保证读者知道先看谁
- 再保证对白区 / 气泡区不压主信息
- 再谈动效、速度线和风格强化

### 7.3 动效格建议
如果是动效漫剧，优先把：
- 静帧主信息
- 动效附加信息
拆开思考，不让动效吞掉阅读顺序

---

## 8. 分镜阶段最小字段补充
建议在结构化分镜表中，至少增加以下字段：
- 镜头任务
- 首看点
- 节拍数
- 安全区
- 风险 / 回退点

---

## 9. 失败信号

以下情况说明镜头时长与密度设计失败：
- 一个镜头里既要讲动作又要讲台词还要讲结果
- 看完后只觉得忙，不知道重点是什么
- 关键爽点顶在切点上
- 需要靠大量解释才能知道镜头在讲什么
- 明明是情绪镜头，却被剪得像动作镜头
- 明明是动作镜头，却没有任何清晰确认点

## 12. 镜头时长自动分配算法（jl 函数）

> 来源：从链式引擎规则层吸收，作为本规范的工程化补充。与上文"方法型建议"共存——方法型建议用于人工判断，jl 算法用于批量自动分配。

### 12.1 函数签名

```
jl(totalSec, shotCount, offset=0, maxShotSec=15, paceKey="balanced")
  → [{ index, start, end, duration, pace, link }, ...]
```

| 参数 | 含义 | 默认 |
|---|---|---|
| `totalSec` | 本场总时长（秒） | — |
| `shotCount` | 切分镜头数 | — |
| `offset` | 全局起始偏移（多场景拼接时累加） | 0 |
| `maxShotSec` | 最大单镜时长 | 15 |
| `paceKey` | 节奏预设（来自 `wordlists/style/narrative-pace-presets.json`） | `balanced` |

### 12.2 算法五步

**Step 1 · 加载节奏预设**
从 `narrative-pace-presets.json` 读取 `shotDivisor`、`phase[]`（起承转合权重）、`pattern[]`（长短交替循环）、`links[]`、`minShotSec`、`cuttingGuide`。

**Step 2 · 确定基础时长**
```
baseSec = (totalSec >= shotCount × minSec) ? minSec : 1
durations = [baseSec, baseSec, ...]  // 长度 = shotCount
remaining = totalSec - shotCount × baseSec
```
先保证每镜至少放下最小时长，剩余秒数按权重分配。

**Step 3 · 计算每镜权重（phase × pattern）**
- **phase 轴**（起承转合）：让权重随剧作结构起伏（0.2→起 / 0.5→承 / 0.75→转 / 1.0→合）
- **pattern 轴**（长短交替循环）：让相邻镜头形成节奏呼吸

**Step 4 · 按权重分配剩余秒数**
```
extra = floor(remaining × weight[b] / sumWeight)
extra = min(extra, maxShotSec - baseSec)   // 不超上限
```

**Step 5 · 补齐余数 + 分类 pace**
- 余数逐镜 +1，直到全部分完或所有镜头触顶
- pace 分类：≤4s→快 / ≤7s→中 / ≤10s→慢 / >10s→长
- 每镜继承 links[] 中的链接类型

### 12.3 shotCount 推荐公式

```
shotCount ≈ ceil(totalSec / shotDivisor)
```

| paceKey | shotDivisor | 示例（45s） |
|---|---|---|
| action | 2.8 | ~16 镜 |
| thriller | 4 | ~11 镜 |
| balanced | 5 | ~9 镜 |
| dialogue | 7.2 | ~6-7 镜 |
| lyrical | 7.8 | ~6 镜 |

### 12.4 关键不变量

- **单镜下限**：`minShotSec`（不能低于此值，否则观众无法读镜）
- **单镜上限**：`maxShotSec`
- **总和守恒**：所有镜头 duration 之和 = totalSec
- **时间轴连续**：shots[b].start === shots[b-1].end（不允许跳秒）

### 12.5 与分镜的对接

- `start/end` → 分镜表时间段列
- `pace` → 影响景别和运镜选择（快=特写/跳切、慢=中全景/推拉）
- `link` → 写入提示词衔接子句（如"与上镜衔接：动作承接"）
- `cuttingGuide` → 注入系统提示词指导切镜策略

### 12.6 视频时长估算公式（Ku 函数）

输入剧本文本，输出推荐视频总时长：

| 维度 | 公式 | 说明 |
|---|---|---|
| 台词 | `dialogueChars / 3.5` | 引号内总字数 ÷ 3.5s/字 |
| 动作 | `actionCount × 3.5` | 动作动词命中数 × 3.5s |
| 场景切换 | `sceneCount × 3` | 场景标记数 × 3s |
| 描述性文字 | `descChars / 18` | 非台词字数 ÷ 18 |

合计后：`total = max(dialogue + action + scene + desc, sceneCount × 8)`，对齐 5 秒， clamp 到 [15s, 300s]。
