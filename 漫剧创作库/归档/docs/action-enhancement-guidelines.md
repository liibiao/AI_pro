# 动作戏增强规范 (Seedance / 即梦 适配版)

> 本规范用于将分镜剧本（Storyboard）翻译为最终可执行的 AI 视频提示词（Seedance 字段版或即梦长句版）。

---

## 1. 核心原则：建立“力的闭环”
所有高燃打斗镜头，必须在 Prompt 中写透四个层级：
1. **角色受力**：谁打谁？打哪里？被击中者怎么形变（吐血、后仰）？
2. **节奏变化**：严禁匀速。必须写出“慢蓄力 -> 快出招 -> 停顿 -> 快反击”的变速感。
3. **环境联动**：让尘土、碎石、气浪承接一拳溢出的威力，但严禁遮盖角色脸部。
4. **镜头反应**：镜头可以手持晃动、可以震动，但严禁跳轴。

## 2. Seedance 适配规范 (分段字段版)

在 `epXXX-seedance2-paste.md` 等文件中，要求如下：

### A. 时间结构
每段动作必须写清时间轴内的节奏变化，例如：
- `0-2s`：对峙蓄力，先静后响。
- `2-4s`：极速突进与出招。
- `4-5s`：碰撞瞬间轻微定格。
- `5-7s`：反击命中，身体击飞与环境破坏。

### B. 主体表达 (必须带 `@`)
- **@Image 角色死锁 (On-model)**：不要用文字长篇大论描述长相！直接利用 Seedance 2.0 的王牌角色参考功能。
  - 格式：`@Image1 (角色A) launches attack... @Image2 (角色B) sidestep...`
  - 原理：把图片当成变量注入，无论打斗多剧烈，大模型都会死死锁住这两个角色的特征，全程不崩坏。
- 必须明确 `@谁` 打 `@谁`，打向哪里。
- **不允许**使用“双方打成一团”、“激烈交锋”这类模糊描述。
- **示例**：`@Image林傲天 极速挥拳，@Image林天 瞬间抬臂格挡硬接。`

### C. 速度与受力表达
- 必须带速度词，至少一快一慢：`缓慢蓄力 + 极速出招`、`碰撞定格 + 猛然击飞`。
- 必须写身体反馈：`后仰`、`离地`、`滞空`、`回弹`、`滑退`、`失衡`。

### D. 环境与镜头门禁
- **读点保护**：脸、拳、兵器锋刃、命中部位只能有一个主读点；粒子和运动模糊**不得遮挡**该读点。
- **物理环境隔离指令 (价值千金)**：为了防止画面一快就糊，必须加入指令：`motion blur on BACKGROUND ONLY (characters and weapons stay crisp)`。强制隔离物理引擎，背景可模糊，但人物和武器边缘必须绝对锐利。
- **特效限制**：冲击波、剑气、雷光只能放大力量，不能代替力量；特效亮度不能污染角色五官。
- **运镜限制**：优先使用 `低角度跟拍 / 命中特写 / 轻微手持震动`，但必须满足 `不跳轴、地平线稳`。
- **高燃动作强化 (ACT视角)**：在剧情推进到极度激烈的高潮近战（如终极连招或处决技）时，可注入 `ACT视角，镜头跟随出拳方向，打击时有停顿感`。该指令能极大增强沉浸感与力量感，但**不可滥用**，需配合“先静后响”与“物理留白”使用，避免整集都在主观晃动。

### E. 典型 Seedance 结构示例
```text
【4s-8s】
主体：@Image林天 压低重心后突然暴起，极速突进至 @Image林傲天 面前；@Image林傲天 瞬间抬臂格挡，碰撞瞬间轻微定格，随后 @Image林天 毫无停顿立刻反击，一拳精准命中其胸口
空间：@林家练武场
镜头：贴地快速推进→命中特写→轻震后迅速回稳；不跳轴，命中点清楚
受力：@Image林傲天 身体后仰离地，短暂滞空后向后猛飞，衣料剧烈翻飞
环境：落点处青石地面崩裂，碎石尘土炸开，但不得遮挡脸部与命中点。motion blur on BACKGROUND ONLY (characters and weapons stay crisp)。
```

## 3. 即梦适配规范 (长句叙事版)

在 `epXXX-omni-paste.md` 等文件中，要求如下：

### A. 句式风格
- 即梦更吃“氛围 + 动势 + 单句强画面”。
- 描述要更直观，像导演的口述。长句串联，但**每句只保一个主动作**。

### B. 优先信息与画面写法
- 多用直观词和可视化结果：`突然暴起`、`快如闪电`、`毫无停顿`、`竹叶被震飞`、`地面炸裂`、`衣摆狂翻`。
- 避免过度堆砌冰冷的参数，保留必要的空间感即可。

### C. 镜头与控制项
- 镜头可以写得更感性：`镜头贴地跟进、命中瞬间猛震、随后快速拉开看全景`。
- 控制项化繁为简：保留 `不跳轴`、`命中点清楚`、`脸不被特效盖住` 即可。

### D. 推荐结构与示例
- **结构**：`场景 + 对抗双方 + 动作链 + 受力结果 + 环境联动 + 镜头反应 + 风格强化`
- **示例**：
> `@林天` 在 `@林家练武场` 压低重心后突然暴起，极速逼近 `@林傲天`，拳头快如闪电直冲胸口。`@林傲天` 仓促抬臂格挡，碰撞瞬间爆出冲击波，画面短暂停顿一下（先静后响）；下一秒 `@林天` 毫无停顿立刻反击，重拳正中 `@林傲天` 胸口，把他打得后仰离地、短暂滞空、随后猛然倒飞。地面炸开裂纹，碎石和尘土冲天而起，镜头贴地跟进，在命中瞬间猛烈震动后迅速拉开。整段动作高燃、凌厉、压迫感极强，严禁跳轴与遮挡脸部读点。
