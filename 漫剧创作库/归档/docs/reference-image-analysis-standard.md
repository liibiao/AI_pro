# reference-image-analysis-standard.md — 参考图八维分析规范

> 适用范围：AI 短剧 / 漫剧 / 角色设计 / 场景设计 / 道具设计 / 分镜参考图反推  
> 核心目标：把外部参考图、历史生成图与项目资产图，从“看感觉”升级为“可拆解、可回收、可复用”的结构化视觉知识。

---

## 1. 规范定位

参考图不是拿来直接模仿的，也不是拿来堆长提示词的。参考图的真正价值在于：

- 提取叙事信息
- 提取视觉结构
- 提取光影与构图规律
- 提取可复用资产锚点
- 反推出稳定可执行的提示词层

本规范要求所有高价值参考图，优先被拆成：

1. **叙事摘要层**
2. **视觉结构层**
3. **资产标签层**
4. **执行提示层**

> 原则：先分析，再归纳；先抽方法，再写提示词；先入资产库，再入生成链。

---

## 2. 八维分析框架

### 2.1 主体身份与当前状态
回答：这张图里，谁是主体？主体现在处于什么叙事状态？

必须拆清：
- 主体是谁
- 主次关系如何分配
- 主体是进攻、压制、硬撑、反扑、观察，还是站定
- 当前画面的叙事作用是什么：建立 / 压迫 / 爽点 / 反转 / 结果 / 钩子

**输出要求：**
- 用一句话写出“这张图在讲什么”
- 用一句话写出“主体当前状态”

### 2.2 面部与表情
回答：观众最先读到的表情信息是什么？

必须拆清：
- 面部朝向
- 视线方向
- 眼神强度
- 嘴角 / 口型状态
- 情绪变化起点与落点

**输出要求：**
- 明确“表情读点”
- 明确哪些信息必须保持清晰，不可被特效或环境吞掉

### 2.3 发型与发色
回答：角色最稳定的头部识别锚点是什么？

必须拆清：
- 发型轮廓
- 发长 / 层次 / 刘海结构
- 发色主色与过渡色
- 容易漂移的风险点

**输出要求：**
- 提炼为 2~4 个高识别锚点
- 禁止只写空泛审美词

### 2.4 服装与配饰
回答：角色靠什么外观元素被认出来？

必须拆清：
- 主服装轮廓
- 材质
- 主色 / 辅色
- 配饰位置与数量
- 是否存在战损、夜景、礼服、职业装等变体入口

**输出要求：**
- 标出主锚点与可变层
- 区分“必须保留”与“可替换”元素

### 2.5 场景环境与空间
回答：这张图的空间关系是什么？

必须拆清：
- 场景类型
- 前景 / 中景 / 后景
- 门、窗、桌、通道、台阶、灯位等关键空间锚点
- 主体与空间的相对位置

**输出要求：**
- 用“空间结构句”描述画面
- 明确哪些空间关系不能乱

### 2.6 光影与色彩
回答：这张图靠什么光影组织情绪？

必须拆清：
- 主光方向
- 光源性质（硬 / 软 / 冷 / 暖）
- 明暗对比
- 主色调与辅助色
- 是否有局部高光、边缘光、剪影、气氛光

**输出要求：**
- 写出“光影组织句”
- 标出影响叙事的关键光影信息

### 2.7 构图与镜头语言
回答：这张图为什么一眼能看清？

必须拆清：
- 景别
- 机位角度
- 画面重心
- 阅读顺序
- 镜头强调的是主体、关系、结果还是空间

**输出要求：**
- 明确阅读顺序
- 标出“观众首先应看见什么”

### 2.8 质感与风格锚定
回答：这张图的风格到底靠什么成立？

必须拆清：
- 线条 / 颗粒 / 材质 / 锐度 / 景深
- 写实 / 风格化 / 韩漫 / 电影感等大类判断
- 真正有效的风格锚点
- 不建议照搬的表面词

**输出要求：**
- 只保留对执行有帮助的风格锚点
- 禁止堆导演名、IP 名、空泛美学词

## 3. 四层输出法

### 3.1 叙事摘要层
只回答：
- 这一帧在讲什么
- 谁主导
- 结果是什么

### 3.2 视觉结构层
只回答：
- 主体外观
- 空间结构
- 光影组织
- 构图重点

### 3.3 资产标签层
建议统一写成：
- `@人物`
- `@场景`
- `@道具`
- `@服装变体`
- `@光影版本`

### 3.4 执行提示层
最后才输出：
- 可复用正向提示词结构
- 禁止项 / 风险项
- 适配模型的执行建议

> 关键原则：分析报告可以长，执行提示必须短、稳、清楚。

## 5. 使用原则

1. 先提叙事，再提审美
2. 先提结构，再提风格
3. 先提锚点，再提修饰词
4. 先入资产标签，再入提示词
5. 外部参考只吸收方法，不照搬作品表面特征

---

## 6. 失败信号

以下情况说明分析不合格：
- 全篇只有“高级、电影感、氛围感”等空词
- 只会描述漂亮，不会描述结构
- 不能指出主体是谁、空间怎么组织、光怎么打
- 看完分析后仍无法进入资产库或提示词执行层
- 把外部参考图直接当最终风格模板，不做项目适配
