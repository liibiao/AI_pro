> 适用：GPT 生图、gpt-image-2、图生图精修、海报/KV/UI/设定稿/信息图/商品广告/漫画页面/静态分镜板/动作分解参考表/品牌视觉/写实人像/3D微缩/国风插画/科幻机械/自然风光等静态图像任务。  
> 核心定位：GPT 生图不是“关键词堆叠器”，而是“可执行的视觉设计说明书”。

## 1. 总原则：把 GPT 当成视觉设计执行者，而不是风格滤镜

从样本库可见，gpt-image-2 对以下信息极其敏感：

1. **结构化任务定义**：`type / format / layout / sections / count / labels` 比单纯风格词更稳定。
2. **画面分区与数量约束**：明确“几格、几栏、几个面板、几个角色、几个模块”。
3. **主体锚点**：角色/产品/建筑/道具必须有可识别外观锚点。
4. **版式约束**：海报、信息图、UI、设定表、广告图必须写清排版层级。
5. **文本约束**：需要文字时必须写“哪些文字、放在哪里、字体气质、不要大量小字乱码”。
6. **反向风险控制**：用“不要杂乱 / 不要模板化 / 不要错误地标 / 不要小字乱码”等排除模型常见失败。
7. **参考图约束**：图生图时要说明参考图只绑定什么，不绑定什么，例如“脸部参考，服道化可改”。

一句话公式：

```text
任务类型 + 主体锚点 + 画面结构 + 分区/数量 + 光影色彩 + 材质质感 + 文本版式 + 输出比例 + 禁止项
```

## 2. GPT 生图的两种高稳定写法

### 2.1 JSON 结构化写法

适合：复杂 UI、角色设定表、产品页、信息图、多面板广告、漫画页、品牌周边、游戏界面。

优点：层级清楚，模型更容易遵守数量、布局和文字。

推荐骨架：

```json
{
  "type": "图像类型",
  "aspect_ratio": "画幅比例",
  "style": "整体视觉风格",
  "subject": {
    "identity": "主体身份",
    "appearance": "外观锚点",
    "pose_or_action": "姿态/动作"
  },
  "scene": {
    "location": "场景",
    "time": "时间",
    "mood": "情绪"
  },
  "layout": {
    "composition": "整体构图",
    "sections": [
      {
        "title": "分区名称",
        "position": "位置",
        "count": 1,
        "elements": ["元素1", "元素2"]
      }
    ]
  },
  "lighting_color": {
    "lighting": "光线组织",
    "palette": "主色/辅助色/点缀色"
  },
  "text": {
    "language": "文字语言",
    "required_text": ["必须出现的文字"],
    "typography": "字体气质与层级"
  },
  "quality": "清晰度、质感、渲染要求",
  "negative": ["禁止项1", "禁止项2"]
}
```

### 2.2 自然语言设计说明写法

适合：单张插画、电影海报、角色肖像、商品广告、照片风格图、叙事封面。

优点：情绪与审美更顺，适合视觉表达强于版式精确的任务。

推荐顺序：

```text
创作一张[类型/比例]的[主题图像]。
主体是[谁/什么]，具有[3-6个外观锚点]，正在[动作/状态]。
画面采用[构图方式]，前景/中景/背景分别是[空间层级]。
光影为[主光方向/冷暖/对比]，色彩为[主色+点缀色]。
质感为[材质/渲染/摄影或插画语言]。
如果有文字，写明[文字内容/位置/字体/层级]。
输出为[比例/用途/清晰度]。
禁止[常见失败项]。
```

## 3. 七层提示词结构

### 3.1 任务层：先定义“它是什么”

不要只写“帮我画一个好看的图”。必须先定义图像产品类型：

- 电影海报 / 收藏版史诗叙事海报
- 角色设定表 / 三视图 / 表情差分表
- 品牌形象与周边设计项目
- SaaS 落地页 / 游戏 UI 截图 / 信息图
- 漫画页面 / 多格分镜 / 杂志封面
- 商品广告 / 奢侈品海报 / 汽车社媒海报
- 科普百科图 / 玄学分析报告图 / 城市宣传海报

任务层决定模型采用“插画逻辑、摄影逻辑、版式逻辑、UI逻辑还是信息图逻辑”。

### 3.2 主体层：写可识别锚点，不写空泛形容

主体至少包含：

1. 身份：年轻女性艺术家 / 巨型 Boss / 苹果 Vision Pro / 大白鲨。
2. 外观锚点：发型、服饰、材质、颜色、道具、标志性轮廓。
3. 当前状态：站立、跃起、伸手、凝视、战斗、展示、被分析。
4. 读图优先级：观众第一眼先看哪里。

错误：

```text
一个高级感女孩。
```

正确：

```text
一位灰蓝色波浪长发女性，戴浅蓝色边框太阳镜，穿白色短款羽绒服与超大工装裤，在蓝色影棚背景中完成半空跳跃，鞋底和裤腿是视觉重心。
```

### 3.3 结构层：复杂图必须写分区

gpt-image-2 对“分区 + 位置 + 数量”响应较好。复杂图应优先使用：

```text
顶部：标题区
中部：主视觉区
左侧：信息模块
右侧：功能卡片
底部：规格/标语/按钮
```

或：

```json
"sections": [
  {"position":"左上", "type":"角色肖像", "count":1},
  {"position":"右上", "type":"功能卡片", "count":3},
  {"position":"底部", "type":"规格栏", "count":4}
]
```

凡是以下任务，必须写分区：

- 角色设定表
- UI 截图
- 信息图
- 多格漫画
- 品牌周边合集
- 产品功能海报
- 杂志封面
- 关系图 / 时间轴 / 地图类图像

### 3.4 镜头与构图层：静态图也要有镜头语言

样本中高质量图大量使用：

- 极低角度透视
- 后部 3/4 视角
- 中心对称构图
- 竖版电影海报构图
- 巨大侧脸剪影 + 内部世界观填充
- 2x2 网格 / 10x10 网格 / 6 格漫画页
- 强迫透视：手、剑、杯子、产品靠近镜头
- 前景主体 + 中景动作 + 背景威胁

推荐写法：

```text
画面采用低角度强透视，前景剑刃占据画面下方并指向镜头，中景角色身体形成斜向动线，背景魔法阵围绕主体但不抢焦点。
```

### 3.5 光影与色彩层：必须服务情绪与版式

不要只写“电影感光影”。要写：

- 光源方向：侧逆光、左上方 45 度硬光、清晨柔光、工作室棚灯。
- 光质：硬 / 软 / 体积光 / 边缘光 / 高调均匀光。
- 冷暖关系：暖金 vs 电光蓝、深蓝 vs 玫瑰金。
- 色彩规则：主色、辅助色、点缀色、禁止色。

示例：

```text
主光为左上方 45 度单向硬质工作室灯，在每层纸雕之间形成清晰硬边投影；全程哑光纸面，无发光、无光晕、无体积雾。
```

### 3.6 材质与渲染层：让模型知道“表面如何成立”

高质量样本会写清：

- 纸纤维、切割边缘、哑光卡纸
- 丝绸、石材、皮肤、碳纤维、玻璃、金属
- 胶片颗粒、印刷褪色、折痕、污渍
- 赛璐珞阴影、半写实插画、照片级 3D、游戏截图 UI
- 高可读性文本、印刷级锐度、手机端可读

材质层是“高级感”的真正来源。

### 3.7 文本与排版层：GPT 生图可以写字，但要克制

如果需要文字，必须写清：

1. 必须出现的文字。
2. 文字语言。
3. 位置。
4. 字体气质。
5. 层级：主标题 / 副标题 / 标签 / 按钮 / 小字。
6. 避免大量小字乱码。

推荐：

```text
顶部居中放置大标题“Vision Pro”，使用现代粗体无衬线字体；底部右下角小号文字显示“$3,499”；其余说明文字控制在短句，避免大量小字。
```

不推荐：

```text
加很多详细说明文字。
```

## 4. 场景类型公式库

### 4.1 电影海报 / IP 主视觉

公式：

```text
主题/IP + 主视觉人物/物体 + 精神核心构图 + 世界观元素 + 情绪光影 + 标题区 + 禁止拼贴感
```

关键技巧：

- 用“巨大侧脸剪影 / 双重曝光 / 精神核心人物”统领画面。
- 背景元素必须服务主题，不要通用拼贴。
- 标题区必须预留，不要被人物和特效遮挡。

模板：

```text
创作一张竖版电影海报。巨大[主角]侧脸剪影作为画面外轮廓，剪影内部生长出[主题]的标志性场景、角色关系、建筑、道具与象征符号。整体不是拼贴，而是高级双重曝光式叙事合成。光影采用电影级侧逆光与局部暖光，保留体积光、轻雾和景深层次。底部预留标题区，标题清晰可读。不要杂乱，不要模板化背景，不要廉价奇幻素材。
```

### 4.2 角色设定表 / 三视图

公式：

```text
角色身份 + 稳定外观锚点 + 分区布局 + 视角数量 + 表情/道具/色卡 + 白底专业参考表 + 一致性红线
```

关键技巧：

- 必须写“同一角色、同一服装、同一比例”。
- 三视图必须写正面/侧面/背面或 3/4 视角。
- 表情、服装细节、色卡要分区。

模板：

```text
创建一张专业角色设定表，白色背景，清晰分栏。左侧为三视图：正面、侧面、背面，全身，从头到脚，同一角色、同一服装、身高比例对齐。右侧为完整全身立绘。上方或下方加入 5 个表情差分、8 个服装道具细节特写、8 个圆形色卡。文字标签简洁清晰。禁止不同角色混入，禁止三视图服装不一致，禁止身高不齐。
```

### 4.3 UI / 落地页 / 游戏界面

公式：

```text
产品类型 + 屏幕比例 + 页面模块 + 功能卡片数量 + 主视觉 + 文字语言 + UI材质 + 可读性
```

关键技巧：

- 使用 JSON 写 `header / sidebar / center / bottom navigation`。
- 数量要明确：顶部 8 个按钮、左侧 3 个区块、底部 6 个导航。
- 文本要少而清晰。

模板：

```json
{
  "type": "桌面游戏 UI 截图",
  "aspect_ratio": "16:9",
  "style": "高质感动漫视觉小说界面，柔和色调，圆角面板，清晰日文 UI",
  "layout": {
    "top_bar": {"count": 8, "components": ["日期", "时间", "金币", "宝石", "公告", "礼物", "任务", "菜单"]},
    "left_sidebar": {"count": 3, "sections": ["状态", "道具", "主人公头像"]},
    "center": {"components": ["大型对话插画", "角色名牌", "4个选项按钮", "主文本框"]},
    "right_sidebar": {"count": 3, "sections": ["月历", "今日计划", "同伴"]},
    "bottom_navigation": {"count": 6, "labels": ["保存", "读取", "地图", "日程", "状态", "系统"]}
  },
  "quality": "所有主要按钮和文字清晰可读，界面平衡，不拥挤"
}
```

### 4.4 信息图 / 科普百科图

公式：

```text
主题 + 主视觉插图 + 模块清单 + 标注线/图标 + 数据字段 + 可读性 + 手机端清晰
```

关键技巧：

- 信息模块用标题 + 字段，不要让模型自由编太多小字。
- 写“每个模块旁附小图标、圆角信息框、清晰标题层级”。

模板：

```text
生成一张纵向模块化科普信息图，主题为[主题]。中央放置[主体]的清晰自然主义插图，周围排列多个圆角信息模块。模块包括：基本简介、外观特征、习性生态、独特结构、风险与保护、著名种类。每个模块只包含短标签和图标，标题层级清晰，手机上可读。使用现代百科页面风格，浅色背景，柔和阴影，高端自然历史插图质感。禁止小字乱码，禁止信息过密。
```

### 4.5 商品广告 / 奢侈品牌图

公式：

```text
产品 + 放大/超现实展示 + 模特互动 + 品牌色 + 棚拍光影 + 材质细节 + 标语文字
```

关键技巧：

- 产品要有“可见工艺细节”：缝线、金属、玻璃、反射、纹理。
- 模特与产品必须有互动，不只是站旁边。
- 背景克制，突出产品。

模板：

```text
一张高端产品广告海报。[产品]被戏剧性放大，位于画面中心偏右，具有清晰材质细节、边缘高光和真实接触阴影。一位模特自然站在旁边，与产品轻微互动。背景为干净渐变棚拍环境，主色为[品牌色]，光线柔和但高光受控。加入极简标注线突出 3 个产品卖点。底部放置短标语。整体为商业时尚广告质感，禁止比例畸变，禁止文字杂乱。
```

### 4.6 多格漫画 / 分镜页面

公式：

```text
格数 + 网格结构 + 每格位置 + 每格内容 + 分隔线 + 全局色彩 + 对话气泡
```

关键技巧：

- 必须逐格写 `panel 1 / panel 2...`。
- 分隔线必须反复强调“清晰白色留白、硬边框、画格不溢出”。
- 色彩和光源统一。

模板：

```json
{
  "type": "6格漫画页面",
  "aspect_ratio": "2:3竖版",
  "panel_borders": "粗白色分格线，画格之间有清晰留白，每格硬质黑色边框，内容不溢出",
  "layout": {
    "sections": [
      {"panel": 1, "position": "顶部宽幅", "description": "..."},
      {"panel": 2, "position": "中上左", "description": "..."},
      {"panel": 3, "position": "中上右", "description": "..."}
    ]
  },
  "global_notes": "所有画格必须清晰分隔，页面背景为白色，角色外观保持一致"
}
```

### 4.7 品牌周边 / 物料合集

公式：

```text
品牌主题 + 角色/Logo + 周边品类 + 分区位置 + 数量 + 统一色板 + 白底/样机展示
```

关键技巧：

- 写清每个物料的数量：T 恤 1 件、徽章 4 枚、糖果 2 包。
- 周边图最怕乱，必须给位置和层级。

### 4.8 城市/文化宣传海报

公式：

```text
城市/主题 + 独特文化符号 + 地理符号 + 现代发展 + 城市理念 + 主标题 + 禁止通用拼贴
```

关键技巧：

- 先要求模型“提炼独特性”，再生成画面。
- 禁止错误地标、通用旅游拼贴。

模板：

```text
请为【城市名】生成竖版城市宣传海报。不要套用固定模板，要先提炼这座城市最独特的历史文化、自然地理、现代产业和城市理念，再据此组织前景、中景、远景。画面必须一眼识别该城市，包含标志性建筑、地域文化、生活气质和未来愿景。主标题为“【城市名】”，另加一句短宣传语。高端国潮城市宣传海报，写实数字绘景与水墨光影融合。不要通用城市拼贴，不要错误地标，不要廉价旅游广告感。
```

## 5. Prompt as Code：工业级模板与变量系统

两个 GPT-image-2 公开仓库的核心共识是：高质量提示词不是散文，而是可复用的结构化协议。执行顺序必须是：

```text
任务类型 → 结构约束 → 风格材质
```

先定义图像产品是什么，再锁定布局、数量、模块、阅读顺序，最后补充摄影、插画、材质、光影和情绪。禁止一上来堆“高级感、电影感、梦幻、精致”。

### 5.1 变量模板技巧：让提示词可复用

样本文档大量使用：

```text
{argument name="变量名" default="默认值"}
```

也可以使用方括号占位：

```text
[PRODUCT] / [BRAND] / [BRAND REFERENCE] / [ASPECT RATIO] / [LIGHTING COLOR]
```

这说明高价值 GPT 生图提示词应做成“可替换模板”，而不是一次性描述。

适合变量化的字段：

- 角色名 / 发色 / 服装 / 主题色
- 城市名 / 品牌名 / 产品名 / 标语
- 画幅比例 / 风格方向 / 主色调 / 点缀色
- 标题文字 / 社交账号 / 日期
- 主体对象 / 事件名称 / IP 名称

推荐模板：

```text
创作一张{argument name="aspect ratio" default="3:4竖版"}的{argument name="poster type" default="电影海报"}。
主体为{argument name="character" default="银发少女"}，主色调为{argument name="color palette" default="深蓝与玫瑰金"}。
标题文字为“{argument name="title" default="星海遗梦"}”。
```

### 5.2 原子化 Schema

复杂任务优先拆成以下可控字段：

```json
{
  "task_type": "UI / infographic / poster / ecommerce / character / scene / storyboard / publication",
  "output_spec": {
    "aspect_ratio": "16:9 / 1:1 / 3:4 / 9:16 / long scroll",
    "language": "中文 / 英文 / 中英双语",
```

### 5.3 工业模板优先级

- **结构复用优先于风格复用**：同一 UI / 信息图 / 分镜板先复用布局，再替换主题和风格。
- **变量替换优先于重写**：品牌、产品、角色、比例、标题、色板应作为变量替换，避免每次重写导致结构漂移。
- **文字可读性优先于文字数量**：标题、短标签、按钮可写；大量说明文字应转成少量模块标题。
- **多面板先锁格数**：2×2、3×3、4×4、9-panel、18-panel、长卷必须先写清数量、编号、分隔线和阅读顺序。

## 6. 图生图 / 参考图精修规则

### 6.1 先声明参考图绑定范围

图生图时不要让模型猜“参考图哪些必须保留”。必须写：

```text
参考图仅用于保持人物脸部结构、肤色、发型和表情气质；服装、背景、道具和光影可以根据新主题重新设计。
```

或：

```text
参考图必须保持产品外形、Logo、颜色和比例；背景、光影、排版可以重新设计为高端广告海报。
```

### 6.2 精修提示词结构

```text
保留：主体身份、脸部结构、关键服饰/产品轮廓。
修改：背景、光影、构图、材质细节、版式。
增强：清晰度、皮肤/布料/金属/玻璃质感、商业摄影光影。
禁止：改变脸、改变产品比例、增加多余人物、文字乱码、低清晰度。
```

### 6.3 参考图风险

- 如果只说“参考这张图”，模型可能把背景、姿势、服装全部锁死。
- 如果只说“换风格”，模型可能丢脸或丢产品结构。
- 最稳写法是“保留项 / 可变项 / 强化项 / 禁止项”四段式。

## 7. 新资料吸收：风格产品化模板层

`26-04-27` 与 `26-04-28` 两份资料的核心价值不是单个风格词，而是把“风格、产品类型、主体、相机、光影、材质、情绪结果”组织成可复用模板。新增以下方法论层。

### 7.1 自然语言七段式

适合：写实人像、风格插画、3D 微缩、科幻机械、自然风光、氛围场景、城市文化海报等“审美表达强、版式约束弱”的任务。

```text
画面风格 → 核心元素 → 具体内容 → 构图方式 → 相机参数 → 光影色彩 → 氛围结果
```

执行要求：

1. **画面风格**：先声明产品类型与审美体系，例如“写实人像摄影 / 国风数字插画 / 3D微缩模型 / 赛博朋克竞速海报”。
2. **核心元素**：明确画面第一读点，不超过 1 个主主体 + 2 个辅助主体。
3. **具体内容**：补齐动作、服装、道具、环境、材质，不写空泛评价。
4. **构图方式**：写景别、机位、视角、主体位置、前中后景。
5. **相机参数**：摄影类写镜头焦段、景深、快门/运动感、胶片颗粒；插画类改写为透视、线条、渲染方式。
6. **光影色彩**：写主光方向、光质、冷暖关系、主色与点缀色。
7. **氛围结果**：用可视化结果收束，例如“潮湿雨夜霓虹反射”“清晨逆光下的松弛感”“微缩玩具级精密比例”。

### 7.2 人像摄影双段式模板

新资料中写实人像最稳定的写法，是“整体场景段 + 面部特写锚点段”。第一段保证姿态、服饰、场景与氛围；第二段锁脸，降低脸部漂移。

```text
第一段：一张[比例]的写实人像摄影，[景别/机位]，[人物身份/年龄气质]正在[姿态动作]，具有[脸型/身形/发型]，穿着[服装/材质/配饰]，位于[场景/时间/天气]。画面采用[构图]，[镜头焦段/景深/胶片质感]，[主光方向/光质]，[主色调]，整体呈现[情绪结果]。

第二段：面部近距离特写锚点：保持[脸型]、[眉形]、[眼型/瞳孔/睫毛]、[鼻梁]、[唇形]、[肤质肌理]、[妆容]、[表情/眼神]；面部光影为[侧光/逆光/柔光/伦勃朗光]，禁止换脸、过度磨皮、五官比例漂移。
```

人像类必须补齐：

- 机位/景别：全身、半身、近景、面部特写、低机位、平视、俯拍。
- 姿态动作：回头、侧坐、行走、撑伞、倚靠、捧花、凝视、发丝被风吹动。
- 脸部锚点：脸型、眉眼、鼻唇、肤质、妆容、眼神。
- 服装材质：针织、丝绸、皮衣、旗袍、婚纱、校服、礼服、夹克等。
- 场景与光：海边、街头、园林、图书馆、列车、夜景、雨天室内、棚拍、晨光、霓虹、逆光。

### 7.3 产品 / 风格 / 场景三轴归类法

写提示词前先归类，避免把“风格词”当成唯一控制器。

| 轴 | 需要判断 | 示例 |
|---|---|---|
| 产品类型 | 这张图最终像什么产品 | 人像摄影、角色设定、海报、3D手办、微缩模型、场景概念图、广告图、字体设计 |
| 风格类型 | 它使用哪套审美语言 | 法式复古、日系胶片、国风水墨、赛博朋克、吉卜力幻想、硬科幻、潮流街头、治愈童话 |
| 场景类型 | 主体处于什么空间与事件 | 海边婚纱、雨夜街头、校园、园林、都市湖畔、地下树屋、竞速赛道、古建岛屿 |

提示词公式升级为：

```text
产品类型 + 风格类型 + 场景类型 + 主体锚点 + 构图/相机 + 光影色彩 + 材质细节 + 情绪结果 + 禁止项
```

### 7.4 风格与产品模板分类库

#### A. 写实人像摄影

```text
[比例]写实人像摄影，[景别/机位]拍摄[人物身份与气质]，[姿态动作]。人物具有[脸型/发型/眼神/表情]，穿着[服饰材质与颜色]，位于[具体场景]。使用[焦段/景深/胶片或数码质感]，[主光方向/光质]，[主色调+点缀色]。补充面部近距离特写锚点：[眉眼鼻唇肤质妆容]。禁止换脸、塑料皮肤、过度磨皮、肢体畸变。
```

可调用风格：法式复古温柔、都市轻熟知性、度假松弛、街头酷飒、甜辣元气、日系胶片、国风旗袍、西域公主、夜景氛围、市井治愈。

#### B. 国风插画 / 新中式视觉

```text
[比例]国风数字插画 / 新中式海报，主体为[人物/建筑/神像/城市符号]，融合[水墨/青铜/纸雕/剪纸/山水/古建]元素。构图采用[中心对称/留白/层叠山水/窗棂框景]，前中后景分别为[层级]。色彩为[主色]配[点缀色]，材质强调[宣纸、金箔、青铜、木纹、石材]。禁止廉价古风拼贴、错误文化符号、元素堆满。
```

#### C. 3D 手办 / 潮玩角色

```text
[比例]高品质3D手办渲染，主体是[Q版/潮玩/神像/角色]，具有[夸张比例、表情、服装、道具]。展示方式为[收藏级摆件/透明底座/桌面摄影/产品白底]，材质包含[树脂、搪胶、磨砂塑料、金属小件]。使用柔和棚拍光、真实接触阴影、干净背景。禁止廉价塑料感、比例失控、五官糊、底座穿模。
```

#### D. 3D 微缩模型 / 微观世界

```text
[比例]3D微缩模型场景，[主体空间]被做成精密微缩景观，包含[建筑/路径/人物/植物/水体/灯光]。构图采用[剖面/俯视45度/等距视角/垂直分层]，每一层都有可读功能。材质为[木材、石材、苔藓、纸雕、树脂、水面]，光影呈现玩具摄影级真实阴影。禁止尺度混乱、细节糊成一团、空间层级不可读。
```

适配：地下树屋、四合院微缩、中式古建岛、热带丛林岛、葫芦屋、心形山石岛、微观草丛骑士。

#### E. 科幻机械 / 赛博竞速

```text
[比例]硬科幻 / 赛博朋克视觉图，主体为[机甲/反应堆/超跑/机器人/未来城市]，具有[机械结构、发光部件、材质锚点]。场景为[雨夜街头/核聚变核心/云端山城/高速赛道]，构图采用[低机位广角/强透视/中心轴线/动感斜线]。光影为霓虹冷暖对撞、金属反射、雨水倒影或高能核心光。禁止机械结构糊、光污染遮挡主体、速度感只靠模糊。
```

#### F. 自然风光 / 微距生态

```text
[比例]自然摄影 / 微距生态图，主体为[海浪/昆虫/森林/草丛/山石]，以[微距/长焦/低机位/航拍感]呈现。画面明确前景纹理、中景主体、远景环境，光线为[清晨柔光/逆光/雨后散射光]，强调[水珠、雾气、叶脉、浪花、苔藓]。禁止风景空泛、主体不明确、过度锐化。
```

#### G. 字体海报 / 城市文化 / 节气视觉

```text
[比例]字体主视觉海报，核心文字为“[文字]”，文字必须清晰可读，占据[位置与比例]。字体与[城市/节气/文化主题]融合，笔画内部或周围加入[地域符号/节气物候/建筑/植物/纸雕层次]。色彩为[主色]，版式留白克制。禁止文字乱码、笔画不可读、符号堆砌、旅游模板感。
```

#### H. UI / 信息图 / 出版物工业模板

```text
[比例]的[UI/信息图/出版物]设计，任务类型为[App界面/游戏HUD/科普信息图/报告封面/杂志跨页]。版式采用[三栏/卡片式/时间线/仪表盘/长卷]，包含[模块数量]个清晰模块：标题区、主视觉区、数据区、标签区、注释区。所有文字使用[语言]，只保留短标题、按钮、标签和关键数字，字体层级清楚，手机端可读。风格为[科技/极简/国风/商业白皮书/游戏界面]，禁止小字乱码、模块拥挤、按钮错位、信息层级混乱。
```

#### I. 静态分镜板 / 动作分解参考表

```text
生成一张[角色/场景/剧情段落]的静态分镜板 / 动作分解参考表。风格为[黑白线稿/漫画分镜/灰阶3D/彩色动画设定]，背景干净，技术参考图气质。版式采用[4×4网格/3×3九宫格/横向9-panel/长卷叙事]，每格等尺寸，细线分隔，左上角编号。所有面板保持同一角色、同一服装、同一比例、同一场景光源。每格包含：动作标题、完整身体姿态或镜头画面、3-4行短说明、方向箭头或运动轨迹线。动作序列按[起势→推进→爆点→结果]排列。禁止复杂背景、角色换脸、服装漂移、面板溢出、阅读顺序混乱。
```

#### J. 品牌 / 电商 / 物料合集


### 7.5 模板选择规则

- 用户要“头像/写真/人物照” → 优先人像双段式。
- 用户要“角色资产/定妆/三视图” → 优先角色设定表公式，不用写真模板替代。
- 用户要“角色卡/卡牌合集/多姿势参考” → 优先角色参考卡或动作分解参考表模板。
- 用户要“分镜图/动作表/故事板/多格剧情” → 优先静态分镜板模板，先锁格数、编号、阅读顺序和角色一致性。
- 用户要“UI/界面/信息图/出版物” → 优先 Prompt-as-Code Schema，先锁模块、层级、文字可读性。
- 用户要“电商/品牌/Logo/物料合集” → 优先品牌电商模板，先锁产品结构、Logo、卖点和物料数量。
- 用户要“可爱角色/摆件/神像/Q版” → 优先 3D 手办模板。
- 用户要“树屋/古建/岛屿/剖面空间” → 优先 3D 微缩模型模板。
- 用户要“城市/节气/文字/活动图” → 优先字体海报/城市文化模板。
- 用户要“机甲/反应堆/超跑/雨夜霓虹” → 优先科幻机械/赛博竞速模板。
- 用户要“海浪/昆虫/森林/生态” → 优先自然风光/微距生态模板。

## 8. 负面提示词方法

GPT 生图负面提示词不宜只堆“low quality, bad anatomy”。更有效的是按任务失败风险写。

### 7.1 通用禁止项

```text
不要水印，不要乱码文字，不要多余手指，不要比例畸变，不要主体偏离画面，不要背景杂乱，不要低清晰度，不要廉价模板感。
```

### 7.2 海报类禁止项

```text
不要硬拼贴，不要通用背景，不要标题区被遮挡，不要大量小字，不要廉价奇幻素材，不要视觉焦点分散。
```

### 7.3 UI/信息图禁止项

```text
不要小字乱码，不要模块拥挤，不要按钮错位，不要图标混乱，不要错误层级，不要不可读文本。
```

### 7.4 角色设定表禁止项

```text
不要不同角色混入，不要三视图服装不一致，不要身高不齐，不要视角错误，不要遮挡关键服饰细节。
```

### 7.5 商品广告禁止项

```text
不要产品比例错误，不要Logo变形，不要材质塑料感，不要模特抢走产品焦点，不要过度复杂背景。
```

## 8. GPT 生图自检门禁

每条 GPT 生图提示词输出前必须检查：

- [ ] 是否明确图像类型？
- [ ] 是否明确画幅比例与用途？
- [ ] 是否有主体外观锚点？
- [ ] 是否写清构图或版式？
- [ ] 复杂图是否写了分区、数量、位置？
- [ ] 是否明确光影与色彩规则？
- [ ] 是否写了材质/渲染/清晰度要求？
- [ ] 需要文字时，是否写了文字内容、位置、字体气质与可读性？
- [ ] 参考图任务是否写清保留项和可变项？
- [ ] 是否有针对性禁止项，而不是泛泛负面词？
- [ ] 工业模板是否遵守“任务类型 → 结构约束 → 风格材质”？
- [ ] 多面板 / 分镜板 / 动作表是否写清格数、编号、边框、阅读顺序和每格任务？
- [ ] UI / 信息图 / 电商 / 品牌图是否先锁模块、层级、文字可读性和数量约束？
- [ ] 角色系列资产是否锁定同一脸型、服装、比例、发型、道具和色板？

## 9. 项目推荐工作流

### 9.1 普通文生图

```text
需求一句话 → 判断图像类型 → 选场景公式 → 写结构化提示词 → 加负面项 → 生成 → 记录成功关键词
```

```text

```

### 9.3 角色资产图

```text
角色设定 → 三视图/表情/服装细节/色卡 → 一致性红线 → 生成 → 入资产库
```

```text
参考图分析 → 保留项/可变项/增强项/禁止项 → 精修生成 → 对比确认 → 保存到图库/资产库
```

## 12. 核心结论

gpt-image-2 的强项不是简单“画得漂亮”，而是能执行复杂的视觉设计任务。提示词越像一份专业设计 brief，结果越稳定。

最佳策略：

1. **先定类型**：海报、UI、设定表、信息图、广告、漫画页。
2. **再定结构**：分区、位置、数量、层级。
3. **再定主体**：外观锚点、动作状态、读图焦点。
4. **再定审美**：光影、色彩、材质、风格。
5. **最后定风险**：禁止项、文字可读性、比例一致性、参考图绑定范围。

不要把 GPT 生图提示词写成“灵感形容词集合”，要写成“视觉导演 + 美术设计 + 平面设计 + 摄影指导”的合并执行单。
