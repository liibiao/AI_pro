# Long Prompt Detail Gate — 长版提示词详细度质检门禁

> 用途：在产出 Seedance / 即梦 / 叙事版长版提示词，以及进入图片、视频生成之前，对提示词完整性和可执行性做硬性检查。不符合即打回重写。

## 1. 适用范围

- Seedance 长版母稿
- 即梦 / 图生视频长版母稿
- 叙事版视频提示词
- 由长版派生的简版投喂稿
- 进入图片、视频生成前的最终提示词

## 2. 固定接口完整性

Seedance 长版母稿必须保留以下接口，任何一个缺失都打回：

```text
画面主体【完整：...】
@Image ...
逐条时间轴
环境联动：
光线：
对白配音：
音效设计：
画质：
负面提示词：
```

无对白段必须写明：`本段无对白配音`。

## 3. 长版详细度必写项

用户给出的这类结构：`画面主体【完整】 + @Image + 0s-15s 时间轴 + 环境联动 / 光线 / 对白配音 / 音效设计 / 画质 / 负面提示词`，即使已经按 1-2 秒颗粒度写满，也只作为本项目的**简版投喂稿标准**。长版母稿必须在此基础上进一步扩写，不能把该篇幅直接当长版交付。

长版必须明显高于简版：更完整的主体关系、位置关系、动作因果、镜头起幅落幅、微动作链、声音空间、环境物理反馈、光线来源与变化、画质读点和负面风险约束都要展开。

输出前必须检查以下字段是否写细：

- 主体：身份、外观、第一读点、关系、强弱状态。
- 动作：起势、推进、命中 / 反应、结果收束。
- 景别：远景 / 全景 / 中景 / 近景 / 特写等必须对应信息任务。
- 镜头：机位、视角、运镜、起幅、落幅必须绑定动作节点。
- 帧率：24fps / 升格 / 降格必须说明服务哪个动作细节。
- 站位：左右、前后、远近、朝向、距离、谁压迫谁。
- 画质：材质、皮肤 / 衣料 / 金属 / 烟尘 / 水花 / 碎片等可见细节。
- 音效：底噪、近景拟音、材质声、特效声、状态声。
- 环境联动：场景元素如何随动作变化。
- 光线：光源方向、颜色、强弱、主体受光和环境反弹。
- 负面提示词：身份、站位、动作连续性、关键物件、结果帧和声音 / 特效风险。

## 4. 时间轴格式

每条时间轴必须采用：

```text
0.0s（24fps / 景别 / 机位或运镜）：主体动作 + 微动作或受力反馈 + 环境反应——【音效：...】。
```

禁止只写镜头参数，不写动作；也禁止只写动作，不写镜头、帧率和音效。

## 5. 镜头动作融合红线

- 景别、运镜、帧率变化必须绑定具体动作节点。
- 不能单独列“镜头很有电影感”“快速运镜”“升格慢动作”。
- 强对抗段必须写清对抗关系、受力方向、重心变化、命中反馈和结果帧。
- 文戏段必须写清微表情、呼吸、视线、手部细节和声音层次。

## 6. 打回规则

命中任一情况，直接判定为不通过：

- 固定接口缺失。
- 标题写 5s / 10s / 15s，但时间轴未真实铺满。
- `@Image` 没有资产锚点或站位关系。
- 主体、动作、景别、镜头、帧率、画质、音效、站位任一字段泛写。
- 运镜、景别、帧率没有绑定动作节点。
- 强对抗没有受力反馈和结果帧。
- 文戏只有情绪形容，没有微动作和声音层次。
- 环境联动、光线、画质、负面提示词是套话，没有针对本段风险。
- 长版未通过却继续派生简版或进入生成。

## 7. 放行标准

只有当提示词同时满足以下条件，才允许进入图片或视频生成：

- 接口完整。
- 时间轴完整铺满。
- 动作链连续。
- 站位和朝向清晰。
- 镜头、景别、帧率与动作绑定。
- 环境、光线、音效、画质均服务第一读点。
- 负面提示词针对本段核心风险。
