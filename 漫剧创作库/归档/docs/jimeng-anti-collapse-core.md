# 即梦 2.0 防崩核心规范

> 来源：基于用户提供的抖音图文教学内容提炼。  
> 适用：即梦 2.0 图生视频、人物短视频、文戏表演、轻动作、口播、分段拼接、首尾帧连续生成。  
> 核心定位：本规范不是风格词库，而是“稳定性参数 + 分段动作 + 连续性控制”的防崩执行层，用于降低崩脸、变脸、歪眼、手指穿模、背景闪烁、明暗跳变与片段拼接错位。

---

## 1. 总原则：先稳人物，再做动作

即梦人物视频最容易崩坏的根因通常不是“提示词不够华丽”，而是：

1. 参考强度不固定。
2. 种子值随机。
3. 人物描述前后漂移。
4. 单段时间过长导致误差累积。
5. 动作没有按关节和时间拆解。
6. 首尾帧、光线、比例、速度不连续。

防崩优先级：

```text
锁脸一致性 > 分段时长 > 动作关节拆解 > 首尾帧对齐 > 光线比例参数固定 > 风格强化
```

## 2. 十条防崩核心规则

### 2.1 锁脸三件套

用于解决：崩脸、变脸、五官漂移、角色不一致。

必须同时满足：

1. 参考强度固定为 `75`。
2. 种子值全程固定，复用底图种子号。
3. 底图人物描述词一字不改。

标准流程：

1. 先生成半身正面底图。
2. 复制底图种子号。
3. 后续所有片段参考强度设为 `75`，填入同一 seed。
4. 提示词只允许修改动作、表情微变化和背景事件；人物年龄、脸型、发型、服装、主光方向必须保持一致。

底图示例：

```text
25岁女生，鹅蛋脸，黑长发，白T恤，半身正面，左侧光，8k
```

### 2.2 动作拆成每秒步骤

用于解决：动作崩坏、手脚穿模、关节乱转。

错误：

```text
她抬手。
```

正确：

```text
0到0.3秒肩关节上抬15度，0.3到0.6秒肘关节弯曲30度，0.6到0.8秒腕关节保持伸直，到位后惯性回弹2度。
```

常用稳定写法：

- 抬手：肩关节 → 肘关节 → 腕关节 → 到位回弹。
- 转头：颈椎小角度起转 → 转至目标角度 → 停留 → 回正。
- 走路：手臂与迈腿相位差 `180度`，避免同手同脚。
- 拿物：眼神先落到物体 → 肩肘带动手掌靠近 → 手指闭合 → 物体离开桌面。
- 坐下：膝关节弯曲 → 重心下降 → 臀部接触椅面 → 上身微调稳定。

### 2.3 反向提示词固定栏

用于解决：畸形、穿模、歪眼、坏手、乱码和多肢体。

即梦反向提示词栏默认加入：

```text
畸形手指, 多余手指, 坏手, 错误解剖, 丑陋, 模糊, 水印, 文字, 额外肢体, 不对称眼睛, 扭曲面部, 双重下巴
```

> 项目规范提醒：若平台对“反向词”执行不稳定，可在正向提示词中改写为“保持五指数量正确、双眼对称、面部结构稳定、无额外肢体、画面清晰干净”。

### 2.4 单段时长不超过 3 秒

用于解决：长视频误差累积、人物越动越崩。

执行规则：

- 单段生成建议 `2-3秒`。
- 复杂动作单段不超过 `3秒`。
- 15 秒视频拆成 5 段左右。

拆分示例：

```text
0-2秒推门，2-5秒走进来，5-8秒坐下，8-11秒拿杯子，11-14秒喝一口。
```

### 2.5 首尾帧对齐

用于解决：片段拼接错位、人物位置跳变。

执行流程：

1. 第一段生成后截取最后一帧。
2. 第二段上传上一段尾帧作为参考图。
3. 参考强度设为 `75`。
4. 提示词加入：`首帧与上一段尾帧一致`。
5. 后续片段重复执行。

### 2.6 叠化转场 0.2 秒

用于解决：硬切暴露轻微帧位移。

剪辑建议：

```text
所有分段视频之间添加 0.2 秒叠化转场。
```

0.2 秒用于掩盖轻微跳帧，不应拖慢节奏；动作命中点、台词重音、表情爆点不建议放在叠化交界处。

### 2.7 固定光线方向

用于解决：明暗跳变、脸部阴影漂移。

执行规则：

- 底图如果使用左侧光，所有片段都必须使用左侧光。
- 可进一步写成：`左侧45度光，色温5500K，阴影边缘0.5厘米`。
- 禁止同一角色连续片段中随意切换逆光、顶光、右侧光。

### 2.8 运动速度设为 6

用于解决：抽帧、卡顿、慢动作拖沓。

执行规则：

- 运动速度固定为 `6`。
- 单动作不低于 `1秒`。
- 推进动作约 `2秒`。
- 抬手约 `1秒`。
- 走路约 `1.5秒`。
- 低于 `1秒`容易抽帧，高于 `3秒`容易慢动作化。

### 2.9 采样步数 40 + 清晰度增强

用于解决：画面模糊、皮肤和头发细节不足。

执行规则：

```text
采样步数40，清晰度增强开。
```

适合用于人物脸部、头发丝、衣服褶皱、手部边缘和小道具细节。

### 2.10 固定底图分辨率

用于解决：画面拉伸、脸部比例变形。

执行规则：

- 竖屏：底图使用 `1080×1920`，视频同为 `9:16`。
- 横屏：底图与视频必须使用同一横屏比例。
- 禁止用方图做竖屏视频底图。

## 3. 动作戏防崩写法

动作戏不直接写“打斗、奔跑、转身、抬手”，必须拆为：

```text
时间段 + 关节/重心变化 + 受力方向 + 接触点 + 结果帧
```

动作戏稳定模板：

```text
参考强度75，种子值[seed]。[角色固定描述一字不改]。[固定光线]。采样步数40，清晰度增强开，运动速度6。
动作：[0-0.5秒起势动作与重心方向]，[0.5-1.2秒主要关节变化]，[1.2-2.0秒接触/受力/停顿]，[2.0-2.5秒结果帧稳定]。
首尾帧要求：[首帧与上一段尾帧一致 / 结尾保持姿态稳定0.3秒]。
反向词：畸形手指, 多余手指, 坏手, 错误解剖, 丑陋, 模糊, 水印, 文字, 额外肢体, 不对称眼睛, 扭曲面部, 双重下巴。
```

动作戏特别规则：

- 每段只做一个核心动作单元。
- 命中点必须留清晰结果帧。
- 手部接触物体时，先写手掌路径，再写手指闭合。
- 追逐和走路必须写左右脚相位和手臂摆动相位。
- 强打击仍遵守项目动作方法论的“蓄力 → 骤静 → Hit Stop → 爆裂释放 → 结果兑现”，但单段生成时只承载其中 1-2 个阶段。

## 4. 文戏防崩写法

文戏最容易崩的是脸、眼睛、嘴型和微表情。文戏不追求大动作，优先保证脸部稳定。

文戏稳定模板：

```text
参考强度75，种子值[seed]。[角色固定描述一字不改]。[固定光线]。采样步数40，清晰度增强开，运动速度6。
表演：[0-0.5秒保持正面/三分之二侧脸，眼神看向目标]，[0.5-1.2秒眉头轻微收紧/眼眶发红/嘴唇微颤]，[1.2-2.2秒完成一句台词口型或一次无声反应]，[2.2-2.8秒表情停留，面部结构保持稳定]。
口型：只匹配当前一句短台词，不夸张张嘴，不大幅转头。
首尾帧要求：结尾保持表情稳定0.3秒，便于下一段对齐。
反向词：畸形手指, 多余手指, 坏手, 错误解剖, 丑陋, 模糊, 水印, 文字, 额外肢体, 不对称眼睛, 扭曲面部, 双重下巴。
```

文戏特别规则：

- 一段只承载一句短台词或一个情绪变化。
- 避免同段同时“转头 + 走路 + 哭 + 说长台词”。
- 眼神方向必须固定：看向对手 / 看向地面 / 看向镜头，不能来回乱跳。
- 口型变化要轻，不要写“大喊大叫式夸张张嘴”，除非剧情必须。
- 微表情用眉眼、嘴唇、呼吸和停顿表达，少用大幅肢体。

## 5. 完整防崩提示词模板

```text
参考强度75，种子值123456。25岁女生，鹅蛋脸，黑长发，白T恤，半身正面。左侧45度光，色温5500K，阴影边缘0.5厘米。底图比例1080×1920，生成视频比例9:16。采样步数40，清晰度增强开。运动速度6。
动作：0到0.3秒右肩关节上抬15度，0.3到0.6秒右肘关节弯曲30度，0.6到0.9秒右腕保持伸直，0.9到1.2秒手掌停在肩膀高度，到位后惯性回弹2度。结尾保持姿态稳定0.3秒。
连续性：首帧与上一段尾帧一致，人物位置、脸型、发型、服装、光线方向保持不变。
反向词：畸形手指, 多余手指, 坏手, 错误解剖, 丑陋, 模糊, 水印, 文字, 额外肢体, 不对称眼睛, 扭曲面部, 双重下巴。
```

## 6. 完整创作流程

1. 生成半身正面底图，固定人物描述、光线、比例。
2. 复制底图 seed。
3. 把完整动作拆成多个 2-3 秒分镜。
4. 第一段使用完整防崩模板生成。
5. 截取第一段最后一帧。
6. 第二段上传上一段尾帧，参考强度 `75`，加入 `首帧与上一段尾帧一致`。
7. 重复生成后续片段。
8. 剪辑时每段裁到脚本时长。
9. 片段之间添加 `0.2秒叠化`。
10. 检查脸、眼、手、光线、背景、比例、首尾帧是否连续。

## 7. 防崩自检清单

- [ ] 参考强度是否固定为 `75`？
- [ ] seed 是否全程固定？
- [ ] 人物年龄、脸型、发型、服装、光线描述是否一字不改？
- [ ] 单段时长是否控制在 `2-3秒`？
- [ ] 动作是否拆成时间段、关节角度、重心变化和结果帧？
- [ ] 文戏是否只承载一句短台词或一个微表情变化？
- [ ] 首帧是否对齐上一段尾帧？
- [ ] 光线方向、色温、底图比例是否固定？
- [ ] 运动速度是否为 `6`？
- [ ] 采样步数是否为 `40`，清晰度增强是否开启？
- [ ] 反向提示词是否已加入？
- [ ] 剪辑拼接是否使用 `0.2秒叠化`？

## 8. 与项目既有规范的关系

- 本文档补充即梦 2.0 稳定性执行层，不替代 `docs/storyboard-methodology.md`、`docs/action-methodology.md`、`docs/drama-tension-design-standard.md`。
- 动作设计仍以项目动作方法论为主，但进入即梦执行时必须套用本文档的分段、seed、参考强度、速度、首尾帧规则。
- 文戏设计仍以戏剧张力和对白配音规范为主，但进入即梦执行时必须套用本文档的锁脸、微表情、口型轻量化和短句分段规则。
