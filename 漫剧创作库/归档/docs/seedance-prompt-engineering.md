# seedance-prompt-engineering.md — Seedance 2.0 提示词工程

## 用途
把 Seedance 2.0 的提示词写作、时长策略、视频类型模板、变量系统与上游大模型编排方法沉淀为统一工程规范，支持从"手写 prompt"升级到"模板化生成 prompt"。

## 核心思想
- Prompt 不只是描述画面，而是调度素材、镜头、声音与节奏的工程脚本。
- 要先按视频时长和视频类型决定镜头密度，再填入角色、动作、场景、运镜和衔接方式。
- 上游大模型负责编排提示词，下游 Seedance 2.0 负责执行生成。
- 站位/轴线/几何/读点/群戏调度属于"导演门禁"层，必须工程化写进每个 Shot（详见：docs/blocking-camera-geometry-methodology.md）。

## 一键闭环（推荐）

在项目目录下执行一条命令完成：Phase1-3 前置检查（故事/导演/资产）→（可选）资产生产→ fullref 校验 → 生成三版提示词（即梦/字段/叙事）→ 协议校验：

```bash
python3 tools/project_pipeline_run.py --project-dir projects/无限强化_漫剧_001 --force --style 纪实克制
python3 tools/project_pipeline_run.py --project-dir projects/无限强化_漫剧_001 --ep 002 --force --style 新黑色
```

## 时长策略
### 5 秒
- 目标：抓眼球、打高光、做短展示、小片段爆点
- 原则：1 个核心亮点，不冗余
- 镜头策略：
  - 漫剧 / 微短剧：2-3 镜头
  - 电商 / TVC：1 镜到底或 2-3 镜头
  - 科普：2-3 镜头快速传递知识点

### 10 秒
- 目标：简单情节、轻剧情、卖点递进
- 原则：有小层次、有逻辑推进
- 镜头策略：
  - 漫剧 / 微短剧：4-6 镜头
  - 电商：3-4 镜头
  - TVC：2-4 镜头或一镜到底

### 15 秒
- 目标：完整小情节、全维展示、迷你 TVC
- 原则：情节 / 卖点 / 情绪完整，镜头衔接自然
- 镜头策略：
  - 漫剧 / 微短剧：6-10 镜头
  - 电商：4-6 镜头
  - TVC：3-5 镜头或一镜到底

## 视频类型适配策略
### 漫剧
- 多镜头、快节奏、强调人物和高光动作
- 适合：表情特写 + 动作镜头 + 场景呼应镜头

### 微短剧
- 多镜头、情绪递进、钩子明确
- 适合：状态建立 → 关系变化 → 情绪爆点 → 钩子定格

### 电商产品展示
- 镜头数按卖点数量走
- 核心：整体外观 + 材质细节 + 功能卖点 + 场景应用

### TVC 广告
- 可一镜到底，也可少量镜头高密度表达
- 核心：品牌调性统一、镜头高级、记忆点明确

### 科普短片
- 镜头服务知识点，不炫技
- 核心：看懂比好看更重要

## 提示词工程结构
### 必备五部分
1. 素材指定
2. 画面 / 动作 / 运镜描述
3. 分镜衔接方式
4. 音效 / 配乐 / 配音（配音建议单独成段书写：音色/语速/情绪/停顿/气口）
5. 风格 / 光线 / 细节要求

## 双轨输出工程（长版母稿 / 简版投喂稿）

> 统一方法论见：`docs/dual-format-prompt-methodology.md`

### 0. Seedance 母格式结论（强制）
经项目实际验证，`seedance` 效果最佳的不是字段块优先格式，而是以下导演长版样本格式：

```markdown
【片段标题：0s - 15s】

画面主体【完整：该段全部任务】
@Image@林天 / @林家练武场 / @灵纹碑石——空间关系——第一听感

0.0s（帧率 / 机位 / 运镜）：动作——结果——【音效】
...

环境联动
...

光线
...

对白配音
...

音效设计
...

画质
...

负面提示词
...
```

从本次起：
- **Seedance 长版母稿必须完全按这套结构生成**
- 六个固定段名 `环境联动 / 光线 / 对白配音 / 音效设计 / 画质 / 负面提示词` 必须写进每一个版本，不能只放在外层说明里
- `对白配音` 只负责人声层，`音效设计` 负责环境音 / 拟音 / 特效音 / 状态音，`BGM` 默认不进入主提示词固定段名
- 写法上直接从 `环境联动` 开始，不需要额外写“辅助段落”总标题
- 字段版、叙事版、即梦版都只能从这套母稿转写或压缩

### 1. 长版母稿
适用：导演定稿、全能参考 15 秒、复杂打戏、跨平台派生。

最低要求：
- 从 `0s` 开始计时
- 时间真实铺满 5s / 10s / 15s
- 必须包含：`画面主体`、`@Image 起手`、逐条时间轴、`环境联动 / 光线 / 对白配音 / 音效设计 / 画质 / 负面提示词`
- 作为即梦版 / Seedance 字段版 / Seedance 叙事版的唯一真实源

### 2. 简版投喂稿
适用：平台长度受限、快速实验、A/B 测试。

压缩原则：
- 只删解释层，不删动作骨架
- 保留起势镜头、关键动作链、关键结果镜头、速度反差、稳定约束
- **仍然必须保留六个固定段名**，只允许缩短，不允许删掉
- 一旦简版导致动作逻辑、结果镜头或速度链路失真，必须回退长版或半长版

### 3. 全版本构图补强最小增量规则
- **适用范围**：`长版 / 简版 / 即梦版 / Seedance版 / 叙事版` 全部适用。
- **补强定义**：构图补强只是在原结构上补稳定器，不是重写镜头结构，不是新增独立构图任务。
- **补强目标**：锁定主体关系、层次关系、结果帧关系，减少主体漂移、层次混乱、高潮读图失败。
- **不得改变**：原动作链、原镜头节拍、原空间推进、原高潮钩子。

#### 允许补的内容
- **主体锚点**：主角位置、主威胁方向、核心对峙关系。
- **层次锚点**：前景 / 中景 / 后景、天地双线、包围层级、首看点层次。
- **结果帧锚点**：命中帧、高潮帧、钩子帧必须读到哪些主体与关系。

#### 禁止补坏的方式
- 禁止把构图补强写成新的主任务，压过动作任务。
- 禁止为了“更高级画面”改站位、改节拍、改调度。
- 禁止过度对称、过度几何、过度静态化，导致群戏和打戏僵掉。
- 禁止每条时间轴重复堆相同构图词，造成信息抢权。

#### 各版本执行密度
- **长版**：可写完整三层锚点，但必须继续绑定动作与镜头用途。
- **简版**：只保留最关键的 `主体锚点 + 结果帧锚点`。
- **即梦版**：用最短表达锁住主主体、主包围、主结果，不把构图写成新的说明书。
- **Seedance版**：可写得最细，但不能独立出“镜头与构图”板块。
- **叙事版**：把构图锚点融入口述句，读起来顺，但不能把关键关系讲丢。

### 4. 平台派生规则
- **即梦版**：更短、更硬、更像投喂指令。保留同样的 `画面主体 / @Image / 时间轴 / 六个固定段名` 结构，但要主动压缩成更少条时间轴、更直接的动词链、更少解释句；重点服务“一次投喂就抓到主动作骨架”。
- **Seedance 版**：唯一正式母稿。必须保留最完整的动作—镜头—音效耦合、最清晰的空间关系、最细的节拍切换，是审稿、回改、正式生成的第一版本。
- **叙事版**：导演讲戏式转写。结构不变，但正文允许把多个紧邻动作组织成更顺的口述句，保留节拍节点和六个固定段名，同时减少过于工程化的字段感。
- **禁止事项**：三平台不能只换标题或做极轻微措辞替换；如果读起来像同一份稿子的复述，视为派生失败。
- 所有独立片段必须写成 `0s - 5s` / `0s - 10s` / `0s - 15s`
- 严禁把整集总时间轴直接复制进单段提示词
- 标题时长与正文时间轴必须一致

### 5. 长版到简版的工程顺序
1. 先写长版母稿
2. 标记不得删除的信息（结果镜头 / 关系镜头 / 爆点镜头 / 稳定约束 / 六个固定段名）
3. 再压缩成简版
4. 再派生为即梦 / Seedance 字段 / 叙事版

## @素材协议
- `@素材1`：首帧 / 主体参考
- `@素材2`：运镜 / 动作 / 表情 / 特效参考
- `@素材3`：音频 / 配乐 / 音色参考
- 多素材时必须写清各自负责内容，避免冲突

## 项目 @引用标签（强制对齐资产库）

- `ep*-fullref-15s.md` 中的 `@引用标签` 必须能在项目资产库中落地到真实文件路径。
- 唯一真实源：`03-assets/asset-index.md` 的"Seedance @引用标签映射（落盘路径）"表。
- 分格脚本/分镜表中的 `@引用` 字段必须使用这些标签（例如 `@林天`, `@林家练武场`, `@灵纹碑石`），以便自动化生成全能参考提示词时能精准匹配资产。
- 上游资产生成 Prompt 文件名可能带 `人物设计图-`/`场景氛围图-`/`道具设计图-` 前缀，但 Seedance 投喂只看落盘资产路径与 `@引用标签` 映射，输出图片统一用"直观资产名"命名（如 `林天觉醒前-v8-1.png`）。

## 打戏控场法（Omni-Reference 适用）

> 定位：这是对"提示词结构与资产引用方式"的优化补丁，用于提升可控性与清晰度；不替代项目既定方法论与规范。
> 强制前提：仍必须遵循本仓库的动作/文戏/运镜心理/转场蒙太奇/视听美学/角色视觉弧光等规范，并落实到每个 Shot 的可执行落点。
> 目标：解决"静态图绝美，一动人物融化/动作无逻辑/画面糊"的典型问题，把大模型从"写小作文"拉回到"时间轴微操"。

### 绝招 1：角色死锁（On-model）

- 原则：不要用文字重复描述长相，把角色图当变量注入。
- 写法：把角色参考明确标成"角色 A / 角色 B"，并在每个打斗镜头持续引用。
- 例：在 `【参考】` 中只写 `@林天, @林傲天` 这类"直观资产名"，并用"素材上传顺序表"把它们与 Seedance 的 Image 槽位对齐（提示词正文不写 @ImageN，避免可读性崩坏）。
- 与本项目规范的衔接：等价于"角色视觉弧光与版本一致性门禁"，用图锁住脸/服装/战损阶段，不让文本抢权。

### 绝招 2：物理环境限制（背景动、人物武器必须清）

- 全局魔法指令（推荐写在提示词开头）：
  - `motion blur on BACKGROUND ONLY (characters and weapons stay crisp), sharp shadows`
- 目的：允许背景出现速度线与模糊，但强制角色与武器边缘锐利，解决打戏一快就糊。
- 与本项目规范的衔接：等价于"清晰帧保护 + 物理受力落点可读"。

### 绝招 3：时间轴微雕（导演级运镜 + 镜头动作融合）

- 原则：不要写"史诗级激烈战斗"，改用 `[时间戳]` 把长镜头拆成可执行的动作链与机位。
- **核心红线：镜头动作融合**——每个时间戳必须紧跟一个具体动作，帧率/运镜必须与动作绑定，不能独立列出镜头板块。（详见 `docs/prompt-standards.md`「镜头动作融合原则」）
- 写法建议（每个 3-4 秒 Shot 内可再拆 2-4 个子节拍）：
  - `[0.0-0.8s]` 全景定场：两人相距 8–10m，低视角，剪影清晰。
  - `[0.8-1.6s]` 起手式：角色A slash，角色B sidestep，机位 snap-pan。
  - `[1.6-2.4s]` 物理交互：Parry → bind → shove-off，给 sparks / splash 等真实反馈。
- 与本项目规范的衔接：等价于"节拍密度（每 2.5 秒 ≤ 1 关键节拍）+ 对抗关系/受力/结果兑现"。

### 克制原则（必须写进提示词）

- 高级画面永远是克制的：拒绝廉价高饱和与无脑大动作。
- 只靠具体动作张力、真实物理反馈与精准机位控制逼模型老实输出。

## 镜头衔接规则
- 每个镜头之间必须明确衔接方式
- 常用：闪切、叠化、硬切、模糊过渡、旋转过渡、缩放过渡、擦除过渡、淡入淡出
- 相邻镜头尽量保持景别差与信息差
- 衔接困难时，增加过渡特写镜头或首尾帧桥接

## 图生视频与控制原则
- 提示词优先描述变化，不重复静态事实
- 谁动谁不动要明确
- 复杂控制不依赖数值逻辑，优先用感知词描述
- 重点写模型默认不会知道的事情

## 动作与镜头控制原则
- 一镜一核心动作
- 复杂动作拆镜
- 少用形容词，多用空间几何、物理反馈、导演机位
- 高速动作时，背景可模糊，但人物和武器边缘必须清晰
- **镜头动作融合（核心红线）**：帧率切换、运镜、景别变化绝不能脱离动作独立列出。每个时间戳必须紧跟具体动作，格式为 `[时间戳] 角色动作 → 镜头响应`。升格/降格必须说明为放大什么动作细节或释放什么冲击感。详见 `docs/prompt-standards.md` 的「镜头动作融合原则」。
- **文戏同理**：镜头推近、景别切换必须与角色微表情变化、视线移动、身体姿态转变绑定，不能单独写"镜头缓慢推近"。

## 全能参考 15 秒标准模块（可变镜头版）

> 用途：为 Seedance 2.0 "全能参考"入口输出可直接投喂的 15 秒片段提示词（适合宣发/预告/片段样片）。  
> 核心原则：参考图决定静态事实，提示词只写"动态变化、运镜与衔接"。  
> 输出形态：同一份分镜可以有两套"表达层"——  
> - **即梦版（Omni-Reference）**：逐 Shot 结构化字段（适合审稿与逐项对齐）。  
> - **Seedance2版（时间轴结构）**：按时间段分段（主体/空间/光影/镜头/台词/音效/门禁），更贴合 Seedance2 的输入习惯与节拍控制。  
> - **Seedance2叙事版（长句叙事）**：按时间段分段但用导演口述长句串联（适合快速投喂与节奏预览）。  
> - **Seedance2短提示词（≤300字）**：面向投喂的精炼版（按时间分段+1条运镜+稳定约束），用于平台长度/风控限制更严格的场景。  
> 文件命名约定：`epXXX-omni-paste.md`（即梦版）、`epXXX-seedance2-paste.md`（字段版）、`epXXX-seedance2-narrative-paste.md`（叙事版）、`epXXX-seedance2-compact-paste.md`（≤300字短提示词）。

### 镜头数不是固定值（关键规则）

15 秒不强制 4 镜头。镜头数由"剧本节奏/情绪反应/镜头密度"决定：

- **慢镜头/压迫留白**：1-2 镜头也合理（镜头运动更重要，切换更少）
- **常规叙事/宣发结构**：3-5 镜头常见（逻辑推进清晰）
- **武戏快切/信息密集**：6-10 镜头常见（但必须遵守清晰帧保护与节拍纪律）

镜头数选择要同时满足两条底线：
- **节拍密度**：每 2.5 秒 ≤ 1 个关键动作节拍（动作/转场/情绪爆点算节拍）
- **清晰帧保护**：爆点镜头必须有"命中点/结果镜头清晰可读"的帧

### 结构骨架

```markdown
# [片段名] — Seedance 2.0 全能参考 15 秒提示词

> 项目：
> 大创意：
> 视觉隐喻：
> 镜头数：N 镜头（按剧本节奏决定）
> 结构（可选）：HOOK→PROBLEM→SOLUTION→CTA/钩子收束（适合宣发/预告）；也可"一镜到底/两镜对峙/多镜快切"
```

### 最低合格线
- 参考图职责清晰：谁定形象、谁定动作、谁定节奏
- 每个 Shot 明确"时间段 + 运镜 + 动态画面 + 参考 + 音效/配乐 + 风格"

### 素材职责矩阵（必须显式写出来）

在"全能参考"入口中，提示词不是在"描述画面"，而是在"分配控制权"。每个素材必须明确负责哪个控制维度，并且每个维度必须只有一个主控制源（避免抢权漂移）。

| 控制维度 | 主控制源建议 | 典型写法 |
|---------|--------------|----------|
| 角色形象一致性（脸/发型/服装/阶段/战损） | @角色参考（三视图）或 @comic-panels 首帧 | `@角色参考 负责人物脸型、发型、服装与战损阶段一致` |
| 场景空间一致性（构图/透视/主光方向/空气透视） | @场景参考 或 @comic-panels 首帧 | `@场景参考 负责空间结构与光影基准，保持非居中构图与负空间` |
| 道具形态一致性（关键道具可读性） | @道具参考 | `@道具参考 负责道具外形与材质反光，必须可读` |
| 动作/运镜/转场节奏 | @动作参考（可选）或纯文本指令 | `参考 @动作参考 的运镜节奏；若无视频参考则用文字明确谁动谁不动` |
| 声音节奏/情绪推进 | @音频参考（可选）或纯文本指令 | `@音频参考 负责BGM节奏与情绪曲线；若无则写明"骤静/入点/收束"` |

### 资产匹配优先级（全项目统一）

> 目标：让"全能参考提示词"与"项目资产库"稳定对齐，且能自动适配不同阶段资产完整度。

1. **优先级 1：角色三视图 + 场景氛围图 + 关键道具图（默认主流程）**
   - 使用方式：用三视图锁脸与服装阶段，用场景图锁空间与色调，用道具图保证"剧情支点道具"可读。
2. **优先级 2：风格锚点（Style Anchor / SREF）补位**
   - 使用方式：当某角色/场景缺少定版图时，用全局风格锚点作为"画风与线条规则"补位，但禁止它抢夺"动作/构图/道具可读性"的控制权。
3. **优先级 3（可选增强）：comic-panels 首帧**
   - 使用方式：当你已经额外产出了 `comic-panels` 静帧分镜图，可把每个 Shot 的首帧替换为对应 panel，进一步锁定构图与层级。
   - 注意：它是增强项，不是前置条件；不允许因为缺少 panels 阻塞全能参考提示词输出。

### 生成流程（从剧本/分格/分镜到全能参考 15 秒）

1. **选片段与核心目的**
   - 来自剧本正文：确定本 15 秒片段要完成的叙事目标（钩子/反转/爽点/宣发记忆点）。
2. **从分格脚本抽"读点"**
   - 来自分格脚本：提取"首看点、对白/旁白落点、阅读顺序风险、情绪留白点"，为镜头取舍提供依据。
3. **把事件压缩成镜头结构（N 镜头，可变）**
   - 可选经典宣发结构（适合 15 秒片段）：HOOK→PROBLEM→SOLUTION→CTA/钩子收束。
   - 慢镜头与压迫留白可采用 1-2 镜头；常规叙事可采用 3-5 镜头；武戏快切可采用 6-10 镜头。
   - 无论镜头数多少，都必须满足：节拍密度与清晰帧保护两条底线。
4. **为每个 Shot 分配"对抗/受力/运镜心理"**
   - 动作戏：先写对抗关系与身体受力，再写镜头节奏与清晰帧保护。
   - 文戏：先写权力高低与空间屏障，再写支点动作与留白。
5. **做参考图清单与职责矩阵**
   - 先按"资产匹配优先级"选图，再写职责矩阵，确认不抢权、不超上限。
6. **写提示词（只写动态变化，镜头与动作融合）**
   - 静态事实由参考图承担，提示词只描述：谁动/谁不动、运镜心理动机、环境介质动态、转场方式、音效空间。
   - **帧率切换、运镜、景别变化必须与具体动作时刻绑定编写**，禁止独立列出"镜头与构图"板块。详见 `docs/prompt-standards.md`「镜头动作融合原则」。
7. **QA 放行**
   - 业务：节拍密度、结果兑现、清晰帧保护、转场反PPT。
   - 合规：血腥/未成年人/敏感内容/写实真人脸等风险。

### 平台上限与减负策略（避免失控）

- 混合输入总上限以平台为准（项目默认：图片≤9、视频≤3、音频≤3、总文件≤12）。
- **减负优先级**：
  1. 优先删"多余角色三视图"，保留"本片段核心角色的 1-2 个角色参考"。
  2. 场景参考尽量只用 1 张（同一地点的多个版本会抢空间控制权）。
  3. 道具只保留"剧情支点道具"（婚约红纸/系统UI/禁忌遗物等），不要把非关键装饰塞进来。
  4. 动作参考视频只在"必须复刻运镜/动作/特效演进路径"时引入。

### Agent/Skill 协作分工（生成逻辑如何接入流水线）

- **Writer**：在剧本正文用 `△/△△` 标注支点动作、受力反馈、留白点（为 15s 的 Shot 分解提供动作粒度）。
- **Director**：把本集"分格/分镜表"映射成 15 秒 4 镜头结构，明确每个 Shot 的权力关系、镜头心理动机与转场方式。
- **Librarian**：从 `03-assets/asset-index.md` 与 `06-generated/images/` 选择可用版本，输出"参考图清单 + 职责矩阵"，并保证全片段不混用冲突版本。
- **Prompt Lab（prompt-experiment-skill）**：对高风险 Shot（爆点/变脸/复杂特效）先跑 baseline，再逐层强化，记录回退策略。
- **Studio**：按职责矩阵投喂 Seedance；优先首尾帧稳定出片，必要时切换全能参考；严格执行环境介质与互动光规则。
- **Reviewer / QA（quality-control-skill, continuity-check-skill）**：审查"素材抢权、节拍密度、关键帧可读性、角色阶段连续性、字幕安全区、转场反PPT"。

1. 先选时长，再选视频类型
2. 先定镜头数，再写镜头内容

## 后处理工具链

> 提示词生成好素材后，经常需要后处理提升质量。以下是项目推荐的外部工具节点。

### 图片高清化
- **工具**：[neodomain.cn](https://neodomain.cn)
- **用途**：AI 修改或压缩后图片模糊 → 一键 4K 高清化重置
- **适用场景**：分镜底图模糊、多次压缩后的资产图、需要提升细节清晰度的静帧
- **插入节点**：资产生成后 → 提示词投喂前

### 灯光精细调节（ComfyUI 节点插件）
- **工具**：ComfyUI 灯光控制插件（通过 ComfyUI 节点市场安装）
- **用途**：自由调节光线角度、强度、主光/辅光配比、硬光/柔光切换、颜色选择
- **适用场景**：生成图光影不理想需要微调、需要精确控制光的方向和质感
- **能力**：可独立设置主光 + 辅光 + 轮廓光，支持多种照射方式
- **插入节点**：初版图生成后 → QA 审核前

### 工具链推荐流程

```
提示词编写 → Seedance/即梦 生成初版图
    ↓
[可选] neodomain.cn 4K高清化（模糊时使用）
    ↓
[可选] ComfyUI 灯光插件微调（光影不理想时使用）
    ↓
QA 审核 → 合格入库 / 不合格回退重生成
```
