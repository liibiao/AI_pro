# 即梦精简版输出模板

> **用途**：即梦平台（JiMeng）直接投喂的精简提示词模板（展示/导出用）
> **核心差异**：去 @标签、字段合并、自然语言压缩、保留台词
> **源头**：由 Seedance 长版母稿转换而来，参考 `skills/quality-control-skill.md` 三版本一致性校验
> **对应规范**：`docs/prompt-standards.md` / `docs/dual-format-prompt-methodology.md`

---

## 【转换规则速查】

| 环节 | Seedance 长版 | 即梦精简版 |
|---|---|---|
| 标签 | `@人物1（疲惫）` | `疲惫的年轻男子，黑色衬衫，短发` |
| 字段 | 主体/空间/光影/镜头/台词/音效 六段分列 | 全部合并为 1-3 段自然语言 |
| 运镜 | `镜头：MS中景 · 慢推 Dolly In 0.5u/s` | `镜头缓缓推近` |
| 动作词 | `缓缓揉太阳穴→目光从屏幕移开→` | `缓缓揉太阳穴，随后目光离开屏幕` |
| 负面提示词 | 独立段落 | 放在末尾 |
| 六个固定段 | 必须保留 | 只保留"画质"和"负面提示词" |

---

## 【基础模板】（单镜头，适合 5-6s 内）

```
[场景氛围一句话] + [人物外观+动作] + [光影] + [镜头] + [台词（可选）] + [风格关键词]

负面：[负面词列表]
```

---

## 【多镜头连续版】（适合 15-60s 场景）

```
总体风格：[视觉风格 + 导演风格 + 主色调]

【第1段】[时长]s
[外观+动作+光影+镜头+台词]

【第2段】[时长]s
[外观+动作+光影+镜头+台词]

...

负面：[全片共用负面词]
```

---

## 【快速生成模板】（最短形式）

适用于测试、灵感抓取、快速迭代：

```
[场景] + [主角外观] + [核心动作] + [光影] + [风格]
```

---

## 【从长版母稿一键转换步骤】

1. **删除所有 @标签**，用外观描述替换
2. **合并六字段** 为 1-3 段自然语言，顺序：氛围 → 主体+动作 → 光影+镜头 → 台词 → 风格
3. **速度词保留**（缓缓/猛然/骤然/渐渐）
4. **运镜保留方向**（推/拉/摇/移/跟），删除技术参数
5. **否定句转肯定**（"不要动" → "保持静止"）
6. **台词保留原文**，但去掉秒数定位
7. **风格三要素**：视觉风格 + 画质 + 情绪关键词
8. **负面词列表**：从原片负面段复制核心 5-10 个

## 【质量检查清单】

- [ ] 所有 @标签已替换为真实名称
- [ ] 字段标签全部去除（无"主体：""空间："等）
- [ ] 长度约为长版母稿的 60-70%
- [ ] 台词原文完整保留
- [ ] 无 `[禁BGM]` `[禁字幕]` 标记
- [ ] 无否定句
- [ ] 否定词列表来自长版母稿负面段
