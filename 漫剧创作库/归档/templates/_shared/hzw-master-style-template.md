### 2.6 PBR 材质升级锚点

适用对象：机甲 / 装甲 / 载具 / 武器 / 金属道具 / 工业资产。

核心词组：`PBR材质，裸铁，粗糙度变化，AO，GI，高光滚降，电影化HDR/类ACES色调映射，细微胶片颗粒、极轻微晕光(halation)`。

- 几何限制：仅升级 PBR 材质，不新增几何结构 / 装甲片 / 新缝隙；只升级真实感，不改变原本设计。
- 金属漆面：裸铁反光有限，斜角清漆层 Fresnel 才是金属反光关键；使用喷涂金属装甲、真实 clearcoat 反射、准确 Fresnel 边缘反射。
- 粗糙度变化：粗糙度指反光锐利或发散；现有面板 roughness variation 应来自新旧、积灰、擦拭频率差异，不均匀且面板之间有细微差异。
- 微观纹理：不加大划痕 / 大战损，只加摄影机近看可见的非常轻微橘皮漆质感、细小微划痕、淡淡擦拭痕迹。
- 污垢灰尘：脏旧必须有生活物理逻辑，只存在于现有缝隙、关节内部、接触凹陷、积灰面或擦拭边界。
- 边缘磨损：只沿现有边缘出现，不得凭空创造损坏图案。
- 光照响应：加强 AO、接触阴影、GI、自然高光滚降、电影化 HDR / 类 ACES；暗部和亮部都保留细节，不死黑不过曝。
- 后期限制：细微胶片颗粒、极轻微 halation 只用于去掉 AI / CG 过度干净感；禁止风格化、梦幻化、过度泛光。

### 2.7 氛围控制锚点

HZW 氛围不是堆满效果，而是让世界“活起来”的受控环境系统。

核心词组：`high contrast, haze, semi metallic lighting, volumetric smoke or fog, sparks`。

- `high contrast`：服务第一读点，用“藏”和“露”制造视线引导、压迫感、戏剧性和空间层次。
- `haze`：只做轻到中度空气层，让空气不空、光有存在感，禁止假雾糊空间和达利园效应。
- `semi metallic lighting`：电影布光不是照清楚，而是照得有戏；必须有主光方向、亮暗重点和情绪目的，禁止平亮棚拍。
- `volumetric smoke or fog`：必须有来源或空间位置，用于让光线可见并强化纵深和立体感。
- `sparks`：只出现在焊接、摩擦、撞击、破损电路、能量释放等合理位置，点到为止，禁止廉价海报感和游戏技能特效感。
- 统一公式：氛围效果 = 叙事理由 + 空间位置 + 强度 + 与主体 / 光线 / 动作的关系。
- 禁止：堆满氛围词、无来源烟雾、全屏雾化、假雾糊空间、火花过量、游戏特效感、廉价海报感、平亮无重点。

## 3. 生图提示词母版

### 3.0 长度控制

- 简单基础画面：只写核心目标，避免加入无关电影词、烟雾、火花、大光比或复杂镜头。
- 复杂高级画面：可以写更长，但每个描述都必须有理由，并服务第一读点、主体、空间、光影、材质、氛围或结果。
- 判断句：删除某个词后目标仍成立，就优先删除；目标复杂但信息不足，就补齐必要字段。

### 3.0b 执行权重控制

- AI 会优先执行明确动作词、姿态词和对象词，不会自动补全隐含空间关系。
- 关键方向、朝向、对象关系必须写成显性强权重词：`身体朝向[方向]`、`头部正对[对象]`、`[对象]位于画面[位置]`。
- 若动作词会抢走构图或朝向，优先删除或降级，只保留服务第一读点的动作。
- 禁止用“克制地、明确地、非常地、电影感、高级感”替代具体动作、姿态和空间关系。

### 3.1 生图顺序：信息版 → 情绪渲染版

- 信息版（Readability Pass）：使用大屏光 / 高可读性光照，只锁定人物、道具、构图、主体行为、机位、静止项和允许运动项；禁止加入影调、氛围、PBR、体积光、雾、火花、胶片颗粒等效果。
- 情绪渲染版：信息版完全正确后，再添加 `high contrast`、`haze`、`volumetric smoke or fog`、逆光、体积光、PBR 材质、AO、GI、细微胶片颗粒、电影化 HDR 等表现词。
- 回退规则：如果要换完全不同的光影风格，必须回到信息版重做，禁止在情绪渲染版上反复补丁式修改。

```text
创作一张[比例/用途]的 HZW大师风格[图像类型]。
主体是[角色/场景/道具]，固定锚点为[锚点]，当前处于[剧情状态]。
人物表演：[大动作 + 微停顿 + 小肌肉反应 + 呼吸 / 视线 / 表情连锁 + 情绪理由]；一个镜头只选 2-4 个关键微动作，禁止抽搐式堆叠。
画面第一读点是[第一读点]。
构图采用[景别/视角/前景遮挡/纵深层次/构图提示词]，可使用受控的 voyeuristic framing / partial-body framing / asymmetrical balance / centered composition；前景是[元素]，中景是[主体动作]，背景是[环境结构]，主体与空间关系服务[情绪目标]。
光影为[主光方向/冷暖/硬软/轮廓光]，色彩为[主色+辅色+点缀色]，整体服务[情绪]。
材质细节包含[材质]，环境介质与主体发生[互动]。
氛围效果：[叙事理由 + 空间位置 + 强度 + 与主体 / 光线 / 动作的关系]；可使用受控的 high contrast / haze / semi metallic lighting / volumetric smoke or fog / sparks，但每个效果都必须有理由。
若为机甲 / 装甲 / 载具 / 武器 / 金属道具：仅通过 PBR 材质升级实现，不新增任何几何结构；喷涂金属装甲，真实 clearcoat 反射，准确 Fresnel 边缘反射；现有面板存在符合物理逻辑的不均匀粗糙度变化；仅有非常轻微橘皮漆质感、细小微划痕、淡淡擦拭痕迹；污垢和灰尘只聚集在现有缝隙与关节内部；边缘磨损只沿现有边缘出现；加强现有缝隙 AO 与接触阴影；改善 GI，全局光照真实，高光滚降自然，电影化 HDR，类 ACES 色调映射；细微胶片颗粒，极轻微 halation，不风格化。
输出要求：[比例/清晰度/用途]。
禁止：[角色换脸、服装漂移、背景杂乱、过曝、低清、文字乱码、多余肢体、风格混杂、新增几何结构、随机裂纹、凭空战损、过度泛光、堆满氛围词、无来源烟雾、全屏雾化、火花过量、平亮无重点]。
```

## 7. 本项目 HZW 风格自检

- [ ] 开剧前已确认整剧视觉风格、编剧师风格、导演风格、分镜师风格。
- [ ] 后续提示词、资产图片、分镜图、视频都明确引用本风格母版。
- [ ] HZW大师风格定义已写清，不是泛泛电影感。
- [ ] 角色、场景、光影、色彩、镜头与氛围锚点齐全。
- [ ] 构图提示词已服务主体与空间关系及情绪目标，不是英文专业词堆叠；前景遮挡、局部裁幅、非对称平衡或居中构图均有明确理由。
- [ ] 人物表演不只写大动作，已补充微停顿、小肌肉反应、呼吸 / 视线 / 表情连锁和情绪理由，且未抽搐式堆叠。
- [ ] 氛围效果有理由、有位置、有强度边界，并明确与主体 / 光线 / 动作的关系，不是堆词。
- [ ] 生图已先完成信息版锁定人物、道具、构图、主体行为、机位和约束，再进入情绪渲染版；大改光影时已回到信息版重做。
- [ ] 已检查提示词执行权重：不存在“主体 → 动作 → 风格”的线性顺序误判；关键朝向、对象关系和空间位置已显性化，且高干扰动作词、训练数据惯性或参考图视觉惯性没有抢走第一读点或构图。
- [ ] 若涉及机甲 / 装甲 / 载具 / 武器 / 金属道具，已执行 PBR 材质升级锚点，且未新增任何几何结构。
- [ ] 生图、场景、分镜、视频共用同一套锚点。
- [ ] 抽卡前已检查主体定义不是笼统词，已使用项目资产名 / 参考图主体名 / 固定外观锚点，并明确谁动、什么不动、哪些环境元素允许轻微变化。
- [ ] 分镜没有改写角色和场景设定。
- [ ] 视频提示词保留固定段名和结果稳定帧。
- [ ] 禁止项包含角色换脸、服装漂移、光线跳变、风格混杂。
