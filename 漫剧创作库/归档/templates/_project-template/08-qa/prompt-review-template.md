## 第一步：业务审核

### A. 母格式与结构完整性
- [ ] `seedance` 长版母稿已采用 `画面主体 + @Image 起手 + 逐条时间轴 + 六个固定段名`
- [ ] 六个固定段名齐全：`环境联动 / 光线 / 对白配音 / 音效设计 / 画质 / 负面提示词`
- [ ] `@Image` 与正文中的 `@`引用优先使用已登记 `@资产名`
- [ ] 长版、简版、平台派生稿保留同一主动作链与结果镜头

### B. 动作—镜头—景别绑定
- [ ] 运镜不是孤立描述，已与人物动作和表演绑定
- [ ] 景别变化与动作推进一致，没有“无理由切近 / 拉远 / 推镜”
- [ ] 站位 / 朝向 / 距离 / 主读点清楚
- [ ] 结果镜头明确兑现，不是只写过程不写结果

### C. 声音双流程检查
- [ ] `对白配音` 只负责人声层（台词 / 旁白 / 心声 / 气口 / 语速 / 停顿）
- [ ] 无对白段已明确写“本段无对白配音”
- [ ] `音效设计` 已覆盖环境音 / 拟音 / 特效音 / 状态音的关键层次
- [ ] `BGM` 未混入固定段名主结构；如出现，已明确为后期可选说明

### D. 节拍、视听与执行可行性
- [ ] 时间轴真实铺满时长，无虚标
- [ ] 节拍密度合理，能读出“蓄力 → 骤静 → Hit Stop → 爆裂释放”节奏反差
- [ ] 音效、特效、环境反馈与关键命中点同步
- [ ] 文案可直接执行，不依赖大量脑补

### E. 平台派生一致性
- [ ] 即梦版确实是压缩，不是改写跑偏
- [ ] Seedance 字段版字段清楚，适合执行与审稿
- [ ] 叙事版顺读自然，但未丢失关键结构与门禁信息
- [ ] 各版本之间没有素材抢权 / 结果冲突 / 声音结构漂移
