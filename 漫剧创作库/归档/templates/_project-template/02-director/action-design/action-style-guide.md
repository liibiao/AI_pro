## Seedance 动作提示词底线

```
1. 不写"腾空飞踢"——写"低身扫腿，对方倒地"
2. 不写"刀光剑影"——写"刀刃从下往上格挡，火星飞溅"
3. 不写"一拳打死"——写"拳头命中腹部，对方捂住倒下"
4. 不写慢镜头打斗——保持写实快节奏
```
