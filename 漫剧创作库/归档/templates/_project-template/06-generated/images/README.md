# images 图片资产目录

本目录用于存放项目内所有最终可引用、可复用、可交付的图片资产。

## 子目录规范

- `characters/`：角色图，包括角色定妆图、三视图、表情图、角色海报等。
- `props/`：道具图，包括关键道具、武器、信物、服饰细节、可复用物件等。
- `scenes/`：场景图，包括主场景、空间概念图、环境氛围图、场景参考图等。
- `others/`：其他图片，包括临时测试图、风格探索图、未归类图片、流程验证图等。

## 使用规则

1. 每个新项目必须在 `06-generated/images/` 下保留以上四个基础子目录。
2. 生成图片后，先按用途放入对应子目录；暂时无法归类的图片统一放入 `others/`。
3. 图片文件名统一使用中文命名，格式：`<用途>-<对象>-<版本>-<日期>[-序号].<扩展名>`

### 命名示例
| 用途前缀 | 示例文件名 |
|----------|-----------|
| 角色定妆 | `角色定妆-男主-v1-20260412.png` |
| 角色头像 | `角色头像-女主-v1-20260412.png` |
| 角色三视图 | `角色三视图-反派-v1-20260412.png` |
| 封面探索 | `封面探索-第1集-v1-20260412-1.png` |
| 封面定稿 | `封面定稿-第1集-v1-20260412.png` |
| 场景氛围 | `场景氛围-古镇夜景-v1-20260412.png` |
| 道具设计 | `道具设计-龙纹剑-v1-20260412.png` |
| 测试图 | `测试图-mjv7风格验证-v1-20260412-1.png` |
| 风格探索 | `风格探索-赛博朋克-v1-20260412-1.png` |

4. 正式入选的图片，应同步登记到 `06-generated/asset-index.md`。
5. 失败图、对照图、风格探索图不要直接删除，建议放入 `others/` 并在文件名或说明中标注原因。
