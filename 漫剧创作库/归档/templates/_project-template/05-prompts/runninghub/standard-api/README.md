# standard-api 标准模型 API 任务卡目录

用于存放 RunningHub 标准模型 API 任务卡。

当前默认支持：
- `mj-v7`

适合：
- 快速测试图
- 封面探索图
- 风格探索图
- 不依赖 workflowId / nodeInfoList 的 prompt 直出图

推荐输出：
- `06-generated/images/others/`

正式入选后，再按用途转入：
- `06-generated/images/characters/`
- `06-generated/images/props/`
- `06-generated/images/scenes/`
