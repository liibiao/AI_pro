### 场景基本信息

| 字段 | 内容 |
|------|------|
| 地点 | _如：北京市朝阳区废弃工厂_ |
| 空间大小 | _如：约200平米仓库，挑高6米_ |
| 主要陈设 | _如：铁架、破旧桌椅、昏暗灯光_ |
| 气味（氛围参考） | _如：潮湿发霉、金属锈蚀味_ |
| 声音环境 | _如：远处车流声、滴漏水声、风声_ |
