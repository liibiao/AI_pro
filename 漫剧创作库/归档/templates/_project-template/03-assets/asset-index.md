# asset-index.md

## 用途
登记项目内人物、场景、道具、封面、宣发等核心资产，作为项目级资产总入口。

## 资产清单
| 资产ID | 分类 | 名称 | 用途 | 首次出现 | 当前版本 | 状态 | 备注 |
|--------|------|------|------|----------|----------|------|------|
|        |      |      |      |          |          |      |      |

## 分类建议
- CHAR：角色
- SCENE：场景
- PROP：道具
- COVER：封面
- PROMO：宣发图
- REF：参考图

## 维护规则
- 每新增一个核心资产就登记一条
- 版本变化必须更新“当前版本”
- 废弃资产标记为 archived，不直接删除
