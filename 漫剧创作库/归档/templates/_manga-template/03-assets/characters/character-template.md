> **首次出现章节 / 页段：** chapter-001 / page-001

### 角色基本信息

| 字段 | 内容 |
|------|------|
| 身份职业 | _如：总裁 / 学生 / 医生 / 驱魔师_ |
| 年龄层 | _如：18-25_ |
| 原型归类 | _如：冷艳反杀型_ |
| 核心关系 | _如：表面柔弱，实则掌控阅读重心_ |
| 行为特征 | _如：动作少，但眼神主导强_ |

### 参考图八维摘要

| 维度 | 内容 |
|------|------|
| 主体状态 | _如：站定、观察、准备反击_ |
| 表情读点 | _如：轻蔑、冷眼、短暂停顿_ |
| 发型 / 发色锚点 | _如：高马尾、茶黑色、刘海分区稳定_ |
| 服装 / 配饰锚点 | _如：校服外套、徽章、领结_ |
| 构图 / 分格偏好 | _如：半身格更利于保气泡区_ |
| 风格锚点 | _如：韩漫冷调、清晰线条、低噪点_ |
