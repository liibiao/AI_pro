# asset-index.md

## 用途
登记项目内人物、场景、道具、封面、宣发等核心资产，作为项目级资产总入口。

## 资产清单
| 资产ID | 分类 | 名称 | 用途 | 首次出现 | 当前版本 | 状态 | @标签 | 参考图来源 | 失败/回退备注 | 备注 |
|--------|------|------|------|----------|----------|------|------|------------|----------------|------|
|        |      |      |      |          |          |      |      |            |                |      |

## 分类建议
- CHAR：角色
- SCENE：场景
- PROP：道具
- COVER：封面
- PROMO：宣发图
- REF：参考图

## 维护规则
- 每新增一个核心资产就登记一条
- 版本变化必须更新“当前版本”
- 废弃资产标记为 archived，不直接删除
- 角色 / 场景 / 道具应尽量映射到 `@标签`
- 若资产来自高价值参考图，需标注来源，并优先关联 `docs/reference-image-analysis-standard.md` 的分析结果
- 若资产曾触发失败版、保底版或减负回退，需在“失败/回退备注”中写明触发器
