# 创作入口说明

本目录用于管理本项目的故事来源、剧本来源与外部系统输入。

## 入口保留规则

以下入口保持可用，不因小说写作系统对接而废弃：

1. 一句话创作
2. 导入现有故事梗概
3. 导入现有剧本
4. 导入小说原文
5. AI 创作故事 / AI 创作剧本，对接小说写作系统输出

## 核心变更

本项目中，只有“AI 创作故事 / AI 创作剧本”类入口改为对接小说写作系统输出物。

漫剧项目不直接承担原创小说或原创剧本从零生成职责，而是接收小说写作系统输出，并负责后续漫剧改编、剧本拆解、导演讲戏、资产、分镜、提示词、图片 / 视频生成与 ffmpeg 拼接。

## 标准流转

```text
创作入口
  → 输入源选择
  → 输入物验收
  → 漫剧改编输入确认
  → 全剧故事
  → 分集大纲
  → 单集剧本
  → 导演讲戏
  → 分镜
  → 提示词
  → 图片 / 视频生成
  → ffmpeg 拼接
  → 每集完整视频
```

## 目录职责

- `01_一句话创作/`：接收一句话灵感。
- `02_导入现有故事梗概/`：接收外部故事梗概。
- `03_导入现有剧本/`：接收外部剧本。
- `04_导入小说原文/`：接收外部小说正文。
- `05_AI创作_对接小说写作系统/`：接收小说写作系统输出物。
