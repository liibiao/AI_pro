## 4. 内容质量验收项

### 4.1 故事层

- [ ] 主线清晰。
- [ ] 主角目标清晰。
- [ ] 核心冲突清晰。
- [ ] 反派 / 阻力清晰。
- [ ] 世界观规则清晰。
- [ ] 人物关系清晰。
- [ ] 情绪卖点清晰。
- [ ] 类型爽点清晰。

### 4.2 分集层

- [ ] 分集节奏清晰。
- [ ] 每集有开场钩子。
- [ ] 每集有关键转折。
- [ ] 每集有结尾悬念或结果兑现。
- [ ] 每集出场人物清楚。
- [ ] 每集核心场景清楚。
- [ ] 第01集可直接拆为剧本。

### 4.3 漫剧改编层

- [ ] 可改编为漫剧场次。
- [ ] 可拆为角色、场景、道具、特效资产。
- [ ] 有足够视觉桥段支撑分镜。
- [ ] 有可视频化的动作、表演或情绪节点。
- [ ] 可继续拆为单集剧本。
- [ ] 不存在影响平台生成的重大设定空洞。

## 6. 打回条件

以下任一情况出现时，不得进入漫剧改编输入确认：

1. 只有概念，没有完整主线。
2. 只有人物名，没有角色关系与动机。
3. 只有世界观名词，没有规则与剧情作用。
4. 分集大纲缺少每集冲突、转折或结尾钩子。
5. 剧本化输出缺少对白、动作、场次或转场。
6. 输出物之间互相冲突，无法统一成项目正式版本。
7. 第01集无法拆出明确场次、角色、场景和钩子。
8. 缺少可转化为画面资产的角色、场景或道具信息。
