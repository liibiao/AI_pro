## 4. 漫剧改编判断

| 判断项 | 当前结论 | 通过标准 |
|---|---|---|
| 是否适合短集漫剧结构 | 待判断 | 每集有清晰冲突、转折、钩子或结果兑现 |
| 单集时长目标 | 待确认 | 建议先按 60-120 秒短集结构拆解 |
| 每集核心爽点 | 待补 | 每集至少一个视觉 / 情绪 /剧情爽点 |
| 每集结尾钩子 | 待补 | 每集结尾能引导下一集 |
| 需要压缩的小说段落 | 待补 | 支线、解释性背景、重复对白优先压缩 |
| 需要强化的视觉桥段 | 待补 | 战斗、觉醒、反转、压迫、情绪爆发优先强化 |
| 需要新增的角色资产 | 待补 | 主角、核心配角、反派、关键 NPC |
| 需要新增的场景资产 | 待补 | 每个核心大场景需支持场景母图和固定视角图 |
| 需要新增的道具 / 特效资产 | 待补 | 只登记承担叙事、动作或世界观功能的关键物件 |

## 5. 改编拆解原则

1. 先确认故事主线，再拆分集，最后进入单集剧本。
2. 不直接把小说正文当剧本；必须完成场次、对白、动作、转场和钩子拆解。
3. 不直接把剧本草稿当锁定版；必须通过台词、场次、节拍和资产可执行性检查。
4. 角色、场景、道具、特效必须能回流到资产库，形成后续分镜和提示词引用源。
5. 第01集必须先具备明确的开场钩子、主角目标、核心冲突、结尾推进或悬念。
6. 若故事输入无法支持画面化、分镜化、资产化，应打回小说写作系统补齐。
