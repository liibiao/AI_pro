# images 图片资产目录

本目录用于存放项目内所有最终可引用、可复用、可交付的图片资产。

## 子目录规范

- `characters/`：角色图（定妆图、三视图、表情图、角色海报等）
- `props/`：道具图（关键道具、武器、信物、服饰细节等）
- `scenes/`：场景图（主场景、空间概念图、环境氛围图等）
- `others/`：其他图片（测试图、风格探索图、未归类图片等）

## 资产文件命名规范
使用中文命名，格式：`<用途>-<对象>-<版本>-<日期>[-序号].<扩展名>`

示例：
- `角色定妆-男主-v1-20260412.png`
- `场景氛围-古镇夜景-v1-20260412.png`
- `测试图-风格验证-v1-20260412-1.png`
