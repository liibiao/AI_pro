# ep001 Storyboard — 第1话《黑风荒原》

## 分镜策略

- 场景类型：史诗战争 / Boss 对峙 / 牺牲 / 温存
- 镜头组：建立组 → 推进组 → 温存组 → 牺牲组 → 点火组 → Boss 战组 → 结果钩子
- 主镜一句话：陆沉在黑风荒原用血点燃烽火，并在牺牲推动下斩断魔君黑角。
