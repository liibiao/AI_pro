# ep001 Edit Plan — 黑风荒原

## 剪辑目标

保留“宏大战争”和“个人牺牲”的双线，让 15 秒名场面能独立成立，完整版第一话则按 90-120 秒节奏展开。

## 推荐剪辑结构

| 段落 | 时长 | 剪辑策略 |
|---|---:|---|
| 黑风荒原建立 | 5-8s | 大远景 + 低频战鼓，快速交代战场 |
| 阿砚系血带 | 10-15s | 声音压低，保留呼吸和布料摩擦 |
| 韩照牺牲 | 8-12s | 黑矛命中帧停住，盾裂声先于画面余波 |
| 血燃烽火 | 8-10s | 火焰爆燃接远处烽火亮起 |
| Boss 战 | 25-35s | 动作清晰优先，命中点停，结果镜头留 |
| 血门钩子 | 6-8s | 战鼓从门内压来，黑屏前留旗响 |

## 声画重点

- 韩照牺牲前，不上煽情音乐，先让盾裂和吐血声成立。
- 阿砚系血带段可以短暂抽掉战鼓，让温存更紧。
- 斩角前 0.2s 抽空，斩角后留全场静默。
- 结尾战鼓来自血门内部，作为下一话威胁。
