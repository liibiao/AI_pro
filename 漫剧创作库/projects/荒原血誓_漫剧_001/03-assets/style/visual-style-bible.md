# Visual Style Bible — 荒原血誓

## 主风格

史诗黑金玄幻战争，竖屏漫剧电影感。画面要有荒原风沙、血色夕阳、黑金魔焰、青铜残甲、金红烽火的强对比。

## 画质基调

- 质感：写实国漫 / 半写实角色 / 电影级光影
- 光影：低角度血色夕阳 + 烽火金红轮廓光 + 魔族黑焰冷暗反光
- 色彩：荒原土黄、暗红血色、青铜绿锈、黑金魔焰、金红烽火
- 材质：旧青铜、裂皮革、磨损骨甲、粗糙砂石、燃烧灰烬
- 构图：大远景建立战争规模，近景保护人物表情和受力读点

## 禁止项

- 不要干净棚拍背景。
- 不要全屏光污染遮住脸和命中点。
- 不要让魔族黑潮变成无意义黑雾。
- 不要把战争拍成单人摆拍。
- 不要让陆沉服装在同一话内无理由变新。

## 生成锚点

- 角色锚点：陆沉右臂红色血带、青铜鳞甲半碎、左眉旧伤。
- 场景锚点：半截烽火台、断旗、黑风、血色夕阳、沙地裂纹。
- Boss 锚点：烬罗双黑角、赤金竖瞳、黑色骨甲、黑焰长矛。
- 情绪锚点：温存藏在战场动作里，悲壮落在具体牺牲上。
