# ep001 动作设计 — 黑风荒原 Boss 战

## 对抗关系

烬罗体型、力量、武器长度全面压制陆沉。陆沉的优势不是更强，而是利用战场遗物：韩照裂盾、断矛、烽火台裂缝、右臂血带带来的心理锚点。

## 位置关系

- 陆沉：烽火台顶中央，背后金红烽火，右臂系红色血带。
- 烬罗：台阶下正前方六米，黑矛拖地，背后魔族黑潮。
- 韩照裂盾：陆沉左前方一米，后续成为格挡和踏跳支点。
- 断矛：韩照牺牲后落在石阶边，后续成为斩角工具。

## 动作链

1. 烬罗黑矛横扫，陆沉侧翻避开，胸甲被擦碎。
2. 陆沉抓裂盾格挡第二击，被震退三步。
3. 陆沉佯攻咽喉，逼烬罗抬矛。
4. 陆沉贴身肘击肋下骨甲，但烬罗只晃半寸。
5. 烬罗膝撞陆沉腹部，陆沉弓身喷血。
6. 陆沉后退时把断刀插进石缝，借刀柄反弹。
7. 骤静，陆沉踏裂盾起跳。
8. 陆沉左手抓黑角，右手用断矛横压角根。
9. 下坠重量带动断矛斩断黑角。
10. 烬罗后退一步，魔族黑潮第一次停退。

## 节奏设计

`压制快打 → 被迫格挡 → 贴身冒险 → 受击喷血 → 借物回弹 → 骤静 → Hit Stop → 黑角断裂 → 结果静默`

## 声音闭环

- 横扫：黑矛拖风，低频撕裂。
- 格挡：金属爆响，盾裂纹连响。
- 膝撞：闷击声，陆沉呼吸中断。
- 骤静：0.2 秒抽空，只保留血带燃响。
- 斩角：骨裂 + 黑焰回喷 + 烽火爆燃。
