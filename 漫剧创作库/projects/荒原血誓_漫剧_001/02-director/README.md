# Director Notes — ep001《黑风荒原》

## 戏核

这不是“人族和魔族打得很大”，而是“最后一座烽火台必须被点燃”。所有宏大战争、牺牲、温存和 Boss 战都围绕这个目标组织。

## 视觉母题

- 血色夕阳：人族旧时代将尽
- 黑风荒原：战争吞没人名
- 金红烽火：人族仍有方向
- 红色血带：温存、伤口、誓言的统一锚点
- 断裂黑角：Boss 受损与下一集血门钩子

## 场景调度

主空间为黑风荒原烽火台。烽火台在画面中是垂直轴，陆沉从低处伤兵线向高处火盆移动，烬罗从正前方黑潮中压来。左右翼是魔族包围，后方是人族伤兵线和撤退方向。

## 情绪曲线

1. 宏大战败：人族防线被压弯。
2. 微小温存：阿砚给陆沉系血带。
3. 具体牺牲：韩照以盾硬接黑矛。
4. 反扑点火：陆沉以血点燃烽火。
5. Boss 压迫：烬罗亲自灭火。
6. 主角爆发：陆沉借裂盾、断矛、烽火台空间完成斩角。
7. 史诗钩子：血门开启，战争规模扩大。

## 镜头语言

- 战争建立用广角远景和低机位，强调人族渺小。
- 温存段用中近景，风声压低，血带作为主读点。
- 韩照牺牲用 Hit Stop，盾裂纹和身体受力必须清楚。
- Boss 战按“站位建立 → 蓄力 → 骤静 → Hit Stop → 爆裂释放 → 结果镜头”组织。
- 所有运动镜头必须绑定具体动作，不单独写空运镜。

## 声音策略

- 魔族：低频战鼓、骨旗摩擦、黑焰燃烧、兽骑蹄震。
- 人族：残旗猎响、甲片碰撞、伤兵喘息、烽火爆燃。
- 温存：短暂抽低战场声，只保留风吹血带。
- 斩角：骤静后接黑角碎裂、火焰回卷、全场静默。
