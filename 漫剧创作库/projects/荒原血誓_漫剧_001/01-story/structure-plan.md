# Structure Plan — 荒原血誓 ep001

## 结构目标

第一话用 90-120 秒建立世界、主角、战役目标、牺牲、温存和 Boss 战钩子。

## 节拍设计

| 时间 | 节拍 | 功能 |
|---|---|---|
| 0-8s | 黑风荒原全景，人族防线被魔潮压弯 | 直接进入大战 |
| 8-20s | 陆沉救下军旗，接到守烽火台命令 | 主角目标 |
| 20-38s | 阿砚给陆沉系血带，短暂温存 | 情感锚点 |
| 38-55s | 魔族破阵，韩照牺牲挡黑矛 | 牺牲与推动 |
| 55-85s | 陆沉点燃烽火台，烬罗亲临 | Boss 压迫 |
| 85-115s | 主角与 Boss 近战，斩断黑角 | 爽点与反扑 |
| 115-120s | 黑角化血门，魔族王庭显现 | 结尾钩子 |

## 爽点与情绪

- 热血：陆沉在崩线中举旗前冲。
- 牺牲：韩照用盾和身体挡住黑矛。
- 温存：阿砚给陆沉系红色血带，告诉他“活着回来，不许把旗还给我”。
- 史诗：黑风、残旗、战鼓、血色夕阳、万军压境。
- Boss 战：拳、肘、矛、膝撞、格挡、翻滚、借盾反击、斩角，动作必须丰富且每下有受力结果。
