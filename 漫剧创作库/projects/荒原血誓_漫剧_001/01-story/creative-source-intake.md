# Creative Source Intake — 荒原血誓

| 项目 | 判断 |
|---|---|
| 输入类型 | 一句话创意 / 史诗战争场面需求 |
| 成熟度 | L2：有场面和情绪方向，缺人物、目标、结构 |
| 推荐路线 | 故事开发线 → 导演讲戏 → 资产卡 → 故事板生产包 |
| 目标集数 | 先做 ep001 样板话 |
| 核心情绪 | 热血、悲壮、温存、誓死守护 |
| 核心视觉 | 黑风荒原、血色夕阳、残旗、魔族黑潮、黑金魔焰、人族青铜战甲 |
| 核心风险 | 群战空间混乱、牺牲不具体、Boss 战只有光效没有受力 |

## Agent 判定

- Producer：锁定第一话主交付为故事板生产包，不直接跳视频生成。
- Writer：补人物关系和明确战术目标，剧本必须可拆分镜。
- Director：建立荒原战争的空间、光影、军阵和 Boss 压迫。
- Storyboard Artist：用“建立组 → 推进组 → 温存组 → 爆点组 → 结果组”拆镜。
- Librarian：先用文本资产卡建立 `@引用`，后续可替换为真实资产图。
- Studio：本轮输出 Seedance/Sora2 适配说明，不调用外部生图 API。
- Reviewer：执行故事板与提示词红线 QA。
