## 1. 设计图规格

### 整体布局
- **排版**：上下两层排版
- **背景**：纯灰色背景（#808080）
- **画面要求**：不得出现文字和边框

### 第一层：道具三视图
| 位置 | 内容 |
|------|------|
| 左 | 正面全景 |
| 中 | 侧面全景 |
| 右 | 背面全景 |

### 第二层：交互状态 × 3
| 位置 | 状态 |
|------|------|
| 左 | 休眠态（灵纹暗淡，七色光微弱游走） |
| 中 | 激活态（A级觉醒，雷光炸裂，碑体狂闪） |
| 右 | 失败态（碑面微弱一闪后熄灭，"伪灵纹"暗淡文字） |

## 2. 道具特征锚点

- 高度：约三丈（10 米），碑形巨石
- 材质：黑色发亮，不明材质，表面光滑但有灵纹刻痕
- 碑身：盘绕灵纹纹路，七系灵纹光芒缓缓游走
- 碑顶：金色大字刻痕（元素、属性、强化、精神、具化、治疗、动物）
- 底座：嵌入地面的石台，周围有古老阵纹
