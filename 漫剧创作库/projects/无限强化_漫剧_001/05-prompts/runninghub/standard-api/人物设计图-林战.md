# 人物设计图任务卡 — 林战 V2（新建）

> 工作流：三等分排版人物设计图
> 模型：MJ-Niji7（统一美漫国漫融合卡通渲染风格）
> 风格基准：参考 `角色设计图-林傲天-v2-3.png`
> 资产类型：角色设计图 | 优先级：P2
> 版本：V2（新建·统一风格）
> 备注：第1话仅背影出场，此为完整设定图备用

---

## 1. 设计图规格

### 整体布局
- **排版**：三等分横向排版（3 行 × 3 列）
- **背景**：纯灰色背景（#808080）
- **画面要求**：不得出现文字和边框

### 第一层：人物三视图
| 位置 | 内容 |
|------|------|
| 左 | 正面全身（英武挺拔，充满力量感的站姿） |
| 中 | 侧面全身（宽阔肩背，英雄气概轮廓） |
| 右 | 背面全身（披风/战袍后摆，长发随风，腰间佩剑） |

### 第二层：面部特写 × 3 表情
| 位置 | 表情 | 细节描述 |
|------|------|----------|
| 左 | 坚毅刚正 | 目光深远坚定，线条刚毅的下颌，沉默的力量感 |
| 中 | 温柔回望 | 回头看向孩子们的眼神变得极其柔和，嘴角微扬 |
|右 | 决然赴死 | 闭眼或远望，表情平静如水，义无反顾的决绝 |

### 第三层：人物动作 × 3
| 位置 | 动作 | 细节描述 |
|------|------|----------|
| 英雄站姿 | 双手自然垂放两侧，脊背笔直如剑，巍峨不动 |  |
| 回头凝望 | 半转身回头，看向身后年幼的孩子，一手微伸 |  |
| 手持遗物 | 一手托举发出银光的禁忌遗物（不完全显露），逆光剪影感 |  |

---

## 2. 角色特征锚点（必须保持一致）

- 年龄：35-40 岁壮年期男子
- 体型：高大英武，**肩宽背厚**，充满力量感和英雄气概，身姿挺拔
- 发型：黑色长发，用简单发带束起，**随风飘动的动态感**
- 面部：轮廓线条刚毅分明，下颌线清晰，第1话不露正脸（悬念保留）
- 服装：**深灰色英雄战袍**——比林啸的更朴实但有战场气息，简洁实用护甲无多余装饰
- 配饰：**腰间佩剑**（剑鞘有银色纹路暗示与禁忌遗物关联）
- 特殊道具：手中可持发出银光的物件（禁忌遗物，不露全貌）
