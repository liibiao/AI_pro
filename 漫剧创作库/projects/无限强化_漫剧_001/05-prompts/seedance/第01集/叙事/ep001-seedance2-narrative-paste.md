【第 1 段：0s - 15s】

画面主体【完整：先建立末世联邦与林家练武场，再把读点稳稳落到灵纹碑石和试炼现场，让观众先感到压迫，再感到秩序。】
@Image@联邦全景 / @林家练武场 / @灵纹碑石——先给远处灰暗城市和能量屏障，再顺着视线往下落到练武场中央巨碑，第一听感是风压和屏障的低频嗡鸣。
位置关系：屏障穹顶在画面最上层包住整座城市，练武场落在画面下半区中央，灵纹碑石固定在中轴偏下作为唯一空间核心，废土与异兽剪影只留在屏障外后景。
0.0s（24fps / 高空俯瞰 / 固定起幅）：能量屏障覆盖整座灰暗城市，边缘冷蓝微光缓慢游走，屏障外荒芜废土上的异兽剪影缓慢掠过——【音效：远处低频风压 + 极弱异兽嘶吼】。
1.8s（24fps / 高空俯瞰 / 缓慢下压）：镜头沿穹顶边缘下沉，城市轮廓向后退去，建筑废墟在尘雾中若隐若现——【音效：屏障低频嗡鸣持续，风声微增强】。
3.0s（24fps / 全景 / 稳定停住）：烈日下练武场人头攒动，中央黑色巨碑稳定占据视觉中心，碑面七色灵纹缓慢流动——【音效：练武场空旷底噪 + 模糊人声】。
4.2s（24fps / 全景 / 极轻前压）：镜头把首看点锁向碑石七色灵纹，世界观在这里收束——【音效：细弱电流声浮起】。
5.0s（24fps / 中景 / 缓慢平移）：镜头从碑石向左平移，扫过练武场前排站立的林家子弟，多数人表情紧张或期待——【音效：人群低语声浮现】。
6.5s（24fps / 中景 / 继续平移）：画面扫过几个正在做热身动作的少年，有人握拳活动指关节，有人活动肩颈——【音效：关节轻响 + 布料摩擦】。
8.0s（24fps / 全景 / 稳定后拉）：镜头回到练武场全景，重新确认碑石居中、人群环绕的空间关系——【音效：练武场环境底噪回归】。
9.5s（24fps / 全景到中景 / 轻微前推）：镜头重新对准碑石方向，前排人群的背影作为前景框住碑石——【音效：心跳暗示底鼓极轻一次】。
11.0s（24fps / 中景 / 缓慢绕碑）：镜头沿碑石做半弧形慢移，碑面七色纹路在不同角度折射出不同色调——【音效：灵纹电流声随角度微变】。
12.5s（24fps / 中景 / 稳定停住）：碑石正面完整呈现，"灵纹试炼"四个暗金色大字在碑面上方若隐若现——【音效：环境底噪稳定】。
13.5s（24fps / 中景 / 极轻前压）：首看点再次锁向碑石正中，灵纹流动速度加快一拍——【音效：电流声微抬】。
14.5s（24fps / 中景 / 稳定收束）：画面在碑石与环境之间找到平衡，空间建立完成——【音效：底噪收窄，为下一段留出切点】。

环境联动：屏障边缘冷蓝微光、远处废土尘雾、练武场热浪和碑石灵纹一起完成天地双线的建立；人群热身动作带来微观动态，不让画面完全静止。

光线：整体灰暗低饱和，屏障边缘作为远景冷蓝点光；落到练武场后回到日照硬光，碑石纹路只做局部点亮。

对白配音：本段无对白配音。

音效设计：风沙、屏障嗡鸣、练武场模糊人声、碑石细弱电流声分层存在，不抢主体。

画质：4K超清，9:16，纪实克制，远景空气透视清楚，人物和碑石边缘稳定清晰。

负面提示词：屏障缺失，废土异兽缺失，练武场未出现，碑石不在中轴，空间关系混乱，画面直接跳到人物近景。

【第 2 段：0s - 15s】

画面主体【完整：把林天与林婉儿压到练武场角落，让衣角拉扯和银纹微光共同完成这段私人而克制的情绪推进。】
@Image@林天 / @林婉儿 / @林家练武场——两个人都被压在画面右侧阴影里，背景只保留模糊的人群和碑石方向，第一听感是远处练武场杂声被压低之后留下的衣料摩擦与浅呼吸。
位置关系：林天坐在右后侧石阶，身体朝向碑石方向但视线下垂；林婉儿紧贴他左侧略靠前半步，手始终抓着他的衣角；背景人群留在左侧中远景，不得穿插到两人之间。
0.0s（24fps / 中景 / 固定观察）：林天低头坐在石阶上，肩背微驼，黑发遮眼；林婉儿紧贴身侧，双手攥住他的衣角不松——【音效：远处模糊人声 + 极轻布料摩擦】。
1.8s（24fps / 中近景 / 缓慢前推）：林婉儿手指发白，衣角被拉出更深褶皱，林天闭眼不回应——【音效：布料拉扯声更清楚，林天浅呼吸】。
3.0s（24fps / 近景 / 继续微推）：林婉儿袖口滑落，手腕银色纹路冷白微光露出，刚好照亮两人下半张脸——【音效：一丝极轻电子脉冲】。
4.0s（24fps / 近景 / 稳定停住）：林婉儿眼眶发红却强忍不哭，嘴唇微张欲言又止，林天下颌收紧，沉默到底——【音效：呼吸声近收，背景杂声被压低】。
5.5s（24fps / 近景 / 极缓横移）：镜头缓缓从林婉儿脸侧移到林天侧脸，黑发下隐约露出紧闭的眼睛和微颤的睫毛——【音效：呼吸声维持，远处人声极弱】。
7.0s（24fps / 中近景 / 轻微后拉）：画面重新框住两人全身，林天的手无力地垂在膝盖上，指节微微蜷缩又松开——【音效：指节轻响】。
8.5s（24fps / 中景 / 缓慢下移）：镜头从两人中景落到林天膝盖上被拉扯变形的布料褶皱——【音效：布料受力细节声】。
10.0s（24fps / 中近景 / 回到两人上半身）：林婉儿终于开口，嘴唇翕动但没有发出声音，只有气流经过喉咙的极轻震动——【音效：无声的气音 + 呼吸停顿】。
11.5s（24fps / 近景 / 推向林天耳朵）：镜头推到林天耳侧，远处人群的欢呼声被放大传进耳朵，形成环境对比——【音效：远处模糊欢呼被拉近成闷响】。
12.8s（24fps / 近景 / 稳定）：林天手指微微攥紧，但始终没有抬头，银纹微光在林婉儿手腕上持续脉动——【音效：银纹脉冲微增】。
14.0s（24fps / 中近景 / 极轻前压）：画面回到两人中近景，林婉儿的手指再次收紧衣角，银纹光亮到最明显的一刻——【音效：布料紧绷 + 电脉冲微响】。
14.8s（24fps / 中近景 / 稳定收束）：两人的姿态定格，沉默与压抑的气氛完全成立——【音效：呼吸声收窄，为下一段切点留白】。

环境联动：远处热浪和人群活动维持模糊背景状态，银纹微光是这段里唯一主动变化的环境信号；远处偶尔传来模糊的欢呼和试炼声，与角落的沉默形成对比。

光线：角落整体压暗，环境日照被阴影吃掉，只保留极弱反射光；银纹冷白微光成为脸部唯一点光源，随脉冲节奏微变。

对白配音：本段无对白配音。

音效设计：远处练武场底噪、衣角摩擦、手指收紧、浅呼吸、银纹轻电脉冲层层递进。

画质：4K超清，人物皮肤、衣料、手指受力褶皱清楚，浅景深但角色五官不糊。

负面提示词：林天抬头反击，林婉儿大哭失控，银纹缺失，衣角未被拉紧，背景人群抢戏，光效过强盖脸。

【第 3 段：0s - 15s】

画面主体【完整：让群众嘲笑和林天隐忍形成连续压迫，用交头接耳到下颌绷紧的动作链，把"废物"被围观的羞辱感推出来。】
@Image@林天 / @林家练武场——先给嘲笑者的视线方向，再硬切林天特写，第一听感是被压低的人声窃笑和一次强行压住的深呼吸。
位置关系：两名嘲笑少年站在练武场中景偏中左，身体斜朝角落；林天处于角落右侧，被他们的视线压住；硬切后只保留林天单人特写，不再让嘲笑者进入前景。
0.0s（24fps / 中景 / 固定观察）：两名少年交头接耳，其中一人侧头斜看角落，嘴角带嘲笑——【音效：压低窃笑声 + 远处脚步踩尘】。
1.2s（24fps / 中景 / 极轻侧移）：另一人手肘轻顶同伴，示意继续看林天方向——【音效：气音式低笑】。
1.8s（24fps / 近景 / 硬切）：画面切到林天面部，闭眼不看任何人，鼻翼缓慢扩张，先把怒气压回去——【音效：背景声骤降，深吸气被拉近】。
3.0s（24fps / 特写 / 极缓推近）：镜头推到下颌线，咬肌微微隆起，后槽牙咬紧但就是不爆发——【音效：牙关轻咬 + 屏息停顿】。
4.5s（24fps / 特写 / 稳定）：林天喉结缓慢上下滚动一次，吞下愤怒——【音效：极轻吞咽声】。
5.8s（24fps / 近景 / 极轻后拉）：画面微拉，重新看到林天上半身在角落的沉默姿态——【音效：远处嘲笑声微弱回传】。
7.0s（24fps / 中景 / 缓慢回到嘲笑者）：镜头切回两名嘲笑少年，一人抬手指向角落方向，嘴型做出"废物"口型——【音效：压低但可辨认的"废物"气音】。
8.5s（24fps / 中景 / 跟随视线）：镜头随嘲笑者视线重新切向角落——【音效：视线引导的环境静默】。
9.0s（24fps / 近景 / 硬切回林天）：林天终于微睁开眼，瞳孔里映着远处碑石的模糊轮廓，但目光没有焦距——【音效：极轻睁眼呼吸】。
10.5s（24fps / 近景 / 缓推至手部）：镜头从林天脸侧下移到他放在膝盖上的拳头，指节因用力而发白——【音效：指节骨响极轻】。
12.0s（24fps / 近景 / 回到面部）：镜头重新回到林天面部，他的嘴唇抿成一条线，太阳穴微微跳动——【音效：心跳底鼓极轻】。
13.5s（24fps / 特写 / 推向下颌线）：再次推向下颌，咬肌这一次比前一次隆起更明显，但没有松开——【音效：牙关咬紧声稍重】。
14.5s（24fps / 特写 / 稳定收束）：下颌线上的咬肌隆起和太阳穴跳动同时存在，隐忍的最高点——【音效：屏息 + 心跳底鼓收窄】。

环境联动：练武场背景维持日照硬光和模糊人流；切入林天特写后，背景存在感迅速退到极低；嘲笑声与沉默特写形成双轨对比。

光线：嘲笑者处于明暗对比稍强的日照区；切到林天时只让顶侧硬光打出下颌骨线。

对白配音：本段无明确对白配音，只保留无法辨清内容的群众窃笑和气声。

音效设计：前半段是练武场底噪和近处窃笑，硬切后主动抽掉环境声，只留下深呼吸、咬牙、屏息这些状态音。

画质：4K超清，特写边缘稳定，下颌线和咬肌细节必须可读。

负面提示词：嘲笑者正面抢主角，林天失控大吼，特写没有下颌绷紧结果，背景声一直很吵。

【第 4 段：0s - 15s】

画面主体【完整：用暗色回忆插入父亲背影和禁忌遗物，让林天的压抑情绪获得宿命来源，并把遗物银光钉成悬念。】
@Image@林天 / @林婉儿 / @禁忌遗物——父亲背影站在家族大门前，幼年兄妹在后，银白遗物是唯一亮点，第一听感是空旷风声和极轻能量脉冲。
位置关系：父亲背对镜头立于最前方目标点，幼年林天与幼年林婉儿站在他身后偏右下方；遗物在父亲右手侧形成唯一光源，兄妹不能越过父亲站到前景中心。
0.0s（24fps / 中景 / 闪切进入后固定）：父亲背对镜头站在家族大门前，衣摆被微风轻拂，右手垂着发出银白柔光的物件——【音效：空旷风声 + 轻微能量脉冲】。
1.5s（24fps / 中景 / 极慢后拉）：幼年林天和幼年林婉儿站在后方，林天仰头盯着父亲背影，林婉儿抓住他的手臂不放——【音效：孩童衣料摩擦】。
2.6s（24fps / 中远景 / 继续后拉）：遗物银光在地面拉出细光带，三人距离被拉开，回忆感越退越远——【音效：风声拉长，能量脉冲变弱】。
3.5s（24fps / 中远景 / 收束停住）：边缘暗角加深，父亲与遗物一同沉入暗色回忆——【音效：余音收窄】。
5.0s（24fps / 中景 / 缓慢前推回到父亲背影）：衣摆上的家族纹饰在银光下若隐若现——【音效：风声微回，脉冲声微起】。
6.5s（24fps / 特写 / 推向右手遗物）：遗物表面纹路在银光下缓慢旋转，内部能量像被封装在晶体里——【音效：能量脉冲节奏变清晰】。
8.0s（24fps / 特写 / 稳定）：遗物银光达到最强的一刻，短暂照亮父亲侧脸轮廓和肩膀线条——【音效：脉冲到达峰值】。
9.5s（24fps / 中景 / 后拉）：镜头后拉，幼年林天的眼神被银光照亮，瞳孔里映出遗物轮廓——【音效：能量脉冲微降，保持稳定】。
11.0s（24fps / 中景 / 轻微横移）：画面从林天移到林婉儿，她也盯着遗物，但表情是恐惧而非好奇——【音效：风声微增强，暗示不安】。
12.5s（24fps / 中远景 / 缓慢后拉）：三人再次被拉开，这次遗物银光开始不稳定地闪烁——【音效：脉冲变得不规律】。
13.5s（24fps / 中远景 / 暗角加深）：银光最终收窄成一点，父亲转身动作的模糊影子在暗角中一闪——【音效：脉冲骤缩成一记短促低频】。
14.5s（24fps / 中远景 / 收束停住）：画面完全沉入暗色回忆，只留下地面光带残余——【音效：余音收窄至极轻，为切出回忆留白】。

环境联动：回忆空间里没有多余人群和动态，只保留风与银光；地面细光带作为过去与现在的连接线；银光闪烁暗示遗物的不稳定性。

光线：整体低饱和深褐暗调，唯一有效光源是禁忌遗物的银白柔光。

对白配音：旁白（低沉克制）："他的父亲，林战……自从留下那件禁忌遗物后，便失踪了。"

音效设计：空旷风声为底，遗物补一层柔和能量脉冲，中段到达峰值后变得不稳定，人物不加夸张动作声。

画质：4K超清，回忆滤镜克制，黑位干净，银光不过曝。

负面提示词：回忆色调过亮，父亲转正脸抢信息，遗物不发光，兄妹不存在，画面变成现实主线色调。
