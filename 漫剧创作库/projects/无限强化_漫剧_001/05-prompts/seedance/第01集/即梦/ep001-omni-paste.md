【第 1 段：0s - 10s】

画面主体【完整：先建立末世联邦与林家练武场，再把首看点落到灵纹碑石与试炼现场。】
@Image@联邦全景 / @林家练武场 / @灵纹碑石——先远后近，屏障穹顶罩住灰暗城市，练武场落在画面下半区，第一听感是远处低频风压与屏障嗡鸣。
位置关系：屏障穹顶在最上层包住整座城市；练武场在下半区中央；灵纹碑石固定在中轴偏下；废土与异兽剪影只留在屏障外后景，不得前压到练武场前景。
0.0s（24fps / 高空俯瞰 / 固定起幅）：屏障覆盖灰暗城市，边缘冷蓝微光游走，废土异兽剪影缓慢掠过——【音效：低频风压 + 极弱异兽嘶吼】。
1.8s（24fps / 高空俯瞰 / 缓慢下压）：镜头沿穹顶边缘下沉，城市后退，练武场从尘雾里显形——【音效：屏障嗡鸣持续】。
3.0s（24fps / 全景 / 稳定停住）：烈日下练武场人头攒动，中央黑色巨碑稳定占据视觉中心，碑面七色灵纹缓慢流动——【音效：练武场空旷底噪】。
4.2s（24fps / 全景 / 极轻前压）：首看点锁向碑石七色灵纹——【音效：细弱电流声】。
5.0s（24fps / 中景 / 缓慢平移）：镜头从碑石向左平移，扫过练武场前排林家子弟，多数人表情紧张或期待——【音效：人群低语浮现】。
6.5s（24fps / 中景 / 继续平移）：画面扫过几个正在热身的少年，有人握拳活动指关节——【音效：关节轻响 + 布料摩擦】。
8.0s（24fps / 全景 / 后拉回到碑石全景）：镜头回到全景，重新确认碑石居中、人群环绕的空间关系——【音效：底噪稳定】。
9.5s（24fps / 全景 / 收束）：空间建立完成，为首看点留出切点——【音效：底噪收窄】。
环境联动：屏障冷蓝微光、废土尘雾、练武场热浪和碑石灵纹共同建立天地双线。
光线：整体灰暗低饱和，屏障是远景冷蓝点光；落到练武场后回到日照硬光。
对白配音：本段无对白配音。
音效设计：风沙、屏障嗡鸣、练武场模糊人声、碑石细弱电流声。
画质：4K超清，9:16，纪实克制，远景空气透视清楚，人物与碑石边缘稳定清晰。
负面提示词：屏障缺失，废土异兽缺失，练武场未出现，碑石不在中心，空间关系混乱，直接跳人物近景。

对白配音：本段无对白配音。

对白配音：本段无明确对白配音，只保留无法辨清内容的群众窃笑和气声。

9.5s（24fps / 中远景 / 收束）：银光最终收窄成一点，画面沉入暗色回忆——【音效：脉冲骤缩成一记短促低频，为切出回忆留白】。

音效设计：空旷风声为底；遗物补一层柔和能量脉冲；人物不加夸张动作声。
