# 仙侠高空追逐 15s 正式流水线稿 v2

【生成任务】
生成一段 15 秒多镜头衔接的仙侠高空追逐动作戏。影片类型为双人飞行斗法追杀。节奏不是“起势 → 推进 → 爆点 → 收势”，而是冷开场截杀、追逃接力、连续失重和坠入古街的空间穿越。音频要求：不生成背景音乐，只保留云层破开、飞剑破风、符箓燃爆、环刃切云、衣袂急响、瓦片炸裂和近身擦杀音效。

【主要主体】
@青霄剑修陆沉舟：年轻成年男性修士，青白长袍，袖口有银色云纹，黑发高束，踩青玉飞剑高速贴云疾飞；武器为半透明青玉飞剑，身后拖出淡青色剑痕。
@赤羽魔修洛绯：年轻成年女性修士，绯红黑金轻甲长裙，赤羽发饰，动作狠辣，擅长贴身瞬杀；武器为一对赤羽环刃，可旋成红色月弧，也可收束成细红杀线。
@云海高空：夜色云海上方，远处能从云隙看见古城屋脊和群山黑影。
@古街屋脊：段落末尾落入的古城屋脊空间，青瓦、飞檐、灯火和瓦片是下一段衔接锚点。

【场景与环境状态】
基础空间：云海上方的高空追逐路线，起点在被剑气切开的云层裂口内，终点是两人穿破云层后坠向古街屋脊。
表层可视细节：云层被剑气切出长缝，飞剑留下淡青拖尾，赤羽环刃留下红色月弧，远处古城屋脊和山影在云隙间忽隐忽现，段尾出现被风压掀起的青瓦。
隐性叙事氛围：这一段不是普通追逐，而是洛绯已经把陆沉舟逼到古城上空的截杀局；观众从第一秒就要感觉“已经差半寸就会被杀”，中段才看清两人如何用飞行轨迹互相骗招。

【情绪目标】
整体基调：凌厉、失重、贴身危险、仙侠唯美中的杀意。
情绪递进：开场直接进入命中边缘 → 中段由追逐变成贴身截杀 → 后段用垂直坠落制造失重反转 → 结尾不是收势，而是坠入下一场古街近身战。

【视觉风格】
1. 画面基调：HZW 材质画质风格 + 国风唯美 + 高级动漫电影质感。画面重点不是单纯大光效，而是飞剑轨迹、环刃切线、云层空间和人物身体姿态的可读性。
2. 光线与色彩：冷月蓝作为云海环境底色，陆沉舟的青玉飞剑为淡青高亮，洛绯的赤羽环刃为赤红高亮。红青光只做轨迹和危险提示，不能盖住脸、手和武器。
3. 画面质感：云气有体积和层次，飞剑玉质半透明，环刃金属与赤羽火纹清晰，人物边缘锐利。高速段允许背景拉伸模糊，但脸、飞剑、环刃、符箓爆点和瓦片结果帧必须清楚。

【分段镜头脚本】

|---|---|---|
| 0-3s | 画面不从风景建立开始，而是从一片被剑气横切的云层裂口里突然冲出。镜头贴在青玉飞剑前端做 FPV，云气擦过镜头边缘，远处古城屋脊和山影在云隙里闪一下又被云吞掉。@青霄剑修陆沉舟侧身回头，袖口一抖，三张青色符箓逆风甩出，在镜头前方炸成细碎光阵；这一秒已经像在躲一记追到后心的杀招。 | 跟随对象：飞剑前端与陆沉舟回头动作；运动路线：从云层裂口冲出并贴云前飞；空间解释：云隙短暂露出古城和山影，说明高空位置与下坠目标；关系变化：陆沉舟不是起势，而是已经在逃杀边缘；停顿点：符箓爆开时短停 0.2s；收尾信息变化：观众知道身后杀招已经逼近。 |

| 7-11s | 陆沉舟没有反击，他突然让飞剑下沉，整个人几乎倒挂贴住剑身，身体和飞剑一起从云层边缘坠下。镜头跟着他做一次垂直翻滚，天空、云海、古城屋檐倒转一圈，红线从他头顶擦过去，把一片云削成上下两层。翻滚结束时，镜头只给他眼神一瞬，他不是慌乱，而是在借下坠把洛绯的杀线带偏。 | 跟随对象：陆沉舟和下沉飞剑；运动路线：水平飞行突然转为垂直坠落；空间解释：翻滚中让天空、云海、古城倒置，强化失重方向；关系变化：陆沉舟从被截杀变成用坠落骗招；停顿点：红线擦过头顶后，眼神停 0.2s；收尾信息变化：洛绯的第一记瞬杀落空，但追逐被带向古街。 |
| 11-15s | 两人一前一后冲破最后一层云，坠向古街屋脊。镜头从 FPV 突然切到贴地仰拍，先看见青瓦被高空风压掀起，再看见两道身影像流星压下来。陆沉舟脚尖擦过屋脊，瓦片成排炸开；洛绯的赤羽环刃紧贴他身后扫过，红色残影几乎贴到他的肩背。最后一帧停在屋脊瓦片飞散、红刃差半寸命中的瞬间，直接切下一段古街穿巷，不做收势。 | 跟随对象：屋脊落点与两人坠落轨迹；运动路线：高空垂直坠入古街屋脊；空间解释：贴地仰拍把下一场空间提前建立；关系变化：高空追逃转为地面屋脊近身追杀；停顿点：红刃差半寸命中时短停；收尾信息变化：段落没有结束战斗，而是把危险带进古街。 |

环境联动
云层被飞剑和环刃切出清晰层次，符箓爆开时碎光被高速气流向后拉散；7-11s 红线削开云层后，上下云面短暂分离；11-15s 高空风压先掀起古街青瓦，随后瓦片随陆沉舟脚尖擦过成排炸开。

光线
冷月蓝云海光贯穿全段，陆沉舟的青玉飞剑提供淡青轨迹光，洛绯的赤羽环刃提供赤红危险线。符箓爆开和红线切云时可以短促闪光，但人物脸部、手部、飞剑和环刃边缘必须保持清晰。

对白配音
本段无对白配音。只保留陆沉舟短促吸气、洛绯压低的发力气口，以及高速坠落时被风切碎的衣袂声。

音效设计
环境层：高空风声、云层被切开的低频撕裂声、远处古城夜风。动作层：飞剑破风、衣摆急响、符箓燃爆、赤羽环刃切光、红线擦身。爆点层：云层被红线削开的瞬间抽声，瓦片被风压掀起和脚尖擦碎的连续脆裂声。

画质
HZW 材质画质风格，国风唯美仙侠动画电影质感。高速 FPV 和垂直翻滚时背景可产生方向性拉伸模糊，但人物脸、眼神、飞剑、环刃、符箓爆点、瓦片结果帧必须清晰可读。运动轨迹要干净，红青光效不能吞掉主体。

负面提示词
低画质，模糊，人物变脸，服装跳变，武器消失，随机新增角色，多余肢体，手指畸形，空间方向混乱，飞行速度像漂浮，镜头无重量感，动作节奏机械套模板，光效遮住脸，全屏光污染，云层糊成白雾，古街突然变现代城市，红线命中点不可读，瓦片结果帧不可读，字幕，水印。
