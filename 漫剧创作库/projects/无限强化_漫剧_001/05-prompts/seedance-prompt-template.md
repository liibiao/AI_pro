## Shot 1..N
【时间段】
【运镜】（必须绑定心理动机：施压/疏离/焦虑/崩塌/宿命等）
【镜头参数】焦段/景深/机位倾向（用于稳定脸与空间关系）
【几何约束】地平线/眼线/roll/消失点稳定（同空间不漂；禁止跳轴）
【画面】只写动态变化、受力反馈、结果兑现；不重复参考图静态事实
【配音】音色/说话状态/语速/情绪/停顿/气口（独立项，不写进【画面】）
【表演】微表情/呼吸/眼神落点/受力反应（可读、克制）
【参考】（只写 @资产名；职责清晰：形象/空间/道具各归一处，避免抢权）
【位置关系】前/中/后景，左/右，距离，视线落点，命中点；群戏需分组锁定与坐标禁入区
【读点保护】首看点坐标化，禁止遮挡，禁止侵入字幕安全区
【音效】环境底噪/拟音/特效音/状态音/BGM/混音（按情绪曲线设计，配音优先）
【风格】主光方向与调色一致；字幕安全区与负空间构图
【转场】硬切/叠化/闪切/定格/Match Cut（群戏建议“群演循环不变，只切主角反应”）

### （武戏可选增强）时间轴微雕

当 Shot 为打戏/快切/物理交互时，建议在 Shot 内补充 2-4 个时间戳子节拍（而不是写小作文）：

```text
[0.0-0.8s] 全景定场：两人相距 8–10m，低视角，剪影清晰。
[0.8-1.6s] 起手式：角色A slash，角色B sidestep；机位 snap-pan。
[1.6-2.4s] 物理交互：Parry → bind → shove-off；sparks / splash。
```

并在全局约束中添加：

```text
motion blur on BACKGROUND ONLY (characters and weapons stay crisp), sharp shadows
```

| 参数 | 值 |
|------|-----|
| 画面比例 | 9:16 / 16:9 |
| 总时长 | 15秒（N镜头） |
| 模式 | 全部 I2V（参考图→视频） |
| 转场 | 叠化 / 闪切 / 硬切 / 首尾帧桥接 |
| 配乐走向 | Shot1噪音 → Shot2骤静 → Shot3高潮 → Shot4收束 |

## 使用说明
- 修改时只改【画面】中的动态描述和【运镜】，静态内容由参考图决定无需重复
- 多素材必须写清职责，避免冲突：形象/动作/运镜/节奏各归一处
```

## 负面提醒
- 不要在一条提示词里塞多个主体和多个高潮
- 不要堆砌 3 个以上互相冲突的风格词
- 不要只写“电影感”“高级感”“氛围感”而没有视觉支撑
- 不要让动作只有结果，没有过程
- 不要让多个素材争夺同一控制权却不说明职责
