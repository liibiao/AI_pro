# 场景设计 — 家主大殿

## 基本信息
- 场景名：家主大殿
- 出现话数：第 1 话（闪回·场景 1-4、1-5、1-6）
- 功能：展现家族权力结构，林啸篡权、强娶婚约的场所

## 空间描述
- 室内，宽敞但压抑的大殿
- 正中高台上设家主位（雕花木椅，扶手有家族徽记）
- 大殿两侧立柱，柱上有古老纹饰
- 地面深色石板，铺有暗红色长毯
- 光线从高处窗口斜射入内，形成明暗对比
- 殿内阴暗，只有家主位附近有光

## 视觉要素
| 要素 | 描述 |
|------|------|
| 家主位 | 高台上的雕花大椅，暗金色装饰 |
| 立柱 | 粗壮石柱，刻有家族纹饰 |
| 地面 | 深色石板 + 暗红长毯 |
| 光线 | 高窗斜射光，明暗强烈 |
| 氛围 | 压抑、威严、权力不对等 |
| 道具 | 家主令牌、婚约红纸（场景 1-5） |

## 色调
- 主色：深红、黑金
- 辅色：暗紫
- 氛围：压抑权力感，居高临下的不对等

## 生图提示词方向（中文）
末世古风家族大殿内部，高台上的雕花家主位，暗金装饰，两侧粗壮石柱，深色石板地面铺暗红长毯，高窗斜射光线明暗对比强烈，压抑威严氛围
