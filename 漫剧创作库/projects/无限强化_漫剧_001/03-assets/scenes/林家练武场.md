# 场景设计 — 林家练武场

## 基本信息
- 场景名：林家练武场
- 出现话数：第 1-5 话（核心场景）
- 功能：测灵纹大会主场地，全部前 5 话的主战场

## 空间描述
- 开阔的露天练武场，地面为灰色石板
- 四周有石柱围栏和看台
- 中央矗立三丈高的灵纹碑石
- 烈日当空，但整体氛围压抑
- 远处可见能量屏障穹顶的弧线

## 视觉要素
| 要素 | 描述 |
|------|------|
| 地面 | 灰色石板，有裂纹和战斗痕迹 |
| 碑石 | 黑色发亮，三丈高，灵纹盘绕，七色光芒游走 |
| 看台 | 石质阶梯，长老席在最高处 |
| 石柱 | 粗壮石柱，有古老纹路（林天被撞飞的目标） |
| 天空 | 烈日 + 远处隐约的屏障弧线 |
| 人群 | 密集围观，各种年龄的族人 |

## 色调
- 主色：灰褐、土黄
- 辅色：碑石蓝黑、灵纹七色
- 氛围：烈日下的压抑感

## 生图提示词方向（中文）
末世古风练武场，灰色石板地面，中央矗立黑色巨碑，碑面灵纹光芒游走，四周石柱看台，人群围观，烈日当空，远处能量屏障穹顶，压抑庄严氛围
