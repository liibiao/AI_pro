# 道具设计 — 系统 UI 面板

## 基本信息
- 名称：无限强化系统 UI 面板
- 功能：林天专属系统界面，显示数值、任务、激活选项
- 出现话数：第 4 话起

## 设计方向
- 风格：半透明 HUD，科技感 + 玄幻感混合
- 配色：金色边框 + 黑底半透明 + 白色/金色文字
- 出现方式：浮在画面上层，不遮挡角色主体
- 位置：通常在角色侧方或上方

## 视觉表现
| 状态 | 表现 |
|------|------|
| 首次出现 | 从虚空中凝聚，金色粒子汇聚成面板 |
| 数值变化 | 数字快速跳动，金光闪烁 |
| 激活瞬间 | 面板炸裂成金色光粒，融入身体 |
| 日常查看 | 半透明悬浮，安静显示 |
