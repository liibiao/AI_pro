# 角色设计 — 林傲天

## 基本信息
- 姓名：林傲天
- 年龄：18-19 岁
- 身份：林啸之子，林家年轻一代第一天才
- 灵纹：A 级·元素系·雷霆灵纹
- 戏剧功能：第一阶段反派 + 第一个被打脸的人

## 外观设计

### 体型
- 高大健壮，比林天高一头
- 体格强壮，肌肉线条明显
- 站姿傲慢，下巴微抬

### 面部
- 五官英俊但带傲慢
- 嘴角常挂冷笑
- 眼神居高临下

### 发型
- 短发，利落，偏深色
- 发型整齐（与林天的凌乱形成对比）

### 服装
- **金纹战甲**：标志性装备
  - 深色底甲 + 金色灵纹纹路
  - 肩甲、护臂有金色雷纹装饰
  - 整体给人"家族精英"的感觉
- 日常：高级练功服，深色系

### 特效 (遵循《后期美学与动作规范》)
- 灵纹觉醒时全身雷光缠绕，**必须伴随光源绑定互动 (Interactive Lighting)，雷光照亮脸部和铠甲**。
- 紫色电弧从指尖和甲面飞溅，**周围空气产生热畸变 (Heat Distortion)**。
- 攻击时雷霆轰鸣，**伴随强烈的后坐力，衣摆与周围环境受到物理冲击**。

## 表情与动作库 (遵循《文戏与权力调度规范》)
| 情绪 | 表现 |
|------|------|
| 日常 (高位) | 傲慢冷笑、下巴微抬，支点动作：慢条斯理整理袖口 |
| 挑衅 (施压) | 视线死死盯住对方 (Unblinking stare)，制造心理屏障 |
| 踩人 (爆发) | 居高临下俯视，利用体型差形成上压下构图 |
| 被反压 (失控) | 瞳孔收缩、脸色大变，下颌线绷紧却止不住颤抖 |
| 恐惧 (溃败) | 下意识后退半步，物理受力失衡，冷汗 |
