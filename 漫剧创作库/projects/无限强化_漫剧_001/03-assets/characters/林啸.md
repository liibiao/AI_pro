# 角色设计 — 林啸

## 基本信息
- 姓名：林啸
- 年龄：40-45 岁
- 身份：林天之叔，篡权掌家者，林傲天之父
- 戏剧功能：幕后反派 / 家族掌权者 / 中期主要对手
- 首次出场：第 1 话（闪回·场景 1-4、1-5、1-6）

## 外观设计

### 体型
- 中等偏高，身材匀称
- 气质威严，不怒自威
- 站姿沉稳，双手常背于身后

### 面部
- 面容阴鸷，颧骨略高
- 眼神深沉锐利，透着算计
- 嘴角常微微下压，不怒自威
- 眉间有竖纹，显示长年城府

### 发型
- 深色长发束于脑后，整齐利落
- 鬓角有少许银丝（权力与年龄的暗示）

### 服装
- **家主袍服**：深色（近黑）长袍，暗纹绣有家族徽记
- 腰间系金色腰带，悬挂家主令牌
- 肩部有暗金色纹饰，象征权力地位
- 整体配色：深色系为主，暗金点缀

## 表情库
| 情绪 | 表现 |
|------|------|
| 日常 | 面无表情，眼神审视 |
| 冷漠 | 居高临下，嘴角微撇 |
| 算计 | 眼神微眯，嘴角隐约上扬 |
| 威压 | 眉头紧锁，目光如刀 |
| 满意 | 微微颔首，眼中闪过精光 |
