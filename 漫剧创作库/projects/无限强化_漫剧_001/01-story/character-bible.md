# 角色设定 — character-bible

## 项目定位
- 类型：漫剧（竖屏条漫 / 横屏分格均可）
- 核心题材：末世玄幻 / 废材逆袭 / 系统流 / 热血战斗
- 核心冲突：被家族踩在脚下的"废物"少年，在妹妹即将被强娶的绝境中觉醒无限强化系统，开始逆袭碾压之路
- 爽点机制：受辱压制 → 绝境觉醒 → 系统激活 → 力量碾压 → 当众打脸 → 持续升级

---

## 主要角色

### 林天（男主）
- **原型**：隐忍爆发型 / 废材逆袭型
- **年龄**：约 17-18 岁
- **外观标签**：
  - 瘦削但骨架不小（暗示潜力）
  - 黑发微乱，额前碎发遮眼
  - 初期穿旧布衣、打补丁练功服
  - 觉醒后：眼瞳泛金光、身体线条变硬朗、气场骤变
  - 手腕有银色纹路（与妹妹呼应，暗示禁忌遗物关联）
- **核心性格**：
  - 表面沉默隐忍，内心极度倔强
  - 对妹妹有绝对守护本能
  - 被逼到极限时爆发力惊人
  - 觉醒后冷静、果断、带压迫感
- **成长弧光**：
  - 第一话：被踩在脚下的废物 → 觉醒系统 → "换你，跪下"
  - 中期：从被动防守 → 主动出击 → 掌控局势
  - 长线：追查父亲真相 → 揭开禁忌遗物秘密 → 走出墙外
- **视觉重点**：
  - 觉醒前：低头、缩肩、眼神暗淡
  - 觉醒后：挺直脊背、眼神冷光、空气扭曲涟漪
  - 关键画面：被踩脸 → 缓缓站起 → 冷笑 → "换你，跪下"
- **战斗风格**：强化系 — 纯粹力量碾压，拳拳到肉，不花哨但极具冲击力

---

### 林婉儿（妹妹 / 核心守护对象）
- **原型**：柔弱但坚韧型
- **年龄**：约 15-16 岁
- **外观标签**：
  - 清秀面容，大眼睛，带泪光时极具感染力
  - 长发，偏柔和的浅色系
  - 手腕有与林天相似的银色纹路（关键线索）
  - 衣着朴素但干净
- **核心性格**：
  - 善良、依赖哥哥、但不是纯花瓶
  - 内心有韧性，关键时刻会拼命挣扎
  - 银色纹路暗示她可能有隐藏能力
- **戏剧功能**：
  - 第一话的情感锚点（观众共情入口）
  - 林天战斗的核心动机
  - 禁忌遗物的关键线索载体
- **视觉重点**：
  - 拉着哥哥衣角、哭着挣扎、尖叫"哥！！！"
  - 手腕银色纹路特写

---

### 林傲天（第一阶段反派）
- **原型**：骄横跋扈型 / 天才压制型
- **年龄**：约 18-19 岁
- **外观标签**：
  - 高大健壮，面容英俊但带傲慢
  - 金纹战甲（家族地位象征）
  - 雷霆灵纹觉醒后全身雷光缠绕
- **核心性格**：
  - 极度自负，享受踩人的快感
  - 对弱者毫无怜悯
  - 本质是靠家族权势撑腰的二代
  - 面对真正强者时会怯懦
- **戏剧功能**：
  - 第一话的压制源 + 打脸对象
  - "踩脸"名场面的施加者
  - 林天觉醒后第一个被碾压的人
- **视觉重点**：
  - 金纹战甲 + 雷光特效
  - 踩脸的残忍画面
  - 被林天反压时的惊恐表情
- **灵纹**：A级·元素系·雷霆灵纹

---

### 林啸（幕后反派 / 家族掌权者）
- **原型**：权谋掌控型
- **外观标签**：
  - 中年，威严面容
  - 深色家主袍服
  - 眼神阴鸷
- **核心性格**：
  - 城府深、手段狠
  - 表面维护家族秩序，实际觊觎禁忌遗物
  - 对林天兄妹的迫害是有计划的
- **戏剧功能**：
  - 林傲天背后的真正推手
  - 强娶林婉儿的决策者
  - 中期主要对手

---

### 林战（父亲 / 悬念线索）
- **原型**：缺席的英雄型
- **核心功能**：
  - 曾经的家族英雄，留下"禁忌遗物"后失踪
  - 是林天兄妹银色纹路的来源
  - 长线悬念：他去了哪里？禁忌遗物是什么？为什么失踪？
- **戏剧功能**：
  - 提供长线追查动力
  - 暗示墙外世界的秘密
  - 后期可能回归或留下关键线索

## 世界观核心设定

### 灾变与联邦
- 灵力复苏导致旧世界文明断层
- 人类退守七大联邦，用能量屏障封城
- "墙内"安全但等级森严，"墙外"是废土与异兽横行的乱区

### 灵纹体系
灵纹是灾变后人类觉醒的超能力标记，通过碑石测试激活。

| 灵纹系别 | 说明 | 地位 |
|----------|------|------|
| 元素系 | 雷、火、冰、风等 | 公认最强之一 |
| 属性系 | 超越元素的高阶能力 | 最顶级 |
| 具化系 | 实体化武器/工具 | 中上 |
| 精神系 | 精神控制/感知 | 特殊 |
| 动物系 | 获得动物特性 | 中等（斥候型） |
| 治疗系 | 治愈能力 | 稀缺宝贵 |
| 强化系 | 强化身体素质 | 公认最差（但林天的系统打破这个认知） |

### 无限强化系统
- 绑定林天的金手指
- 核心能力：无限叠加力量点数
- 新手礼包：+300 力量（直接从练体境二重冲到聚灵境巅峰）
- 后续机制：任务、战斗、突破均可获得强化点
- 核心反差：公认最差的强化系 × 无限叠加 = 最恐怖的存在

## 人物关系图

```
林战（父·失踪）
  ├── 林天（男主·废物 → 觉醒）
  └── 林婉儿（妹·银色纹路·被强娶）

林啸（叔·篡权掌家）
  └── 林傲天（子·A级天才·第一反派）

禁忌遗物 ← 林战留下 ← 银色纹路（林天+林婉儿共有）
无限强化系统 ← 绑定林天 ← 来源未知（可能与禁忌遗物有关）
```

## 第一话目标
1. 开场即建立压制场面（测灵纹 + 嘲笑）
2. 让观众快速共情林天的绝境（妹妹被抢、当众羞辱、被踩脸）
3. 给出系统觉醒的爆发高潮
4. 结尾必须形成"他要怎么碾压回去"的强钩子
5. 名场面锁定：**被踩脸 → 缓缓站起 → "换你，跪下"**
