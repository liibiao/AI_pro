# Logline — 一句话剧情

## 核心 Logline

灾变后的末世联邦中，被家族当作废物踩在脚下的少年林天，在妹妹即将被强娶、自己被当众羞辱的绝境下，觉醒了"无限强化系统"，必须在家族权力倾轧中一路逆袭碾压，否则妹妹和父亲留下的秘密都将被彻底吞噬。

## Logline 公式拆解

| 要素 | 内容 |
|------|------|
| 主角 | 林天 — 被家族遗弃的"废物"少年 |
| 困境 | 父亲失踪、家族权力洗牌、沦为最底层 |
| 重大冲突 | 妹妹被强娶、当众测试被羞辱、被踩在脚下 |
| 必须完成的目标 | 觉醒系统、逆袭翻盘、保护妹妹、追查父亲真相 |
| 否则失去什么 | 妹妹被夺走、禁忌遗物秘密暴露、彻底被逐出家族 |

## 题材标签
`末世玄幻` `废材逆袭` `系统流` `家族权斗` `热血战斗` `守护妹妹`

## 爽点机制
**受辱压制 → 绝境觉醒 → 系统激活 → 力量碾压 → 当众打脸 → 持续升级**

## 改编判断
- **适合漫剧**：视觉冲击强（灵纹光效、碑石测试、力量爆发）、冲突密集、人设标签鲜明、天然分话结构
- **核心卖点**：废物翻盘 + 系统升级 + 守护妹妹 + 打脸爽感
- **风格定位**：国漫热血 + 末世暗色调 + 灵纹光效 + 日漫动作分镜
