# Style Guide — 全局视觉风格规范

## 目标
确保同一项目中人物、场景、道具、光影、镜头语言保持统一，避免 AI 生成风格漂移。

> **题材适配**：不同题材（仙侠、武侠、都市、赛博朋克）对"统一"的定义不同。详见 `docs/genre-visual-playbook.md` 获取题材专属视觉参数包（色调盘、光影模式、必须元素、禁止元素）。

---

## 1. 人物风格统一

### 必填项
- 年龄段
- 发型
- 脸型
- 眼神气质
- 服装主色
- 身体比例
- 标志性特征（疤痕/耳饰/纹身/眼镜）

### 建议做法
- 每个角色都建立 `face-prompt.md` 和 `three-view-prompt.md`
- 每次换装单独建变体，不覆盖原始版本
- 主角与反派优先固定视觉锚点

## 2. 场景风格统一

### 必填项
- 主色调
- 光源方向
- 空间感
- 材质关键词
- 时间段（日/夜/黄昏）

### 建议做法
- 每个关键场景做宫格图参考
- 同一场景拆分日景/夜景版本
- 用 `scene-index.md` 管理 @引用

## 3. 道具风格统一

- 关键道具必须有独立描述
- 关键细节不能丢：刻字、裂痕、材质、颜色
- 道具状态变化要记录（完好/破损/染血/缺角）

## 4. 镜头风格统一

### 推荐统一项
- 运镜节奏：固定/推镜/拉镜/跟拍
- 剪辑风格：慢切/中速/快切
- 景别偏好：近景多还是中景多
- 画幅比例：16:9 / 9:16

## 5. 光影统一

| 类型 | 建议 |
|------|------|
| 都市现实 | 冷白硬光，略去饱和 |
| 古风情感 | 暖黄侧光，层次柔和 |
| 灵异惊悚 | 昏黄烛光 + 阴影浓重 |
| 热血动作 | 高反差硬光，强调力量感 |
| 仙侠/武侠 | 丁达尔体积光 + 冷调通透 / 硬光高反差（详见 `genre-visual-playbook.md` §3-4） |

## 6. 漫剧附加规范

漫剧比短剧更依赖静帧统一性，因此要特别注意：
- 角色脸不能频繁变化
- 背景不要每格都重做
- 同一话的色彩脚本先统一再生成
- 镜头感可以强，但不要丢阅读顺序

## 7. HZW大师风格专项

> 统一专项规范：`docs/hzw-master-style-system.md`

当项目声明使用 **HZW大师风格** 时，必须把它作为整部短剧 / 漫剧的视觉操作系统，而不是单个风格词。生图、场景、分镜、视频提示词都必须继承同一套角色锚点、场景锚点、光影锚点、色彩锚点和镜头锚点。

### 强制执行
- 生图提示词必须标注 `HZW大师风格`，并写清第一读点、主体锚点、前中后景、光影色彩、材质和禁止项。
- 场景提示词必须写清空间结构、主材质、光源方向、可拍摄站位区和结果镜头落点。
- 分镜必须按“建立镜头 → 推进镜头 → 爆点镜头 → 结果镜头 → 转场镜头”组织镜头组。
- 视频提示词必须从分镜母稿派生，保留 `环境联动 / 光线 / 对白配音 / 音效设计 / 画质 / 负面提示词` 固定段名。
- 后续吸收 HZW 学习资料时，先提炼方法论和模板，再同步回填 skill、workflow、phase gate 与 pipeline sync log。

## 8. 小白避坑

- 不要同时混三种画风
- 不要今天写实、明天二次元、后天油画风
- 先把主角和 2 个场景固定，再扩展世界观
- 一致性优先于“每张都惊艳”
- 使用 HZW大师风格时，不要只写风格名，必须补齐五类锚点和平台执行字段
