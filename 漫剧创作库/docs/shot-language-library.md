# shot-language-library — 镜头语言参考库

## 用途
给导演、分镜师、提示词工程师统一一套可复用的镜头语言速查表，避免跨项目镜头描述不一致。

## 镜头分类

### 景别
- 特写：强调情绪、关键道具、眼神变化
- 近景：突出人物动作与表情
- 中景：适合双人对话、身体动作展示
- 全景：交代人物与环境关系
- 远景：建立世界观、压迫感或群像规模

### 机位
- 平视：客观、日常、平衡
- 仰拍：强化压迫、权威、英雄感
- 俯拍：体现脆弱、渺小、受控
- 侧拍：适合动作链、对峙、关系张力
- 背拍：制造悬念、孤独感、离场感

### 运动
- 推镜：聚焦信息、强化情绪逼近
- 拉镜：揭示环境、制造距离感
- 横移：展示空间、跟随人物移动
- 跟拍：强化代入感与速度感
- 环绕：突出情绪高潮、关系对冲、力量释放
- 手持抖动：制造失控、危险、临场混乱

## 常见场景镜头公式

### 对峙戏
建立远景 → 双人中近景对切 → 手部或眼神特写 → 爆发动作特写

### 情绪戏
环境空镜 → 人物半身停顿 → 眼神/嘴角/手指微动作特写 → 缓慢推近

### 动作戏
空间建立 → 起手动作中景 → 受击/闪避局部特写 → 连招跟拍 → 收势定格

### FPV 穿越戏
建立入口/出口空间 → 第一人称高速前冲 → 擦身穿过障碍或缝隙 → 穿出后立刻揭示新空间/新威胁/新目标

**推荐写法**：
`[广角 / 第一人称] 主体视角锁定穿越目标 + 高速前冲 / 俯冲 / 贴壁掠过 + 穿过门窗/缝隙/桥洞/管道 + 边缘动态模糊 / 轻微震颤 / 广角畸变 + 穿出后揭示结果信息`

**示例**：
`广角第一人称视角，镜头贴着废墟断梁高速前冲，擦身穿过两根倾斜钢柱之间的狭窄裂口，边缘动态模糊和轻微镜头震颤持续成立，穿出后正面揭示前方坠落中的主角与下方翻涌火海。`

#### FPV 镜头包（推荐默认拆法）
- **入口建立镜头**：先交代要钻入的洞口、裂缝、桥洞、走廊、峡谷、赛道或落点
- **穿越动作镜头**：镜头贴着障碍物擦身而过，强调速度参照物与空间压迫
- **结果兑现镜头**：穿出后立即揭示新空间、新威胁、新目标或落地后的状态

#### FPV 写法硬锚点
- 必写：`入口 / 穿越介质 / 擦身关系 / 出口 / 结果`
- 常用补强：`广角畸变 / 边缘动态模糊 / 轻微震颤 / 风压扭曲 / 地面纹理极速后退`
- 若用于图生 / 多帧视频：优先套用 `fpv-director-skill` 的 `Trinity` 三帧流（起势 / 过渡 / 落幅）

#### 禁止误用
- 纯情绪对话戏、静压权力戏、重要信息宣读戏，不用 `FPV` 抢阅读主点
- 路径不明、空间太平、没有前景参照物时，不要硬写 `FPV`
- 不允许把 `FPV` 仅当“酷炫速度词”使用，必须服务空间推进和结果揭示

### 悬念揭示

## Seedance 2.0 镜头落地规则
- 一镜一核心动作，一镜一核心信息点
- 先写看得见的物理信息，再写情绪和风格
- 每个镜头尽量写明景别、主体、动作链、镜头运动、光影重点
- 复杂剧情优先拆成多镜头，不要在一镜中塞满多主体和多高潮
- 镜头节奏必须与平台时长、剧情节拍匹配

## 统一写法建议
- 先写景别，再写主体，再写动作，再写镜头运动
- 每条镜头描述尽量只承载一个核心意图
- 镜头语言必须服务剧情信息，不为炫技而炫技
- 抽象词必须落到运镜、光影、构图、材质等具体层面

## 推荐格式
`[景别][机位] 主体 + 动作链 + 镜头运动 + 光影重点 + 情绪目标`

示例：
`中近景，侧拍，女主缓慢抬眼看向门外，呼吸压住怒意，镜头缓慢推近，冷白顶光压住面部轮廓，情绪克制但危险。`

## 常见误区
- 只写“电影感”，不写镜头具体怎么拍
- 一镜同时要求转身、奔跑、爆炸、哭泣、群像反应
- 风格词堆叠过多，导致镜头语义互相打架
- 只写人物，不写环境与光影支撑
