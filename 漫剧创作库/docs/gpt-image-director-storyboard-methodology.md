# GPT-image-2 专业导演故事板图体系方法论

> 版本：v1.0  
> 日期：2026-05-06  
> 等级：Pipeline Sync L3  
> 适用范围：AI 短剧 / 漫剧项目中，基于剧本、分镜表、资产图与导演意图，使用 `gpt-image-2` 图生图生成专业导演故事板图，并作为 Sora2 / Seedance2 视频生成前主交付物。

---

## 1. 体系定位

本体系用于把当前项目从“提示词直接驱动视频生成”升级为“专业导演故事板图驱动视频生成”。

专业导演故事板图不是普通分镜预览图，而是面向视频模型执行的导演级视觉说明书，必须同时承载：

- 分镜图；
- 剧本与台词；
- 人物站位关系；
- 空间关系；
- 运镜；
- 运动关系；
- 镜头语言；
- 音效；
- 对白；
- 光影；
- 风格；
- 导演批注；
- 资产引用；
- 首尾连续性；
- 视频生成注意事项。

故事板图是视频生成前的主交付物。提示词生成能力保留，但降级为内部引擎、参数记录、模型适配和必要补充说明，不再默认输出长版提示词、简版投喂稿或平台字段稿。

---

## 2. D12-Sora2 / D15-Seedance2 定义

### 2.1 D12-Sora2

`D12-Sora2` 是面向 Sora2 视频模型的故事板图规格。

- 原因：Sora2 单段视频最高支持 12 秒。
- 单张 D12 故事板总时长必须 `≤ 12s`。
- 不是固定 12 格，也不是固定每格 1 秒。
- 通过故事板内部格数与每格时长控制节奏。
- 强调短、准、清、可控。

### 2.2 D15-Seedance2

`D15-Seedance2` 是面向 Seedance2 视频模型的故事板图规格。

- 原因：Seedance 单段视频最高支持 15 秒。
- 单张 D15 故事板总时长必须 `≤ 15s`。
- 可以容纳更多起幅、推进、反应、环境反馈与落幅稳定。
- 不得为了凑满 15 秒灌水。

### 2.3 同一剧情母段的双版本关系

同一剧情母段可以派生两个视频模型适配版本：

| 版本 | 视频模型 | 时长上限 | 主目标 |
|---|---|---:|---|
| D12-Sora2 | Sora2 | 12s | 高压缩、高可读、单一戏核明确 |
| D15-Seedance2 | Seedance2 | 15s | 更完整的动作因果、反应、环境反馈和尾帧稳定 |

D12 与 D15 必须共享同一剧情母段、资产锚点、角色状态、场景状态、风格基调和连续性锚点，但可以在格数、每格时长、镜头密度和节奏呼吸上不同。

## 3. 与旧提示词系统的关系

### 3.1 新主链路

旧链路：

```text
剧本 → 分镜表 → 长版提示词 → 简版 / 平台提示词 → 视频生成
```

新链路：

```text
剧本 → 分镜表 → 资产图 → 导演故事板图 → 模型适配简短提示词 → 视频生成
```

### 3.2 提示词保留但不默认输出

提示词系统保留以下能力：

- 内部 `gpt-image-2` 故事板图生成提示词；
- Sora2 简短风格叙事提示词；
- Seedance2 参考图说明与简短风格提示词；
- 参数记录；
- 失败复盘；
- 模型适配；
- 用户明确要求时输出平台提示词。

除非用户明确要求，否则默认交付物是故事板图、连续性卡、QC 记录和交付索引，不默认输出长版提示词。

## 4. 输入资产规范

每张专业导演故事板图必须从真实资产链路生成，不得凭空脑补关键视觉设定。

### 4.1 必选输入

- 剧本段落；
- 分镜表；
- 导演讲戏；
- 场景资产图；
- 角色标准图；
- 必要道具图；
- 项目风格规范；
- 上一板尾帧连续性锚点；
- 下一板首帧预期。

### 4.2 推荐输入

- 场景 12 宫格视角全景图；
- 人物站位图；
- 角色卡标准图；
- 关键表情 / 动作参考图；
- 道具多视角图；
- 场景光影方向图；
- 战损 / 服装 / 道具状态记录。

### 4.3 资产优先级

当模型参考图数量受限时，按以下优先级选择：

```text
故事板图 > 关键角色图 > 场景图 > 关键道具图 > 次要角色图 > 氛围参考图
```

如果是 Seedance2 视频生成阶段，故事板图必须保留，其余参考图按角色数、场景复杂度和道具叙事重要性裁剪。

## 6. 格数与时长编排方法

故事板格数不固定，必须由戏份决定。

### 6.1 决定因素

- 戏剧信息量；
- 动作复杂度；
- 人物数量；
- 空间复杂度；
- 镜头语言复杂度；
- 视频模型可控性；
- 是否需要首尾帧稳定；
- 是否存在关键道具或战损状态变化。

### 6.2 常用单格时长

- 0.5s：闪回、插帧、打击瞬间、枪口火光、残影节点；
- 0.8s：快速反应、眼神、转头、短动作；
- 1.0s：标准动作格、明确读点；
- 1.2s：动作承接、表情变化、短距离位移；
- 1.5s：文戏停顿、起势、慢半拍命中；
- 2.0s：完整表演、空间交代、动作结果；
- 2.5s：情绪压迫、悬疑揭示、对峙；
- 3.0s：主镜、场景建立、宏观调度；
- 4.0s：大场面、长运镜、转场留白。

### 6.3 D12 时长求和

```text
Σ Panel Duration ≤ 12s
```

D12 不允许出现信息拥堵。若剧情母段无法在 12 秒内讲清，应拆成多张 D12 故事板。

### 6.4 D15 时长求和

```text
Σ Panel Duration ≤ 15s
```

D15 可以保留更多反应和结果，但每一格都必须承担叙事、动作、情绪或连续性任务。

## 7. 场景类型节奏模板

### 7.1 文戏 / 对话

以下 D12 / D15 格数只作为故事板图规划参考，不是固定数量。正式拆分必须按剧情节奏、动作复杂度、空间变化和画面读点动态决定；普通段可少，强动作段可多，但每一格都必须承担新的读点或结果信息。

- D12：4-7 格；
- D15：5-9 格；
- 核心：关系、视线、停顿、反应；
- 禁止：只排台词不排站位和情绪变化。

### 7.2 情绪压迫 / 对峙

- D12：5-8 格；
- D15：6-10 格；
- 核心：权力关系、距离变化、视角压迫、呼吸停顿；
- 禁止：只有正反打，没有空间压力变化。

### 7.3 悬疑 / 揭示

- D12：5-8 格；
- D15：6-10 格；
- 核心：遮挡、窥视、信息延迟、揭示落点；
- 禁止：提前暴露谜底或缺少反应镜头。

### 7.4 武打 / 动作戏

- D12：6-10 格；
- D15：8-12 格；
- 核心：对抗关系、发力、接触点、受力延迟、结果兑现；
- 禁止：只写快速打斗，不写谁压谁、谁失衡、谁反扑。

### 7.5 街头追逐

- D12：6-10 格；
- D15：8-12 格；
- 核心：方向、速度参照物、障碍物、距离变化、转角和落点；
- 禁止：方向跳变、空间关系丢失。

### 7.6 枪战

- D12：6-10 格；
- D15：8-12 格；
- 核心：掩体、火线、视线、弹道、压制与转移；
- 禁止：枪口方向、人物站位和掩体关系不清。

### 7.7 宏大战争 / 群戏

- D12：5-9 格；
- D15：7-12 格；
- 核心：主读点、阵线、层次、群体运动方向、关键角色锚点；
- 禁止：大场面堆满元素导致主体不可读。

## 9. gpt-image-2 故事板图生成方法

### 9.1 生成目标

`gpt-image-2` 负责把输入资产、分镜表和导演意图合成为一张专业导演故事板图。

### 9.2 内部提示词结构

内部提示词应写成结构化视觉设计说明书：

```text
任务类型 + 故事板版本 + 剧情母段 + 资产引用 + 版面结构 + 分格数量 + 每格镜头内容 + 人物站位 + 空间关系 + 运动箭头 + 台词音效 + 光影风格 + 导演批注 + 连续性要求 + 禁止项
```

### 9.3 图像生成要求

- 保持角色脸、服装、比例一致；
- 保持场景空间结构一致；
- 保持道具外观和位置逻辑一致；
- 保持同一故事板内部光线方向一致；
- 保持风格、画质、材质统一；
- 文本信息必须排版清晰；
- 镜头格数不得错误；
- 阅读顺序必须明确；
- 运镜箭头和运动箭头不得混乱；
- 导演批注不能遮挡分镜主画面。

## 10. 视频生成阶段模型适配规则

生成故事板图之后，故事板图不是在所有模型中都以“一张图直接生成视频”的方式使用。必须按视频模型能力、参考图数量限制和稳定性策略分别适配。

### 10.1 Sora2 版本使用方式

Sora2 版本以 `一张 D12-Sora2 导演故事板图 + 简短叙事风格提示词` 为主。

基础结构：

```text
根据 @导演故事板图 生成视频。请遵循故事板中的镜头顺序、人物站位、动作路径、光影关系、镜头语言和导演批注。
[影片基调 / 风格 / 光影 / 镜头节奏 / 动作速度 / 画质质感的简短补充]
```

示例方向：

```text
根据 @图片中的导演故事板图生成视频。保持故事板中的分镜顺序、人物站位、动作路径、镜头运动和光影方向。日式动画，Trigger 社风格，高饱和霓虹色碰撞，强烈电影画布感与镜头语言，动态夸张，动作清晰有冲击力。
```

注意：后半段不是固定模板，必须根据当前项目和当前故事板的影片基调、风格、光影、镜头节奏、运动速度、动作强度和画质要求动态生成。禁止所有项目套同一句风格词。

### 10.2 Seedance2 版本使用方式

Seedance2 版本以 `一张 D15-Seedance2 导演故事板图 + 必要参考图 + 简短模型适配提示词` 为主。

Seedance2 输入结构不是固定的，必须根据当前故事板的角色数、场景图数、关键道具数、动作复杂度和参考图上限规划。

基础结构示例：

```text
图1 = 故事板中的关键人物参考图。
图2 = 故事板中的场景全景 / 12宫格视角图。
图3 = 关键道具参考图。
图4 = 导演故事板图。
请根据导演故事板图生成视频，遵循故事板中的镜头顺序、人物站位、动作路径、空间关系、光影方向、对白音效标注和导演批注。
[影片基调 / 风格 / 光影 / 镜头节奏 / 动作速度 / 画质质感的简短补充]
```

### 10.3 Seedance2 稳定版参考图限制

Seedance2 稳定版当前按 `4 图 + 1 视频` 规划。

在稳定版中，必须严格控制参考图数量，优先保证故事板图和关键角色一致性。

推荐优先级：

```text
导演故事板图 > 关键角色图 > 场景图 > 关键道具图
```

稳定版推荐组合：

| 输入位 | 推荐内容 | 说明 |
|---|---|---|
| 图1 | 关键角色图 | 多角色时优先主角 / 当前镜头第一读点角色 |
| 图2 | 场景全景或 12 宫格核心视角图 | 保证空间一致 |
| 图3 | 关键道具图 | 仅当道具承担叙事或动作结果时保留 |
| 图4 | 导演故事板图 | 必须保留，作为镜头和节奏主控 |
| 视频 | 可选参考视频 | 仅当需要动作质感、节奏或风格参考时使用 |

若角色一致性风险高，图3 可由关键道具改为第二角色图。若场景极简单，图2 可降级为角色组图或站位图。

### 10.4 Seedance2 非稳定版参考图限制

Seedance2 非稳定版按 `9 图 + 1 视频 + 1 音频` 规划。

非稳定版可以提供更完整的角色、场景、道具和声音锚点，但稳定性风险更高，必须避免无关参考图争夺模型注意力。

推荐优先级：

```text
导演故事板图 > 主角图 > 对手 / 配角图 > 场景 12 宫格图 > 人物站位图 > 关键道具图 > 战损 / 状态图 > 风格光影参考图
```

推荐组合：

| 输入位 | 推荐内容 | 说明 |
|---|---|---|
| 图1 | 主角标准图 | 锁定主角脸、服装、比例 |
| 图2 | 对手 / 配角标准图 | 多人戏必须保留主要互动角色 |
| 图3 | 当前场景 12 宫格图 | 锁定空间结构 |
| 图4 | 人物站位图 | 锁定站位和运动方向 |
| 图5 | 关键道具图 | 锁定叙事道具或武器 |
| 图6 | 战损 / 状态图 | 仅当状态连续性重要时使用 |
| 图7 | 光影 / 风格参考图 | 仅当项目风格尚不稳定时使用 |
| 图8 | 上一板尾帧或连续性锚点 | 用于板间连续性 |
| 图9 | 导演故事板图 | 必须保留，作为镜头和节奏主控 |
| 视频 | 动作 / 镜头节奏参考 | 可选 |
| 音频 | 台词 / 氛围 / 音乐参考 | 可选 |

### 10.5 Seedance2 双版本输出策略

每张 D15-Seedance2 故事板进入视频生成前，应可选输出两种模型适配包：

1. `D15-Seedance2-Stable`：稳定版，遵守 `4 图 + 1 视频`，用于优先保证人物、场景和故事板执行稳定。
2. `D15-Seedance2-Extended`：非稳定扩展版，遵守 `9 图 + 1 视频 + 1 音频`，用于更复杂的多人、多场景、强道具、强声音或复杂动作段落。

默认优先使用稳定版。只有当稳定版无法满足角色数量、空间复杂度、关键道具或声音锚点要求时，才启用非稳定扩展版。

## 11. 连续性体系

### 11.1 板内连续性

每个 Panel 的结果必须成为下一个 Panel 的起点。

必须检查：

- 人物位置；
- 人物朝向；
- 身体姿态；
- 道具位置；
- 光线方向；
- 动作方向；
- 情绪状态；
- 战损状态；
- 场景破坏状态。

### 11.2 板间连续性

上一张故事板最后一格必须合理接入下一张故事板第一格。

必须记录：

```text
Board N Last Panel → Board N+1 First Panel
```

### 11.3 集间连续性

每集最后一张故事板最后一格必须为下一集第一张故事板第一格提供连续性锚点。

必须记录：

```text
Episode N Ending Continuity Anchor → Episode N+1 Opening Continuity Anchor
```

## 12. Agent 协作流程

```text
Producer
  ↓
Writer
  ↓
Director
  ↓
Storyboard Artist
  ↓
Camera Director
  ↓
Librarian
  ↓
Studio
  ↓
Reviewer
  ↓
Producer Phase Gate
```

### 12.1 Producer

- 决定是否进入导演故事板图阶段；
- 判断是否需要 D12、D15 或双版本；
- 控制 Phase Gate；
- 执行 Pipeline Sync L3。

### 12.2 Writer

- 提供剧本段落；
- 提供台词；
- 标注情绪转折；
- 标注必须被观众看见的信息。

### 12.3 Director

- 提供导演讲戏；
- 定义戏核；
- 判断场景类型；
- 指定影片基调、风格、光影、镜头节奏；
- 提供导演批注。

### 12.4 Storyboard Artist

- 切分故事板母段；
- 决定 D12 / D15 格数；
- 分配每格时长；
- 设计每格镜头任务；
- 组织人物站位、空间关系、运动路径和阅读顺序。

### 12.5 Camera Director

- 校验每格景别、机位、视角身份；
- 校验运镜是否绑定动作节点；
- 校验起幅、过程、落幅；
- 校验镜头衔接是否顺畅。

### 12.6 Librarian

- 校验所有资产引用真实存在；
- 选择模型参考图；
- 维护故事板连续性卡；
- 维护集间状态锚点。

### 12.7 Studio

- 将输入包转为内部 `gpt-image-2` 提示词；
- 执行故事板图生成；
- 输出 D12 / D15 故事板图；
- 为 Sora2 / Seedance2 生成模型适配包；
- 记录参数和失败原因。

### 12.8 Reviewer

- 审核故事板图可读性；
- 审核时长是否超限；
- 审核资产一致性；
- 审核板内、板间、集间连续性；
- 审核是否可进入视频生成。

## 17. 质量门禁

进入视频生成前必须满足：

- D12 总时长 `≤ 12s`；
- D15 总时长 `≤ 15s`；
- 每格时长求和正确；
- 格数符合场景类型；
- 每格镜头任务明确；
- 人物站位清楚；
- 空间关系清楚；
- 运镜与人物动作绑定；
- 运动路径清楚；
- 对白与音效明确；
- 光影方向一致；
- 风格统一；
- 资产引用真实存在；
- 板内连续性成立；
- 板间连续性成立；
- 集间连续性有锚点；
- Sora2 / Seedance2 适配包符合模型输入限制；
- 提示词没有重新夺回主交付物地位。

## 18. 打回条件

命中任一情况必须打回：

- D12 超过 12 秒；
- D15 超过 15 秒；
- 格数与场景类型不匹配；
- 每格只画动作，没有镜头任务；
- 站位、朝向、距离不清；
- 运镜未绑定动作节点；
- 板内结果无法接下一格；
- 板间尾帧无法接下一板首帧；
- 集间状态断裂；
- 角色脸、服装、比例漂移；
- 场景空间结构漂移；
- 道具状态漂移；
- 光影方向冲突；
- Seedance2 参考图超过当前版本限制；
- Sora2 提示词过长、重新变成长版提示词；
- 视频适配提示词套用固定模板，不服务当前影片基调。

## 20. 总结

D12-Sora2 / D15-Seedance2 专业导演故事板图体系的核心变化是：

```text
提示词不再是视频生成主交付物。
专业导演故事板图成为视频生成前主交付物。
提示词保留为内部引擎与模型适配说明。
```

其中：

- Sora2：主要依赖 `一张 D12 故事板图 + 简短动态风格叙事提示词`；
- Seedance2：依赖 `一张 D15 故事板图 + 角色 / 场景 / 道具参考图 + 简短模型适配提示词`；
- Seedance2 必须拆分稳定版 `4图+1视频` 与非稳定扩展版 `9图+1视频+1音频`；
- 所有版本都必须遵守人物、场景、道具、风格、光影、画质和连续性一致。
