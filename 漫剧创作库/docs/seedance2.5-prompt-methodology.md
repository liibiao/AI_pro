# seedance2.5-prompt-methodology.md — Seedance 2.5 连续叙事提示词子方法论

> 来源：用户提供的《Seedance 2.5 专业视频提示词创作方法论 教学课件.pdf》  
> 定位：在现有故事板生产包体系下，新增 `seedance2.5` 提示词输出版本。  
> 兼容：`seedance2.5-15s` 同时适用于 Seedance 2.0 的 15s 规则；`seedance2.5-30s` 面向 Seedance 2.5，最大时长 30s。  
> 上游：必须从故事板生产包、资产引用矩阵、镜头表、声音设计和视觉风格母版派生。

---

## 一、版本定位

`seedance2.5` 不是替代现有长版母稿、即梦版、Seedance 字段版和叙事版，而是新增一类 **连续叙事型 Seedance 输出稿**。

它主要解决：

- 30 秒叙事短片缺少完整故事线
- 一镜到底长镜头空间关系混乱
- 人物、载具、道具中途消失或凭空新增
- 前后光影、美术、情绪基调漂移
- 镜头运动没有叙事目的
- 情绪曲线无铺垫、无放大、无释放

当前新增两套模板：

| 版本 | 模板 | 适用 |
|---|---|---|
| `seedance2.5-15s` | `templates/_shared/prompt-output/seedance2.5-15s-template.md` | Seedance 2.5 的 15s 片段；也兼容 Seedance 2.0 15s 规则 |
| `seedance2.5-30s` | `templates/_shared/prompt-output/seedance2.5-30s-template.md` | Seedance 2.5 30s 连续叙事、一镜到底、电影感短片 |

推荐落盘路径：

```text
05-prompts/seedance/第XX集/seedance2.5/epXXX-seedance2.5-15s-paste.md
05-prompts/seedance/第XX集/seedance2.5/epXXX-seedance2.5-30s-paste.md
```

## 二、核心公式

Seedance 2.5 连续叙事提示词采用以下固定公式：

```text
生成任务 + 主要主体 + 场景与环境状态 + 情绪目标 + 视觉风格 + 分段脚本
```

**重要修正：结构不是模板腔。**

这套公式是正式流水线接口结构，不能因为“去模板化”而删掉。去模板化要处理的是 **动作节奏、镜头句式和招式推进不要同构**，不是取消母板结构。

`seedance2.5` 必须区分两层：

| 层级 | 用途 | 允许形态 |
|---|---|---|
| 工作底稿 | 给 Agent / Reviewer 检查六大模块、主体全集、场景三层、情绪曲线、分段六步法 | 可以用表格、清单、字段 |
| 正式流水线投喂稿 | 给项目归档、Reviewer、自动化流水线和 Seedance 平台直接复制使用 | 必须保留六大模块与六固定段名，但分段镜头脚本必须写成时间轴自然段，禁止使用 Markdown 表格、六步核对列或 QA 列 |
| 平台极简投喂稿 | 只在用户明确要求“直接复制到平台”时使用 | 可以合并标题为自然段，但不得丢失母板信息 |

正式流水线稿读起来应该像导演在对应字段里讲一条完整镜头，而不是像质检表。六步信息要被**融入画面句**，例如：

```text
0-2s，镜头贴着湿冷桥面裂缝向前推，两名角色被裂缝自然分在画面左右，风把衣摆压向同一个方向，观众先读到空间狭窄和胜负前的停顿。
```

而不是：

```text
跟随对象：两人中线；运动路线：贴地推近；镜头解释空间：桥面裂缝建立左右对抗。
```

这套公式采用三层约束：

### 正式投喂稿格式边界

- **工作底稿可以表格化，正式投喂稿禁止表格化。** 表格、六步逻辑核对、QA 列只服务内部检查，不进入可复制给 Seedance 的正文。
- 正式稿的 `【分段镜头脚本】` 使用 `0-3s：...`、`3-7s：...` 这样的时间轴自然段；每段把跟随对象、运动路线、空间解释、关系变化、停顿点和收尾信息融入画面句。
- 若用户说“直接可以复制给 Seedance”，默认输出正式流水线投喂稿或平台极简投喂稿，不输出表格。
- 内部风格库名不能裸写给模型。类似 `HZW 材质画质风格` 只能作为流水线内部标签，正式投喂稿必须展开为具体材质、画质、光影和氛围描述。

`HZW` 在 Seedance 正式稿中的展开示例：

```text
受控高反差电影动画质感，轻中度空气层与体积云雾让光线可见；冷月主光配合青玉与赤红能量的边缘反射，人物脸部和武器边缘有清晰半金属轮廓光；材质包含半透明玉质飞剑、黑金金属环刃、丝绸衣料纤维、湿石板反光、青瓦磨损、岩壁水汽和木梁纹理；画面保留 AO 接触阴影、GI 环境反弹、自然高光滚降、类 ACES 色调映射、细微胶片颗粒和极轻微 halation。高速段只让背景和轨迹方向性模糊，脸、手、武器、命中点和结果帧必须锐利。
```

### 结构保留与节奏去同构

用户说“不按模板生成”时，默认含义是：

- 保留用户指定结构、项目母板结构、六大模块和六固定段名。
- 不再把动作戏固定写成“起势 → 推进 → 压制 → 反击 → 爆点 → 收势”。
- 不再每段都用同一种时间分割、同一种镜头语法、同一种关系曲线。
- 让每段动作由战术目的、空间条件、角色能力和镜头视角决定。

禁止把“去模板化”误解为：

- 删除 `【生成任务】/【主要主体】/【场景与环境状态】/【情绪目标】/【视觉风格】/【分段镜头脚本】`。
- 删除 `环境联动 / 光线 / 对白配音 / 音效设计 / 画质 / 负面提示词`。
- 把正式流水线稿改成只有自然段、没有接口字段的短文。

动作戏的节奏可以采用不同结构，例如：

- **冷开场截杀型**：第一秒已经在命中边缘，中段才补空间，末尾只给脱险或反杀结果。
- **连续失重型**：用坠落、翻滚、穿云、贴地切换组织节奏，不设置传统对峙。
- **误导反杀型**：前半段看似追击，实际用环境反射、影子、替身或道具完成反杀。
- **一镜穿越型**：镜头通过云、门洞、瓦片、瀑布、衣摆遮挡连续换空间，动作节奏由穿越介质决定。
- **骤停瞬杀型**：高速追逐中突然抽空声音和画面，0.2-0.5 秒停顿后出现一击结果。
- **追逃接力型**：主读点在两人之间多次转移，镜头接力而不是单一角色推进。
- **空间压缩型**：从大远景快速压进极窄空间，动作节奏由空间越来越窄推动。
- **爆点前置型**：开头先给一次大撞击，后面 10 秒写余波、追击、结果重构。

### 1. 顶层约束：生成任务

先锁死成片硬参数：

- 视频时长：15s / 30s
- 镜头形式：一镜到底 / 多镜头 / 伪一镜到底
- 影片类型：悬疑 / 动作 / 情绪文戏 / 宣发 / 预告 / 奇观展示
- 音频规则：只保留音效 / 人声配音 + 音效 / 可选 BGM / 禁止 BGM

写法要求：

- 必须放在提示词第一项
- 必须一口气写清全局目标
- 不在这一句里塞人物外观、场景细节、剧情过程

### 2. 中层统一：主体 + 场景 + 情绪 + 视觉风格

这一层负责锁住全片一致性：

- 所有出场主体提前列全，避免中途新增或丢失
- 场景分为基础空间、表层可视细节、隐性叙事氛围
- 情绪写成递进路径，而不是单个形容词
- 视觉风格分为画面基调、光线与色彩、画面质感

### 3. 底层落地：分段脚本

分段脚本负责把剧情落到时间轴：

- 每段有明确时间范围
- 每段绑定跟随对象、运动路线、空间解释、主体关系变化、停顿点、收尾信息变化
- 镜头运动必须与人物动作、空间揭示或情绪变化绑定
- 结尾必须有信息变化，不能只是“继续走、继续看、继续氛围”

## 三、六大模块写作规则

六大模块必须在工作底稿和正式流水线投喂稿里齐全。  
如果交付对象是项目归档、用户审稿或自动化流水线，默认保留六大模块标题；如果用户明确要求“平台极简投喂稿”，才可以把标题合并成自然段，但信息不得丢失。

### 模块 1：生成任务

必填要素：

- 时长
- 镜头形式
- 影片类型
- 音频规则

示例句式：

```text
生成一段 15 秒一镜到底的电影感悬疑短片，只保留环境音、动作音效和必要人声，不生成背景音乐。
```

### 模块 2：主要主体

必须完整列出：

- 人物
- 载具
- 关键道具
- 机械 / 怪物 / 能量体
- 需要持续出现的群众或背景主体

人物必须标注：

- 年龄段
- 身份
- 外貌锚点
- 服装 / 战损 / 标志物
- 若有资产，优先写 `@资产名`

规则：

- 未在此处登记的主体，不得在分段脚本中突然出现
- 登记过的关键主体，必须在脚本中解释其出现、消失或转入背景的方式

### 模块 3：场景与环境状态

采用三层写法：

```text
基础空间：故事主发生地点、开篇起始位置、空间边界。
表层可视细节：地面状态、天气、灯光、路人、车辆、商铺、尘土、水汽、烟雾等可见元素。
隐性叙事氛围：观众提前知道但角色未必知道的危险、压迫、诱导、伏笔或情绪底色。
```

### 模块 4：情绪目标

必须写清两件事：

- 整体基调
- 情绪递进路径

推荐句式：

```text
整体基调为[情绪A]、[情绪B]、[情绪C]。情绪递进为：开篇[铺垫] → 中段[放大] → 结尾[释放/反转/留钩子]。
```

### 模块 5：视觉风格

采用三分结构：

```text
1. 画面基调：风格定位、写实/夸张取向、核心观看重点。
2. 光线与色彩：核心光源、明暗对比、饱和度、视觉锚点配色、冷暖分配。
3. 画面质感：颗粒、噪点、焦感、边缘锐度、实拍复刻、动画线条或材质表现。
```

风格库名称只允许在工作底稿中指向项目母板。正式投喂稿必须把风格库名称拆成模型能执行的描述：材质是什么、光从哪里来、反射如何出现、暗部和高光如何保留细节、什么可以模糊、什么必须清晰。

### 模块 6：分段镜头脚本

每段必须写：

- 时间段
- 画面与镜头描述
- 六步逻辑核对

承载内容：

- 时间轴分段
- 机位景别
- 镜头运动
- 主体动线
- 人物动作 / 台词 / 表演
- 画面事件
- 音效变化

正式投喂稿中禁止使用分段表格。推荐格式：

```text
0-3s：镜头从[入口]进入，[主体动作]触发[空间变化]，[运镜]绑定[动作节点]，[本段结果或新危险]。
3-7s：...
```

## 四、分段脚本六步法

每一段镜头脚本都按下面 6 步检查：

1. **确定跟随对象**：本段观众跟谁看？
2. **设计运动路线**：主体怎么移动、转向、停靠、穿越空间？
3. **用镜头运动解释空间**：机位高低、推拉摇移跟升降如何帮助观众理解位置关系？
4. **安排主体关系变化**：谁从主景变背景？谁从远景变近景？关系强弱如何变化？
5. **设计停顿点**：哪里需要主体停、镜头缓停、声音抽空或表情停留？
6. **明确结尾的信息变化**：本段结束时新增了什么信息、危险、结果、情绪或钩子？

如果某段缺少第 6 步，通常说明这段只是氛围堆叠，应打回重写。

### 六步法的输出原则

- 工作底稿可以显式列出六步。
- 正式流水线投喂稿必须保留分段结构，但把六步融入画面句，不再逐项列标签。
- 不要每段都写成同样句型；每段的语法应随镜头任务变化：对峙段更克制，冲刺段更短促，爆点段更密集，结果段更清楚。
- 允许使用自然连接词：开场、随后、同一瞬间、镜头顺势、约第 X 秒、末尾。
- 禁止模板腔：连续多段重复“跟随对象 / 运动路线 / 镜头解释空间 / 关系变化 / 停顿点 / 收尾信息变化”。
- 禁止节奏同构：连续多个动作段不能都套“起势 → 推进 → 中段升级 → 转折 → 爆点收束”。时间轴可以冷开场、先爆点、骤停、误导、穿越、接力、反杀或留白，只要每段的动作因果和结果帧清楚。

## 五、15s 与 30s 的分工

| 维度 | seedance2.5-15s | seedance2.5-30s |
|---|---|---|
| 兼容模型 | Seedance 2.5 / Seedance 2.0 | Seedance 2.5 |
| 最大时长 | 15s | 30s |
| 核心用途 | 单事件、单爆点、小情绪弧、短段落投喂 | 完整微剧情、一镜到底、连续悬念、长镜头调度 |
| 时间轴密度 | 由剧情节奏、动作复杂度和画面读点决定，不固定段数 | 由完整微剧情、空间调度和主体切换决定，不固定段数 |
| 主体数量 | 1-3 个核心主体 | 可包含主角、对手、载具、群众、道具，但必须提前登记 |
| 情绪结构 | 铺垫 → 转折 → 结果 | 铺垫 → 接近 → 主体切换 → 升级 → 爆发 / 反转 |
| 风险 | 细节太多导致动作糊 | 主体漂移、空间断裂、后半段空转 |

### seedance2.5-15s 兜底节奏

```text
0-2s：建立主体、空间、第一危险或情绪压点
2-5s：核心动作 / 关系推进开始
5-9s：空间关系或主体关系发生变化
9-12s：情绪或动作转折
12-15s：结果兑现、反转或钩子收束
```

说明：这只是缺少导演设计时的兜底切分，不是动作戏固定节奏，也不是固定时间点数量。正式生成时必须按剧情节奏决定密度：普通位移、空间建立、慢压迫和结果余波应更疏；闪现、瞬影杀、块切、FPV 穿越和多层斗法可以更密，但每个时间点都要带来新的动作结果、空间关系、威胁变化、视角变化、声音变化或清晰结果帧。

### seedance2.5-30s 兜底节奏

```text
[起始]-[按剧情决定的秒数]：建立空间、主体、视觉锚点，或直接从危险 / 截杀 / 结果余波进入
[按剧情决定的秒数]-[按剧情决定的秒数]：危险、目标、动作路线、主读点接力或空间穿越启动
[按剧情决定的秒数]-[按剧情决定的秒数]：镜头解释空间，主体进入新关系，或关系被误导 / 反转 / 压缩
[按剧情决定的秒数]-[按剧情决定的秒数]：主次切换、情绪放大、斗法升级、骤停瞬杀或追逃接力
[按剧情决定的秒数]-[按剧情决定的秒数]：危险逼近、误导揭示、连续爆点、动作蓄力或结果余波
[按剧情决定的秒数]-30s：结果爆发、反转、收束或留钩子
```

说明：这只是连续叙事兜底节奏，不得机械套用到每个 30s 段落。追逐、斗法、群战、逃亡、潜入、坠落等段落，应根据空间变化和主读点转移重新设计节奏。

## 六、与项目既有六固定段的关系

Seedance 2.5 的六大模块是 **提示词主体结构**。  
项目既有的六固定段是 **工程 QA 与生成稳定器**。

因此 `seedance2.5` 输出必须同时保留：

```text
【生成任务】
【主要主体】
【场景与环境状态】
【情绪目标】
【视觉风格】
【分段镜头脚本】

环境联动
光线
对白配音
音效设计
画质
负面提示词
```

但在最终投喂稿中，这些固定段可以压缩为自然段落，推荐格式：

```text
全片环境、光线与声音统一为：...
人声：...
画质与负面约束：...
```

若用于项目归档或 Reviewer 审核，仍可在稿末保留六个固定段名；若用于平台直接投喂，则优先保持自然口吻。

说明：

- `视觉风格` 负责全局美术描述
- `光线` 负责把光源、色温、变化节点工程化
- `音频要求` 写在生成任务里
- `对白配音` 只写人声层
- `音效设计` 写环境音、拟音、特效音、状态音
- `BGM` 默认不进入主提示词固定段，除非该片段本身是音乐驱动

## 七、质量门禁

输出前必须检查：

- [ ] 生成任务位于首项，且一句话锁定时长、镜头形式、影片类型、音频规则
- [ ] 15s 版本不超过 15s，30s 版本不超过 30s
- [ ] 独立片段从 `0s` 起算
- [ ] 所有主体提前登记，无随机新增角色、道具、载具
- [ ] 场景包含基础空间、表层可视细节、隐性叙事氛围
- [ ] 情绪目标有开篇、中段、结尾递进
- [ ] 视觉风格包含画面基调、光线与色彩、画面质感
- [ ] 每个分段都有跟随对象、运动路线、镜头解释空间、主体关系变化、停顿点、结尾信息变化
- [ ] 镜头运动与具体动作、空间揭示或情绪变化绑定
- [ ] 六固定段名齐全：环境联动 / 光线 / 对白配音 / 音效设计 / 画质 / 负面提示词
- [ ] 无对白时，`对白配音` 明确写“本段无对白配音”
- [ ] 负面提示词针对本段风险定制，覆盖主体丢失、空间跳变、风格跑偏、无关字幕水印等风险

## 八、Agent 接入规则

### Director

当导演判断片段需要 15s / 30s 连续叙事、悬疑推进、一镜到底或强空间调度时，应明确标注：

```text
提示词输出版本：seedance2.5-15s / seedance2.5-30s
镜头形式：一镜到底 / 多镜头 / 伪一镜到底
情绪路径：开篇 → 中段 → 结尾
禁止压缩项：主体 / 空间 / 结果 / 声音 / 情绪钩子
```

### Storyboard Artist

故事板生产包中必须能推导出：

- 主体全集
- 起始空间和终止空间
- 每段跟随对象
- 每段运动路线
- 主体关系变化
- 停顿点
- 收尾信息变化

### Studio

执行时优先测试：

1. `seedance2.5-15s`：验证角色、空间、动作、情绪能否稳定
2. `seedance2.5-30s`：在 15s 版本稳定后扩展为完整 30s 连续叙事

如果 30s 后半段出现空转、主体丢失或空间错乱，应拆回两个 15s 版本，而不是继续堆描述。

### Reviewer

Reviewer 审核 `seedance2.5` 时，除了既有红线，还必须额外检查：

- 顶层生成任务是否首项生效
- 主要主体是否全集锁定
- 场景三层是否完整
- 情绪递进是否真实发生
- 每段结尾是否有信息变化
- 30s 是否真实铺满而不是后半段重复氛围
