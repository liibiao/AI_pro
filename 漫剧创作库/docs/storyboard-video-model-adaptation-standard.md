# 故事板视频模型适配规范

> 版本：v1.0  
> 日期：2026-05-06  
> 关联方法论：`docs/gpt-image-director-storyboard-methodology.md`

---

## 1. 总原则

生成专业导演故事板图之后，不能默认认为“一张故事板图即可直接生成所有视频”。不同视频模型的输入能力、参考图数量、稳定性和风格控制方式不同，必须分别适配。

本规范定义：

- D12-Sora2 视频生成适配；
- D15-Seedance2 稳定版适配；
- D15-Seedance2 非稳定扩展版适配；
- 参考图优先级；
- 简短风格叙事提示词规则。

---

## 2. D12-Sora2 输入结构

Sora2 版本以以下结构为主：

```text
一张 D12-Sora2 导演故事板图 + 简短叙事风格提示词
```

Sora2 不默认追加角色图、场景图、道具图。故事板图必须承载足够完整的镜头顺序、人物站位、动作路径、空间关系、光影方向、声音标注和导演批注。

---

## 3. D12-Sora2 简短提示词规则

基础格式：

```text
根据 @导演故事板图 生成视频。请遵循故事板中的镜头顺序、人物站位、动作路径、空间关系、光影方向、镜头运动和导演批注。
[影片基调 / 风格 / 光影 / 镜头节奏 / 动作速度 / 画质质感]
```

示例：

```text
根据 @图片中的导演故事板图生成视频。保持故事板中的分镜顺序、人物站位、动作路径、镜头运动和光影方向。日式动画，Trigger 社风格，高饱和霓虹色碰撞，强烈电影画布感与镜头语言，动态夸张，动作清晰有冲击力。
```

注意：

- 后半段不是固定模板；
- 必须根据当前项目的影片基调、风格、光影、镜头节奏速度动态生成；
- 禁止把 Sora2 简短提示词写成长版提示词；
- 禁止固定套用同一句风格词。

---

## 4. D15-Seedance2 输入结构

Seedance2 版本以以下结构为主：

```text
一张 D15-Seedance2 导演故事板图 + 必要角色图 + 场景图 + 关键道具图 + 简短模型适配提示词
```

参考图结构不固定，必须按当前故事板的角色数、场景图数、关键道具数和模型限制合理规划。

基础描述示例：

```text
图1 = 故事板中的人物参考图。
图2 = 故事板中的场景全景 / 12宫格视角图。
图3 = 关键道具图。
图4 = 导演故事板图。
请根据导演故事板图生成视频，遵循故事板中的镜头顺序、人物站位、动作路径、空间关系、光影方向、对白音效标注和导演批注。
[影片基调 / 风格 / 光影 / 镜头节奏 / 动作速度 / 画质质感]
```

---

## 5. Seedance2 稳定版：4图 + 1视频

稳定版按 `4 图 + 1 视频` 规划。

### 5.1 适用场景

- 常规文戏；
- 单主角动作；
- 双人对峙；
- 场景相对稳定；
- 角色一致性优先；
- 需要较高生成稳定性。

### 5.2 参考图优先级

```text
导演故事板图 > 关键角色图 > 场景图 > 关键道具图
```

### 5.3 推荐组合

| 输入位 | 推荐内容 | 说明 |
|---|---|---|
| 图1 | 关键角色图 | 主角或当前第一读点角色 |
| 图2 | 场景全景 / 12宫格核心视角图 | 保证空间一致 |
| 图3 | 关键道具图 / 第二角色图 | 按叙事重要性二选一 |
| 图4 | 导演故事板图 | 必须保留 |
| 视频 | 动作 / 镜头节奏参考 | 可选 |

### 5.4 裁剪规则

- 多角色时，优先保留当前故事板第一读点角色；
- 对手比道具更重要时，用第二角色图替代道具图；
- 场景简单时，可用人物站位图替代场景图；
- 道具不承担叙事结果时，可删除道具图；
- 导演故事板图不可删除。

---

## 6. Seedance2 非稳定扩展版：9图 + 1视频 + 1音频

非稳定扩展版按 `9 图 + 1 视频 + 1 音频` 规划。

### 6.1 适用场景

- 多角色群戏；
- 复杂动作戏；
- 枪战；
- 街头追逐；
- 宏大战争；
- 关键道具强叙事；
- 声音节奏对画面执行影响较大。

### 6.2 参考图优先级

```text
导演故事板图 > 主角图 > 对手 / 配角图 > 场景12宫格图 > 人物站位图 > 关键道具图 > 战损 / 状态图 > 风格光影参考图
```

### 6.3 推荐组合

| 输入位 | 推荐内容 | 说明 |
|---|---|---|
| 图1 | 主角标准图 | 锁脸、服装、比例 |
| 图2 | 对手 / 配角标准图 | 多人互动必选 |
| 图3 | 场景 12 宫格图 | 锁空间结构 |
| 图4 | 人物站位图 | 锁站位和方向 |
| 图5 | 关键道具图 | 锁武器 / 叙事道具 |
| 图6 | 战损 / 状态图 | 状态连续性重要时使用 |
| 图7 | 光影 / 风格参考图 | 风格不稳时使用 |
| 图8 | 上一板尾帧 / 连续性锚点 | 保证板间衔接 |
| 图9 | 导演故事板图 | 必须保留 |
| 视频 | 动作 / 镜头节奏参考 | 可选 |
| 音频 | 台词 / 氛围 / 节奏参考 | 可选 |

### 6.4 风险控制

- 不得塞入无关风格图；
- 不得让多个参考图互相抢构图权；
- 不得让道具图压过故事板图；
- 不得让光影参考图改变项目主风格；
- 必须在提示词中声明导演故事板图是镜头和节奏主控。

---

## 7. Seedance2 双版本输出策略

每张 D15-Seedance2 故事板进入视频生成前，可输出两套适配包：

### 7.1 `D15-Seedance2-Stable`

- 使用 `4 图 + 1 视频`；
- 默认优先；
- 目标是稳定生成；
- 适合绝大多数常规镜头。

### 7.2 `D15-Seedance2-Extended`

- 使用 `9 图 + 1 视频 + 1 音频`；
- 非稳定扩展版；
- 用于复杂多人、多场景、强动作、强道具、强声音段落；
- 使用前必须说明为什么稳定版不足。

---

## 8. 风格提示词动态生成规则

风格提示词不是固定模板，必须根据以下因素动态生成：

- 项目影片基调；
- 当前场景类型；
- 光影方向；
- 色彩策略；
- 镜头节奏；
- 动作速度；
- 画质质感；
- 当前故事板第一读点；
- 视频模型能力。

示例结构：

```text
[动画 / 写实 / 漫剧风格]，[项目风格锚点]，[色彩与光影]，[镜头节奏]，[动作速度]，[画质质感]。
```

禁止把风格提示词写成无关高级词堆叠。

---

## 9. 打回条件

命中任一情况必须打回：

- Sora2 版本没有使用 D12 故事板图；
- Sora2 简短提示词过长，变成长版提示词；
- Seedance2 稳定版超过 `4 图 + 1 视频`；
- Seedance2 扩展版超过 `9 图 + 1 视频 + 1 音频`；
- Seedance2 未保留导演故事板图；
- 参考图优先级错误，导致关键角色或故事板图缺失；
- 风格提示词固定套用，不符合当前影片基调；
- 参考图之间互相冲突；
- 视频生成说明没有声明故事板图为镜头和节奏主控。
