# scene-storyboard-formulas — 分场景分镜公式库

> 适用范围：导演讲戏转分镜、故事板生产包、镜头组预设、短剧 / 漫剧 / 动画 / 短视频分场景快速拆解。  
> 核心目标：把常见场景类型整理成**可直接调用、可回退、可校验**的分镜公式，解决“知道原则但不会落镜头顺序”的问题。

---

## 1. 公式库的使用原则

分场景公式不是死模板，而是三件事的捷径：
1. **快速搭骨架**：先有可用镜头组，再局部微调
2. **降低翻车率**：避免一上来就散写镜头
3. **方便回退**：复杂方案不成立时，退回基础公式依然能讲清戏

使用顺序统一为：
**先判场景类型 → 再套基础公式 → 再按戏核/关系/节拍微调 → 最后接入景别、视角、运镜与平台执行。**

---

## 2. 六大分场景公式总览

| 场景类型 | 核心目标 | 默认镜头组 | 重点检查 |
|---------|---------|-----------|---------|
| 文戏 / 对话 | 关系清晰、台词命中、情绪留白 | 建立 → 推进 → 命中 → 反应 → 余波 | 轴线、眼线、留白、主读点 |
| 对峙 / 压迫 | 权力差、空间屏障、压迫升级 | 建立 → 施压 → Beat → 命中 → 结果 | 高低位、屏障、谁压谁 |
| 悬疑 / 揭示 | 信息延迟、观察路径、揭露冲击 | 异常提示 → 观察接入 → 误导 / 压延 → 揭示 → 反应 | 焦点控制、视线、隐藏与揭示 |
| 动作 / 爆点 | 看清关系、爆发爽点、结果兑现 | 关系建立 → 起势 → 骤静 → 命中 → 结果 | 力传递、命中点、结果镜头 |
| 追逐 / 逃逸 | 路径清楚、压迫持续、空间推进 | 路径建立 → 跟进 → 压近 → 危机 / 转折 → 出口 / 结果 | 路径、方向、速度参照物 |
| 转场 / 时空切换 | 连续性、跳跃合理、情绪可继承 | 前镜落点 → 桥接镜 → 后镜起点 | 动作/视线/方向/情绪匹配 |

## 3. 文戏 / 对话公式

### 3.1 基础稳定版（零翻车默认）
1. **主镜头全景**：交代两人位置、轴线、空间关系
2. **A 过肩拍 B**：进入对话关系
3. **B 单打**：接台词或反应
4. **B 过肩拍 A**：切回关系反打
5. **A 单打**：命中关键台词或情绪反应
6. **侧机位 / 同框收尾**：留停顿或收关系变化

### 3.2 情绪压迫版
1. 稳定观察中景
2. 缓推逼近主角
3. 插对方压迫视角 / OTS
4. 特写命中关键台词
5. 反应镜头
6. 余波停顿

### 3.3 适配条件
- 对话主导、动作弱、重点在情绪与关系
- 需要稳、清楚、能演

### 3.4 红线
- 不要一开始就堆特写
- 不要频繁切主视角
- 不要无缘由乱推拉

### 3.5 回退方案
若压迫版不成立，直接回退到**五镜头正反打基础版**。

---

## 4. 对峙 / 压迫公式

### 4.1 基础压迫版
1. **全景建立**：两人 / 多人站位、高低位、屏障关系
2. **权力差强化镜**：仰拍强者 / 俯拍弱者 / 屏障遮挡
3. **Beat 停顿**：让压迫成立，不急着爆
4. **命中镜**：台词、动作或眼神打穿
5. **结果镜**：谁被压住、谁扛住、关系是否翻转

### 4.2 权力反转版
1. 初始压制建立
2. 被压方蓄力或观察
3. 中性停顿 / 特写缓冲
4. 反击命中
5. 权力位置重排结果镜

### 4.3 适配条件
- 人物关系紧张
- 重点不是动作量，而是谁占上风

### 4.4 红线
- 没先交代屏障和站位就直接近景互切
- 只有狠话，没有结果镜头
- 仰俯拍乱用，导致权力逻辑失真

### 4.5 回退方案
若权力反转版太复杂，退回：**全景建立 → 近景施压 → 命中 → 结果**。

---

## 5. 悬疑 / 揭示公式

### 5.1 观察揭示版
1. **异常提示镜**：道具、声音、空间异样
2. **观察接入镜**：角色看向异常处
3. **视线匹配镜 / 缓推**：逐步逼近信息点
4. **揭示镜**：真相、人物、线索显现
5. **反应镜**：角色或旁观者吸收信息

### 5.2 误导反转版
1. 锁定一个错误焦点
2. 用构图 / 焦点转移延迟真焦点
3. 中性镜或空镜缓冲
4. 真正揭示镜
5. 反应 / 代价镜

### 5.3 适配条件
- 重点是“观众何时知道”
- 要控制信息释放顺序

### 5.4 红线
- 一开始就把答案给全
- 角色没看，镜头自己先知道
- 误导过度，导致看不懂而不是悬疑

### 5.5 回退方案
若误导版失控，回退到：**异常提示 → 看 → 看到 → 反应**。

---

## 6. 动作 / 爆点公式

### 6.1 标准爽点版
1. **关系建立**：谁打谁、距离、方向、威胁源
2. **起势镜**：蓄力、启动、破绽形成
3. **骤静 / Hit Stop**：爆点前压住一拍
4. **命中镜**：真正的打击点 / 爆裂释放
5. **结果镜**：受力、位移、环境反馈、关系变化

### 6.2 连续动作版
1. 起手关系镜
2. 动作链中段
3. 转折镜 / 失衡镜
4. 反压命中
5. 收势结果镜

### 6.3 适配条件
- 强动作、强受力、需要爽点
- 必须保证观众看清谁压谁

### 6.4 红线
- 只写 motion blur，不写清晰命中
- 没有起势就直接爆
- 没有结果镜头

### 6.5 回退方案
若复杂动作链不成立，退回：**建立 → 起势 → 命中 → 结果** 四镜基础版。

---

## 7. 追逐 / 逃逸公式

### 7.1 路径清晰版
1. **路径建立镜**：入口、方向、障碍物、追逃关系
2. **跟进镜**：角色开始移动，建立速度参照
3. **压近镜**：追兵逼近 / 危险临近
4. **危机转折镜**：拐角、坠落、阻挡、擦身而过
5. **出口 / 结果镜**：逃脱、被追上、进入新空间

### 7.2 沉浸代入版
1. 半主观背跟
2. 路径穿越
3. 危险擦身
4. 速度升级
5. 结果镜头

### 7.3 适配条件
- 路径推进比台词重要
- 观众必须知道“从哪到哪”

### 7.4 红线
- 路径不清楚，只剩速度词
- 空间方向频繁乱换
- 一直跟拍但没有出口结果

### 7.5 回退方案
若长追逐镜头失控，退回多镜组合：**全景路径 → 跟拍 → 危机 → 结果**。

---

## 8. 转场 / 时空切换公式

### 8.1 匹配转场版
1. 前镜停在动作 / 方向 / 视线 / 情绪落点
2. 桥接镜承接同类运动或同类焦点
3. 后镜从相同逻辑起幅进入新场景

### 8.2 时空跳转版
1. 前镜结果点
2. 闪白 / 黑场 / 空镜 / 中性镜缓冲
3. 后镜新空间建立
4. 一镜交代“已经变了什么”

### 8.3 适配条件
- 需要切时间、切空间、切情绪，但不能像 PPT

### 8.4 红线
- 无桥接直接硬跳
- 前后镜头方向和情绪完全断裂
- 只切位置，不交代新关系

### 8.5 回退方案
若复杂匹配转场不成立，退回：**前镜结果 → 中性桥接 → 新空间建立**。

---

## 9. 公式库的智能体调用规则

### 9.1 调用优先级
1. 先判场景类型
2. 先套场景公式
3. 再接镜头组方法论
4. 再接单镜镜头设计
5. 最后接平台格式与派生

### 9.2 当场景混合时
按主任务决定主公式：
- 对话里突然爆发动作 → 先文戏公式，再切动作公式
- 追逐中出现揭示 → 先追逐公式，再嵌悬疑揭示镜
- 对峙后反转 → 先压迫公式，再加结果重排镜

### 9.3 输出建议
每次调用公式库时，至少写清：
- 当前场景类型
- 采用哪套公式
- 关键镜头组顺序
- 这一版的风险点
- 若不成立退回哪套基础版

---

## 10. 总口诀

> 先判这是什么场景，再用对应公式搭骨架；先把戏讲清，再去加风格；公式不是束缚，而是最低稳定解。
