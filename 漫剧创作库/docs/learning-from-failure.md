# learning-from-failure.md — 学习跌倒规范

> 适用范围：AI 短剧 / 漫剧 / 提示词实验 / 分镜复盘 / 正式资产沉淀  
> 核心目标：把失败版、保底版、观察型镜头和减负决策，变成可训练、可复用、可持续优化的方法资产。

---

## 1. 为什么要学习跌倒

真正有价值的团队方法，不只来自成功版本，还来自：
- 为什么强化版没收益
- 为什么镜头一复杂就失控
- 为什么某些镜头必须保底
- 为什么有些镜头适合插入，有些不适合

> 成功告诉我们“什么能做”，失败告诉我们“什么时候不能再做”。

---

## 2. 四类学习样本

### 2.1 主版本
定义：通过实验、QA、拼接验证后，可作为正式资产候选的稳定版本。

### 2.2 保底版
定义：当主版本因强化、信息过满、漂移或失真而不稳定时，可以快速切回的稳定版本。

### 2.3 失败版
定义：收益低于风险，或已经破坏可读性、稳定性、叙事命中的版本。

### 2.4 观察型镜头
定义：可插可不插，不影响主线成立，但有学习价值的镜头。

---

## 3. 必须复盘的四个问题

每次失败或回退后，至少回答：
1. 失败发生在主体、空间、光影、动作、表情、台词、群像中的哪一层？
2. 是信息过多，还是任务不清，还是镜头时长 / 节拍密度失控？
3. 为什么主版本还能成立，而失败版不成立？
4. 这次应提炼成“回退触发器”还是“减负规则”？

---

## 4. 常见回退触发器

### 4.1 表情 / 台词镜头
一旦出现以下任一信号，优先回退：
- 口型不准
- 眼神失焦
- 表情读点被环境信息吞掉
- 停顿不成立

### 4.2 群像镜头
一旦出现以下任一信号，优先减负或回退：
- 每个人都在动
- 事件成立但统一性下降
- 主信息被边缘动作分走注意力

### 4.3 动作镜头
一旦出现以下任一信号，优先回退 baseline：
- 起势不清
- 命中不清
- 结果不清
- 全程靠 blur 假装快

### 4.4 场景镜头
一旦出现以下任一信号，优先删环境干扰：
- 首看点不明确
- 空间关系被杂物打碎
- 光影虽漂亮但不服务叙事

---

## 5. 常见减负规则

### 5.1 先删环境噪音，不先删主叙事
### 5.2 先删辅助动作，不先删主动作
### 5.3 先删风格堆叠，不先删身份锚点
### 5.4 先删群像杂动，不先删事件核心
### 5.5 先删速度词，不先删结果镜头
