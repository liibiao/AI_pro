# global-character-library.md — 全局角色资产库

## 用途
沉淀跨项目可复用的角色原型、视觉标签、行为标签、常见情绪状态与提示词方向，减少每次从零搭建角色设定的重复劳动。

## 使用规则
- 先选原型，再做项目化改写
- 不允许角色设定只有外貌，没有行为标签
- 每个高频主角都应绑定面部关键词与三视图关键词
- 跨项目复用时，必须写明改写点与差异点
