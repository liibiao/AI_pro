# storyboard-methodology.md — 分镜方法论与工程规范

> 适用范围：导演讲戏转分镜、AI 短剧 / 漫剧镜头拆解、Seedance / 即梦 / 叙事版提示词母稿、镜头级执行稿、剪辑前预判。  
> 核心目标：把分镜从“会描述镜头”升级为“能稳定产出可执行镜头系统”的工程能力。

---

## 1. 分镜的本质定位

分镜不是把剧本改写得更像电影，也不是把导演的话拆成很多小句。

**分镜的本质，是把抽象叙事转成可执行的镜头系统。**

这个镜头系统至少要同时满足 6 件事：

1. **叙事成立**：观众知道这镜在讲什么
2. **关系清晰**：谁压谁、谁看谁、谁在什么位置
3. **节拍可控**：哪里停、哪里推、哪里切、哪里留 Beat
4. **结果可读**：命中点、反应点、结果镜头明确
5. **平台可执行**：适合 Seedance / 即梦 / AI 视频生成
6. **可派生**：能从同一母稿稳定派生多平台版本

---

## 2. 分镜五层模型（总装框架）

任何一个合格分镜，都必须按以下五层顺序思考，而不是直接写镜头。

### 第 1 层：戏核层
先回答：
- 这一段真正要讲什么
- 这段的主关系是什么
- 这一段的爆点或情绪落点是什么
- 这一段结束后，关系发生了什么变化

### 第 2 层：空间层
先建立：
- 场景空间
- 人物站位
- 左右屏幕方向
- 前中后景层级
- 主读点位置
- 禁穿轴与字幕安全区

### 第 3 层：镜头任务层
每个镜头先定任务，再定拍法。镜头任务常见九类：
- 空间建立
- 关系建立
- 压迫建立
- 爆发动作
- 命中确认
- 情绪变化
- 台词命中
- 结果兑现
- 钩子打断

### 第 4 层：节拍层
确定：
- 哪些信息要在本镜完成
- 每镜几个有效节拍
- 哪些镜头必须留 Beat
- 哪些地方必须 Hit Stop / 骤静
- 哪些切点靠动作顺接，哪些切点靠情绪顺接

### 第 5 层：平台执行层
最后才决定：
- 用什么景别 / 视角 / 运镜
- 是否启用 FPV
- 是否拆为多镜头
- 是否需要长版母稿 + 简版派生
- 哪些信息属于禁止压缩项

## 3. 分镜九大核心原则

### 原则 1：先戏核，后镜头
镜头不能先于戏核存在。镜头设计必须回答“为什么现在要这样看”。

### 原则 2：先关系，后爆点
强对抗、强情绪、强反转段落，必须先建立站位、朝向、距离、主读点，再进入爆点。

### 原则 3：一个镜头一个主任务
一个镜头可以附带次任务，但只能有一个主任务。若要同时承担多个主任务，优先拆镜。

### 原则 4：镜头动作必须融合
帧率切换、景别变化、运镜变化必须绑定具体动作或表演节点，禁止单独列“镜头与构图”。

### 原则 5：任何爆点都必须有结果镜头
重击、情绪失控、反压、终结技、揭露真相，都不能只有过程没有结果。

### 原则 6：位置关系必须显式化
重要镜头必须明确：左右、前后、高低位、距离、视线、命中点、轴线规则。

### 原则 7：节拍密度受控
节拍密度由剧情节奏、动作复杂度和画面读点决定，不按固定秒数机械切分。普通段主动降密；闪现、瞬影杀、快切、FPV 穿越等强动作段可以更密，但每个密集节点都必须带来新的动作结果、空间关系、威胁变化或清晰结果帧。时长不够先拆镜或删减信息，不靠堆词硬塞。

### 原则 8：转场不是补丁，是叙事动作
切点必须承载动作延续、情绪延续、时间跳跃或空间跳跃，不可默认硬切。

### 原则 9：平台派生必须同源
即梦版、Seedance 字段版、Seedance 叙事版必须从同一长版母稿派生，禁止各写各的。

## 3.5 经典影视分镜基础层（对话 / 采访 / 对手戏强制）

> 本层吸收专业影视分镜训练中的**经典工业规则**，作为当前 AI 分镜体系的基础约束层。
> 原则：**基础影视空间规则优先于风格发挥。规则 > 创意。**

### A0. 定义层（用于智能体识别与校验）
- **轴线 / 关系轴线 / 180°轴线**：两个存在互动关系的角色之间的虚拟连线，是空间逻辑的核心基准线。
- **180°规则 / 轴向规则**：拍摄该互动场景的机位，必须统一设置在轴线同一侧的 180° 半圆范围内。
- **跳轴 / 越轴**：机位在无合理过渡的情况下直接跨越轴线，到另一侧拍摄的违规操作。

### A0.1 跳轴的违规后果（用于风险判定）
1. **视觉后果**：角色朝向、左右位置与空间认知被打断，观众会感到画面“怪”但不一定立刻说出原因。
2. **叙事后果**：互动关系识别变差，情绪代入被中断。
3. **训练后果**：是新手分镜“看起来违和但找不到问题”的高频根因。

### B. 正反打五镜头公式（双人对话默认模板）
当场景属于双人对话 / 采访 / 对手戏 / 1主1次多人主对话时，默认优先启用以下公式：
1. **主镜头（全景）**：双人同框，交代站位、轴线、环境
2. **A 过肩拍 B（OTS）**：前景 A 肩膀约占画面 1/5，B 面部完整清晰
3. **B 单人镜头（单打）**：近景，B 视线朝向 A
4. **B 过肩拍 A（OTS）**：前景 B 肩膀约占画面 1/5，A 面部完整清晰
5. **A 单人镜头（单打）**：近景，A 视线朝向 B
6. **可选侧机位全景**：用于空间锚定、收尾、节奏停顿或转场

补充约束：
- 正反打五镜头公式是**默认基础结构**，除非明确有动作、压迫、信息藏匿或风格化叙事需求，否则不应跳过。
- 过肩镜头中前景肩膀占画面约 1/5-1/4，且不得遮挡对面人物面部。
- 单人镜头优先保证面部完整、视线清晰、眼线稳定。

### C. 景别量化标准（基础量尺）
- **远景**：人物占画面 1/10 以下，以环境为主；用于地点建立、转场、大场景展示。
- **全景**：人物全身 + 完整环境，人物占画面 1/3-1/2；用于站位建立、主镜头、场景收尾。
- **中景**：人物腰部以上，环境占画面 1/3 以下；用于动作、互动、过肩镜头。
- **近景**：人物胸部以上，无多余环境；用于对话、表情与人物关系压迫。
- **特写**：人物面部核心器官或局部道具；用于情绪高潮、台词重点、关键物件。

### D. 机位类型四分法（基础执行模板）
- **主镜头**：固定机位，全景，默认与地面平行；负责完整交代站位、轴线、环境。
- **过肩镜头（OTS）**：固定机位，中景 / 近景，前景肩膀 45° 进入画面，不遮脸。
- **单人镜头（单打）**：固定机位，近景 / 特写，镜头高度与眼线平齐。
- **侧机位**：固定机位，全景 / 中景，机位与轴线平行；用于空间锚定、节奏停顿、收尾。

### E. 经典基础层与现体系的关系
- `blocking-camera-geometry-methodology.md` 负责**AI 工程化坐标、几何门禁、读点保护**。
- 本节负责**经典影视分镜空间语言、正反打公式、景别量尺、机位类型模板**。
- 两者关系是：**先用经典影视规则确保空间语法正确，再用 AI 工程规则确保生成稳定。**

### F. 新手高频红线（可直接用于合规校验）
- 双人对话未先划定轴线，机位随意分布在轴线两侧。
- 直角互动场景无过渡镜头直接跨轴硬切。
- 三人互动 / 对峙场景未先用全景建立位置关系，就直接切正反打。
- 为了“画面好看”随意跨轴，忽略叙事与空间逻辑。

### H. 合规修复动作（智能体默认回退策略）
- 若发现**轴线不明**：先补主镜或全景建立镜头，再继续拆镜。
- 若发现**跨轴硬切**：优先插入中性镜头 / 过机位 / 全景重置镜头。
- 若发现**多轴混乱**：先锁定当前核心互动轴，弱化次要互动轴，必要时拆段处理。
- 若发现**焦点乱跳**：优先重排景别、视高与构图焦点，使核心信息平稳传递。
- 若发现**信息过载**：执行“强重点 / 弱非重点”，删掉非必要镜头。

### Step 0：先做基础影视规则自检与修正
在真正拆镜之前，必须先检查：
- 轴线是否明确
- 左右屏幕方向是否稳定
- 视线方向是否互相成立
- 是否适合优先采用正反打五镜头公式
- 是否存在越轴 / 视线反向 / 主体左右互换

若发现问题，必须先修正空间方案，再继续拆镜，并记录“修正原因”。

### Step 1：提炼戏核
写出这一小段的：
- 段落目标
- 主关系
- 情绪杠杆
- 爆点
- 结果

### Step 2：画空间关系
至少明确：
- 谁在画左 / 画右 / 画中
- 谁在前景 / 中景 / 后景
- 谁高位 / 谁低位
- 谁朝向主要威胁
- 轴线在哪里

### Step 3：拆镜头组
优先拆成镜头组，而不是直接散写镜头。常用镜头组：
- 建立组
- 推进组
- 爆点组
- 结果组
- 转场组

### Step 4：给每镜定义主任务
每镜必须标明：
- 镜头任务
- 首看点
- 结果点
- 风险点 / 回退点

### Step 5：绑定视角与运镜心理动机
每镜必须明确摄像机身份：
- 行为观察
- 动态跟拍
- POV
- OTS
- 上帝视角
- 虫视角
- 低处视角
- 窥视视角

并写清为什么此时要用这个视角。

### Step 6：确定衔接与节拍
每镜写清：
- 切点依据
- 转场方式
- 是否有 Beat / 骤静 / Hit Stop
- 是否预留安全区

### Step 7：写成长版母稿，再压缩派生
先写长版母稿，后生成即梦 / Seedance 字段 / 叙事版。禁止反过来。

## 4.5 老白实操 SOP 增量层（可直接执行）

### A. 剧本转分镜 7 步拆解法
1. **拆剧本**：先按起 / 承 / 转 / 合切成大段，再把每段切成动作单元。
2. **定关键帧**：每个动作单元先抓开始帧 / 高潮帧 / 结束帧三张关键分镜。
3. **补过渡帧**：只补必要过渡镜头，观众能自行脑补的镜头优先删除。
4. **标时长**：按情绪与信息量标每镜时长，而不是平均分配。
5. **加声音**：同步标出台词 / 音效 / BGM 起止点。
6. **顺节奏**：把镜头串起来检查是否拖、堵、跳。
7. **查逻辑**：复查空间关系、动作连续性、视线方向、轴线与跳切风险。

### B. 单张分镜标准模板（结构化字段）
- 镜头号：`集数-段落号-镜头号`
- 景别：远 / 全 / 中 / 近 / 特 / 大特
- 角度：平 / 仰 / 俯 / 侧 / 鸟瞰 / 鱼眼
- 运镜：推 / 拉 / 摇 / 移 / 跟 / 升 / 降 / 甩 / 固定
- 时长：精确到 0.5s
- 画面内容：客观、可拍摄、无抽象修辞
- 声音：台词 / 音效 / BGM
- 备注：光影 / 特效 / 特殊执行要求

### C. 镜头衔接三大黄金法则
1. **动作匹配剪辑**：在动作中点或顶点切换，保证动作方向、速度、受力延续。
2. **视线匹配剪辑**：上镜人物看向哪里，下镜就从对应方向或对应对象接入。
3. **方向匹配剪辑**：人物 / 物体连续运动方向必须稳定；若要改方向，先用中性镜头或全景重置。

### D. 分镜三板斧（90% 场景通用基线）
- **全景交代**：先交代时间 / 地点 / 人物 / 环境。
- **中景动作**：再展示人物主要动作或互动。
- **特写细节**：最后强调关键情绪、道具或命中点。

变体：
- **紧张场景**：特写 → 中景 → 全景
- **抒情场景**：全景 → 特写 → 中景
- **悬念场景**：特写 → 特写 → 全景

### E. 情绪驱动的镜头时长量化参考
- **平静叙事**：2-3s / 镜；固定或缓推；偏中景 / 近景；硬切。
- **紧张刺激**：0.5-1s / 镜；快速摇 / 甩 / 跟；偏特写 / 大特；硬切 / 跳切。
- **抒情悲伤**：5-10s / 镜；缓拉 / 缓移；偏全景 / 远景；淡入淡出 / 叠化。
- **幽默搞笑**：1-2s / 镜；固定或快切；偏中景 / 特写；硬切 / 匹配转场。
- **悬疑恐怖**：3-5s / 镜；缓推 / 跟；偏特写 / 近景；硬切 / 黑场。

### G. 主镜与机位反推法
- **主镜**：不是最漂亮的镜头，而是讲清这一段故事必不可少的核心画面。
- 操作顺序：**先通读剧本 → 抓段落目标 → 浓缩一句话主镜 → 提炼 3-5 个关键主镜 → 再反推机位与补充镜头。**
- 推机位时优先标记：观众最关心的脸 / 手 / 道具 / 命中点在画面何处，再围绕它安排正反打、单打、反应镜头、插入镜头、过机位。
- 复杂场景中，主镜先确定“观众最该看到什么”，再决定“摄影机该站哪儿”。

### H. 分镜叙事三原则
1. **实际上发生了什么**：事件逻辑必须成立。
2. **想让观众看到什么**：主动筛选主信息，不把所有信息平铺给观众。
3. **观众实际上看到了什么**：检查你的镜头是否真的把重点送达。

补充执行动作：
- **强重点**：用反应镜头、特写、重复读点强化核心信息。
- **弱非重点**：删掉无关镜头，避免干扰主信息。
- **节奏推进**：需要加压时，可采用“镜头时长越来越短、景别越来越紧”的推进策略。

### J. 视觉焦点控制（信息锚点层）
- **视觉焦点**：观众第一眼会看到的核心元素，是镜头叙事中的信息锚点。
- **四大控制维度**：
  1. **构图控制**：用三分法交点、黄金螺旋终点、脸带、前景框架与遮挡隔离无关元素。
  2. **光影控制**：核心主体亮、背景压暗，避免多个高亮区争抢注意力。
  3. **景深控制**：浅景深突出主体，深景深用于同时交代人物与环境关系。
  4. **运动控制**：动态元素天然抢焦点，切镜时尽量保持前后镜头焦点位置稳定。
- **红线**：禁止单画面出现多个同等权重焦点；禁止焦点与叙事重点脱节；禁止切镜时焦点大幅跳位。
- **执行动作**：关键节点可用“道具特写 → 焦点转移到人物反应”完成信息递进。

### K. 空间感塑造（纵深与方位层）
- **前中后景三层法**：至少建立两个层次，避免所有元素落在同一平面。
- **透视强化法**：广角拉空间、长焦压空间，用于控制开放感 / 压迫感。
- **空间方位锚定法**：每场戏开场优先用全景 / 定场镜头建立整体布局与初始站位。
- **遮挡关系法**：用前后遮挡明确人物方位与距离。
- **运动展示法**：推 / 拉 / 移 / 跟可动态揭示空间规模与结构。
- **红线**：禁止无全景交代直接连切特写；禁止前后镜头空间逻辑矛盾；禁止全程正面平视导致画面扁平。

### L. 运镜叙事逻辑（8 种基础运镜）
- **推镜头**：聚焦主体、放大情绪、逼近关键信息。
- **拉镜头**：揭示环境、制造疏离感、展示关系变化。
- **摇镜头**：展示环境全貌、跟随视线或多人切换。
- **移镜头**：强化空间纵深与沉浸感。
- **跟镜头**：持续锁定主体，增强代入与动作真实感。
- **升降镜头**：上升用于宏大揭示，下降用于压迫 / 宿命感。
- **甩镜头**：强化突发、切换冲击与速度感。
- **晃动镜头**：模拟纪实、不安、慌乱或失衡主观感受。
- **总原则**：所有运镜必须服务叙事与情绪；必须有清晰起幅与落幅；单镜避免叠加过多运镜造成读点崩坏。

### M. 合法越轴扩展法（创意破规层）
在既有运动越轴 / 中性镜头越轴 / 全景重置越轴之外，可补充：
- **主观镜头越轴**：用角色 POV 视线变化引导观众完成轴线切换。
- **特写缓冲越轴**：插入无明确方向的大特写，弱化空间方向感后再切轴。
- **摄像机连续移动越轴**：镜头自身连续跨轴，不通过硬切完成切换。
- 原则：越轴必须服务关系反转、情绪升级、观察视角变化，不得只为炫技。

### N. 叙事视角系统（主观 / 客观 / 半主观）
- **客观视角**：旁观者位置，适合定场、全局交代、多人空间认知建立。
- **主观视角（POV）**：完全代入角色所见，适合观察、惊恐、打斗、悬疑沉浸段落。
- **半主观视角**：贴近角色但不完全代替其眼睛，是最常用的叙事主线视角。
- **执行规则**：主观镜头必须有前后铺垫（看 → POV → 反应）；同一场戏避免频繁切换主视角；视角必须与观众代入对象一致。

### O. 蒙太奇与镜头组接
- **叙事蒙太奇**：连续、平行、交叉、重复，用于保证事件推进与戏剧张力。
- **表现蒙太奇**：对比、隐喻、抒情，用于表达主题、情绪和潜台词。
- **组接黄金法则**：动接动、静接静、视线匹配、方向匹配、情绪匹配。
- **红线**：禁止为炫技乱用蒙太奇；禁止隐喻过晦涩；禁止交叉节奏失控导致高潮塌陷。

### P. 分镜全流程实战闭环（17 课总收束）
1. 通读剧本并拆成起因 / 经过 / 高潮 / 结果。
2. 提炼一句话主题与主镜序列，确定核心叙事视角。
3. 划定轴线与机位安全区，完成空间设计。
4. 填充景别、视高、构图、焦点、运镜与插入 / 反应 / 过渡镜头。
5. 用节拍、景别、运镜、蒙太奇优化情绪推进。
6. 做合规与流畅度校验：轴向、视角统一、组接、焦点、结果镜头是否成立。
7. 输出标准化分镜表与草图级表达，最终回看是否真的完成叙事目标。

## 5. 镜头组方法论（分镜真正的组织单位）

一个好的分镜，不是很多镜头堆在一起，而是多个镜头组彼此咬合：
- 建立关系组
- 强化压迫组
- 爆发释放组
- 结果兑现组
- 收势留钩组

### 5.2 常用镜头组模板

#### A. 对峙镜头组
- 镜 1：空间 / 关系建立
- 镜 2：权力差强化
- 镜 3：Beat 停顿
- 镜 4：台词 / 动作命中
- 镜 5：结果停住

#### B. 动作爆点镜头组
- 镜 1：关系建立
- 镜 2：起势
- 镜 3：骤静 / Hit Stop
- 镜 4：命中
- 镜 5：结果兑现

#### C. 文戏压迫镜头组
- 镜 1：稳定观察
- 镜 2：微推进 + 表情变化
- 镜 3：反应镜头
- 镜 4：台词命中
- 镜 5：余波停顿

#### D. FPV 穿越镜头组
- 镜 1：入口建立
- 镜 2：穿越介质
- 镜 3：擦身关系
- 镜 4：出口揭示
- 镜 5：结果兑现

## 7. 分镜阶段四大硬门禁

### 门禁 1：可读性门禁
- 首看点必须明确
- 结果点必须明确
- 关键镜头不可被特效 / blur / 字幕遮挡

### 门禁 2：空间门禁
- 左右不乱换
- 轴线不乱跳
- 群众不乱跑
- 主角活动区与字幕安全区受保护

### 门禁 3：节拍门禁
- 每镜节拍数受控
- 爆点前后有进入与收尾空间
- 高密度镜头必须有看清点

### 门禁 4：平台门禁
- 5s / 10s / 15s 时长真实铺满
- 独立片段从 `0s` 起算
- Seedance 长版必须采用统一母格式
- 平台派生稿必须同源

## 8. 特殊场景分镜策略

### 8.1 动作戏
优先回答三件事：
- 谁压谁
- 力怎么传递
- 哪一镜负责看清结果

### 8.2 文戏
优先回答三件事：
- 权力高低位
- 空间屏障
- 哪一拍留白最有杀伤力

### 8.3 群戏
优先回答三件事：
- 谁是主读点
- 群众如何制造压力但不抢戏
- 屏幕分区和动作循环是否稳定

### 8.4 FPV / 穿越
优先回答三件事：
- 路径是否清楚
- 擦身关系是否明确
- 穿过去之后发生了什么

## 9. 常见失败信号

以下情况说明分镜不合格：
- 只是在改写剧本文字，没有镜头系统
- 一镜塞太多任务
- 没先建立空间就直接爆点
- 只有过程，没有结果镜头
- 运镜写得很花，但不知道为什么这么动
- 快切很多，但没有清晰命中点
- 多平台稿件互相打架
- 分镜表写完了，平台却很难执行
