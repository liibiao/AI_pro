# global-scene-library.md — 全局场景资产库

## 用途

## 使用规则
- 场景资产必须写明“功能”，不要只写外观
- 每个高频场景至少给出 1 条镜头建议
- 如果同一场景跨时段使用，必须拆分白天/夜晚版本
- 场景库更新后，要同步给 art-director 与 storyboard-artist
