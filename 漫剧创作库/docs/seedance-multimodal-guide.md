# seedance-multimodal-guide — Seedance 2.0 多模态创作指南

## 用途
统一说明 Seedance 2.0 在图像、视频、音频、文本四模态输入下的能力边界、素材调度方式、适用任务与执行原则，帮助团队从“写一句提示词”升级为“调度多模态素材完成导演式生成”。

## 核心结论
- Seedance 2.0 最强的不是凭空生成，而是根据参考做可控生成。
- 图片定视觉，视频定动作与运镜，音频定节奏与情绪，文本定意图和调度。
- 提示词不只是描述画面，更是调度多模态素材关系的脚本。

## 输入模态与上限
### 图片输入
- 支持：jpeg、png、webp、bmp、tiff、gif
- 数量：≤ 9 张
- 大小：单次总量需小于平台限制，单文件通常建议控制在 30MB 内

### 视频输入
- 支持：mp4、mov
- 数量：≤ 3 个
- 总时长：2-15 秒
- 大小：小于 50MB
- 总像素数范围：约 640×640 到 834×1112 / 720p 范围内

### 音频输入
- 支持：mp3、wav
- 数量：≤ 3 个
- 总时长：不超过 15 秒
- 大小：小于 15MB

### 文本输入
- 自然语言
- 用于绑定素材用途、说明镜头与补充模型不知道的上下文

### 混合输入上限
- 当前支持的混合输入总上限：12 个文件
- 建议优先上传对画面、动作、节奏影响最大的素材

## 交互入口选择
### 首尾帧入口
适合：
- 只上传首帧图 + prompt
- 单镜头延展
- 简单首尾过渡

### 全能参考入口
适合：
- 图像 + 视频 + 音频 + 文本组合输入
- 需要参考动作、运镜、转场、节奏、音色
- 需要做视频延长、视频编辑、复杂复刻

## @素材调度规则
### 基本原则
- 所有素材必须用 `@素材名` 明确绑定用途
- 不要让多个素材竞争同一控制权而不说明优先级
- 同一提示词中，每个素材至少要说明它负责什么

### 常见写法
- `@图片1 作为首帧参考`
- `参考 @视频1 的运镜和动作节奏`
- `@音频1 用于配乐与情绪参考`
- `将 @视频1 延长 5s`
- `将 @视频1 中的角色替换成 @图片2 的形象`

## 四类模态的职责分工
### 图片负责
- 首帧
- 角色外观
- 构图
- 场景样貌
- 材质与光影基准

### 视频负责
- 动作参考
- 运镜参考
- 转场参考
- 节奏参考
- 特效演进路径

### 音频负责
- BGM 节奏
- 音效氛围
- 音色参考
- 说话风格
- 情绪推进

### 文本负责
- 说明素材用途
- 指定镜头意图
- 补充上下文
- 指定编辑目标
- 指定谁动谁不动

## Seedance 2.0 强项能力
- 一致性提升：角色、服装、商品、场景、镜头风格更稳定
- 复杂动作与复杂运镜复刻
- 创意模板与特效复刻
- 视频延长与连续镜头衔接
- 视频局部编辑、角色替换、剧情改写
- 声音、音色、BGM 与卡点能力增强
- 一镜到底与主观视角镜头更可控

## 常见应用场景
### 1. 图像首帧 + 视频动作参考
适合：角色定形后复刻动作与镜头

### 2. 图像 + 多视频融合
适合：合成多段运镜、动作、转场参考

### 3. 视频延长
适合：已有片段后接续生成，不再从零重做

### 4. 视频编辑
适合：局部改动作、换角色、补桥接、颠覆剧情

### 5. 音频驱动
适合：旁白、MV、配乐卡点、方言对白、戏曲片段

## 图生视频控制原则
- 不要重复描述输入图中已经明确且无歧义的信息
- 提示词优先描述“如何变化”，而不是“静态事实”
- 优先写模型不知道、容易理解错或默认不会那样动的信息
- 明确谁动谁不动，对抗 AI 推理惯性
- 图生视频优先服从输入图结构，时间/距离/风格词是辅助控制

## 视频延长与编辑原则
### 视频延长
- 先明确延长的是新增部分时长
- 先写延长后的新内容，再说明如何衔接原视频
- 建议补桥接镜头或环境延展，避免突然起跳

### 视频编辑
- 明确保留什么、不改什么
- 明确替换的对象、片段、动作或情节
- 先小范围测试，再扩展整段改写

## 常见风险与排障
### 1. 素材调用冲突
- 解决：明确谁负责形象、谁负责动作、谁负责运镜、谁负责音色

### 2. 参考过多导致失控
- 解决：优先保留最关键的 1-2 个控制源

### 3. 角色不一致
- 解决：用首帧图 + 角色参考图固定，减少无关风格词

### 4. 镜头衔接生硬
- 解决：增加过渡特写、转场、首尾帧承接、景别差

### 5. 音色不匹配
- 解决：先在剪映等工具提取已生成成功的角色声音，再作为音色参考复用

## 平台限制与合规提醒
- 当前不支持上传包含写实真人脸部的素材作为参考
- 案例中若出现真人写实人脸，仅作能力展示，不代表实际可直接复用
- 商业项目中应优先使用风格化角色、非真人写实脸或授权素材

## 使用建议
1. 先做最小可验证镜头，不一口气赌整段成片
2. 先定参考职责，再写 prompt
3. 先稳定角色和空间，再增加特效和卡点
4. 复杂项目拆成镜头段生成 → 延长 → 补桥接 → 局部编辑
5. 每次成功生成后回收可复用的图、视频、音频参考资产
