# 全品类武打动作戏设计规范 (力的闭环融合版)

> 适用范围：AI 短剧 / 漫剧 / 动作分镜 / Seedance 动作视频设计
> 核心目标：结合“对抗关系 / 身体受力 / 镜头节奏”三要素，与“力的闭环”方法论，建立涵盖武侠、仙侠/玄幻、现代格斗、群像战斗等全品类的工业化“武打戏”指导思想与执行标准。

---

## 1. 核心指导思想：三要素与“力的闭环”

打斗的本质不是单纯的视觉炫技，而是**“动作即叙事，技能即权力”**。
在具体执行 Prompt 和分镜设计时，必须严格贯彻以下两套核心框架：

### A. 设计层：动作三要素（决定打戏的意义与重量）
1. **对抗关系（谁压制谁）**：必须先看清谁占上风、谁被逼退、谁在强撑。没有压迫与反扑的前提，一拳只是一拳，毫无“反扑感”。
2. **身体受力（物理代价）**：重心稳不稳、步伐乱不乱、发力是顺还是硬顶。即便是法术对轰，也必须有物理溃败（倒飞砸石、鲜血喷出、重甲碎裂），不能轻飘飘。
3. **镜头节奏（视觉放大）**：哪一拍停顿，哪一拍推进，哪一拍必须给清晰的结果镜头。快切和 motion blur 只是放大器，不是发动机。

### B. 执行层：力的闭环（决定 AI 的生成下限）
必须在 Prompt 里人为构建**「力的传递链」**，让力依次穿透：**角色 ➔ 节奏 ➔ 环境 ➔ 镜头**。
- 绝招指令护体：必须使用 `@Image` 角色死锁，并全局挂载 `motion blur on BACKGROUND ONLY (characters and weapons stay crisp)` 保证命中点绝对清晰。

---

## 2. 五大武打品类：细分闭环规范与 Prompt 模板

针对不同品类，力的闭环在表现形式上应有所侧重。

### 2.1 物理系格斗（武侠 / 传统搏击 / 冷兵器）
**核心追求：拳拳到肉、刀刀见血的“痛感”与“重感”。**

- **对抗与受力（角色闭环）**：强调腰马合一。发力前必须有清晰的沉肩坠肘或蓄力动作；受击后必须有身体失去平衡的踉跄、呈反弓状向后猛飞。
- **节奏与镜头（节奏/镜头闭环）**：多用中景（MS）交代招式，快切展现连击压迫，特写放大伤口与兵刃碰撞瞬间（碰撞瞬间画面轻微定格）。
- **环境联动（环境闭环）**：利用环境反馈力量（踢碎桌椅、借墙反弹、兵刃在墙上擦出火花、竹叶被气流卷起纷飞）。
- **Prompt 模板（示例）**：
  > @Image黑衣刀客 压低重心突然暴起，持刀极速冲刺；@Image白衣剑客 瞬间横剑格挡硬接，刀剑碰撞爆发冲击波（先静后响）。@Image黑衣刀客 被震得重心不稳踉跄后退，脚下青石板崩裂碎石飞溅。镜头低角度跟拍，命中瞬间猛烈震动，严禁跳轴。motion blur on BACKGROUND ONLY。

### 2.2 能量系斗法（仙侠 / 玄幻 / 超能力）
**核心追求：高维碾压的“压迫感”与法术碰撞的“毁坏力”。**

- **对抗与受力（角色闭环）**：维度打击体现力量差距。不能只亮光，必须有物理溃败（法宝碎裂、重甲炸开、口角狂喷鲜血）。
- **节奏与镜头（节奏/镜头闭环）**：施法前摇必须有“起势”（慢蓄力），释放时毁天灭地（快爆发）。对波僵持时，镜头给施法者面部的吃力特写（青筋、咬牙），配合广角全景（仰视）展现压迫感。
- **环境联动（环境闭环）**：天地变色、气流倒卷、周围碎石悬浮、地面下陷。**绝对门禁**：光效绝不能遮挡脸部读点。
- **Prompt 模板（示例）**：
  > @Image林天 悬浮半空单手结印，雷云滚滚汇聚（缓慢蓄力）。随后万千雷蛇化作雷龙极速俯冲，正中 @Image林傲天 胸口。@Image林傲天 护体金光碎裂，身体如断线风筝砸入地面，砸出深坑与冲天尘土。镜头仰拍雷龙落下，命中瞬间白光定格，尘土不遮挡五官。motion blur on BACKGROUND ONLY。

### 2.3 现代战术格斗（特工 / 枪斗术 / CQC 室内近战）
**核心追求：极简、致命、高效的“工业化杀戮感”。**

- **对抗与受力（角色闭环）**：没有多余的摆架子，招招直奔要害（夺枪、折颈、锁喉）。枪械是近战延伸。
- **节奏与镜头（节奏/镜头闭环）**：高密度的快切（Quick Cuts）与极速的局部特写。例如夺枪瞬间的快切，随后立刻接一声枪响的清晰爆头定格。
- **环境联动（环境闭环）**：狭窄空间的高频利用（身体撞碎走廊玻璃、用书本/毛巾格挡、墙壁擦出弹痕）。
- **Prompt 模板（示例）**：
  > 狭窄电梯内，@Image杀手 极速拔枪，@Image特工 瞬间侧身闪避并反手折断其手腕，夺枪射击一气呵成。@Image杀手 头部中弹向后砸碎电梯玻璃，血液飞溅。镜头快切至特写，手持极度摇晃，命中定格极度清晰。motion blur on BACKGROUND ONLY。

### 2.4 非对称战斗（1打多割草 / 绝境突围）
**核心追求：空间拉扯的“割草感”或被围剿的“绝望突围感”。**

- **对抗与受力（角色闭环）**：
  - **割草局**：主角一招毙敌不作停留，杂兵呈现溃败姿态。
  - **突围局**：主角动作体现体力透支，动作沉重，甚至用敌尸作肉盾。
- **节奏与镜头（节奏/镜头闭环）**：
  - **割草局**：主角高速移动（残影），杂兵反应极慢（对比）。镜头使用甩镜（Whip Pan）在敌阵穿梭。
  - **突围局**：景别从全景（WS）压迫到过肩（OTS）甚至近景（CU），画面塞满敌人的兵刃。
- **环境联动（环境闭环）**：敌人群体如潮水崩溃，血肉横飞（依尺度克制），残肢撞击墙壁。
- **影分身瞬杀割草局（瞬移 / 残影 / 闪现）**：
  - 先用全景锁定围攻空间、主角中轴位置、敌人包围方向与地面参照物，再进入高速闪现。
  - 节奏公式：**围攻建立 → 主体骤静 → 眼神触发 → 瞬移爆发 → 命中慢半拍 → 目标倒飞 / 倒地 → 主体消失 → 甩镜找新目标 → 再出现 → 连续瞬杀 → 残影回收 → 收势留白**。
  - 每次瞬移必须写清：从哪里消失、到谁身前 / 身侧 / 身后再出现、命中哪个接触点、目标如何被迫位移、残影如何留下或收束。
  - 镜头策略：消失与横移过程可用 `whip pan`、急速跟拍、背景 blur、半透明残影；命中帧、敌人受击反馈和主角收势必须清晰。
  - 特效边界：残影数量、透明度、颜色和持续时间要可控，残影服务速度路径，不抢主角脸部、武器、掌拳接触点和敌人倒地结果。
  - 声音闭环：瞬移有短促破空 / 闪烁声，命中有沉闷击打 / 骨骼轻响 / 武器脱手声，结果有倒地、水花、尘土、衣袂和空间混响。

### 2.5 巨物与群战（机甲 / 凶兽 / 军阵）
**核心追求：绝对的“质量感”与“绝望感”。**

- **对抗与受力（角色闭环）**：巨物的动作不应该快，而应该**慢且沉重**。攻击落下时必须展现碾压级的质量。
- **节奏与镜头（节奏/镜头闭环）**：永远用人类的渺小视角（Low Angle 虫视角 / 仰拍）去仰望巨物攻击。
- **环境联动（环境闭环）**：挥动武器带起强烈的音爆云或风压，砸地引发地震波，群战体现“阵型崩溃”与“人仰马翻”。

## 3. 全品类打戏通用指导口诀

> **“物理看腰马，玄幻看异象；**
> **枪斗在咫尺，群战拉空间；**
> **过程快准狠，命中留定格；**
> **光效不遮脸，战损见真章。”**
