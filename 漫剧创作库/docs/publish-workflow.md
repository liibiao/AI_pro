# Publish Workflow — 发布与平台适配流程

> 用途：规范内容从 QA 通过到正式发布前的最后一公里，包括标题、封面、文案、标签、版本和平台差异化处理。

---

## 发布前准备
- 成片版本号明确
- QA 通过
- 合规结论明确
- 标题 / 封面 / 简介已拟定
- 平台适配版本确认

---

## 平台适配维度
### 短视频平台
- 前 3 秒钩子更强
- 标题更直接
- 封面文字更短更狠
- 评论区引导更重要

### 漫剧 / 长内容平台
- 简介可更完整
- 封面更重人物与美术质量
- 标签更偏题材与风格
