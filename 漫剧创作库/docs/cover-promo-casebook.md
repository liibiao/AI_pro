## 高点击封面常见结构
- 双人对峙 + 大字反转句
- 主角近景 + 高情绪表情 + 身份揭示文案
- 受辱瞬间 / 反杀前一秒定格
- 恐怖凝视 / 灵异细节局部放大

## 使用规则
- 封面必须先定义“主卖点”，再决定构图
- 标题、封面、大字文案必须讲同一件事
- 不允许标题一个方向、封面另一个方向
- 复盘时必须回看评论区真实反馈
