# 光动态化提示词指南 (Lighting Dynamics Prompt Guide)

> 适用范围：Seedance 2.0 视频提示词、分镜导演讲戏本、AI 视频生成
> 核心目标：让光从"静态布景"变成"活的叙事参与者"，使画面有呼吸感与时间流逝感。

---

## 1. 核心思想

静态图时代，光是一张照片的布光参数——定死的。
视频时代，光有时间维度——**它在动**。

- 烛光会晃
- 阳光会被云遮挡再透出来
- 车灯会扫过墙壁
- 火焰会在脸上跳动
- 窗外的闪电会瞬间照亮整个房间又归于黑暗

**把光的运动写进提示词 = 让画面"活起来"的最低成本手段。**

与本项目规范的衔接：
- `lighting-color-aesthetics-standard.md` 定义了"光是什么类型、什么颜色"（静态层）
- 本文档定义"光怎么动、怎么随时间和事件变化"（动态层）
- 两者互补，不是替代

---

## 2. 光动态化的三种基本模式

### 2.1 光源自身运动（光源在动）

光源物理位置或强度在变化，光随之一同移动。

| 场景 | 光源动态 | 提示词写法 |
|------|---------|-----------|
| 烛光/火把 | 火焰随风摇晃，光在墙上跳动 | `烛光在墙壁上投下摇晃的影子，火焰随呼吸微微起伏` |
| 车辆/探照灯 | 光束扫过环境 | `一束探照灯光从画面左侧缓慢扫过，依次照亮废弃的货架` |
| 闪电 | 瞬时全亮→归暗 | `窗外闪电骤亮，瞬间照亮整个房间，人物轮廓一闪而过，随即重归黑暗` |
| 灯泡闪烁 | 不稳定电源 | `头顶白炽灯不规则闪烁，每次亮起时人物的影子位置都不同` |
| 摇摆的吊灯 | 来回晃动 | `天花板上悬挂的吊灯缓慢来回摆动，人物面部的光影随灯的摆动交替明暗` |

### 2.2 遮挡物运动（光源不动，遮挡物在动）

光源稳定，但有东西在光源和主体之间移动，产生光影变化。

| 场景 | 遮挡动态 | 提示词写法 |
|------|---------|-----------|
| 窗帘/百叶窗 | 风吹动，光带在人物身上移动 | `百叶窗被风吹动，一道道光带依次扫过人物的脸和肩膀` |
| 树影/枝叶 | 风吹树冠，斑驳光影流动 | `树冠在风中摇曳，斑驳的光影在人物脸上和地面流动` |
| 云层遮挡 | 阳光时隐时现 | `阳光被云层间歇遮挡，环境亮度在明暗之间缓慢脉动` |
| 人群走过 | 身影掠过 | `人群从镜头前走过，一道道阴影快速掠过人物面部` |
| 门开/关 | 光缝变化 | `门被缓慢推开，一束走廊的光逐渐照亮黑暗的房间` |

### 2.3 主体的运动导致光影变化（主体在动，光不动）

光源和环境固定，但人物在空间中位移，导致身上的光影关系发生变化。

| 场景 | 主体动态导致的光影变化 | 提示词写法 |
|------|---------------------|-----------|
| 从暗处走向亮处 | 半身阴影→全身被照亮 | `人物从黑暗的走廊走向出口，阳光逐渐从脚底爬上全身，最终完全照亮` |
| 从亮处走入暗处 | 全身明亮→逐渐被阴影吞没 | `人物背对夕阳走入巷口，光线从他身后逐渐消失，身影没入阴影` |
| 转身 | 受光面/背光面切换 | `人物缓缓转身，面部从背光变成侧光，另一半脸沉入阴影` |
| 蹲下/站起 | 地面反射光变化 | `人物从蹲姿站起，面部从地面反射的暖光区进入直射冷光区` |
| 走过窗前 | 光带从身体一端滑到另一端 | `人物从窗前走过，一束午后的阳光从他的肩膀滑到脸上再消失` |

## 3. 光动态化的叙事功能

光不是装饰，它承担叙事功能。写提示词时，先问自己：**这个镜头的光要完成什么叙事任务？**

### 3.1 情绪信号

| 情绪 | 光动态 | 用法 |
|------|--------|------|
| 紧张/不安 | 光不稳定、闪烁、忽明忽暗 | `头顶灯管发出不稳定的嗡嗡声，光线不规则闪烁` |
| 压抑/窒息 | 光在收窄、阴影在扩大 | `门缝中的光线在逐渐收窄，房间越来越暗` |
| 希望/释放 | 光在扩展、从暗到亮 | `云层散开，阳光从缝隙中倾泻而下，照亮整个废墟` |
| 危险逼近 | 阴影在靠近、光在退却 | `一个巨大的影子从墙壁尽头缓慢向人物方向移动` |
| 时间流逝 | 光在缓慢平移（日出到日落感） | `阳光的角度在缓慢变化，影子从长变短再变长` |

### 3.2 注意力引导

- 光亮处 = 观众看哪里
- 光移动 = 观众跟着看
- 光消失 = 信息隐藏
- 光骤现 = 惊吓/强调

### 3.3 时间与节奏

- 光变化快 = 紧急/混乱
- 光变化慢 = 平静/等待
- 光完全不动 = 时间凝固（适合压迫或神圣感）

## 4. 提示词写法模板

### 基础模板

```
[主光描述] + [动态描述] + [光影结果] + [与主体的关系]
```

### 示例拆解

**原版（静态光）：**
> 昏暗的房间，人物坐在桌前，窗外月光照进来。

**升级版（动态光）：**
> 昏暗的房间，人物坐在桌前。月光从窗外斜射进来，随着窗外树影摇曳，斑驳的光影在人物脸上缓慢流动，每当大块阴影掠过时，他的表情被短暂隐藏。

**再升级（光参与叙事）：**
> 昏暗的房间，人物坐在桌前。月光被缓慢飘过的云层间歇遮挡，每次月光消失时房间完全陷入黑暗，只剩他手中打火机的一簇微弱火苗。月光再次透出时，桌面上的信纸被短暂照亮——上面只有三个字。

## 5. 光动态化的克制原则

1. **不是每个镜头都需要光在动**。静态光适合：压迫留白、权力对峙、情绪冻结时刻
2. **一个镜头只给一个光源动态**。多个光源同时动 = 混乱
3. **光动要与主体动作同步或对比**，不能各动各的
4. **光动态要可执行**，不要写"光线如命运般缠绕"——模型不知道命运怎么缠
5. **优先物理真实的光动态**（火焰/云层/遮挡物），慎用纯抽象的光变化

## 7. 快速参考卡

写提示词时，如果画面里有"光源"，花 5 秒问自己：

```
□ 这个光源是固定的还是在动的？
□ 如果是动的——是光源自己在动，还是有什么东西挡在它前面？
□ 光的运动会怎么影响人物身上的影子/明暗？
□ 这个光动态跟当前情绪/叙事有没有关系？
```

四个问题里，至少回答前两个。回答完，你的光就从"布景"升级成"叙事参与者"了。
