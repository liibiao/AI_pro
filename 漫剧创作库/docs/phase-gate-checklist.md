# Phase Gate Checklist — 阶段门禁检查清单

> 用途：在各阶段流转前做统一门禁检查，配合 `master` 的放行判断使用。适合作为 `08-qa/phase-gate.md` 的母版模板。

---

## 0. 前置检查：链路闭环（Pipeline Sync v2 分层版）

> **详细规范**：`docs/pipeline-sync-protocol.md`

在执行任何阶段门禁前，Producer 必须确认：

- [ ] 自上次 Phase Gate 以来，是否存在**未完成的 L3 闭环任务**
- [ ] L1/L2 积累变更是否已在本次门禁前**批量签收**
- [ ] `docs/pipeline-sync-log.md` 中无未签收的 L3 记录
- [ ] 若本阶段新增或修改了方法论、工作流、Agent 职责、Skill 调用、模板、门禁、项目产出物状态或复盘结论，已按 `docs/project-memory-system.md` 写入对应项目文件，未只保存在聊天记录或外部记忆中
- [ ] 若新工具、新 Agent 或跨 IDE 接手项目，已按 `docs/project-memory-system.md` 完成强制读取顺序与第一轮自检
- **结论：** 可继续门禁 / 存在未闭环变更（先完成闭环再门禁）

> **注意**：L1/L2 允许在 Phase Gate 切换时批量处理，但 L3 必须立即独立闭环。

---

## 0.5 前置检查：创作源输入 / 母版 / 影片风格基调定层

在进入 story → director 前，Producer 必须先完成创作入口、方法论层级与影片风格基调判断：

- [ ] 已默认加载 `docs/master-methodology-toolkit.md` 作为母版通用方法论工具集
- [ ] 已读取 `docs/creative-source-intake-workflow.md`，并完成创作源类型识别：一句话创意 / 故事梗概 / 小说原文 / 已有剧本 / 角色设定 / 世界观 / 从0到1原创 / 已有分镜或资产
- [ ] 已标注创作成熟度 L0-L5，并据此判断进入故事开发线、小说改编线、剧本标准化线或制作执行线
- [ ] 已判断当前新增内容属于：母版通用方法论 / 子风格工具集 / 项目级设定 / 影片风格画质基调 / 场景类型规则
- [ ] 若为子风格工具集，已确认它继承母版，而不是另起孤立规范
- [ ] 已确认母版只作为上层基础指导思想，不替项目决定具体视觉风格和走向
- [ ] 已读取 `docs/film-style-tone-system.md`、`docs/scene-type-style-library.md` 与 `docs/film-style-bible-standard.md`，并完成影片风格画质基调初筛或记录用户指定风格
- [ ] 已完成 Top3 风格推荐或用户指定风格登记，且写清主风格、副风格、光影、色彩、材质、画质、镜头、声音气质和禁止项
- [ ] 已确认 HZW大师风格不再被默认视为唯一影片风格；若使用 HZW，已明确其是主风格，还是 PBR / 构图 / 氛围 / 微动作 / 权重控制方法论
- [ ] 进入批量资产、分镜、D12 / D15 导演故事板图或视频生成前，必须建立项目级 `visual-style-bible.md`
- [ ] 若新增或更新风格基调、场景类型、模板、词库或门禁，已同步 workflow、skill、agent、template、wordlist、phase gate、pipeline sync log 与文件化记忆
- **结论：** 可进入项目阶段 / 需先完成创作源、风格基调或子风格闭环
