# 视角-情绪映射系统 (Perspective-Emotion Mapping System)

> 适用范围：导演讲戏、分镜设计、Seedance 提示词编写、漫画面板构图
> 核心目标：**视角不是技术选择，是叙事态度。** 每一个镜头的"摄像机身份"直接决定观众的代入位置、权力感受和情绪强度。

---

## 1. 核心概念：视角 ≠ 景别 ≠ 角度

这三个概念经常被混用，但在创作中必须区分：

| 概念 | 回答的问题 | 举例 |
|------|-----------|------|
| **景别 (Shot Size)** | 多近？ | 特写 / 中景 / 全景 |
| **角度 (Angle)** | 摄像机高度？ | 平视 / 仰拍 / 俯拍 |
| **视角 (Perspective)** | 摄像机以什么身份存在？ | 第一人称 / 越肩 / 上帝视角 / 鱼眼 |

**视角 > 角度 > 景别**。视角决定叙事身份，角度在此基础上叠加权力关系，景别决定信息密度。

---

## 2. 八大叙事视角体系

### 2.1 POV 主观视角（第一人称）
- **摄像机身份**：角色的眼睛
- **心理功能**：**完全代入，零距离沉浸**
- **观众感受**：我就是角色，我看到的就是角色看到的
- **适用场景**：
  - 角色从昏迷中醒来（视觉模糊→清晰）
  - 被追杀时的逃亡奔跑（剧烈晃动+边缘模糊）
  - 发现关键证据的瞬间
  - 恐怖/悬疑场景（不知道身后有什么）
  - 武器瞄准/战斗第一击
- **不适合**：群像展示、环境交代、角色之间的互动关系展示
- **Seedance 提示词**：`first-person POV, subjective camera, through the character's eyes`
- **使用禁忌**：不要连续超过 2-3 秒，长时间第一人称会让观众失去空间定位感。切换回第三人称时用"角色眨眼/甩头"作为硬切锚点。

### 2.2 OTS 越肩视角（第三人称-亲密型）
- **摄像机身份**：站在一个角色身后，越过肩膀看另一个角色
- **心理功能**：**关系性视角，建立"我在这个对话里"的空间感**
- **观众感受**：我既是旁观者，又参与了这场对话的权力关系
- **适用场景**：
  - 双人对峙/对话的核心镜头
  - 对话中"倾听者"的反应镜头（越倾听者的肩看说话者）
  - 权力反转场景（前后半段切换谁在前谁在后）
  - 谈判/审讯/告白
- **不适合**：无对话的动作场面、环境展示
- **Seedance 提示词**：`over-the-shoulder shot, camera behind character's shoulder, looking past at the other character`
- **使用禁忌**：越肩镜头的前景角色不能完全挡住画面主体，肩膀/头部占比不超过画面 15-20%。双侧越肩对切时，保持高度一致，不要一侧高一侧低（除非故意表达权力差）。

### 2.3 行为观察视角（第三人称-标准型 / ACT视角的日常化版）
- **摄像机身份**：隐形的旁 观者，站在场景边缘记录
- **心理功能**：**客观记录，让观众看到完整的动作和空间关系**
- **观众感受**：我在看这个角色的故事，但保持一定距离
- **适用场景**：
  - **日常叙事的默认视角**（全剧占比最高，约 50-60%）
  - 角色行走、转身、与物体互动
  - 动作戏的"安全距离"展示（能看到出拳和受击的完整链条）
  - 群像站位和空间关系交代
- **不适合**：需要极强代入感的生死瞬间、需要展示宏大局面的俯瞰
- **Seedance 提示词**：`medium shot, observational camera, steady recording of the character`
- **变体**：
  - **侧拍行为视角**：从 90° 侧面记录，适合展示横向运动（追逐、对峙走位）
  - **正面行为视角**：角色面对镜头，适合独白、宣言、最终决战前的对视
  - **背面行为视角**：角色背对镜头，适合表现孤独、离别、走向未知

### 2.4 上帝视角（俯瞰）
- **摄像机身份**：全知全能的旁观者，从高空俯视一切
- **心理功能**：**宿命感、渺小感、全局掌控或全局失控**
- **观众感受**：这些人在命运面前多么渺小（或：我终于看清了全局）
- **适用场景**：
  - 战场全貌/城市全景/大规模场面
  - 角色孤独地站在巨大的空旷空间中
  - 棋盘式布局（展示攻防阵型、包围圈）
  - 时间流逝/四季更迭的蒙太奇
  - "上帝视角最终被打破"的反转（从俯瞰→快速拉近到特写）
- **不适合**：情感细节展示、对话、需要观众代入恐惧的场景
- **Seedance 提示词**：`bird's eye view, aerial shot looking straight down, overhead perspective`
- **使用禁忌**：俯瞰镜头不宜超过 3-4 秒，信息密度过高观众来不及消化。必须配合一个快速拉近到角色层面的镜头（Pull Back Reveal 的反向操作）。

### 2.5 鱼眼/畸变视角
- **摄像机身份**：扭曲现实的观察者
- **心理功能**：**表现角色主观的异常心理状态——眩晕、幻觉、世界观崩塌、被压迫到变形**
- **观众感受**：画面不对劲了，和角色一起感到不安/迷幻/恐惧
- **适用场景**：
  - 角色受到重击后的眩晕反应
  - 精神控制/洗脑/走火入魔的表现
  - 力量觉醒时世界观被重写的瞬间
  - 反派的压倒性力量展示（空间在反派面前"弯曲"）
  - 梦境/幻觉/中毒
- **不适合**：正常叙事段落（全剧使用不超过 1-3 次）
- **Seedance 提示词**：`fisheye lens, barrel distortion, warped perspective, extreme wide-angle distortion`
- **使用禁忌**：**这是视觉核弹级别，比 Dutch Angle 更稀有。** 一部短剧/漫剧最多用 2-3 次，每次不超过 2 秒。用多了就变廉价了。

### 2.6 动态视角（跟拍+实时切换）
- **摄像机身份**：有反应的舞者，跟随角色的能量场实时调整
- **心理功能**：**节奏引擎，让观众的心率跟着镜头一起加速/减速**
- **观众感受**：画面活了，摄像机在呼吸
- **适用场景**：
  - **动作戏的核心视角**——连招跟拍、打击瞬间切换景别
  - 追逐戏的加速/减速节奏控制
  - 角色情绪爆发时的"呼吸运镜"（身体微动→镜头微动）
  - 高潮蒙太奇的节奏控制
- **不适合**：需要稳定情绪压住的文戏、正式对话
- **Seedance 提示词**：`dynamic camera, fluid tracking shot, camera responds to character movement, real-time framing adjustment`
- **关键原则**：动态视角的运镜必须有"呼吸节奏"——加速→爆发→减速→停顿→再加速。不要全程匀速运动，那不叫动态，叫无意义的漂移。

### 2.7 低处视角 / 虫视角（Ground Level / Worm's Eye）
- **摄像机身份**：趴在地上或贴着地面仰视
- **心理功能**：**极端的权力倒置——让观众感到渺小、被压制、或者仰望伟力**
- **观众感受**：我在地上，那个东西太大了/太强了/太可怕了
- **适用场景**：
  - 角色被击倒后仰望施暴者/对手
  - 巨型敌人/建筑/自然力量的压迫感
  - 反派出场的"不可阻挡"感
  - 角色跪地后的视角
- **不适合**：平等对话、需要展示环境全貌
- **Seedance 提示词**：`worm's eye view, ground level camera, extreme low angle looking up, towering perspective`
- **与"低角度仰拍"的区别**：低角度仰拍是摄像机在腰部高度向上拍；虫视角是摄像机贴地，画面中地面占据画面下 30-50%，形成极端的"仰望"感。

### 2.8 窥视视角（Voyeuristic / Surveillance）
- **摄像机身份**：藏起来的偷窥者——门缝、窗帘后、监控摄像头、镜子反射
- **心理功能**：**不安、危险、偷窥感、被监视的恐惧**
- **观众感受**：我不应该看到这个 / 我不知道有没有人在看我
- **适用场景**：
  - 悬疑/恐怖场景
  - 反派的秘密行为
  - 角色被跟踪/监视
  - 通过镜子/水面/窗户的间接观察
  - "打破第四面墙"的前奏
- **不适合**：正常的叙事展示、英雄时刻
- **Seedance 提示词**：`surveillance camera, hidden camera, through crack in door, reflection in mirror, voyeuristic framing`
- **使用禁忌**：窥视视角必须有"被发现"或"转向正常视角"的后续镜头，不能悬而未决地停留在窥视状态。

## 3. 视角选择与情绪调动的核心逻辑

### 3.1 视角切换的三种基本节奏

#### A. 稳定叙事流（日常文戏）
```
行为观察（主视角）→ 偶尔切换 OTS（对话时）→ 回到行为观察
```
节奏平稳，视角切换频率低（每 5-8 秒最多切换 1 次）。观众感到安全。

#### B. 递进代入流（情绪升级）
```
行为观察 → OTS → 行为观察更近景 → 视线/手部 MCU → 角色情绪的 ECU
```
视角不断"靠近"，从"看故事"变成"进入角色的情绪"。景别和距离同步收缩。

#### C. 失控爆发流（高潮/战斗）
```
行为观察 → 动态视角跟拍 → POV（被打的瞬间）→ 低处视角仰视 → 快速切回行为观察（反杀）
→ 全景确认结果
```
视角快速切换，信息密度高，观众心率跟着加速。高潮结束后必须回到行为观察或全景"稳住"。

### 3.2 视角-权力关系映射

| 权力状态 | 推荐视角 | 不推荐视角 |
|----------|---------|-----------|
| 角色处于强势/觉醒 | 行为观察（正面） / OTS（角色在后） / 低处仰望对手 | 俯瞰 / 鱼眼 / 窥视 |
| 角色处于弱势/被压制 | 低处仰望 / POV（被打） / 鱼眼（眩晕） / 窥视（被监视） | 正面行为观察 / 上帝视角 |
| 双方势均力敌 | OTS 对切 / 侧拍行为观察 / 动态视角 | 俯瞰 / POV |
| 揭示真相/反转 | 上帝视角 → 快速拉近 / 窥视 → 揭示 | 稳定行为观察 |
| 孤独/遗弃 | 上帝视角（角色在画面中很小） / 背面行为观察 / 拉远揭示 | POV / OTS |
| 亲密/信任 | OTS 距离近 / 行为观察 MCU / 正面行为观察 | 俯瞰 / 鱼眼 / 窥视 |

### 3.3 视角切换的情绪杠杆

| 切换类型 | 情绪效果 | 使用频率 |
|----------|---------|---------|
| 行为观察 → POV | **代入突增**：从"旁观"瞬间变成"我就是他" | 每集 1-2 次，用在关键爆发点 |
| 行为观察 → 俯瞰 | **孤独突增**：角色突然变得渺小 | 每集 0-1 次，用在情绪低谷 |
| 俯瞰 → 快速拉近到 CU | **冲击突增**：从上帝视角瞬间砸到角色面前 | 每集 0-1 次，用在反转点 |
| OTS 对切突然中断 | **权力反转**：一方突然站起/逼近 | 每集 1-2 次，用在对峙转折 |
| 正常 → 鱼眼 | **世界观崩塌**：角色精神状态突变 | 每集最多 0-1 次，全剧 ≤3 次 |
| 任何视角 → 窥视 | **恐惧突增**：有人/有危险在暗处 | 每集 0-1 次，悬疑向可适当增加 |

## 4. 视角与 Seedance 提示词的落地规范

### 4.1 提示词中必须写明视角身份

不要只写 `medium shot`（这只是景别），必须写清视角身份：

```
❌ 中景，林天站在练武场中间
✅ 行为观察视角，侧拍中景，林天站在练武场中间，摄像机在右前方 45° 记录他的动作
✅ OTS 越肩视角，从林天右肩后方越过肩膀看向对面的林傲天，镜头高度与林天肩膀齐平
✅ POV 主观视角，通过林天的眼睛看到自己手掌上的灵纹纹路正在发光
```

### 4.2 视角描述的必填字段

| 字段 | 说明 |
|------|------|
| 视角类型 | POV / OTS / 行为观察 / 上帝视角 / 鱼眼 / 动态 / 低处 / 窥视 |
| 摄像机位置 | 相对于主体的空间关系（身后/侧面/正面/上方/下方） |
| 摄像机高度 | 地面/腰部/肩部/眼部/高空 |
| 摄像机态度（可选） | 稳定/手持晃动/呼吸感/急促 |

### 4.3 视角切换的提示词写法

在两个相邻镜头之间，用方括号标注视角切换方式：

```
Shot A: [行为观察·侧拍中景] 林天被击退三步撞上柱子
→ [视角切换：行为观察 → POV] 角色视线模糊后重新聚焦
Shot B: [POV] 透过林天的眼睛看到林傲天正在逼近，拳头越来越大
→ [视角切换：POV → 低处视角] 镜头"摔倒"到地面
Shot C: [低处视角·贴地仰拍] 林天仰面躺在地上，看到林傲天居高临下俯视自己
```

## 6. 视角使用频率指南（单集 3 分钟漫剧/短剧）

| 视角 | 建议占比 | 单集使用次数 |
|------|---------|-------------|
| 行为观察（标准第三人称） | 50-60% | 持续使用 |
| OTS 越肩 | 15-20% | 4-8 次 |
| 动态视角 | 10-15% | 2-4 次 |
| POV 主观 | 3-5% | 1-2 次 |
| 低处/虫视角 | 2-3% | 0-2 次 |
| 上帝视角 | 2-3% | 0-1 次 |
| 鱼眼/畸变 | ≤1% | 0-1 次 |
| 窥视 | 1-2% | 0-1 次 |

> **行为观察视角是"主食"，其他视角是"调味料"。** 一顿饭（一集）可以没有调味料，但不能没有主食。调味料放多了会串味。
