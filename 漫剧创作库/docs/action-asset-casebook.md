# action-asset-casebook.md — 正式资产案例库

## 用途
沉淀已经通过 QA、拼接验证或正式资产候选判断的镜头案例，形成“主版本 / 保底版 / 失败版 / 观察型镜头”四类对照资产库，便于后续项目直接复用，并为 `docs/learning-from-failure.md` 提供稳定训练样本来源。

## 使用原则
1. 只收录已完成实验记录与 QA 判断的镜头
2. 每条案例至少包含：任务目标、主版本、保底版本、失败版本或失败原因
3. 优先收录具有方法代表性的镜头，而不是只收录好看的画面
4. prompt-lab 负责整理，quality-control 负责审核，master 决定是否进入标准库
5. 每条案例都应尽量补齐：失败层级、回退触发器、减负动作与是否属于观察型镜头

## 建议补充字段
- 失败层级：主体 / 空间 / 光影 / 动作 / 表情 / 台词 / 群像 / 节拍密度
- 回退触发器：出现什么信号立即回退
- 减负动作：先删什么、保什么
- 观察型判断：可插入条件 / 应移除条件

## 案例 001：SHOT 1-9 — 转身回场
- **项目：** `demo_shortdrama_001`
- **阶段：** 视频 / 情绪动作 / 回场反压
- **模型：** Seedance 2.0
- **目标：** 证明“主动回场 + 重新夺回中心”可以在 baseline 层先成立，而不是依赖速度强化

### 主版本
- **版本：** baseline-v1
- **结果：** 稳定 / A-
- **有效点：**
  - 人物方向明确，不会误读为离场
  - 第一步落点清楚，身体重心成立
  - 中心回夺关系清晰
- **残留问题：** 宾客让位反应偏弱

### 保底版本
- **版本：** fallback-v1
- **结果：** 稳定 / A-
- **保留价值：** 当强化层让人物偏成离场或主体被 blur 吞掉时，可直接切回

### 失败 / 不推荐方向
- **版本：** enhanced-v1
- **问题：** 强化收益有限，不值得继续堆速度层
- **结论：** 保留为问题记录，不进入正式资产主线

### 可复用方法
- 先保“主动回场”关系，不先加速度词
- 回场镜头先验证第一步落点和重心
- 若环境反应不够，再补配角让位层，不先加 blur

## 案例 002：SHOT 1-14 — 门开回头
- **项目：** `demo_shortdrama_001`
- **阶段：** 视频 / 群像事件 / 钩子打断
- **模型：** Seedance 2.0
- **目标：** 证明“门开 + 冷暖变化 + 集体回头”三条信息必须优先于速度强化成立

### 主版本
- **版本：** baseline-v1
- **结果：** 可用 / B+
- **有效点：**
  - 门开事件清楚
  - 冷暖变化成立
  - 群像统一回头总体成立
- **残留问题：** 局部人群略挤

### 保底版本
- **版本：** fallback-v1
- **结果：** 稳定 / B+
- **保留价值：** 群像镜头若因强化层导致各动各的，可直接切回，信息组织更稳

### 失败 / 不推荐方向
- **版本：** enhanced-v1
- **问题：** 打断感增强，但群像统一性下降
- **结论：** 不进入正式资产主线，仅保留问题记录

### 可复用方法
- 群像事件镜头先保事件，不先保速度
- 门开镜头先看空间变化是否清楚，再谈动量
- 人群一旦过乱，优先回退群像动作词，不继续堆强化

## 案例 003：SHOT 1-12 — 轻笑冷眼
- **项目：** `demo_shortdrama_001`
- **阶段：** 视频 / 情绪表演 / 爽点前奏
- **模型：** Seedance 2.0
- **目标：** 证明“轻笑前锁住 / 轻笑后更冷”的细微变化，可以不依赖多余动作就形成高价值爽点

### 主版本
- **版本：** baseline-v1
- **结果：** 稳定 / A
- **有效点：**
  - 轻笑起点清楚
  - 眼神转冷成立
  - 动作极少但压迫感上升
- **残留问题：** 无关键问题

### 保底版本
- **版本：** fallback-v1
- **结果：** 稳定 / A-
- **保留价值：** 当表情镜头被强化层或环境信息吞掉时，可直接切回稳镜头版

### 失败 / 不推荐方向
- **版本：** 不额外扩强化版
- **问题：** 表情镜头收益主要来自控制，不来自叠加强化层
- **结论：** 终版阶段维持 baseline + fallback 双版本结构即可

### 可复用方法
- 情绪表演镜头优先保表情读点，不先保速度
- 轻笑类爽点先看“起点是否成立”，再看“情绪是否更冷”
- 一旦表情信息变脏，直接回退稳镜头

## 案例 004：SHOT 1-13 — 钩子台词
- **项目：** `demo_shortdrama_001`
- **阶段：** 视频 / 台词命中 / 反压兑现
- **模型：** Seedance 2.0
- **目标：** 证明“口型 + 眼神 + 停顿”三项同时成立时，台词镜头本身就能构成正式资产

### 主版本
- **版本：** baseline-v1
- **结果：** 稳定 / A-
- **有效点：**
  - 口型清楚
  - 眼神有压迫感
  - 台词停顿命中
- **残留问题：** 无关键问题

### 保底版本
- **版本：** fallback-v1
- **结果：** 稳定 / A-
- **保留价值：** 当口型、停顿或表情被环境信息干扰时，可直接切回

### 失败 / 不推荐方向
- **版本：** 不额外扩强化版
- **问题：** 台词镜头一旦追求强化，容易损失口型和停顿清晰度
- **结论：** 终版阶段禁止继续加速处理

### 可复用方法
- 台词镜头优先保口型，再保眼神，再保气场
- 稳镜头比速度词更重要
- 钩子台词镜头不适合继续堆 blur 或快切

## 案例 005：SHOT 1-15 — 董事会来人
- **项目：** `demo_shortdrama_001`
- **阶段：** 视频 / 集尾悬念 / 身份确认
- **模型：** Seedance 2.0
- **目标：** 证明“声音信息落地 + 灯下站定 + 空气冻结”可以作为集尾钩子结构独立成立

### 主版本
- **版本：** baseline-v1
- **结果：** 可用 / B+
- **有效点：**
  - 声音信息成立
  - 苏晚站定关系清楚
  - 空气冻结感可读
- **残留问题：** 门口信息略多

### 保底版本
- **版本：** fallback-v1
- **结果：** 稳定 / B+
- **保留价值：** 当门口元素过多导致身份确认不清时，可直接切回更静的版本

### 观察 / 学习点
- **版本：** baseline-v1 继续保留学习价值
- **问题：** 信息量略多时，容易稀释声音命中力
- **结论：** 适合作为“减负判断”学习样本

### 可复用方法
- 集尾身份确认镜头先保信息命中，不先保场面复杂度
- 声音镜头要给画面留空
- 若门口信息过多，先删环境干扰，不先改主叙事信息
