# prompt-casebook — 提示词案例库规范

## 用途
沉淀跨项目可复用的提示词案例，形成从目标、版本、结果到问题复盘的闭环记录。

## 记录原则
1. 每一条案例都必须绑定明确任务目标
2. 必须标注模型、版本、日期、操作者
3. 必须记录结果评估，而不是只存提示词文本
4. 优秀案例与失败案例都要保留
5. 若案例依赖参考图，必须补一层参考图拆解摘要，优先按 `docs/reference-image-analysis-standard.md` 记录主体、空间、光影、构图与风格锚点
6. 若案例来自结构化分镜，必须写清该提示词对应的镜头任务、首看点与回退点，不能把长提示词本身当主资产
