# 摄影机运动与观众心理学规范 (Camera Movement & Viewer Psychology Standard)

> 适用范围：导演讲戏、分镜表设计、Seedance 视频镜头运镜参数
> 核心目标：解决 AI 视频生成的“无脑缓慢推镜头（Slow Push）”或“随机漂移”问题，将**摄影机的每一次运动都与角色的内心状态或剧情推演直接绑定**，利用运镜来控制观众的潜意识心理。

---

## 1. 核心指导思想：摄影机是有态度的观察者

摄影机不只是记录动作的机器，它是观众的眼睛。
- **平庸的运镜**：为了让画面动起来而动（无意义的平移、匀速推镜头）。
- **高级的运镜**：摄影机带有明确的“主观情绪”——它在窥视、在施压、在退缩、在晕眩、或在冷静地旁观。

---

## 2. 五大心理运镜系统与执行标准

### 2.1 侵入与施压 (Aggressive Push-in / Dolly In)
- **心理暗示**：揭示真相、内心恐惧放大、或反派/强权的致命逼近。
- **视觉特征**：镜头以不可阻挡的匀速（甚至略带加速）向人物面部推进，空间被急剧压缩。
- **Seedance 提示词映射**：`aggressive push in, dolly towards character, rapid zoom, background compression`
- **使用禁忌**：不要在普通的日常对话中使用，会显得莫名其妙地紧张。

### 2.2 疏离与遗弃 (Pull Back / Dolly Out)
- **心理暗示**：孤独、无助、绝望、或者人物被庞大的世界/宿命吞噬。
- **视觉特征**：镜头缓慢向后退，人物在画面中变得越来越小，周围空旷的负空间（Negative Space）越来越多。
- **Seedance 提示词映射**：`slow pull back, camera dollying out, expanding negative space, character becoming small in the frame`
- **使用禁忌**：不要在角色获得胜利或力量觉醒时使用后退镜头，这会削弱力量感（除非是表现“一将功成万骨枯”的悲凉）。

### 2.3 偷窥与焦虑 (Handheld / Shaky Cam)
- **心理暗示**：混乱、真实感、极度的心理焦虑、或者被人暗中监视。
- **视觉特征**：镜头带有不规则的微小呼吸感或剧烈晃动，甚至有时焦点不实。
- **Seedance 提示词映射**：`handheld camera, shaky cam, documentary style, unstable framing, voyeuristic angle`
- **使用禁忌**：打戏中适度使用可以增加痛感，但**文戏中如果不是表现极度焦虑（如掩盖杀人现场），严禁使用晃动镜头**，否则会破坏权力的稳定感。

### 2.4 迷失与失控 (Dutch Angle / Vertigo Effect)
- **心理暗示**：世界观崩塌、精神失常、走火入魔、邪恶降临。
- **视觉特征**：
  - **荷兰角 (Dutch Angle)**：地平线倾斜，画面不再横平竖直。
  - **滑动变焦 (Dolly Zoom / Vertigo)**：机位后退同时拉长焦（或机位前进同时推广角），导致主体大小不变，但背景发生剧烈的空间扭曲。
- **Seedance 提示词映射**：`Dutch angle, tilted camera, tilted horizon, vertigo effect, dolly zoom, background warping`
- **使用禁忌**：这是视觉核弹，全剧只能在主角三观破碎或大反派现出真身时使用 1-2 次。

### 2.5 环绕与宿命 (Circular Tracking / Arc Shot)
- **心理暗示**：命运的交汇、极致的浪漫、或者无路可逃的绝境。
- **视觉特征**：摄影机以角色为圆心进行 180 度或 360 度环绕。
  - **慢速环绕**：表现高光时刻的史诗感或浪漫。
  - **快速环绕**：表现人物陷入重围、迷失方向或极度恐慌。
- **Seedance 提示词映射**：`camera tracking in a circle around the character, 360 degree arc shot, spinning camera`

---

### 2.6 穿越与压迫 (FPV Fly-Through / Tunnel Run)
- **心理暗示**：强侵入、目标锁定、危险逼近、空间压迫、命悬一线的高速推进感；适合表现追逐、逃逸、坠入、闯关、异空间通道穿梭。
- **视觉特征**：第一人称或高度主观的广角高速前冲，镜头贴着障碍物、墙体、柱体或缝隙擦身而过，前景快速切换，空间纵深连续被打开；可伴随轻微震颤、边缘动态模糊、鱼眼感或风压扭曲。
- **Seedance 提示词映射**：`FPV fly-through, first-person high-speed rush, threading through a narrow gap, near-miss pass, tunnel run, wide-angle distortion, edge motion blur`
- **使用禁忌**：
  - 不能只写“很快地飞过去”，必须明确入口、穿越介质、出口和穿越后的结果揭示。
  - 不适用于需要稳定权力关系阅读的静态文戏。
  - 若段落中主体目标不明确，FPV 穿越会把信息读点冲散。
  - 穿越距离过长、障碍过密但没有节拍分层时，模型容易生成连续漂移或空间混乱。

#### 2.6.1 触发条件（什么时候必须考虑 FPV）
- 剧本 / 讲戏 / 分镜中出现以下目标时，必须显式判断是否启用 `FPV`：
  - `追逐 / 逃逸 / 坠落 / 闯关 / 穿洞 / 钻缝 / 穿楼 / 通道突破 / 异空间跃迁 / 贴地高速释放`
  - 场景内存在明确的 `洞口 / 门窗 / 裂缝 / 桥洞 / 走廊 / 管道 / 峡谷 / 街道中轴线 / 赛道`
  - 需要观众获得“马上要撞上去 / 掉下去 / 钻过去”的身体感
- 若同时满足“明确路径 + 前景参照物 + 出口结果镜头”三项，优先考虑 `FPV` 方案。

#### 2.6.2 剧本→讲戏→分镜的闭环写法
- **剧本层**：只写事件目标与空间危险，不提前堆镜头术语；重点写清“冲向哪里 / 穿过什么 / 出来后看见什么”。
- **导演讲戏层**：明确 `FPV` 的心理目标（压迫 / 追杀 / 跃迁 / 释放），并指定入口、擦身关系、出口和结果镜头。
- **分镜层**：`FPV` 段落必须拆成最少三步：
  1. 入口建立镜头
  2. 穿越 / 撞击 / 擦身镜头
  3. 穿出后的结果兑现镜头
- **提示词层**：动作、运镜、景别必须与穿越动作绑定，禁止只写“高速穿梭”。
- **QA 层**：检查是否真的写清路径、介质、速度参照物与结果镜头，而不是把 `FPV` 当风格词。

#### 2.6.3 分镜拆解硬规则
- 一段 `FPV` 不得只靠单镜头包打天下；除极短钩子镜头外，默认拆成 `入口 → 穿越 → 落幅`。
- 每个 `FPV` 段必须至少保留一个**结果镜头**，证明“穿过去之后发生了什么”。
- 若是图生视频或多帧工作流，优先调用 `fpv-director-skill` 的 `Trinity` 三帧流模式。
- 若段落重点是情绪停顿、权力静压、关系阅读，禁止强插 `FPV` 炫技镜头。

## 3. 工作流执行门禁

- **Director (导演)**：在《导演讲戏本》和分镜表中，**严禁写“镜头推近”这种缺乏情绪的词**。必须写明心理动机，例如：`[侵入性推进：放大主角得知真相的恐惧]` 或 `[缓慢后退：表现主角被家族遗弃的孤独]`。涉及 `FPV` 时，必须同时写清入口 / 擦身介质 / 出口 / 结果镜头。
- **Studio (执行)**：在输入 Seedance 提示词时，必须将运镜参数与角色的心理状态绑定，严禁使用系统默认的随机缓慢漂移。涉及 `FPV` 时，不得只保留速度词，必须保留路径、近景遮挡物和结果揭示。
- **Reviewer (审片)**：如果发现全片的运镜都是千篇一律的“缓慢推近”，直接打回，要求根据情绪重构运镜节奏。涉及 `FPV` 段落时，若不存在明确路径、擦身关系或结果镜头，也直接打回。
