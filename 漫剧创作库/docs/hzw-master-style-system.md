# HZW大师风格系统 — 整剧电影专业质感视觉风格总控

> 定位：HZW大师风格不是单个 skill、单个滤镜词或单张图风格，而是一整套用于短剧 / 漫剧立项前、创作中、生成后的电影专业质感风格总控系统。它必须先继承 `docs/master-methodology-toolkit.md` 的母版通用方法论工具集，再帮助确定本剧的整体视觉风格、编剧师风格、导演风格、分镜师风格，并向下统一约束最终产出的提示词、资产图片、分镜图、视频和后期质检。后续用户提供的 HZW 学习资料，应先提炼为可执行方法论，再并入本文、相关 skill 与模板，不直接堆叠案例。

---

## 0. 与母版通用方法论工具集的关系

HZW大师风格是一套**子风格工具集**，不是孤立体系。它的上游母版是 `docs/master-methodology-toolkit.md`。

```text
母版通用方法论工具集
→ HZW大师风格核心方法论
→ HZW skill
→ HZW 风格母版模板
→ Director / Storyboard Artist / Studio / Reviewer 作业原则
→ workflow / phase gate / pipeline sync log
```

母版负责文戏、武打戏、动作戏、分镜、镜头、生图、视频、声音、后期与 QA 的通用专业方法；但母版不决定本剧最终视觉风格。HZW 作为子风格工具集，才是本剧视觉风格、审美走向、镜头气质、光影色彩、材质语言和最终资产统一性的直接决策层。

## 1. 核心目标

HZW大师风格不是单个滤镜词，而是一套继承母版通用方法论后形成的整剧视觉操作系统。它在每部剧启动前必须先完成“风格定调”，再进入剧本、导演、资产、分镜和生成阶段。

### 1.1 开剧前必须先确定四层风格

| 风格层 | 作用 | 必须产出 |
|--------|------|----------|
| 整剧视觉风格 | 决定这部剧看起来像什么，统一电影专业质感、题材气质、光色、构图和材质 | `visual-style-bible.md` 或 HZW风格母版 |
| 编剧师风格 | 决定故事气质、人物说话方式、爽点密度、悬念组织和情绪底色 | 编剧风格说明：冷峻 / 热血 / 诗性 / 强爽点 / 黑色幽默等 |
| 导演风格 | 决定场面调度、镜头倾向、表演控制、节奏和视听压迫方式 | 导演风格说明：写实克制 / 强类型片 / 压迫式 / 史诗化 / 主观沉浸等 |
| 分镜师风格 | 决定镜头组组织、景别节奏、轴线控制、读点路径和爆点呈现 | 分镜风格说明：近景压迫 / 纵深调度 / 快切动作 / 长镜头观察 / 漫画式冲击等 |

### 1.2 全链路统一对象

1. **剧本与编剧风格**：统一故事气质、台词密度、冲突节奏和情绪颜色。
2. **导演讲戏**：统一表演尺度、调度方式、镜头意图和视听策略。
3. **生图提示词**：统一角色、场景、道具、封面、分镜静帧的画面审美。
4. **分镜**：统一镜头选择、景别节奏、视角身份、读点路径和情绪推进。
5. **场景提示词**：统一空间层级、材质、光影、色彩脚本与环境介质。
6. **视频提示词**：统一动态镜头、动作节拍、光影运动、转场方式和生成参数。
7. **最终资产与成片**：提示词、资产图片、分镜图、视频、剪辑说明和 QA 都必须引用并服从本剧风格母版。

## 2. 风格总公式

```text
HZW大师风格 = 整剧视觉风格总控 + 编剧师风格 + 导演风格 + 分镜师风格 + 戏剧主读点 + 电影级空间层次 + 高控制光影色彩 + 可复用资产锚点 + 镜头动作融合 + 平台可执行参数
```

其中前四项是开剧前的风格根目录，后六项是进入资产、分镜、提示词和视频生成时的执行层。

任何 HZW 风格输出都必须回答六个问题：

| 层级 | 必须回答 |
|------|----------|
| 戏剧层 | 这一张 / 这一镜第一眼要观众看什么？情绪是什么？ |
| 主体层 | 角色脸、服装、姿态、道具的固定锚点是什么？ |
| 场景层 | 空间分几层？前景 / 中景 / 背景分别承担什么？ |
| 光色层 | 主光方向、冷暖关系、明暗对比、点缀色是什么？ |
| 镜头层 | 景别、视角、运镜、起幅落幅如何服务动作或情绪？ |
| 执行层 | 生图 / 分镜 / 视频各平台需要哪些结构化字段和禁止项？ |

## 3. 开剧前风格确认流程

每部剧开始正式创作前，必须先完成一次 HZW 风格确认。没有风格母版，不应进入大批量资产生成、分镜拆解或视频提示词生产。

### 3.1 必问问题

1. 这部剧的题材类型是什么：都市、玄幻、仙侠、科幻、悬疑、复仇、热血、甜宠、恐怖或混合类型？
2. 这部剧整体视觉像什么：写实电影、暗黑史诗、国风水墨、赛博霓虹、冷峻现实、热血少年漫、荒诞黑色电影？
3. 编剧师风格是什么：强爽点、强悬念、强反转、强情绪、强台词、诗性留白、冷幽默、类型片快节奏？
4. 导演风格是什么：克制观察、压迫调度、主观沉浸、史诗大场面、手持纪实、漫画式夸张、动作类型片？
5. 分镜师风格是什么：纵深调度、近景压迫、快切爆点、稳定主镜、长镜头、漫画分格冲击、强主观 POV？
6. 这部剧禁止什么风格：塑料棚拍、网红滤镜、过度柔光、欧美奇幻乱入、日漫化过度、平亮无层次等。

### 3.2 必交付风格母版

风格确认后，必须形成一份本剧风格母版，建议存放：

```text
projects/<项目名>/03-assets/style/hzw-style-bible.md
```

风格母版至少包含：

- 整剧视觉风格一句话定义
- 编剧师风格
- 导演风格
- 分镜师风格
- 角色视觉锚点
- 场景视觉锚点
- 光影色彩锚点
- 镜头语言锚点
- 生图提示词母版
- 场景提示词母版
- 分镜单镜母版
- 视频提示词母版
- 禁止混入的风格

## 4. 五个固定锚点

HZW大师风格在任何任务中都必须锁定以下五类锚点：

### 3.1 角色锚点
- 年龄段、脸型、发型、五官气质、服装主色、身体比例、标志性道具。
- 同一角色跨生图、分镜、视频时，角色锚点不得随意改写。
- 角色状态变化只能来自剧情阶段：低谷、觉醒、战损、升级、黑化、释然。

### 3.2 场景锚点
- 主空间名称、时代 / 题材属性、主材质、空间层级、动线、尺度参照。
- 场景必须有可复用元素，例如门、窗、柱、屏风、霓虹牌、祭坛、擂台、雨巷、灵纹墙。
- 同一场景允许日 / 夜 / 雨 / 战损版本，但核心结构不得漂移。

### 3.3 光影锚点
- 固定主光方向，优先写成“左侧45度冷光 / 背后轮廓光 / 顶部压迫硬光”。
- 明暗不是装饰，必须服务人物处境：压迫、觉醒、隐忍、爆发、孤立、胜利。
- 视频段落必须写光随动作的变化，不只写“电影感光影”。

### 3.4 色彩锚点
- 每部短剧建立 `主色 + 辅色 + 点缀色 + 禁止色`。
- 主色负责世界观，辅色负责场景区分，点缀色负责爽点 / 能量 / 关键道具。
- 同一集避免每个镜头换一套色彩。

### 3.4b 氛围控制锚点

HZW 的氛围不是堆效果，而是让世界“活起来”的受控环境系统。材质提示词决定物体真实感，氛围提示词决定空气、光线、危险、工业感和空间是否有生命。

核心原则：**氛围感不是加得越多越好，而是越有控制越高级；每一个氛围效果都必须有叙事理由、空间位置和强度边界。**

HZW 氛围控制核心词组：

```text
high contrast, haze, semi metallic lighting, volumetric smoke or fog, sparks
```

| 氛围词 | HZW 作用 | 使用边界 |
|--------|----------|----------|
| `high contrast` 高反差 / 大光比 | 通过“藏”和“露”让亮处更亮、暗处更暗，明确明暗关系；用于引导视线、主体正面打亮 / 背景压暗的压迫感、一束光切开黑暗的戏剧性、前景横梁阴影落在主体上的空间定位 | 必须服务第一读点，解决“画面没重点、不知道看哪里”；禁止全画面乱黑、主体丢失或只做无意义高反差 |
| `haze` 雾感 | 让空间更柔和、更有深度，增加自然颗粒感，让空气不再“空”，让光线有存在感，缓解 AI 画面的数码死硬感 | 只做轻到中度空气层；禁止空泛假雾、糊空间、达利园效应 |
| `semi metallic lighting` 电影布光 | 普通打光是照清楚，电影布光是照得有戏；明确哪里该亮、哪里该暗，让光影有方向、有情绪，用光影传递情绪 | 必须写明主光方向、亮暗重点和情绪目的，禁止平亮棚拍或只把场景照亮 |
| `volumetric smoke or fog` 体积烟雾 / 雾气 | 给空气添加介质，让原本看不见的光线可以被肉眼看见，进一步强化层次、空间感和场景立体感 | 必须有来源或空间位置，禁止全屏白雾、无来源烟雾和遮蔽主体轮廓 |
| `sparks` 火花 | 增加工业感、危险感、动态感和能量释放感，让平淡画面活起来 | 必须点到为止，只出现在焊接、摩擦、撞击、破损电路、能量释放等合理位置；禁止廉价海报感、游戏技能特效感、爆炸素材包感 |

HZW 氛围提示词必须写成：

```text
氛围效果 = 叙事理由 + 空间位置 + 强度 + 与主体/光线/动作的关系
```

示例：

```text
high contrast 大光比让主体胸甲被左侧冷硬主光切亮，背景沉入深阴影；薄 haze 只停留在中远景，让背光光束可见但不糊掉轮廓；少量 sparks 从右后方破损机械缝隙飞出，点到为止，强化危险感和工业现场感。
```

反向约束：

```text
禁止堆满氛围词，禁止无来源烟雾，禁止全屏雾化，禁止假雾糊空间，禁止火花过量，禁止游戏特效感，禁止廉价海报感，禁止平亮无重点。
```

### 3.5 镜头锚点
- 镜头风格必须可复用：偏近景压迫、低机位英雄感、纵深构图、前景遮挡、慢推进、动作匹配切。
- 运镜必须绑定人物动作或情绪变化，禁止空泛炫技。
- 分镜与视频提示词必须保持同一镜头任务，不得生成阶段重新发明镜头。

### 3.5b 构图提示词锚点

HZW 构图提示词不是描述画面里有什么，而是控制主体和空间之间的关系。真正高级的构图，不是在画面里放了什么，而是让每一个元素都在替情绪说话。

核心原则：**构图提示词 = 主体位置 + 空间关系 + 前景 / 裁切 / 视觉重量 + 情绪目的。**

| 构图词 | 中文含义 | HZW 作用 | 使用边界 |
|--------|----------|----------|----------|
| `voyeuristic framing` | 窥视感取景 | 用虚焦前景遮挡物从画面边缘伸入，将主体夹在缝隙或环境障碍之间，形成隔着环境观察主体的窥视感、冲击力和氛围感 | 必须说明前景遮挡物、虚焦程度、主体被夹住的位置；禁止无意义遮挡主体或遮挡第一读点 |
| `partial-body framing` | 局部裁幅取景 | 裁掉脸部或部分身体，把信息集中到肢体线条、机械臂、剑、手压刀柄等力量线条上，制造戏剧张力 | 必须明确裁掉哪里、保留哪条力量线和情绪目的；禁止误裁关键表情或导致主体不可读 |
| `asymmetrical balance` | 非对称平衡 | 不做完全对称，而用元素视觉重量平衡画面，如大树与小人、云层与留白，塑造孤独、安静或压迫情绪 | 必须写清左右 / 上下视觉重量如何互相平衡；禁止画面失衡变成随意偏置 |
| `centered composition` | 居中构图 | 将主体放在画面中心，制造秩序、稳定、仪式感；若遮住主体脸部，可把重心压在上半部分形成压迫感 | 必须说明居中服务稳定、压迫、仪式或英雄感；禁止所有镜头机械居中导致单调 |

构图提示词必须与第一读点和情绪目标绑定，不能作为英文专业词堆叠。英文构图术语因模型识别权重较高，可以保留原文，但必须配合中文解释和空间关系约束。

### 3.5c 微动作与表演真实感锚点

HZW 人物不能只写大肌肉群动作。真人的真实感来自小肌肉群的微表情、微动作和呼吸节奏；AI 人物僵硬、像机器人，通常是因为只执行了“走、看、打、抽烟、转身”等大动作，没有生活化的细节链。

核心原则：**人物表演提示词 = 大动作 + 微停顿 + 小肌肉反应 + 呼吸 / 视线 / 表情连锁 + 情绪理由。**

必须把“人物在做什么”升级为“人物为什么这样做，以及身体细节如何连锁反应”：

| 层级 | 写法要求 | 示例 |
|------|----------|------|
| 大动作 | 只说明基础行为，不足以产生真实感 | 抽烟、思考、看人、拔刀、转身 |
| 微停顿 | 加入真实生活中的节奏卡点 | 烟送到嘴边时短暂停顿，像注意力被思绪打断 |
| 小肌肉反应 | 写面部、眼部、眉头、手指、肩颈等细节 | 吸气时面部肌肉收紧，眉头轻皱，眼周被牵动 |
| 呼吸与气息 | 写吸气、呼气、停顿、气息长短 | 呼气时气息绵长，烟雾缓慢从唇边散开 |
| 情绪理由 | 微动作必须来自角色心理或场景压力 | 严肃沉静、压抑思考、克制怒意、疲惫警觉 |

示例：

```text
一个人边抽烟边思考，烟送到嘴边时有短暂的停顿；吸气时面部肌肉轻微收紧，眉头忍不住皱起，眼部肌肉被牵动；呼气时气息绵长，烟雾缓慢散开，脸保持严肃沉静。
```

微动作必须符合日常生活认知，不能堆成抽搐式表演；一个镜头只选 2-4 个关键微动作，绑定情绪和节拍，禁止让人物同时出现过多不相关小动作。

### 3.6 PBR 材质升级锚点

当 HZW 用于机甲、装甲、载具、武器、金属道具或高规格工业资产时，材质升级必须遵守“只升级物理材质，不新增几何”的原则。材质提示词不能写成“非常有金属质感”这类甲方式夸张描述，而要写清材质与光线如何按真实物理规律互动。

PBR 材质升级的本质：**不动原本五官 / 脸型 / 骨相，也就是不改变原画面设计；只优化皮肤、妆面、光泽、质感，让它从 CG 模型变成被摄影机拍到的真实物体。**

| 规则 | HZW 执行要求 |
|------|--------------|
| PBR 材质 | 使用基于物理的渲染材质，让材质和光线的互动接近真实物理规律，不是简单加亮斑高光 |
| 金属装甲 | 裸铁本身反光有限，金属反光主要来自斜角观看清漆层产生的 Fresnel；使用喷涂金属装甲，带真实清漆层 `clearcoat` 反射，必须体现准确 Fresnel 边缘反射 |
| 粗糙度 | 粗糙度不是摸起来扎不扎手，而是反光锐利还是发散；在现有面板上做符合物理逻辑的 roughness variation，不同面板因新旧、积灰、擦拭频率不同而有细微差异 |
| 几何限制 | 绝不新增几何结构、外接零件、额外装甲片、无来源凸起或新缝隙；只升级真实感，不改变原本创作设计 |
| 微观纹理 | 不加大量大划痕 / 大战损，只加现实里肉眼未必注意、但摄影机近看会捕捉到的小纹理，例如非常轻微的橘皮漆质感、细小微划痕、淡淡擦拭痕迹 |
| 污垢灰尘 | 脏和旧必须有生活物理逻辑，只能存在于现有缝隙、关节内部、接触凹陷、积灰面或常被擦拭面的边界，不得随机铺满表面 |
| 边缘磨损 | 只能沿现有边缘出现，不得凭空创造新的损坏图案、裂口或战损形状 |
| AO / 接触阴影 | 加强现有缝隙中的环境遮蔽 AO 与接触阴影；两个结构贴近处、凹陷夹角里光线更难进入，因此应更暗，让结构立体感更真实但不改结构 |
| GI / 高光 | 改善全局光照 GI，让光照在环境中有真实反弹；使用更真实的高光滚降，让亮到暗的过渡自然，避免塑料反光和数码味 |
| 电影化 HDR / 类 ACES | 暗部和亮部都保留细节，不出现死黑或过曝，这是电影感真实度的一部分 |
| 后期颗粒 / halation | 允许细微胶片颗粒与极轻微 halation 晕光，模拟真实拍摄里的细微瑕疵，去掉 AI / CG 过度干净感；不得风格化、梦幻化或过度泛光 |

PBR 材质升级核心词组：

```text
PBR材质，裸铁，粗糙度变化，AO，GI，高光滚降，电影化HDR/类ACES色调映射，细微胶片颗粒、极轻微晕光(halation)
```

这组词只能在理解作用后按目标调用，不能乱堆：PBR 负责物理互动，裸铁 / 粗糙度变化负责金属真实反光差异，AO 负责缝隙阴影，GI 负责环境反弹光，高光滚降负责自然亮暗过渡，电影化 HDR / 类 ACES 负责保留暗部亮部细节，细微颗粒与极轻微 halation 负责去掉 AI 过度干净感。

PBR 材质升级提示词应优先使用：

```text
仅通过 PBR 材质升级实现，不新增任何几何结构；喷涂金属装甲，真实 clearcoat 反射，准确 Fresnel 边缘反射；现有面板存在符合物理逻辑的不均匀粗糙度变化，面板之间粗糙度略有差异；仅有非常轻微橘皮漆质感、细小微划痕、淡淡擦拭痕迹；污垢和灰尘只聚集在现有缝隙与关节内部；边缘磨损只沿现有边缘出现；加强现有缝隙 AO 与接触阴影；改善 GI，全局光照真实，高光滚降自然，电影化 HDR，类 ACES 色调映射；细微胶片颗粒，极轻微 halation，不风格化。
```

反向约束必须包含：

```text
禁止新增几何结构，禁止新增装甲片，禁止新增缝隙，禁止随机裂纹，禁止凭空战损，禁止大面积污垢，禁止夸张刮痕，禁止塑料感，禁止过度泛光，禁止风格化滤镜。
```

## 4.5 提示词长度控制锚点

HZW 提示词的好坏与长度没有直接关系：不是越长越好，也不是越短越好。唯一判断标准是：**画面越简单，目标越明确；目标越复杂，描述越精准。**

### 4.5.1 两类常见误区

| 误区 | 问题 | HZW 回退方式 |
|------|------|--------------|
| 盲目追求复杂长提示词 | 把高级词、效果词、画质词全部堆进去，混入大量与当前目标无关的信息，让 AI 抓不住核心需求 | 删除与本次目标无关的烟雾、火花、大光比、机甲、电影镜头等词，只保留服务第一读点、主体、光影、材质和结果的描述 |
| 盲目追求极简短提示词 | 复杂电影感画面只写几个词，AI 无法理解空间、光影、材质、氛围和动作关系，结果平淡普通 | 按目标补齐必要细节：主体锚点、空间层次、光影方向、材质、氛围理由、镜头结果 |

### 4.5.2 长度匹配公式

```text
提示词长度 = 目标复杂度 × 必要信息密度
```

- 简单基础画面：只写核心目标，避免加无关复杂效果。例如：`25岁女生，白T恤，半身正面，左侧光`。
- 复杂高级画面：可以写长，但每个描述都必须有对应理由。例如工业机甲短片可使用 `high contrast` 引导视线、`sparks` 强化工业危险感，但不能因为“高级”而乱加。

### 4.5.3 HZW 判断标准

每个提示词元素输出前必须通过三问：

1. 它是否服务本次画面目标？
2. 它是否服务第一读点、空间层次、光影、材质、氛围或动作结果之一？
3. 删除它以后，画面目标是否仍然成立？如果成立，就优先删除。

核心原则：**高级提示词是控制出来的，不是堆叠出来的；有效提示词只给 AI 必要的、与目标匹配的精准信息。**

## 4.5b 提示词执行权重锚点

HZW 提示词不是在“完整描述创作者脑子里的想法”，而是在决定 AI 优先看见什么。AI 不会自动补全隐含的空间关系、意图逻辑和方向关系，它会优先执行提示词里最明确、最容易视觉化、最强动作化的信号。

核心原则：**AIGC 提示词的本质，不是在描述你想要什么，而是在决定 AI 优先看见什么。**

补充原则：**提示词没有固定执行顺序，只有执行权重；执行权重也不是线性排序，而是多种信号之间的竞争。**模型不是按“主体 → 动作 → 风格”的流程图执行，而是在所有词、参考图和训练数据惯性之间分配解释权。

### 4.5b.1 权重判断

| 类型 | 权重 | 说明 |
|------|------|------|
| 明确动作词 | 高 | 如双手合十、俯身参拜、抬手、奔跑、挥刀，AI 会优先让动作可见 |
| 明确姿态词 | 高 | 如身体朝向正前方、头部正对目标、半跪、背对镜头 |
| 明确对象词 | 高 | 如正前方佛像、右手武器、胸前发光核心、背景巨大佛像 |
| 隐含空间关系 | 低 | 如“背景是佛像”并不等于“人物正对佛像” |
| 空泛修饰词 | 低 | 如克制地、明确地、非常地、电影感、高级感，不能替代动作和空间关系 |

### 4.5b.2 五个权重竞争因素

1. **词本身的强度**：双手合十、跪拜、挥刀、奔跑等动作词天然更强；克制地、自然地等修饰词天然更弱。
2. **词是否容易视觉化**：抬头、转身、半跪比虔诚、压抑、庄严更容易被模型执行；抽象词必须转译成可见姿态、表情、构图或光影。
3. **词之间是否冲突**：例如“背对镜头看向前方佛像，同时让观众明显看到表情”本身冲突，模型会折中成侧头、半侧脸或重构站位。
4. **训练数据里的组合频率**：模型会向高频视觉组合靠拢，例如“僧人 + 双手合十 + 侧脸 + 参拜”可能比创作者隐含的正面朝向更有支配力。
5. **参考图的影响**：参考图同样参与争夺解释权；人物背影偏右、佛像偏左等视觉惯性，会影响模型推导出的朝向和空间关系。

### 4.5b.3 优化规则

当生成结果“看似符合提示词，但与意图不一致”时，必须先排查执行权重：

1. 找出提示词里最强的动作词、姿态词和对象词。
2. 判断这些强权重词是否抢走了画面结构或人物朝向。
3. 检查提示词中是否存在互相冲突的视觉要求。
4. 检查模型是否被训练数据里的高频组合带偏。
5. 检查参考图是否提供了更强的视觉惯性。
6. 把脑子里的隐性逻辑改写成显性强权重词，例如“身体朝向正前方”“头部正对佛像”“目标位于画面正前方”。
7. 删除会干扰构图、朝向和空间关系的高权重动作词。
8. 用明确方向、对象和身体关系替代空泛修饰。

错误示例：

```text
僧人，望向佛像，双手合十，俯身参拜，双手抬至胸前，背景是巨大佛像，参考图XXX
```

问题：`双手合十`、`俯身参拜`、`双手抬至胸前` 是强动作词，AI 为了让动作可见，可能改写人物朝向；而“背景是巨大佛像”没有显性说明人物正对佛像。

校正示例：

```text
僧人，转头看向正前方的佛像，拜佛，身体朝向正前方，头部正对佛像，背景是巨大佛像，参考图XXX
```

## 4.6 抽卡方向校正锚点

HZW 允许抽卡，但禁止在错误方向上无限抽卡。抽卡的前提是：**主体定义、镜头、行为、场景和约束都已经精准；否则反复生成只是在错误方向上碰运气。**

### 4.6.1 核心问题：知识的诅咒

创作者自己知道“机甲”“怪物”“高级机器人”“神秘装置”指什么，但 AI 未必知道。笼统主体词在 AI 眼里可能漂移成外星人、怪物、普通机器人、特摄角色或完全不同的形象。把自己的认知默认成 AI 也懂，就是知识的诅咒。

### 4.6.2 抽卡前排查顺序

```text
生成失败 → 不先疯狂抽卡 → 先排查提示词方向 → 校正主体定义 → 再少量抽卡验证
```

必须优先检查：

1. 主体是否是 AI 能明确识别的精准对象，而不是创作者自己才懂的笼统词。
2. 主体锚点是否足够具体：外形轮廓、颜色、部件、发光位置、比例、姿态、不可变化项。
3. 镜头是否稳定：如 `locked-off tripod` / 固定机位 / 不手持 / 不漂移。
4. 行为是否明确：谁动、动什么、不动什么、运动速度和幅度。
5. 场景与环境介质是否只允许该动的元素动，例如薄雾、烟、体积光束可轻微变化，其余物体静止。
6. 约束是否结构清晰：常亮、不闪烁、不变化、不变形、不重构、不新增动作。

### 4.6.3 主体定义替换原则

```text
笼统主体词 → AI 可识别的精准主体描述 / 项目角色资产名 / 固定外观锚点
```

错误方向示例：

```text
机甲眼部绿色光保持稳定常亮
```

校正方向示例：

```text
[项目已登记机甲资产名]，高大人形战斗装甲，紫黑主色，细长头部轮廓，双眼绿色发光，眼部绿色光保持稳定常亮，不闪烁、不变化
```

如果任务依赖参考图或项目资产，应优先使用项目登记资产名与固定锚点，而不是临时换成泛化 IP 名称。只有当主体定义已经精准、约束结构清晰、失败仍来自模型随机性时，抽卡才有意义。

## 4.7 生图顺序锚点：先信息版，再情绪渲染

HZW 生图禁止一开始就堆电影感、氛围、材质和影调词。正确顺序是：**先做信息版（Readability Pass），锁死内容；再做情绪渲染版，添加镜头语言、材质、光影和氛围。**

### 4.7.1 信息版（Readability Pass）

信息版使用大屏光 / 高可读性光照，目标是让 AI 看清所有基础内容，禁止暗部、高光和氛围效果吞掉结构。

信息版只处理：

1. 人物 / 主体 / 道具是否正确。
2. 构图、站位、比例和空间结构是否正确。
3. 主体行为、姿态和约束是否清楚。
4. 固定机位、静止项、允许运动项是否写明。
5. 角色、道具、场景和关键发光项是否锁定。

信息版禁止加入：

```text
high contrast, haze, volumetric smoke or fog, sparks, 逆光，体积光，胶片颗粒，复杂影调，强风格化调色，电影感氛围词
```

信息版示例：

```text
大屏光，[项目已登记机甲资产名]，站在工业工厂前，机位完全锁定，除烟雾外所有物体完全静止，眼部绿色光保持稳定常亮。
```

### 4.7.2 情绪渲染版

只有当信息版的主体、构图、行为、道具、场景和约束全部正确后，才允许进入情绪渲染版。情绪渲染版是在信息版基础上添加影调、氛围、情绪、色彩、明暗对比、轮廓光、逆光、体积光、雾、烟、雨雪、胶片颗粒、PBR 材质、AO、GI、电影化 HDR / 类 ACES 等效果。

情绪渲染版示例：

```text
大屏光，[项目已登记机甲资产名]，站在工业工厂前，机位完全锁定，除烟雾外所有物体完全静止，眼部绿色光保持稳定常亮；high contrast, haze, volumetric smoke or fog, 逆光，体积光，PBR材质，AO，GI，细微胶片颗粒，电影化HDR。
```

### 4.7.3 回退规则

如果要换完全不同的光影风格，必须回到信息版重做，禁止在情绪渲染版上继续硬改。因为情绪版的暗部、高光和氛围会吞掉信息，AI 会看不清结构并开始脑补，导致主体重绘、结构漂移、越改越乱、再次陷入疯狂抽卡。

```text
信息版锁内容 → 情绪版加表现 → 大改光影时回到信息版 → 禁止在情绪版上反复补丁式修改
```

## 7. 分镜模板

HZW大师风格分镜优先使用“主读点 → 空间关系 → 情绪推进 → 结果兑现”的镜头组结构。

### 6.1 单镜字段

| 字段 | 要求 |
|------|------|
| 镜头号 | `Shot 01` |
| 镜头任务 | 建关系 / 推情绪 / 给爆点 / 给结果 / 转场 |
| HZW风格锚点 | 本镜必须继承的角色、场景、光色、镜头锚点 |
| 景别视角 | 远景 / 全景 / 中景 / 近景 / 特写 + 客观 / 主观 / 半主观 |
| 起幅 | 镜头开始时第一读点 |
| 动作 / 表演 | 人物具体动作或微表情 |
| 运镜绑定 | 运镜必须绑定动作发生点或情绪变化点 |
| 落幅 | 镜头结束时的结果画面 |
| 光影变化 | 光如何随动作 / 情绪发生变化 |
| 声音 | 对白 / 气口 / 环境音 / 拟音 / 特效音 |
| 禁止项 | 不可改写的角色、场景、光色、轴线和结果 |

### 6.2 镜头组公式

```text
建立镜头：先给空间与权力关系，不急着炫技。
推进镜头：让角色动作、视线或微表情推动情绪。
爆点镜头：用景别压缩、光色突变、速度控制放大关键瞬间。
结果镜头：必须让观众看清动作或情绪造成的结果。
转场镜头：用动作匹配、视线匹配、光色匹配或物件匹配连接下一段。
```

## 8. 视频提示词模板

适用：Seedance、即梦、图生视频、连续人物片段。

```text
HZW大师风格视频片段，[时长]秒，[比例]。
画面主体【完整：[角色固定锚点 + 当前状态 + 服装 + 道具 + 场景位置]】。
@Image [只写已登记资产名]

时间轴：
0.0-0.5秒：[起幅]，观众第一眼看到[主读点]，主光来自[方向]，前景[元素]形成纵深。
0.5-1.5秒：[角色具体动作/微表情]，镜头以[推/拉/跟/摇/固定]绑定[动作节点]，环境介质发生[互动]。
1.5-2.5秒：[情绪或动作推进]，光影/点缀色随[能量/视线/动作]变化，但角色脸、服装、场景结构不漂移。
2.5-3.0秒：[落幅/结果]，动作收住，结果画面清晰，保留0.3秒稳定帧。

环境联动：[风雨雾尘/水汽/碎屑/光粒如何与人物、服装、道具互动]
光线：[主光方向、冷暖、阴影、轮廓光、点缀色]
对白配音：[原台词；无对白则写本段无对白配音]
音效设计：[环境音/拟音/特效音/状态音]
画质：[清晰度、质感、电影级层次、平台参数]
负面提示词：[角色换脸、服装漂移、光线跳变、背景闪烁、低清模糊、多余肢体、文字乱码]
```

若用于即梦 / 图生视频 / 连续人物片段，必须叠加 `docs/jimeng-anti-collapse-core.md`：参考强度75、固定 seed、单段2-3秒、首尾帧一致、运动速度6、采样步数40、底图比例与视频比例一致。

## 9. 风格学习资料吸收流程

后续用户继续提供 HZW 学习资料时，必须按以下流程吸收：

1. **提炼层级**：判断资料属于生图、分镜、场景、视频、光影、角色、材质、转场、后期哪一层。
2. **抽象规则**：把案例转为可复用规则，不原样照抄外部提示词。
3. **冲突判断**：若与现有 `style-guide.md`、`gpt-image-prompt-methodology.md`、`storyboard-methodology.md`、`seedance-prompt-engineering.md` 冲突，优先保留平台稳定性和项目一致性。
4. **模板归位**：开剧风格进 §3，生图进 §5，场景进 §6，分镜进 §7，视频进 §8。
5. **skill 回填**：同步更新 `art-design-skill.md`、`runninghub-image-skill.md`、`storyboard-artist-skill.md`、`storyboard-generator-skill.md`、`seedance-multimodal-skill.md` 中的 HZW 调用规则。
6. **门禁登记**：同步更新 `workflow.md`、`phase-gate-checklist.md`、`skills/README.md`、`pipeline-sync-log.md`。

## 10. HZW风格自检清单

- [ ] 开剧前是否已明确整剧视觉风格、编剧师风格、导演风格、分镜师风格。
- [ ] 是否已形成本剧 HZW 风格母版，并被剧本、导演、资产、分镜、提示词、视频共同引用。
- [ ] 是否明确写出 HZW大师风格，而不是泛泛“高级电影感”。
- [ ] 是否锁定角色锚点、场景锚点、光影锚点、色彩锚点、镜头锚点。
- [ ] 生图是否包含任务类型、主体锚点、画面结构、光影色彩、材质、比例和禁止项。
- [ ] 场景是否有前景 / 中景 / 背景、材质、动线、尺度和可拍摄落点。
- [ ] 分镜是否每镜只有一个核心任务，并明确起幅、动作、运镜绑定、落幅。
- [ ] 视频提示词是否按时间轴写动作和光影变化，并保留固定段名。
- [ ] 是否避免角色换脸、服装漂移、场景重构、光线跳变和风格混杂。
