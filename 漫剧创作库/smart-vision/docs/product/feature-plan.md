# 智能视界平台功能规划

## 1. 平台定位

智能视界是面向 AI 短剧 / 漫剧工业化生产的前端平台工程，负责把创作库方法论、能力包 Runtime、工程记忆、审核门禁与无限画布工作流执行器产品化。

平台大脑统一称为 `AI / 大模型`，支持用户配置模型、OpenAI-compatible 模型和可选 GPT-5.5，不绑定单一模型。

## 2. 第一阶段核心功能

### 2.1 项目入口与工程恢复

- 打开本地智能视界工程目录。
- 读取 `.smart-vision/` 工程状态。
- 恢复当前项目、集数、故事板、任务阶段和下一步动作。
- 扫描缺失产物与孤儿文件，生成恢复检查点。

### 2.2 能力包上下文装配

- 读取创作库 `docs/`、`skills/`、`agents/`、`templates/`、`wordlists/`。
- 根据任务类型装配 AI / 大模型可执行上下文。
- 记录能力包 hash 和 Runtime hash。

### 2.3 任务流与审核门禁

- 将剧本、资产、分镜、提示词、生成、审核拆为可追踪任务。
- 每个阶段写入工程记忆。
- Phase Gate 未通过时阻止进入下一阶段。

### 2.4 无限画布入口

- 内嵌或跳转迁移版无限画布。
- 支持 Workflow JSON 导入、节点状态查看、生成任务触发。
- 保留原无限画布 UI、JS 逻辑与本地服务能力。

### 2.5 产物与版本管理

- 记录图片、视频、提示词、故事板、审核结果的路径、版本、模型、状态。
- 支持迁移到另一台电脑后通过工程文件恢复。

## 3. 后续功能

- 平台壳层 React / TypeScript 化。
- Recipe 可视化编辑。
- 多模型 provider 管理。
- 审核中心与返工队列。
- 项目级仪表盘。
- 多人协作与云同步增强。
