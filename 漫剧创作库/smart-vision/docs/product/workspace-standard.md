# 智能视界输出目录标准

`smart-vision/outputs/` 按用户可见优先级组织，不按内部生产阶段堆目录。

```text
smart-vision/outputs/
├── .smart-vision/              # 系统状态账本，勿手动改
├── 01-资产图与提示词/           # 第一优先级：角色、道具、场景、故事板、配套提示词
│   ├── 角色/
│   ├── 道具/
│   ├── 场景/
│   ├── 故事板/
│   ├── 提示词/
│   └── 参考图/
├── 02-工作流/                  # 第二优先级：可导入画布的 .mjb-workflow.json
├── 03-视频/                    # 第三优先级：生成视频、剪辑片段、成片视频
├── 04-输入资料/                # 第四优先级：原始输入、能力上下文、规划资料
│   ├── 原始输入/
│   ├── 能力上下文/
│   └── 规划/
└── 05-可选输出/                # UI 层可筛选显示：剧本、分镜表、审核、剪辑发布、历史归档
    ├── 剧本/
    ├── 分镜表/
    ├── 审核剪辑发布/
    └── 历史归档/
```

## UI 展示原则

1. 默认优先展示 `01-资产图与提示词/`。
2. `02-工作流/` 次级展示，用于导入无限画布。
3. `03-视频/` 第三级展示，用于预览生成结果。
4. `04-输入资料/` 保留为项目恢复和追溯入口。
5. `05-可选输出/剧本` 与 `05-可选输出/分镜表` 在 UI 层作为可选筛选项，不默认抢占主视图。
