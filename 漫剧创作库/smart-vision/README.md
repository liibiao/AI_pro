# 智能视界独立平台工程

`smart-vision/` 是智能视界平台开发工程主目录，用于承载平台文档、前端平台壳层、无限画布迁移副本、后台服务副本、能力包 Runtime 预留接口、配置与工程状态模板。

## 当前阶段定位

本阶段目标不是重写无限画布，而是将现有无限画布相关代码完整迁移到独立工程内，作为后续智能视界能力对接和接口调用基础。

## 目录分层

- `docs/`：平台开发文档、落地计划、架构设计、功能规划、技术选型、画布接入与迁移验收。
- `app/`：后续智能视界前端平台壳层预留区，当前不改造原画布 UI。
- `canvas/legacy-workbench/`：原无限画布 UI 与 JS 逻辑迁移副本。
- `services/workbench/`：原工作台/无限画布相关 Python 服务迁移副本。
- `config/`：模型、节点、环境与 provider 配置入口。
- `runtime/`：能力包 Runtime、Workflow JSON Builder、工程记忆接口预留区。
- `templates/`：`.smart-vision/` 工程状态模板。
- `scripts/`：迁移版启动、检查和验证脚本。
- `outputs/`：智能视界独立工程交付区，承载 `.smart-vision/` 状态源、Workflow、生成图片 / 视频 / 音频、审核记录、剪辑结果、发布包与历史归档；所有智能视界最终交付物必须写入此目录。

## 迁移原则

1. 原始 `tools/`、根 `studio` 不删除、不移动、不重构。
2. 无限画布迁移以完整复制和最小路径适配为主。
3. 不迁移与无限画布无直接关系的批处理、提示词流水线、RunningHub 项目生产脚本。
4. 保留 `AI / 大模型` 泛称，不把平台大脑绑定到单一模型。
5. 后续平台化改造必须先验证迁移版画布仍可正常打开、加载配置、调用服务。
