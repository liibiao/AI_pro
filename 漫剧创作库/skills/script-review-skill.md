# script-review-skill — 剧本审核技能

## 技能定位
从节奏、冲突、爽点、悬念、台词五个维度审核剧本，帮助编剧快速发现问题并给出可执行修改意见。

## 审核维度
- 节奏是否拖沓
- 冲突是否明确
- 爽点是否够密
- 悬念是否有效
- 台词是否有力

## 输出建议
- 总分
- 维度评分
- 关键问题列表
- 修改建议
- 是否通过

## 常见问题
- 开场过慢
- 人物目标不清
- 反派压力不足
- 结尾钩子弱
- 台词解释太多

## 输出位置
- `08-qa/ep*-script-review.md`

## 失败信号
- 审核只给感受，不给定位与建议
