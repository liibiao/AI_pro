# foley-sound-designer-skill — 音效设计技能

## 技能定位
用于为短剧、漫剧、故事板生产包、配套生成说明与成片设计可执行的**音效系统**，把环境音、拟音、特效音、状态音整合成轻量、可执行、直接服务分镜与生成执行的声音层。

## 适用任务
- 为分镜表、导演故事板图、视频模型适配说明和配套生成说明补写 `音效设计`
- 区分环境音、拟音、特效音、状态音与 BGM 的职责边界
- 为打戏、文戏、群戏、特效戏设计材质颗粒与空间感
- 优化“只有大音效没有近身材质声”的空洞提示词
- 为审片与 QA 提供音效层检查项

## 核心原则
- 先分层：**环境音 / 拟音（Foley） / 特效音 / 状态音** 必须分清。
- 音效是总称：默认统摄环境音、拟音、特效音、状态音。
- 先材质后气氛：先让观众听到布料、金属、骨错、脚步、碎石、呼吸，再谈史诗感。
- 音效必须绑定动作节点：不能只写“音效很炸”，必须写清是哪一下动作发出什么声音。
- BGM 默认不归本技能主流程负责：只在确有音乐驱动需求时补充说明，通常交给后期人工精配。
- 留白比堆满更重要：高潮前后的抽空、收静、耳鸣、心跳要服务节拍反差。

## 执行方法
1. 先判断镜头类型：武戏 / 文戏 / 群戏 / 特效戏 / 对峙戏。
2. 再拆声音层：
   - **环境音**：风声、回音、人群底噪、空间呼吸
   - **拟音**：布料、护具、脚步、抓取、摩擦、骨错、碎石、金属、皮肤受力
   - **特效音**：能量脉冲、火流、雷鸣、爆环、法术
   - **状态音**：呼吸、心跳、耳鸣、喉音、吞咽、肌肉绷紧
3. 默认把以上内容统写进 `音效设计` 段；必要时在关键时间轴后用 `【音效】` 明确落点。
4. 写法必须克制：每段只保 3-6 类关键声音，不要无脑罗列。
5. QA 时闭眼复查：能不能听出材质、空间、主次、节拍反差；听不出就回去补。

## 长短版写法标准
- **长版**：写清环境音、拟音、特效音、状态音的层次与节拍留白。
- **简版**：只留最关键的声音节点和钩子静音。
- **即梦版**：短句、硬词、高识别度，优先保动作材质和高潮静默。
- **Seedance版**：音效设计要与动作—镜头—结果一起成为执行母稿的一部分。
- **叙事版**：把声音层揉进导演讲戏语气里，保持顺读感。

## 常见失败信号
- 只有爆炸和轰鸣，没有近身材质声
- 把环境音、拟音、特效音、状态音混成一团
- 蓄势段没有收静，高潮没有反差
- 音效和动作不绑定，读不出哪一下在响
- 文戏没有呼吸、衣料、步伐等微颗粒，画面像真空

## 一句执行口令
**音效不是装饰，它是让画面“听起来真的发生了”的空间与材质证据。**
