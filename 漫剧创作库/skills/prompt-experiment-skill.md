# prompt-experiment-skill — 提示词实验技能

## 技能定位
用于系统化测试不同提示词写法、不同模型组合和不同镜头变量，找到更稳定、更可复用的生成方案。

## 适用任务
- 同镜头多版本提示词测试
- 不同模型效果对比
- 稳定关键词筛选
- 失败关键词排查
- baseline / 强化版 / 回退版实验
- 外部视频参考改写验证

## 核心输出
- 实验记录表
- 推荐版本
- 失败案例总结
- 模型适配建议
- 回退策略建议

## 实验原则
- 一次只改变少量变量
- 先拆外部视频中可吸收的方法信息，再列出禁止照搬项
- baseline 先保住主体、关系、受力、节奏、结果镜头
- 强化版每次只增加一层变量
- 记录模型 / 光影 / 动作密度 / 运镜差异
- 一旦漂移，优先回退最近新增强化层
- 明确结果评级
- 优先沉淀可复用结论
- 对失败版、保底版和观察型镜头，补写失败层级、触发器与减负动作
- **镜头动作融合实验**：对比"镜头独立列出"vs"镜头与动作融合绑定"的生成效果，验证融合写法的稳定性提升
- **故事板 / 配套生成说明对照实验**：同一片段先固定故事板生产包，再测试不同模型适配说明压缩强度，记录哪些信息一旦被删掉就会导致动作逻辑、结果镜头或角色一致性失真
- **GPT 生图结构化实验**：涉及 `gpt-image-2` / GPT 生图时，先固定图像类型、画幅比例、分区数量、主体锚点和文字层级，再逐轮测试光影、材质、风格强化项；复杂图优先用 JSON 结构化提示词做 baseline
- **图生图精修实验**：每轮必须明确保留项 / 可变项 / 增强项 / 禁止项，避免参考图绑定范围不清导致脸部漂移、服装锁死或背景无法重构
- **风格产品模板实验**：涉及写实人像、3D微缩、国风插画、科幻机械、自然风光、字体海报等任务时，先固定产品类型，再分别测试风格类型与场景类型，不允许一次同时更换产品、风格、场景三轴
- **人像双段式实验**：同一人物先测试“整体场景单段式”与“整体场景段 + 面部特写锚点段”的稳定性差异，重点记录脸型、眼神、肤质、妆容和服装是否漂移
- **Prompt-as-Code 变量实验**：同一结构模板只替换产品、品牌、角色、比例、主色、标题等变量，验证结构复用是否比整段重写更稳定
- **多面板约束实验**：静态分镜板、动作分解表、UI、信息图先固定格数、编号、分隔线、阅读顺序和文字层级，再逐轮测试风格与材质
- **角色一致性网格实验**：角色设定表、卡牌合集、多姿势参考必须记录脸型、服装、比例、发型、道具是否跨格一致
- **文字可读性实验**：UI、信息图、电商、品牌图优先测试短标题 / 标签 / 数字的可读性，失败时减少文字数量而不是继续增加说明

## 推荐实验流程
1. 选定待实验镜头或页段
2. 若存在外部视频参考，先拆出关系、受力、节奏、结果四类可吸收信息
3. 先写 baseline 版提示词
4. 再写强化版提示词
5. 为可能漂移的镜头预写回退版
6. 记录每轮变量与结果评级
7. 输出推荐版本与禁用写法

## 结果记录建议
每轮实验至少记录：
- 镜头号 / 页码
- 使用模型
- 提示词版本号
- 提示词类型：baseline 版 / 强化版 / 回退版
- 结果评级（A/B/C/废弃）
- 问题描述
- 推荐使用方案

## 失败信号
- 没记录变量，只凭感觉比较
- 没有结果评级
- 实验结论无法复现
- 一次改太多变量，无法判断原因
- 只堆速度词和风格词，不保 baseline

## 智能匹配与风格推荐（Auto-Match）

> 来源：从规则层吸收，作为实验前"题材识别 + 风格推荐 + 时长估算"的预处理工具。

### 三层识别链

```
创作源输入 / 项目立项输入
   ├── 输入类型识别        → 一句话创意 / 故事梗概 / 小说原文 / 已有剧本 / 角色设定 / 世界观 / 从0到1原创 / 已有分镜或资产
   ├── 成熟度判断          → L0-L5，决定故事开发线或制作执行线
   ├── 题材识别（Rl）      → action / thriller / dialogue / lyrical / comedy / crime / horror / racing / pet / balanced
   ├── 场景类型识别        → 命中 `wordlists/style/scene-type-presets.json`
   ├── 风格基调匹配        → Top3 {style_id, 影片基调, 命中理由, 风险}
   └── 时长 / 视觉难度估算  → {total, breakdown, confidence, visual_complexity}
```

### 题材识别规则

| paceKey | 触发关键词 |
|---|---|
| `action` | 追逐/打斗/枪战/爆炸/战斗/搏斗/动作/逃亡/冲刺/对决/生死/危机/高速/追车 |
| `thriller` | 悬疑/惊悚/恐怖/诡异/凶案/密室/追凶/反转/谜团/真相/压迫 |
| `dialogue` | 对话/谈判/争吵/辩论/审讯/采访/会议/课堂/独白/旁白 |
| `lyrical` | 回忆/抒情/浪漫/温柔/诗意/治愈/宁静/唯美/思念/感伤/情绪 |
| `balanced` | 以上均不匹配时的默认回落 |

### 风格匹配流程

1. 用 `wordlists/style/genre-keywords.json` 的 30 条题材-导演-视觉风格映射表做关键词命中统计
2. 按命中次数降序排序，去重取 Top3
3. 无命中时回落：`标准电影感 / cinematic`

### 时长估算

详见 `docs/shot-duration-and-density-standard.md` §12.6 的 Ku 公式。

### 实验接入方式

- 实验前先用 Rl 识别题材，自动匹配 paceKey 驱动 jl() 时长分配
- 实验时可参考 Top3 导演/视觉风格做 A/B 对照
- 置信度判断：`script.length > 300` → high / `> 100` → medium / `< 100` → low（低置信度建议先扩写再实验）
