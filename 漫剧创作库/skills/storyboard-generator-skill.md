# storyboard-generator-skill — 分镜生成技能

## 技能定位
把导演讲戏本转化为结构化分镜表、导演故事板图结构、连续性卡与视频模型适配说明。目标是保证每镜头都有明确任务、明确节拍、明确引用和明确生成依据。

> 本技能是独立 `Storyboard Artist` 角色的核心生产技能之一，负责实际分镜拆解与故事板生产包落地；不再默认等同于 `Director` 本体。

## 适用任务
- 基于导演讲戏本输出分镜表
- 拆分复杂动作成为多个稳定镜头
- 生成 Seedance 2.0 提示词
- 组织 `@人物 / @场景 / @道具 / @视频 / @音频` 引用
- 设计镜头之间的衔接方式
- 生成 D12-Sora2 / D15-Seedance2 专业导演故事板图结构，包括 Panel 格数、每格时长、连续性卡和视频模型适配包

## 分镜总装方法论（新增强制）
- 任何分镜任务都必须先执行 `docs/storyboard-methodology.md` 的五层模型：**戏核层 → 空间层 → 镜头任务层 → 节拍层 → 平台执行层**。
- 任何段落都应先提炼**一句话主镜**与 3-5 个关键主镜节点，再反推镜头组与补充镜头。
- 先拆**镜头组**，再写单镜头；最少识别：建立组 / 推进组 / 爆点组 / 结果组 / 转场组。
- 每个镜头必须显式回答：主任务是什么、首看点是什么、结果点是什么、为什么在这里切。
- 若镜头无法同时保证“关系清晰 + 结果可读 + 平台可执行”，优先拆镜或回退为观察式镜头。
- 优先用**7步拆解法**搭骨架：拆剧本 → 定关键帧 → 补过渡 → 标时长 → 加声音 → 顺节奏 → 查逻辑。
- 动作单元默认先抓**开始帧 / 高潮帧 / 结束帧**三张关键分镜，再补必要过渡。
- 默认采用**单镜标准模板**：镜头号 / 景别 / 角度 / 运镜 / 时长 / 画面内容 / 声音 / 备注。
- 生成分镜时必须同步执行**定义识别 → 风险判定 → 红线命中检查 → 修复回退**四步合规校验。
- 若场景存在空间混乱、视线不稳、多轴冲突或焦点跳变，优先修复后再继续写镜头，不得带病输出。
- 必须额外检查**视觉焦点、空间感、运镜动机、叙事视角、蒙太奇组接**五项高级叙事控制，避免只会拆镜不会引导观众。
- 涉及 POV / 半主观镜头时，必须写清视角来源、前后衔接与代入对象；涉及运镜时，必须写清起幅、落幅与叙事作用。

## 故事板生产包与配套生成说明职责（新增）
- 每个片段必须先生成**故事板生产包**，再按目标模型派生配套生成说明。
- 即梦 / Seedance / 叙事类说明必须从同一故事板生产包派生，禁止绕过故事板各写各的。
- 所有独立片段必须从 `0s` 开始计时，不能沿用整集总时间轴。
- 标题写 5s / 10s / 15s，就必须在故事板 Panel 与模型适配说明里真实铺满，不足时优先补关系动作、环境动作、结果动作，而不是空洞形容词。
- 分镜表中必须显式标出：哪些信息允许在下游生成说明中压缩，哪些信息属于禁止压缩项。
- 配套生成说明必须继承故事板生产包的主体、动作、景别、镜头、声音、站位、环境联动、光线、参考图职责和负面风险，不得把提示词当作新的主创作源。
- `对白配音` 只负责人声层；`音效设计` 统一负责环境音 / 拟音 / 特效音 / 状态音；`BGM` 默认不进入主提示词固定段名。

## HZW大师风格分镜规则
- 若项目使用 HZW大师风格，分镜必须继承同一套角色锚点、场景锚点、光影锚点、色彩锚点和镜头锚点。
- 镜头组优先组织为：建立镜头 → 推进镜头 → 爆点镜头 → 结果镜头 → 转场镜头。
- 每镜必须写清 HZW 风格锚点、起幅、动作 / 表演、运镜绑定、落幅、光影变化与禁止项。
- 从分镜派生生图 / 场景 / 视频提示词时，不得改写已锁定的角色、场景、光色和镜头任务。

## 输出形态说明
### A. 镜头级执行稿（首尾帧优先）
用于把分镜表拆成可逐镜头投喂 Seedance 的执行稿，默认入口优先选"首尾帧"，并把每镜头时长控制在 2.5s-4s 以保证稳定性。

### B. 片段级全能参考 15 秒（可变镜头结构）
用于直接在 Seedance 2.0 的"全能参考"入口生成一个 15 秒片段（适合宣发/预告/片段样片）。
输出格式遵循统一模块：
- 基础信息（项目/大创意/视觉隐喻/结构）
- 参考图清单（以 @素材名 标注用途与镜头范围）
- Shot 1..N（时间段 + 运镜 + 画面 + 参考图/视频/音频 + 风格）
- 全片技术参数（比例/总时长/模式/转场/配乐走向）
- 情绪曲线
- 使用说明（素材职责、谁动谁不动、改动边界）

### C. GPT 生图静态分镜板 / 动作分解参考表
用于把视频分镜表转换为可直接投喂 GPT 生图的静态视觉资产，不替代视频提示词，只服务首帧、分镜预览、动作参考和资产归档。

输出字段必须包含：
- 图像类型：静态分镜板 / 9-panel storyboard / 4×4 动作分解参考表 / 长卷叙事图
- 画幅与网格：2×2 / 3×3 / 4×4 / 横向9格 / 竖版长卷
- 面板编号与阅读顺序：从左到右、从上到下或时间线方向
- 每格任务：镜号、景别、角色位置、核心动作、结果点、说明文字
- 一致性约束：同一角色、同一服装、同一比例、同一主光源、同一场景空间
- 版式约束：清晰边框、留白、编号、短标签、禁止画格溢出
- 负面项：禁止角色换脸、服装漂移、面板数量错误、文字乱码、阅读顺序混乱

## Seedance 三条铁律
### 1. 节拍密度
- 每 2.5 秒 ≤ 1 个动作节拍
- 5 秒镜头最多 2 个节拍

### 2. 安全区
- 前后各预留 0.5 秒
- 开头建镜，结尾收动作

### 3. @引用限制
- 图 ≤ 9
- 视频 ≤ 3
- 音频 ≤ 3

## 分镜拆解原则
- 一个镜头只承担一个核心视觉任务
- 复杂动作必须拆镜
- 先保证可执行性，再追求酷炫度
- 镜头之间必须有清晰连接点，**严禁跨时空默认硬切，必须使用高级转场（Match Cut, Action Match Cut, Wipe 等）**（执行《视听转场与蒙太奇规范》）
- 相邻镜头尽量形成景别差与信息差
- **严格执行《摄影机运动与观众心理学规范》**：严禁"无脑推镜头"，必须根据角色的心理状态指定运镜（如：侵入性推进、疏离感后退、偷窥感手摇、或迷失感荷兰角）。
- **严格执行《后期视听与美学包装总规范》与《光影与色彩美学规范》**：必须注明 Z 轴运动与非居中构图，明确明暗对比（如伦勃朗光、轮廓光）和调色基调，严禁平光棚拍感。
- **严格执行《文戏与戏剧张力表现总规范》**：文戏分镜必须体现权力高低位（俯仰角）、空间屏障，并强制插入 2-3 秒的无台词反应镜头（Beat）。
- **严格执行《环境氛围与物理互动规范》与《角色视觉成长弧线规范》**：注明环境介质对人物的物理影响，并核对角色的战损、服装是否与当前阶段匹配。
- **严格执行《镜头动作融合原则》**：帧率切换、运镜、景别变化必须与具体动作时刻绑定编写，禁止在分镜表中独立列出"镜头与构图"板块。每个时间段必须紧跟具体动作描述，升格/降格必须说明为放大什么动作细节或释放什么冲击感。文戏同理——镜头推近必须与微表情变化绑定。
- **严格执行《视听打击与对峙调度方法论》**：强对抗段落必须先建立站位/朝向/距离/主读点，再拆爆点；涉及重击、龙啸、巨物压迫、终结技时，优先拆为“蓄力→骤静→Hit Stop→爆裂释放→结果镜头”，并同步写入音效空间、特效爆点与环境反馈。
- **涉及 `FPV` 的段落必须执行 `fpv-director-skill`**：先判断是否存在明确路径、前景参照物与结果场景；默认拆为 `入口建立 → 穿越动作 → 结果兑现` 三步，除极短钩子外禁止一镜包打天下。
- **图生 / 智能多帧的 `FPV` 段落优先走 `Trinity` 三帧流**：把画面拆成 `起势帧 / 过渡帧 / 落幅帧`，再生成两段动态连接词，避免平台误生机体或空间漂移。

## FPV 段落专项拆镜规则
- 若剧本中出现 `追逐 / 逃逸 / 坠落 / 穿洞 / 钻缝 / 穿楼 / 贴地冲刺 / 异空间跃迁`，必须先判断是否启用 `FPV`。
- 启用 `FPV` 后，分镜表中至少写清：`入口 / 穿越介质 / 擦身关系 / 出口 / 结果镜头`。
- 至少保留一个**结果镜头**，确认“穿过去之后发生了什么”；禁止只保留速度过程，不保留兑现。
- 若空间路径不清、前景参照物不足、信息重点是对话或权力关系，直接回退到观察式镜头，不强做 `FPV`。

## 时长适配规则
### 5 秒
- 快节奏爆点、抓眼球、强调一个核心亮点
- 漫剧 / 微短剧建议 2-3 镜头
- 适合单次爆发、单次反应、单次钩子，不适合堆叠多重速度变化

### 10 秒
- 简单情节、情绪递进、卖点递进
- 漫剧 / 微短剧建议 4-6 镜头
- 适合"压制 → 停顿 → 反应"或"起势 → 爆发 → 命中"的完整小节奏

### 15 秒
- 完整小情节或全维展示
- 漫剧 / 微短剧建议 6-10 镜头
- 适合容纳起势、推进、爆发、结果与尾钩，但必须严格控制清晰区与模糊区分配
- 涉及强对抗段落时，建议同步拆出"关系建立镜头 / 受力放大镜头 / 命中确认镜头 / 结果兑现镜头"

## 多模态调度原则
- 图片优先负责首帧、角色形象、场景样貌
- 视频优先负责动作、运镜、节奏、转场参考
- 音频优先负责 BGM、音色、环境氛围
- 文本负责解释素材用途与镜头意图

## 全能参考 15 秒执行规则（必须落地）
- 必须先做"素材职责矩阵"，避免素材抢权漂移（参考 `docs/seedance-prompt-engineering.md` 的"素材职责矩阵"段落）
- 必须遵守"资产匹配优先级"：角色三视图/场景/道具（默认） > 风格锚点补位；comic-panels 仅作为可选增强
- 必须在每个 Shot 写清：权力关系/受力反馈/留白点/转场方式/音效空间（不是写空泛情绪词）

## 入口选择决策（必须显式写入输出）
- 首尾帧：默认路径。以 `comic-panels` 的稳定分镜图作为首帧（可加一张角色三视图作 CREF），写"微动/轻运镜/环境介质"即可。
- 全能参考：当需要复刻动作/运镜/转场/节奏或需要 15 秒整段输出时使用，必须提供"素材职责表 + Shot 分解 + 转场策略"。

## 镜头衔接策略
- 过渡特写
- 叠化 / 闪切 / 硬切 / 模糊过渡 / 旋转过渡
- 首尾帧桥接
- 景别差衔接

## 三要素分镜判断法
涉及打斗、追逐、压迫对峙、情绪反压时，分镜生成前优先判断：
1. **对抗关系**：谁压谁，谁在硬撑，谁在反扑，哪一镜负责展示关系变化
2. **身体受力**：重心、步伐、呼吸、肩背、落地、失衡、再稳住分别由哪一镜承担
3. **镜头节奏**：哪里停顿，哪里推进，哪里切近景，哪里留结果镜头

补充要求：
- 不要用快切替代关系表达
- 不要用 motion blur 掩盖受力不足
- 每个强对抗段落至少保留一个结果兑现镜头
- 需要时优先参考 `docs/action-case-opposition-force-camera.md`
- 强对抗镜头组必须把站位 / 朝向 / 距离、接触点、受力方向、被迫位移、止退 / 回稳、镜头停推切留拍、关键清晰点、环境与音效反馈写成可执行字段
- 涉及瞬移 / 影分身 / 闪现 / 残影瞬杀时，必须先建围攻空间 baseline，再拆“骤静触发 → 消失点 → 再出现点 → 命中清晰帧 → 目标结果 → 残影回收”；每次闪现只承担一个清晰目标，不能用残影和快切替代目标切换逻辑
- 外部视频只吸收关系、受力、节奏与结果设计，不直接照搬表面速度和剪辑频率
- 倍速素材只用于拆节奏和镜头结构，不作为原生动作速度标准
- 生成分镜时先建立稳定 baseline 镜头组，再补快切感、blur 与风格强化

## 台词锁定规则（最高优先级铁律）

台词原文一字不差强制保留，凌驾于所有其他规则。

**优先级排序**：
```
台词锁定 > 动作连续性 > 节拍密度 > 镜头美学 > 其他所有规则
```

### 三阶段锁定
1. **剧本切分时**：所有台词（含引号对话、说/道/问等动词引出的对话）必须原文保留在场次摘要中
2. **分镜生成时**：台词必须一字不差出现在对应镜头的台词字段中，禁止改写/省略/意译
3. **质量检查时**：逐条比对原始台词与分镜表台词，遗漏或改写均视为严重错误

### 台词字段格式
```
台词：第Xs @人物N："台词原文"
```
- `X` = 本镜相对秒数（台词时刻 - 本镜起始时间），严禁用全局秒数
- 无台词时省略整段

### 冲突处理
- 台词与镜头时长冲突 → **延长镜头时长**以容纳台词（时长 ≥ 字数/3.5 + 1s）
- 台词与动作冲突 → **调整动作**以配合台词，或拆为两镜（镜1说台词 + 镜2动作）
- 台词时间点模糊 → 默认出现在本镜前 1/3 时间

### 忠实模式
用户启用剧本忠实模式时，额外约束：
- 禁止添加原剧本没有的台词
- 禁止删减任何一句台词
- 禁止调整台词出现顺序

## 链式生成策略（长剧本分段处理）

> 来源：从规则层吸收。当总时长 ≥ 180s 时，单次 AI 调用会导致后半段质量下降、台词丢失、动作断裂，必须采用"分而治之"策略。

### 触发条件
- `totalSec >= 180` → 启动链式分段生成
- `totalSec < 180` → 单次生成

### 三阶段流程

**A. 剧本切分**
1. 将长剧本拆成 N 个"节拍"（beat），每个节拍 15-45s
2. 识别每个节拍的叙事模式（action/dialogue/lyrical/thriller/balanced）
3. 为每个节拍生成内容摘要（**保留台词原文**，遵循台词锁定规则）
4. 计算每场预估时长

**B. 分段生成**
1. 逐场生成分镜表，每场完成后立即保存
2. 维护全局时间轴偏移量（globalOffset），每场累加
3. 传递"桥接状态"（上一场最后一镜的动作/朝向/情绪/光影）给下一场，确保无缝衔接

**C. 拼接验证**
1. 合并所有场次表格，重新编号镜头序号
2. 校验时间轴连续性（前场末尾 = 后场开头）
3. 全量执行台词锁定校验
4. 检查桥接衔接是否成立（动作延续/朝向一致）

### 断点恢复
- 生成中断时，自动记录已完成场次与当前进度
- 恢复时跳过已完成场次，从未完成场次的 globalOffset 继续
- 单场生成失败不阻塞其他场次，可单独重试

## 失败信号
- 一镜头塞太多动作
- 只有文学描写没有镜头信息
- 没有 @引用无法复用资产
- 时长与动作量不匹配
- 镜头之间没有衔接逻辑
- 多模态素材职责冲突
- 镜头信息与动作分离列出（独立"镜头与构图"板块）
- 帧率切换未绑定具体动作时刻
- 台词被改写、省略或意译（台词锁定违规）
- 长剧本未分段生成导致后半段质量下降或台词丢失
