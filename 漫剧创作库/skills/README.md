## 使用建议
- `docs/master-methodology-toolkit.md` 是母版通用方法论工具集，所有文戏、武打戏、动作戏、生图、分镜、视频、声音、后期、agent 作业原则和 skill 继承关系都先归入母版判断
- 后续新增任何子风格工具集（如 HZW大师风格），都必须先继承或参考母版，再建立自己的核心方法论文档、skill、模板、agent 作业原则和 phase gate
- skill 是"能力模块"，不是"项目文件"
- `storyboard-*` 负责整场戏的分镜总装；`shot-design-skill.md` 负责单镜级运镜与镜头设计专项层，二者应协同而不是互相替代
- `director-storyboard-image-skill.md` 负责把剧本、分镜表、资产图和导演意图转为 D12-Sora2 / D15-Seedance2 专业导演故事板图；故事板图是视频生成前主交付物，提示词仅作为内部引擎和模型适配说明，不默认输出
- skill 要尽量通用，不要把某个具体项目内容写进去
- 项目内容放 `projects/`，通用方法论放 `skills/`
- 新增 skill 后必须同步更新本 README 和 `docs/workspace-status.md`
- 若新增的是项目级方法论文档（如站位/速度/Hit Stop/视听同步这类总装规范，或运镜与镜头运用总方法论、分场景分镜公式库、场景设定稿规范、GPT 生图方法论、即梦防崩核心规范、HZW大师风格系统），也必须同步更新 `docs/workflow.md`、`docs/phase-gate-checklist.md`、相关 agent/skill 定义与 `docs/pipeline-sync-log.md`，确保形成流程闭环
- **⚠️ 方法论文档自动纳入规则**：任何新增到 `docs/` 下的方法论文档，必须自动评估其归属分类（通用/分镜/动作/文戏/FPV/群戏/VFX/角色弧线/参考图等），并同步更新以下三处的强制前置检查表：
  1. `skills/storyboard-artist-skill.md` → 「强制前置检查」
  2. `skills/seedance-action-skill.md` → 「强制前置检查」
  3. `docs/workflow.md` → Phase 3 方法论自动加载门禁表
  4. `docs/phase-gate-checklist.md` → 创作源 / 风格母版 / 场景类型门禁
  评估标准：该文档是否包含可在提示词编写中直接执行的视觉/听觉/镜头/动作/环境/转场规则，或是否改变工作流入口、风格锁定、产出格式、Agent 职责、模板和门禁
