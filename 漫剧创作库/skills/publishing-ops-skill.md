# Publishing Ops Skill — 发布运营技能

## 技能定位
用于将已通过 QA 的短剧 / 漫剧内容包装成适合不同平台发布的标题、封面文案、简介、标签与发布清单。

## 适用任务
- 生成标题备选
- 生成封面文案
- 生成平台简介与标签
- 做平台适配建议

## 核心输出
- `09-publish/title-options.md`
- `09-publish/cover-brief.md`
- `09-publish/platform-copy.md`
- `09-publish/release-checklist.md`

## 设计原则
- 标题必须突出冲突 / 爽点 / 悬念
- 封面文案要短
- 平台简介要清楚说清题材卖点
- 标签不要乱堆，优先精准

## 失败信号
- 标题没有钩子
- 封面剧透过度
- 文案和内容主卖点不一致
