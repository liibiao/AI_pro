# tools

> `小说写作系统` 的自动化工具预留层。
> 这里用于放置后续为写作流程服务的脚本、批处理工具与数据清洗工具。

---

## 规划中的工具方向

- **字数统计**：按章节、按卷、按项目统计正文进度
- **连贯性扫描**：检查角色称谓、时间线、设定冲突
- **研究数据清洗**：清洗公开榜单、样本池、题材标签
- **发布包装辅助**：标题评分、简介钩子检测、标签建议
- **项目状态汇总**：自动汇总 `project.json` 与阶段文档状态

---

## 使用原则

1. 工具服务于流程，不替代流程
2. 自动化结果必须能回写到对应文档
3. 任何工具都要优先兼容 `templates/` 与 `projects/` 的标准结构
4. 工具输出应尽量可审阅、可追踪、可复用
