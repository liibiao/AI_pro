# title-blurb-skill — 标题与简介技能

## 用途

为不同平台、不同篇幅（长篇/短篇）的作品设计高点击率书名、高转化率简介和最优标签组合。基于起点/番茄/七猫等平台真实热门书名和简介数据分析。

## 触发条件

当项目进入 P7 包装发布阶段，需要设计标题和简介时调用。也可在 P1 选题阶段配合 Market-Researcher 进行书名方向预研。

## 输入

- 故事核（`story-core.md`）
- 核心卖点（`market-positioning.md`）
- 目标平台（`project.json` 中的 `platform` 字段）
- Market-Researcher 提供的平台书名规律和竞品分析
- 金手指/核心设定（`02-outline/story-core.md`）
- 主角人设（`02-outline/characters.md`）
- 正文前3章（推荐：写完前三章后再定标题和简介，此时对核心卖点最清晰）

## 输出

- `08-publish/title-options.md`（书名候选方案+评分）
- `08-publish/blurb.md`（多版本简介+平台适配）
- `08-publish/tag-strategy.md`（标签策略）

## 方法论

### 一、书名设计

#### §1.1 书名的核心作用

书名是读者接触作品的**第一个触点**，承担三大功能：

1. **一眼懂**：读者扫 0.5 秒就知道这本书讲什么题材、什么爽点
2. **有情绪**：引发好奇/愤怒/爽感/紧张中的至少一种
3. **有信息**：包含具体信息（身份/事件/冲突），不是泛泛的抽象词

> 关键数据：番茄小说读者平均在书名上停留 **0.3-0.5 秒**，超书名区一次展示仅 15 字。

#### §1.2 平台书名差异总览

| 维度 | 番茄小说 | 起点中文网 | 七猫小说 |
|------|---------|-----------|---------|
| **字数限制** | 5-15字（最优 8-12字） | 2-12字（最优 4-8字） | 5-15字（最优 8-12字） |
| **风格偏好** | 直给冲突、情绪化、口语化 | 可含蓄有意境、世界观型、体系型 | 直给冲突、情绪化 |
| **高频词** | 开局/觉醒/重生/规则/系统/长生 | 无特定高频词，看重辨识度 | 霸总/甜宠/逆袭/重生 |
| **禁忌** | 文艺晦涩、过于含蓄、偏离主线 | 营销感过强、低俗标题 | 同番茄 |
| **标点** | 可用冒号`：`分隔主副标题 | 偏好简洁，少用标点 | 可用冒号分隔 |

#### §1.3 长篇书名结构模式库（12种）

| # | 模式 | 公式 | 番茄示例 | 起点示例 |
|---|------|------|---------|---------|
| 1 | **悬念型** | [角色]+[异常行为/事件] | 前夫跪在我面前，求我救他妈 | 深渊序列 |
| 2 | **反差型** | [被低估的身份]+[隐藏真相] | 全家逼我净身出户，不知道我才是继承人 | 末法时代的尸解仙 |
| 3 | **冲突型** | [压迫者]+[压迫行为]+[反转信号] | 婆婆说我配不上她儿子，转头我前男友开着劳斯莱斯来了 | 穿甲弹不相信碳基怪物 |
| 4 | **身份逆袭型** | [失去身份]+[获得更强身份] | 被赶出豪门后，我成了全球首富 | 重生08：装备系男神 |
| 5 | **秘密型** | [日常表象]+[隐藏秘密] | 离婚后，前妻才知道我的真实身份 | 我的化身正在成为最终BOSS |
| 6 | **倒计时型** | [限定时间]+[必须完成的事] | 还有三天，如果找不到真凶，我就是替死鬼 | 今天毁灭世界了吗？ |
| 7 | **选择型** | [两难选择] | 救女儿还是救老公，我只能选一个 | 循规蹈矩也能叫重生吗？ |
| 8 | **公式型** | [题材/金手指]+[冒号]+[卖点/人设] | 规则怪谈：华夏扛刀参赛 | 快收了神通吧！ |
| 9 | **体系型** | [世界观]+[核心概念] | — | 元始法则、山河稷 |
| 10 | **职业/身份型** | [职业]+[反转/异常] | 谁说特型演员不能当影帝？ | 从恒大踢后腰开始 |
| 11 | **古风意象型** | [意象词]+[情绪/动作] | 惹娇枝、逢灯纪 | 惊涛落日、剑出大唐 |
| 12 | **穿书/穿模型** | [穿越]+[身份]+[反转] | 穿成恶毒女配后，我成了团宠 | 非正常穿越 |

#### §1.4 短篇书名结构模式（番茄短篇专用）

番茄短篇（6000-80000字）的书名与长篇不同，更像"一句话梗概+情绪钩子"：

| 模式 | 公式 | 示例 |
|------|------|------|
| **第一人称冲击型** | "我"+[令人震惊的经历] | 我死后第三天，老公带着白月光回家了 |
| **疑问型** | [反常识提问] | 你知道凌晨三点不要照镜子吗？ |
| **倒计时型** | [时间压力]+[必须做的事] | 只剩七十二小时，我必须找出那个改规则的人 |
| **反转型** | [表面]+[惊人转折] | 住院三年，老公从未来过，出院那天他跪在门口 |

**短篇书名铁律**：
- 必须在 10 字以内制造悬念或情绪冲击
- 第一人称代入感 > 第三人称叙述感
- 番茄短篇推荐书名长度：**8-12字**
- 禁止用文艺/含蓄/意象型书名

#### §1.5 书名生成流程

```
Step 1: 素材提取
  ├─ 从 story-core.md 提取：核心冲突、主角困境、核心反转
  ├─ 从 characters.md 提取：主角身份标签、金手指/特殊能力
  ├─ 从 market-positioning.md 提取：目标读者情绪、竞品书名分析
  └─ 从 正文前3章 提取：实际最抓人的情节/台词

Step 2: 模式匹配
  ├─ 根据题材选择 2-3 个适合的书名模式
  └─ 根据目标平台选择适配风格（番茄=直给/起点=可含蓄）

Step 3: 批量生成
  ├─ 每个模式生成 3-5 个候选
  └─ 确保覆盖不同情绪维度（好奇/愤怒/爽感/紧张）

Step 4: 平台筛选
  ├─ 字数是否符合平台最优区间
  ├─ 风格是否匹配平台调性
  └─ 是否与同类型热门书名撞车

Step 5: 评分排序
  └─ 用下方评分表对每个候选打分，保留 Top 5
```

#### §1.6 书名评分表（满分 15 分）

| 维度 | 权重 | 评分标准 |
|------|------|---------|
| **一眼懂** | 4分 | 4=一眼看出题材和爽点；3=能猜到大概；2=需要思考；1=完全看不懂 |
| **情绪抓手** | 3分 | 3=强烈情绪触发；2=有情绪但不强烈；1=平淡无感 |
| **信息密度** | 3分 | 3=包含身份+冲突+反转；2=包含两项；1=只有一项 |
| **平台匹配** | 3分 | 3=完全符合平台风格；2=基本匹配；1=风格错位 |
| **记忆度** | 2分 | 2=听过一次就能记住；1=容易混淆 |

**放行标准**：总分 ≥ 12/15 方可进入最终候选。

#### §1.7 书名禁忌

- 禁止文艺/晦涩（"风起青萍""云深不知处"等）—— 番茄/七猫致命伤
- 禁止过于泛泛（"修仙之路""都市风云"）—— 无法区分
- 禁止脱离主线（书名暗示的内容正文不涉及）—— 误导读者
- 禁止恶意撞名（与同平台热门书名高度相似）—— 平台可能拒审
- 禁止超过 15 字（番茄）或 12 字（起点）—— 手机端展示截断

### 二、简介写作

#### §2.1 简介的核心作用

简介是仅次于书名的**第二大转化率因素**。手机端简介展示区仅显示**前 3-5 行**（约 60-80 字），超出部分被折叠。因此：

- **前 60 字决定读者是否展开全部简介**
- **前 150 字决定读者是否点击"开始阅读"**
- 简介不是"内容简介"，而是**广告文案**

#### §2.2 平台简介差异总览

| 维度 | 番茄小说 | 起点中文网 | 七猫小说 |
|------|---------|-----------|---------|
| **字数范围** | 80-150字（极简） | 150-300字（可展开） | 80-150字（极简） |
| **展示折叠** | 前3-5行，约60-80字 | 前5-8行，约100-150字 | 前3-5行，约60-80字 |
| **核心要求** | 前60字必须有冲突/反转 | 设定深度+长期追更价值 | 情绪钩子+快速爽点 |
| **结构偏好** | 一句话钩子+2-3行加压+结尾悬念 | 世界观+主角处境+核心矛盾+长期看点 | 冲突钩子+情绪渲染+爽点暗示 |
| **语调** | 口语化、直给、情绪化 | 可适度文艺、展示文笔 | 情绪化、打脸感 |
| **可加标签** | 可在开头加【爆笑】【虐渣】等 | 不推荐加标签前缀 | 同番茄 |

#### §2.3 长篇简介结构模板

**通用五段式结构**（各平台按需裁剪）：

```
[钩子]    一句话制造强烈悬念/反差/提问（≤20字）
[主角]    主角身份、处境或独特之处（≤30字）
[冲突]    核心矛盾、最大困难或对手（≤40字）
[转折]    金手指/核心反转/独特优势（≤40字）
[收尾]    用调侃/反问/金句收尾，暗示调性（≤20字）
```

**番茄长篇版**（80-150字）：
```
[钩子+主角+冲突] 合并为前60字（必须在折叠线内完成）
[转折+收尾] 合并为后60-90字（展开后看到）
```

**起点长篇版**（150-300字）：
```
[钩子] 独立一句，展示设定或悬念
[主角] 身份+处境
[冲突] 世界观/核心矛盾
[转折] 金手指/成长路线
[收尾] 暗示长期可读性（体系/世界深度）
```

#### §2.4 短篇简介结构模板（番茄短篇专用）

番茄短篇简介与长篇**完全不同**。短篇没有"长期追更"概念，读者决策只有"看/不看"：

**短篇简介模板**（60-100字）：

```
模式A：情绪冲击型
  第一人称+极限困境+情绪渲染
  例："住院三年，老公一次没来看过我。出院那天，我拎着行李箱站在门口，
      他搂着别的女人从里面走出来，对我说：'你谁啊？'"

模式B：规则怪谈型
  核心规则+违反后果+主角处境
  例："小区公告栏上出现了一条红字规则：晚上十点后，任何住户不得在
      走廊奔跑。如果听见奔跑声，请立刻关门。那晚，一个男孩在走廊里
      只留下了一只鞋。"

模式C：反转逆袭型
  被压迫处境+意外反转+爽点暗示
  例："被全公司排挤的我，在年终聚餐上喝多了，把老板桌上的花瓶砸了。
      第二天HR通知我去领离职赔偿金——三百万。"
```

#### §2.5 简介四要素（通用）

无论平台和篇幅，高转化率简介必须包含以下至少 3 个：

| 要素 | 定义 | 检验问题 |
|------|------|---------|
| **冲突** | 主角面临什么困境？ | 读者能说出主角的"麻烦"是什么吗？ |
| **反差** | 有什么出乎意料的元素？ | 读者会产生"居然是这样？！"的感觉吗？ |
| **悬念** | 有什么未解的谜题？ | 读者会想"然后呢？"吗？ |
| **情绪** | 读者应该产生什么感受？ | 愤怒？好奇？爽感？紧张？同情？ |

#### §2.6 不同题材简介侧重

| 题材 | 核心要素 | 关键词示例 |
|------|---------|-----------|
| **都市/异能** | 金手指+日常反差爽点 | "外卖员觉醒传承，客户竟是修仙大佬" |
| **玄幻/仙侠** | 世界观+升级路线+势力对抗 | "废材弟子得远古神棺，沉睡万年醒来无敌" |
| **言情/甜宠** | 男女主人设+感情主线+甜/虐点 | "协议结婚后，禁欲总裁夜夜敲门求安慰" |
| **悬疑/恐怖** | 诡异事件+求生规则+解密线索 | "入住新家那天，楼上邻居递来纸条：别在凌晨照镜子" |
| **历史/架空** | 时代背景+权谋目标+知识碾压 | "穿成废太子，他靠签到打卡搅动朝堂风云" |
| **规则怪谈** | 核心规则+违反后果+主角处境 | "当别国选手在怪谈中惨死，我对着诡异露出了微笑" |
| **末世/天灾** | 灾难设定+重生优势+生存压力 | "重生回到极寒前七天，我手撕婚书，开始疯狂囤货" |

#### §2.7 简介写作禁忌

| 禁忌 | 错误示例 | 正确做法 |
|------|---------|---------|
| **流水账开头** | "XXX是个普通的高中生，一天放学回家的路上……" | 从冲突/异常/反差直接切入 |
| **剧透完毕** | 简介写完了全部反转和结局 | 只展示前20%的设定，核心反转绝不写 |
| **世界观介绍** | "在苍茫大陆上，有修仙者和妖兽共存……" | 用剧情和冲突体现世界观，不要"百科全书"式介绍 |
| **"本文讲述了"** | "本文讲述了一个少年修仙的故事" | 删掉，永远不要用这种格式 |
| **脱离正文** | 简介暗示的爽点正文前三章完全没有 | 简介承诺的内容必须在正文兑现 |
| **平台错位** | 在番茄写起点风格的文艺简介 | 根据平台调性调整 |

#### §2.8 简介生成流程

```
Step 1: 素材提取
  ├─ story-core.md：核心冲突、核心反转、核心情绪
  ├─ characters.md：主角身份标签、金手指
  ├─ market-positioning.md：目标读者情绪、竞品简介分析
  ├─ 正文前3章：实际最抓人的情节/台词/场景
  └─ project.json：平台类型、篇幅类型（长篇/短篇）

Step 2: 选择简介模式
  ├─ 长篇番茄 → 番茄长篇版模板（80-150字）
  ├─ 长篇起点 → 起点长篇版模板（150-300字）
  ├─ 短篇番茄 → 短篇简介模板（60-100字）
  └─ 跨平台 → 每个平台输出不同版本

Step 3: 批量生成
  ├─ 至少生成 3 个版本（悬念型/卖点型/情绪型）
  └─ 每个版本必须通过"四要素"检验（至少包含3个）

Step 4: 折叠线检查
  ├─ 前60-80字是否包含钩子+核心信息（番茄/七猫）
  └─ 前100-150字是否包含钩子+世界观（起点）

Step 5: 3秒钩子测试
  └─ 找3个未读过正文的人，看第一句话是否让他们想读下去
```

#### §2.9 简介自检清单

**通用自检**：
- [ ] 第一句话有钩子（冲突/悬念/反常识/提问）
- [ ] 没有剧透核心反转（只展示前20%）
- [ ] 主角的困境/欲望/特殊之处清晰
- [ ] 读完会产生"想知道后面怎样"的冲动
- [ ] 包含类型关键词（有利于平台推荐算法）
- [ ] 简介的语言调性与正文匹配
- [ ] 没有使用"本文讲述了""一个关于……的故事"等格式

**番茄/七猫专项**：
- [ ] 前 60-80 字（折叠线内）有冲突或反转
- [ ] 总字数 80-150 字
- [ ] 没有"百科全书"式世界观介绍
- [ ] 可在开头加情绪标签（【爆笑】【虐渣】等）

**起点专项**：
- [ ] 体现设定深度和长期可读性
- [ ] 主线目标、世界规则、主角成长空间清楚
- [ ] 总字数 150-300 字
- [ ] 适度保留悬念但不空泛

**短篇专项**：
- [ ] 总字数 60-100 字
- [ ] 第一人称代入感强
- [ ] 核心冲突一句话交代清楚
- [ ] 不需要展示世界观或成长体系

### 三、标签策略

#### §3.1 标签层级

1. **核心标签**（1-2个）：最准确描述题材的标签（如"规则怪谈""末世囤货"）
2. **情绪标签**（1-2个）：描述阅读体验（如"爽文""虐心""轻松""悬疑"）
3. **流量标签**（1-2个）：当前平台热门但竞争不过饱和的标签

#### §3.2 标签组合原则

- 核心标签必须准确，不能为了蹭流量乱标（标签不符→读者差评→算法降权）
- 情绪标签要与正文实际体验匹配
- 流量标签选"热度上升中但未饱和"的，避免在红海中竞争
- 男频/女频标签体系不同，不可混用

#### §3.3 各平台标签特点

| 平台 | 标签数量 | 特点 |
|------|---------|------|
| 番茄 | 5-8个 | 标签影响推荐流量，选对标签=多10倍曝光 |
| 起点 | 系统分类+自定义 | 分类固定，标签更多体现在简介关键词中 |
| 七猫 | 5-8个 | 同番茄，标签与推荐算法强绑定 |

### 四、A/B测试与优化

#### §4.1 发布前测试

1. **写完正文前3章后再定书名和简介**（此时对核心卖点最清晰）
2. **生成3个版本**，分别对应不同情绪维度
3. **3秒钩子测试**：让未读过正文的人看第一句话，记录是否能引发"想读下去"的冲动
4. **竞品对比**：与同类型Top10书名/简介并排展示，检查自己的是否更有吸引力

#### §4.2 发布后优化

1. **监控数据**：点击率（展示→点击转化）、收藏率、追读率
2. **如果点击率低**：问题在书名或简介前60字（折叠线内容）
3. **如果收藏率低**：问题在简介承诺的内容与正文前3章不匹配
4. **优化周期**：发布后3-7天可修改1次简介，根据数据调整
5. **迭代原则**：每次只改一个变量（书名或简介），定位问题
