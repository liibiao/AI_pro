# line-edit-skill — 句级编辑技能

## 用途
句级打磨、冗余删除、措辞升级、文风统一。

## 触发条件
当初稿完成需要进入改稿阶段，对语言层面进行精修时调用。

## 输入
- 初稿章节
- 目标文风（从 `project.json` 的 `style_profile`）

## 输出
- 修改后的章节
- `05-edit/revision-log.md` 条目

---

## 方法论

### 一、句级编辑优先级

按以下顺序处理，不要乱序：

1. **删废句**：删除不推进剧情、不揭示人物、不建立氛围的句子
2. **杀副词**：删除"非常""十分""极其"等弱化表达的副词
3. **换弱动词**：把"走过去""看了一眼"换成更有力的动词
4. **收长句**：超过 30 字的句子考虑拆分
5. **统一文风**：确保全篇叙述距离、句长、修辞密度一致

### 二、常见废句类型

| 类型 | 示例 | 处理 |
|------|------|------|
| 重复信息 | "他很愤怒。他的愤怒已经到了极点。" | 删一句 |
| 空抒情 | "那一刻，时间仿佛静止了，整个世界都安静了下来……" | 删或换成具体动作 |
| 解释性旁白 | "他这样做是因为他小时候受过伤害。" | 删，用行为暗示 |
| 无效过渡 | "就这样，时间一天天过去了。" | 直接跳到下一个事件 |
| 冗余描写 | 对非关键物品做详细描写 | 缩减到一句或删除 |

### 三、动词升级表

| 弱动词 | 强动词选项 |
|--------|-----------|
| 走 | 踱、窜、挪、蹿、晃 |
| 看 | 瞥、盯、扫、瞪、凝视 |
| 说 | 低吼、冷笑、嗤、喃喃、咬牙 |
| 拿 | 攥、抄、掂、捏、一把抓 |
| 想 | 琢磨、盘算、闪过念头 |

### 四、句长控制

| 场景类型 | 推荐句长 | 节奏感 |
|---------|---------|--------|
| 动作/打斗 | 5-15 字 | 短促、有力 |
| 对话冲突 | 10-20 字 | 快切 |
| 环境氛围 | 15-30 字 | 舒缓、沉浸 |
| 心理描写 | 10-25 字 | 中等 |
| 高潮时刻 | 3-10 字 | 极短、爆发 |

### 五、文风一致性检查

- [ ] 叙述人称前后一致
- [ ] 叙述距离前后一致（不要忽远忽近）
- [ ] 修辞密度前后一致（不要前半段朴素后半段华丽）
- [ ] 角色语言风格前后一致
- [ ] 时态前后一致

### 六、编辑标记规范

在 `revision-log.md` 中使用以下标记：

```
[DEL] — 删除
[REP] — 替换
[ADD] — 新增
[MOV] — 移动位置
[注] — 编辑说明
```

### 七、编辑阶段常见修补点（实战沉淀）

基于 `fanqie_duanpian_001` 等样板项目验证，编辑阶段最常需要修补的三类问题：

1. **时间线修补**：初稿容易出现时间跳跃不清、事件顺序混乱，需要在编辑阶段统一时间锚点
2. **机制前置修补**：主角破局的关键信息（如规则漏洞、工具权限）必须在使用前埋下，不能临时解释
3. **反派情感锚点修补**：纯恶反派缺乏余味，需要补充情感动机或悲剧背景，让反转更有层次
