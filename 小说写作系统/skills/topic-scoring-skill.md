# topic-scoring-skill — 选题评分技能

## 用途
用统一标准筛选题材，判断是否值得投入生产资源。

## 触发条件
当有候选选题需要评估时调用。

## 输入
- 选题描述（一句话故事核或灵感）
- 目标平台

## 输出
- 选题评分卡

---

## 方法论

### 一、评分维度（总分 50 分）

#### 1. 点击感（10 分）
- 是否一眼能看出冲突或异常？（0-3）
- 是否有明确点开欲望？（0-4）
- 是否适合生成高点击标题？（0-3）

#### 2. 情绪浓度（10 分）
- 是否天然带强情绪（愤怒/委屈/好奇/爽感/紧张）？（0-5）
- 是否能快速让读者站队？（0-5）

#### 3. 冲突强度（10 分）
- 矛盾是否直给？（0-3）
- 对立关系是否清晰？（0-4）
- 是否容易持续加压？（0-3）

#### 4. 反转与爽点潜力（10 分）
- 是否存在自然翻盘空间？（0-5）
- 是否具备阶段性爽点或真相揭露空间？（0-5）

#### 5. 扩写稳定性（10 分）
- 是否能稳定写成目标字数？（0-4）
- 是否不容易 2000 字就写干？（0-3）
- 是否不依赖单一 gimmick？（0-3）

### 二、风险扣分项

以下情况额外标记（不扣分但标红）：
- 同质化严重
- 平台疲劳题材
- 标题好做但正文难撑
- 过分依赖设定解释
- 冲突虚高，落地无力

### 三、评分分段

| 分段 | 建议 |
|------|------|
| 45-50 | 优先进入项目池 |
| 38-44 | 可做，需要优化包装或结构 |
| 30-37 | 谨慎，建议先做变体测试 |
| 0-29 | 不建议进入生产 |

### 四、爽点预期定位

**开篇3章必须告诉读者"这本书能让你爽什么"。**

| 原则 | 说明 |
|------|------|
| **单一聚焦** | 主打一个核心爽点（如"极致打脸"），其他爽点作为辅助 |
| **避免贪多** | 不要"又想写打脸又想写权谋又想写种田"，导致重点模糊 |
| **黄金三章兑现** | 前3章必须兑现一次核心爽点，让读者确认"这本书的爽点是我喜欢的" |

| 核心爽点类型 | 读者期待 | 典型题材 |
|------------|---------|---------|
| 极致打脸 | "看他怎么碾压那些看不起他的人" | 赘婿/战神/废柴流 |
| 快速升级 | "看他怎么一步步变强" | 系统/修炼/面板流 |
| 扮猪吃虎 | "等他暴露真实实力的那一刻" | 隐藏大佬/低调流 |
| 赚钱暴富 | "看他怎么从穷变富" | 商业/系统赚钱/种田 |
| 权谋博弈 | "看他怎么一步步掌控全局" | 官场/谋士/争霸 |
