# platform-adapt-skill — 平台适配技能

## 用途
根据不同平台的规则和偏好，调整作品的字数、风格、包装和发布策略。

## 触发条件
当需要将作品适配到特定平台，或评估跨平台迁移方案时调用。

## 输入
- 完成的作品
- 目标平台
- Market-Researcher 的平台研究报告

## 输出
- 平台适配方案
- `08-publish/platform-notes.md`

---

## 方法论

### 一、主流平台特征对比

| 维度 | 番茄小说 | 起点中文网 | 七猫小说 |
|------|---------|-----------|---------|
| **主力读者** | 下沉市场、碎片阅读 | 核心网文读者 | 下沉市场 |
| **变现模式** | 免费+广告 | 付费订阅 | 免费+广告 |
| **短篇字数** | 5000-15000 | 不主推短篇 | 5000-15000 |
| **长篇字数** | 50万-200万 | 100万-500万 | 50万-200万 |
| **节奏偏好** | 极快、高密度爽点 | 可以稍慢、重世界观 | 极快 |
| **开篇要求** | 前3章必须抓人 | 前5章建立世界观 | 前3章必须抓人 |
| **标题风格** | 直给冲突、情绪化 | 可以含蓄、有意境 | 直给冲突 |

### 二、平台适配清单

#### 番茄短篇适配
- [ ] 字数控制在 5000-15000
- [ ] 前 500 字有明确冲突
- [ ] 每 1000 字至少一个爽点/反转
- [ ] 标题直给冲突
- [ ] 简介有强情绪抓手
- [ ] 无大段世界观介绍
- [ ] 结尾有强回响

#### 番茄长篇适配
- [ ] 前 3 章抓住读者
- [ ] 每章 1500-2500 字
- [ ] 章章有钩子
- [ ] 爽点密度高
- [ ] 标题直给
- [ ] 付费卡点设计合理

#### 起点男频适配
- [ ] 前 5 章建立世界观+核心冲突
- [ ] 每章 2000-3000 字
- [ ] 允许适度的设定介绍
- [ ] 金手指/系统设定清晰
- [ ] 升级体系明确
- [ ] 付费章节有足够吸引力

### 三、跨平台迁移

当一部作品需要从平台 A 迁移到平台 B 时：

| 迁移方向 | 需要改什么 |
|---------|-----------|
| 起点 → 番茄 | 加快节奏、删减设定、强化开篇、标题改直给 |
| 番茄 → 起点 | 补充世界观、丰富设定、适度放慢节奏 |
| 短篇 → 长篇 | 扩展支线、增加配角、补充过渡章节 |
| 长篇 → 短篇 | 砍支线、聚焦主线、压缩到核心冲突 |

### 四、敏感词与审核

每个平台都有内容红线，发布前必须检查：
- 暴力描写是否过度
- 是否涉及敏感话题
- 是否有平台禁止的内容类型
- 角色年龄是否符合平台要求
