# rhythm-tuning-skill — 节奏调优技能

## 用途
调整章节节奏、段落密度、快慢切换，让阅读体验流畅有力。

## 触发条件
当 Editor 需要优化章节节奏、处理拖沓或跳跃问题时调用。

## 输入
- 待调优的章节正文
- 章节计划（目标节奏）
- `chapter-rhythm-standard.md`

## 输出
- 节奏诊断报告
- 调优后的章节

---

## 方法论

### 一、节奏诊断

#### 快节奏信号
- 短句为主（5-15字）
- 段落短（1-3句/段）
- 动作密集
- 对话快切
- 描写极少

#### 慢节奏信号
- 长句为主（20-40字）
- 段落长（5-8句/段）
- 环境描写多
- 心理描写多
- 对话少

#### 节奏问题诊断
| 问题 | 症状 | 原因 |
|------|------|------|
| 全程快 | 读起来累，没有喘息 | 缺少慢段过渡 |
| 全程慢 | 读起来困，想跳过 | 缺少冲突和动作 |
| 忽快忽慢 | 读起来晕，节奏混乱 | 快慢切换没有过渡 |
| 高潮不高 | 高潮段没有爆发感 | 前面没有足够的蓄力 |
| 中段塌腰 | 中间部分无聊 | 缺少加压机制 |

### 二、节奏调优工具箱

#### 加速手段
- 缩短句子
- 删除环境描写
- 用动作代替心理
- 加快对话节奏（删除动作穿插）
- 删除过渡段

#### 减速手段
- 加入环境描写（1-2句）
- 加入角色微动作
- 拉长对话间隔
- 加入心理反应
- 加入感官细节

#### 蓄力手段（为高潮做准备）
- 连续 2-3 段慢节奏建立紧张感
- 用倒计时制造压迫
- 用沉默和留白制造不安
- 用环境变化暗示即将到来的变化

### 三、章节节奏模板

#### 标准战斗章
```
慢（环境+状态）→ 中（对峙+试探）→ 快（爆发+交锋）→ 极快（高潮）→ 慢（结果+反应）
```

#### 标准情感章
```
中（日常互动）→ 慢（情感铺垫）→ 中（冲突触发）→ 慢（情感爆发）→ 中（新平衡）
```

#### 标准悬疑章
```
慢（氛围建立）→ 中（线索发现）→ 快（危机触发）→ 慢（推理分析）→ 快（真相揭露/新悬念）
```

### 四、节奏密度参考

| 类型 | 每千字冲突点 | 每千字对话占比 | 每千字描写占比 |
|------|------------|--------------|--------------|
| 爽文 | 2-3 个 | 40-50% | 10-15% |
| 情感文 | 1-2 个 | 30-40% | 20-30% |
| 悬疑文 | 1-2 个 | 25-35% | 25-35% |
| 文艺文 | 0.5-1 个 | 20-30% | 35-45% |

### 五、主动拖慢节奏（白特慢看稿重点）

**核心一句话：慢不是水字数，是把"关键瞬间"拉长、放大、塞满细节，让张力拉满、爽点更炸、读者更代入。**

#### 5.0 只在4种场景慢（其他全快写）

| 场景 | 为什么慢 | 效果 |
|------|---------|------|
| **金手指第一次登场** | 读者最期待的瞬间 | 拉满期待，放大震撼 |
| **反转/打脸/高潮爆发** | 爽点释放前蓄力 | 压抑越久，爆发越爽 |
| **生死危机/绝境对峙** | 读者最揪心的瞬间 | 窒息感→爆发 |
| **强情绪点：离别/复仇/相认/忏悔** | 情感高峰需要沉浸 | 让读者跟着角色一起感受 |

#### 5.1 为什么要"主动拖慢"？

**拖慢 ≠ 拖沓。拖沓是无意义的注水，主动拖慢是有目的的节奏控制。**

| 主动拖慢的目的 | 说明 | 适用场景 |
|-------------|------|---------|
| **蓄力** | 让读者积累期待感，为即将到来的爆发做准备 | 高潮前、大反转前、关键战斗前 |
| **呼吸** | 给读者喘息空间，避免全程紧绷导致疲劳 | 高潮后、长战斗间隙、紧张剧情中间 |
| **沉浸** | 用慢节奏让读者沉浸在氛围中 | 情感戏、世界观展示、角色内心戏 |
| **信息释放** | 在慢节奏中释放重要信息，让读者有时间消化 | 世界观揭秘、身份揭露、真相浮现 |

#### 5.2 主动拖慢的6种方法

**① 环境锚定（最常用）**

在需要放慢的地方加入1-3句环境描写，把读者"锚定"在场景中：

> 例：战斗前的短暂宁静
> "他站在校场中央，风把沙土吹到他靴边。远处的太阳刚升到城墙上方，把石板地面照得发白。他握刀的手微微收紧。"

**② 微动作放大**

把一个极小的动作拆解成3-5个步骤，制造"时间变慢"的效果：

> 例：开战前一秒
> "他的拇指推开刀镡，刀身滑出半寸——刀背上的霜气散开，周围的草叶卷起了细小的冰花。"

**③ 感官延迟**

在关键事件发生前，先写感官感知（声音/气味/温度），延迟"事件本身"的呈现：

> 例：察觉危险
> "他先闻到了血腥味，然后听到身后传来极轻的脚步声——不是一个人的。刀在出鞘前，他的身体已经动了。"

**④ 心理拉长**

在动作之间插入角色的心理活动，让"瞬间"变长：

> 例：生死抉择
> "剑尖距离他的喉咙只有三寸。三寸——他算过这个距离刚好够他侧身。但侧身意味着背对身后的暗箭。他咬紧后槽牙。"

**⑤ 重复与凝视**

用"角色反复做同一件事"或"盯着某个细节"来制造时间停滞感：

> 例：等待判决
> "她数着地板上的裂缝。一条、两条、三条。房间里没有人说话，只有火盆里的炭偶尔发出一声轻响。"

**⑥ 信息/回忆穿插**

在动作进行中插入一段回忆或内心信息，制造"时间分层"效果：

> 例：战斗中闪回
> "对方的刀法他见过——师父用同样的起手式斩断过他的木剑。那是十年前。他的身体已经自动做出了应对。"

**⑦ 切旁人视角**

用围观者、反派、手下的反应放大氛围，制造"时间分层"效果：

> 例：高手出手
> "所有人都在看那把刀。不是看它多快——而是看它太慢了。慢到每个人都能看清刀身上映出的那个人的脸。站在最前面的弟子退了半步，手在发抖。"

#### 5.3 拖慢节奏的"三不"原则

| 原则 | 说明 |
|------|------|
| **不超过3句** | 主动拖慢的环境/心理描写，每次不超过2-3句，否则变成拖沓 |
| **必须有目的** | 拖慢前确认目的（蓄力？呼吸？沉浸？信息释放？） |
| **必须有回收** | 拖慢段中埋的细节/铺垫，在后面的爆发段中要有回应 |

#### 5.4 节奏切换过渡

**从快到慢的过渡**：用一个"感官锚点"做切换
> 快段：连续短句打斗
> 过渡："刀锋擦过他的脸颊，留下一道热辣的痕迹。"（感官锚点）
> 慢段：他靠在墙上，感受着血从伤口渗出的温度……

**从慢到快的过渡**：用一个"触发器"做切换
> 慢段：安静的环境描写
> 过渡："门突然被踹开。"（触发器）
> 快段：连续动作爆发

---

#### 5.5 慢节奏的4个禁忌

| 禁忌 | 说明 |
|------|------|
| 不在吃饭/走路/闲聊这种无关剧情的场景慢 | 这些场景快写，读者不关心 |
| 不重复解释读者已经懂的设定 | 慢节奏≠水字数，新信息才值得展开 |
| 不堆空洞华丽的形容词 | 细节要有信息量，不是堆词 |
| 不写无意义内心乱想 | 想半天不行动=拖沓，心理活动要推动决策 |

#### 5.6 快慢节奏黄金公式

```
日常：快写（短句、少描写、直推进）
关键：慢写（拆动作、加细节、扩心理）
高潮：先慢后快（拉满张力再爆发）
```

> **白特慢总结金句：对白要瘦，节奏要稳。该快则飞，该慢则碎。对白不拖沓，慢戏不注水。**

### 六、玄幻快节奏+杀伐果断（白特慢专项）

**核心一句话：快节奏≠乱写，杀伐果断≠乱杀；玄幻要爽，核心是——抓死「情绪」，用情绪带节奏，用节奏推杀伐，干净、干脆、不拖、不圣母。**

> 与 §五「主动拖慢」互补：§五 教你"什么时候该慢"；本节教你"怎么保持快"和"杀伐怎么写得刚"。

#### 6.1 快节奏的本质

**不是写得快，是「信息密度高、无效内容零」。**

| 原则 | 操作 | 反面 |
|------|------|------|
| **每段都有事** | 冲突→动作→结果→情绪 | 无意义铺垫、寒暄、回忆 |
| **全程推进** | 不写平静，只写逼近/追杀/夺宝/反击/爆发 | 原地踏步、日常注水 |
| **镜头锁定主角** | 不切多余视角，不跳来跳去 | 频繁切配角视角打断节奏 |

> 快节奏=删到只剩核心。保留的每一段都要有信息量、有冲突、有情绪推进。

**删三类"节奏杀手"**：

| 节奏杀手 | 示例 | 处理 |
|---------|------|------|
| 无意义环境描写 | "天空万里无云，阳光明媚……"（战斗中） | 删，除非服务于情绪/伏笔 |
| 无效寒暄/客套对话 | "你好""好久不见""最近可好" | 删，或压缩到一句 |
| 作者旁白式解释设定 | "这个世界的修炼体系分为九层……" | 穿插到剧情中，不单独解释 |

#### 6.2 句式变短、动作变脆

| 技巧 | 操作 | 示例 |
|------|------|------|
| 少用长句/修饰 | 一句一个动作 | ❌"他用手中的长剑以极快的速度朝着敌人的胸口刺了过去" → ✅"一剑刺出，直取胸口" |
| 一段一个反转 | 不让读者预测到下一步 | 每段结尾必须有新变化 |
| 短句堆叠制造冲击 | 连续短句=快速连续画面 | "闪、避、刺！三招之内，敌人已无还手之力" |

**玄幻杀伐万能句式模板**（直接套用）：

```
眼神一冷，不再多言。
既然找死，那便成全。
话音未落，杀机已至。
不闪不避，抬手便是杀招。
一剑了断，绝不拖泥带水。
众人尚未反应，战局已分生死。
```

#### 6.3 杀伐果断人设写法（不圣母、不崩、读者超爱）

**三不原则**：

| 原则 | 含义 | 写作要点 |
|------|------|---------|
| **不犹豫** | 判断即行动 | 不需要内心戏八百字 |
| **不废话** | 能动手别吵吵 | 不与敌人讲道理、不辩论 |
| **不回头** | 斩草必除根 | 不留后患、不心软 |

**杀伐要有"理由"但不需要"辩解"**：

```
敌人要杀你 → 杀
敌人害你亲友 → 杀
敌人拦你路 → 杀
不需要内心纠结、不需要讲道理、不需要道德辩论
```

**杀伐要"干净"**：

| 要素 | 操作 | 反面 |
|------|------|------|
| 一招制敌 | 不缠斗 | 打了三百回合还没分胜负 |
| 不审问/不逼逼 | 出手即杀招 | 先审问半章再动手 |
| 不戏耍 | 打完立刻进下一段剧情 | 碾压后还得嘲讽几句才走 |

#### 6.4 核心：用情绪带节奏（压抑→爆发→爽）

> 这一切（快节奏+杀伐果断）的根，都在**情绪**。情绪一到位，节奏自然快；情绪一干净，杀伐自然刚。

```
第一步：给"压"（让读者揪心）
    被追杀、被夺宝、被羞辱、亲友遇险、绝境
    ↓
第二步：给"爆"（情绪瞬间释放）
    主角不忍、不拖、不圣母，直接出手
    ↓
第三步：给"爽"（情绪闭环）
    敌人覆灭、危机解除、主角立威
```

**公式：压抑 → 爆发 → 爽点 = 最强快节奏杀伐文**

| 情绪阶段 | 节奏 | 写作要点 |
|---------|------|---------|
| **压**（恨/怒/急/险） | 中偏快 | 快速交代危机，不拖，让读者立刻揪心 |
| **爆**（燃/决绝） | 极快 | 短句、干脆、一气呵成，主角出手没有任何犹豫 |
| **爽**（畅快/立威） | 先快后收 | 快速解决+众人反应（1-2句），不拖泥带水 |

#### 6.5 最容易扑街的5个错误

| 错误 | 表现 | 修复 |
|------|------|------|
| ❌ **杀伐前疯狂内心戏** | 犹豫、心软、讲道理八百字 | 删掉内心戏，判断即行动 |
| ❌ **战斗又长又水** | 缠斗三百回合，来回复读 | 一招制敌，干净利落 |
| ❌ **反派降智但主角还耗** | 明明能秒杀，非要打半天 | 能秒就秒，不能秒才缠斗 |
| ❌ **节奏忽快忽慢** | 情绪断断续续，刚燃起来又冷了 | 全程保持情绪线，不中断 |
| ❌ **为装酷而装酷** | 没有情绪支撑的耍帅 | 所有"酷"都要有"压"的前置 |

#### 6.6 玄幻快节奏自检

- [ ] 本章是否"全程有事发生"（没有原地踏步的段落）？
- [ ] 是否删掉了三类节奏杀手（无意义环境/无效寒暄/旁白解释）？
- [ ] 句子是否偏短、动作是否干脆（一句一个动作）？
- [ ] 杀伐场景是否"干净"（一招制敌/不缠斗/不逼逼）？
- [ ] 杀伐前是否有"压抑"铺垫（让读者先揪心）？
- [ ] 杀伐时主角是否"不犹豫/不废话/不回头"？
- [ ] 情绪线是否完整（压→爆→爽 闭环）？
- [ ] 是否避免了"杀伐前疯狂内心戏"？
