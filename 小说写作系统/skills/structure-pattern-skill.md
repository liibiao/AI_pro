# structure-pattern-skill — 结构模式技能

## 用途
根据题材、平台和字数选择最合适的故事结构模式，提供结构骨架模板。

## 触发条件
当 Story-Architect 需要为新项目选择结构模式时调用。

## 输入
- 故事核
- 题材类型
- 目标平台与字数
- `project.json`

## 输出
- 结构模式推荐与理由
- 对应的阶段划分模板

---

## 方法论

### 一、结构模式库

#### 1. 三幕式（经典）
```
第一幕（25%）：建立 → 触发事件 → 进入冲突
第二幕（50%）：加压 → 中点反转 → 最低谷
第三幕（25%）：高潮 → 解决 → 新平衡
```
**适用**：短篇、情感文、悬疑反转文
**平台**：番茄短篇、七猫短篇

#### 2. 五幕式（升级版）
```
第一幕（15%）：铺设 — 世界+人物+日常
第二幕（20%）：上升 — 冲突触发+加压
第三幕（20%）：高潮前 — 中段转折+最大危机
第四幕（25%）：高潮 — 最终对决+真相揭露
第五幕（20%）：收束 — 回收+新平衡
```
**适用**：中长篇、多线叙事
**平台**：起点连载、番茄长篇

#### 3. 螺旋升级式（爽文专用）
```
循环单元：压制 → 蓄力 → 爆发 → 短暂平静 → 新压制
每个循环升级一个量级
全书由 5-10 个循环单元组成
```
**适用**：系统流、升级流、逆袭流
**平台**：番茄男频、起点男频

#### 4. 洋葱剥皮式（悬疑专用）
```
表层谜题 → 解开后发现更深谜题 → 再解开 → 核心真相
每层剥开都改变读者对故事的理解
```
**适用**：悬疑、推理、阴谋文
**平台**：番茄悬疑、起点悬疑

#### 5. 双线交织式
```
A线（现在时间线）：正在发生的事件
B线（过去/另一视角）：逐步揭露的真相
两线在关键节点交汇
```
**适用**：复仇文、真相揭露文、双视角文
**平台**：番茄女频、起点女频

#### 6. 碎片拼图式
```
非线性叙事，每章是一块拼图
读者在阅读过程中逐步拼出完整画面
最后一块拼图改变一切
```
**适用**：高概念短篇、实验性作品
**平台**：番茄短篇（高风险高回报）

### 二、结构选型决策树

```
题材是爽文/升级流？ → 螺旋升级式
题材是悬疑/推理？ → 洋葱剥皮式
题材是复仇/真相揭露？ → 双线交织式
字数 < 15000？ → 三幕式
字数 15000-80000？ → 五幕式
字数 > 80000？ → 五幕式 + 螺旋升级式混合
```

### 三、结构自检

- [ ] 每个阶段是否有独立的小高潮？
- [ ] 中段是否有持续加压机制（不塌腰）？
- [ ] 结构是否支持目标字数（不会写干也不会注水）？
- [ ] 结尾是否有回收能力？
