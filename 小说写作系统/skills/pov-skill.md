# pov-skill — 视角控制技能

## 用途
控制叙述视角、叙述距离与信息管控，确保读者获得的信息量恰到好处。

## 触发条件
当确定项目叙述视角、检查视角一致性、处理多视角切换时调用。

## 输入
- 项目类型与平台
- 故事结构
- 角色数量与复杂度

## 输出
- 视角方案
- 视角规则文档

---

## 方法论

### 一、视角类型

| 视角 | 特征 | 优势 | 劣势 | 适用 |
|------|------|------|------|------|
| **第一人称** | "我"叙述 | 代入感强、情绪直给 | 信息受限、无法写他人内心 | 番茄短篇、情感文、悬疑文 |
| **第三人称限制** | 跟随一个角色 | 兼顾代入感和叙事灵活性 | 仍有信息限制 | 长篇连载、玄幻、都市 |
| **第三人称全知** | 上帝视角 | 信息自由、可写任何角色 | 代入感弱、容易散 | 群像文、史诗文 |
| **多视角** | 不同章节不同视角 | 信息丰富、悬念感强 | 容易混乱、需要强结构 | 悬疑、多线叙事 |

### 二、视角选型建议

```
番茄短篇 → 第一人称（代入感最强）
番茄长篇 → 第一人称 或 第三人称限制
起点男频 → 第三人称限制（主角视角为主）
起点女频 → 第一人称 或 多视角
悬疑推理 → 第一人称 或 多视角
群像文 → 第三人称全知 或 多视角
```

### 三、叙述距离控制

| 距离 | 特征 | 效果 | 适用场景 |
|------|------|------|---------|
| **极近** | 角色内心独白、意识流 | 极强代入感 | 关键抉择、情感高潮 |
| **近** | 角色感受+行为 | 共情 | 大部分正文 |
| **中** | 客观描述+适度内心 | 平衡 | 日常推进、信息传递 |
| **远** | 纯客观、旁观者 | 冷静、紧张 | 大场面、群像、转场 |

#### 距离切换规则
- 情绪高潮时拉近（极近/近）
- 大场面时拉远（中/远）
- 同一场景内不要频繁切换距离
- 切换时用环境描写或动作做过渡

### 四、信息管控

#### 核心原则
读者知道的信息 = 视角角色知道的信息（限制视角下）

#### 常见信息管控错误
| 错误 | 说明 | 修复 |
|------|------|------|
| 上帝视角泄露 | 角色知道了不该知道的事 | 删除或改为推测 |
| 信息超前 | 还没发生的事被提前暗示 | 检查是否是故意伏笔 |
| 信息遗忘 | 角色忘记了已知信息 | 补充引用或反应 |
| 信息重复 | 同一信息多次交代 | 删除重复 |

### 五、多视角切换规范

如果使用多视角：
1. 每次切换必须有明确标记（章节标题/分隔符）
2. 切换后第一段必须明确当前视角角色
3. 不同视角的叙述风格应有区分
4. 同一事件从不同视角描述时，信息必须一致
5. 切换频率不宜过高（建议每章一个视角）

### 六、视角自检

- [ ] 全篇视角是否一致（除非故意切换）？
- [ ] 是否存在上帝视角泄露？
- [ ] 叙述距离的变化是否有过渡？
- [ ] 多视角切换是否有明确标记？
