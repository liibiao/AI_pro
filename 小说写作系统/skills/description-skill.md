# description-skill — 描写技能

## 用途
环境描写、动作描写、心理描写、五感写作，建立场景沉浸感。

## 触发条件
当需要为场景增加感官细节、氛围营造或心理刻画时调用。

> **配套 Skill**：`xiaolongbai-style-skill`（小白文风）提供完整的环境→人设→剧情联动方法论，适用于开篇环境、职业空间、世界观暗示等场景。

## 输入
- 场景设定（地点、时间、天气）
- 角色当前状态
- 场景情绪基调

## 输出
- 描写段落

---

## 方法论

### 一、五感写作法

每个重要场景至少调动 3 种感官：

| 感官 | 优先级 | 功能 | 使用频率 |
|------|--------|------|---------|
| **视觉** | 最高 | 建立画面基础 | 每次必写 |
| **听觉** | 高 | 营造氛围利器 | 推荐90%场景使用 |
| **触觉** | 中 | 增强代入感 | 推荐60%场景使用 |
| **嗅觉** | 中低 | 制造记忆点 | 推荐40%场景使用，开篇必写 |
| **味觉** | 低 | 点睛之笔 | 特殊场景使用（<10%） |

> **核心原则**：每次描写选2-3种最强的感官，不需要全写。动态 > 静态。

#### 各感官细化方向

**视觉**：光影（光源、明暗对比）→ 色彩（主色调、对比色）→ 状态（破旧/整洁/忙碌）→ 动态（正在发生的变化）

**听觉**：职业核心声（锤击/琴声）→ 环境声（远处人声/风雨）→ 角色声（喘息/心跳）→ 余韵声（回声/冷却声）
> 听觉"近→远→回"层次感：先写核心声，再写环境声，最后用余韵收尾。

**触觉**：温度（热浪/冰冷/温差）→ 质感（粗糙/光滑/油腻）→ 疼痛（烫伤/割伤/疲劳）

**嗅觉**：职业气味（炭火焦糊/药香/墨汁）→ 环境气味（潮湿/霉味）→ 异常气味（魔法气息/血腥味，用于埋钩子）

**味觉**：少用，仅特殊场景（铁锈腥甜/烟尘呛喉/汗水咸味）

#### 五感示例表

| 感官 | 通用示例 | 职业示例（铁匠） |
|------|---------|----------------|
| 视觉 | "路灯把他的影子拉得很长，像一把断了的刀。" | "炉膛里的火把整个铺子映成暗红色，火星在空气中划出短促的亮线。" |
| 听觉 | "雨打在铁皮屋顶上，像密集的鼓点。" | "铁锤砸铁砧叮——当！风箱呼哧作响，远处传来佣兵的吆喝声。" |
| 触觉 | "金属把手冰得刺骨，她的手指几乎粘在上面。" | "扑面热浪烤得脸发烫，后背却渗着冷汗，木柄粗糙得磨手。" |
| 嗅觉 | "空气里有血腥味，混着泥土的潮湿。" | "炭火焦糊混着铁腥味扑面而来，角落里有一股陈年油烟的腻味。" |
| 味觉 | "嘴里泛起铁锈般的腥甜。" | "烟尘呛得嗓子发紧，舌头干涩发苦。" |

### 二、描写密度控制

| 场景类型 | 描写密度 | 说明 |
|---------|---------|------|
| 动作/打斗 | 低 | 只写关键动作和结果，不做环境铺陈 |
| 氛围建立 | 高 | 用 2-4 句五感描写建立基调 |
| 日常推进 | 中低 | 穿插 1-2 句环境细节即可 |
| 情感高潮 | 中 | 用环境映射情绪，但不抢主角戏份 |
| 转场 | 极低 | 一句带过即可 |

### 三、环境描写技巧

#### 功能性描写（推荐）
环境描写必须服务于叙事，不是风景明信片：
- **映射情绪**：用环境暗示角色内心状态
- **制造氛围**：用环境建立紧张/压抑/温暖的基调
- **提供信息**：通过环境细节暗示世界观或剧情线索
- **推动剧情**：环境变化触发事件（暴风雨、停电、地震）

#### 禁止的描写
- 与剧情无关的纯风景描写
- 超过 5 行的连续环境描写
- 用华丽辞藻堆砌但没有信息量的描写

### 四、动作描写技巧

#### 核心原则：写受力结果，不写过程分解
- ❌ "他抬起右手，握紧拳头，手臂向后拉，然后猛地向前挥出。"
- ✅ "一拳砸下去，桌面裂了一条缝。"

#### 动作描写三要素
1. **动作本身**：谁做了什么
2. **受力结果**：产生了什么物理效果
3. **旁观反应**：其他人/环境的反应

### 五、心理描写技巧

#### 层次递进法
```
生理反应（心跳加速）→ 本能反应（想逃）→ 理性判断（不能逃）→ 决定（面对）
```

#### 心理描写方式
| 方式 | 适用 | 示例 |
|------|------|------|
| 内心独白 | 第一人称、关键抉择 | "不能退。退了就全完了。" |
| 微表情/微动作 | 第三人称、不想暴露内心 | "她的手指不自觉地攥紧了衣角。" |
| 环境投射 | 任何视角 | "窗外的雨越下越大。" |
| 生理反应 | 强烈情绪 | "胃里一阵翻涌，酸液涌上喉头。" |

### 六、描写自检

- [ ] 这段描写是否服务于叙事（映射情绪/制造氛围/提供信息/推动剧情）？
- [ ] 是否调动了至少 2 种感官？
- [ ] 描写密度是否与场景类型匹配？
- [ ] 是否存在"纯装饰性"的废描写？

### 七、镜头感写作（白特慢专项）

**核心一句话：镜头感不是"堆描写"，是用「视角切换+画面取舍+节奏控制」，让文字像"看电影"一样，读者能直观看到场景、动作、情绪，代入感翻倍。**

> 镜头感的本质，是"取舍"——知道该拍什么、该放大什么、该省略什么。

#### 7.1 镜头感的核心逻辑

**像导演一样思考**：拍什么、从哪个角度拍、拍多久、镜头怎么动。

| 对比 | 无镜头感 | 有镜头感 |
|------|---------|---------|
| 表达 | "他很生气，拿起刀砍向敌人" | "他瞳孔骤缩，指节因用力而发白，手中长刀猛地出鞘，寒光闪过，直劈敌人面门" |
| 效果 | 干巴巴，无画面 | 有角度、有细节、有动作，像看镜头 |

**网文镜头感的关键**："快、准、狠"

| 原则 | 含义 | 操作 |
|------|------|------|
| **快** | 镜头切换不拖沓，符合网文节奏 | 不在一个镜头上停留太久（除非是关键瞬间） |
| **准** | 聚焦核心动作、情绪、场景，不写无关细节 | 每个镜头只拍1个重点 |
| **狠** | 用特写放大关键瞬间（拔刀/打脸/反转），强化爽感 | 关键瞬间用慢镜头"放大" |

#### 7.2 五大核心技巧

**技巧一：镜头角度切换（像导演选机位）**

| 镜头类型 | 作用 | 适用场景 | 示例 |
|---------|------|---------|------|
| **特写** | 放大细节、强化情绪 | 关键动作、表情、道具 | 嘴角冷笑（表情特写）、剑尖滴血（道具特写）、指节发白（动作细节特写） |
| **中景** | 展现人物互动、动作过程 | 两人对峙、短兵相接 | 他后退半步避开劈砍，同时抬脚踹向敌人膝盖 |
| **远景** | 渲染氛围、展现格局 | 大场面、环境描写 | 漫天黄沙中两支军队遥遥相对，战旗猎猎作响 |
| **跟随** | 增强代入感、紧张感 | 追逐、逃跑、冲锋 | 他踩着碎石狂奔，身后追兵脚步声越来越近 |
| **俯视/仰视** | 凸显地位、气势 | 大佬登场、绝境场景 | 从脚下往上拍，他站在悬崖边衣摆猎猎，眼神睥睨众生 |

**技巧二：动作拆解（把"1秒动作"拆成"镜头片段"）**

> 动作拆解不是"啰嗦"，是让读者看到"镜头流动"，像看电影慢动作一样，爽感翻倍。

```
❌ 无镜头："他拔剑杀了敌人"
✅ 拆解版：
   他手按刀柄（预备镜头）
   → 手腕发力（动作特写）
   → 长刀出鞘发出"呛啷"声（听觉+动作）
   → 寒光闪过（视觉特写）
   → 敌人脖颈喷血倒地（结果镜头）
```

> 与 §四 动作描写"写受力结果不写过程"的互补：日常动作写结果（简洁），关键高潮动作拆过程（镜头感）。

**技巧三：感官镜头搭配（让画面"活"起来）**

镜头不只有"视觉"，还要加"听觉、触觉、嗅觉"——与 §一 五感写作法联动。

```
刀刃划破空气的锐响（听觉）
+ 肌肤被寒气刺痛的触感（触觉）
+ 血腥味在鼻尖弥漫（嗅觉）
+ 他盯着敌人惊恐的眼睛（视觉）
+ 嘴角勾起一抹冰冷的笑（表情特写）
```

> 关键：感官描写要"服务于镜头"，不堆砌无关感官（战斗场景不用写"路边花香"）。

**技巧四：镜头节奏控制（张弛有度）**

| 节奏 | 手段 | 适用场景 | 示例 |
|------|------|---------|------|
| **快镜头** | 短句、少描写 | 战斗、追逐、紧张 | "砍、挡、退、刺！刀光剑影中，他步步紧逼" |
| **慢镜头** | 长句、多特写 | 反转、打脸、情感爆发 | "时间仿佛静止，所有人的目光聚焦在圣旨上，'免死'二字墨迹未干……" |

**黄金搭配**：快镜头铺垫→慢镜头放大→快镜头收尾

```
追逐战快镜头 → 反转慢镜头 → 解决敌人快镜头
```

**技巧五：留白镜头（不写满，留想象空间）**

```
❌ 写满："众人纷纷露出震惊的表情，有人张大嘴巴，有人瞪大眼睛，有人后退一步……"
✅ 留白："他把刀扔在地上，转身走向远方。身后，是反派倒在血泊中的尸体，和众人震惊的沉默。"
```

> 留白留的是"无关细节"，核心动作/情绪必须拍清楚。

#### 7.3 三大场景镜头感模板

**① 战斗场景（快节奏+特写）**

```
跟随镜头（主角视角）
    → 动作特写（拔刀/出拳）
    → 听觉镜头（兵器碰撞声）
    → 慢镜头（击中敌人瞬间）
    → 快镜头（敌人倒地）
```

示例："他压低重心，脚步在石板上划出火花（跟随），右手紧握长刀，指节泛白（特写），'呛啷'一声出鞘（听觉），刀身寒光直逼敌人面门（视觉），就在刀刃即将触碰的瞬间，镜头突然放慢，能看到敌人瞳孔中的恐惧（慢镜头），下一秒，'噗嗤'一声，长刀入肉，敌人闷哼倒地（快镜头收尾）。"

**② 打脸场景（慢镜头+对比）**

```
中景（双方对峙）
    → 特写（反派嚣张表情）
    → 慢镜头（主角反击动作）
    → 特写（反派错愕表情）
    → 远景（众人反应）
```

示例："宴会厅里，反派拿着把柄仰头大笑（中景），嘴角的唾沫飞溅（特写）。突然，主角从怀中掏出证据，'啪'地拍在桌上（慢镜头），反派笑声戛然而止，眼睛瞪得像铜铃（特写），周围宾客纷纷倒吸凉气（远景）。"

**③ 金手指激活场景（特写+氛围）**

```
特写（主角困境）
    → 特写（金手指触发物）
    → 慢镜头（金手指激活特效）
    → 特写（主角震惊表情）
```

示例："他被逼到悬崖边，胸口剧痛（特写），手指无意间触碰到脖子上的玉佩（特写），玉佩突然发出耀眼的白光（慢镜头），温暖能量涌入四肢百骸，他瞪大双眼看着双手——伤势竟然瞬间愈合（特写）。"

#### 7.4 3个避坑要点

| 避坑 | 表现 | 修复 |
|------|------|------|
| ❌ **镜头混乱** | 频繁切换角度，没有主线（特写→远景→跟随→特写，读者晕） | 一段场景内镜头切换不超过3次，有主镜头 |
| ❌ **细节过载** | 每个镜头都堆满细节（衣服纹理+头发丝+路边小草） | 每个镜头只聚焦1个重点 |
| ❌ **脱离剧情** | 为镜头感而堆描写，不服务于冲突/爽点/人设 | 镜头必须服务于叙事（与§三功能性描写一致） |

#### 7.5 镜头感写作公式

```
镜头角度（特写/中景/远景）+ 动作拆解（连续镜头）+ 感官搭配（视/听/触）+ 节奏控制（快/慢）+ 留白 = 有画面感的文字
```

#### 7.6 镜头感自检

- [ ] 是否像导演一样思考了"从哪个角度拍"？
- [ ] 关键动作是否进行了"拆解"（不是一笔带过）？
- [ ] 镜头中是否调用了至少2种感官？
- [ ] 快慢节奏是否交替使用（纯快/纯慢都会疲劳）？
- [ ] 是否避免了"细节过载"（每个镜头只拍1个重点）？
- [ ] 是否避免了"镜头混乱"（一段场景内切换不超过3次）？
- [ ] 打脸/反转等关键瞬间是否用了"慢镜头"放大？
- [ ] 镜头感是否服务于叙事（不是纯装饰性描写）？

### 八、情绪极致拉满技法（白特慢·末世看稿）

> 来源：白特慢（白蘸糖）末世文看稿+情绪拉满实操教学。核心心法：**用细节把绝望、紧张、共情拉到极致**。
>
> 虽然以末世为例，但技法**通用**于所有高压/极端情绪场景（末世/悬疑/恐怖/废土/末日求生等）。

#### 8.1 拉情绪核心心法

**心法一：不写"很绝望"，写"活不下去的细节"**

| 错误 | 正确 |
|------|------|
| "末世好残酷，我好绝望。"（用形容词堆情绪） | "喉咙干得冒血，舔不到一滴露水；手指冻得握不紧刀，连块硬面包都抢不到。"（用**生理反应+生存困境**让读者共情） |

> 与 §五 心理描写"生理反应"互补：§五 提供通用生理反应框架（心跳加速→胃里翻涌），本节提供极端环境的**生存困境描写**方向（饥饿/寒冷/伤痛/匮乏）。

**心法二：情绪 = 极端环境 + 普通人 + 两难选择**

- 丧尸、天灾只是背景，**人性抉择**才是情绪爆点。
- 例：只剩一份水，给孩子还是给自己；救队友还是保物资。
- 核心逻辑：读者不是因为"末世"而共情，是因为"**和我一样的普通人在这种处境下该怎么办**"而共情。

**心法三：先压后爽，绝望越足，反击越爽**

- 把主角逼到绝境（断粮/受伤/被背叛），再用金手指/反转翻盘，爽感翻倍。
- 压制越具体（不是"他很惨"，而是"他的水壶只剩最后一口，而且那一口还漏了一半"），反击越爽。

> 与 `plot-loop-skill` §三剧情循环模式互补：白特慢循环侧重"发育→冲突→解决→收获"的结构闭环，本节侧重"**压制→绝境→翻盘**"的情绪曲线——两者组合使用，结构有骨架、情绪有血肉。

#### 8.2 生理窒息法（最稳、最通用）

用**极度具象的生理细节**让读者"跟着主角一起窒息"：

| 维度 | 技法 | 示例 |
|------|------|------|
| **呼吸** | 写呼吸的痛感和克制 | 吸气像吞碎玻璃，不敢大口换气，换气就咳血 |
| **触觉** | 写身体与物体的接触痛感 | 摸金属像被烙铁烫，皮肉粘在铁器上，撕开带皮 |
| **视觉** | 写视野收窄、注意力收缩 | 视线收窄，只能看到脚下半步，世界只剩生存 |

> 通用化：不限于末世。任何高压场景（审讯/被困/濒死/绝境战斗）都可以使用——关键是**写身体的具体痛感/受限感**，而非抽象的恐惧。

#### 8.3 记忆闪回杀（催泪/破防）

用**末世前的温暖碎片**，对比现在的惨状，制造强烈的情感落差：

| 写法 | 示例 |
|------|------|
| **触物生情** | 摸到半块巧克力，想起以前和家人逛街；看到旧照片，瞬间红眼眶 |
| **场景重叠** | 曾经热闹的街道，现在满地碎玻璃和血迹；以前在这家面馆吃面，现在只剩一面墙 |
| **感官触发** | 闻到一缕烟味，想起老爸抽烟的样子；听到远处孩子的笑声，想起自己的弟弟 |

**核心原则**：闪回必须**极短**（1-3句），像一闪而过的念头，不能变成大段回忆。闪回越短、对比越烈、催泪效果越强。

**闪回公式**：
```
当前困境触发（触物/场景/感官）
  → 短闪回（1-3句温暖碎片）
  → 硬切回现实（更残酷的现实）
```

#### 8.4 感官放大法 × 环境映照情绪

> 这两项是 §一 五感写作法 + §三 功能性描写→映射情绪 在极端情绪场景下的**强化版**，不再重复基础方法，只补充末世/高压场景的专属用法。

**感官放大法（末世专项）**：

| 感官 | 末世专属方向 | 示例 |
|------|-------------|------|
| 嗅觉 | 腐臭、硝烟、血腥味、发霉食物味，**反复强调**同一气味 | "空气里永远带着一股腐臭，洗不掉、躲不开" |
| 听觉 | 丧尸嘶吼、风声、自己的心跳、骨头摩擦声 | "夜里安静得只能听到自己的心跳，每一下都像在倒计时" |
| 味觉 | 水是涩的，食物是苦的，伤口是咸腥的 | "罐头打开，第一口是铁锈味，第二口才尝到那种发苦的肉味" |

**环境映照情绪（末世专项）**：

| 情绪 | 环境写法 |
|------|---------|
| 绝望 | 天是灰的，风是冷的，废墟像坟墓 |
| 希望 | 一缕阳光、一朵小花、一声婴儿啼哭 |
| 恐惧 | 影子被拉得变形，拐角处有不明响动，走廊尽头的灯忽明忽暗 |

#### 8.5 开局3段式情绪模板（直接套用）

> 与 `zhouzi-style-skill` §1.4「黄金一句→黄金三段」互补：肘子的进阶是"钩子→处境→冲突→看点"，本模板是"困境→压迫→钩子"——两者角度不同，可按需选用。

```
第1句（砸困境）：生理窒息法开场，用身体感受把读者拉入绝境
  ↓
第2句（给压迫）：外部威胁逼近，紧迫感拉满
  ↓
第3句（留钩子）：出现意外/转折，强迫读者点下一章
```

**末世示例**：
> 我攥着空水壶，指节泛白，喉咙里像塞了团烧红的炭。（困境）
> 丧尸的嘶吼越来越近，脚步声震得地面发颤，我连躲的地方都没有。（压迫）
> 就在这时，口袋里的旧手机，突然亮了一下。（钩子）

**通用化替换**（非末世场景）：

| 场景 | 砸困境 | 给压迫 | 留钩子 |
|------|--------|--------|--------|
| 悬疑 | "我从冰柜里摸到一个不属于我的东西——一只女人的手。" | "门外的脚步声停了。然后，门把手开始慢慢转动。" | "我低头一看，那只手戴着和我一模一样的戒指。" |
| 赘婿/打脸 | "离婚协议书摔在我脸上的时候，丈母娘还在笑。" | "门外传来了前妻和情夫的笑声，而我连住的地方都没有了。" | "手机响了，来电显示是本市首富的私人号码。" |
| 职场 | "工位上的东西已经被装进纸箱，HR站在我旁边催我签字。" | "老板的秘书走过来，当着所有人的面把门禁卡扔进垃圾桶。" | "邮箱弹出一条未读消息，发件人是竞争对手公司的CEO。" |

#### 8.6 末世/高压场景写作避雷

| 避雷 | 表现 | 修复 |
|------|------|------|
| ❌ **只打丧尸不写人** | 全程战斗动作，没人性挣扎，情绪出不来 | 每场战斗之间穿插"人的困境"（抉择/矛盾/牺牲） |
| ❌ **物资无限** | 永远不缺吃穿，绝望感直接归零 | 持续制造资源匮乏感，物资永远"差一点" |
| ❌ **圣母/双标** | 末世人设不稳，该狠的时候犹豫、该逃的时候心软 | 末世人设要有**一致的生存逻辑**，犹豫可以写，但必须有代价 |

#### 8.7 情绪极致拉满自检

- [ ] 是否用"生理反应+生存困境"替代了"情绪形容词"？
- [ ] 是否设计了"两难选择"让读者代入？（而非纯外部威胁）
- [ ] 压制是否足够具体？（不是"很惨"，而是具体的缺什么/痛在哪里）
- [ ] 生理窒息法是否至少用了1种？（呼吸/触觉/视觉）
- [ ] 是否用了记忆闪回制造情感落差？（1-3句，短促有力）
- [ ] 开局是否按"困境→压迫→钩子"三段式展开？
- [ ] 感官描写是否与情绪方向一致？（绝望时不用温暖的颜色/气味）
