# baiteman-design-skill — 白特慢创作设计技能

## 用途
建立"创作≠叙述"的核心方法论——创作是「有目的的设计」（埋逻辑、勾冲突、立人设），叙述是「单纯的信息罗列」。好故事要通过"设定→细节→冲突"的设计，让读者主动感知，而非被动告知。

## 触发条件
- 角色首次出场或需要强化人设时
- 世界观设定需要展示（而非说明书式介绍）时
- 组织/势力/系统（如情报系统、宗门、 guild）需要建立时
- 编辑阶段发现"信息倾销"或"形容词堆砌"时
- 任何需要将"设定"转化为"读者体验"的时刻

## 输入
- 需要传达的核心信息（人设/能力/世界观/组织架构）
- 该信息需要服务的叙事目的（建立信任感/制造悬念/推动冲突）
- 角色当前处境与状态

## 输出
- 通过细节和场景设计自然呈现信息的描写段落

## 方法论

### 一、核心原理：创作与叙述的本质区别

| 维度 | 叙述（❌ 避免） | 创作（✅ 追求） |
|------|---------------|---------------|
| **方式** | 罗列信息，直白告知 | 设计细节，让读者自己悟 |
| **工具** | 形容词（厉害/强大/缜密） | 具体场景、动作、道具 |
| **读者状态** | 被动接收信息 | 主动推导、参与感知 |
| **记忆效果** | 读完即忘 | 画面感强、印象深刻 |
| **核心公式** | 结论 + 原因 | 细节暗示 → 读者自行推导结论 |

**一句话准则**：
> 「让读者自己悟」永远大于「作者直接说」。

---

### 二、创作设计四步法（通用方法论）

任何需要传达信息的场景，都按以下四步执行：

```
第一步：明确核心目标
    ↓ 这段内容要让读者知道什么？（人设/能力/世界观/冲突）
第二步：设计细节载体
    ↓ 用什么具体事物承载这个目标？（服饰/道具/动作/场景）
第三步：加入冲突/张力
    ↓ 怎么让设定"活"起来？（矛盾/风险/漏洞/反差）
第四步：让读者主动感知
    ↓ 细节暗示，不直白告知，让读者自己推导
```

**自检问题**：写任何内容前先问——"这能体现什么？能推动什么？删掉后读者会损失什么？"

### 三、角色设计：用细节替代形容词

#### 3.1 身份设计：用"细节符号"替代"直白命名"

**反面**（叙述）：
> "张三是大明锦衣卫，武功高强，心思缜密，负责京城情报侦查。"

**正面**（创作）：
> 飞鱼服领口磨出的暗纹、腰侧绣春刀鞘口镶着小块和田玉、靴底藏着三根细针、指尖有厚茧（练刀+握笔）。

**身份符号设计四维度**：

| 维度 | 设计方向 | 示例 |
|------|---------|------|
| **视觉符号** | 服饰磨损/特殊装饰/随身物品 | 暗纹磨损（常年穿用）、玉鞘（皇家专属）、暗藏细针（情报人员） |
| **行为符号** | 习惯动作/警惕表现/职业痕迹 | 进门先扫出口、喝茶只抿一口、听到特定词摸刀柄 |
| **身体符号** | 茧子/伤疤/体态/微表情 | 指尖厚茧（双修）、旧刀痕、眼神不聚焦（实则在观察） |
| **社交符号** | 他人的反应/回避/特殊对待 | 同僚见他就避开、太监笑脸相迎但拒绝核心卷宗 |

#### 3.2 能力设计：用"具体场景"替代"形容词"

| 能力 | ❌ 叙述写法 | ✅ 创作写法 |
|------|-----------|-----------|
| 武功高强 | "他武功很好" | "刺客拔刀的瞬间，他没回头，反手用茶杯挡开刀刃，杯沿不晃，茶水未洒。" |
| 心思缜密 | "他很细心" | "他看了眼桌上凌乱的账本，指出第三行墨迹比其他行深（后补的假账），发现砚台底下压着半张密语纸条。" |
| 权势滔天 | "他很有权势" | "他走到哪里，周围的人自觉让出一条路；连城门口的守卫都不敢查他的通关文牒。" |
| 智谋过人 | "他足智多谋" | "他故意把假消息泄露给酒馆的乞丐，三天后敌军果然中了埋伏。" |

**能力设计公式**：
```
不写"他能做什么"，写"他在什么具体场景下做了什么，产生了什么结果"。
核心 = 场景（具体情境）+ 动作（具体行为）+ 结果（物理效果/他人反应）
```

#### 3.3 处境设计：用"隐性冲突"替代"直接说明"

| 处境 | ❌ 叙述写法 | ✅ 创作写法 |
|------|-----------|-----------|
| 深受信任但孤立 | "他受皇帝信任但被人孤立" | "拿着皇帝手谕去东厂调档，太监笑脸相迎却拒绝核心卷宗；回到衙门，同僚见他就避开。" |
| 暗藏危机 | "他处境危险" | "睡前把刀放枕边，床底藏着逃生密道机关；半夜听到屋顶瓦片响动，不动声色摸向信号弹。" |
| 经济困窘 | "他很穷" | "酒馆里他只要了一碗最便宜的素面，吃的时候却一口一口很慢，像是在品味山珍海味。" |
| 隐藏身份 | "他其实是XX" | 表面行为与某个细节矛盾（普通铁匠铺的炉火温度异常地高） |

#### 3.4 角色创作设计公式

```
身份符号（服饰/道具/身体痕迹）
    +
行为细节（习惯动作/警惕表现/职业痕迹）
    +
场景化能力（具体事件中做了什么）
    +
隐性冲突（处境中的矛盾/危机/反差）
    =
立体角色人设
```

### 四、世界观/组织设计：用具体节点替代笼统描述

#### 4.1 反面与正面对比

**反面**（叙述）：
> "这个世界有一套强大的情报系统，遍布各地，眼线众多，传递消息很快，没人能逃过监视。"

**正面**（创作）——分三层设计：

**第一层：架构节点（分层分工）**
```
京城"天机阁"（总控）→ 各州"驿站"（中转）→ 各县"据点"（收集）→ 底层"眼线"（各行各业）
分工：收集→整理→传递→分析→决策，每环节有明确职责
```

**第二层：运作细节（具体方式）**
```
传递：货郎货担里藏中空竹管，丝绸卷密语；信鸽+快马双保险，油纸防水+暗号加密
监视：茶馆老板擦桌时用手势示意伙计；乞丐留意路人衣着口音，每晚汇报
```

**第三层：冲突与张力（风险漏洞）**
```
内部：眼线被收买传假情报、驿卒被截杀密信丢失、内部争权隐瞒信息
外部：敌人用暗语交流避监视、故意误导眼线、猎杀据点致情报中断
```

#### 4.2 组织设计公式

```
架构节点（分层分级，有具体名称和地点）
    +
运作细节（用什么方式传递/收集/分析）
    +
冲突张力（系统漏洞/内外风险/对抗手段）
    =
真实可信的组织/系统
```

#### 4.3 组织设计通用模板

| 设计维度 | 问自己 | 示例方向 |
|---------|--------|---------|
| 顶端 | 谁控制？在哪？用什么名义？ | 天机阁/皇室暗卫/商会情报部 |
| 中层 | 怎么分层？节点在哪？ | 州→县→镇，每个层级有具体据点名称 |
| 底层 | 谁在干活？怎么隐藏身份？ | 茶馆老板/货郎/乞丐/青楼姑娘 |
| 传递 | 信息怎么流动？用什么载体？ | 信鸽/密信/暗号/特殊物品夹层 |
| 漏洞 | 系统哪里会出问题？ | 被收买/被截杀/内部权力斗争 |
| 对抗 | 敌人怎么反制？ | 暗语/误导/猎杀据点/渗透内部 |

### 五、创作禁忌清单

| 禁忌 | 表现 | 正确做法 |
|------|------|---------|
| ❌ 信息倾销 | 一次性罗列身份/能力/系统规则 | 分散在情节与细节中，每次只透露一部分 |
| ❌ 无细节支撑 | 用"厉害/强大/缜密"等形容词 | 用具体场景、动作、道具证明 |
| ❌ 无目的设计 | 写了与叙事无关的设定 | 每个设定都要服务"体现人设/冲突/世界观" |
| ❌ 逻辑断裂 | 设定之间自相矛盾 | 每个设定要考虑合理性与世界观一致性 |
| ❌ 被动告知 | 作者直接告诉读者结论 | 用细节暗示，让读者自己推导 |
| ❌ 设定平铺 | 没有冲突和张力 | 用矛盾/风险/漏洞让设定"活"起来 |

### 六、场景写作中的创作设计检查

#### 6.1 写作前检查（动笔前问自己）

- [ ] 这段内容的核心目标是什么？（让读者知道/感受到什么？）
- [ ] 我用的是"叙述"还是"创作"方式？（是否有具体细节和场景？）
- [ ] 读者是否能通过细节自己推导出结论？（还是我在直接告诉他们？）
- [ ] 这些细节是否服务于叙事？（人设/冲突/世界观/伏笔）

#### 6.2 写作后检查（写完问自己）

- [ ] 如果删掉这段，读者会损失什么？（如果什么都不损失，删掉）
- [ ] 这段内容中是否有至少一个"让读者自己悟"的细节？
- [ ] 是否存在"形容词堆砌"而没有场景支撑的情况？
- [ ] 信息量是否过大？（一段中不要超过2个新信息点）

#### 6.3 快速转换练习（叙述→创作）

| 叙述 | → | 创作 |
|------|---|------|
| 他很富有 | → | 他随手把一锭银子扔给店小二，连看都没看一眼 |
| 她武功很高 | → | 三名持刀匪徒围上来，她连眼皮都没抬，指尖弹出一颗石子，三把刀同时脱手 |
| 这个宗门很强 | → | 方圆千里的散修提起"天剑宗"三个字，都会不自觉地压低声音 |
| 他很谨慎 | → | 进任何房间，他都会先站在门口数三秒，确认没有异常才迈步进去 |
| 情报系统很厉害 | → | 你以为酒馆里那个擦桌子的伙计只是伙计？他每晚都会把今天听到的所有对话，用只有自己看得懂的符号记在一块布巾上 |
