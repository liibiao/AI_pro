# character-voice-skill — 角色语言风格技能

## 用途
为核心角色定义独特的语言风格，确保"遮住名字也能猜出是谁说的"。

## 触发条件
当设计角色对话风格、检查台词个性化程度时调用。

## 输入
- 角色圣经（性格、身份、教育背景）
- 已有对话样本

## 输出
- 角色语言档案（语言风格卡）
- 对话风格自检报告

---

## 方法论

### 一、语言风格四维度

#### 1. 句式偏好
| 类型 | 特征 | 适合角色 |
|------|------|---------|
| 短句型 | 5-10字为主，干脆利落 | 军人、杀手、冷漠型 |
| 长句型 | 20-30字，逻辑严密 | 学者、谋士、话痨型 |
| 碎片型 | 断句多、省略多 | 紧张、慌乱、少年型 |
| 书面型 | 用词考究、句式工整 | 贵族、文人、老派型 |

#### 2. 用词层级
| 层级 | 特征 | 适合角色 |
|------|------|---------|
| 粗糙 | 口语化、脏话、俚语 | 底层、江湖、军队 |
| 日常 | 普通口语、无明显特征 | 普通人、学生 |
| 精致 | 成语、典故、修辞 | 文人、权贵、老者 |
| 专业 | 行业术语、技术词汇 | 医生、黑客、科学家 |

#### 3. 情绪表达方式
| 类型 | 特征 | 示例 |
|------|------|------|
| 直给型 | 情绪直接外露 | "我恨你！" |
| 压抑型 | 说反话、冷处理 | "哦，是吗。" |
| 转移型 | 用别的事掩盖情绪 | "天气不错。"（刚吵完架） |
| 爆发型 | 平时沉默，关键时刻爆发 | "……够了！！！" |

#### 4. 口头禅与标志性用语
每个核心角色应有 1-2 个标志性语言习惯：
- 特定口头禅："妈的""行吧""有意思"
- 特定句式："你觉得呢？""不是我说……"
- 特定称呼方式：叫人全名/叫绰号/不叫名字

### 二、语言风格卡模板

```markdown
## [角色名] 语言风格卡

- 句式偏好：[短句型/长句型/碎片型/书面型]
- 用词层级：[粗糙/日常/精致/专业]
- 情绪表达：[直给/压抑/转移/爆发]
- 口头禅：[xxx]
- 标志性句式：[xxx]
- 禁忌用语：[这个角色绝不会说的话]
- 示例台词（3句）：
  1. 日常状态：""
  2. 愤怒状态：""
  3. 脆弱状态：""
```

### 三、对话个性化自检

- [ ] 遮住角色名，能否猜出是谁说的？
- [ ] 同一场景中不同角色的说话方式是否有区分？
- [ ] 角色的语言风格是否与其身份/性格匹配？
- [ ] 角色在不同情绪下的说话方式是否有变化但保持底色一致？
