# dialogue-skill — 对话写作技能

## 用途
写出有冲突、有潜台词、有信息量、有个性的对话。

## 触发条件
当需要写作或优化对话段落时调用。

## 输入
- 场景目标（这段对话要推进什么）
- 参与角色及其语言风格卡
- 当前冲突状态

## 输出
- 对话段落
- 潜台词标注（如需要）

---

## 方法论

### 一、对话功能分类

| 类型 | 目标 | 写法要点 |
|------|------|---------|
| **冲突对话** | 两方立场碰撞 | 短句快切、不退让、每句都在攻防 |
| **信息对话** | 传递关键情报 | 穿插动作和反应、不能变成问答 |
| **情感对话** | 建立/加深情感 | 留白多、动作多、台词少、潜台词重 |
| **威胁对话** | 制造压迫感 | 语气平静但内容残酷、用具体细节 |
| **揭秘对话** | 揭露真相 | 先铺垫、再投弹、留反应时间 |

### 二、潜台词技巧

#### 什么是潜台词
角色说的话 ≠ 角色想说的话。好对话的张力来自这个差距。

#### 潜台词模式
| 模式 | 示例 |
|------|------|
| 说反话 | "没事，我不在意。"（在意得要死） |
| 顾左右而言他 | "今天天气真好。"（不想谈刚才的事） |
| 用问题回避问题 | "你觉得呢？"（不想回答） |
| 用行动否定台词 | 说"我走了"但没动 |
| 沉默 | 不说话本身就是回答 |

### 三、对话节奏控制

#### 快节奏（冲突/打斗/争吵）
```
"滚。"
"你说什么？"
"我说——滚。"
```
特征：句短、无动作描写、无心理、纯台词对撞。

#### 中节奏（日常/信息/推进）
```
"报告出来了。"他把文件夹扔在桌上。
她拿起来翻了两页，眉头皱起来："这个数据不对。"
"哪里不对？"
"死亡时间。"她指着第三行，"和监控记录差了两个小时。"
```
特征：台词+动作穿插、有信息推进。

#### 慢节奏（情感/告别/独白）
```
他站在门口，很久没有说话。
"你还回来吗？"她问。
风吹过走廊，把门推开了一条缝。
"……不知道。"
```
特征：留白多、环境穿插、台词极少但每句都重。

### 四、对话禁忌

1. **问答模式**：A问B答A问B答，像采访
2. **独白伪装**：一个人说了200字，另一个人只说"嗯"
3. **旁白代言**：角色说出不符合身份的分析性语言
4. **信息倾倒**：通过对话一次性解释大量设定
5. **站桩聊天**：两人对话全程没有任何动作和环境互动

### 五、对白拖沓诊断（白特慢看稿重点）

**核心一句话：网文对白只干三件事——立人设、推剧情、造冲突；凡是不服务这三点的对话，全是拖沓。**

#### 5.0 一秒判断（满足任意一条就是拖沓）

- 删掉这句话，剧情**完全不受影响**
- 一句话能说清，硬拆成三句以上
- 角色说的话，**不符合身份、性格、处境**
- 连续三句只有情绪，**没有信息、没有目的**
- 角色在替作者"解释设定""复述剧情"

#### 5.1 干净对白三条铁律（白特慢核心）

| 铁律 | 说明 |
|------|------|
| **每一句对白都要有目的** | 质问、试探、威胁、拉拢、撒谎、炫耀、求饶、暗示、挑衅……必须带目的 |
| **谁说话，像谁** | 大佬不啰嗦、锦衣卫不软话、小人物不抢戏、反派不嘴碎 |
| **能用动作代替，绝不用嘴说** | 皱眉=不满；拍桌=动怒；转身=拒绝；递刀=信任；冷笑=不屑 |

#### 5.1 对白拖沓的判定标准

**核心判定：读完这段对话后，问自己——"删掉它，剧情会损失什么？"如果答案是"没损失"或"损失不大"，就是拖沓。**

| 判定维度 | 拖沓表现 | 正常表现 |
|---------|---------|---------|
| **信息推进** | 对话结束后情况没变化 | 对话结束后发生了推进/反转/冲突 |
| **角色塑造** | 对话中没有体现角色个性/立场 | 每个人的话都符合人设且有态度 |
| **冲突密度** | 几百字对话里没有一次交锋 | 每3-5句台词有一次小交锋 |
| **重复度** | 同一个意思换不同说法说了两三遍 | 每句话都有新信息或新态度 |
| **动作穿插** | 纯文字对话超过5句没有动作/环境/心理穿插 | 每2-3句台词穿插一个非台词元素 |

#### 5.2 对白拖沓的6种常见类型

| 类型 | 表现 | 修复方法 |
|------|------|---------|
| **寒暄式对白** | "你来了""嗯""坐吧""好"——无信息无态度无冲突 | 删掉寒暄，直接进入正题 |
| **重复确认式** | A说了，B复述一遍，A再说一遍确认 | 信息传递一次就够，B用行动/反应替代复述 |
| **解释式对白** | 角色像老师在给学生讲课一样解释设定 | 改为事件触发（让读者在场景中自己理解） |
| **站桩式对白** | 两个人站着/坐着聊了几百字，全程无动作无环境变化 | 每2-3句台词穿插动作、环境变化、心理活动 |
| **无分歧式对白** | 两个人意见完全一致，没有任何分歧或碰撞 | 加入分歧、质疑、不同立场，制造冲突 |
| **流水账式对白** | 对话只是在交代"接下来要做什么"，像任务清单 | 把任务交代压缩到最少，让对话聚焦于"为什么要这样做" |

#### 5.3 精简对白的4个技巧

**① 一句顶三句**
> ❌ "我觉得这件事我们不应该这么做，因为风险太大了，万一失败了后果不堪设想。"
> ✅ "别去。会死人的。"

**② 用动作/沉默替代台词**
> ❌ "他说他不同意。""她说她也不同意。"
> ✅ 他摇头。她也摇头。

**③ 删掉"过渡台词"**
> ❌ "接下来我要说一件事。""什么事？""就是关于……"
> ✅ 直接说那件事。

**④ 合并同类台词**
> ❌ "你确定？""你真的确定？""你百分之百确定？"
> ✅ "你确定？"（一句就够了，后面用动作展示角色在反复确认）

#### 5.4 拖沓→高能修改公式

> ❌ 拖沓：你怎么现在才来，我等你很久了，我真的很着急。
> ✅ 高能：你迟到了三刻钟。（冷脸抬眼）

> ❌ 拖沓：这件事太危险了，你千万别去，去了会死的。
> ✅ 高能：这是死路。（把刀按在他手里）

#### 5.5 对白拖沓自检

- [ ] 这段对话中，每句话是否都有新信息或新态度？（没有就删）
- [ ] 是否有超过5句连续纯台词没有任何动作/环境/心理穿插？（有就加入）
- [ ] 对话结束后，角色关系或情况是否发生了变化？（没变就拖沓）
- [ ] 删掉其中任何一句，读者能否察觉？（察觉不到就说明那句多余）
- [ ] 对话中是否有至少一次交锋/分歧/态度碰撞？（没有就是流水账）

#### 5.6 终极红线（白特慢强调）

- 对白**越短越有力**，长对话必崩节奏
- 对话只负责**交锋**，不负责**说明**
- 连续纯对话不要超过**3行**，超过必拖沓
