# xiaolongbai-style-skill — 小白文风技能（环境描写方法论）

## 用途
建立"小白文风"体系——以环境描写为核心竞争力的文风方法论。环境不是风景，而是「人设 + 世界观 + 剧情」的载体。适用于网文开篇、场景建立、职业氛围营造等需要用环境推动叙事的场景。

## 触发条件
- 写作开篇章节时（黄金3章环境建立）
- 新场景切入时（地点转换后的氛围建立）
- 角色职业空间描写时（铁匠铺/药铺/酒馆/修炼室等）
- 需要用环境展示世界观时
- 编辑阶段发现环境描写"纯写景无信息量"时

## 输入
- 场景类型（开篇/转场/职业空间/高潮场景）
- 角色当前状态（落魄/资深/隐藏身份）
- 世界观基调（西幻/仙侠/都市/末世）
- 该场景需要承担的叙事功能（人设/钩子/世界观/目标）

## 输出
- 符合"可感知 + 有职业 + 带钩子"三原则的环境描写段落

---

## 方法论

### 一、环境描写的核心定位

#### 1.1 环境 ≠ 风景

环境是**人设、世界观、剧情**三者的共同载体，不是风景明信片。

```
环境 = 主角当前状态 + 职业属性 + 世界背景 + 潜在冲突
```

**核心公式**：
> 好的环境描写 = 读者读完能同时知道"主角是什么人"+"这是什么样的世界"+"接下来要发生什么"

#### 1.2 网文开篇环境三原则

| 原则 | 含义 | 检验标准 |
|------|------|---------|
| **可感知** | 用五感落地，读者能"身临其境" | 读完能否"看到、听到、闻到"场景？ |
| **有职业** | 环境细节全是职业专属元素 | 换成其他职业，描写是否完全不成立？ |
| **带钩子** | 环境里埋悬念/矛盾/目标 | 读完是否想知道"接下来怎么办"？ |

#### 1.3 轻量化世界观原则

**禁止**：在开篇堆砌复杂设定（如神系、历史、种族大全）

**推荐**：用小元素快速出奇幻感：

| 世界观类型 | 快速出感元素（选2-3个即可） |
|-----------|------------------------|
| 西幻 | 魔法微光、异族订单、佣兵、边陲小镇、神秘矿石、符文铁器 |
| 仙侠 | 灵气波动、丹炉药香、符篆、阵法纹路、异兽、飞剑 |
| 都市异能 | 异常监控、超管局标志、能力残留痕迹、特殊装备 |
| 末世 | 废墟、变异痕迹、求生工具、资源匮乏标志 |

### 二、五感细化法

#### 2.1 五感选择策略

**核心原则**：每次描写选2-3种最强的感官，不需要全写。

| 感官 | 优先级 | 功能 | 使用频率 |
|------|--------|------|---------|
| 视觉 | 最高 | 建立画面基础 | 每次必写 |
| 听觉 | 高 | 营造氛围利器 | 推荐90%场景使用 |
| 触觉 | 中 | 增强代入感 | 推荐60%场景使用 |
| 嗅觉 | 中低 | 制造记忆点 | 推荐40%场景使用，开篇必写 |
| 味觉 | 低 | 点睛之笔 | 特殊场景使用（<10%） |

#### 2.2 视觉细化维度

| 维度 | 元素方向 | 写法要点 |
|------|---------|---------|
| **光影** | 光源、明暗对比、反光、阴影 | 从角色视角出发写光怎么照到主角身上 |
| **色彩** | 主色调、对比色、特殊颜色 | 用色彩暗示情绪（暗红=危险，冷蓝=异变） |
| **状态** | 破旧/整洁/忙碌/冷清 | 用物品状态暗示角色处境 |
| **动态** | 正在发生的视觉变化 | "火星溅在手臂上烫出泡"优于"地上有很多火星" |

**铁匠铺视觉示例**：
> 炉膛里的火把整个铺子映成暗红色，铁砧上放着一块烧得发白的铁料，火星飞溅出去，在昏暗的空气里划出一道道短促的亮线。

#### 2.3 听觉细化维度

| 类型 | 元素方向 | 氛围效果 |
|------|---------|---------|
| **核心声** | 职业专属声音（锤击/炉火/琴声/键盘） | 建立职业身份感 |
| **环境声** | 远处的声音（钟声/马蹄/风雨/人声） | 扩展空间感 |
| **角色声** | 角色发出的声音（喘息/心跳/脚步） | 增强代入感 |
| **余韵声** | 动作结束后的余响（嗡鸣/回声/冷却声） | 增加质感 |

**听觉黄金法则**：
> 先写职业核心声，再写环境声，最后用余韵声收尾。这种"近→远→回"的层次感让读者自然融入场景。

#### 2.4 触觉细化维度

| 类型 | 元素方向 | 写法要点 |
|------|---------|---------|
| **温度** | 热浪/冰冷/温差 | 用温度差制造不适感（烤脸vs后背冷汗） |
| **质感** | 粗糙/光滑/油腻/硌脚 | 用质感暗示环境品质 |
| **疼痛** | 烫伤/割伤/疲劳 | 用微痛增加真实感 |

#### 2.5 嗅觉细化维度

| 类型 | 元素方向 | 使用场景 |
|------|---------|---------|
| **职业气味** | 炭火焦糊/药香/墨汁/机油 | 开篇必写，建立场景记忆点 |
| **环境气味** | 潮湿/霉味/清新/腐臭 | 暗示环境状态 |
| **异常气味** | 与世界观不符的气味（魔法气息/血腥味） | 埋钩子、制造悬念 |

**嗅觉特殊价值**：嗅觉是最容易触发记忆的感官，开篇一段独特的职业气味能成为整个场景的"嗅觉锚点"，后续再次出现时读者会瞬间回想起来。

#### 2.6 味觉（少用，点睛）

- 嘴里泛起铁锈般的腥甜（战斗后）
- 烟尘呛喉（进入环境的第一反应）
- 汗水咸味（间接写，不直写味觉）

### 三、职业空间环境结构模板

任何职业空间都可分为三个圈层：

#### 3.1 核心区（必须写，1-2段）

职业空间中最具代表性的区域，直接展示角色在做什么：

| 职业 | 核心区 | 关键元素 |
|------|--------|---------|
| 铁匠 | 熔炉+铁砧 | 火势、燃料、铁水、锤痕、工具摆放 |
| 药师 | 药柜+炼丹炉 | 药格、丹炉火候、药材气味、成品/废丹 |
| 酒馆 | 吧台+大厅 | 酒桶、杯子、嘈杂声、告示板、角落暗影 |
| 修仙者 | 洞府/修炼室 | 灵脉阵法、蒲团、灵气波动、法器 |
| 侦探/调查员 | 办公室 | 案板、线索墙、咖啡杯、资料堆 |

#### 3.2 工作区（选择性写，1段）

展示角色的专业度和资源状况：

- **材料/资源区**：材料架/药柜/资料柜——显示资源丰裕还是匮乏
- **工具墙**：工具的种类、数量、磨损程度——显示专业度和经济状况
- **成品/成果区**：成品展示/案例墙——显示水平高低
- **废品/失败区**：废料堆/失败品——暗示尝试次数和困境

#### 3.3 环境延伸（1-2句，带出世界观）

从室内扩展到室外，用少量信息暗示更大的世界：

- 铺子外：街道上什么人经过？远处有什么标志性建筑？天气如何？
- 铺子内：挂在墙上的物品/账本/订单/告示——暗示社交关系和世界观

### 四、环境→人设→剧情联动法

#### 4.1 用环境写人设（不直接说"他是XX"）

**落魄型角色**的环境特征：
> 铺子破旧、工具少、材料差、废品多、炉膛弱、自己拉风箱、汗流浃背、订单少

**资深型角色**的环境特征：
> 工具齐全、炉火旺盛、材料优质、成品精良、订单多、有学徒帮手、神态沉稳

**隐藏身份型角色**的环境特征：
> 表面普通但暗藏玄机——普通铁匠铺角落有一块发光的矿石、药铺老板随手泡的茶有灵气波动

**环境人设对照表**：

| 人设标签 | 环境信号 | 具体表现 |
|---------|---------|---------|
| 穷 | 材料差、工具磨损、空间狭小 | 只剩一块神秘黑铁，其他都是废料 |
| 忙 | 东西堆满、来不及收拾、订单多 | 桌上堆着三层未完成的委托 |
| 强 | 成品精良、有独特作品、被人尊重 | 墙上挂着某位大人物亲赠的兵器 |
| 隐藏 | 表面普通但有异常细节 | 破旧铺子的炉火温度异常地高 |
| 危机 | 材料告急、有人催债、外部威胁 | 门外贴着限期缴租的通知 |

#### 4.2 用环境埋钩子

**四类环境钩子**：

| 钩子类型 | 示例 | 效果 |
|---------|------|------|
| 资源危机 | 优质铁快用完、只剩一块神秘黑铁 | 制造紧迫感 + 神秘感 |
| 特殊订单 | 贵族/骑士/巫师送来奇怪图纸 | 引出下一个事件 |
| 异常现象 | 铁块自动发热、淬火时异象 | 悬疑钩子 |
| 生存压力 | 欠租、师傅施压、竞争威胁 | 制造动机 |

#### 4.3 环境→目标（第一章立刻有行动线）

```
环境差   → 目标：赚钱升级/打造好兵器/还债
神秘料   → 目标：锻造成神器/查明来历/完成特殊订单
危机到   → 目标：赶制兵器/保护自己/逃离险境
异常现象 → 目标：调查真相/掌握能力/揭开秘密
```

### 五、环境描写禁忌清单

| 禁忌 | 错误表现 | 正确做法 |
|------|---------|---------|
| ❌ 纯写景 | 无角色、无职业、无冲突 | 每个环境细节都要服务于人设/剧情/世界观 |
| ❌ 堆砌设定 | "这个世界有XX神、XX种族、XX等级" | 用环境细节自然带出世界观 |
| ❌ 无关细节 | 写铁匠铺时描写花、鸟、云 | 只写与职业/剧情相关的细节 |
| ❌ 平淡静态 | 全是"有什么"，没有动态 | "火星溅在手臂上"优于"地上有很多火星" |
| ❌ 无世界观感 | 写成现代铁匠铺，缺少奇幻元素 | 至少2个世界观暗示元素 |
| ❌ 超过5行连续描写 | 大段环境铺陈 | 环境描写穿插在动作和对话中 |

### 六、环境描写自检清单

**开篇环境（黄金3章）**：
- [ ] 是否从主角视角出发（不是上帝视角）？
- [ ] 是否包含至少3种感官（视+听+触/嗅）？
- [ ] 环境是否展示主角的职业/身份/处境？
- [ ] 环境中是否埋了至少一个钩子（悬念/危机/目标）？
- [ ] 是否有至少2个世界观暗示元素？
- [ ] 环境描写是否穿插在动作中（不是纯静态铺陈）？
- [ ] 总描写长度是否控制在3-5段以内？

**转场环境**：
- [ ] 是否用1-2句快速建立新场景的氛围？
- [ ] 是否与上一场景有情绪/色调对比？
- [ ] 是否至少有1个新信息（推动剧情或展示世界观）？

**职业空间**：
- [ ] 核心区是否写到位？
- [ ] 环境→人设的映射是否清晰？
- [ ] 工具/材料的描写是否符合世界观（不是现实照搬）？

### 七、实战范例

#### 西幻铁匠铺开篇（落魄学徒）

> 炉膛里的火快要灭了，只剩一簇暗红色的余烬在炭灰里明灭。林恩咬着牙拉风箱，手臂酸痛得像灌了铅，呼哧呼哧的喘息声比风箱还响。
>
> 铁砧上放着半块黑铁，边缘已经冷了，锤痕歪歪扭扭——那是一个时辰前他第七次尝试的成果，又是一把废品。墙角的废铁堆已经快齐腰高了。
>
> 门口的木板上贴着一张泛黄的催租通知，墨迹被雨水晕开，但"三日之内"四个字还是看得清清楚楚。铺子外面，几个佣兵正骑着马走过，马蹄声在小石板路上哒哒作响，带着远处酒馆传来的嘈杂人声和劣质麦酒的酸味。
>
> 林恩把目光移向材料架——最底层只剩几块生锈的粗铁，上面一层空空荡荡。唯一还发着微光的，是架子最角落里那块拇指大小的、来历不明的暗紫色矿石。

**拆解**：
- 五感：视觉（暗红余烬/歪扭锤痕）+ 听觉（风箱喘息/马蹄/酒馆嘈杂）+ 触觉（手臂酸痛）+ 嗅觉（麦酒酸味）
- 人设：落魄（废铁齐腰/催租通知/材料告急）
- 钩子：神秘暗紫色矿石 + 催租三日
- 世界观：佣兵/酒馆/马蹄暗示西幻边陲小镇
- 动态：拉风箱的喘息、马蹄声、远处嘈杂——没有一段纯静态
