# xiuxian-genre-skill — 修仙文写作技能

## 用途
修仙文的题材专属写作方法论，覆盖境界体系、战斗设计、细节真实感、情绪闭环等修仙文核心要素。避免"堆境界、扔法宝"的流水账写法，用细节真实感留住读者。

## 触发条件
- 写修仙/玄幻/仙侠类题材时
- 需要设计境界体系、功法、丹药、法器时
- 需要设计修仙战斗场景时
- 需要设计宗门/门派社会结构时
- 修仙文出现"读者劝退"风险时

## 输入
- 故事三要素（题材/金手指/主角身份）
- 世界观设定（力量体系/势力格局）

## 输出
- 修仙文细节真实感设计方案
- 战斗/升级/宗门等场景的"不劝退"设计

## 方法论

### 一、修仙文6个致命劝退细节

#### 1.1 境界升级太随意，没有"代价感"

| 错误 | 正确 |
|------|------|
| 打坐就升级、吃丹就突破、随便捡本秘籍就无敌 | 升级必须有门槛、有风险、有资源、有代价 |

升级的"代价"来源：

| 代价类型 | 说明 | 示例 |
|---------|------|------|
| **资源门槛** | 灵气/丹药/功法不够 | 需要特定天材地宝才能突破 |
| **心魔干扰** | 内心执念/恐惧干扰突破 | 突破时必须面对过去的阴影 |
| **丹药反噬** | 药力过猛或杂质积累 | 吃太多丹药导致经脉堵塞 |
| **宗门限制** | 不允许私自突破/资源被管控 | 想突破但材料被长老垄断 |
| **天道雷劫** | 越级突破会引来天劫 | 突破时必须在雷劫中存活 |

> 读者要的是**"好不容易才变强"**，不是"随便就成神"。

#### 1.2 战斗只拼境界，没有"战术感"

| 错误 | 正确 |
|------|------|
| 谁境界高谁赢，大喊招式名就结束 | 战斗靠环境、心智、底牌、克制关系、弱点 |

**修仙战斗5要素**：

| 要素 | 说明 | 示例 |
|------|------|------|
| **利用地形** | 地形对战局的影响 | 引敌人到灵气稀薄之地削弱对方 |
| **心智博弈** | 试探、佯攻、心理战 | 假装露出破绽引对方近身 |
| **底牌策略** | 藏底牌、出其不意 | 隐藏实力直到关键一刻 |
| **克制关系** | 属性/功法/法器相克 | 水系功法克火系法器 |
| **攻敌破绽** | 利用对方功法/法器的缺陷 | 消耗对方灵气使其法器失控 |

> 战斗要有**来有回、有算计、有反转**，才好看。

#### 1.3 人设千人一面，没有"真实感"

| 错误 | 正确 |
|------|------|
| 所有人都无脑挑衅、无脑跪舔、无脑嫉妒 | 角色做事有动机、立场、利益 |

| 角色行为 | 错误理解 | 正确逻辑 |
|---------|---------|---------|
| 长老打压主角 | "天生坏人" | 怕主角威胁他的地位/资源 |
| 同门敌视 | "嫉妒心强" | 资源有限，多一个竞争者 |
| 反派使坏 | "纯粹作恶" | 争夺机缘/利益驱动 |
| 高手不出手 | "装逼" | 有不出手的合理原因（代价/规则/利益） |

> 角色不降智，读者才不尴尬。

#### 1.4 金手指无规则、无限制，越写越崩

| 错误 | 正确 |
|------|------|
| 系统想给就给、功能随便加、用时无冷却 | 有规则、有限制、有代价、有升级路径 |

> 详见 `plot-loop-skill.md` §4.1-4.5 金手指全套设计方法论。

#### 1.5 世界观只写设定，不"影响主角"

| 错误 | 正确 |
|------|------|
| 开篇堆世界观背景、历史、种族，跟主角无关 | 世界观直接给主角使绊子 |

| 世界观要素 | 使绊子方式 |
|-----------|-----------|
| **宗门规矩** | 压制主角的行为/突破/资源获取 |
| **资源稀缺** | 关键材料被垄断，主角必须冒险 |
| **境界歧视** | 低境界被轻视/排挤，制造冲突 |
| **正邪对立** | 主角的身份/行为触犯阵营规则 |

> 详见 `plot-loop-skill.md` §4.4 三者使绊子方法论。

#### 1.6 情绪不闭环，爽点"不痛不痒"

| 错误 | 正确 |
|------|------|
| 被羞辱不愤怒、升级不激动、复仇不解气 | 先压抑→再期待→最后爆发 |

```
情绪闭环公式：被踩到底 → 积累怒气/期待 → 反弹 → 爽感爆发
```

> 读者追的是**情绪**，不是剧情流水账。详见 `hook-design-skill.md` §6 爽点设计体系。

### 二、修仙文5个核心细节（留住读者）

#### 2.1 灵气细节（真实感基础）

| 维度 | 设计方向 | 示例 |
|------|---------|------|
| **浓度** | 不同环境灵气浓度不同 | 灵脉旁=浓郁，荒漠=稀薄，禁地=狂暴 |
| **属性** | 灵气有属性（金木水火土/冰雷风暗） | 火属性灵地适合火系修炼，水系吸收效率低 |
| **纯度** | 灵气纯度影响修炼效率 | 天地灵气 vs 丹药灵气 vs 杂气 |
| **吸收速度** | 经脉/体质影响吸收 | 主角经脉堵塞，吸收极慢→需要功法/丹药辅助 |
| **紊乱风险** | 吸收过快/杂气过多→走火入魔 | 主角为了快速突破冒进→灵气紊乱→代价 |

#### 2.2 功法细节（差异化关键）

每部功法必须有以下维度：

| 维度 | 说明 | 示例 |
|------|------|------|
| **优缺点** | 没有完美功法 | 攻击强但防御弱；修炼快但上限低 |
| **适配体质** | 功法与体质匹配 | 纯阳体质适合火系功法，阴寒体质练不了 |
| **反噬风险** | 修炼不当的后果 | 功法走偏→经脉寸断→修为倒退 |
| **修炼速度** | 影响升级节奏 | 低阶功法=龟速；高阶功法=但材料难求 |
| **战斗偏向** | 功法决定战斗风格 | 剑修=锋利爆发；符修=多变控制 |
| **品级/残缺/秘密** | 功法本身的"梗" | 残缺功法→后续补全→实力暴涨 |

#### 2.3 丹药/法器细节（不做摆设）

**丹药**：
| 维度 | 说明 |
|------|------|
| **副作用** | 吃多了有抗性/杂质积累/依赖性 |
| **品级差异** | 低品=效果弱但安全；高品=效果好但难求/有风险 |
| **适配度** | 不同体质/境界对丹药反应不同 |
| **稀缺性** | 关键丹药被垄断/需要珍稀材料/炼制难度高 |

**法器**：
| 维度 | 说明 |
|------|------|
| **灵力消耗** | 使用法器需要消耗灵力，不是无限用 |
| **破损** | 法器会损坏，需要维护/修复/升级 |
| **破绽** | 再强的法器也有弱点，可被利用 |
| **适配度** | 不是越高级越强，要看与功法/体质的匹配 |
| **成长性** | 法器能否成长/进化（可以是一个长期目标） |

#### 2.4 宗门与人际细节（真实社会感）

| 维度 | 说明 | 示例 |
|------|------|------|
| **资源分配** | 资源有限导致竞争 | 灵石/丹药/秘境名额按贡献/境界分配 |
| **派系斗争** | 宗门内部分派 | 长老A派vs长老B派，主角被夹在中间 |
| **师徒关系** | 师父不是无条件的 | 师父收徒有目的/师父也受宗门约束 |
| **赏罚制度** | 有明确的奖惩规则 | 立功=奖励资源；犯错=禁闭/逐出 |
| **晋升规则** | 内外门/等级有门槛 | 外门弟子需要特定条件才能进入内门 |
| **人情往来** | 人脉是隐性资源 | 欠人情=将来要还；帮别人=积累人脉 |

#### 2.5 危机与代价细节（张力来源）

| 场景 | 代价/风险 |
|------|----------|
| **突破失败** | 陨落、修为倒退、重伤、经脉损毁 |
| **夺机缘** | 被追杀、被记恨、被反噬、触发禁制 |
| **用禁术** | 折寿、化魔、遭天谴、被正道追杀 |
| **越级挑战** | 灵气耗尽、法器损毁、受暗伤 |
| **进入禁地** | 迷路、中毒、被困、遇到远古存在 |

### 三、修仙文"不扑街"公式

```
真实细节（灵气/功法/宗门/丹药/法器）
  + 刚性压力（生存/竞争/规则/资源）
  + 逻辑行动（主角不得不做）
  + 情绪闭环（压抑→反转→爽）
  = 读者追着看的修仙文
```

### 四、修仙文自查表（3秒判断是否劝退）

- [ ] 升级有没有**代价与风险**？（不是随便突破）
- [ ] 战斗有没有**战术与反转**？（不是境界高就赢）
- [ ] 角色做事有没有**动机与逻辑**？（不是降智反派）
- [ ] 金手指有没有**规则与限制**？（不是无限外挂）
- [ ] 世界观有没有**给主角施压**？（不是背景板）
- [ ] 爽点有没有**先压后爆**？（不是无痛爽）

> 全满足→稳；缺2项以上→必扑。
