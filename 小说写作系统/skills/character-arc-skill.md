# character-arc-skill — 角色弧线技能

## 用途
设计主角成长弧线、反派压制链、配角功能分配与人物变化路径。

## 触发条件
当需要设计角色系统、追踪角色变化、检查人设一致性时调用。

## 输入
- 故事核与大纲
- 角色初始设定
- 目标平台与题材

## 输出
- `02-characters/character-bible.md`
- `02-characters/relationship-map.md`
- `02-characters/arc-tracker.md`

---

## 方法论

### 一、角色弧线设计

#### 弧线公式
```
起点状态（缺口）→ 触发事件 → 挣扎与试错 → 关键抉择 → 终点状态（成长/堕落）
```

#### 弧线类型
| 类型 | 说明 | 适用 |
|------|------|------|
| **正向弧** | 从弱到强、从迷茫到清醒 | 爽文、成长文 |
| **负向弧** | 从善到恶、从信任到崩塌 | 悲剧、黑暗文 |
| **平弧** | 角色不变，但改变周围世界 | 英雄文、信念文 |
| **螺旋弧** | 反复在成长与退步间挣扎 | 现实文、深度文 |

#### 弧线锚点
每个弧线必须标注 3-5 个锚点：
1. **起点锚**：角色最初的状态和缺口
2. **触发锚**：打破日常的事件
3. **低谷锚**：角色最脆弱/最绝望的时刻
4. **抉择锚**：角色做出关键选择的时刻
5. **终点锚**：角色最终的状态

### 二、反派压制链

#### 压制链设计原则
1. 反派的压制必须层层升级，不能一直同一水平
2. 每次压制必须逼出主角的新能力或新认知
3. 反派必须有自己的逻辑，不能为恶而恶

#### 压制链模板
```
小反派压制 → 主角突破 → 中反派压制 → 主角再突破 → 大反派压制 → 最终对决
```

#### 反派层级
| 层级 | 功能 | 存在时长 |
|------|------|---------|
| 炮灰反派 | 让主角小试牛刀 | 1-3 章 |
| 阶段反派 | 制造阶段性危机 | 5-15 章 |
| 核心反派 | 贯穿全书的主要对手 | 全书 |
| 隐藏反派 | 真相揭露时的震撼 | 后半段揭露 |

### 三、配角功能分配

每个配角必须承担至少一个功能：

| 功能 | 说明 | 示例 |
|------|------|------|
| **镜像** | 映射主角的另一种可能 | 走了不同路的同门 |
| **催化** | 推动主角做出关键决定 | 导师、挚友 |
| **信息** | 提供关键情报或线索 | 知情者、调查者 |
| **情感锚** | 让读者共情的情感载体 | 妹妹、恋人 |
| **对比** | 通过对比凸显主角特质 | 同类型但不同选择的角色 |
| **工具** | 提供特定能力或资源 | 治疗师、黑客 |

### 四、人物关系动力学

#### 关系类型
- **对立**：目标冲突，必须有一方妥协或失败
- **同盟**：目标一致，但方法或底线可能不同
- **暗线**：表面一种关系，实际另一种
- **动态**：关系在故事中发生根本性变化

#### 关系网自检
1. 主角与每个核心角色的关系是否有张力？
2. 是否存在"没有冲突的关系"？（如果有，考虑删除或增加冲突）
3. 关系变化是否推动了剧情？

### 四B、主角核心标签与反差感（白特慢看稿重点）

#### 4B.1 核心标签设计

**核心标签 = 用1-2个关键词定义主角，让读者一眼记住。**

| 设计原则 | 说明 | 示例 |
|---------|------|------|
| **少而精** | 1-2个标签足够，多了等于没标签 | "隐忍赘婿""暴躁战神""腹黑学霸" |
| **有冲突感** | 两个标签之间要有内在矛盾 | "腹黑"+"善良"（聪明但善良，而非纯阴险） |
| **有画面感** | 标签能让人联想到具体形象 | "抠门首富"（不直接说有钱，说抠门+首富有反差） |
| **可量化** | 标签能在剧情中"升级"或"转化" | "废柴"→"天才"，"赘婿"→"龙王" |

**标签提取三问**：
1. 如果用3个词形容主角，哪2个最重要？
2. 读者看完第1章，能用1个词描述主角吗？
3. 标签是否与金手指/身份有化学反应？

#### 4B.2 反差感设计

**反差感 = 角色的外表/身份/表象 与 内在/实力/真相 之间存在矛盾，读者会好奇"为什么这样"。**

| 反差维度 | 设计方向 | 示例 |
|---------|---------|------|
| **外表 vs 实力** | 看起来弱，其实强 | 柔弱少女是顶级杀手、憨厚胖子是金融大佬 |
| **身份 vs 真实** | 表面身份 vs 隐藏身份 | 普通学生是隐形富豪、实习医生是顶尖专家 |
| **性格 vs 处境** | 性格与当前处境矛盾 | 高冷战神私下怕老婆、杀神其实是个路痴 |
| **动机 vs 行为** | 想要A却做着与A矛盾的事 | 想低调却不断被迫高调、想独处却总被卷入麻烦 |
| **期望 vs 实际** | 别人以为他是A，其实是B | 所有人以为他是废物，实际他在扮猪吃虎 |

**反差感设计公式**：
```
表面印象（读者第一反应）
    +
隐藏真相（第2-5章逐步揭露）
    +
矛盾张力（表面与真相的冲突产生剧情推动力）
    =
有记忆点的立体角色
```

**反差感使用原则**：
- 反差不能太多（1-2个维度足够，多了读者记不住）
- 反差必须有合理解释（不是强行反转）
- 反差要在前3章内埋下暗示（不能突然揭晓毫无铺垫）
- 反差的揭露本身就是一个爽点（震惊众人+读者恍然大悟）

### 四C、配角羁绊设计（白特慢看稿重点）

#### 4C.1 什么是"羁绊"？

**羁绊 = 读者会在意这个配角的原因。** 如果配角只是"有用"但没有"羁绊"，读者不会在意他的死活。

| 有羁绊的配角 | 没羁绊的配角 |
|------------|------------|
| 读者会在意他的安危 | 读者不在乎他死不死 |
| 他的牺牲会让读者心疼 | 他的牺牲毫无波澜 |
| 他叛变会让读者震惊愤怒 | 他叛变读者毫无感觉 |

#### 4C.2 羁绊建立的5种方式

| 方式 | 说明 | 示例 |
|------|------|------|
| **共同经历** | 一起经历过生死/困境/冒险 | 主角和配角一起被困在密室，互相托付后背 |
| **救命之恩** | 一方救过另一方，产生情感债务 | 配角在主角最危险时出手相救 |
| **秘密共享** | 共同保守一个秘密，形成特殊联系 | 两人一起发现了某个真相，不能告诉任何人 |
| **师徒/亲人关系** | 有教导/培养的情感纽带 | 主角的师父/义父/兄弟，有深厚的感情基础 |
| **从敌到友** | 曾经对立，经历事件后成为盟友 | 反派被主角救了一命，从此效忠 |

#### 4C.3 羁绊升级的3个阶段

```
阶段1：初识/建立联系（表面关系）
    ↓ 通过共同经历/事件加深
阶段2：信任/依赖（深层关系）
    ↓ 通过危机/考验确认
阶段3：生死之交/背叛（关系转折）
```

#### 4C.4 配角羁绊自检

- [ ] 这个配角如果死了，读者会心疼吗？（如果不会，羁绊不够）
- [ ] 配角与主角之间是否有"共同经历"？（不是单方面的帮助）
- [ ] 配角是否有自己的目标/欲望？（不是只围着主角转）
- [ ] 配角与主角之间是否存在潜在的矛盾？（纯粹和谐的关系没张力）

### 五、角色一致性检查清单

- [ ] 角色的决策是否符合其欲望和恐惧？
- [ ] 角色的语言风格是否前后一致？
- [ ] 角色的能力是否在合理范围内？
- [ ] 角色的情绪反应是否符合其性格？
- [ ] 角色的成长是否有足够的铺垫？

### 六、男主原型设计（白特慢看稿重点）

#### 6.1 "魅力渣男主"设计法

**核心一句话：读者讨厌的是"又渣又坏又蠢"，喜欢的是"渣得有底线、有理由、有魅力、有原则"。**

> 渣是行为，不是人品；浪是选择，不是烂人。

**真渣 vs 魅力渣**：

| ❌ 真渣（劝退） | ✅ 魅力渣（吸粉） |
|-----------------|-----------------|
| 自私自利，出卖亲友，毫无底线 | 只对敌人渣，不对弱者坏 |
| 懦弱、甩锅、暴力、PUA | 有底线：不害亲友、不坑队友、护短 |
| 为了爽而渣，为了开后宫而渣 | 渣得清醒、渣得坦荡、渣得有原则 |
| 伤害无辜，毫无愧疚 | 行为浪，内心稳；嘴上骚，做事狠 |

**5大核心设计**：

| # | 原则 | 说明 |
|---|------|------|
| 1 | **渣是保护色，不是本性** | 内心有创伤/责任/不得不装冷漠的理由；外表玩世不恭，内心极度清醒 |
| 2 | **对外渣，对内宠** | 对敌人：算计、利用、翻脸无情；对队友/亲人/爱人：护短、双标、拼命守护 |
| 3 | **渣得有魅力，不油腻** | 智商在线、布局一流、气场强；说话一针见血，行动干脆利落；不猥琐、不纠缠 |
| 4 | **有反差感** | 人前浪荡不羁，人后孤独隐忍；嘴上无所谓，关键时刻拿命扛 |
| 5 | **有道德底线** | 不杀无辜、不出卖信任自己的人、不把痛苦转嫁给弱者 |

**黄金公式**：
```
外在玩世不恭 + 内心有执念 + 对外狠辣无情 + 对内极致护短 + 底线清晰
= 读者最爱的渣男主
```

**3种爆款类型**：

| 类型 | 核心特征 | 适用题材 |
|------|---------|---------|
| **腹黑心机渣**（最稳） | 表面温和爱笑，内心算尽一切，只坑敌人护自己人到极致 | 官场/商战/权谋 |
| **狂拽不羁渣**（最吸女粉） | 玩世不恭嘴毒爱撩，不按常理出牌，大事从不含糊 | 都市/校园/赘婿 |
| **冷漠疏离渣**（最高级） | 冷淡寡言不近女色，只讲利益不谈感情，一旦动心极致深情 | 玄幻/高冷/战神 |

**4个绝对雷区**：

| 雷区 | 表现 |
|------|------|
| ❌ 不尊重女性 | 强迫、贬低、物化 |
| ❌ 坑害身边人 | 背叛恩人、出卖队友、毫无良心 |
| ❌ 又菜又爱玩 | 没实力还装逼 |
| ❌ 为渣而渣 | 没有动机、没有逻辑 |

**渣男主自检**：

- [ ] 主角的"渣"行为是否有合理动机？（不是为了渣而渣）
- [ ] 主角对"自己人"是否有明确的"护短"表现？
- [ ] 主角是否有不可触碰的"道德底线"？
- [ ] 主角是否有"反差感"？（外表vs内在/嘴上vs行动）
- [ ] 主角是否"有实力+有魅力"？不是又菜又爱装？

### 七、用剧情把主角人设"拨"出来（白特慢专项）

**核心一句话：人设不是靠"作者说"（例："他很隐忍"），而是靠"剧情逼"——用选择、冲突、代价、细节，让主角的性格、底线、执念自然暴露，读者自己"看出来"的人设才够立体。**

> 剧情是刀，人设是玉，只有用剧情反复雕刻，玉才能成器；没有剧情的打磨，人设永远是一块普通的石头。

#### 7.1 核心底层逻辑

**① 人设="绝境下的选择"**

| 状态 | 特点 | 设计启示 |
|------|------|---------|
| 顺境中看不出真假 | 主角平时温和，可能是真善良，也可能是伪装 | 日常场景不适合立人设 |
| 绝境中见本性 | 逼到"二选一"死局，他的选择就是人设 | 用二选一困境暴露最在意的东西 |

> 没有冲突的人设是纸糊的，只有被剧情反复"敲打"，人设才会立起来。

**② 避免"标签化人设"**

```
❌ 标签化写法：直接贴标签——"他隐忍、狠辣、护短"（没有剧情支撑）
✅ 剧情拨出写法：具体事件+行为细节
    例："主角被羞辱不还手，却在反派伤害亲友时瞬间暴走"
    → 读者自己总结出"隐忍+护短"，比作者说100遍都强
```

**③ 人设要"有反差、有层次"**

- 单一性格没人记："只狠不柔""只善不恶"的主角容易扁平
- 反差感才吸粉：对外人狠辣，对亲友温柔；平时玩世不恭，关键时刻拎得清；表面懦弱，实则腹黑

#### 7.2 用剧情"拨"出人设的4个核心方法

**方法一：绝境二选一——逼出主角的"核心底线"**

设计逻辑：给主角设置"两难困境"，两个选项都有代价，没有完美答案。

| 高频困境类型 | 设计示例 | 人设暴露 |
|-------------|---------|---------|
| 利益 vs 底线 | 杀无辜者就能获得无敌力量，主角选不选？ | 是否有道德底线 |
| 亲情/爱情 vs 前途 | 为救亲友放弃能改变命运的机缘 | 最在意什么 |
| 私仇 vs 大义 | 仇人就在眼前，却要为大局放他一马 | 是否有大格局 |

> 示例：反派提出"杀了队友就放你走还送功法"→ 主角宁愿受酷刑也不伤队友 → 人设：护短、重情义、有底线

**方法二：冲突升级——逼出主角的"性格强度"**

设计逻辑：让反派/环境一次次挑衅、打压，从"小冒犯"到"大伤害"，看主角反应如何升级。

```
第一层冒犯（言语羞辱/小利益掠夺）
    → 主角反应：隐忍/无视
第二层冒犯（陷害/孤立/断后路）
    → 主角反应：暗中布局/轻微反击
第三层冒犯（伤害亲友/毁其根基）
    → 主角反应：彻底爆发/鱼死网破
```

> 示例：被嘲讽"废柴"（忍）→ 被偷修炼资源（忍，默默找回）→ 亲友被重伤（暴走，废了反派但没下死手）→ 人设：隐忍、护短、有分寸

**方法三：代价交换——逼出主角的"执念与取舍"**

设计逻辑：主角想要的东西（实力、机缘、真相）必须付出"对等代价"。

| 代价类型 | 设计示例 | 人设暴露 |
|---------|---------|---------|
| **身体代价** | 折寿、断肢、修炼出岔子 | 愿意牺牲多少肉体 |
| **情感代价** | 失去爱人、亲友误解、孤独一生 | 愿意承受多少孤独 |
| **尊严代价** | 下跪、受辱、装疯卖傻 | 愿意放下多少自尊 |

> 示例：母亲重病，只有"下跪求仇人给丹药"才能救 → 放下所有尊严当众下跪，拿到丹药后默默记仇 → 人设：孝顺、隐忍、能屈能伸

**方法四：细节反差——逼出主角的"隐藏面"**

设计逻辑：在"非关键剧情"中加入与表面人设相反的细节。

| 表面人设 | 反差细节 | 人设效果 |
|---------|---------|---------|
| 狠辣冷血 | 偷偷喂流浪猫、对小孩温柔 | 外冷内热 |
| 高冷疏离 | 在亲友面前笨拙关心、偷偷准备礼物 | 有情有义 |
| 玩世不恭 | 深夜独自擦拭旧物，露出落寞眼神 | 有伤痛/有故事 |

> 示例：人人惧怕的"冷面杀手"，为保护素不相识的孤儿耽误任务被组织追杀 → 人设：不冷血、有恻隐之心

#### 7.3 不同人设的"剧情拨出"模板（直接用）

**① 隐忍腹黑型**

```
剧情设计：
1. 被反派当众羞辱，不反驳不还手，低头认怂（隐忍）
2. 反派以为主角懦弱放松警惕，主角暗中收集罪证（腹黑）
3. 最关键场合（宗门大会/朝堂），抛出所有证据，让反派身败名裂（爆发）

核心细节：主角全程表情平静，只有反派落难时眼底闪过一丝冷光
```

**② 护短疯批型**

```
剧情设计：
1. 平时温和甚至有点懦弱，被欺负也不反抗（反差）
2. 反派绑架妹妹威胁交出宝物（触发点）
3. 瞬间暴走，以命相搏，动用禁术哪怕同归于尽也要救妹妹（疯批护短）

核心细节：救回妹妹后立刻恢复温和，只说"别怕，有我"，转头对反派眼神冰冷如刀
```

**③ 玩世不恭靠谱型**

```
剧情设计：
1. 平时爱撩爱开玩笑吊儿郎当，什么都无所谓（表面）
2. 团队生死危机，队友慌作一团，主角突然收起玩笑，冷静分析局势制定计划（靠谱）
3. 危机解除后恢复玩世不恭，仿佛什么都没发生（反差）

核心细节：制定计划时手指快速敲击桌面，眼神专注，和平时的吊儿郎当判若两人
```

#### 7.4 3个避坑要点

| 避坑 | 表现 | 修复 |
|------|------|------|
| ❌ **人设前后矛盾** | 前面选择"护短"，后面却为利益牺牲亲友，无合理理由 | 任何改变都需要铺垫+触发事件 |
| ❌ **无代价的选择** | 既救了亲友又拿到机缘还没付出代价，选择失去意义 | 每个选择必须付出对等代价 |
| ❌ **用嘴说人设** | 反复强调"主角很隐忍"，却从未设计他被羞辱不还手的剧情 | 用具体事件替代旁白描述 |

#### 7.5 人设拨出万能公式

```
绝境选择（底线）+ 冲突反应（性格）+ 代价取舍（执念）+ 细节反差（层次）
= 立体人设
```

#### 7.6 人设拨出自检

- [ ] 主角的核心底线是否通过"绝境二选一"剧情展现（而非旁白说明）？
- [ ] 主角的性格强度是否通过"冲突升级"三层反应展现？
- [ ] 主角的执念是否通过"代价交换"展现（他愿意付出什么代价）？
- [ ] 主角是否有"细节反差"（表面人设vs隐藏面）？
- [ ] 是否避免了"用嘴说人设"（没有人设标签的旁白描述）？
- [ ] 主角的每次选择是否都有"对等代价"？
- [ ] 人设是否前后一致（没有无理由的转变）？
- [ ] 主角是否有至少2个性格层次（不是单一扁平）？
