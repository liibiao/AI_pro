# scene-writing-skill — 场景写作技能

## 用途
把结构与章节目标转化为具体场景——动作、对话、心理、环境、信息推进。

## 触发条件
当需要将章节计划转化为正文初稿时调用。

> **核心质量准则**：创作 ≠ 叙述。每个场景都要用具体细节和场景化设计呈现信息，而非罗列信息。详见 `baiteman-design-skill`。

## 输入
- 章节计划（核心事件、推进项、钩子）
- 角色圣经
- 前一章结尾状态

## 输出
- 章节正文草稿

---

## 方法论

### 一、场景微结构

每个场景按以下五拍推进：

```
1. 场景进入（建立空间+角色状态）
2. 冲突触发（打破平衡）
3. 信息推进（新信息/新变化）
4. 情绪升级（压力加大或情感加深）
5. 段尾钩子（制造继续读的动力）
```

### 二、场景进入技巧

#### 快进入（推荐）
直接从动作或对话开始，不做环境铺垫：
> "把东西放下，滚出去。"

#### 氛围进入
用一两句环境描写建立情绪基调：
> 雨打在铁皮屋顶上，声音像密集的鼓点。她站在门口，手里的伞已经合上了。

#### 禁止的进入方式
- 大段环境描写后才出现人物
- 用旁白交代"上一章发生了什么"
- 角色内心独白超过 3 行才进入行动

### 三、动作写作规范

#### 核心原则：用动作代替解释（创作≠叙述）
- ❌ "他很愤怒。"（叙述——直白告知）
- ✅ "他一拳砸在桌上，杯子弹起来，咖啡洒了一桌。"（创作——细节呈现）

**创作设计四步法**（适用于场景中任何信息传达）：
1. 明确目标：这段要让读者感受到什么？
2. 设计载体：用什么具体动作/道具/场景承载？
3. 加入冲突：怎么让画面"活"起来？
4. 让读者自己悟：不直说，用细节暗示。

> 完整方法论见 `baiteman-design-skill`（白特慢创作设计技能）。

#### 动作层次
1. **大动作**：影响剧情走向的行为（出手、逃跑、告白）
2. **微动作**：揭示心理状态的细节（攥拳、咬唇、移开目光）
3. **环境互动**：角色与空间的关系（靠墙、踢石子、摸口袋）

### 四、对话写作规范

#### 好对话的标准
1. 有冲突或信息量（不是废话）
2. 有潜台词（说的不是想的）
3. 有个性（遮住名字能猜出是谁）
4. 推动剧情（对话结束后情况发生了变化）

#### 对话节奏
- 冲突对话：短句、快切、少动作描写
- 信息对话：穿插动作和反应，避免"问答模式"
- 情感对话：留白多、动作多、台词少

#### 对话禁忌
- 两人以上的长对话没有动作穿插
- 角色说出不符合身份的话
- 用对话代替旁白做世界观介绍

### 五、信息管控（白特慢看稿重点）

#### 5.1 信息释放的核心原则

**信息释放 = 在读者"需要知道"的时刻，用"正在发生的事"自然带出信息，而非作者主动告知。**

> 基础节奏：每章只释放 1-2 个新信息点；重要信息分 2-3 次释放；释放后必须有角色反应。

#### 5.2 信息释放的四种方式

| 方式 | 适用场景 | 示例 |
|------|---------|------|
| **事件触发** | 世界观规则、能力设定 | 不说"他能看到等级"，写"他看了一眼对方头顶，瞳孔微缩—— lv.35" |
| **对话透露** | 关系、背景、势力格局 | 不说"他师傅死了"，写"别人问起师傅，他沉默了很久，端起酒杯一饮而尽" |
| **环境暗示** | 世界观细节、社会阶层 | 不说"这个城市阶级森严"，写"街道中央的青石板路光可鉴人，两旁的小巷却满是泥泞" |
| **行为展现** | 角色能力、性格、身份 | 不说"他是锦衣卫"，写"他进门先扫过所有出口，喝茶只抿一口" |

#### 5.3 信息释放的时机控制

| 时机 | 说明 | 示例 |
|------|------|------|
| **读者好奇时** | 先制造疑问，再释放信息 | 先写"所有人见了那块令牌都变了脸色"，再逐步揭示令牌来历 |
| **角色需要时** | 信息在剧情中真正被需要时才释放 | 主角要参加比赛，此时才介绍比赛规则（不是3章前就介绍） |
| **冲突升级时** | 新信息打破当前平衡 | 正面打不过→发现敌人有个弱点（新信息）→反转 |
| **情感爆发时** | 关键信息在情感高潮点揭示 | "他终于知道，当年那个救他的人，就是一直在暗中追杀他的那个" |

#### 5.4 信息释放的禁忌（新人常见错误）

| 禁忌 | 表现 | 正确做法 |
|------|------|---------|
| ❌ 开篇信息倾销 | 第一章就介绍世界观/体系/势力 | 开篇只释放与当前场景直接相关的信息 |
| ❌ 旁白式告知 | 作者跳出来说"读者请注意，接下来要介绍……" | 用角色的视角和行动带出信息 |
| ❌ 提前剧透 | 还没到悬念揭示的时候就把真相说了 | 控制信息释放节奏，制造信息差 |
| ❌ 无反应的信息 | 释放了重要信息但角色毫无反应 | 信息释放后立即写角色的行为/情绪变化 |
| ❌ 重复交代 | 同一个信息在不同章节反复解释 | 释放一次就够，后面通过角色行为暗示读者已理解 |

#### 5.5 信息释放自检

- [ ] 这段信息是否在"读者需要知道"的时刻释放？（不是作者想说就说）
- [ ] 信息是否通过"正在发生的事"带出？（不是旁白告知）
- [ ] 释放后角色是否有反应？
- [ ] 这一章释放的新信息是否超过 2 个？
- [ ] 删掉这段信息释放后，当前场景是否还能理解？（如果删掉也不影响，说明释放时机太早）

### 六、主角动机（白特慢看稿重点）

#### 6.1 为什么必须写主角动机？

**没有动机的主角 = 没有灵魂的提线木偶 = 读者无法代入 = 剧情没有推动力。**

| 维度 | 有动机 | 没有动机 |
|------|--------|---------|
| 读者代入 | 读者理解他为什么这么做，能共情 | 读者不理解主角在干什么，失去兴趣 |
| 剧情推动 | 主角的欲望驱动事件发生 | 事件随机发生，主角被动应对 |
| 角色立体感 | 有弱点、有执念、有矛盾 | 扁平化，工具人 |
| 冲突来源 | 动机之间的矛盾产生冲突 | 冲突只能靠外部事件推动 |

#### 6.2 动机的层次设计

| 层次 | 持续时间 | 特征 | 示例 |
|------|---------|------|------|
| **即时动机** | 当前场景/章节 | 具体的、眼前的 | "我要在三天内炼出这把剑" |
| **短期动机** | 当前卷/当前地图 | 与当前剧情线绑定 | "我要在武馆大比中拿到前三名" |
| **中期动机** | 2-3卷 | 驱动跨地图行动 | "我要查清父亲失踪的真相" |
| **长期动机** | 全书 | 主角的终极追求 | "我要成为这个世界的最强者" |

**关键规则**：**每时每刻，主角都必须有一个明确的即时动机在驱动他当前的行动。**

如果读者看完一段剧情后问"他为什么要做这件事？"而答不上来，就说明动机缺失。

#### 6.3 动机的呈现方式

| 呈现方式 | 说明 | 示例 |
|---------|------|------|
| **直接表述** | 角色内心独白或对话说出（适用关键时刻） | "我要活下去。不管付出什么代价。" |
| **行为暗示** | 通过角色的行动展现动机（更推荐） | 他明知危险还走进那个洞穴——因为他必须找到解药 |
| **他人点破** | 配角指出主角的执念 | "你就是放不下那件事，对吧？" |
| **代价展示** | 主角为动机付出了什么 | 他为了买那本功法，把唯一的房子也卖了 |

#### 6.4 动机与冲突的关系

**好的冲突 = 主角的动机被阻碍**

```
主角想要X（动机）
    ↓
但是Y阻碍了他（外部阻碍）
    ↓
而且他自己的另一个动机Z与X矛盾（内部阻碍）
    ↓
冲突 = 外部阻碍 + 内部矛盾
```

示例：
- 动机A：想要保护妹妹（情感动机）
- 动机B：想要变强去参加比赛（成长动机）
- 外部阻碍：比赛对手是他妹妹的仇人
- 冲突：参加比赛意味着和妹妹的仇人合作（A vs B）

#### 6.5 新人常见动机问题

| 问题 | 表现 | 修复方法 |
|------|------|---------|
| 动机缺失 | 主角行动没有理由，"莫名其妙就去了" | 每个场景开始前确认"主角为什么做这件事" |
| 动机模糊 | "他想要变强"——变强是为了什么？ | 给动机一个具体的、可感知的目标 |
| 动机不一致 | 前面说想报仇，后面完全忘了 | 用动机追踪表管理 |
| 动机太被动 | 主角只在别人要求时才行动 | 让主角主动做出选择（哪怕选错了） |
| 只有长期动机 | 全书只有一个大目标，短期没有抓手 | 长期动机拆解为多个短期子目标 |

### 七、场景自检

每个场景写完后问：
1. 这个场景删掉，故事会损失什么？
2. 场景结束时，情况是否发生了变化？
3. 读者读完这个场景，会产生什么情绪或问题？
4. 主角在这个场景中是否有明确的即时动机？（他为什么做这件事？）
5. 这一章释放的新信息是否≤2个？释放时机是否合理？
6. 信息释放后角色是否有反应？
