# zhouzi-style-skill — 肘子文风技能

## 用途
建立"肘子文风"体系——以起点白金作者会说话的肘子（《大王饶命》《第一序列》《夜的命名术》）创作经验为核心提炼的文风方法论，覆盖**开篇注意力争夺、题材选择、开局类型、结构精简**等全维度。
同时整合起点金牌编辑星河的**新人题材实操指南**。

## 触发条件
- P0 选题阶段判断题材可行性和切口
- P1 立项阶段确定开篇策略
- P4 正文生产阶段写第一章（黄金一句）
- 任何需要"怎么在第一句话就抓住读者"的时刻

## 输入
- 目标平台与题材
- `project.json` 的 `style_profile`
- 核心卖点与目标读者

## 输出
- 开篇策略文档
- 黄金一句（第一章第一句话）
- 题材切口定位

## 方法论

### 一、黄金一句 ＞ 黄金三章

> 肘子核心观点：传统"黄金三章"已经不够用了。现在读者耐心极低，**第一句话就要抓注意力**，否则三章再精致也没用。

#### 1.1 为什么黄金一句比黄金三章更重要？

| 现实 | 数据 |
|------|------|
| 读者平均试读时长 | < 30秒 |
| 读者决定弃书的页面 | 第1-3屏（约300-800字） |
| 推荐/广告导入的读者耐心 | 几乎为0 |

**结论**：如果第一句不能让读者产生"等等，这是什么？"的念头，后面三章写得再好也白搭。

#### 1.2 黄金一句的标准

**好的第一句话 = 制造认知落差**

| 类型 | 原理 | 示例 |
|------|------|------|
| **反常识** | 打破读者预期，制造"等等？" | "死去三年的妻子，今天早上给我发了一条微信。" |
| **悬念型** | 抛出未解之谜 | "他杀了人，但警方判定为自杀——因为他用的是一把不存在的刀。" |
| **冲突直给** | 一上来就在冲突中 | "把东西放下，滚出去。" |
| **情绪钩子** | 直接触发情绪 | "签了这份协议，你就不是我们家的人了。" |
| **信息差** | 读者知道角色不知道的 | "所有人都不知道，这座城市的地下三层，住着另一个文明。" |

#### 1.3 黄金一句的禁忌

| 禁忌 | 错误示例 | 为什么错 |
|------|----------|---------|
| ❌ 世界观介绍 | "在灵气复苏的第137年……" | 读者不关心设定，关心"关我什么事" |
| ❌ 环境描写 | "清晨的阳光透过窗帘洒在书桌上……" | 没有人物、没有冲突、没有钩子 |
| ❌ 心理独白 | "他一直觉得自己的人生太平淡了……" | 读者没有理由关心这个人的心理 |
| ❌ 旁白铺垫 | "故事要从那个夏天说起……" | 浪费读者耐心 |
| ❌ 设定说明 | "在异世界，每个人都有一项天赋能力……" | 信息倾销，读者没有代入感 |

#### 1.4 黄金一句 → 黄金三段的进阶

从第一句到第一段（300-800字），层层递进：

```
第1句：制造认知落差（钩子）
  ↓
第1段：建立主角处境（他是谁？遇到了什么？）
  ↓
前300字：亮核心冲突（他要面对什么？）
  ↓
前800字：亮金手指/核心看点（这本书能让我爽什么？）
```

> 与 `topic-scoring-skill` §四"黄金三章兑现"互补：小郎君/白特慢标准是"三章兑现爽点"，肘子标准是"一句抓注意力+300字亮冲突+800字亮看点"——肘子的标准更严格，是黄金三章的升级版。

#### 1.5 纯武力流已过时：情绪先行

> 肘子核心判断：传统玄幻靠**武力碾压**的写法越来越不吃香，读者现在更看重**情绪、人设、关系、反差**。

| 过时做法 | 现在做法 |
|---------|---------|
| 全程打打杀杀、升级碾压 | 先有**情感/情绪钩子**，再叠加能力 |
| 武力值决定一切 | 反差、性格、关系网才是主角的魅力来源 |
| 战斗描写占大头 | 战斗服务于情绪转折，不独立存在 |

**核心逻辑**：读者追的不是"谁打得过谁"，而是"这个角色让我爽/让我哭/让我笑"。情绪永远是第一生产力。

#### 1.6 黄金一句自检

- [ ] 第一句话是否制造了认知落差？（读者会"等等？"）
- [ ] 第一句话是否包含人物或冲突？（不是纯设定/纯环境）
- [ ] 读者看完第一句话后，是否有理由继续读第二句？
- [ ] 前300字是否亮出了核心冲突？
- [ ] 前800字是否亮出了金手指/核心看点？

### 二、小众切口 + 大众情绪

> 肘子选题哲学：不追空泛大热，用**小众身份/场景**切入**大众情绪共鸣**。

#### 2.1 核心公式

```
小众切口（降低竞争、提高辨识度） + 大众情绪（保证读者基数）
```

| 错误做法 | 正确做法 |
|---------|---------|
| 写"都市异能"（太大、太泛） | 写"小区物业夜班值班员发现业主名单上的人正在一个一个消失" |
| 写"重生文"（红海内卷） | 写"重生回高考前一天，但只保留了三天的记忆" |
| 写"系统流"（同质化严重） | 写"系统每天随机给我一个任务，完不成就死" |

#### 2.2 小众切口的三种来源

| 来源 | 示例 |
|------|------|
| **特殊职业/身份** | 验尸官、物业夜班、入殓师、外卖骑手、建筑工人 |
| **特殊场景/空间** | 高速公路服务区、医院太平间、烂尾楼、城中村 |
| **限制条件** | 只能活三天/只能说真话/每天失去一段记忆/不能离开某座城 |

#### 2.3 大众情绪的四种类型

| 情绪类型 | 读者心理 | 适用题材 |
|---------|---------|---------|
| **逆袭/打脸** | "被人看不起，我偏要证明给你看" | 赘婿/废柴/重生 |
| **好奇/悬念** | "这到底是怎么回事？我要知道真相" | 悬疑/推理/灵异 |
| **共鸣/代入** | "这不就是我的生活吗？" | 都市日常/年代文/职场 |
| **爽感/释放** | "太解气了！就是这样！" | 系统流/无敌流/碾压 |

#### 2.4 题材选择判断

| 题材类型 | 肘子建议 | 原因 |
|---------|---------|------|
| 都市脑洞 | ✅ 新人优先 | 门槛低、受众广、创意空间大 |
| 文娱/电竞 | ✅ 新人优先 | 易蹭热点、节奏好控制 |
| 轻同人 | ✅ 新人优先 | 自带受众、世界观可借用 |
| 小众历史 | ✅ 可尝试 | 替代性低、铁粉多 |
| 硬科幻 | ⚠️ 慎选 | 专业门槛高、读者基数小 |
| 纯灵异 | ⚠️ 慎选 | 头部垄断、新人难出头 |
| 高武 | ⚠️ 慎选 | 内卷严重、同质化 |
| 复杂西幻 | ⚠️ 慎选 | 世界观构建成本高 |

> 与 `market-research-skill` §六"白特慢选题三步法"互补：白特慢侧重"查榜单→拆对标→找切口"的方法论流程，肘子侧重"小众切口+大众情绪"的选题哲学——两者可组合使用。

### 三、题材×金手指×人设：三位一体

#### 3.1 三者必须统一体系

```
题材决定：世界观范围、爽点类型、读者期待
金手指决定：主角的核心差异化优势
人设决定：主角的社会位置、性格、行为方式

三者交汇 = 这本书最独特的卖点
```

**绑定检验**：
- 金手指是否**服务题材**？（金手指的功能要与题材的核心玩法一致）
- 金手指是否**制造冲突**？（金手指要有使用代价/限制/副作用）
- 金手指是否**强化人设**？（金手指的使用方式要体现主角性格）

#### 3.2 主角唯一性原则 + 单主线

> 肘子结构原则：主角必须是**特定环境里独一无二**的存在。用反差、特殊性格/能力立住人设。**开篇只立一个主角**，无关配角全删，降低读者记忆成本。

| 原则 | 原因 |
|------|------|
| 主角唯一性 | 主角在所处环境里必须是"最特殊的那个人"，不是路人脸 |
| 单主线 | 多主线 = 读者记忆成本翻倍 = 追读率下降 |
| 少人物 | 每增加一个重要角色，读者就要记住一层关系 |
| 支线控制 | 支线 ≤ 2条，且必须与主线有明确的交织点 |
| 配角功能化 | 每个配角必须有**唯一的戏剧功能**（镜像/催化/信息/情感锚/工具），不养闲角 |

> 与 `plot-loop-skill` §1 三要素锁定互补：白特慢强调三者的"一致性检验"，肘子强调三者的"绑定检验"（金手指服务题材+制造冲突+强化人设）。

### 四、有效开局类型

#### 4.1 极简开篇四要素（编辑+作者双认证）

> 肘子 × 星河共识：开篇必须同时满足以下四个要素，缺一不可。

| 要素 | 要求 | 错误做法 |
|------|------|---------|
| **一句话钩子** | 第一句必须有悬念/冲突/反差，制造认知落差 | 环境描写、世界观介绍、旁白铺垫 |
| **一个主角** | 困境/目标清晰，读者立刻知道"这是谁、他怎么了" | 多人物同屏、群像式开篇、配角抢戏 |
| **一条主线** | 能用一句话说清"这本书讲什么"，不跑偏、不杂线 | 多线并行、信息分散、读者不知道主线是什么 |
| **章尾留悬** | 每章结尾制造"必须点下一章"的紧迫感 | 章末总结、情绪落定、自然段落结束 |

#### 4.2 前两章核心任务

> 星河核心观点：**前两章立住一个人物，读者就会接受你的世界，愿意继续看。**

**前两章只做一件事：让读者记住并喜欢上主角。**

| 任务 | 具体要求 |
|------|---------|
| 立住人物 | 通过行动和对话展示主角性格、处境、目标 |
| 建立共情 | 让读者对主角产生"代入感"或"同情/好奇" |
| 给出钩子 | 制造悬念或危机，驱动读者翻页 |

**前两章坚决不做的事**：
- ❌ 慢热铺垫（"先写日常生活再引入主线"）
- ❌ 设定堆砌（世界观/体系/势力/历史等）
- ❌ 人物扎堆（前两章出场角色 ≤ 3个核心）
- ❌ 无意义抒情（主角的哲学思考、诗意描写）

#### 4.3 四种高留存开局

| 类型 | 核心机制 | 适用题材 | 示例 |
|------|---------|---------|------|
| **悬疑开局** | 抛出未解之谜 | 悬疑/推理/灵异 | "死去的同事今天给我发了工资条。" |
| **惊悚开局** | 直接制造恐惧/危险 | 恐怖/末世/高武 | "他低头一看，自己的影子不见了。" |
| **情感/暧昧开局** | 直接触发情感反应 | 都市/言情/校园 | "她说'我们分手吧'的时候，正在给我盛饭。" |
| **冲突直给开局** | 一上来就在冲突中 | 爽文/打脸/复仇 | "签了这份协议，你爸的债一笔勾销——代价是你妹妹。" |

**共同点**：**第一时间抓注意力**，不铺垫、不解释、不犹豫。

#### 4.4 开局的唯一任务

开篇只做两件事：
1. **立主角人设**：用行动和对话让读者快速了解"这是个什么样的人"
2. **给钩子**：给读者一个继续读下去的理由

**开篇不做的事**：
- ❌ 不堆设定（世界观/体系/势力等）
- ❌ 不铺环境（大段环境描写）
- ❌ 不灌鸡汤（主角的哲学思考）
- ❌ 不讲背景（主角的身世介绍）
- ❌ 不慢热铺垫（先写日常再引主线）
- ❌ 不人物扎堆（前3章出场角色 ≤ 3核心+2工具人）
- ❌ 不无意义抒情（与主线无关的情绪/诗意描写）
- ❌ 不秀文笔（商业文：情绪 ＞ 文笔）

### 五、编辑星河选题实操指南

> 来源：起点金牌编辑星河连麦补充。

#### 5.1 三步定题材

1. **明确故事**：用一句话说清——主角身份、开局危机、金手指、核心矛盾
2. **扫榜对标**：看同题材成绩、爽点、节奏，找差异化
3. **切口要小**：
   - 大众题材 → 做**小众身份/场景**（如都市→物业夜班）
   - 冷门题材 → 做**强情绪+快节奏**（如历史→穿越后第一天就要被砍头）

#### 5.2 新人推荐题材优先级

| 优先级 | 题材 | 优势 |
|--------|------|------|
| ★★★ | 非冷门同人 | 低门槛、自带受众、世界观可借用 |
| ★★★ | 都市脑洞（重生/年代/日常/创业） | 受众广、创意空间大、生活代入感强 |
| ★★★ | 文娱/电竞 | 易蹭热点、节奏好控制、对话趣味高 |
| ★★☆ | 小众历史 | 替代性低、铁粉多、但需要一定历史功底 |
| ★☆☆ | 硬科幻/纯灵异/高武/复杂西幻 | 头部垄断、新人难出头 |

#### 5.3 编辑审稿核心三看

> 星河签约标准：**第一句不行直接Pass，不看第二章反转。**

| 审稿维度 | 看什么 | 红线 |
|---------|--------|------|
| **看钩子** | 是否第一时间抓住人？第一句/第一段是否有认知落差？ | 第一句不吸引人 = 直接Pass |
| **看人物** | 主角是否立得住？有没有记忆点？ | 主角模糊/无辨识度 = 继续观察 |
| **看节奏** | 是否拖沓？有无多余信息？ | 前3000字还在铺垫 = Pass |

#### 5.4 新人三不原则

> 星河核心忠告：大神的写法逻辑和新人完全不同，**照搬必扑**。

| 原则 | 解释 | 反面教材 |
|------|------|---------|
| **别模仿白金写法** | 白金作者有读者基础，可以慢热开局；新人没有这层信任，必须第一句就抓人 | 学某大神开篇写3000字世界观介绍 |
| **别秀文笔** | 商业文**先留住人，再讲故事**，情绪 ＞ 文笔 | 大段修辞、排比、诗意描写 |
| **别多线并行** | 单主线才是新人最优解，多线 = 读者记忆成本翻倍 | 同时展开3条以上线索 |

#### 5.5 开书避雷清单

- [ ] 开篇是否在堆设定？（应改为通过事件带出设定）
- [ ] 节奏是否拖沓？（开篇前300字必须有冲突）
- [ ] 人物是否杂乱？（前3章出场角色 ≤ 3个核心+2个工具人）
- [ ] 金手指是否悬浮？（金手指必须与题材和人设绑定）
- [ ] 主线是否清晰？（能用一句话说清"这本书讲什么"）

### 六、长篇稳定爆款逻辑

#### 6.1 节奏公式

```
小危机 → 解决 → 小爽点 → 新钩子 → 小危机 → ……
```

这是支撑长篇不崩的核心循环。每一轮循环完成两个任务：
1. **解决当前危机** → 产出爽点（满足读者情绪）
2. **制造新钩子** → 驱动下一轮阅读（维持追读动力）

| 循环频率 | 建议 | 说明 |
|---------|------|------|
| 每章 | 1个完整小循环 | 读者每次阅读都有收获 |
| 每3-5章 | 1个中循环（阶段性目标达成） | 产出中等级别的爽感 |
| 每10-20章 | 1个大循环（阶段性高潮） | 产出高强度爽感，作为留存锚点 |

#### 6.2 更新与人设

> 肘子长篇经验：**稳定更新 + 鲜明人设 + 持续爽点 = 长期留存关键**。

| 要素 | 具体做法 |
|------|---------|
| 稳定更新 | 日更4000-6000字，不断更，建立读者阅读习惯 |
| 鲜明人设 | 主角的性格标签贯穿全书，不崩、不漂移 |
| 持续爽点 | 每轮节奏循环都必须产出爽点，不允许"纯过渡章节" |

#### 6.3 核心认知：网文是情绪商品

> 肘子终极判断：**网文是情绪商品，先满足读者情绪，再谈创作表达。**

| 认知层级 | 说明 |
|---------|------|
| 第一层 | 读者追的是"让我爽/让我哭/让我笑"的情绪体验 |
| 第二层 | 所有技巧（节奏、钩子、人设、开篇）都是为情绪服务的工具 |
| 第三层 | 创作表达可以融入，但**不能凌驾于读者情绪需求之上** |

> 与 `plot-loop-skill` 互补：白特慢的节奏循环侧重"小循环→中循环→大循环"的三级结构，肘子的节奏循环侧重"危机→解决→爽点→新钩子"的四步公式——两者可组合使用。

### 七、落地公式

```
题材小切口 + 独特金手指 + 鲜明人设 + 黄金一句开局 + 单主线 + 少人物 = 高留存开篇
```

| 要素 | 标准 | 自检 |
|------|------|------|
| 题材小切口 | 小众身份/场景/限制条件 + 大众情绪共鸣 | 切口能用一句话说清？ |
| 独特金手指 | 紧扣题材、有代价、强化人设 | 金手指有使用限制吗？ |
| 鲜明人设 | 核心标签鲜明、行为符合身份 | 遮住名字能猜出是谁？ |
| 黄金一句开局 | 第一句制造认知落差 | 读者会"等等？"吗？ |
| 单主线 | 能用一句话说清全书主线 | 支线有明确的交织点？ |
| 少人物 | 前3章核心角色 ≤ 3个 | 每个角色都有戏剧功能？ |

### 八、肘子文风特征

> 以下特征基于肘子公开作品的风格提炼，供 Style-Master 在文风定调时参考。

| 特征 | 描述 | 示例 |
|------|------|------|
| **幽默对白** | 大量吐槽、互怼、梗密集 | 大王饶命的吕树vs吕小鱼日常互怼 |
| **情绪切换** | 幽默→燃→催泪的快速切换 | 前一秒还在搞笑，下一秒直接泪点 |
| **角色辨识度** | 每个角色有独特的语言和行为标签 | 吕树的"无形装逼最为致命" |
| **都市感** | 世界观贴近现实生活，读者代入感强 | 超能力融入日常城市生活 |
| **爽点节奏** | 密集、快速、不拖沓 | 几乎每章都有爽点或笑点 |
| **反套路** | 在套路中制造意外，打破读者预期 | 明明以为要打脸了，结果搞笑收场 |
