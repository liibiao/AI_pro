# book-dissection-skill — 拆书与模仿技能

## 用途
从成功网文中拆解核心梗，正确模仿并融入自己的创作，避免抄袭的同时学到精髓。

## 触发条件
- 阅读爆款/万订作品后想拆解其成功要素时
- 需要找到适合自己题材的核心梗时
- 想学习某本成功作品的结构/节奏/爽点设计时
- 担心自己的设定"太像某本书"需要差异化处理时

## 输入
- 目标拆解作品（书名/前30章内容）
- 自己的故事三要素（题材/金手指/主角身份）

## 输出
- 拆解报告（核心梗/结构/爽点/节奏）
- 适合自己的模仿方案（不是照搬）

---

## 方法论

### 一、什么是"核心梗"？

**核心梗 = 读者因为这一个点就愿意追下去的核心吸引力。**

| 核心梗层级 | 说明 | 示例 |
|-----------|------|------|
| **一句话梗** | 一句话能说清的最独特卖点 | "我能看到别人的寿命剩余天数" |
| **爽点模式** | 读者反复获得爽感的核心机制 | 每次预知死亡后救人→获得信任+资源→更多预知机会 |
| **情绪钩子** | 读者持续追读的情绪驱动力 | "他到底能不能改变命运？" |
| **记忆符号** | 读者提到这本书就想到的东西 | 倒计时数字/面板面板/签到系统 |

**关键：核心梗不是"这本书讲了什么故事"，而是"读者为什么觉得这本书好看"。**

**核心梗的万能公式——任何爆款梗都能拆成4个固定模块：**

```
前置压抑 → 触发条件 → 反转爆发 → 结果爽感
（被轻视） （事件/挑衅） （亮出底牌） （打脸+震惊+收益）
```

> 模仿的是这个**结构**，不是内容。情绪曲线一模一样，就是成功模仿；内容一字不一样，就是成功原创。

#### 1.1 不能抄 vs 必须学（安全底线）

| 绝对不能抄（抄袭） | 必须模仿（核心梗） |
|-------------------|-------------------|
| 情节顺序、场景细节 | 爽点逻辑、冲突结构 |
| 人名地名、对话原文 | 反转模式、情绪路径 |
| 设定原文、桥段照搬 | 套路公式、节奏模式 |

> **网文可以"套路共享"，但不能"内容照搬"。**

### 二、拆书的六维拆解法

> 白特慢核心原则：拆书不是抄情节，而是**拆结构、拆逻辑、拆爽点、拆循环**，把别人的成功变成自己的写作模板。

#### 第一层：拆题材定位与核心梗（最重要）

| 拆解维度 | 问自己 | 记录 |
|---------|--------|------|
| 这本书的"一句话梗"是什么？ | 如果你只能用一句话向别人推荐这本书，你会说什么？ | ___ |
| **核心情绪是什么？** | 读者追这本书是为了获得什么情绪体验？（爽/笑/哭/紧张/好奇） | ___ |
| **受众是谁？** | 这本书吸引的是哪类读者？年龄段？阅读偏好？ | ___ |
| **爽点偏向哪一类？** | 打脸/升级/收集/养成/推理/情感？ | ___ |
| 这个梗的前提条件是什么？ | 这个梗需要什么设定支撑才能成立？ | ___ |
| 这个梗的限制是什么？ | 作者给这个梗设了什么边界？ | ___ |
| 这个梗还能怎么用？ | 如果换一个题材/身份，这个梗还能成立吗？ | ___ |

#### 第二层：拆结构

| 拆解维度 | 问自己 | 记录 |
|---------|--------|------|
| 前10章的结构是什么？ | 金手指何时出现？第一个循环什么时候完成？ | ___ |
| 剧情循环的模式是什么？ | 每个循环的基本流程是什么？（进入→冲突→破局→收益） | ___ |
| 地图切换的节奏是什么？ | 多少章换一次地图？换地图的触发条件是什么？ | ___ |
| 爽点的分布密度？ | 平均多少章一个大爽点？小爽点的间距是多少？ | ___ |
| 钩子怎么挂？ | 章节结尾常用的钩子类型是什么？ | ___ |

**开局黄金三章评估**：

| 维度 | 评估标准 | 记录 |
|------|---------|------|
| **快** | 第1句是否 hook 读者？前300字是否亮冲突？前800字是否亮看点？ | ___ |
| **准** | 第1章是否立住主角？金手指是否在第1-3章内出现？ | ___ |
| **狠** | 第1-3章是否有足够强的压抑/冲突让读者"停不下来"？ | ___ |

> 与 `zhouzi-style-skill` §一"黄金一句＞黄金三章"互补：肘子标准更严格（第一句就要抓人），白特慢标准聚焦黄金三章的整体评估——两者组合使用。

**三级循环拆解**：

| 循环层级 | 分析要点 | 记录 |
|---------|---------|------|
| **小循环**（每章） | 冲突→解决→收获→新冲突，每章的起伏点在哪？ | ___ |
| **中循环**（3-10章） | 地图/阶段升级，阶段性目标何时达成？中等级别爽感在哪？ | ___ |
| **大循环**（10-30章） | 主线推进+伏笔回收，大的情绪高潮在哪？ | ___ |

> 与 `plot-loop-skill` §三剧情循环模式互补：plot-loop-skill 提供"怎么写循环"的方法论，本节提供"怎么拆别人的循环"的分析框架。

#### 第三层：拆节奏

| 拆解维度 | 问自己 | 记录 |
|---------|--------|------|
| 快慢节奏怎么切换？ | 战斗/日常/情感段的字数比例是多少？ | ___ |
| 信息释放的节奏？ | 新设定/新角色/新势力多久出现一次？ | ___ |
| 对话和描写的比例？ | 偏对话驱动还是偏描写驱动？ | ___ |
| 每章结尾的节奏？ | 章末通常是快（悬念）还是慢（余韵）？ | ___ |

#### 第四层：拆人设

| 拆解维度 | 问自己 | 记录 |
|---------|--------|------|
| 主角的核心标签是什么？ | 用3个词形容主角 | ___ |
| 主角的性格如何推动剧情？ | 主角的什么性格特质导致了关键冲突？ | ___ |
| 配角的功能是什么？ | 每个主要配角承担什么角色功能？（**助攻/施压/制造冲突/信息源/情感锚**） | ___ |
| 反派的特点是什么？ | 反派的威胁感来自哪里？压制力如何层层升级？ | ___ |

#### 第五层：拆金手指设计

| 拆解维度 | 问自己 | 记录 |
|---------|--------|------|
| 金手指如何与题材绑定？ | 金手指的功能是否服务于题材的核心玩法？ | ___ |
| 金手指有什么限制？ | 冷却时间？使用代价？规则约束？副作用？ | ___ |
| 金手指如何驱动剧情？ | 金手指是被动触发还是主动使用？如何**制造新冲突**而非消灭冲突？ | ___ |
| 金手指的成长路径？ | 是固定不变还是可升级？升级方式是什么？ | ___ |

> 金手指设计核心原则：**金手指必须制造冲突，而非消灭冲突。** 如果金手指让所有问题都轻松解决，故事就崩了。
>
> 与 `plot-loop-skill` §二金手指设计法互补：plot-loop-skill 提供"怎么设计金手指"的方法论，本节提供"怎么拆别人的金手指设计"的分析框架。

#### 第六层：拆信息投放

| 拆解维度 | 问自己 | 记录 |
|---------|--------|------|
| 世界观信息何时投放？ | 前N章投放了多少设定？是否通过事件自然带出？ | ___ |
| 设定投放的节奏？ | 是集中灌输还是随剧情分散释放？ | ___ |
| 读者先关心什么？ | 读者是先关心主角命运，还是先关心世界观设定？ | ___ |
| 信息优先级？ | 哪些信息先给？哪些后给？哪些留悬念？ | ___ |

> 白特慢核心原则：**读者先关心主角，再关心世界。** 世界观只给必要的，设定随剧情丢，不集中灌输。

#### 补充维度：拆情绪设计

| 情绪模式 | 分析要点 | 记录 |
|---------|---------|------|
| **压抑→释放** | 压抑了多久？压抑多深？释放方式是什么？（打脸/翻盘/获得认可） | ___ |
| **期待→兑现** | 建立了什么期待？兑现了没有？兑现是否超出预期？ | ___ |
| **委屈→打脸** | 委屈的铺垫够不够？（被谁/被什么轻视？）打脸的力度够不够？ | ___ |
| **绝望→翻盘** | 绝境够绝吗？（断粮/受伤/被背叛？）翻盘够爽吗？ | ___ |

> 与 `description-skill` §八"情绪极致拉满技法"互补：本节是"拆别人怎么设计情绪"，§八是"自己怎么写出极致情绪"。

### 三、正确模仿的核心原则

#### 3.1 模仿 ≠ 抄袭

| 抄袭 | 正确模仿 |
|------|---------|
| 照搬核心梗 | 学习核心梗的设计逻辑 |
| 复制金手指设定 | 用相同的设计逻辑创造不同的金手指 |
| 套用剧情线 | 学习剧情循环的结构，写不同的剧情 |
| 模仿文风 | 学习节奏控制的方法，用自己风格表达 |
| 抄袭人设 | 学习人设如何与金手指配合，创造不同人设 |

**一句话：模仿"为什么好看"，不模仿"写了什么"。**

#### 3.2 模仿的三个层次

| 层次 | 做什么 | 难度 | 效果 |
|------|--------|------|------|
| **表层模仿** | 模仿设定/金手指/人设 | 低 | 差（容易被看出来，缺乏新意） |
| **结构模仿** | 模仿结构/节奏/循环模式 | 中 | 好（结构正确，但内容不同） |
| **逻辑模仿** | 模仿"为什么这样设计"的底层逻辑 | 高 | 最好（学到了精髓，完全原创） |

**目标：至少做到结构模仿，追求逻辑模仿。**

#### 3.3 换壳四步法（快速上手版）

```
换世界观：都市梗 → 玄幻/末世/古代/西幻/修仙
换主角身份：赘婿 → 弃子/学徒/卧底/废柴/囚犯
换金手指：系统 → 神医/战神/传承/透视/炼器
换冲突场景：宴会厅 → 拍卖会/宗门大比/考场/战场
```

> 只要换2项以上，就是你的原创梗。

**完整示范**：
```
原梗：赘婿被羞辱 → 当众亮身份打脸
├── 换世界观：西幻
├── 换身份：落魄铁匠学徒
├── 换金手指：神级锻造传承
├── 换场景：骑士团装备验收会
└── 保留结构：被轻视→被嘲讽→锻造神级装备→全场震惊
结果：结构一样，内容完全不同，合法合规，还爽
```

#### 3.4 核心梗迁移四步法（深度版）

这是将别人的核心梗"迁移"到自己作品中的深度实操方法：

```
第一步：提取核心逻辑（不是提取表面设定）
├── 问：这个梗的本质是什么？（信息差？收集癖？养成感？逆袭？）
├── 问：读者爽感的核心机制是什么？
└── 记录：用抽象语言描述梗的运行逻辑

第二步：更换承载载体
├── 问：同样的逻辑，换一个题材能成立吗？
├── 问：换一个金手指类型能成立吗？
├── 问：换一个主角身份能成立吗？
└── 尝试：用不同的"三要素"承载同样的"梗逻辑"

第三步：制造差异化
├── 至少改变 2 个维度（题材/金手指/身份/世界观/势力结构）
├── 重新设计"使绊子"链条
└── 确保核心体验不同（即使逻辑相似，读者的具体感受不同）

第四步：验证独立性
├── 不看原书，能独立写出大纲吗？
├── 别人看了你的大纲，能联想到原书吗？（不应该能）
└── 核心爽点是否足够差异化？
```

#### 3.4 核心梗迁移实例

| 原书核心梗 | 核心逻辑（提取） | 迁移方案 |
|-----------|----------------|---------|
| 签到系统（每天签到获得奖励） | **低门槛+确定性+积累感**：读者知道每天都会有收获，期待今天签到什么 | 每日修炼自动获得领悟碎片，碎片积累解锁功法——逻辑相同，载体不同 |
| 能看见好感度面板 | **信息差+社交博弈**：主角知道别人不知道的信息，据此决策 | 能看见物品的"记忆"——知道这把剑杀过谁、这块玉佩的主人经历了什么——同样的信息差逻辑，不同的应用场景 |
| 重生回到过去 | **预知+改命+遗憾弥补**：读者期待"如果重来一次会怎样" | 不是重生，而是获得"平行世界的自己的记忆碎片"——同样的信息优势，但机制不同 |
| 系统任务强制打脸 | **被动驱动+确定性爽感**：系统逼主角去做事，读者知道主角必须赢 | 不是系统任务，而是"命运之书的预言"——预言说他会做什么，他被迫去做——同样的被动驱动，载体完全不同 |

#### 3.5 拆书后落地三板斧（白特慢）

> 白特慢拆书核心原则：拆完必须落地，否则拆了白拆。

| 板斧 | 做什么 | 为什么 |
|------|--------|--------|
| **套框架不套情节** | 用别人的结构（循环模式/节奏/开局设计），装自己的设定与人设 | 结构是通用的，情节是特定的。套结构 = 学到了骨架 |
| **仿爽点不仿桥段** | 学别人的**情绪曲线**（压抑→释放、期待→兑现），不学具体事件 | 读者爽的是"情绪"，不是"事件"。同样的事件换个写法可能完全不爽 |
| **做微创新** | 在成熟模板上**改金手指/改身份/改背景**，至少改2个维度 | 换2项以上就是原创梗（§3.3 换壳四步法） |

### 四、模仿的禁忌

| 禁忌 | 说明 | 正确做法 |
|------|------|---------|
| ❌ 模仿具体设定 | 照搬别人的金手指/世界观/人设 | 只模仿"设计逻辑"，创造不同设定 |
| ❌ 模仿具体剧情 | 照搬别人的情节线和转折 | 只模仿"结构节奏"，写不同剧情 |
| ❌ 模仿具体台词 | 使用类似的台词或对话模式 | 学台词设计的技术（潜台词、冲突），内容自己写 |
| ❌ 只模仿一本书 | 只拆一本书就开写 | 至少拆3-5本同类好书，提炼共性 |
| ❌ 模仿不考虑适配性 | 看到好梗就直接套用 | 确认核心梗与自己的"三要素"兼容 |
| ❌ 不理解就模仿 | 不知道别人为什么这样设计就照搬 | 先拆解"为什么这样设计"，再决定是否模仿 |
| ❌ 抄表层不抄底层 | 只抄"被羞辱→反击"，不抄铺垫力度和反转节奏 | 同时模仿压抑强度、反转节奏、爽感释放方式 |
| ❌ 照搬场景 | 别人写宴会厅打脸你也写宴会厅 | 用换壳四步法换掉场景 |
| ❌ 只抄情节不抄爽点 | 情节一样但压抑不够、反转太快 | 确保"前置压抑"足够→反转才有冲击力 |

### 五、最简模仿公式

```
别人的核心梗 = 压抑 → 触发 → 反转 → 爽感
你的改编 = 换世界 + 换身份 + 换金手指 + 换场景 + 保留情绪曲线
```

### 六、拆书实操流程

```
第一步：选书（选3-5本同题材万订/爆款）
├── 选近期作品（规则更符合当前市场）
├── 选题材完全相同的
└── 选核心梗不同的（学习多样性）

第二步：快速通读前30章（每本2-3小时）
├── 边读边标记"爽点"出现的位置
├── 记录金手指何时出现、首秀是什么
├── 记录每个剧情循环的基本模式
└── 记录让你"停不下来"的时刻是什么

第三步：四层拆解（每本30分钟）
├── 第一层：核心梗是什么？为什么爽？
├── 第二层：结构是怎样的？
├── 第三层：节奏是怎样的？
└── 第四层：人设是怎样的？

第四步：交叉对比
├── 多本书的共同点是什么？（→ 市场验证的有效方法）
├── 每本书的独特差异是什么？（→ 可以学习的差异化方向）
└── 哪些设计我可以用？（→ 结合自己的三要素选择）

**【质量门】拆到能默写大纲才算拆透**
├── 不看原书，能用"六维拆解法"写出这本书的完整拆解报告吗？
├── 能用一句话说清这本书的核心情绪、爽点模式、循环结构吗？
└── 如果说不清 → 回到第二步重新通读，直到能说清

第五步：迁移到自己作品
├── 选择最适合自己的核心梗逻辑
├── 用"四步迁移法"改造为自己的设计
└── 验证独立性和差异化

**【行动项】拆完立刻写3000字仿写，固化思路**
├── 用拆到的结构框架 + 自己的设定/人设/金手指
├── 写一段3000字的开篇或核心章节
└── 写完后对比原书：结构相似但内容完全不同 → 成功迁移
```

### 七、拆书自检

- [ ] 我拆解的是"为什么好看"（逻辑），而不是"写了什么"（表面）？
- [ ] 我模仿的是至少2本书的共性，而不是只模仿1本书？
- [ ] 我的"核心梗"与原书至少有2个维度的差异？
- [ ] 别人看了我的设定，不会立刻联想到某本具体的书？
- [ ] 核心梗与我的"三要素"（题材/金手指/身份）是否兼容？
- [ ] 我是否拆清了这本书的**情绪设计**？（压抑→释放/期待→兑现/委屈→打脸/绝望→翻盘）
- [ ] 我是否拆清了金手指的**限制条件**和**驱动剧情方式**？
- [ ] 我是否拆清了这本书的**信息投放节奏**？（设定何时给？怎么给？）
- [ ] 不看原书，我能**默写**出这本书的六维拆解报告吗？
- [ ] 我是否做了**3000字仿写**验证迁移效果？

### 八、新人拆书建议

| 建议 | 原因 | 操作 |
|------|------|------|
| **一次只拆一本同赛道爆款** | 拆多本容易浮于表面，一本拆透胜过五本拆皮 | 选1本与你目标题材完全相同的万订/爆款，按六维拆解法逐层拆 |
| **拆到能默写大纲才算拆透** | 能默写 = 真正理解了结构，而不是"看过了觉得好" | 拆完后合上书，用六维框架写出拆解报告，写不出就回去重看 |
| **拆完立刻写3000字仿写** | 理解≠能写，仿写才是真正的内化 | 用拆到的结构 + 自己的设定，写一段开篇或核心章节 |
| **至少拆3本再开书** | 单本有偶然性，3本以上的共性才是市场验证的有效方法 | 第一本拆透 → 第二本拆透 → 第三本拆透 → 交叉对比 → 提炼共性 → 开始自己的创作 |

### 九、与其他 Skill 的协作关系

| Skill | 协作方式 |
|-------|---------|
| `plot-loop-skill` | 拆书时用"三要素+剧情循环"框架分析目标作品；模仿后用本 Skill 验证结构正确性 |
| `hook-design-skill` | 拆书时分析目标作品的钩子设计方法；模仿后用本 Skill 设计自己的钩子 |
| `rhythm-tuning-skill` | 拆书时分析目标作品的节奏模式；模仿后用本 Skill 控制自己的节奏 |
| `baiteman-design-skill` | 确保模仿的内容是"创作"而非"叙述" |
