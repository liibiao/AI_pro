# golden-opening-skill — 黄金开篇技能

## 用途

指导正文前3章（约6000-9000字）的写作方法论，确保读者从第一句话开始就被抓住，在平台"开篇6000字"数据检测窗口内完成留存转化。

## 触发条件

- P4 正文生产阶段写第1-3章时
- P5 编辑改稿阶段优化开篇时
- P1 立项阶段设计开篇策略时
- 任何需要"如何让读者从第一句就停不下来"的时刻

## 输入

- `project.json`（platform、format、genre、style_profile）
- `story-core.md`（核心冲突、主角困境、金手指设定）
- `characters.md`（主角人设、身份标签）
- `03-outline/chapter-plan.md`（前3章章节计划）
- Market-Researcher 平台开篇规律

## 输出

- 开篇策略文档（嵌入 `03-outline/` 或 `04-draft/`）
- 第1-3章正文

## 方法论

### 一、为什么开篇6000字决定生死

#### 1.1 平台数据窗口

| 维度 | 数据 |
|------|------|
| 读者平均试读时长 | < 3分钟 |
| 读者决定弃书的页面 | 第1-3屏（约300-800字） |
| 平台开篇检测窗口 | 6000字（约15-20分钟阅读） |
| 推荐导入读者耐心 | 几乎为0 |
| 弃书高峰 | 前6000字内流失率高达60-70% |

**6000字是平台基于读者行为数据得出的最小稳定样本**。平台通过开篇6000字内的阅读完成率、章节停留时长、翻页率等行为数据，预测全文留存率。**开篇6000字的数据表现直接决定推荐量。**

#### 1.2 开篇的核心目标

不是"介绍世界观"，不是"铺垫背景"，而是：

1. **让读者停下来**（第一句）
2. **让读者产生兴趣**（前300字）
3. **让读者想看下去**（前800字）
4. **让读者觉得"这本书追得值"**（前3000字）
5. **让读者形成阅读习惯**（前6000字）

### 二、黄金一句：第一句话的设计

> 核心来源：`zhouzi-style-skill` §一（肘子文风）
> 核心来源：`hook-design-skill` §四（开篇钩子专项）

#### 2.1 好的第一句话 = 制造认知落差

| 类型 | 原理 | 示例 |
|------|------|------|
| **反常识** | 打破读者预期 | "死去三年的妻子，今天早上给我发了一条微信。" |
| **悬念型** | 抛出未解之谜 | "他杀了人，但警方判定为自杀——因为他用的是一把不存在的刀。" |
| **冲突直给** | 一上来就在冲突中 | "把东西放下，滚出去。" |
| **情绪钩子** | 直接触发情绪 | "签了这份协议，你就不是我们家的人了。" |
| **信息差** | 读者知道角色不知道的 | "所有人都不知道，这座城市的地下三层，住着另一个文明。" |

#### 2.2 黄金一句禁忌

| 禁忌 | 错误示例 |
|------|---------|
| 世界观介绍 | "在灵气复苏的第137年……" |
| 环境描写 | "清晨的阳光透过窗帘洒在书桌上……" |
| 心理独白 | "他一直觉得自己的人生太平淡了……" |
| 旁白铺垫 | "故事要从那个夏天说起……" |
| 设定说明 | "在异世界，每个人都有一项天赋能力……" |
| 天气开头 | "这是一个风雨交加的夜晚……" |
| 起床照镜子 | "他睁开眼，从床上坐起来……" |
| 自我介绍 | "我叫林凡，今年25岁……" |

### 三、黄金三段：前300字的递进结构

> 核心来源：`zhouzi-style-skill` §1.4（黄金一句→黄金三段）

```
第1句：制造认知落差（钩子）
  ↓ 读者产生"等等？"
第1段：建立主角处境（他是谁？遇到了什么？）
  ↓ 读者产生"这个人在什么状况下？"
前300字：亮核心冲突（他要面对什么？）
  ↓ 读者产生"他会怎么办？"
```

#### 3.1 前300字的5种切入方式

| 切入方式 | 核心操作 | 适用题材 |
|---------|---------|---------|
| **危机切入** | 直接从危险/紧迫事件开始 | 高武、末日、无限流 |
| **悬疑切入** | 发生无法解释的事件 | 怪谈、悬疑、两界 |
| **反转切入** | 第一印象被迅速推翻 | 都市、系统、反套路 |
| **对话切入** | 用一句有冲击力的对话开篇 | 所有题材（最通用） |
| **五感爆破** | 同时刺激多种感官制造沉浸感 | 末世、恐怖、西幻 |

#### 3.2 前300字必须回答的问题

- 这个故事的主角是谁？（身份/处境）
- 他遇到了什么问题？（核心冲突）
- 接下来会怎样？（悬念/期待）

#### 3.3 前300字禁止做的事

- 禁止出场超过2个角色（读者记忆成本过高）
- 禁止解释世界观（世界观通过事件自然带出）
- 禁止静态场景描写（必须是"正在发生的事"）
- 禁止内心独白超过2行（读者不关心陌生人的心理）

### 四、黄金三章：前3章（约6000-9000字）的完整架构

#### 4.1 三章功能分工

```
第1章（2000-3000字）：建立 → 破碎
  核心任务：建立主角处境 → 打碎现状 → 金手指/核心转折亮相
  读者感受："这个人遇到了大麻烦" → "等等，有转机！"

第2章（2000-3000字）：首秀 → 反响
  核心任务：金手指/核心能力首次使用 → 解决最紧迫的困境 → 他人反应
  读者感受："爽！" → "但事情没那么简单"

第3章（2000-3000字）：限制 → 新目标
  核心任务：核心能力的限制/代价 → 引发新麻烦 → 确立短期目标
  读者感受："哦原来有代价" → "期待后续"
```

#### 4.2 第1章详细结构

> 核心来源：`plot-loop-skill` §4.5.2（开局剧情通用公式）

```
[开头 300字]
  ├─ 黄金一句（制造认知落差）
  ├─ 主角处境（他是谁？什么状态？）
  └─ 核心冲突（他遇到了什么问题？）

[中段 1000-1500字]
  ├─ 困境加深（问题变得更严重）
  ├─ 主角应对（尝试解决但失败/不够）
  ├─ 环境描写（穿插五感，带出世界观暗示）
  └─ 困境走到绝境（看似无路可走）

[转折 200-400字]
  ├─ 金手指激活 / 核心转折发生
  ├─ 快速说明核心功能（不啰嗦）
  └─ 展示初步效果

[尾巴 100-200字]
  └─ 章节钩子（更大的问题/机会/危险出现）
```

**第1章困境设计的三层递进**（`plot-loop-skill` §4.5）：

| 层级 | 定义 | 示例 |
|------|------|------|
| **表层困境** | 直观冲突 | 被追杀、欠巨款、被羞辱 |
| **中层困境** | 解决障碍 | 没钱、没实力、没人脉 |
| **深层困境** | 内在驱动 | 救家人、复仇、证明自己 |

**三层叠加才能让读者对金手指的期待值拉满。**

#### 4.3 第2章详细结构

```
[开头 200-300字]
  └─ 承接第1章钩子，快速进入行动

[中段 1500-2000字]
  ├─ 金手指/核心能力首次正式使用
  ├─ 解决最紧迫的困境（反差+具体场景）
  ├─ 他人反应（反派/旁观者/亲友）
  └─ 确认能力价值

[尾巴 200-300字]
  ├─ 问题只解决了一半（留余地）
  └─ 更大的机会/危险出现 → 钩子
```

**金手指首秀的"他人反应"设计**（`plot-loop-skill` §4.5）：

| 反应方 | 变化轨迹 |
|--------|---------|
| 反派 | 嚣张 → 震惊 → 愤怒/恐惧 |
| 旁观者 | 冷漠 → 惊讶 → 羡慕/敬畏 |
| 亲友 | 担忧 → 欣慰 → 支持 |

#### 4.4 第3章详细结构

```
[开头 200-300字]
  └─ 承接第2章钩子，进入新局面

[中段 1500-2000字]
  ├─ 金手指的限制/代价在实战中展现（不是旁白介绍）
  ├─ 利用限制制造新麻烦
  ├─ 新危机出现（因使用金手指引来）
  └─ 主角的应对策略

[尾巴 200-300字]
  ├─ 金手指驱动的短期目标确立
  └─ 埋下长线悬念 → 钩子
```

### 五、开局策略选择矩阵

#### 5.1 三种开局方法

| 方法 | 核心操作 | 效果 | 适用题材 |
|------|---------|------|---------|
| **危机开局** | 主角身处危险，亟待解决 | 紧张感拉满 | 高武、末日、无限流 |
| **悬疑开局** | 发生无法解释的事件 | 好奇心驱动 | 怪谈、悬疑、两界 |
| **反转开局** | 第一印象被迅速推翻 | 惊喜感+记忆点 | 都市、系统、反套路 |

#### 5.2 题材×开局节奏适配

| 题材类型 | 开篇节奏 | 第1章目标 | 前3章目标 |
|---------|---------|---------|---------|
| 爽文/都市/高武 | 极快 | 第一章就有异常事件+第一次翻盘 | 确立爽感模式 |
| 悬疑/探险/两界 | 中快 | 第一章建立悬疑+主角处境 | 揭示第一层真相 |
| 长生/苟道 | 中速 | 第一章建立氛围+特殊设定 | 暗示世界观深度 |
| 规则怪谈 | 极快 | 第一章亮规则+违反后果 | 规则升级+身份揭露 |
| 末世/天灾 | 极快 | 第一章天灾降临+生存压力 | 建立据点+第一次反杀 |
| 穿书/恶毒女配 | 中快 | 第一章穿越/穿书+认清处境 | 逆转第一个反派 |

#### 5.3 平台×开篇强度适配

| 平台 | 前300字要求 | 前1000字要求 | 前3000字要求 |
|------|-----------|-----------|-----------|
| **番茄** | 必须有冲突/反转 | 核心设定亮相+第一波钩子 | 第一次反打/翻盘 |
| **起点** | 可适度铺设但有事件驱动 | 主角处境+世界规则+主要矛盾 | 体系演进方向清晰 |
| **七猫** | 必须有冲突/反转 | 同番茄 | 第一次打脸/爽点 |

### 六、开篇环境描写规范

> 核心来源：`xiaolongbai-style-skill`（小白文风·环境描写方法论）

#### 6.1 开篇环境 = 主角状态 + 职业属性 + 世界背景 + 潜在冲突

开篇的环境描写不是风景，而是「人设 + 世界观 + 剧情」的载体。

#### 6.2 开篇环境三原则

| 原则 | 检验标准 |
|------|---------|
| **可感知** | 读完能否"看到、听到、闻到"？ |
| **有职业** | 换成其他职业，描写是否完全不成立？ |
| **带钩子** | 读完是否想知道"接下来怎么办"？ |

#### 6.3 开篇环境感官选择

- 必写：视觉 + 听觉
- 强烈推荐：嗅觉（开篇必写，建立场景记忆点）
- 推荐：触觉（温度、质感、微痛）
- 总描写长度：控制在3-5段以内，穿插在动作和对话中

#### 6.4 开篇环境→目标联动

环境中的细节必须暗示主角的目标/困境/机会：

| 环境信号 | 暗示的目标 |
|---------|-----------|
| 破旧/匮乏 | 赚钱升级/改变现状 |
| 危机信号 | 生存/逃离/保护 |
| 神秘元素 | 调查真相/掌握能力 |
| 时间压力 | 限时任务/紧迫决策 |

### 七、开篇信息管控

> 核心来源：`scene-writing-skill` §五（信息管控）

#### 7.1 信息释放的铁律

- **开篇只释放与当前场景直接相关的信息**
- 每章只释放 1-2 个新信息点
- 重要信息分 2-3 次释放
- 释放后必须有角色反应

#### 7.2 信息释放的四种方式

| 方式 | 适用 | 示例 |
|------|------|------|
| **事件触发** | 世界观规则 | 不说"他能看到等级"，写"他看了一眼对方头顶，瞳孔微缩——lv.35" |
| **对话透露** | 关系、背景 | 不说"他师傅死了"，写"别人问起师傅，他沉默了很久" |
| **环境暗示** | 世界观细节 | 不说"阶级森严"，写"街道中央青石板光可鉴人，两旁小巷满是泥泞" |
| **行为展现** | 角色能力、身份 | 不说"他是锦衣卫"，写"他进门先扫过所有出口" |

### 八、开篇7维度质量检测

> 基于平台开篇6000字检测的7大维度

| # | 维度 | 检测标准 | 权重 |
|---|------|---------|------|
| 1 | **开篇钩子** | 第一句是否制造认知落差？前300字是否有冲突/悬念？ | 20% |
| 2 | **场景清晰度** | 读者能否快速知道"在哪里""发生了什么"？是否有五感落地？ | 10% |
| 3 | **主角存在感** | 主角是否在前300字内出场？是否有明确的身份/处境/困境？ | 15% |
| 4 | **冲突张力** | 前1000字是否有核心冲突？困境是否有三层递进？ | 20% |
| 5 | **叙事节奏** | 信息密度是否合理？是否有拖沓/信息倾销？ | 15% |
| 6 | **可读性** | 段落长度是否适配手机阅读？句式是否有变化？ | 10% |
| 7 | **对白叙述平衡** | 对话与描写的比例是否合理？对话是否有冲突/信息量？ | 10% |

**评分标准**：每维度0-10分，加权总分 ≥ 7.0/10 方可放行。

### 九、开篇自检清单

#### 9.1 黄金一句自检

- [ ] 第一句话是否制造了认知落差？
- [ ] 第一句话是否包含人物或冲突？
- [ ] 读者看完第一句话后，是否有理由继续读第二句？

#### 9.2 黄金三段（前300字）自检

- [ ] 是否亮出了核心冲突？
- [ ] 读者是否知道主角是谁、遇到了什么问题？
- [ ] 是否出场了超过2个角色？（应≤2个）
- [ ] 是否有大段世界观介绍？（应删除）
- [ ] 是否有静态场景描写超过3行？（应删除或改为动态）

#### 9.3 黄金三章（前6000-9000字）自检

- [ ] 第1章：困境是否有三层递进（表层+中层+深层）？
- [ ] 第1章末尾：金手指/核心转折是否亮相？
- [ ] 第2章：金手指首秀是否有具体场景（不是笼统描述）？
- [ ] 第2章：是否有他人反应（反派/旁观者/亲友）？
- [ ] 第3章：金手指限制是否在实战中展现（不是旁白介绍）？
- [ ] 第3章末尾：是否确立了短期目标？
- [ ] 前3章是否埋了至少1个长线悬念？
- [ ] 前3章的信息释放是否超过6个？（应≤6个）
- [ ] 开篇7维度加权总分是否 ≥ 7.0？

#### 9.4 平台专项自检

**番茄/七猫**：
- [ ] 前300字有冲突/反转？
- [ ] 前1000字完成设定亮相+第一波钩子？
- [ ] 前3章有第一次反打/翻盘？

**起点**：
- [ ] 前1-3章建立：主角处境+世界规则+主要矛盾？
- [ ] 前3章体系演进方向清晰？
- [ ] 慢热≠无事发生，是否有事件驱动？
