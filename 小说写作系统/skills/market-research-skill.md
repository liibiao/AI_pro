# market-research-skill — 市场研究技能

## 用途
平台研究、榜单分析、趋势识别、精品拆解，为选题决策提供数据支撑。

## 触发条件
当需要了解平台规则、分析热门题材、拆解竞品时调用。

## 输入
- 目标平台
- 研究方向（题材/标题/结构/包装）

## 输出
- 研究报告（存入 `research/`）
- 可迁移结论

---

## 方法论

### 一、平台研究框架

每个平台必须搞清楚：

| 维度 | 要点 |
|------|------|
| 流量机制 | 推荐算法偏好什么？完读率/点击率/互动率的权重？ |
| 读者画像 | 年龄/性别/阅读习惯/付费意愿 |
| 热门题材 | 当前哪些题材在涨？哪些在跌？ |
| 标题风格 | 平台头部作品的标题有什么共性？ |
| 字数偏好 | 短篇/中篇/长篇的最优字数区间？ |
| 内容红线 | 哪些内容不能写？审核标准？ |
| 变现模式 | 免费+广告？付费？打赏？ |

### 二、精品拆解流程

按 `bestseller-analysis-standard.md` 执行，核心步骤：

1. 选样本（同题材 Top 3-5）
2. 填基础信息
3. 六维拆解（选题/包装/角色/结构/文风/平台适配）
4. 输出可迁移结论
5. 回写到系统模板库

### 三、热门题材分析

#### 题材生命周期
```
萌芽期 → 爆发期 → 饱和期 → 衰退期
```

#### 判断方法
- 萌芽期：少量作品但数据好，模仿者少
- 爆发期：大量新作涌入，头部作品数据爆炸
- 饱和期：同质化严重，读者审美疲劳
- 衰退期：新作数据持续下滑

#### 策略
- 萌芽期进入 → 高风险高回报
- 爆发期进入 → 需要差异化
- 饱和期进入 → 必须有强创新点
- 衰退期 → 不建议进入

### 四、选题评分

按 `topic-scoring-standard.md` 执行，50 分制：
- 点击感（10分）
- 情绪浓度（10分）
- 冲突强度（10分）
- 反转与爽点潜力（10分）
- 扩写稳定性（10分）

### 五、研究输出规范

每份研究报告必须包含：
1. 研究目标
2. 数据来源与时间
3. 核心发现（3-5 条）
4. 可迁移结论
5. 对系统的更新建议

### 六、题材理解核心方法论（白特慢）

> 来源：白特慢（白蘸糖）2025.6.24 直播教学。题材理解是选题的前提——选题评分之前，先要"吃透题材"。

#### 6.1 题材底层认知：怎么表现 > 能不能写

**核心观念**：不要问"这个题材能不能写"，要问"我怎么把题材的表现力拉满"。

| 错误思维 | 正确思维 |
|---------|---------|
| "XX题材现在火，我也来写一本" | "XX题材的核心看点/爽点/毒点是什么？我怎么做差异化？" |
| 跟风热门题材，不思考呈现方式 | 先吃透题材底层逻辑，再设计如何呈现 |
| 题材=故事背景（可有可无） | 题材=情绪释放载体（选题材=选情绪体验） |

**99%新人扑街根源**：只跟风热门题材，不思考**如何呈现题材、戳中爽点**。

**三个必须想清楚的问题**（动笔前）：
1. 这个题材的**核心看点**是什么？（读者冲什么来看）
2. 这个题材的**核心爽点**是什么？（读者要爽在哪里）
3. 这个题材的**核心毒点**是什么？（踩了什么会弃书）

> 与 `xiaolangjun-style-skill` §十二"情绪商品观"互补：小郎君强调"网文是情绪商品"，白特慢强调"题材是情绪释放的载体"——两者共同指向：**选题材 = 选读者情绪体验**。

#### 6.2 选题三步法

白特慢选题流程 = **查榜单 → 拆对标 → 找切口**：

**Step 1：查榜单（判断读者基数）**
- 翻平台近一年上架/三江/新书榜
- 看同题材数量和排名分布
- 判断：这个题材的**读者基数够不够支撑长篇？**

**Step 2：拆对标（提炼题材核心梗）**
- 选 3-5 本同题材头部作品
- 提炼：核心爽点、金手指类型、人设模板、剧情循环模式
- 判断：这个题材的**成功公式是什么？**
- 详见 `book-dissection-skill` 四层拆解法

**Step 3：找切口（做差异化）**
- 用**小众设定 / 特殊职业 / 限制条件**做切口
- 避开同质化内卷：别人写"系统流"，你写"系统有Bug"；别人写"重生"，你写"重生次数有限"
- 判断：**我的切入点是否足够独特？**

```
查榜单（有没人看？）
  → 拆对标（怎么写的才好？）
    → 找切口（我怎么写得不一样？）
      → 三要素锁定（`plot-loop-skill` §1：题材×金手指×主角身份）
```

#### 6.3 新人选题避雷

| 风险类型 | 表现 | 建议 |
|---------|------|------|
| **高门槛题材** | 需要大量专业知识/世界观构建（如硬科幻、部分灵异） | 新人优先选**世界观简单、读者门槛低**的赛道 |
| **老作者垄断题材** | 头部作者已形成品牌壁垒（如部分高武） | 新人先在**易切入、受众广**的赛道练手 |
| **红海内卷题材** | 同质化严重，读者审美疲劳 | 必须**有强差异化切口**才进入，否则避开 |
| **冷门题材** | 读者基数太小 | 除非有独特理解+明确目标平台，否则慎重 |

#### 6.4 长篇 vs 短篇的题材策略

| 类型 | 核心驱动力 | 题材选择建议 |
|------|-----------|-------------|
| **长篇** | **循环架构**——题材必须能支撑持续循环（发育→冲突→解决→收获→新目标） | 选世界观可扩展、势力可叠加、升级有空间的题材 |
| **短篇** | **情绪密度**——题材必须在有限篇幅内释放高强度情绪 | 选冲突密度高、反转空间大、情绪张力集中的题材 |

> 与 `plot-loop-skill` §三剧情循环模式互补：循环模式提供"长篇怎么持续产出爽点"的方法，本节提供"选什么题材才能搭循环"的判断依据。

#### 6.5 题材理解自查清单

动笔前（P0-P1），用以下清单验证是否"吃透了题材"：

- [ ] 我能说出这个题材的**3个核心看点**吗？
- [ ] 我能说出这个题材的**3个核心爽点**吗？
- [ ] 我能说出这个题材的**3个核心毒点**吗？
- [ ] 我查过近一年的**榜单数据**，确认读者基数吗？
- [ ] 我拆过 3-5 本同题材头部作品吗？
- [ ] 我的**差异化切口**是什么？（能用一句话说清）
- [ ] 我的**三要素**（题材×金手指×主角身份）是否统一？
- [ ] 长篇：这个题材能支撑**循环架构**吗？
- [ ] 短篇：这个题材的**情绪密度**够高吗？
- [ ] 我知道**读者期待什么**，我能兑现吗？
