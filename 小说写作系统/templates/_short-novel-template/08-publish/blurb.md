# 简介文案（短篇版）

> 短篇简介与长篇完全不同。核心是"一个极端困境 + 情绪冲击"，不需要世界观或成长体系。
> 详见 `skills/title-blurb-skill.md` §2.4 和 `docs/platform-fit-standard.md` §一.3。

## 短篇简介铁律

1. **60-100字**：极简，一句说完核心困境
2. **第一人称优先**："我"的代入感 >> 第三人称叙述
3. **折叠线前必须有钩子**：前3行（50-60字）决定生死
4. **不需要世界观**：只需要一个极端困境
5. **禁止文艺/含蓄**：直给冲突，直给情绪

## 简介自查

- [ ] 总字数 60-100字
- [ ] 前3行（50-60字）有钩子
- [ ] 第一人称代入感强（或第三人称但视角紧凑）
- [ ] 核心困境一句话交代清楚
- [ ] 读完会产生"想知道结局"的冲动
- [ ] 没有世界观介绍/体系设定
- [ ] 没有剧透核心反转
