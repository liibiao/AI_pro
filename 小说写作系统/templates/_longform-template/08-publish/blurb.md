## 简介设计原则

1. **折叠线法则**：折叠线前的内容决定读者是否展开全部简介（最关键！）
2. **3秒法则**：第一句话必须抓住注意力
3. **不剧透**：只展示前20%的设定，核心反转绝不能写
4. **四要素**：至少包含冲突/反差/悬念/情绪中的3个
5. **卖点前置**：核心爽点/卖点放在前3行
6. **字数控制**：按平台要求严格执行

## 简介自查

### 通用自检

- [ ] 第一句话有钩子（冲突/悬念/反常识/提问）
- [ ] 没有剧透核心反转（只展示前20%）
- [ ] 主角的困境/欲望/特殊之处清晰
- [ ] 读完会产生"想知道后面怎样"的冲动
- [ ] 包含类型关键词（有利于平台推荐算法）
- [ ] 没有使用"本文讲述了"格式
- [ ] 简介语言调性与正文匹配

### 番茄/七猫专项

- [ ] 折叠线前60-80字有冲突或反转
- [ ] 总字数 80-150字
- [ ] 没有"百科全书"式世界观介绍

### 起点专项

- [ ] 折叠线前100-150字有钩子+设定
- [ ] 总字数 150-300字
- [ ] 体现设定深度和长期可读性
