# 双平台标题模式库（基于 66 个公开样本）

> 目标：不是罗列好标题，而是提炼“标题为什么有效”的结构模式。

---

## 一、番茄标题模式库

### 模式 1：我在 X 做 Y
- **结构**：我在 + 异常场景 + 高概念行为
- **代表**：`我在精神病院学斩神`
- **优势**：一眼看到反差与设定，点击欲高
- **适合题材**：都市异能、超凡、收容、职业文

### 模式 2：开局 X
- **结构**：开局 + 关键资源 / 金手指 / 奇特身份
- **代表**：`开局地摊卖大力`
- **优势**：快速交代起点，天然有“接下来会变强”的预期
- **适合题材**：系统、高武、玄幻、经营

### 模式 3：X：这个 Y 有点 Z
- **结构**：大类名词 + 冒号 + 角色/系统/职业 + 有点X
- **代表**：`神级选择：这个御兽师有亿点生猛`
- **优势**：既有类型锚点，又有情绪标签
- **适合题材**：系统、御兽、高武、都市爽文

### 模式 4：反问句 / 反常识句
- **结构**：X？我竟然 / 我只要 / 我一块钱就……
- **代表**：`天赋差？我一块钱买一年修为！`
- **优势**：强情绪、强好奇心、适合免费平台点击竞争
- **适合题材**：系统、模拟器、高武、逆袭爽文

### 模式 5：职业 / 身份 × 怪谈 / 规则 / 异常
- **结构**：规则怪谈：我的职业是 X
- **代表**：`规则怪谈：我的职业是社区大妈`
- **优势**：职业反差 + 副本类型，极易形成传播点
- **适合题材**：规则怪谈、无限流、直播、副本闯关

### 模式 6：超长标题直接卖点
- **结构**：完整讲清主角处境 + 场景 + 卖点
- **代表**：`大一实习，你跑去749收容怪物`
- **优势**：不需要读简介就能明白值不值得点
- **适合题材**：都市异能、国家流、职业文、悬疑超凡

## 二、起点标题模式库

### 模式 1：四字 / 五字抽象名
- **结构**：高度凝练的意象或世界观名词
- **代表**：`夜无疆`、`青山`
- **优势**：有作品感，有品牌感，更适合精品路线
- **适合题材**：玄幻、仙侠、历史、科幻

### 模式 2：概念型规则名
- **结构**：法则 / 图谱 / 之环 / 纪元 / 无疆 / 巡天
- **代表**：`元始法则`、`天人图谱`、`宿命之环`
- **优势**：天然有世界观和秩序感
- **适合题材**：玄幻、诡秘、科幻、体系流

### 模式 3：直接讲主线设定
- **结构**：从X开始 + 建立/修仙/成长/崛起
- **代表**：`从赘婿开始建立长生家族`
- **优势**：清楚交代故事路线，读者知道长期看点在哪
- **适合题材**：家族修仙、经营、长线成长文

### 模式 4：反套路问题句
- **结构**：没钱修什么仙？/ 谁让他修仙的！
- **代表**：`没钱修什么仙？`、`谁让他修仙的！`
- **优势**：在起点也能制造轻微传播感，但不会太像广告
- **适合题材**：反套路仙侠、轻松流、黑色幽默流

### 模式 5：X 之 Y
- **结构**：以X之Y / 宿命之环 / 以神通之名
- **优势**：文学感更强，适合有体系、有格局的书
- **适合题材**：玄幻、仙侠、科幻、悬疑

### 模式 6：题材 + 机制直给
- **结构**：苟在两界修仙 / 无限：来自X的我……
- **优势**：在保留起点克制感的同时，明确题材卖点
- **适合题材**：两界文、诸天文、规则文、修仙文

---

## 三、标题使用原则

### 番茄
1. 标题优先卖点，不怕直白。
2. 读者要一眼知道：主角是谁、挂是什么、爽点是什么。
3. 标题应该像一句广告文案。

### 起点
1. 标题优先辨识度，不必过度营销。
2. 书名最好能体现气质、世界观或长期主线。
3. 标题不能太虚，否则正文承接不住。

---

## 四、实操建议

- 同一个题材做双平台适配时，**标题必须重写，不要共用**。
- 番茄版标题可以更长、更直白、更像钩子。
- 起点版标题应更凝练、更有作品感。

### 示例：同题材双平台改写

- **题材**：家族修仙 + 长生
- **番茄版**：`长生修仙：我在家族里苟成老祖`
- **起点版**：`长生家族` / `万世仙族`

- **题材**：都市异能 + 收容机构
- **番茄版**：`大一实习，你跑去749收容怪物`
- **起点版**：`异常收容录` / `超凡收容档案`
