## 三、当前高频模式
- 高频主角模型：
  1. 开局受压 → 获得特殊能力 → 快速反打型
  2. 平凡人误入超凡体系 → 逐步成长型
  3. 有缺陷但高人格魅力的“反差型主角”

- 高频冲突模型：
  1. 身份压制与翻盘
  2. 规则世界中的求生与破局
  3. 等级/资源稀缺下的持续升级
  4. 组织、家族、学院、势力之间的系统性对抗

- 高频反转模型：
  1. 金手指真相反转
  2. 身份反转
  3. 副本规则误导反转
  4. 同伴/势力立场反转

- 高频标签组合：
  - 都市 + 异能 + 系统
  - 仙侠 + 家族 + 经营
  - 规则怪谈 + 无限流 + 群像
  - 高武 + 升级 + 热血
  - 长生 + 苟道 + 轻松

- 高频标题结构：
  - 我在X做Y
  - 开局X
  - X：这个Y有点Z
  - 抽象型作品名 + 强口碑传播（起点更常见）

## 四、上升趋势
- 新增题材方向：家族修仙、长生陪伴型、轻松反套路仙侠、规则怪谈细分化。
- 新增情绪表达：从纯打脸爽转向“压迫感 + 情绪浓度 + 反差魅力”。
- 新增包装方式：标题更强调高概念词，简介更强调第一波矛盾。

## 五、风险观察
- 同质化严重方向：普通系统爽文、标准模板玄幻升级、无差异御兽文。
- 热门但难写方向：规则怪谈、家族修仙、诡秘悬疑，这些方向对结构和逻辑要求高。
- 标题强但正文弱方向：夸张概念文、无持续升级设计的脑洞文。

## 六、选题建议
- 值得进入题材池：
  1. 都市超凡 + 规则体系
  2. 家族修仙 / 宗门经营变体
  3. 长生流 + 关系陪伴 / 见证时代变迁
  4. 高武流 + 职业 / 竞赛 / 城市副本

- 适合做变体的方向：
  1. 规则怪谈 + 职场 / 学院 / 都市职业
  2. 系统文 + 情绪价值（陪伴、守护、执念）
  3. 传统玄幻 + 轻松反套路表达

- 暂不建议进入的方向：
  1. 无平台区分的普通爽文
  2. 只有概念没有世界规则的伪悬疑
  3. 题材老但包装和主角模型都无新意的跟风作品
