# 双平台稳态题材池（基于 66 个公开样本）

> 样本基础：番茄 34 个 + 起点 32 个，共 66 个公开样本。
> 目标：形成更稳定的题材判断框架，直接服务选题与平台分发。

---

## 一、A级稳态题材池（优先进入选题池）

| 题材 | 平台优势 | 热度稳定性 | 进入理由 | 推荐变体 |
|---|---|---|---|---|
| 都市异能 / 都市超凡 | 番茄强，起点中强 | 高 | 现代代入感强，设定扩展空间大，开篇容易出钩子 | 都市职业 + 异能、学院 + 异能、收容机构 + 异能 |
| 规则怪谈 / 无限流 / 副本流 | 番茄强，起点中强 | 高 | 强悬念、强追读、强反转，短视频传播性高 | 规则怪谈 + 职业、规则怪谈 + 国运、规则怪谈 + 直播 |
| 家族修仙 / 仙侠体系流 | 起点强，番茄中 | 高 | 长线稳定，势力经营与成长空间大，订阅价值强 | 家族 + 御兽、家族 + 长生、家族 + 宗门博弈 |
| 高武 / 升级流 | 双平台都强 | 高 | 目标明确，成长量化，热血驱动稳定 | 高武 + 职业、城市副本高武、竞赛高武 |
| 长生流 / 苟道流 | 番茄中强，起点中强 | 中高 | 兼具陪伴感和长期发展空间，容易形成读者陪跑感 | 长生 + 送葬、长生 + 学院、长生 + 家族 |

## 二、B级潜力题材池（适合做变体）

| 题材 | 平台优势 | 潜力说明 | 风险 |
|---|---|---|---|
| 御兽流 | 双平台可做 | 容易和系统/养成结合，爽点明确 | 同质化高，核心看进化路线设计 |
| 末世生存 / 末日经营 | 番茄强 | 危机感强，职业文和经营文都能挂载 | 写着写着容易只剩资源流水账 |
| 两界穿越 / 两界修仙 | 起点中强 | 资源对冲、世界切换有天然爽点 | 需要控制两界节奏平衡 |
| 都市职业系统文 | 起点中，番茄中 | 医疗、警探、收容、工程等职业切口有新鲜感 | 容易写成流水账或行业说明书 |
| 国家流 / 上交流 | 番茄中 | 近年有传播力，题材新鲜 | 设定平衡难，容易空喊口号 |

## 三、不建议直接跟进的方向

| 方向 | 原因 |
|---|---|
| 普通模板式系统爽文 | 已严重内卷，除非概念极新，否则很难跑出来 |
| 无规则支撑的伪悬疑 / 伪怪谈 | 标题容易吸引人，但正文崩得快 |
| 只有设定没有人物关系的长生文 | 容易变成时间流水账 |
| 纯模仿头部玄幻升级文 | 没有差异化很难在双平台中突围 |

## 四、直接给你的选题策略建议

### 如果你要冲番茄
优先从以下组合选：
1. 都市异能 + 收容 / 机构
2. 规则怪谈 + 职业反差
3. 长生流 + 轻搞笑 + 强陪伴感
4. 高武 + 竞赛 / 副本 / 都市危机

### 如果你要冲起点
优先从以下组合选：
1. 家族修仙 + 御兽 / 长生
2. 高武体系流 + 文明探索
3. 玄幻 + 法则 / 图谱 / 规则体系
4. 都市职业异能 + 长期成长

---

## 五、一句话判断法

- **番茄要问**：这个题材能不能在标题和前三章里立刻爽到人？
- **起点要问**：这个题材能不能撑起 200 章以后还越写越有劲？
