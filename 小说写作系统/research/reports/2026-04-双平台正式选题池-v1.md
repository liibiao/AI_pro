## 二、详细选题卡

### A01 都市收容局实习生

- **一句话故事核**：普通大学生进入超自然收容机构实习，结果发现自己能“看见异常的真实名字”，从边缘实习生一路卷进城市级灾厄。
- **平台优先级**：**番茄 S** / 起点 A
- **推荐理由**：兼具都市代入感、机构体系、异常事件和快速钩子，非常适合番茄前期爆点推进；若增强体系深度，也可适配起点。
- **标题方向**：
  - **番茄版**：`大一实习，你跑去749收容怪物`
  - **起点版**：`异常收容档案` / `城市收容局`
- **主角模型**：低配天赋型实习生 + 冷静观察脑 + 被迫成长
- **核心冲突**：个人保命需求 vs 机构任务责任；异常命名权背后的真相
- **成长模型**：看见名字 → 理解规则 → 介入规则 → 重写部分规则
- **开篇建议**：第 1 章就出现第一只异常个体，第 3 章必须给第一次“实习生反救正式成员”的反打

### A02 社区规则怪谈管理员

- **一句话故事核**：一个即将失业的社区网格员，被迫接手“异常社区”，她每天要处理的不是邻里纠纷，而是夜里会改规则的居民楼。
- **平台优先级**：**番茄 S** / 起点 B
- **推荐理由**：职业反差极强，天然适合番茄传播；怪谈题材有样本支撑，职业切口又能做出差异化。
- **标题方向**：
  - **番茄版**：`规则怪谈：我的职业是社区管理员`
  - **起点版**：`异常街区管理员`
- **主角模型**：嘴硬心细的基层女性角色 / 或中年失意男性角色
- **核心冲突**：现实生活的琐碎规则 vs 异常世界的致命规则
- **成长模型**：执行规则 → 发现漏洞 → 学会谈判 → 成为规则制定者
- **开篇建议**：前 1000 字必须出现第一条“荒谬但致命”的社区规则

### A03 长生送葬人

- **一句话故事核**：主角在修仙乱世中获得不死身与“送葬得奖励”的能力，从人人看不起的白事先生，熬成见证万古的送葬老祖。
- **平台优先级**：番茄 A / 起点 A
- **推荐理由**：长生流稳定，送葬职业自带记忆点，既能做番茄轻快版，也能做起点厚重版。
- **标题方向**：
  - **番茄版**：`长生苟道：我给仙人送葬变强`
  - **起点版**：`送葬长生` / `长生葬师`
- **主角模型**：极度谨慎的观察者型主角，表面窝囊，内心极稳
- **核心冲突**：永生者的安全需求 vs 修仙乱世的持续卷入
- **成长模型**：活下去 → 躲得住 → 看得懂 → 影响时代走向
- **开篇建议**：从一场普通送葬切入，最后发现死者是某位大人物的替身或关键伏笔

### A04 城市高武联赛

- **一句话故事核**：灾变后的城市高武时代，主角为了给家人换取生存资源，被迫参加一场决定阶层命运的城市联赛。
- **平台优先级**：番茄 A / **起点 S**
- **推荐理由**：高武是双平台稳赛道，联赛机制天然适配节奏推进和成长量化，起点尤其吃这套。
- **标题方向**：
  - **番茄版**：`高武联赛：我一拳打穿城市天榜`
  - **起点版**：`高武纪元：城市联赛`
- **主角模型**：资源匮乏型热血主角 + 对家人强责任心
- **核心冲突**：底层资源争夺 vs 城市上层规则垄断
- **成长模型**：地方赛 → 城市赛 → 联邦赛 → 战场级试炼
- **开篇建议**：第 1 章先写资源压迫，第 2 章出现第一次资格争夺

### A05 家族修仙御兽志

- **一句话故事核**：一个边缘修仙小家族，在灵脉破碎、兽潮压境的时代，靠驯养异兽和家族经营，艰难往上爬。
- **平台优先级**：**起点 S** / 番茄 B
- **推荐理由**：家族修仙 + 御兽是起点稳定强需求，长线经营和势力升级空间非常大。
- **标题方向**：
  - **番茄版**：`家族修仙：我靠养兽带全族飞升`
  - **起点版**：`御兽仙族` / `万灵仙族`
- **主角模型**：少族长 / 家族弃子逆位上台型主角
- **核心冲突**：家族存亡 vs 外部宗门、世家与兽潮多线压力
- **成长模型**：守族地 → 扩资源 → 建势力 → 定规则
- **开篇建议**：从家族危机或兽潮攻山开篇，尽快建立“这家快没了”的危机感

### A06 两界药师

- **一句话故事核**：主角同时拥有现代药学知识与修仙世界灵药资源，在两界倒腾资源的过程中，被卷入更大的垄断阴谋。
- **平台优先级**：**起点 A** / 番茄 B
- **推荐理由**：两界文有稳定爽点，药师职业让成长线更专业，也便于做资源与文明差。
- **标题方向**：
  - **番茄版**：`我在两界倒卖灵药发家`
  - **起点版**：`两界药师` / `苟在两界炼丹`
- **主角模型**：理性经营型主角，擅长做局和避险
- **核心冲突**：底层求生套利 vs 两界势力垄断资源
- **成长模型**：小倒爷 → 地区药商 → 战略资源掌控者
- **开篇建议**：先用一次“两界差价”给读者看到爽点，再揭示代价和风险

### A07 国运规则直播

- **一句话故事核**：全球进入规则副本时代，主角被强制投进直播副本，而他发现每条规则都像专门为自己写的陷阱。
- **平台优先级**：**番茄 S** / 起点 C
- **推荐理由**：规则怪谈 + 国运 + 直播属于番茄高传播组合，天然适合追读和短视频切片感。
- **标题方向**：
  - **番茄版**：`规则怪谈：全球直播我即规则`
  - **起点版**：`国运怪谈录`
- **主角模型**：高压下超冷静型主角，擅长观察细节
- **核心冲突**：个人生存 vs 全球注视；破局能力越强越容易被规则针对
- **成长模型**：单人破局 → 团队协作 → 国家级副本对抗
- **开篇建议**：第一个副本必须简洁狠辣，3 条规则内打出记忆点

### A08 末日生存方案商

- **一句话故事核**：末日爆发后，主角的职业不是战士，而是专门给不同势力定制“生存方案”的顾问商人。
- **平台优先级**：番茄 A / 起点 B
- **推荐理由**：职业文 + 末日经营有新鲜感，能避免纯打怪疲劳，适合番茄的连续事件推进。
- **标题方向**：
  - **番茄版**：`末日来了，我靠卖生存方案暴富`
  - **起点版**：`末日方案师`
- **主角模型**：脑力型商人主角，不靠单体战力取胜
- **核心冲突**：卖方案求活 vs 客户随时翻脸；末日秩序重建中的利益博弈
- **成长模型**：街区顾问 → 城市顾问 → 联盟战略师
- **开篇建议**：第 1 个客户必须是“不给方案就会死”的极限场景

### A09 国家修仙项目组

- **一句话故事核**：灵气复苏后，国家秘密成立修仙项目组，主角作为唯一能稳定解析古法阵的人，被迫从研究员变成实战核心。
- **平台优先级**：番茄 A / 起点 B
- **推荐理由**：国家流有传播性，研究员主角也有差异化，适合做“理工感修仙”。
- **标题方向**：
  - **番茄版**：`开局上交修仙界，国家让我先成仙`
  - **起点版**：`国家修仙计划` / `灵气工程局`
- **主角模型**：理工脑主角 + 不想出风头却总被推上前台
- **核心冲突**：科研理性 vs 修仙世界的不讲道理；个人安全 vs 国家战略需求
- **成长模型**：解析古法 → 搭建体系 → 改造体系 → 制定新秩序
- **开篇建议**：从一次实验失控或古阵启动事故切入

### A10 失败者修仙账本

- **一句话故事核**：在“修仙等于负债”的时代，一个资质普通、背着贷款的青年，只能靠精打细算活下去，直到他发现账本里隐藏着旧时代漏洞。
- **平台优先级**：**起点 A** / 番茄 C
- **推荐理由**：符合起点对黑色修仙、反套路、社会结构批判的偏好，容易写出辨识度。
- **标题方向**：
  - **番茄版**：`没钱修什么仙？我拿账本杀穿仙门`
  - **起点版**：`修仙账本` / `负债修仙`
- **主角模型**：底层聪明人，偏现实主义生存流
- **核心冲突**：普通人修仙权利 vs 资源垄断秩序
- **成长模型**：还债 → 漏洞套利 → 反向掌控旧制度
- **开篇建议**：先写“修仙穷人活不下去”的窒息感

### A11 学院长生日志

- **一句话故事核**：主角意外获得近乎无限寿命，却被困在一座代代更替的修仙学院中，以讲师身份目送一届届天才崛起与陨落。
- **平台优先级**：**起点 A** / 番茄 B
- **推荐理由**：长生流加学院群像有厚度，不容易陷入纯流水账，适合起点。
- **标题方向**：
  - **番茄版**：`长生不死：我在修仙学院教了三千年`
  - **起点版**：`长生学宫` / `学院长生录`
- **主角模型**：旁观者型导师主角，情绪克制但内心深重
- **核心冲突**：长生者的超脱姿态 vs 他与学生、时代不可避免的情感连接
- **成长模型**：旁观 → 介入 → 承担时代责任
- **开篇建议**：从一位最像主角年轻时的学生写起

### A12 诡异都市职业人

- **一句话故事核**：在一座被异常事件侵蚀的现代城市里，不同职业的人都在用各自的方式对抗诡异，而主角的能力是“看见每个人职业背后的隐藏规则”。
- **平台优先级**：番茄 A / 起点 A
- **推荐理由**：都市职业切口新，异常规则体系可深可浅，双平台都能做。
- **标题方向**：
  - **番茄版**：`这座城市太诡异，我能看穿所有职业规则`
  - **起点版**：`职业异常录` / `诡异职业人`
- **主角模型**：观察型主角 + 半辅助能力 + 高行动力
- **核心冲突**：职业秩序崩坏 vs 城市维稳；主角的“知晓规则”能力被多方争夺
- **成长模型**：认识单职业规则 → 理解城市规则网络 → 改写职业规则链
- **开篇建议**：从一个最普通的职业岗位出现超现实规则开始
