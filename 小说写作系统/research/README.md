# 市场研究模块

> 用于持续研究番茄、起点等平台的公开信息，沉淀热门题材、精品样本、标题包装、开篇模式、节奏结构与平台差异，最终反哺小说选题与系统迭代。

## 1. 模块目标

这个模块不负责“直接写小说”，而负责回答五个问题：

1. 现在什么题材在热
2. 哪些精品为什么能打
3. 同类题材在不同平台怎么变体
4. 热门作品的标题、简介、开篇、节奏有什么共性
5. 这些结论怎样沉淀回写作系统

## 2. 研究边界

仅研究公开可见信息：
- 榜单页
- 分类页
- 作品公开详情页
- 标签、简介、公开评论关键词
- 平台公开规则与活动页

不做：
- 绕过限制
- 侵入式抓取
- 登录态数据滥采
- 高频违规采集

## 3. 推荐目录

```text
research/
├── README.md
├── raw-data/                  # 原始公开信息记录
├── cleaned-data/              # 清洗后的结构化数据
├── reports/                   # 周报、月报、专题报告
├── casebooks/                 # 精品拆解库
├── scorecards/                # 评分表、选题评分、趋势评分
└── snapshots/                 # 榜单/分类页截图或文本快照说明
```

## 4. 推荐使用顺序

1. 先读 `docs/platform-research-workflow.md`
2. 再读 `docs/bestseller-analysis-standard.md`
3. 再用 `templates/research/` 下的模板开始记录
4. 每轮研究完成后，把结论回写到：
   - `docs/genre-methodology.md`
   - `docs/platform-fit-standard.md`
   - `projects/` 中对应项目的 `01-positioning/` 与 `08-publish/`

## 5. 当前优先研究方向

- 番茄短篇热门题材
- 起点男频长篇热门题材
- 番茄 vs 起点的平台差异
- 热门标题结构
- 开篇 1000 字钩子模式
- 爽点/反转/付费卡点布局
