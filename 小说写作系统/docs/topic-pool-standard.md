# 选题池建设补充规范（v2.1）

> 本文档是对 `topic-scoring-standard.md`、`genre-methodology.md`、`platform-fit-standard.md` 的补充，用于指导如何从样本池进入正式选题池。

---

## 一、选题池入池规则

一个新选题进入正式题材池，至少满足以下 4 条中的 3 条：

1. **样本支持**：在对应平台 30+ 公开样本中能找到至少 3 个相关成功样本
2. **平台适配**：能明确判断更适合番茄还是起点
3. **变体空间**：不是纯复制头部，而是能给出明确变体
4. **可写性**：主角模型、冲突模型、成长模型三者都能说清

---

## 二、题材池分层

### A 池：立即可做
- 有样本支撑
- 有平台适配
- 有变体空间
- 有足够成熟的方法论

### B 池：观察中
- 有热度，但同质化较重
- 或样本不够稳定
- 需要再补 10-20 个样本验证

### C 池：暂不建议
- 热度虚高
- 正文承接差
- 过于依赖噱头
