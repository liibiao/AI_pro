# platform-fit-standard

> 平台适配规范：解决"同一个题材在不同平台怎么写"的问题。涵盖标题、简介、开篇、节奏、排版全链路适配。

> 详细的书名设计方法见 `title-blurb-skill` §一，简介写作方法见 `title-blurb-skill` §二。本文侧重平台差异。

---

## 一、番茄小说适配标准

### 1. 标题

- **字数**：5-15字（最优 8-12字）
- **风格**：直给冲突、情绪化、口语化
- **高频词**：开局/觉醒/重生/规则/系统/长生/神明/怪谈/御兽
- **可用冒号**：`规则怪谈：华夏扛刀参赛`（主标题+副标题）
- **允许口语化**：出大事了！/摊牌了/离婚后/被赶出

### 2. 简介（长篇）

- **字数**：80-150字
- **折叠线**：前3-5行（约60-80字）必须有冲突/反转
- **结构**：一句话钩子 + 2-3行加压 + 结尾悬念
- **明确要素**：主角困境 + 特殊设定 + 第一阶段目标
- **可加标签**：可在开头加【爆笑】【虐渣】【快穿】等情绪标签
- **禁忌**：不要写成散文化世界介绍，不要超过150字

### 3. 简介（短篇 6000-80000字）

- **字数**：60-100字
- **折叠线**：前3行必须有钩子（番茄短篇折叠更狠）
- **人称**：优先第一人称"我"，代入感极强
- **结构**：极限困境 + 情绪渲染 + 悬念/反转
- **核心**：不需要展示世界观或成长体系，只需要"一个极端困境"
- **禁忌**：禁止用文艺/含蓄写法

### 4. 开篇

- 前 300 字就要有异常/冲突/危机
- 前 1000 字完成设定亮相和第一波钩子
- 前 3 章最好出现第一次反打/翻盘

### 5. 节奏

- 高频刺激、小高潮密集
- 强调追读感而非慢热沉浸
- 每1000字至少一个爽点/反转

### 6. 排版

- 段落短（80-150字为主），手机阅读优先
- 参见 `docs/text-formatting-standard.md`

### 7. 适合题材

- 都市异能、系统爽文
- 规则怪谈/无限流
- 长生轻松流
- 快节奏御兽/高武
- 末世/天灾
- 女频穿书/恶毒女配逆袭

## 二、起点中文网适配标准

### 1. 标题

- **字数**：2-12字（最优 4-8字）
- **风格**：可含蓄有意境、世界观型、体系型
- **特色**：允许"元始法则""山河稷""惊涛落日"这类有质感的书名
- **高频词**：无特定高频词，看重辨识度和独特性
- **禁忌**：过度营销感（"震惊！""前夫跪在"等番茄风在起点违和）

### 2. 简介

- **字数**：150-300字（可展开）
- **折叠线**：前5-8行（约100-150字）
- **结构**：世界观 + 主角处境 + 核心矛盾 + 长期看点
- **体现设定深度和长期可读性**
- 主线目标、世界规则、主角成长空间需要清楚
- 可以适度保留悬念，但不能空泛
- **禁忌**：不在开头加【标签】

### 3. 开篇

- 允许适度铺设，但必须有事件驱动
- 前 1-3 章至少建立：主角处境 + 世界规则 + 主要矛盾
- 慢热不等于无事发生

### 4. 节奏

- 更看重长期订阅价值
- 爽点不必太密，但必须扎实
- 强调体系演进、世界深挖、角色成长

### 5. 适合题材

- 家族修仙、高武体系流
- 玄幻长线升级
- 科幻/诡秘/规则体系文
- 精品都市成长文
- 游戏异界/诸天无限
- 历史架空

## 三、七猫小说适配标准

### 1. 标题

- **字数**：5-15字（最优 8-12字）
- **风格**：同番茄，直给冲突、情绪化
- **高频词**：霸总/甜宠/逆袭/重生/离婚后/夫人
- **可用冒号**分隔主副标题

### 2. 简介

- **字数**：80-150字
- **折叠线**：前3-5行（约60-80字）必须有钩子
- **风格**：情绪渲染+打脸感+爽点暗示
- **同番茄**，可加情绪标签前缀

### 3. 节奏

- 同番茄，极快节奏

### 4. 适合题材

- 都市甜宠/霸总
- 女频逆袭/重生
- 规则怪谈/悬疑
- 末世囤货

## 四、系统执行规则

1. `project.json` 必须明确 `platform`。
2. `title-options.md` 和 `blurb.md` 必须按平台输出不同版本。
3. `chapter-rhythm-standard.md` 后续应增加平台分支。
4. 同一题材做跨平台适配时，不是简单换书名，而是要重写：
   - 标题策略（番茄直给 vs 起点含蓄）
   - 简介策略（番茄80字 vs 起点300字）
   - 开篇强度（番茄300字 vs 起点3000字）
   - 钩子密度
   - 爽点分布
   - 排版格式

## 六、一句话判断

- **番茄**：先让人点开，再让人一直刷。
- **起点**：先让人认可质量，再让人愿意长期追。
- **七猫**：先让人点开，再让人一直刷。
