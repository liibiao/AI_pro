## 〇、核心理念（3条底层逻辑）

| # | 底层逻辑 | 来源 | 一句话 |
|---|---------|------|--------|
| 1 | **情绪商品论** | 小郎君 | 网文是"情绪商品"，读者追求解压/爽/共情，把"一个核心情绪"做到极致 |
| 2 | **创作≠叙述** | 白特慢 | 创作是设计（冲突/选择/代价），叙述是执行；先创作后叙述，不能混为一谈 |
| 3 | **人设=绝境下的选择** | 白特慢 | 人设不是"作者说"而是"剧情逼"，用选择/冲突/代价/细节自然暴露 |

**爆文公式**：
```
情绪价值拉满 + 节奏精准把控 + 人设极致鲜明 + 逻辑闭环 + 细节真实 = 爆文
```

## 二、按创作维度的方法论速查

### 金手指设计全链路

```
1. 三要素锁定（题材×金手指×主角身份）          → plot-loop-skill §1
2. 金手指适配人设（隐忍/暴躁/务实→对应金手指）   → plot-loop-skill §4.5.0
3. 金手指限制设计（代价/冷却/渐进解锁）          → plot-loop-skill §4.3
4. 三者使绊子（世界观↔金手指↔主角互相制约）      → plot-loop-skill §4.4
5. 开局五步设计（困境→登场→首秀→限制→目标）     → plot-loop-skill §4.5.1
6. 类型专项：
   ├── 重生回档（30章锁死结构）                  → plot-loop-skill §4.6
   └── 杀人变强（有底线的爽）                    → plot-loop-skill §4.7
7. 剧情内在逻辑（动机+能力+因果+世界观）         → plot-loop-skill §六
```

### 人设打造全链路

```
1. 核心标签设计（1-2个关键词）                   → character-arc-skill §四B
2. 反差感设计（外表vs实力/身份vs真相等5维度）    → character-arc-skill §四B
3. 人设拨出4方法：
   ├── 绝境二选一（逼出底线）                    → character-arc-skill §七
   ├── 冲突升级（逼出性格强度）                  → character-arc-skill §七
   ├── 代价交换（逼出执念）                      → character-arc-skill §七
   └── 细节反差（逼出隐藏面）                    → character-arc-skill §七
4. 特殊人设：
   ├── 魅力渣男主                                → character-arc-skill §六
   └── 杀伐果断型                                → rhythm-tuning-skill §六
5. 配角设计：
   ├── 功能分配（镜像/催化/信息/情感锚/对比/工具）→ character-arc-skill §三
   └── 羁绊建立（5种方式+3个阶段）               → character-arc-skill §四C
```

### 节奏控制全链路

```
1. 节奏诊断（快/慢/忽快忽慢/高潮不高/中段塌腰）  → rhythm-tuning-skill §一
2. 三种手段：
   ├── 加速（短句/删描写/动作代替心理）          → rhythm-tuning-skill §二
   ├── 减速（环境/微动作/拉长对话/心理/感官）    → rhythm-tuning-skill §二
   └── 蓄力（慢节奏+倒计时+沉默+环境变化）       → rhythm-tuning-skill §二
3. 主动拖慢（4种场景+6种方法+三不原则）          → rhythm-tuning-skill §五
4. 玄幻快节奏+杀伐果断（压→爆→爽三步）          → rhythm-tuning-skill §六
5. 章节节奏模板（战斗/情感/悬疑）               → rhythm-tuning-skill §三
```

### 描写与画面全链路

```
1. 五感写作（视觉+听觉+触觉+嗅觉≥2种）          → description-skill §一
2. 描写密度控制（场景类型→密度→说明）             → description-skill §二
3. 功能性环境描写（映射情绪/制造氛围/提供信息/推动剧情）→ description-skill §三
4. 镜头感写作（角度+拆解+感官+节奏+留白）        → description-skill §七
5. 动作描写（关键高潮拆过程/日常写结果）          → description-skill §四
6. 环境描写（可感知+有职业+带钩子）              → xiaolongbai-style-skill
```

## 三、自检清单速查（按阶段）

### P1 立项自检
- [ ] 三要素（题材/金手指/主角身份）是否全部锁定？
- [ ] 三者是否有明确交汇点（故事核）？
- [ ] 是否完成开书准备7步清单？（`new-book-checklist.md`）

### P2 角色自检
- [ ] 主角是否有1-2个核心标签+反差感？
- [ ] 主角人设是否能通过"绝境二选一"剧情展现？
- [ ] 每个配角是否有明确的戏剧功能？
- [ ] 反派是否分级且"智商在线"？

### P3 大纲自检
- [ ] 金手指是否有明确的使用限制/代价？
- [ ] 三者（世界观/金手指/主角）是否相互制约？
- [ ] 剧情内在逻辑4根支柱是否满足？
- [ ] 钩子密度是否达标？

### P4 正文自检
- [ ] 每章是否推进了至少一项（主线/关系/信息）？
- [ ] 描写是否调用了≥2种感官？
- [ ] 关键场景是否有镜头感？
- [ ] 节奏是否有起伏（不是一条直线）？
- [ ] 对话是否有潜台词（不超3行）？
