# genre-methodology

> 基于研究模块沉淀的题材方法论库。用于回答：某一类题材为什么能打、怎么写、容易写崩在哪。

---

## 一、当前优先题材池（2026-04）

### 1. 都市超凡 / 都市异能
- **平台适配**：番茄强，起点中强
- **核心卖点**：现代都市代入感 + 超凡力量突破现实边界
- **典型爽点**：身份翻盘、组织晋升、能力碾压、规则破局
- **写作要点**：开篇必须快，第一章最好就出现异常事件或能力亮相
- **常见硬伤**：背景像空壳、组织体系不完整、只有打架没有社会关系网

### 2. 规则怪谈 / 无限流
- **平台适配**：番茄强，起点中强
- **核心卖点**：高压环境 + 规则破译 + 死亡风险
- **典型爽点**：发现规则漏洞、反杀副本、智斗翻盘
- **写作要点**：规则必须可执行、可误导、可反转
- **常见硬伤**：规则不自洽、主角开挂太硬、纯靠作者解释推进

**规则怪谈短篇特别注意事项**（基于 `fanqie_duanpian_001` 实战验证）：
1. **规则机制前置**：主角反打规则的方法必须在前文埋下伏笔（如物业流程、公章权限），不能临时解释
2. **时间线硬伤易发**：夜班时间、规则生效时间、事件发生顺序必须前后一致，建议用时间轴表追踪
3. **反派情感锚点**：规则怪谈的"规则制定者"不能只是纯恶，需要有情感动机（如父亲为留住亡女），才能让反转有余味
4. **连续性检查重点**：角色称谓、规则条数、住户信息、监控细节等容易前后矛盾，终审阶段必须逐项核对

### 3. 家族修仙 / 仙侠体系流
- **平台适配**：起点强，番茄中
- **核心卖点**：成长跨度长、势力经营、世界秩序感强
- **典型爽点**：家族崛起、境界突破、资源争夺、布局回收
- **写作要点**：境界、资源、势力、时间线必须同时稳定
- **常见硬伤**：世界设定空洞、升级节奏失衡、家族角色全工具人

### 4. 长生流 / 苟道流
- **平台适配**：番茄中强，起点中强
- **核心卖点**：时间跨度、见证时代、陪伴感与安全感
- **典型爽点**：隐忍发育、时代跃迁、反差反打
- **写作要点**：不能只苟不变，要有阶段性收获和情感锚点
- **常见硬伤**：剧情重复、长期无高潮、人物关系薄弱

### 5. 高武 / 升级流
- **平台适配**：起点强，番茄强
- **核心卖点**：竞争、成长、排名、资源争夺
- **典型爽点**：破纪录、越级胜利、赛场/战场高燃爆发
- **写作要点**：每个阶段要给清晰目标和衡量标准
- **常见硬伤**：数值体系混乱、战斗同质化、成长缺乏代价

## 二、选题判断公式

一个题材是否值得做，优先看：

```text
题材价值 = 平台适配度 × 情绪强度 × 变体空间 × 作者掌控力
```

- **平台适配度**：放在番茄还是起点更合适
- **情绪强度**：是否能迅速调动读者情绪
- **变体空间**：是否能做出差异化
- **作者掌控力**：你是否真的能写住它

---

## 三、当前建议

1. 番茄优先做“高概念 + 快刺激 + 强钩子”题材。
2. 起点优先做“深体系 + 长线成长 + 高完成度”题材。
3. 系统未来应按题材继续建立子方法论，例如：
   - `urban-superpower-methodology.md`
   - `rule-thriller-methodology.md`
   - `family-cultivation-methodology.md`
   - `longlife-methodology.md`
