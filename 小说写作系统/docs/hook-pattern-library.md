# 钩子模式库

> 引擎A·叙事引擎核心文档。提供各层级钩子的模式、案例与设计方法。

---

## 一、书级钩子（让读者点开）

### 标题钩子
详见 `title-blurb-skill.md`。

### 简介钩子
第一句必须有冲突或异常，结尾不揭底。

### 第一段钩子
前三行必须包含：异常事件 / 强烈冲突 / 身份反差 / 紧迫时间压力。

---

## 二、章级钩子（让读者点下一章）

| 类型 | 模式 | 示例 |
|------|------|------|
| 悬念钩 | 信息缺口 | "他打开门，脸色骤变——" |
| 反转钩 | 打破预期 | "验证报告上写着：DNA匹配度99.99%。" |
| 升级钩 | 更大威胁 | "他只是先锋，真正的人还没来。" |
| 情感钩 | 情感期待 | "她转过身，眼眶红了。" |
| 倒计时钩 | 时间紧迫 | "还有三天。" |
| 选择钩 | 两难困境 | "救一个，还是救另一个？" |
| 揭秘钩 | 真相即将揭露 | "他终于说出了那个名字——" |

---

## 三、段级钩子（让读者继续往下读）

在每个场景结尾制造微悬念：
- 角色说了半句话被打断
- 发现异常但还没看清
- 做出决定但还没行动
- 收到消息但还没打开

---

## 四、付费卡点（让读者愿意付费）

### 最佳位置
1. 主角即将翻盘的前一刻
2. 真相即将揭露的前一刻
3. 最大危机的顶点
4. 感情线关键时刻前

### 卡点前必须满足
- 读者已站队（共情主角）
- 压制已到位（读者憋着气）
- 翻盘期待已建立
- 不付费就看不到结果

---

## 五、钩子密度参考

| 平台 | 每千字钩子数 | 说明 |
|------|------------|------|
| 番茄短篇 | 2-3 | 极高密度 |
| 番茄长篇 | 1-2 | 高密度 |
| 起点男频 | 0.5-1 | 中密度，允许铺垫 |
| 起点女频 | 1-1.5 | 中高密度 |

---

## 六、钩子自检

每个钩子必须回答：
1. 读者看到这里会产生什么问题？
2. 这个问题是否足够强烈？
3. 答案在多远的距离内给出？
