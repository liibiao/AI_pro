# 故事核设计规范

## 一、目标

故事核负责解决三个问题：

1. 这本小说讲什么
2. 主角为什么非走下去不可
3. 读者为什么愿意点开

---

## 二、标准公式

> 主角 + 当前困境 + 核心目标 + 关键障碍 + 最大异常点

示例：

> 被前夫和婆家逼到净身出户的我，本想带着女儿离开，却在离婚体检那天发现他们真正盯上的，是我的肾。

---

## 三、合格标准

- 一句话就能看出冲突
- 能看出主角痛点
- 能看出后续升级空间
- 必须有异常点或秘密点
- 不能只有设定，没有情绪抓手

---

## 四、常见废核类型

1. 只有世界观，没有人物困境
2. 只有情绪，没有可推进事件
3. 只有设定反常，没有持续冲突
4. 主题很大，但缺具体行动线
