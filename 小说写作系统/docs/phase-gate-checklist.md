# 阶段门禁检查清单

## Phase 1：定位与立项

- [ ] 平台已明确
- [ ] 目标读者已明确
- [ ] 一句话故事核已明确
- [ ] 卖点能在 1~2 句说清
- [ ] 没有明显题材漂移

放行标准：通过 4 项以上，且故事核清晰。

---

## Phase 2：设定与结构

- [ ] 主角目标明确
- [ ] 对立关系明确
- [ ] 关键冲突链成立
- [ ] 结构不存在明显空档
- [ ] 结尾回收方向已预设

放行标准：关键冲突链与结构主轴稳定。

---

## Phase 3：正文生产

- [ ] 当前章节有推进
- [ ] 当前章节有人物动作与信息变化
- [ ] 章节末尾有钩子
- [ ] 无大段无效抒情
- [ ] 人设未漂移

放行标准：章节有效推进，读者有继续读的动力。

---

## Phase 4：编辑改稿 + 去AI味

- [ ] 语言收紧
- [ ] 节奏明显优于初稿
- [ ] 重复信息已删除
- [ ] 开头更强
- [ ] 结尾更有回响
- [ ] **AI味检测综合分 ≥ 7.0**（`de-ai-skill` §四 8维度评分卡）
- [ ] **AI高频连接词密度 ≤ 1次/千字**（P0级修正项）

放行标准：文风统一、可读性提升明确、**AI味检测通过**。

---

## Phase 5：审校终审 + AI味复检

- [ ] 逻辑闭合
- [ ] 时间线合理
- [ ] 角色称谓一致
- [ ] 设定无冲突
- [ ] 包装与正文一致
- [ ] **AI味抽检通过**（不低于20%章节，`de-ai-skill` 8维度复检）

放行标准：可进入发布或归档状态。
