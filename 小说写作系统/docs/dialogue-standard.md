# 对话写作规范

> 引擎C·文笔引擎核心文档。规范对话写作的质量标准与技巧。

---

## 一、好对话的四个标准

1. **有冲突或信息量**：不是废话
2. **有潜台词**：说的不一定是想的
3. **有个性**：遮住名字能猜出是谁
4. **推动剧情**：对话结束后情况发生了变化

---

## 二、对话类型与写法

### 冲突对话
- 短句快切
- 每句都在攻防
- 少动作描写
- 语气词用"冷笑""低吼"而非"说"

### 信息对话
- 穿插动作和反应
- 不能变成问答模式
- 重要信息用角色反应强调

### 情感对话
- 留白多、动作多、台词少
- 用沉默和微动作传递情感
- 不直说"我爱你"，用行为暗示

### 威胁对话
- 语气越平静越可怕
- 用具体细节而非抽象威胁
- "我知道你女儿在哪上学" > "你会后悔的"

---

## 三、潜台词技巧

| 技巧 | 示例 |
|------|------|
| 说反话 | "没事，我不在意。" |
| 顾左右而言他 | "今天天气真好。" |
| 用问题回避问题 | "你觉得呢？" |
| 用行动否定台词 | 说"我走了"但没动 |
| 沉默 | 不说话本身就是回答 |

---

## 四、对话动作穿插

每 3-5 句台词必须穿插至少一个动作或反应：

```
"报告出来了。"他把文件夹扔在桌上。
她拿起来翻了两页，眉头皱起来："这个数据不对。"
"哪里不对？"
"死亡时间。"她指着第三行，"和监控记录差了两个小时。"
他沉默了几秒，把烟掐灭在烟灰缸里。
```

---

## 五、对话禁忌

1. 问答模式（A问B答A问B答）
2. 独白伪装（一人说200字另一人只说"嗯"）
3. 旁白代言（角色说出不符合身份的分析性语言）
4. 信息倾倒（通过对话解释大量设定）
5. 站桩聊天（全程无动作和环境互动）

---

## 六、对话自检

- [ ] 删掉这段对话，剧情会损失什么？
- [ ] 对话结束后情况是否变化？
- [ ] 每个角色说话方式是否有区分？
- [ ] 是否存在"没人会这样说话"的台词？
- [ ] 是否超过5句台词没有动作穿插？
