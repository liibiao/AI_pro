# 新小说项目初始化指南 v2.0

> 适用于 `小说写作系统` 中的短篇项目、长篇项目与题材测试项目。
> 目标：把“新建项目”从随手建文件夹，升级为可复制、可审核、可追踪的标准化启动流程。

---

## 一、适用范围

- 番茄短篇
- 都市/情感/悬疑短篇
- 起点/番茄/七猫长篇连载
- 新题材测试项目
- 世界观或系列书孵化项目

---

## 二、启动前先回答 4 个问题

在复制模板前，先明确以下问题：

1. **写给谁看？**
   - 平台：番茄 / 起点 / 七猫 / 其他
   - 目标读者：年龄、性别、阅读偏好、情绪需求

2. **这本书卖什么？**
   - 核心卖点是什么？
   - 与同类书相比的差异点是什么？

3. **为什么现在写？**
   - 题材热度处在上升期还是红海期？
   - 你是否有把它写好的经验或资源？

4. **项目规模有多大？**
   - 短篇（3k-2w）/ 中篇 / 长篇连载（20w+）
   - 单本完结 / 系列计划

如果这 4 个问题说不清，先不要启动项目，先去做 `P0 选题研究`。

## 三、模板选择

| 项目类型 | 使用模板 | 适合场景 |
|----------|----------|----------|
| 短篇项目 | `templates/_short-novel-template/` | 番茄短篇、情感反转、都市爽文、悬疑反转 |
| 长篇项目 | `templates/_longform-template/` | 长篇连载、签约书、系列书 |
| 研究项目 | `templates/research/` | 榜单快照、精品拆解、题材评估 |

---

## 四、项目目录命名规范

建议统一使用：

```text
平台_题材_序号
```

示例：
- `fanqie_duanpian_001`
- `qidian_xuanhuan_001`
- `fanqie_dushi_002`

命名要求：
- 全小写
- 使用下划线分隔
- 不使用中文空格
- 序号三位数递增

详见：`docs/naming-convention.md`

## 五、标准初始化步骤

### Step 1：复制模板

短篇：
```bash
cp -r templates/_short-novel-template projects/你的项目名
```

长篇：
```bash
cp -r templates/_longform-template projects/你的项目名
```

### Step 2：修改 `project.json`

至少填写：
- `name`
- `type`
- `platform`
- `genre`
- `target_readers`
- `target_length`
- `style_profile`
- `core_selling_point`

### Step 3：完成 P1 立项定位文件

必须先完成：
- `01-positioning/logline.md`
- `01-positioning/market-positioning.md`

### Step 4：完成 P2-P3 的最小可写骨架

至少完成：
- `02-characters/character-bible.md`
- `03-outline/story-architecture.md`
- `03-outline/chapter-plan.md`

### Step 5：通过门禁后再开写

**禁止跳过以下环节直接写正文：**
- 没有 Logline，不开写
- 没有角色圣经，不开写
- 没有章节规划，不开写

## 六、短篇项目最小启动标准

一个短篇项目可以开始写正文，至少要满足：

- [ ] 已明确目标平台
- [ ] 已明确目标读者
- [ ] 已明确一句话卖点
- [ ] 已明确主角与对手/镜像关系
- [ ] 已完成短篇结构（开头钩子 / 中段递进 / 结尾反转）
- [ ] 已有章节/段落级计划
- [ ] 已通过 Phase Gate（P1-P3）

---

## 七、长篇项目最小启动标准

一个长篇项目可以开始写第 1 章，至少要满足：

- [ ] 已完成选题研究或竞品拆解
- [ ] 已完成 Logline 和市场定位
- [ ] 已完成主角、反派、核心配角的人设档案
- [ ] 已完成整体结构（至少到第一卷）
- [ ] 已完成前 20-30 章规划
- [ ] 已明确世界规则 / 力量体系 / 关键势力（如题材需要）
- [ ] 已建立 `04-draft/chapter-index.md`
- [ ] 已建立 `05-edit/continuity-tracker.md`

---

## 八、推荐启动顺序

### 短篇推荐顺序

```text
P0 选题研究 → P1 立项定位 → P2 角色设定 → P3 结构大纲 → P4 正文生产
```

### 长篇推荐顺序

```text
P0 选题研究 → P1 立项定位 → P2 角色设定 → P3 结构大纲 → 07-worldbuilding → P4 正文生产
```

## 九、常见错误

### 错误 1：先写正文再补设定
结果：人物跑偏、结构返工、前后矛盾严重。

### 错误 2：只有灵感，没有市场定位
结果：写出来自己爽，但不适配平台。

### 错误 3：角色设定过多
结果：短篇塞不下，长篇控不住。

### 错误 4：没有章节索引
结果：进度不可追踪，改稿成本飙升。

### 错误 5：没有复盘层
结果：项目做完即散，经验无法沉淀。

---

## 十、初始化完成定义

当以下条件全部满足，才算“项目初始化完成”：

- [ ] 目录结构正确
- [ ] `project.json` 已填写
- [ ] `01-positioning/` 已完成
- [ ] `02-characters/` 已完成
- [ ] `03-outline/` 已完成
- [ ] 长篇项目已补齐 `07-worldbuilding/`
- [ ] 已通过 `docs/phase-gate-checklist.md` 中对应门禁
- [ ] 可以进入 `04-draft/` 正文阶段

---

## 十一、初始化后下一步做什么

初始化完成后，立刻进入：

1. 建立 `04-draft/chapter-index.md`
2. 从第 1 章 / 第 1 节开始试写
3. 每写完一章运行一次章节自检
4. 每完成一个阶段更新状态文档与改稿记录
5. 项目结束后填写 `09-retro/` 复盘文档
