# 正文排版规范

> 版本：v1.0 | 基于起点、番茄等主流网文平台热门小说排版惯例总结

## 核心原则

> **手机屏幕是第一阅读场景。** 所有排版决策以手机阅读体验为最高优先级。
> 排版的目标不是"好看"，而是让读者**看得快、看得轻松、不想停下来**。

---

## 一、段落长度

### 1.1 手机阅读黄金法则

| 段落类型 | 字数上限 | 手机屏幕行数 | 适用场景 |
|---------|---------|-------------|---------|
| **标准段落** | 80-150字 | 4-7行 | 日常叙事、环境描写 |
| **短段落** | 20-60字 | 1-3行 | 对话、动作、心理活动 |
| **极短段落** | 1-15字 | 1行以内 | 强调、转折、钩子 |
| **长段落**（慎用） | 150-250字 | 8-12行 | 大场景铺陈、回忆闪回 |

**铁律**：**超过 200 字（约10行手机屏幕）的段落必须拆分。** 超过 300 字的段落视为排版事故。

### 1.2 一段一意

**一个自然段只表达一个核心意思。** 意思转换时立即分段。

```
❌ 错误（多意混段）：
他走到窗边，看着外面灰蒙蒙的天空，想起了小时候和妈妈一起看雨的情景。那时候的雨好像总是带着泥土的清香，不像现在只有灰尘的味道。他叹了口气，转身走向门口。

✅ 正确（一段一意）：
他走到窗边。

外面灰蒙蒙的，空气里全是灰尘的味道。

小时候的雨不是这样的。那时候一下雨，就能闻到泥土的清香。他好像还牵着妈妈的手……

他叹了口气。转身走向门口。
```

### 1.3 分段口诀

```
意思换了就分段
说完一句就回车
对话一人占一行
紧张时刻分段密
描写场景分层写
```

## 二、对话排版

### 2.1 基本规则

| 规则 | 说明 |
|------|------|
| **一人一段** | 不同角色的对话永远不在同一段，即使对话很短 |
| **对话+动作同段** | 说话人的动作/神态放在对话前后，不单独成段 |
| **可省略对话标签** | 节奏快且角色特征明显时，省略"XX说" |

```
❌ 错误：
"你来了。"张三说道。"我等你很久了。"李四回应。

✅ 正确：
"你来了。"张三抬起头，眼神复杂。

"我等你很久了。"李四冷冷地回应。
```

### 2.2 对话节奏与分段

| 对话节奏 | 段落特征 | 适用场景 |
|---------|---------|---------|
| **快节奏对话** | 短句+极短段落+省略标签 | 吵架、追逃、紧急情况 |
| **正常节奏** | 对话+动作/神态同段 | 日常交流、信息交换 |
| **慢节奏对话** | 对话间穿插环境/心理描写 | 情感戏、伏笔铺垫、氛围渲染 |

**快节奏对话示例**：
```
"走！"
"来不及了。"
"我说走！"

他一把拽住她的手腕，冲了出去。
```

### 2.3 独白与内心戏

| 类型 | 排版方式 |
|------|---------|
| **直接想法** | 不用引号，直接写，可单独成段 |
| **自言自语** | 用引号，格式同对话 |
| **长段思考** | 拆成多段，每段一个想法层次 |

```
直接想法（不用引号）：
不对劲。

这个人不像是偶然路过的。

自言自语：
"怎么会这样……"

他反复翻看着手中的照片，手指微微发抖。
```

## 三、描写排版

### 3.1 分感官描写

复杂场景/人物描写**按感官分层呈现**，不堆砌在一个段落里。

```
❌ 错误（感官堆砌）：
房间里弥漫着一股发霉的气味，墙上挂满了蜘蛛网，角落里堆着腐烂的木头，窗户破碎了，冷风从裂缝中灌进来，发出呜呜的声音，地上满是碎玻璃和灰尘，几乎无处落脚。

✅ 正确（分感官分层）：
一股发霉的气味扑面而来。

墙角堆着腐烂的木头，蜘蛛网从天花板垂下来，沾满了灰尘。

窗户碎了。冷风灌进来，呜呜作响。

地上全是碎玻璃。他踩上去，咯吱一声。
```

### 3.2 分区域描写

大场景描写**按空间顺序分段**：整体→局部→细节，或从左到右、从上到下。

### 3.3 外貌描写分段

| 分段 | 内容 |
|------|------|
| 第一段 | 整体气质/第一印象 |
| 第二段 | 五官特写（最有个性的特征） |
| 第三段 | 穿着/举止/标志性物品 |

> 不要写简历式外貌（身高体重发型眼睛鼻子嘴巴一口气列完）。

## 四、节奏与排版的关系

> 与 `chapter-rhythm-standard.md` 互补：该规范讲"节奏快慢怎么控制"，本规范讲"节奏快慢在排版上怎么呈现"。

### 4.1 快节奏排版

| 手段 | 效果 | 适用场景 |
|------|------|---------|
| 极短段落（1行以内） | 制造紧迫感 | 战斗、追逃、危机 |
| 一句一段 | 视觉冲击 | 关键反转、重要信息 |
| 独词成段 | 强调/停顿 | "空了。""跑！""死了。" |
| 省略过渡 | 加速叙事 | 动作衔接、场景切换 |

```
快节奏示例：
他猛地回头。

身后没有人。

但脚步声还在。

越来越近。
```

### 4.2 慢节奏排版

| 手段 | 效果 | 适用场景 |
|------|------|---------|
| 标准段落（4-7行） | 舒缓沉浸 | 环境描写、情感戏 |
| 长段落（8-12行，慎用） | 氛围铺陈 | 回忆、大场景 |
| 感官分层 | 丰富立体 | 细致描写 |
| 对话间穿插描写 | 放缓节奏 | 情感对话、伏笔 |

### 4.3 钩子排版

章尾钩子**必须单独成段**，制造视觉冲击：

```
✅ 好的钩子排版：
门缓缓打开。

站在门后的，竟然是——

❌ 差的钩子排版：
门缓缓打开了，他惊讶地发现站在门后的竟然是那个他以为再也见不到的人，这让他一时之间不知道该说什么好。
```

## 五、标点符号规范

### 5.1 基本规则

| 规则 | 说明 |
|------|------|
| **全角标点** | 一律使用中文全角标点（，。！？""''；：） |
| **中英文不混用** | 引号、逗号、句号严格使用中文标点 |
| **省略号** | 用六个点（……），不用三个点（...） |
| **破折号** | 用两个（——），不用一个（-） |
| **对话标点** | "说"前面用冒号（："），不用逗号 |

### 5.2 标点与节奏

| 标点 | 节奏效果 | 适用场景 |
|------|---------|---------|
| **句号** | 断句、停顿 | 制造节奏的基本单位 |
| **逗号** | 连续、流畅 | 日常叙事 |
| **省略号** | 犹豫、未尽 | 心理活动、悬念 |
| **破折号** | 突然转折 | 意外、打断 |
| **感叹号** | 情绪爆发 | 警告、呐喊（**慎用，一章≤3个**） |
| **问号** | 疑问、钩子 | 设问、反问 |
| **分号** | 并列关系 | AI味重，**尽量不用** |

### 5.3 标点禁区

| 禁区 | 原因 |
|------|------|
| 一段内超过3个感叹号 | 情绪过载，廉价化 |
| 一段内连续3+个逗号 | 句子过长，读者喘不过气 |
| 用英文标点 | 视觉不协调，不专业 |
| 用分号代替句号 | AI味特征（`de-ai-skill` §三 Step 8） |

## 六、特殊排版格式

### 6.1 章节标题

| 项目 | 格式 |
|------|------|
| 标题格式 | 第X章 章节名称（中文数字或阿拉伯数字，全书统一） |
| 标题位置 | 单独一行，正文开始前 |
| 标题长度 | 2-10字，简洁有力 |
| 标题内容 | 可用事件名/地点名/悬念句，不用总结性标题 |

```
✅ 好的标题：
第一百二十三章 雨
第三十四章 谁在说谎
第56章 你知道太多了

❌ 差的标题：
第一章 主角出生
第二章 开始修炼
第三章 第一次战斗（模板化，无吸引力）
```

### 6.2 分隔线/过渡

| 场景 | 排版方式 |
|------|---------|
| **场景切换** | 空一行 + 新段落开头（不需要分隔线） |
| **时间跳跃** | 用一句时间提示过渡："三天后。""半年过去了。" |
| **视角切换**（多POV） | 用分隔线或空两行明确标注 |
| **回忆/闪回** | 用短句触发，不标注"（回忆）" |

### 6.3 强调格式

| 手段 | 适用场景 |
|------|---------|
| **独词成段** | 强调、停顿 |
| **短句连续排列** | 紧迫、连续动作 |
| **重复句式** | 情绪叠加（慎用） |
| **省略号结尾** | 悬念、未尽之意 |

```
强调示例：
他低头。

手在抖。

不是因为冷。
```

### 6.4 禁止使用的排版元素

| 禁止项 | 原因 |
|--------|------|
| 星号分隔线（***） | 网文平台不支持或显示异常 |
| 颜色/加粗/斜体 | 平台统一渲染，作者设置的会被忽略 |
| 多级标题（###） | 章内不需要标题层级 |
| 序号列表（1. 2. 3.） | 正文不是文档 |
| 英文括号/方括号 | 视觉不协调 |

## 七、平台适配

### 7.1 各平台排版差异

| 平台 | 段落间距 | 缩进 | 章节字数 | 特殊要求 |
|------|---------|------|---------|---------|
| **起点** | 段落间不空行 | 段首空两格 | 2000-5000字/章 | 全角标点，章节序号统一 |
| **番茄** | 段落间空一行 | 不缩进（顶格） | 1500-3000字/章 | 手机阅读优化，段落宜短 |
| **七猫** | 段落间空一行 | 不缩进 | 1500-3000字/章 | 段落宜短，对话清晰 |
| **纵横** | 段落间空一行 | 不缩进 | 2000-4000字/章 | 章节标题简洁 |
| **知乎/头条** | 段落间空一行 | 不缩进 | 800-2000字/篇 | 短段落，标题党 |

### 7.2 通用适配策略

> 本系统默认采用**手机阅读优先**的排版策略，兼顾所有平台：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| **段落间距** | 段落间空一行 | 手机阅读黄金法则 |
| **首行缩进** | 不缩进（顶格） | 依赖空行区分段落，适配移动端 |
| **标准段落长度** | 80-150字（4-7行手机屏） | 手机阅读最舒适区间 |
| **极短段落** | 1-15字 | 强调/转折/钩子 |
| **最大段落** | ≤200字 | 超过必须拆分 |
| **单章字数** | 2000-3500字 | 主流平台通用区间 |
| **标点** | 全角中文标点 | 全平台通用 |

> 发布到特定平台时，按 `platform-adapt-skill` 调整段落间距和缩进方式。

## 八、排版自检清单

### 8.1 每章自检

- [ ] 是否有超过 200 字的段落？（有则拆分）
- [ ] 是否有超过 300 字的段落？（有则视为排版事故）
- [ ] 是否遵守"一段一意"原则？（多意混段则拆分）
- [ ] 对话是否一人一段？（多人在同一段则拆分）
- [ ] 标点是否全部为全角中文标点？（有英文标点则修正）
- [ ] 一章内感叹号是否 ≤ 3个？（过多则替换）
- [ ] 章尾钩子是否单独成段？（否则调整排版）
- [ ] 章节标题是否符合2-10字规范？

### 8.2 快节奏段落自检

- [ ] 战斗/追逃场景是否使用了极短段落？
- [ ] 关键反转是否单独成段？
- [ ] 紧张场景是否省略了不必要的过渡句？

### 8.3 慢节奏段落自检

- [ ] 环境描写是否分了感官层次？
- [ ] 外貌描写是否分段呈现（气质→五官→穿着）？
- [ ] 情感戏对话间是否穿插了动作/环境？

### 8.4 AI味排版自检

> 与 `de-ai-skill` §三 Step 8 互补。

- [ ] 标点使用是否有多样性？（省略号/破折号/独词段）
- [ ] 是否过度使用分号？（分号为AI味特征）
- [ ] 段落长度是否有波动？（AI倾向均匀段落）
- [ ] 是否有模板化结尾段？（总结/点题/呼应）
