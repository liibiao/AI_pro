# 命名规范

## 一、项目目录命名

```
[平台简称]_[题材简称]_[序号]
```

示例：
- `fanqie_duanpian_001`（番茄短篇第1个）
- `qidian_xuanhuan_001`（起点玄幻第1个）
- `fanqie_dushi_002`（番茄都市第2个）

---

## 二、章节文件命名

```
chapter-[三位数序号].md
```

示例：
- `chapter-001.md`
- `chapter-012.md`
- `chapter-100.md`

---

## 三、文档文件命名

使用小写英文 + 连字符：
- `character-bible.md`
- `story-architecture.md`
- `chapter-plan.md`
- `revision-log.md`

---

## 四、研究文件命名

```
[平台]-[类型]-[日期].md
```

示例：
- `fanqie-ranking-snapshot-20260415.md`
- `qidian-bestseller-breakdown-20260415.md`
- `fanqie-hot-topic-analysis-20260415.md`

---

## 五、角色/设定命名

在文档内部使用中文全名，不缩写：
- 角色：林天、林婉儿
- 设定：无限强化系统、灵纹体系
- 地点：墙外乱区、联邦七城
