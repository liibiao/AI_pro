# 张力升级规范

> 引擎A·叙事引擎核心文档。规范"压制→爆发→再压制"的循环设计。

---

## 一、张力公式

```
张力 = 读者的期待 × 实现的阻力
```

期待越高、阻力越大，张力越强。爽点 = 张力释放的瞬间。

---

## 二、压制-爆发循环

### 基本单元
```
蓄压（制造困境）→ 加压（困难升级）→ 临界（绝望顶点）→ 爆发（翻盘/碾压）→ 余波（短暂平静）
```

### 循环升级原则
1. 每次循环的压制强度必须高于上一次
2. 每次爆发的爽感必须高于上一次
3. 不能连续两次用同样的方式翻盘
4. 余波阶段必须埋下一次循环的种子

---

## 三、压制手段库

| 类型 | 说明 | 示例 |
|------|------|------|
| 实力压制 | 敌人比主角强 | 打不过、被碾压 |
| 身份压制 | 地位/权力不对等 | 被欺负、被驱逐 |
| 情感压制 | 伤害主角在意的人 | 妹妹被抓、恋人被威胁 |
| 信息压制 | 主角不知道真相 | 被蒙在鼓里、被陷害 |
| 时间压制 | 倒计时/deadline | 三天内必须找到解药 |
| 道德压制 | 两难选择 | 救一个就要牺牲另一个 |

---

## 四、爆发方式库

| 类型 | 说明 | 爽感来源 |
|------|------|---------|
| 实力碾压 | 一拳秒杀 | 力量反差 |
| 身份揭露 | 真实身份曝光 | 打脸反差 |
| 智谋翻盘 | 用计策反杀 | 智力优越感 |
| 情感爆发 | 压抑后的呐喊 | 情绪释放 |
| 真相揭露 | 揭开隐藏的秘密 | 认知反转 |
| 牺牲换取 | 付出代价获得胜利 | 悲壮感 |

## 六、张力自检

- [ ] 当前压制是否比上一次更强？
- [ ] 读者是否已经"憋到极限"？
- [ ] 爆发方式是否与之前不同？
- [ ] 爆发后是否留了下一次循环的种子？
