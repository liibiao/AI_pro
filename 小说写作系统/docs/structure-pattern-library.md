# 结构模式库

> 引擎A·叙事引擎核心文档。提供常见故事结构的模板与适用场景。

---

## 一、三幕式

```
第一幕（25%）：建立世界 → 触发事件 → 进入冲突
第二幕（50%）：持续加压 → 中点反转 → 最低谷
第三幕（25%）：高潮对决 → 解决 → 新平衡
```

### 适用
- 短篇（5000-15000字）
- 情感反转文
- 悬疑反转文

### 关键节点
| 位置 | 事件 | 功能 |
|------|------|------|
| 10% | 触发事件 | 打破日常 |
| 25% | 第一转折 | 进入主冲突 |
| 50% | 中点反转 | 改变方向或揭露信息 |
| 75% | 最低谷 | 主角最绝望的时刻 |
| 90% | 高潮 | 最终对决/最大反转 |
| 95-100% | 收束 | 回收+新平衡 |

---

## 二、五幕式

```
铺设（15%）→ 上升（20%）→ 高潮前（20%）→ 高潮（25%）→ 收束（20%）
```

### 适用
- 中长篇（30000字以上）
- 多线叙事
- 需要丰富世界观的题材

---

## 三、螺旋升级式

```
[压制 → 蓄力 → 爆发 → 短暂平静] × N
每个循环升级一个量级
```

### 适用
- 系统流、升级流、逆袭流
- 长篇连载

### 循环单元模板
| 阶段 | 字数占比 | 内容 |
|------|---------|------|
| 压制 | 30% | 新敌人/新困难出现，主角受挫 |
| 蓄力 | 20% | 获得新能力/新信息/新盟友 |
| 爆发 | 30% | 碾压/反杀/打脸 |
| 平静 | 20% | 收获奖励、铺设下一循环伏笔 |

---

## 四、洋葱剥皮式

```
表层谜题 → 解开 → 更深谜题 → 解开 → 核心真相
每层剥开都改变读者对故事的理解
```

### 适用
- 悬疑、推理、阴谋文

---

## 五、双线交织式

```
A线（现在）：正在发生的事件
B线（过去/另一视角）：逐步揭露的真相
关键节点两线交汇
```

### 适用
- 复仇文、真相揭露文、双视角文

---

## 六、选型速查

| 条件 | 推荐结构 |
|------|---------|
| 短篇 + 反转 | 三幕式 |
| 长篇 + 升级爽文 | 螺旋升级式 |
| 长篇 + 多线 | 五幕式 |
| 悬疑 | 洋葱剥皮式 |
| 复仇/真相 | 双线交织式 |
| 长篇 + 爽文 + 世界观 | 五幕式 + 螺旋升级式混合 |
