# 角色设计规范

> 引擎B·角色引擎核心文档。规范角色设计的标准流程与质量要求。

---

## 一、角色设计四层模型

### 第一层：基础层
- 姓名、年龄、身份
- 外在标签（3-5个视觉/行为标签）
- 核心性格（2-3个关键词）

### 第二层：动力层
- **欲望**：他最想要什么？
- **缺口**：他缺什么？（与欲望形成张力）
- **恐惧**：他最怕什么？
- **底线**：他绝不会做什么？

### 第三层：功能层
- 在故事中承担什么叙事功能？
- 与主角的关系动力是什么？
- 如果删掉这个角色，故事会损失什么？

### 第四层：弧线层
- 起点状态 → 关键转折 → 终点状态
- 变化的内在驱动力是什么？

---

## 二、主角设计标准

### 必须有
1. 明确的欲望（想要什么）
2. 明确的缺口（缺什么）
3. 明确的外在障碍（谁/什么在阻止他）
4. 明确的内在障碍（自身的弱点/恐惧）
5. 成长空间（从A到B的变化路径）

### 禁止
- 完美无缺的主角（无缺口=无成长空间）
- 被动等待的主角（必须有主动行为）
- 没有底线的主角（底线是人设锚点）

---

## 三、反派设计标准

### 好反派的标准
1. 有自己的逻辑（不为恶而恶）
2. 有足够的实力（能真正威胁主角）
3. 与主角形成镜像或对比
4. 有自己的欲望和恐惧

### 反派层级
| 层级 | 功能 | 存在时长 |
|------|------|---------|
| 炮灰 | 小试牛刀 | 1-3章 |
| 阶段反派 | 阶段性危机 | 5-15章 |
| 核心反派 | 贯穿全书 | 全书 |
| 隐藏反派 | 真相震撼 | 后半段揭露 |

---

## 四、配角功能表

每个配角必须承担至少一个功能：

| 功能 | 说明 |
|------|------|
| 镜像 | 映射主角的另一种可能 |
| 催化 | 推动主角做出关键决定 |
| 信息 | 提供关键情报或线索 |
| 情感锚 | 让读者共情的载体 |
| 对比 | 凸显主角特质 |
| 工具 | 提供特定能力或资源 |

- [ ] 主角是否有欲望和缺口？
