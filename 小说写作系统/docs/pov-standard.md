# 视角规范

> 引擎C·文笔引擎核心文档。规范叙述视角的选择、控制与切换。

---

## 一、视角类型

| 视角 | 特征 | 适用 |
|------|------|------|
| 第一人称 | "我"叙述，代入感强 | 番茄短篇、情感文、悬疑 |
| 第三人称限制 | 跟随一个角色 | 长篇连载、玄幻、都市 |
| 第三人称全知 | 上帝视角 | 群像文、史诗文 |
| 多视角 | 不同章节不同视角 | 悬疑、多线叙事 |

---

## 二、选型建议

| 平台/类型 | 推荐视角 |
|-----------|---------|
| 番茄短篇 | 第一人称 |
| 番茄长篇 | 第一人称 或 第三人称限制 |
| 起点男频 | 第三人称限制 |
| 起点女频 | 第一人称 或 多视角 |
| 悬疑推理 | 第一人称 或 多视角 |

---

## 三、叙述距离

| 距离 | 效果 | 适用 |
|------|------|------|
| 极近 | 意识流、极强代入 | 关键抉择、情感高潮 |
| 近 | 角色感受+行为 | 大部分正文 |
| 中 | 客观+适度内心 | 日常推进 |
| 远 | 纯客观旁观 | 大场面、转场 |

---

## 四、信息管控规则

1. 限制视角下：读者知道的 = 视角角色知道的
2. 角色不能知道不该知道的事
3. 已揭露的信息必须被正确引用
4. 同一信息不重复交代

---

## 五、多视角切换规范

1. 每次切换有明确标记
2. 切换后第一段明确当前视角
3. 不同视角的叙述风格有区分
4. 切换频率不宜过高（建议每章一个视角）

---

## 六、视角自检

- [ ] 全篇视角是否一致？
- [ ] 是否存在上帝视角泄露？
- [ ] 叙述距离变化是否有过渡？
- [ ] 多视角切换是否有标记？
