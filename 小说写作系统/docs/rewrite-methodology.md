# 改稿方法论

## 一、改稿顺序

改稿不要乱改，按以下顺序：

1. 先改结构
2. 再改章节节奏
3. 再改人物一致性
4. 最后改句子与措辞

---

## 二、优先改四个位置

1. 开头 500 字
2. 每章结尾钩子
3. 最大反转段
4. 最后一段回响

---

## 三、局部返工原则

出现问题时，优先局部回流：

- 钩子弱 → 重写开头与章尾
- 人设漂 → 重修相关章节对话与行为
- 逻辑断 → 补埋伏笔或调整桥段顺序
- 结尾虚 → 单独重写结尾 300~800 字

---

## 四、不要做的事

- 不带目标地通篇润色
- 不用更华丽的句子掩盖结构问题
- 不为保留原句而牺牲节奏
