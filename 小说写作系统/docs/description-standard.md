# 描写规范

> 引擎C·文笔引擎核心文档。规范环境、动作、心理描写的质量标准。

---

## 一、核心原则

**描写必须服务于叙事。** 不服务于叙事的描写就是废描写。

描写的四种功能：
1. 映射情绪
2. 制造氛围
3. 提供信息
4. 推动剧情

---

## 二、五感写作

每个重要场景至少调动 3 种感官：

| 感官 | 常用元素 | 示例 |
|------|---------|------|
| 视觉 | 光影、色彩、动态 | "路灯把他的影子拉得很长" |
| 听觉 | 声响、节奏、沉默 | "雨打在铁皮屋顶上" |
| 触觉 | 温度、质感、疼痛 | "金属把手冰得刺骨" |
| 嗅觉 | 气味、空气质感 | "空气里有血腥味" |
| 味觉 | 口感、生理反应 | "嘴里泛起铁锈般的腥甜" |

---

## 三、描写密度控制

| 场景类型 | 密度 | 字数参考 |
|---------|------|---------|
| 动作/打斗 | 低 | 0-1句环境 |
| 氛围建立 | 高 | 2-4句五感 |
| 日常推进 | 中低 | 1-2句穿插 |
| 情感高潮 | 中 | 环境映射情绪 |
| 转场 | 极低 | 一句带过 |

---

## 四、动作描写

### 写受力结果，不写过程分解
- ❌ "他抬起右手，握紧拳头，手臂向后拉，然后猛地向前挥出。"
- ✅ "一拳砸下去，桌面裂了一条缝。"

### 三要素
1. 动作本身
2. 受力结果
3. 旁观反应

---

## 五、心理描写

### 层次递进法
```
生理反应 → 本能反应 → 理性判断 → 决定
```

### 四种方式
| 方式 | 适用 |
|------|------|
| 内心独白 | 第一人称、关键抉择 |
| 微表情/微动作 | 第三人称、不想暴露内心 |
| 环境投射 | 任何视角 |
| 生理反应 | 强烈情绪 |

---

## 六、禁止事项

- 与剧情无关的纯风景描写
- 超过5行的连续环境描写
- 华丽辞藻堆砌但无信息量
- 用描写代替动作推进剧情
