## 一、情节线梳理

### 主线：系统绑定 → 能力获取 → 副作用社死 → 被迫卷入碎片世界

**推进路径**：
1. **Ch1-4**：裁员危机 → 系统强制绑定 → 读心术激活 → 小缺登场
2. **Ch5-10**：读心术社死日常 → 第一个系统任务 → 救人（老唐）
3. **Ch11-18**：副作用初现（被遗忘机制）→ 世界观碎片 → 隐藏任务 → 获得瞬移
4. **Ch19-30**：鸡腿事件 → 社死升级 → 被跟踪（周燃）→ 裁员 → 失业
5. **Ch31-40**：新住处 → 重遇老唐 → 透视激活 → 废品站地下室 → 投屏事件
6. **Ch41-55**：被周燃追杀 → 第一次战斗 → 老唐指导 → 能力转化（心声干涉）
7. **Ch56-68**：周燃再战 → 三方混战（冰面）→ 冰面被遗忘
8. **Ch69-80**：老唐恐惧 → 苏念正式接触 → 能力集体进化 → 卷末悬念

## 二、场景序列

### 段落一：社死开端（Ch1-30，约9.6万字）

**场景组1：裁员日常（Ch1-3）**
- S1：林默工位，收到裁员通知邮件 → 压抑（困境第一层）
- S2：公司走廊，被同事当空气 → 孤独感递进
- S3：下班路上，手机疯狂弹窗 → 不安→恐慌
- S4：出租屋，试图各种方式关弹窗 → 焦虑→绝望
- *状态变化*：普通人 → 被系统盯上的人

**场景组2：系统绑定（Ch4-7）**
- S5：出租屋，系统强制绑定，小缺登场 → 崩溃+喜剧（小缺毒舌）
- S6：第二天早上，到公司 → 紧张
- S7：办公室，读心术自动激活 → 喜剧爆发（内心吐槽弹幕）
- S8：茶水间，偷听同事八卦 → 喜剧+孤独加深
- S9：下班，发现关不掉 → 焦虑
- *状态变化*：被动受害者 → 被迫使用能力的人

**场景组3：第一个任务（Ch8-12）**
- S10：出租屋，发现系统商城+任务面板 → 好奇+紧张
- S11：3公里外，赶去救人 → 紧张（倒计时30分钟）
- S12：路边，推开受害者 → 释然+困惑
- S13：医院门口，老唐完全不记得他 → 震惊（副作用初现）
- S14：出租屋，小缺科普碎片/持有者 → 世界观扩容
- *状态变化*：好奇的体验者 → 意识到危险的人

**场景组4：日常社死+隐藏任务（Ch13-18）**
- S15：公司日常，读心术持续社死 → 喜剧+孤独
- S16：出租屋，发现差评计数+隐藏任务 → 升级期待
- S17：下班路上，路过"半杯"咖啡店 → 伏笔（苏念微笑）
- S18：出租屋，隐藏任务完成→瞬移激活 → 喜剧铺垫
- S19：出租屋，瞬移测试（传到隔壁老王浴室） → 喜剧
- *状态变化*：被动的体验者 → 开始主动探索能力的人

**场景组5：鸡腿事件+危机升级（Ch19-26）**
- S20：公司，瞬移拿东西→鸡腿视频会议 → 喜剧最高峰
- S21：公司，"鸡腿哥"火了 → 尴尬+社死升级
- S22：公司，差评加速+裁员倒计时 → 紧张
- S23：出租屋，小缺警告"有东西在靠近" → 恐惧
- S24：街道，感觉被跟踪→读心听到"就是他" → 恐慌
- S25：公司楼下，周燃出现盯着看三秒 → 极度不安
- S26：城市各处，调查周燃的"猎场" → 紧张+悬疑
- *状态变化*：觉得系统是好玩的 → 意识到有人在猎杀自己

**场景组6：裁员+失业（Ch27-30）**
- S27：出租屋，系统升级提示 → 升级期待+裁员倒计时
- S28：公司HR办公室，被约谈 → 压抑
- S29：公司工位，收拾东西→没人在意 → 情感最低谷
- S30：公司宿舍→街头，搬出+找新住处+人才市场 → 喜剧缓冲
- *状态变化*：有工作的社畜 → 失业的透明人

### 段落二：能力扩展（Ch31-55，约8万字）

**场景组7：新住处+废品站（Ch31-37）**
- S31：城东出租屋，发现房租便宜得离谱 → 疑惑
- S32：楼下废品站，又遇到老唐 → 惊喜+疑惑
- S33：废品站，老唐透露自己15年前是持有者 → 世界观大扩容
- S34：废品站，碎片共鸣→透视触发 → 能力获取
- S35：废品站，第一次透视→看到地下有东西 → 悬疑
- S36：地下室，老唐的"情报室" → 世界观炸弹
- S37：地下室，老唐讲述47个失踪持有者 → 震撼
- *状态变化*：无家可归的透明人 → 找到据点+导师的持有者

**场景组8：透视副作用+周燃追杀（Ch38-47）**
- S38：出租屋，系统商城详解+透视副作用说明 → 系统
- S39：废品站，透视测试（投影到对面楼） → 喜剧铺垫
- S40：公司附近，透视失控投屏全公司大屏 → 喜剧最高峰
- S41：出租屋，被当黑客+上热搜 → 恐慌
- S42：城东街道，周燃追踪到林默 → 紧张升级
- S43：废弃工厂，周燃自我介绍+展示能力 → 恐惧（碾压级实力）
- S44：整条街，情绪操控展示→人群恐慌 → 战斗+世界观
- S45：城市各处，疯狂瞬移逃跑+社死（澡堂/女厕所/网红面前） → 喜剧+紧张
- S46：澡堂/直播现场，连续社死名场面集锦 → 喜剧高峰
- S47：废品站附近，老唐帮甩掉周燃 → 情感+战术
- *状态变化*：觉得自己在变强 → 被碾压的弱者（认知重置）

**场景组9：能力转化+修炼（Ch48-55）**
- S48：废品站，透视发现周燃弱点（绷带下什么都没有） → 战斗转折
- S49：废品站，发现周燃身体"消失"→悲剧人物 → 情感深化
- S50：出租屋，差评破千 → 升级倒计时
- S51：出租屋，心声干涉激活→第一次影响别人想法 → 能力质变
- S52：街道，测试心声干涉（路人唱天气歌） → 喜剧
- S53：出租屋，心声干涉副作用（被迫说真心话） → 喜剧+社死
- S54：废品站，老唐教控制能力+隐藏技巧 → 导师指导
- S55：地下室，三种能力组合训练 → 战斗力提升
- *状态变化*：被碾压的弱者 → 有反击能力的持有者

### 段落三：猎手来袭（Ch56-80，约8万字）

**场景组10：第二次战斗（Ch56-61）**
- S56：城东街道，周燃再上门直接动手 → 紧张最高点
- S57：废弃建筑工地，三能力组合战被碾压 → 绝望
- S58：工地，心声干涉制造"犹豫"→周燃失误 → 转折
- S59：工地，捕捉到周燃内心"有人……在帮……我？" → 情感震撼
- S60：工地，周燃犹豫→林默瞬移逃跑 → 缓冲
- S61：废品站，复盘战斗分析周燃弱点 → 战术升级
- *状态变化*：恐惧敌人 → 理解敌人+找到战术

**场景组11：三方混战（Ch62-68）**
- S62：废品站，周燃再来→目的改变（临时合作） → 悬念
- S63：城东街道，周燃提出合作→第三个持有者 → 紧张+好奇
- S64：商场附近，冰面登场（冻结能力） → 新角色引入
- S65：商场内部，冰面失控冻结整个商场 → 危机
- S66：商场，林默+周燃临时合作解救 → 高潮（并肩作战）
- S67：商场外，冰面碎片被"什么东西"吸走 → 悬疑炸弹
- S68：医院，冰面被遗忘——更快更彻底 → 震撼+恐惧
- *状态变化*：孤独战斗 → 有了临时盟友（但盟友不稳定）

**场景组12：缓冲+进化+卷末（Ch69-80）**
- S69：废品站，老唐看到冰面消失露出恐惧 → 悬疑
- S70：半杯咖啡店，林默躲进咖啡店→苏念倒咖啡 → 情感缓冲
- S71：咖啡店，苏念和林默第一次正式对话 → 暗线启动
- S72：废品站，周燃第一次讲过去 → 情感深化
- S73：出租屋，小缺第一个创可贴松动 → 伏笔
- S74：出租屋，发现系统被监视 → 反派暗示
- S75：出租屋，小缺泄露"组织"信息 → 世界观
- S76-78：废品站/出租屋/街道，三种能力集体进化 → 升级高潮
- S79：废品站附近，三能力合一组合战演练 → 战斗力质变
- S80：废品站天台，周燃放弃碎片+小缺泄露"上一个选中者消失了" → 终极悬念
- *状态变化*：被动的透明人 → 主动的持有者（知道自己在对抗什么，虽然还很弱）
