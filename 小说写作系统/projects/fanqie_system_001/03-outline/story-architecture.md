# 故事骨架（320万字版）

## 一句话主轴

林默从「世界最透明的人」到「选择被所有人遗忘来修复世界」，核心驱动力是在社死的荒诞中找到自己存在的意义。

---

## 结构模式

**螺旋升级式 + 单元副本式 + 双线交织**

- **螺旋升级**：每个能力循环（获得→副作用社死→积累→转化→新能力），全书15+个能力
- **单元副本**：每1-2卷嵌入一个独立"副本"（城市/组织/事件），提供新鲜感和节奏缓冲
- **双线交织**：
  - A线（喜剧日常）：社畜生活 + 系统副作用的搞笑应用
  - B线（悬疑主线）：系统碎片争夺 + 织网者阴谋 + "被遗忘"真相

> **选型理由**：《大奉打更人》的核心成功要素是"单元副本+主线推进"交替。番茄320万字长篇必须用此模式，否则后期纯主线会疲劳。
