# 质量基线

> Chief-Editor 建立于 P1 阶段，贯穿全书质量把控。

## 质量目标

| 维度 | 目标值 | 说明 |
|------|--------|------|
| 爽点密度 | 每3章至少1个爽点 | 副作用转化 = 爽点，社死逆袭 = 爽点 |
| 钩子密度 | 每章≥1个章尾钩子 | "下次副作用是什么"天然钩子 |
| 笑点密度 | 每1000字≥1个笑点 | 吐槽+社死+反差三引擎 |
| 节奏基速 | 快（番茄标准） | 段落1-3行，对话密集，环境描写克制 |
| 悬疑线推进 | 每5章推进一次 | 系统碎片/组织/完整系统之谜 |
| 人设立住 | 前10章内 | 主角标签：佛系外表+吐槽内心+被迫卷入 |

## 角色人设标准

- **林默（主角）**：不是圣母，不是莽夫。表面佛系躺平，内心吐槽弹幕不断。被逼到极限才会爆发，爆发方式自带喜剧效果。核心驱动力从"想退货"→"想保护身边的人"→"想弄清系统真相"。
- **反派/对手**：每个系统持有者都有自己的"副作用"和"执念"，不是脸谱化反派。

## 副作用设计铁律

1. 副作用必须具体、可视化、能引发笑点（不能是"消耗精神力"这种抽象代价）
2. 副作用必须与正面效果形成极致反差（能力越强，副作用越社死）
3. 副作用的转化条件必须是"痛苦的积累"（越惨越强，读者替主角委屈→然后看到转化，情绪过山车）
4. 每个副作用至少设计3种搞笑使用场景（单元剧素材）
5. 后期副作用开始变得"沉重"，喜剧色调逐渐加入悬疑和情感

## 节奏规划

```
前期（1-30章）：纯喜剧+世界观建立
  - 密集笑点，快速吸引读者
  - 每3-5章一个新能力+新副作用=一个完整搞笑单元
  - 章尾钩子 = 下一个副作用预告

中期（31-80章）：喜剧+悬疑交替
  - 笑点密度略降，悬疑线加强
  - 其他系统持有者登场，能力碰撞
  - "副作用可转化"机制首次揭示

后期（81章+）：喜剧外壳+严肃内核
  - 笑点保留但穿插情感和牺牲
  - 完整系统之谜揭开
  - 副作用成为终极武器
```

## 禁区

- ❌ 不写无意义的装逼打脸（不同于一般系统文）
- ❌ 不写后宫/暧昧拖沓（感情线简洁明快）
- ❌ 不写大段世界观设定说明（通过剧情展示，不通过旁白解释）
- ❌ 副作用不能重复使用同一个笑点模式超过3次
- ❌ 不能让主角在任何一次冲突中"轻松解决"——必须付出社死代价
