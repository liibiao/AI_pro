调用链路

当前上线架构的关键路径，排查问题时按这个顺序定位。

用户浏览器 打开画布页面，登录后发起文生图、图生图、视频或账户请求。
主平台 Nginx 公网入口 124.156.137.236，转发静态页面和 /api 请求。
主平台 API Node 服务 127.0.0.1:4000，处理登录、积分扣费、任务和模型路由。
日本中转站 CLIProxyAPI 43.165.186.217/v1，仅允许主平台服务器调用。
上游模型 通过 CPAMC/OAuth 维护上游账号认证，返回图片、视频或模型响应。

模型配置检查

数据库
主平台服务器 api-server 目录执行 
cd /var/www/ai-admin/ai-admin-platform/api-server
psql "$DB_URL" -x -c "
select
  m.id,
  m.display_name,
  m.name,
  m.type,
  m.adapter,
  m.status,
  p.provider_key,
  p.base_url,
  p.default_model,
  p.status as provider_status
from ai_models m
join upstream_providers p on p.id = m.provider_id
where m.display_name ilike '%GPT-Image%';
"
