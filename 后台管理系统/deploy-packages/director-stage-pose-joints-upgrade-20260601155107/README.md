# director-stage-pose-joints-upgrade-20260601155107

升级 `3D导演台` 的人物骨骼精度、姿态库和关节拖拽能力。

## 内容

- 将角色骨架扩展为 32 个可编辑关节：根节点、骨盆、两段脊柱、胸腔、颈部、头顶、锁骨、肩肘腕掌指、髋膝踝脚跟脚尖。
- 姿态库扩展到 15 个预设：站立、坐姿、行走、奔跑、半蹲、低蹲、指向、对话、伸手、挥手、抱物、前倾、躺卧、仰头、低头。
- 新增 `骨` 工具：选择角色后可在属性面板选择具体关节，也可在画布里点选关节点。
- 关节可通过 TransformControls 自由拖拽，拖拽后自动写入角色 `joints` 数据，并实时更新相连骨段。
- 切换姿态预设时会清空该角色的自定义关节，回到预设姿势；输出提示词会标记自定义关节数量。
