PERSONAL OPEN API

个人 API 接入文档

从画布账户设置生成个人 API Key 后，即可调用 /api/open/personal/* 创建和查询生成任务。扣当前个人账号余额，会员 / 体验卡折扣实时生效。

开始接入
1

接入流程

入口画布 → 账户设置 → 个人 API 接入 → 创建 API Key。明文 Key 只展示一次，请立即复制保存。
2

鉴权方式

HTTP Header 
Authorization: Bearer sk_live_xxx
Content-Type: application/json
3

接口列表

能力方法URL
创建生成任务POST/api/open/personal/generation/tasks
查询任务列表GET/api/open/personal/generation/tasks?limit=100
查询任务详情GET/api/open/personal/generation/tasks/:id
主动刷新任务POST/api/open/personal/generation/tasks/:id/query
4

创建生成任务

cURL 示例 
curl -X POST "__BASE__/api/open/personal/generation/tasks" \
  -H "Authorization: Bearer sk_live_xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "channelKey": "gpt-image",
    "modelId": "model_image_xxx",
    "type": "IMAGE",
    "mode": "txt2img",
    "prompt": "一只赛博朋克风格的猫",
    "negativePrompt": "",
    "inputFiles": [],
    "params": { "size": "1024x1024", "quantity": 1 },
    "clientRequestId": "client_order_001"
  }'

请求体参数表

字段必填类型穷举说明
channelKey是string渠道 Key，不能为空。
modelId是string模型 ID / modelKey / 模型名，不能为空。
type是"IMAGE" | "VIDEO" | "LLM"生成类型。
mode是string生成模式，如 txt2img、img2img、text2video。
prompt是string正向提示词，不能为空。
negativePrompt否string反向提示词。
inputFiles否array默认 []，元素可为 URL 字符串或对象。
params否object默认 {}，值可为 string / number / boolean / array / object / null。
clientRequestId否string幂等 ID，长度 1-160。

params 常见字段类型

字段示例类型穷举说明
sizestring图片尺寸。
width / heightnumber宽高。
quantitynumber生成数量。
seednumber | string随机种子。
referenceImagesarray参考图数组。
durationnumber | string视频时长。
fpsnumber视频帧率。
任意扩展字段string | number | boolean | array | object | null是否生效取决于模型适配器。
5

响应体参数表

字段类型穷举说明
okboolean成功为 true。
taskobject任务对象。
chargedCreditsnumber本次预扣积分。
balancenumber | undefined扣费后余额。
task.idstring任务 ID。
task.type"IMAGE" | "VIDEO" | "LLM"生成类型。
task.status"CREATED" | "PENDING" | "RUNNING" | "SUCCESS" | "FAILED"任务状态。
task.resultJsonobject | array | string | number | boolean | null生成结果详情。
task.resultUrlsJsonarray | null结果资源 URL。
task.errorCodestring | null错误码。
task.errorMessagestring | null错误信息。
task.progressnumber | null进度，常见 0-100。
task.createdAt / updatedAt / startedAt / completedAt / failedAtstring | nullISO 时间字符串。
task.modelobject | undefined查询接口可能返回模型信息。
task.providerobject | undefined查询接口可能返回渠道信息。
6

查询接口

查询详情 
curl "__BASE__/api/open/personal/generation/tasks/task_xxx" \
  -H "Authorization: Bearer sk_live_xxx"
主动刷新 
curl -X POST "__BASE__/api/open/personal/generation/tasks/task_xxx/query" \
  -H "Authorization: Bearer sk_live_xxx"
字段类型穷举说明
limitnumber | string列表数量，默认 100，最大 300。
idstring路径中的任务 ID。
itemsarray任务列表数组。
refundobject | null | undefined刷新失败任务时可能返回退款信息。
7

错误码

code含义处理方式
OPEN_API_TOKEN_REQUIRED缺少个人 API Key检查 Authorization。
OPEN_API_TOKEN_INVALIDKey 无效或已禁用重新创建 / 复制 Key。
USER_DISABLED账号已禁用联系管理员。
INSUFFICIENT_BALANCE余额不足充值后重试。
PROVIDER_NOT_FOUND渠道不可用检查 channelKey。
MODEL_NOT_FOUND模型不可用检查 modelId / type。
GENERATION_TASK_NOT_FOUND任务不存在或无权访问确认任务属于当前账号。
8

安全说明

重要不要把 API Key 写到公开网页、GitHub、截图或聊天群。怀疑泄露后，请立即禁用并重新创建。
