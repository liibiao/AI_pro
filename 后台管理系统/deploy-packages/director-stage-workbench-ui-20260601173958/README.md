# director-stage-workbench-ui-20260601173958

重构 `3D导演台` 节点的 UI 结构：节点只保留简略预览，完整编辑能力收拢到固定大图操作台。

## 内容

- 节点改为轻量预览卡片：3D 预览、当前机位、背景、选中对象、角色/道具/机位/截图统计。
- 新增固定全屏详情操作台：原有场景库、背景导入、角色/道具/机位、骨骼姿态、截图、属性面板全部保留在操作台内。
- 节点预览 surface 与操作台 surface 分离，二者共享同一份 `n.values`，操作台编辑后会同步刷新节点预览。
- 节点预览不再挂 TransformControls，避免在节点内误触骨骼/变换控件；拖拽编辑只在大操作台里发生。
- 场景库弹层层级提高，确保从大操作台打开时显示在操作台之上。
