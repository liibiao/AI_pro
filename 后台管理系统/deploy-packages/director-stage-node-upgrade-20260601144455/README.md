# director-stage-node-upgrade-20260601144455

升级 `3D导演台` 节点首版人偶与操作能力。

## 内容

- 将角色从简单圆柱占位升级为分段关节人偶：头、胸、骨盆、肩、肘、腕、髋、膝、踝、脚部均有清晰结构。
- 姿态库升级为关键点骨架：站立、坐姿、行走、半蹲、指向、对话。
- 增加角色朝向箭头和脚底选中参考环，便于看清面向和站位。
- 增加 `+10人`、复制当前对象、聚焦对象、道具预设、更新机位、进入机位。
- 道具从单方块升级为更清晰的沙发、桌子、床、墙体等组合代理模型。
- 属性面板补充颜色、动作备注、机位目标点和 FOV。
