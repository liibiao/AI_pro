# director-stage-64joints-scene-library-20260601163911

升级 `3D导演台` 的人物模型精度与场景资产导入。

## 内容

- 人物骨架从 32 个关节点扩展到 64 个关节点，增加面部、躯干侧点、手部、上下肢中段和脚掌细节。
- 模型外形升级为更接近导演台参考的人体蓝色实体模型：椭圆头部、下颌/鼻梁/眼眉/嘴角/耳部、胸腹骨盆体块、肩肘膝踝球形关节、上下肢胶囊体块和脚部体块。
- 保留 `骨` 工具和关节拖拽，64 个关节都可从属性面板选择并通过 TransformControls 调整。
- 新增导演台内 `场景库`，读取现有资产库图片/本地图片/画布资产，点击即可导入成导演台实景背景。
- 支持把资产库图片或本地图片直接拖入导演台视口作为背景；全局资产库导入候选也增加 `3D导演台`。
