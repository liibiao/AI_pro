# 积分消费比例方案

## 基础比例

```text
1 分钱 = 1 积分
1 元 = 100 积分
```

用户侧所有扣费都用整数积分；平台成本允许小数积分，用于后台毛利核算。

## 出图模型

| 档位 | 用户扣积分 | 用户付费 | 平台成本 | 毛利 |
| --- | ---: | ---: | ---: | ---: |
| 1K | 5 | 0.05 元 | 0.035 元 | 30% |
| 2K | 8 | 0.08 元 | 0.056 元 | 30% |
| 3K | 25 | 0.25 元 | 0.175 元 | 30% |
| 4K | 50 | 0.50 元 | 0.350 元 | 30% |

计费公式：

```text
扣积分 = 分辨率档位积分 * 生成张数
平台成本 = 扣积分 * 70%
```

分辨率识别优先级：

```text
resolution -> requestedResolution -> imageSize -> size -> requestedPixelSize -> quality
```

未传档位时按 `1K` 计费。

## 视频模型

| 档位 | 用户扣积分 | 用户付费 | 平台成本 | 毛利 |
| --- | ---: | ---: | ---: | ---: |
| 视频 | 36 / 秒 | 0.36 元 / 秒 | 0.252 元 / 秒 | 30% |

计费公式：

```text
扣积分 = 视频秒数 * 36
平台成本 = 视频秒数 * 25.2
```

## 语言模型

语言模型仍按 token 对应的上游美元成本换算积分：

```text
扣积分 = ceil(上游成本美元 * creditsPerUsdCost * markupRate)
```

当前约定：

```text
gpt-5.4：20 积分 / 1 美元上游成本
gpt-5.5：80 积分 / 1 美元上游成本
```

## 会员

```text
正式月度会员：29 元 / 月 = 2900 积分 / 30 天
内测体验阶段：月度会员暂设 0 积分
```

上线收费时，把 `月度会员` 套餐价格从 `0` 改为 `2900` 即可。
