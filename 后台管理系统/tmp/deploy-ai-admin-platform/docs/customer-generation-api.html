个人 / 企业 API 对接文档

如果你不会写代码，只要按下面 4 步走：创建 Token → 复制 Token → 复制示例代码 → 替换提示词并运行。

开始接入
个人 API用个人 API Key 调用，扣个人钱包，会员折扣实时生效。
企业 API用企业 Token 调用，扣企业钱包，默认按 VIP 4 折计费。
安全设计Token 明文只展示一次，服务端只保存 Hash，不暴露上游密钥。
1

小白接入流程

进入入口
个人用户：画布 / 后台账户中心 → API 接入。企业用户：超级管理员后台 → 企业 API 管理。
创建并复制 Token
创建后立刻复制保存，关闭弹窗后不会再显示明文。
选择接口前缀
个人用 /api/open/personal/*，企业用 /api/open/enterprise/*。
复制示例代码运行
把示例里的 sk_live_xxx 或 ent_live_xxx 替换成自己的 Token。
2

Token 获取与复制

请求头固定写法：

HTTP Header 
Authorization: Bearer 你的Token
Content-Type: application/json
3

个人 API

能力说明
创建任务POST /api/open/personal/generation/tasks
查询列表GET /api/open/personal/generation/tasks?limit=100
查询详情GET /api/open/personal/generation/tasks/:id
主动刷新POST /api/open/personal/generation/tasks/:id/query

扣费 扣个人钱包；账号状态、余额、会员 / 体验卡折扣实时生效。

4

企业 API

能力说明
创建任务POST /api/open/enterprise/generation/tasks
查询列表GET /api/open/enterprise/generation/tasks?limit=100
查询详情GET /api/open/enterprise/generation/tasks/:id
主动刷新POST /api/open/enterprise/generation/tasks/:id/query

扣费 扣企业钱包；企业无需购买会员，固定按 VIP 4 折计费。

5

创建生成任务

cURL 示例

个人接口：把 Token 换成自己的 
curl -X POST "__BASE__/api/open/personal/generation/tasks" \
  -H "Authorization: Bearer sk_live_xxx" \
  -H "Content-Type: application/json" \
  -d '{
    "channelKey": "gpt-image",
    "modelId": "model_image_xxx",
    "type": "IMAGE",
    "mode": "txt2img",
    "prompt": "一只赛博朋克风格的猫",
    "negativePrompt": "",
    "inputFiles": [],
    "params": { "size": "1024x1024", "quantity": 1 },
    "clientRequestId": "client_order_001"
  }'

JavaScript 示例

浏览器 / Node.js 
const res = await fetch('__BASE__/api/open/personal/generation/tasks', {
  method: 'POST',
  headers: {
    Authorization: 'Bearer sk_live_xxx',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    channelKey: 'gpt-image',
    modelId: 'model_image_xxx',
    type: 'IMAGE',
    mode: 'txt2img',
    prompt: '一只赛博朋克风格的猫',
    negativePrompt: '',
    inputFiles: [],
    params: { size: '1024x1024', quantity: 1 },
    clientRequestId: 'client_order_001'
  })
});
const data = await res.json();
console.log(data.task.id, data.task.status);

Python 示例

requests 
import requests

res = requests.post(
    '__BASE__/api/open/personal/generation/tasks',
    headers={
        'Authorization': 'Bearer sk_live_xxx',
        'Content-Type': 'application/json'
    },
    json={
        'channelKey': 'gpt-image',
        'modelId': 'model_image_xxx',
        'type': 'IMAGE',
        'mode': 'txt2img',
        'prompt': '一只赛博朋克风格的猫',
        'negativePrompt': '',
        'inputFiles': [],
        'params': {'size': '1024x1024', 'quantity': 1},
        'clientRequestId': 'client_order_001'
    }
)
print(res.json())

常见错误码

code小白解释处理方式
OPEN_API_TOKEN_REQUIRED没传个人 Token检查 Authorization 请求头
OPEN_API_TOKEN_INVALID个人 Token 错误或被禁用重新创建 / 复制 Token
ENTERPRISE_API_TOKEN_INVALID企业 Token 错误或被禁用联系管理员检查企业 Token
INSUFFICIENT_BALANCE余额不足充值后重试
MODEL_NOT_FOUND模型不可用或 ID 写错检查后台模型配置
GENERATION_TASK_NOT_FOUND任务不存在或无权限确认任务 ID 和 Token 是否属于同一账号
8

安全说明

重要不要把 Token 写到公开网页、GitHub、截图或聊天群。Token 泄露后别人可以消耗你的余额；如怀疑泄露，请立即禁用并重新创建。
