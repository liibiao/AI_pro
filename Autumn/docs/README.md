## 使用建议

- 需求评审先看产品需求文档和界面交互与布局文档。
- 技术方案评审先看前端技术架构与技术选型。
- 排期和任务拆分参考开发计划实施方案。
- 代码开发和 Code Review 参考开发架构与编码规范设计文档。
- Agent 持续开发、任务跟进、日志、记忆和验收参考软件工程师 Agent 系统。
- 多角色协作、总架构师调度、产品/架构/前端/后端/测试/UI/项目管理流水线参考多 Agent 软件开发流水线。
