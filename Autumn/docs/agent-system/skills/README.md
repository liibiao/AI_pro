# Autumn Skill System

本目录定义 Autumn 项目专用 Skill 系统，用于让软件工程师 Agent 按固定方式开发和维护项目。

## 当前 Skill

- [autumn-software-engineer](./autumn-software-engineer/SKILL.md)：Autumn 项目总控工程 Skill，覆盖需求拆解、架构守护、任务开发、进度日志、记忆维护和验收。

## Skill 分类规划

| Skill | 职责 | 状态 |
| --- | --- | --- |
| autumn-software-engineer | 总控工程流程 | 已落地 |
| requirement-breakdown | 需求拆解为任务 | 规划中 |
| architecture-guard | 架构分层和依赖检查 | 规划中 |
| frontend-implementation | 前端模块实现 | 规划中 |
| api-integration | 后台接口和 DTO adapter | 规划中 |
| state-sync | Zustand 多模块联动 | 规划中 |
| qa-acceptance | 测试和验收 | 规划中 |
| engineering-memory | 项目记忆维护 | 规划中 |

## 使用方式

在处理 Autumn 相关开发时，先读取总控 Skill，再按任务类型读取对应参考文档。
