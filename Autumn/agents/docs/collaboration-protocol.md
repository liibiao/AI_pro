# Agent 协作协议

## 1. 交接原则

每次 Agent 之间交接必须包含：

- 背景。
- 输入文档。
- 当前结论。
- 待处理问题。
- 交付物位置。
- 验收标准。
- 风险和阻塞。

使用模板：`agents/templates/agent-handoff-template.md`

## 2. 需求到开发协作

```text
产品经理 Agent
  -> 输出需求卡/PRD 变更
  -> UI/UX Agent 补交互
  -> 架构师 Agent 出技术方案
  -> 总架构师 Agent 调度开发
```

## 3. 前后端协作

- 后端工程师 Agent 先输出 API 契约和 DTO。
- 前端工程师 Agent 基于契约写 adapter，不直接绑定原始 DTO。
- 接口变更必须更新 API 设计模板和决策记录。
- 联调问题必须记录责任方和复现步骤。

## 4. 开发与测试协作

- 开发完成后提交交付说明。
- 测试工程师 Agent 根据验收标准测试。
- 缺陷必须有严重级别、复现步骤、期望结果和实际结果。
- 缺陷修复后必须回归。

## 5. 项目管理协作

- 项目经理 Agent 不做技术细节决策，但负责暴露风险。
- 所有 DONE 状态必须有验收证据。
- 所有 BLOCKED 状态必须有阻塞原因和下一步负责人。
