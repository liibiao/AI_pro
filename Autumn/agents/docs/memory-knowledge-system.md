# 多 Agent 记忆与知识管理

## 1. 记忆类型

- 项目记忆：长期目标、架构原则、技术基线。
- 产品记忆：需求变更、用户反馈、竞品洞察。
- 架构记忆：ADR、模块边界、依赖规则。
- 前端记忆：组件库约定、状态联动、UI 实现注意事项。
- 后端记忆：API、数据库、错误码、权限规则。
- 测试记忆：高风险用例、历史缺陷、回归范围。
- 管理记忆：进度、阻塞、交接、阶段复盘。

## 2. 写入规则

写入记忆的信息必须满足：

- 长期有效。
- 可复用。
- 会影响后续开发。
- 已确认，不是猜测。

## 3. 存放位置

- 项目级记忆优先写入 `docs/agent-system/memory/`。
- 多 Agent 协作记忆写入 `agents/docs/` 或由项目经理 Agent 汇总。
- 重大技术决策写入 ADR 模板。

## 4. 每轮开发结束动作

项目经理 Agent 必须确认：

- 进度是否更新。
- 开发日志是否更新。
- 决策是否记录。
- 阻塞是否升级。
- 下一步是否清楚。
