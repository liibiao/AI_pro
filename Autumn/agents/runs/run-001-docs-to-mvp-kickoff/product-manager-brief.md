# 产品经理 Agent 首轮任务

## 输入

- `docs/product-requirements.md`
- `docs/ui-interaction-layout.md`

## 当前结论

MVP 以“可进入工作台、可发送指令、可产生分镜占位、可联动预览和时间线”为第一目标。

## 本轮任务

1. 将 PRD 继续维护为需求基线。
2. 后续新增需求必须先进入需求卡模板。
3. 为 Sprint 0 输出明确验收口径。
4. 标记暂缓能力，避免工程过早进入复杂功能。

## Sprint 0 产品验收

- 用户打开应用后看到真实创作工作台，而不是营销页。
- 工作台包含 TopBar、LeftPanel、CenterCanvas、RightPanel、BottomTimeline。
- 有 Mock 分镜、Mock 对话、Mock 时间线数据。
- 能表达生成中、已完成、失败等状态。
