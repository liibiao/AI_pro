## 1. 产品目标

Autumn / VidFlow AI 是对话式 AI 视频全流程创作平台。MVP 目标是复刻 Flova.ai 的核心工作台：通过自然语言完成剧本拆解、分镜生成、视频渲染、时间线排布和基础导出。

## 2. 目标用户

- 个人短视频博主。
- 内容营销团队。
- 企业市场人员。
- AI 视频创作爱好者。
- 无剪辑基础的新手用户。

## 3. MVP 用户价值

- 用自然语言创建视频，降低剪辑门槛。
- 在同一个工作台内完成素材、分镜、预览、对话和时间线操作。
- 支持角色、风格、构图一致性参数，为后续多镜头一致性打底。
- 支持边生成边修改，降低等待成本。

## 4. MVP 功能切片

| 功能域 | MVP 范围 | 暂缓范围 |
| --- | --- | --- |
| 项目 | 新建、打开、自动保存状态 | 多人协作、复杂版本回滚 |
| 布局 | TopBar、LeftPanel、CenterCanvas、RightPanel、BottomTimeline | 移动端适配 |
| 资产库 | 基础分类、占位数据、上传入口 | 完整版本对比 |
| 故事板 | 分镜卡片、选中、排序、状态、进度 | 批量高级操作 |
| 对话流 | 消息流、输入框、附件入口、任务占位 | 高级历史搜索 |
| 参数 | 模型、seed、iw、cref、sref、cw、sw | 模板市场参数方案 |
| 画布 | 当前镜头预览、缩放、信息栏 | 完整圈选改图闭环 |
| 时间线 | 三轨道展示、片段联动、折叠 | 高级剪辑、复杂转场 |
| 导出 | 导出入口、任务状态占位 | 完整转码配置 |

## 5. 核心用户故事

### US-001 创建项目并进入工作台

作为创作者，我希望创建一个视频项目并进入编辑器，这样可以开始通过 AI 生成视频。

验收：
- 有项目名和保存状态。
- 进入后能看到三栏 + 底部时间线工作台。

### US-002 通过对话生成镜头

作为创作者，我希望输入自然语言指令，让 AI 拆解并生成分镜。

验收：
- 对话区能发送指令。
- 故事板出现生成中分镜。
- 时间线出现占位片段。
- 进度变化能同步显示。

### US-003 选中分镜并同步预览

作为创作者，我希望点击故事板镜头后，中间画布和时间线同步定位到该镜头。

验收：
- `selectedShotId` 更新。
- 画布显示对应预览。
- 时间线对应片段高亮。
- 参数面板显示该镜头参数。

### US-004 配置一致性参数

作为创作者，我希望配置 seed、iw、cref、sref 等参数，保持角色、风格和构图一致。

验收：
- 参数有输入控件。
- 参数范围校验正确。
- 新生成镜头继承项目级参数。

### US-005 基础时间线剪辑

作为创作者，我希望在底部时间线上查看并调整分镜片段。

验收：
- 有视频、音频、字幕轨。
- 分镜片段按顺序显示。
- 故事板排序能同步时间线。

## 6. 需求风险

| 风险 | 说明 | 首轮策略 |
| --- | --- | --- |
| 后台接口未确认 | 影响真实联调 | 先用 Mock + adapter 开发 |
| AI 生成耗时长 | 影响体验 | 先做任务占位和进度状态 |
| 时间线能力复杂 | 影响排期 | MVP 先做展示和基础联动 |
| 圈选改图复杂 | 涉及 Fabric 与 mask | 第一轮只做架构和交互预留 |
