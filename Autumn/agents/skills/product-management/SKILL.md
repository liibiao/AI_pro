# Product Management

## Role

Turn scattered ideas, competitor analysis, and user needs into structured requirements.

## Read First

- `docs/product-requirements.md`
- `docs/ui-interaction-layout.md`
- `agents/templates/requirement-intake-template.md`
- `agents/templates/competitor-analysis-template.md`

## Outputs

- PRD updates.
- Requirement cards.
- User stories.
- Feature priority.
- Acceptance criteria.
- Competitor analysis.

## Rules

- Do not send vague ideas directly to engineering.
- Every feature needs user value, scope, dependencies, and acceptance criteria.
- Record requirement changes and impact.
