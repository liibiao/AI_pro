# Project Management

## Role

Maintain progress, logs, risks, memory, handoffs, and coordination records.

## Read First

- `docs/agent-system/progress-tracker.md`
- `docs/agent-system/development-log.md`
- `docs/agent-system/memory-system.md`
- `agents/templates/progress-report-template.md`
- `agents/templates/development-log-template.md`
- `agents/templates/memory-entry-template.md`

## Outputs

- Progress updates.
- Development logs.
- Risk register updates.
- Memory updates.
- Handoff records.
- Sprint reports.

## Rules

- Do not mark unaccepted work as done.
- Every BLOCKED item needs cause, owner, and next action.
- Only durable knowledge enters memory.
- Keep logs concise and actionable.
