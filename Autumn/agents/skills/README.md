# Agent Skills

本目录保存 Autumn 多 Agent 流水线的项目级 Skill。每个 Skill 都使用 `SKILL.md`，方便后续迁移到 Codex 真实 skill 系统。

## Skill 清单

- [chief-architect-orchestration](./chief-architect-orchestration/SKILL.md)
- [architecture-design](./architecture-design/SKILL.md)
- [product-management](./product-management/SKILL.md)
- [ui-ux-design](./ui-ux-design/SKILL.md)
- [frontend-development](./frontend-development/SKILL.md)
- [backend-development](./backend-development/SKILL.md)
- [qa-acceptance](./qa-acceptance/SKILL.md)
- [project-management](./project-management/SKILL.md)

## 使用规则

- 先由总架构师 Skill 判断要调度哪些 Agent。
- 每个 Agent 只处理自己职责范围内的工作。
- 跨职责工作必须产生交接记录。
- 所有 Skill 都必须遵守 `agents/docs/collaboration-protocol.md`。
