# 即梦精简版模板

> **用途**：即梦平台（JiMeng）直接投喂的精简提示词模板  
> **核心差异**：去 @标签、字段合并、自然语言压缩、保留台词  
> **源头**：由 Seedance 长版母稿转换而来（参考 `lingjing-integrate-skill.md`）

---

## 【转换规则速查】

| 环节 | Seedance 长版 | 即梦精简版 |
|---|---|---|
| 标签 | `@人物1（疲惫）` | `疲惫的年轻男子，黑色衬衫，短发` |
| 字段 | 主体/空间/光影/镜头/台词/音效 六段分列 | 全部合并为 1-3 段自然语言 |
| 运镜 | `镜头：MS中景 · 慢推 Dolly In 0.5u/s` | `镜头缓缓推近` |
| 动作词 | `缓缓揉太阳穴→目光从屏幕移开→身体渐渐靠向椅背` | `缓缓揉太阳穴，随后目光离开屏幕靠向椅背` |
| 负面提示词 | 独立段落 | 放在末尾，用 `--no` 或直接列出 |
| 六个固定段 | 必须保留 | 只保留"画质"和"负面提示词" |

## 【基础模板】（单镜头，适合 5-6s 内）

```
[场景氛围一句话] + [人物外观+动作] + [光影] + [镜头] + [台词（可选）] + [风格关键词]

负面：[负面词列表]
```

### 示例骨架

```
深夜现代办公室，一个疲惫的年轻男子（黑色衬衫、短发、眼眶微青）
独自坐在工位前，缓缓揉着太阳穴，目光从发光的屏幕上移开，
身体渐渐靠向椅背，肩膀下沉。
顶部冷白荧光 + 屏幕蓝光 + 窗外远处霓虹，明暗反差柔和，
画面中央偏左构图，中景镜头缓缓推近。
男子低声自语："又是一个人的深夜..."
电影写实风格，1080p，冷色调，孤独氛围。

负面：低画质、模糊、畸变、多余肢体、面部扭曲、文字水印、卡通化
```

## 【多镜头连续版】（适合 15-60s 场景）

```
总体风格：[视觉风格 + 导演风格 + 主色调]

【第1段】[时长]s
[外观+动作+光影+镜头+台词]

【第2段】[时长]s
[外观+动作+光影+镜头+台词]

...

负面：[全片共用负面词]
```

### 示例

```
总体风格：电影写实，诺兰式冷峻构图，青橙双色调

【第1段】5s
深夜办公室，疲惫的年轻男子（黑色衬衫、短发）独自坐在工位前，
缓缓揉太阳穴并靠向椅背。顶部冷白荧光 + 屏幕蓝光。
中景缓缓推近。低语："又是一个人的深夜..."

【第2段】4s
男子突然抬头，手腕内侧浮现出银色灵纹光纹，
眼神从疲惫转为震惊。特写，机位微仰，快速拉焦。
环境骤暗，灵纹蓝白光成为唯一光源。

【第3段】6s
男子缓缓站起，身体被蓝白灵纹光包围，桌上物品开始轻微漂浮。
全景，机位缓慢环绕，慢动作。
风声渐起，低频共鸣。

负面：低画质、模糊、畸变、多余肢体、面部扭曲、文字水印、
      现代科技感过强、塑料感、卡通化
```

## 【快速生成模板】（最短形式，10 词以内描述）

适用于：测试、灵感抓取、快速迭代

```
[场景] + [主角外观] + [核心动作] + [光影] + [风格]

示例：雨夜街角，穿黑色风衣的年轻男子低头抽烟，霓虹倒影，黑色电影风格。
```

## 【从 Seedance 一键转换步骤】

1. **删除所有 `@标签`**，用外观描述替换
2. **合并六字段** 为 1-3 段自然语言，顺序：氛围 → 主体+动作 → 光影+镜头 → 台词 → 风格
3. **速度词保留**（缓缓/猛然/骤然/渐渐）
4. **运镜保留方向**（推/拉/摇/移/跟），删除技术参数（如 `0.5u/s`、`Dolly In` 术语）
5. **否定句转肯定**（"不要动" → "保持静止"）
6. **台词保留原文和语气**，但去掉秒数定位
7. **风格三要素**：视觉风格 + 画质 + 情绪关键词
8. **负面词列表**：从原片负面段复制核心 5-10 个

## 【负面词模板库】

```yaml
通用负面：
  - 低画质, 模糊, 畸变, 多余肢体, 面部扭曲, 文字水印, 变形

写实风格追加：
  - 卡通化, 塑料感, 假发感, 过度锐化, 塑料质感

动画风格追加：
  - 写实面部, 过度细节, 胶片颗粒

国风仙侠追加：
  - 现代服装, 现代建筑, 塑料感, 西式元素

赛博朋克追加：
  - 田园风光, 暖黄色调, 自然光, 古装
```
