# Seedance 长版母稿模板

> **用途**：Seedance 2.0 长版母稿填充参考模板  
> **字段顺序**：主体 → 空间 → 光影 → 镜头 → 台词 → 音效（六字段固定）  
> **辅以**：六个固定段（环境联动 / 光线 / 对白配音 / 音效设计 / 画质 / 负面提示词）

---

## 【文件头】

```yaml
# ========== 元数据 ==========
项目名：[项目标题]
集数段落：[如：第01集 第03段]
总时长：[X 秒]
导演风格：@[导演ID]（如 @nolan / @wong / @miyazaki）
视觉风格：[如 cinematic / donghua_xianxia / ink_wash]
镜头数：[N 个]
节拍密度：1拍≈2秒，每3s镜头≤2拍
首帧安全区：每镜头0.3s画面建立
轴线：[180°轴线说明，如 @人物1 在画左·@人物2 在画右]

# ========== 角色 @标签定义 ==========
@人物1：[名称，外观核心锚点，衣着，标志物]
@人物2：[同上]
@道具1：[名称，材质，颜色，特征]
@场景1：[名称，时段，氛围]
```

## 【文件尾：六个固定段】

```
========================================
【环境联动】
{场景与动作的互动关系：风吹动@人物1发丝 / 玻璃倒影中出现@人物2 / 地面积水反射霓虹}

【光线】
{全片主导光影策略}
· 主色温：{如 3200K暖橙 / 5500K日光白 / 6500K冷蓝}
· 主要光比：{1:2柔光 / 1:4戏剧 / 1:8高对比}
· 时段：{黎明/正午/黄金时刻/蓝调时刻/深夜}
· 情绪隐喻：{光影如何服务情绪}

【对白配音】
· @人物1 配音基调：{年龄感+音色+语速+情绪起伏}
· @人物2 配音基调：{同上}
· 台词节奏：{紧凑对话 / 停顿留白 / 旁白叠画}

【音效设计】
· 环境层基底：{空间混响/底噪特征}
· 动作层重点：{哪些动作需要精确音效贴合}
· 情绪层配乐：{流派/乐器/情绪曲线}
· 关键声效点：{第Xs 的重点音效}

【画质】
· 视觉风格：{cinematic / anime / donghua_xianxia / ...}
· 分辨率：{1080p / 4K}
· 帧率：{24fps电影感 / 30fps标准 / 60fps高帧}
· 色彩科学：{胶片质感 / 数字锐利 / 水彩晕染}
· 质感关键词：{颗粒/光晕/景深/焦外散景/油画笔触}

【负面提示词】
低画质, 模糊, 畸变, 多余肢体, 面部扭曲, 文字水印, 
{按风格追加：如现代服装/塑料感/卡通化（写实风格时）}
========================================
```

---

## 【填充提示】

1. **每个镜头时长 ≤ 6s**（Seedance 2.0 单镜上限约 6s，长镜需分段）
2. **动作链至少 2-3 节**（速度词 + 动作 + 速度词 + 动作 ...）
3. **@标签在首次出现时定义，后续直接引用**，不重复描述外观
4. **台词必须带秒数定位**（第 Xs @人物1："..."）
5. **禁止出现独立"镜头与构图"段落**，运镜必须与动作同句绑定
6. **否定句必须转肯定**（"不要移动" → "保持静止"）
7. **朝向/轴线前后一致**，跨镜头切换前检查 180° 线

## 【示例片段】

```
【0s–5s】（5s · MS中景 · 慢推 Dolly In）

主体：@林天（疲惫）[朝向：面朝屏幕] 正在 
  缓缓揉太阳穴→目光从屏幕移开→身体渐渐靠向椅背，
  重心后移，肩膀微微下沉，
  表情从专注转为疲惫
  （开篇镜头，建立人物状态）

空间：前景-键盘和鼠标（虚焦） 
      中景-@林天 独自坐在工位前 
      背景-落地窗外的城市夜景，远处灯火稀落
      （@林天位于画面中央偏左，形成孤独构图）

光影：顶部冷白荧光灯主光 + 屏幕蓝光辅光 + 窗外霓虹轮廓光
  · 主光：顶部垂直5500K冷白，强度偏弱
  · 辅光：屏幕6500K冷蓝，打亮面部左侧
  · 轮廓光：窗外霓虹混合色，勾勒发丝
  · 环境光：办公区其他工位已暗

镜头：中景 MS · 慢推 Dolly In（0.5u/s）
  · 机位高度：平视
  · 焦距暗示：标准50mm感
  · 构图：三分法，@林天占画面左1/3
  · 节奏：全镜匀速慢推，最后0.5s定格

台词：第2s @林天（内心独白）："又是一个人的深夜..."（低沉，气音）

音效：
  · 环境层：空调低频嗡鸣 + 键盘远处敲击声
  · 动作层：椅背皮革轻微摩擦声 + 呼吸声
  · 情绪层：钢琴单音 C小调，稀疏下行
```
