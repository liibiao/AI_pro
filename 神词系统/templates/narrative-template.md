# 叙事性提示词模板

> **用途**：段落式电影化叙事提示词，适配 Seedance 2.0 / 可灵 / Wan / Luma / Runway  
> **核心差异**：保留 @标签、段落式融合叙述、分时段描述、多镜段智能合并  
> **源头**：由 Seedance 长版母稿叙事化改写而来（参考 `lingjing-integrate-skill.md`）

---

## 【核心原则】

1. **保留 @标签**：`@人物1` / `@人物2` / `@道具1` 的引用在叙事中保留
2. **融合叙述**：主体/空间/光影/镜头/音效 融入连贯叙述，不再独立分段
3. **分时段描述**：用 `开篇 / 第1秒起 / 第3秒时 / 末尾` 自然时间标记
4. **运镜叙事化**：运镜动作与人物动作同句绑定
5. **多镜段合并**：符合合并条件的相邻镜头可自然衔接为一段叙事
6. **节拍密度**：每 3 秒最多 2 个动作拍
7. **首帧安全区**：每段前 0.3 秒保留画面建立时间

---

## 【基础模板】（单场景/单镜）

```
【{起始}s–{结束}s】{场景一句话}

开篇，{空间建立 + 主光源 + 氛围}。{镜头} 缓缓 {运镜方向}，
呈现 @{人物}（{情绪}）正在 {动作链}。第{X}秒，@{人物} 
{关键动作 + 全身动态}，同时镜头 {运镜调整}。@{人物} 
低声说："{台词}"（{语气}）。{光影细节与情绪呼应}。
背景音 {音效}，情绪层 {配乐}。{末尾动作与下镜衔接}。

视觉风格：{风格名}；画质：{分辨率/帧率/质感}；
负面：{负面词列表}
```

---

## 【多镜段合并版】（2-4 个镜头合并为一段叙事）

### 合并前提（满足任意 2 条即可合并）

- 同一场景签名（时间+地点）
- 同一主体持续在画
- 对话连贯未断
- 总时长 4-15 秒
- 无轴线反转

### 合并模板

```
【{起始}s–{结束}s】{大场景一句话}（含 {N} 个镜头衔接）

开篇，{空间+光影+氛围}。镜头以 {初始景别+运镜} 开场，
@{人物}（{初始情绪}）正在 {初始动作}。

约第 {t1} 秒，{转折动作/事件}，镜头顺势 {运镜变化} 推至
{新景别}，@{人物} 的表情从 {A} 转为 {B}，{全身动态}。

约第 {t2} 秒，@{人物}（或 @{人物2}）{新动作}，
镜头 {最终运镜}，定格于 {末帧画面}。

期间台词：
· 第 {x1}s @{人物}："{台词1}"（{语气}）
· 第 {x2}s @{人物2}："{台词2}"（{语气}）

光影随动作推进：{从初始光影 → 转折光影 → 末尾光影}。
音效层次：{环境底噪} / {关键动作音} / {情绪配乐曲线}。

视觉风格：{风格}；画质：{质感}；负面：{负面词}
```

## 【分时段精细描述模板】（单镜 ≥ 5s 或情绪复杂）

```
【{起始}s–{结束}s】{标题}

=== 第 0s-1s（建立） ===
{首帧画面 + 空间介绍 + 主体出场状态}

=== 第 1s-3s（发展） ===
{动作链核心 + 镜头推进 + 光影变化}

=== 第 3s-5s（转折/高潮） ===
{关键动作或台词 + 情绪峰值 + 运镜配合}

=== 末尾 0.5s（衔接） ===
{末帧姿态 + 与下镜的视觉连接}

台词精确时间轴：
· {时间点} @{人物}："{台词}"（{语气}）

综合参数：
- 视觉风格：{风格}
- 主色温：{色温}
- 主要运镜：{运镜}
- 画质：{质感}
- 负面：{负面词}
```

---

## 【Seedance → 叙事转换步骤】

1. **保留所有 @标签**（人物/道具/场景）
2. **六字段融合为连贯段落**：
   - 主体 → 作为叙事主语
   - 空间 → 融入开篇环境句
   - 光影 → 分散到场景描述中
   - 镜头 → 与动作同句绑定（"镜头随 @人物1 的转身顺势环绕"）
   - 台词 → 精确秒数独立列出
   - 音效 → 末尾综合描述
3. **速度词保留**（缓缓/骤然/渐渐/猛然）
4. **引入叙事连接词**：
   - 开篇 / 随后 / 紧接着 / 约第 X 秒 / 同时 / 期间 / 末尾
5. **否定句自动修正**（30+ 规则，详见 integrate-skill）
6. **检查节拍密度**：每 3s 不超过 2 个动作拍
7. **检查首帧安全区**：每段前 0.3s 不出现关键动作
8. **六个固定段压缩为一行参数**：视觉风格/画质/负面词

## 【多镜段预合并算法（伪代码）】

```python
def merge_shots(shots):
    merged = []
    current = [shots[0]]
    for shot in shots[1:]:
        # 合并条件
        same_scene = shot.scene_sig == current[-1].scene_sig
        same_subject = set(shot.subjects) & set(current[-1].subjects)
        dialog_continuous = shot.dialog_start and current[-1].dialog_end
        total_duration = sum(s.duration for s in current) + shot.duration
        no_axis_flip = shot.axis == current[-1].axis
        
        if (same_scene and same_subject and no_axis_flip 
            and total_duration <= 15 
            and (dialog_continuous or total_duration >= 4)):
            current.append(shot)
        else:
            merged.append(current)
            current = [shot]
    merged.append(current)
    return merged
```

## 【完整示例】

```
═══════════════════════════════════════════
叙事性提示词 · 第01集 第03-04段（合并）
═══════════════════════════════════════════

【0s–9s】深夜办公室 · @林天 灵纹觉醒的开端
（由原第03段[0-5s] + 第04段[5-9s] 合并）

开篇，夜已深，@深夜办公室 安静得只剩空调的低频嗡鸣，
落地窗外城市灯火稀落，顶部冷白荧光灯与屏幕蓝光在桌面
交叠出青冷色调。镜头以中景缓缓推近（Dolly In 0.5u/s），
呈现 @林天（疲惫）正独自坐在工位前，缓缓揉太阳穴，
目光从发光屏幕移开，身体渐渐靠向椅背，肩膀微微下沉，
表情从专注转为疲惫。

第 2 秒，@林天 低声自语："又是一个人的深夜..."（气音，
低沉）。画面中央偏左构图，@林天 占据画面左侧 1/3，
形成孤独感。

约第 5 秒，@林天 的手腕内侧突然浮现出银色 @灵纹，
他骤然抬起左手凑近眼前，眼神从疲惫急速转为震惊，
镜头顺势推为特写并微仰，同时快速拉焦聚焦手腕。
环境光骤暗，@灵纹 的蓝白冷光成为画面唯一光源，
映亮他半张脸，另一半陷入深影。

约第 8 秒，@林天 缓缓起身，身体被蓝白光纹包围，
桌面上的 @钢笔 与 @马克杯 开始轻微漂浮、缓慢旋转。
镜头拉远为全景并缓慢环绕半圈，慢动作呈现。
末尾定格于 @林天 仰头望向天花板，眼中倒映着 @灵纹
流动的光。

音效层次：开篇空调低频嗡鸣 + 远处零星键盘声；第 5 秒
起低频共鸣渐起并盖过环境音；第 8 秒加入钢琴单音 C 小
调下行，伴随风声拉扯窗帘的细微摩擦。情绪从疲惫孤独
逐步上升为神秘惊悸。

视觉风格：cinematic 电影写实 · 诺兰式冷峻构图；
主色调：青橙双色（冷荧光 + @灵纹 蓝白 + 温暖肤色）；
画质：1080p，24fps 电影感，胶片颗粒，深景深，焦外散景；
负面：低画质、模糊、畸变、多余肢体、面部扭曲、文字水印、
     卡通化、塑料感、现代科技感过强
═══════════════════════════════════════════
```

## 【质量检查清单】

- [ ] @标签保留完整，未被替换为外观描述
- [ ] 六字段已融合为连贯段落，无独立字段分段
- [ ] 时间点台词精确到秒
- [ ] 运镜与动作同句绑定，无独立"镜头与构图"段
- [ ] 速度词保留（缓缓/骤然/渐渐/猛然）
- [ ] 无否定句（已全部转为肯定表达）
- [ ] 节拍密度 ≤ 2拍/3s
- [ ] 首帧 0.3s 安全区留白
- [ ] 末尾附视觉风格 / 画质 / 负面三要素
- [ ] 合并段落无轴线反转、无主体消失

## 【平台适配提示】

| 平台 | 建议时长 | 特点 |
|---|---|---|
| Seedance 2.0 | 5-10s | 长句叙事 + @标签保留，效果最佳 |
| 可灵 Kling | 5s 单镜 | 需拆分为单镜叙述，保留台词秒数 |
| Wan | 5s 单镜 | 去除过多分时段标记，保留主干 |
| Luma Dream Machine | 5s 单镜 | 强调光影氛围和运镜，减少复杂动作链 |
| Runway Gen-3 | 10s | 接受叙事段落，但需英译 |
