# 灵境 Storyboard Skill

> 灵境分镜生成技能 — 导演讲戏稿转 Seedance 长版母稿

---

## 技能定位

本技能是灵境系统的**第二道工序**：接收 `lingjing-director-skill` 输出的讲戏稿，生成标准化的分镜表与 Seedance 长版母稿。

**触发前置**：由 `lingjing-agent` 在讲戏阶段完成后调度。

---

## 核心职责

### 1. 分镜表生成（Storyboard Table）

**输入**：导演讲戏稿（含时间轴、景别、运镜、画面、光影、情绪、音效）

**输出**：标准 Markdown 表格

```markdown
| 时间段 | 景别 | 运镜 | 画面描述 | 光影氛围 | 戏剧张力 | SEEDANCE提示词 |
|--------|------|------|----------|----------|----------|----------------|
| 0s-5s  | ELS  | 鸟瞰俯拍+慢推 | 空旷办公区鸟瞰，@人物1孤独身影 | 冷白+台灯暖黄，3:1明暗 | [孤独:压抑→疲惫] | [SEEDANCE六字段] |
```

**表格列说明**：
- **时间段**：格式必须为 `Xs-Ys`（无空格，连字符 `-` 或破折号 `–`）
- **景别**：ECU / CU / MCU / MS / FS / LS / ELS
- **运镜**：叙事性描述（如"慢推轨"、"鸟瞰俯拍"）
- **画面描述**：自然语言，禁用 @标签（读者友好）
- **光影氛围**：简短光影色调（20-40字）
- **戏剧张力**：`[+/-][情绪：从X→Y] [冲突：障碍描述（10字内）]`
- **SEEDANCE提示词**：完整的六字段格式，含 @标签

---

### 2. Seedance 六字段填充（Six-Field Filling）

对每一镜，将讲戏稿转换为 Seedance 长版母稿格式：

```
主体：@人物N（情绪状态）[朝向：面朝XX] 正在 [连续动作链] + [全身动态] + [表情变化]（与上镜衔接）
空间：前景-[引导视线元素] 中景-[叙事主体] 背景-[氛围元素]（多人站位关系）
光影：[光源方向 + 色温 + 明暗反差 + 情绪隐喻]
镜头：[景别，叙事性运镜描述，机位高度]（轴线：A在画左·B在画右）（结尾动势）
台词：第Xs @人物N："台词原文"（无台词省略整段）
音效：环境层-[持续底噪] 动作层-[同步声响] 情绪层-[配乐+乐器] [禁BGM]/[禁字幕]
```

**字段填充规则**：

#### 主体字段
```
主体：@人物1（疲惫）[朝向：面朝屏幕] 正在 缓缓揉太阳穴→目光从屏幕移开→身体渐渐靠向椅背，重心后移，肩膀微微下沉，呼吸略显沉重，表情从专注转为疲惫（延续上镜的工作状态）
```

- 必须包含：@标签 + 情绪状态 + 朝向 + 正在 + 连续动作链 + 全身动态 + 表情变化 + 衔接说明
- 速度词强制：每个动作前必须有 猛然/缓缓/骤然/徐徐/渐渐 之一
- 多人用 `；` 分隔

#### 空间字段
```
空间：前景-键盘和鼠标 中景-@人物1独自坐在工位前 背景-落地窗外的城市夜景，远处灯火稀落（@人物1位于画面中央偏左）
```

- 前景/中景/背景三层必须明确
- 可选：多人站位关系注明

#### 光影字段
```
光影：冷白荧光灯从顶部照亮@人物1的面容，3:1明暗比，半边脸隐入阴影，营造孤独疲惫的氛围
```

- 必须包含：光源方向 + 色温（可含K值）+ 情绪隐喻
- 可选：明暗比（2:1 / 3:1 / 4:1）

#### 镜头字段
```
镜头：中景，镜头从@人物1的侧脸缓缓推向窗外夜色，平视（轴线：@人物1在画面中央偏左）（结尾动势：镜头停在窗外夜景）
```

- 必须包含：景别 + 叙事性运镜 + 机位高度
- 首次双人场景必填轴线
- 禁用技术参数（焦距、光圈、设备名）

#### 台词字段
```
台词：第3s @人物1："又是一个人。"
```

- 相对时间（本镜起始时间为 0s）
- 一字不差，中文引号 `""`
- 无台词时完全省略本字段

#### 音效字段
```
音效：环境层-空调低鸣，远处车流声若隐若现 动作层-键盘声渐弱，椅子轻微吱呀声 情绪层-低沉钢琴单音渐入 [禁字幕]
```

- 三层结构强制：环境层 + 动作层 + 情绪层
- 音频开关：`[禁BGM]`（无配乐）/ `[禁字幕]`（无文字）

---

### 3. 连续性校验（Continuity Validation）

**必检项**：

#### ① 时间轴连续性
- 所有镜头时长之和 = 总时长
- 相邻镜头时间段必须无缝衔接（上一镜 end = 下一镜 start）
- 无缝隙、无重叠

#### ② @标签一致性
- 所有 @标签必须在讲戏稿的资产清单中定义
- 同一角色全程使用同一编号
- @人物N / @图片N / @道具N 格式统一

#### ③ 景别跳跃控制
- 景别等级：ECU(0) / CU(1) / MCU(2) / MS(3) / FS(4) / LS(5) / ELS(6)
- 相邻镜头景别跳跃 ≤ 2 级
- 连续 3 镜禁止同景别

#### ④ 动作连续性
- 相邻镜头间角色位置、动作进度、朝向必须物理逻辑一致
- 上一镜"手伸到半空" → 下一镜必须从半空状态接续

#### ⑤ 180° 轴线守恒
- 对话场景中角色位置全片固定同侧
- 首次建立后不得跨轴

#### ⑥ 否定句排查
- 除 `[禁BGM]` `[禁字幕]` 外，严禁否定表达
- 自动替换：
  - "不要移动" → "保持静止"
  - "没有背景音乐" → "仅自然环境音效"
  - "不要说话" → "保持沉默"

---

### 4. 六个固定段追加（Six Fixed Sections）

每集末尾必须追加六个固定段：

```
━━━ 六个固定段 ━━━

【环境联动】
风吹乱@人物1的头发，雨滴打在@人物2的脸上，阳光穿过@人物1的指缝，尘埃在光柱中飞舞。

【光线】
冷白荧光灯从顶部照亮面容（4500K，3:1 明暗比），营造孤独疲惫的氛围。贯穿本集的光影基调：高对比冷蓝钢灰调。

【对白配音】
- @人物1："又是一个人。"（低声自语，带着疲惫和无奈）
- @人物2："你在说什么？"（惊讶，声音微微颤抖）

【音效设计】
- 环境层：空调嗡鸣、远处车流、键盘声、风声
- 动作层：脚步声、关门声、椅子吱呀声、呼吸声
- 情绪层：低沉钢琴单音、紧张弦乐渐起、温暖吉他

【画质】
电影级画质，画面清晰流畅，色彩自然真实，细节丰富，4K 超高清。

【负面提示词】
overlay text, caption, label, annotation, subtitle, heading, watermark, logo, signature, stamp, emblem, panel number, view label, measurement, HUD, multiple people (if solo scene), collage, split screen, border, frame, colored background (if neutral required)
```

## 质量检查清单

### 必检项

- [ ] 分镜表表头完整（7列或6列）
- [ ] 所有时间段格式正确（`Xs-Ys`）
- [ ] 时间轴连续无缝
- [ ] 每镜的 SEEDANCE 列包含完整六字段
- [ ] 字段顺序正确（主体→空间→光影→镜头→台词→音效）
- [ ] 所有 @标签在资产清单中定义
- [ ] 景别跳跃 ≤ 2 级
- [ ] 连续 3 镜非同景别
- [ ] 无否定句（除音频/字幕开关）
- [ ] 六个固定段完整追加

### 常见错误

❌ **字段名变体**
```
动作：@人物1 正在...  # 错误
场景：前景-...        # 错误
声音：环境层-...      # 错误
```

✅ **正确**
```
主体：@人物1 正在...
空间：前景-...
音效：环境层-...
```

❌ **时间段格式错误**
```
0-5秒  # 错误（中文秒）
0s - 5s  # 错误（有空格）
```

✅ **正确**
```
0s-5s
0s–5s  （破折号亦可）
```

❌ **@标签滥用**
```
| 画面描述 | 林天揉太阳穴 |  # 画面描述列应用真实名字
| SEEDANCE | @人物1正在... |  # SEEDANCE 列必须用 @标签
```

## 输出交接（传递给 integrate-skill）

**下游**：`lingjing-integrate-skill`（接收 Seedance 长版母稿，生成三版本）

**交接协议**：
1. 必须是完整的 Markdown 表格 + 六个固定段
2. 表格中每行的 SEEDANCE 列必须是完整的六字段
3. 资产清单必须在表格之前列出（供 integrate-skill 转换即梦精简版时查询真名）
4. 六个固定段紧跟在表格之后
