# 灵境 Director Skill

> 灵境导演讲戏技能 — 将剧本转化为可视化画面描述

---

## 技能定位

本技能是灵境系统的**第一道工序**：接收剧本文字，输出可视化的画面拆解，为后续分镜生成提供导演级指导。

**触发前置**：用户通过 `@lingjing` 提交剧本或剧情描述后，由 `lingjing-agent` 调度本技能。

---

## 核心职责

### 1. 剧本分析（Scene Analysis）

**输入**：剧本文本（500-10000字）

**任务**：
- 提取核心情节、主要角色、关键场景、重要道具
- 识别情感弧线（起承转合）
- 判断场景类型（对话 / 动作 / 悬疑 / 情绪 / 环境）

**输出结构**：
```yaml
核心情节: [100-200字概括]
主要角色:
  - id: "@人物1"
    name: "林天"
    role: "男主角"
    emotion_arc: "疲惫 → 震惊 → 觉醒 → 决心"
  - id: "@人物2"
    name: "林啸"
    role: "反派"
    emotion_arc: "冷漠 → 轻蔑 → 警觉"
关键场景:
  - id: "@图片1"
    name: "深夜办公室"
    description: "冷白荧光灯、落地窗、工位"
关键道具:
  - id: "@道具1"
    name: "灵纹手环"
    description: "银色金属，发光符文"
情感弧线:
  - [0s-10s] 孤独压抑（冷色调 + 慢节奏）
  - [10s-20s] 异象觉醒（高对比 + 急速节奏）
  - [20s-30s] 决心蜕变（暖冷混合 + 稳定节奏）
场景类型分布:
  - 环境建立: 0-5s
  - 情绪铺垫: 5-10s
  - 动作觉醒: 10-20s
  - 收尾钩子: 20-30s
```

### 2. 风格匹配（Style Matching）

**自动匹配规则**：

| 剧情关键词 | 推荐导演 | 推荐视觉风格 |
|-----------|---------|------------|
| 科幻、时间、悬疑、概念 | nolan / villeneuve | cinematic |
| 仙侠、修真、灵纹、觉醒 | donghua_xianxia | donghua_xianxia |
| 都市、孤独、情感、怀旧 | wong / kore-eda | cinematic |
| 动作、武打、追逐、打斗 | chan / yuen / woo | cinematic |
| 恐怖、惊悚、心理、悬疑 | fincher / hitchcock / carpenter | noir |
| 动画、童话、奇幻 | miyazaki / shinkai | anime |
| 史诗、宏大、战争 | villeneuve / cameron | cinematic |
| 赛博、未来、科技 | ridley / wachowski | cyberpunk |

**匹配算法**（伪代码）：
```
1. 扫描剧本中的关键词
2. 统计每个导演风格的关键词命中数
3. 排序并推荐 Top 3
4. 如果用户指定风格，直接使用
5. 如果无匹配，使用 generic（标准电影感）
```

**输出**：
```yaml
推荐导演:
  - id: "nolan"
    name: "克里斯托弗·诺兰"
    score: 8
    reason: "命中关键词：时间、概念、觉醒"
  - id: "villeneuve"
    name: "丹尼斯·维伦纽瓦"
    score: 5
    reason: "命中关键词：宏大、静穆"
选择: "nolan"
视觉风格: "cinematic"
应用风格特征:
  - 非线性叙事
  - IMAX实拍宏大构图
  - 高对比冷蓝钢灰调
  - Dolly Zoom眩晕感
```

### 3. 时长估算（Duration Estimation）

**公式**（基于 HTML 中提取的算法）：
```
对话时长 = 台词字数 / 3.5 字/秒
动作时长 = 动作词数 × 3.5 秒/动作
场景时长 = 场景数 × 3 秒/场景
描述时长 = 描述字数 / 18 字/秒

总时长 = 对话 + 动作 + 场景 + 描述
总时长向上取整到 5 的倍数
限制范围：15-300 秒
```

**节奏判断**：
- **动作/武打/追逐**：快速切镜，每镜 1.5-3 秒
- **悬疑/发现/反转**：中速切镜，每镜 3-5 秒
- **对话/谈判**：稳定节奏，每镜 5-8 秒
- **情绪/抒情/回忆**：慢节奏，每镜 6-10 秒
- **环境建立/开场**：长镜头，每镜 5-12 秒

---

### 4. 场景→镜头组合建议（Shot Selection）

**场景语义 → 镜头组合**（基于 HTML 中提取的速查表）：

| 场景类型 | 推荐镜头组合 |
|---------|------------|
| 史诗定场/世界观开场 | ELS极远景 + 鸟瞰/航拍 + 缓慢推进 |
| 主角登场/英雄化 | FS全景/MS中景 + 微仰拍 + 慢推轨或轻环绕 |
| 对话场景 | MS/MCU + 平视 + OTS过肩反打（守180°轴线） |
| 情绪加压/进入内心 | MCU→CU递进 + 平视 + 慢推轨（非变焦） |
| 权力对峙/审讯 | 强势方MCU微仰+定镜，弱势方MCU微俯+定镜 |
| 悬疑揭示/真相 | LS/MS + 横移从遮挡物后滑出 + 拉焦到真相 |
| 追捕/恐惧/混乱 | MS/CU + 手持 + 轻度倾斜构图 |
| 动作/追逐 | MS + 跟拍/手持 + 方向一致性优先 |
| 浪漫/温馨 | MCU + 浅景深 + 缓推或轻环绕 |
| 独白/沉思 | CU/MCU + 侧面轮廓 + 定镜或极缓横移 |
| 高潮/转折 | 眩晕变焦(Dolly Zoom)或环绕+浅景深 |

## 导演视觉化六原则（强制遵守）

### ① 动作连续化
- 写连续物理动作链（"猛然转身 → 衣摆翻飞 → 大步冲出"）
- 每个动作必须有速度变化词（猛然/缓缓/骤然/徐徐/渐渐）
- 禁止匀速单一动作

### ② 全身动态化
- 人物永远有身体局部在运动
- 没有主动作时也要有：呼吸起伏/重心微移/衣物飘动/发丝摆动
- 禁止任何时刻完全静止

### ③ 光影情绪化
- 光影服务情绪，不是装饰
- 紧张 → 冷调硬光
- 温暖 → 暖调柔光
- 孤独 → 单侧剪影光
- 用氛围词而非技术参数

### ④ 运镜叙事化
- 运镜必须描述镜头在"看什么"
- ✅ "镜头从她颤抖的指尖缓缓上移到紧咬的嘴唇"
- ❌ "推镜头，焦距85mm"

### ⑤ 情绪大动作化
- 情绪通过全身动态传达，而非面部微表情
- 愤怒 = 猛然起身/拍桌/摔门
- 悲伤 = 跌坐/掩面/蜷缩
- 喜悦 = 旋转/奔跑/拥抱
- AI视频平台无法渲染瞳孔/嘴唇微颤

### ⑥ 环境呼应情绪
- 场景元素随情绪变化
- 风吹乱头发、雨滴打在脸上、阳光穿过指缝、尘埃在光柱中飞舞

---

## 八大视觉铁律（构图与节奏）

### ① 情绪驱动构图
- 对称构图 = 秩序/压迫/庄重（库布里克式）
- 三分法偏侧留白 = 孤独/期待/未知（王家卫式）
- 对角线构图 = 运动/冲突/紧张（诺兰式）
- 框中框构图 = 囚禁/窥视/心理距离（李安式）

### ② 空间纵深三层分离
- 前景：引导视线 / 中景：叙事主体 / 背景：情绪氛围
- 禁止所有元素铺在同一平面

### ③ 光影即叙事
- 光源方向 + 色温 + 明暗比 + 情绪隐喻
- 同一场景内光影体系严禁跳变

### ④ 动作连续性
- 相邻镜头间角色的位置、动作进度、朝向必须物理逻辑一致

### ⑤ 景别递进法则
- 渐进聚焦：大远景→全景→中景→近景→特写（情绪收紧）
- 渐进释放：特写→近景→中景→远景（情绪释放）
- 连续 3 镜禁止同景别

### ⑥ 视轴守恒
- 180度线原则，角色位置全片固定同侧

### ⑦ 信息控制
- 给手不给脸 = 悬念
- 先声后画 = 期待
- 只给背影 = 疏离
- 全貌揭示 = 高潮兑现

### ⑧ 朝向空间逻辑
- 对话面朝彼此，操作面朝物品，注视远方则面朝远方
- 严禁无差别面朝镜头

## 节拍密度约束

每个连续镜头内：
- **1 拍 ≈ 2 秒** 屏幕时间
- 1 个物理动作 = 1 拍
- 1 次镜头运动 = 1 拍
- 1 句短台词（≤10字）= 1 拍
- 1 句长台词（>10字）= 2 拍
- 同时发生的事合并为 1 拍

**示例**：
- 3s 镜头 → 最多 2 拍
- 5s 镜头 → 最多 3 拍
- 8s 镜头 → 最多 4 拍

---

## 首帧安全区（强制）

每一镜的第一帧（约 0.3s）用于画面建立，从第二帧起才开始动作。

**规则**：
- 0s - 0.3s：画面建立（环境/主体呈现）
- 0.3s - 结束前：连续动作
- 结束帧：保持动作的自然延续态势（不刻意收住，让势头流入下一镜）

```markdown

- 光影基调：[高对比冷蓝钢灰调 | 暖金黄昏 | ...]

### 角色资产（@标签锁定）
- @人物1 = 林天（男主）| 情绪弧：疲惫→觉醒→决心

**光影**：

#### 镜头 2 | 5s-10s | MCU中近景 | 慢推
... (依此类推)
```

## 失败信号（自动重写）

当出现以下情况时，必须重写：

1. ❌ 动作描述无速度词（"他走过去"）
2. ❌ 人物完全静止（"她站着不动"）
3. ❌ 运镜用技术参数（"推镜头，85mm"）
4. ❌ 光影仅描述色彩（"冷色调"）
5. ❌ 景别跳跃 > 2 级
6. ❌ 连续 3 镜同景别
7. ❌ 违反 180° 轴线
8. ❌ 使用否定句（"不要移动"）
