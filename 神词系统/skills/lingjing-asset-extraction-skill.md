# 灵境 · 资产提取技能（Asset Extraction Skill）

> 源自 `soullensV69更新.html` 第 887 行示例提示词 + `runAssetExtractionSilent` 函数
> 这是灵境的"人物一致性"保障机制：从剧本自动提取人物卡/场景卡/道具卡，生成结构化资产库。

---

## 一、核心能力

**输入**：完整剧本文本

**输出**：三类资产卡片
1. **人物卡（Character Card）**：外貌、服装、性格、关系
2. **场景卡（Scene Card）**：空间描述、光影氛围、适用题材
3. **道具卡（Prop Card）**：外观、材质、功能、象征意义

---

## 二、人物卡提取规则

### 提示词模板（示例）

```
你是专业美术指导。请从以下剧本中提取所有出场人物，为每个人物生成一张【人物设计卡】。

输出格式：
---
人物：[姓名]
外貌：[年龄段、身高体型、面容特征、发型发色、眼睛、皮肤]
服装：[主要服装风格、颜色、材质、配饰]
性格标签：[3-5个关键词]
核心关系：[与其他角色的关系]
视觉提示词：[150-200字，用于 AI 绘图的详细描述]
---

要求：
1. 外貌描述必须具体可视觉化（禁止"帅气""美丽"等抽象词）
2. 服装描述到材质、颜色、款式细节
3. 视觉提示词格式：主体：... 面容：... 发型：... 服装：... 光影：... 构图：... 风格：...
4. 如剧本未明确描述，根据人物性格/身份推断合理外观
```

## 五、自动提取流程（runAssetExtractionSilent）

```javascript
async function runAssetExtractionSilent(script) {
    // Step 1: 调用 AI 提取三类资产
    const prompt = buildAssetExtractionPrompt(script)
    const result = await callAI(prompt)
    
    // Step 2: 解析 Markdown 输出为结构化数据
    const assets = parseAssetCards(result)
    // assets = {
    //   characters: [{name, appearance, clothing, ...}, ...],
    //   scenes: [{name, space, lighting, ...}, ...],
    //   props: [{name, appearance, function, ...}, ...]
    // }
    
    // Step 3: 存储到项目资产库
    k.assetBlob = JSON.stringify(assets)
    await saveProjectSnapshot()
    
    // Step 4: 在分镜生成时自动注入
    // 系统提示词中追加：
    // 【资产库】：
    // 人物：@林天 → [外貌描述]
    // 场景：@废弃教室 → [空间描述]
    // 道具：@铁剑 → [外观描述]
    
    return assets
}
```

## 六、在分镜生成中的应用

### 注入方式

分镜生成系统提示词末尾追加：

```
🔒【资产库（最高优先级）】：
以下资产描述必须原文引用，禁止改写：

【人物】
@林天：18岁少年，精瘦体型，黑色短发微乱，灰色粗布武道服...
@苏婉：17岁少女，身高165cm，长发及腰，白色襦裙...

【场景】
@废弃教室：前景-倾倒课椅，中景-积灰课桌，背景-碎裂落地窗...
@演武场：...

【道具】
@铁剑：长约90cm，铁灰色剑身有划痕，深褐色皮革剑柄...

【引用规则】
- 分镜表"主体："字段必须用 @标签 引用人物（如"@林天 正在..."）
- 首次出现时自动展开完整描述，后续镜头只需 @标签
- 禁止凭空创造未在资产库的人物/场景/道具
```

### 一致性保障

| 问题 | 传统方式 | 资产提取方式 |
|---|---|---|
| 人物外貌前后不一致 | AI 每次重新描述，细节冲突 | 统一引用 `@林天` 资产卡 |
| 场景细节遗忘 | 后半段场景描述简化 | 统一引用 `@废弃教室` 资产卡 |
| 道具突然消失 | AI 忘记道具存在 | 资产库强制提醒 |

## 七、一句话调用

```
@lingjing 提取资产：从这段剧本生成人物卡、场景卡、道具卡
@lingjing 查看当前项目的资产库
@lingjing 在分镜生成时自动引用资产库
```

Agent 执行步骤：
1. 读入剧本文本
2. 调用 `runAssetExtractionSilent(script)`
3. 解析输出为结构化 JSON
4. 存储到 `k.assetBlob`
5. 在后续分镜生成时自动注入系统提示词
6. 输出资产库摘要（Markdown 表格）

## 十、质量检查清单

提取完成后自动检查：

- [ ] 每个人物卡的"视觉提示词"≥150字
- [ ] 每个场景卡包含前景/中景/背景三层
- [ ] 每个道具卡有"象征意义"字段
- [ ] 所有 @标签 在剧本中至少出现 1 次
- [ ] 资产库总数 ≤ 20（过多会导致提示词超限）

**失败信号**：
- 人物卡只有抽象描述（"帅气""美丽"）
- 场景卡缺少光影描述
- 道具卡只有名称没有细节
