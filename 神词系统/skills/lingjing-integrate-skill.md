# 灵境 Integrate Skill

> 灵境三版本整合技能 — Seedance 长版母稿派生即梦精简版和叙事性提示词

---

## 技能定位

本技能是灵境系统的**第三道工序**：接收 `lingjing-storyboard-skill` 输出的 Seedance 长版母稿，并行派生另外两个版本（即梦精简版 / 叙事性提示词）。

**触发前置**：由 `lingjing-agent` 在分镜生成完成后调度。

---

## 核心职责

### 1. 即梦精简版生成（JiMeng Compact）

**转换目标**：Seedance 长版母稿 → 即梦平台友好的精简描述

**转换步骤**：

#### 步骤 1：@标签替换为真名
从资产清单查询 @标签对应的真实名称：
```
@人物1 → 林天
@人物2 → 林啸
@图片1 → 深夜办公室
@道具1 → 灵纹手环
```

#### 步骤 2：合并字段为自然描述
将六个字段（主体/空间/光影/镜头/台词/音效）融合为一段自然语言：

**原文（Seedance 长版母稿）**：
```
主体：@人物1（疲惫）[朝向：面朝屏幕] 正在 缓缓揉太阳穴→目光从屏幕移开→身体渐渐靠向椅背
空间：前景-键盘和鼠标 中景-@人物1独自坐在工位前 背景-落地窗外的城市夜景
光影：冷白荧光灯从顶部照亮@人物1的面容，3:1明暗比
镜头：中景，镜头从@人物1的侧脸缓缓推向窗外夜色
台词：第3s @人物1："又是一个人。"
音效：环境层-空调低鸣 动作层-键盘声渐弱 情绪层-低沉钢琴单音
```

**转换后（即梦精简版）**：
```
【0s-5s】中景，深夜办公室，林天独自坐在工位前，冷白荧光灯照亮他疲惫的面容。他缓缓揉太阳穴，目光从屏幕移开，身体渐渐靠向椅背。镜头从他的侧脸缓缓推向窗外夜色。第3s轻声自语："又是一个人。"空调低鸣，键盘声渐弱，钢琴单音渐入。
```

#### 步骤 3：精简压缩（目标长度：原文的 60-70%）
- 去除技术参数（如"3:1明暗比"、"4500K色温"）
- 去除空间三层标记（前景-/中景-/背景-）
- 去除轴线和结尾动势
- 合并动作链，保留核心动作
- 保留关键的画面元素、情绪、光影

#### 步骤 4：台词保留
- 台词必须原字保留，用中文引号
- 可简化时间标记（"第3s" 可保留）

#### 步骤 5：去除音频/字幕开关
- 即梦版无需 `[禁BGM]` `[禁字幕]` 标记

---

### 2. 叙事性提示词生成（Narrative Prompt）

**转换目标**：Seedance 长版母稿 → 段落式电影脚本描述

**转换步骤**：

#### 步骤 1：保留 @标签
- 首次出现时说明用途：`以@人物1为主角，场景参考@图片3的深夜办公室`
- 后续直接使用：`@人物1转身看向@人物2`

#### 步骤 2：融合叙述（严禁字段标签）
将六个字段融合为段落，**严禁出现**"主体：""空间：""光影："等字段名。

**示例**：
```
【0s-12s】以@人物1为主角，场景参考@图片3的深夜办公室。
0-4秒：远景建立，空旷的办公区只有角落一盏台灯亮着，@人物1的剪影映在落地窗上。空调嗡鸣，键盘声稀疏。
4-8秒：中景推近，@人物1揉太阳穴，目光从屏幕移开，身体缓缓靠向椅背，表情从专注转为疲惫。椅子轻微吱呀声。
8-12秒：特写他的侧脸，视线转向窗外，城市灯火稀落，轻声自语："又是一个人。"镜头缓慢拉远，他的身影在空旷办公区中越来越小，画面定格。远处车流声若隐若现，低沉钢琴单音渐入。
```

#### 步骤 3：多镜段预合并（4-15秒）
基于 HTML 提取的算法，相邻镜头在以下情况下合并为一个叙事段：

**合并规则**：
- 场景签名相同（同一@图片N）
- 主体延续（同一@人物N继续主导）
- 对话连续（台词由同一角色说出）
- 合并后总时长 4-15 秒

**不合并规则（强制切段）**：
- 场景完全切换（@图片N 改变）
- 主角完全切换（@人物N 改变 + 无对话衔接）
- 累计时长 > 15 秒

**合并算法**（伪代码）：
```python
def merge_shots(shots, min_duration=4, max_duration=15):
    segments = []
    current = []
    cumulative = 0
    
    for shot in shots:
        if not current:
            current.append(shot)
            cumulative = shot.duration
            continue
        
        prev = current[-1]
        sig_changed = different_scene(prev, shot)
        subject_changed = different_subject(prev, shot)
        dialogue_linked = has_dialogue_link(prev, shot)
        
        new_total = cumulative + shot.duration
        
        # 超过最大时长，必须切段
        if new_total > max_duration:
            segments.append(current)
            current = [shot]
            cumulative = shot.duration
            continue
        
        # 场景切换 + 无对话衔接，切段
        if cumulative >= min_duration and sig_changed and not dialogue_linked:
            segments.append(current)
            current = [shot]
            cumulative = shot.duration
            continue
        
        # 主体切换 + 无对话衔接，切段
        if cumulative >= 6 and subject_changed and not dialogue_linked:
            segments.append(current)
            current = [shot]
            cumulative = shot.duration
            continue
        
        # 其他情况：合并
        current.append(shot)
        cumulative = new_total
    
    if current:
        segments.append(current)
    return segments
```

#### 步骤 4：分时段描述（多镜段强制）
多镜段使用分时段描述，按时间顺序组织：

```
【0s–12s】以@人物1为主角，场景参考@图片3。
0-4秒：[时段1描述]
4-8秒：[时段2描述]
8-12秒：[时段3描述]
```

#### 步骤 5：节拍密度约束
- 每段开头 0.3s 用于画面建立
- 1 拍 ≈ 2 秒
- 3s 段最多 2 拍，5s 段最多 3 拍，8s 段最多 4 拍

### 3. 否定句自动修正（Negation Sanitization）

基于 HTML 提取的 30+ 条规则，自动替换否定表达：

| 否定表达 | 替换为 |
|---------|--------|
| 不要移动 / 不要运动 / 不要动 / 禁止移动 | 保持静止 |
| 不要说话 / 不要开口 / 禁止说话 | 保持沉默 |
| 不要有背景音乐 / 没有背景音乐 / 不要BGM | 仅自然环境音效 |
| 不要有字幕 / 没有字幕 | 画面无文字叠加 |
| 不要笑 | 表情严肃 |
| 不要哭 | 表情平静 |
| 不要回头 | 持续面朝前方 |
| 不要转身 | 保持当前朝向 |
| 不要看镜头 | 目光看向远方 |
| 不要眨眼 | 目光坚定凝视 |
| 不要跑 | 缓步行走 |
| 不要停 | 持续前行 |
| 不要出现人物 / 没有人物 / 不要有人 | 纯环境空镜 |
| 不要晃动 / 不要抖动 / 禁止晃动 | 镜头稳定固定 |

**保留的否定标记**（白名单）：
- `[禁BGM]` - 音频开关
- `[禁字幕]` - 字幕开关

---

### 4. 台词一致性校验（Dialogue Lock）

**规则**：三版本中的台词必须完全一致，一字不差。

**校验流程**：
1. 从 Seedance 长版母稿提取所有台词：
   ```regex
   /台词[：:]\s*第\d+s\s*@人物\d+[：:]\s*["「『"]([^"」』"]+)["」』"]/g
   ```
2. 从即梦精简版提取所有台词：
   ```regex
   /["「『"]([^"」』"]{3,})["」』"]/g
   ```
3. 从叙事性提示词提取所有台词
4. 三版本台词逐条对比
5. 如发现差异，以 Seedance 长版母稿为准，强制替换

## 失败场景与降级策略

### 场景 1：@标签无法在资产清单中找到真名
**处理**：保留 @标签原样，在即梦版输出末尾追加警告：
```
⚠️ 以下 @标签无法映射为真名，请手动替换：@人物5, @图片7
```

### 场景 2：合并后时长超过 15s
**处理**：强制在超过 15s 处切段，不合并

### 场景 3：台词校验发现差异
**处理**：以 Seedance 长版母稿为准，自动替换其他版本，并在日志中标注

### 场景 4：叙事版出现字段标签
**处理**：自动清洗，替换为自然语言连接词
