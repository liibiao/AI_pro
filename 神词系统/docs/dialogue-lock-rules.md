# 灵境 · 台词锁定规则（Dialogue Lock Rules）

> 源自 `soullensV69更新.html` 第 899/900/940/975/990/1302/1458 行多次强调
> 这是灵境的"**最高优先级铁律**"：台词原文一字不差强制保留，凌驾于所有其他规则。

---

## 一、核心原则

```
🔒【台词原文锁定（最高优先级）】
以下台词必须一字不差地出现在对应镜头的「台词：["……"]」字段中，
禁止任何改写、省略或意译。
```

**优先级排序**：
```
台词锁定 > 动作连续性 > 节拍密度 > 镜头美学 > 其他所有规则
```

**含义**：
- 如果台词与镜头时长冲突 → 延长镜头时长以容纳台词
- 如果台词与动作冲突 → 调整动作以配合台词
- 如果台词与节奏冲突 → 打破节奏以保留台词
- **任何情况下都不允许改写台词**

## 二、三阶段锁定机制

### 阶段 A · 剧本切分时锁定（第 921/940/956/975 行）

**场景**：链式引擎将长剧本切分为多个场次时

**规则**：
```
⚠️【台词锁定规则（最高优先级）】：
以下台词必须原文保留，禁止任何改写或意译：

[台词清单]
1. "我不会放弃的，绝不！"
2. "父亲，我终于明白了你当年的选择..."
3. "这一剑，为了所有被欺压的人！"

🔒【原始台词清单（每段摘要必须按出现位置保留对应台词原文）】：
- 若原著有对话台词，必须原文保留在对应摘要中
- 台词强制提取规则：原始情节中的所有台词（含引号对话、说/道/问等动词引出的对话）
  必须原文一字不差地保留在对应摘要中，禁止改写或意译
```

**检测方式**：
```javascript
// 提取剧本中所有台词
const dialogues = script.match(/"([^"]+)"|「([^」]+)」|『([^』]+)』/g)

// 在每个场次的 contentSummary 中验证
for (const scene of scenes) {
    for (const dialogue of dialogues) {
        if (剧本该段包含此台词 && !scene.contentSummary.includes(dialogue)) {
            throw new Error(`场次 ${scene.title} 遗漏台词：${dialogue}`)
        }
    }
}
```

### 阶段 B · 分镜生成时锁定（第 899/900/989/990 行）

**场景**：AI 生成分镜表时

**系统提示词注入**：
```
🔒【台词原文锁定（分镜生成最高优先级）】：
以下台词必须一字不差地出现在对应镜头的「台词：["……"]」字段中，
禁止任何改写、省略或意译：

1. 第 5-8s，@林天："我不会放弃的，绝不！"
2. 第 12-15s，@苏婉："你真的要去吗？那里太危险了..."
3. 第 20-23s，@林天："这一剑，为了所有被欺压的人！"

↑ 以上每一句台词都必须原文照搬，如有台词未出现在分镜中视为严重错误。
```

**格式要求**：
```
台词：第Xs @人物N："台词原文"
```
- `X` = 本镜相对秒数（台词时刻 - 本镜起始时间）
- 严禁用全局秒数
- 无台词时省略整段

**示例**：
```
| 时间段 | 主体 | 台词 |
|---|---|---|
| 5-8s | @林天 握紧拳头... | 第1s @林天："我不会放弃的，绝不！" |
| 12-15s | @苏婉 转身... | 第0.5s @苏婉："你真的要去吗？那里太危险了..." |
```

### 阶段 C · 质量检查时验证（第 1302/1458 行）

**场景**：分镜表生成完成后自动检查

**检查逻辑**：
```javascript
function validateDialogueLock(originalScript, storyboard) {
    // 提取原始台词
    const originalDialogues = extractDialogues(originalScript)
    
    // 提取分镜表中的台词
    const storyboardDialogues = extractDialoguesFromTable(storyboard)
    
    // 逐一比对
    const missing = []
    const modified = []
    
    for (const original of originalDialogues) {
        const found = storyboardDialogues.find(d => d === original)
        if (!found) {
            // 检查是否被改写
            const similar = storyboardDialogues.find(d => 
                levenshteinDistance(d, original) < 3
            )
            if (similar) {
                modified.push({ original, modified: similar })
            } else {
                missing.push(original)
            }
        }
    }
    
    if (missing.length > 0 || modified.length > 0) {
        throw new Error(`
            台词锁定验证失败：
            遗漏台词：${missing.join(', ')}
            改写台词：${modified.map(m => `"${m.original}" → "${m.modified}"`).join(', ')}
        `)
    }
}
```

**失败处理**：
- 自动标记错误镜头
- 提示用户手动修正或重新生成
- 记录到日志供调试

## 三、特殊情况处理

### 3.1 台词过长超出镜头时长

**问题**：台词 15 字，但镜头只有 3s

**解决**：
```
优先级：台词完整性 > 镜头时长约束
→ 自动延长镜头至 5-6s 以容纳台词
→ 调整后续镜头的起始时间
```

**代码**：
```javascript
const dialogueDuration = calculateDialogueDuration(dialogue)  // 字数 / 3.5
if (dialogueDuration > shot.duration) {
    shot.duration = Math.ceil(dialogueDuration) + 1  // 留 1s 余量
    recalculateGlobalOffset(shotIndex)  // 重算后续镜头时间轴
}
```

---

### 3.2 台词与动作冲突

**问题**：台词"我不会放弃"，但动作描述"转身离开"

**解决**：
```
优先级：台词语义 > 动作描述
→ 修改动作为"握紧拳头，眼神坚定"以匹配台词
→ 或拆分为两镜：镜1 说台词 + 镜2 转身离开
```

---

### 3.3 台词时间点模糊

**问题**：剧本只写"林天说：'...'，然后转身"，未标注秒数

**解决**：
```
默认规则：台词出现在本镜的前 1/3 时间
→ 如镜头 6-9s，台词标注为"第1s @林天：'...'"
→ 如需精确控制，用户可在剧本中标注"(8s) 林天：'...'"
```

---

### 3.4 多人对话快速切镜

**问题**：A 说一句 → B 回一句 → A 再说，需要 3 镜

**解决**：
```
每句台词独立成镜，用"对话接续"链接类型
→ 镜1: 3s, @A："你去哪？"
→ 镜2: 2s, @B："不关你事。"
→ 镜3: 3s, @A："我跟你一起去！"
→ 总计 8s，节奏紧凑
```

## 四、忠实模式（scriptFaithfulMode）

**触发条件**：用户勾选"剧本忠实模式"

**行为变化**：
```
关闭 AI 扩写 → 禁止添加原剧本没有的台词
关闭节拍重构 → 按原剧本场景边界切分，不强加戏剧节拍
1:1 视觉化 → 只做"文字→画面"转换，不做"剧作优化"
```

**台词锁定增强**：
```
🔒【保真直通模式（最高优先级指令）】：
- 台词必须原文一字不差
- 禁止添加原剧本没有的台词
- 禁止删减任何一句台词
- 禁止调整台词出现顺序
```

## 七、错误示例与正确示例

### ❌ 错误示例 1：改写台词

**原剧本**：
```
林天："我不会放弃的，绝不！"
```

**错误分镜**：
```
台词：第1s @林天："我绝不会放弃！"
```

**问题**：调整了语序，违反"一字不差"原则

---

### ❌ 错误示例 2：省略台词

**原剧本**：
```
苏婉："你真的要去吗？那里太危险了..."
```

**错误分镜**：
```
台词：第0.5s @苏婉："你真的要去吗？"
```

**问题**：省略了后半句

---

### ❌ 错误示例 3：意译台词

**原剧本**：
```
赵铁："哼，不自量力。"
```

**错误分镜**：
```
台词：第1s @赵铁："你太弱了。"
```

**问题**：意译了原文

---

### ✅ 正确示例

**原剧本**：
```
林天握紧拳头："我不会放弃的，绝不！"然后转身冲向演武场。
```

**正确分镜**：
```
| 时间段 | 主体 | 台词 |
|---|---|---|
| 5-8s | @林天（愤怒）[朝向：面朝右] 正在 猛然握紧拳头，手臂肌肉紧绷，青筋暴起 | 第1s @林天："我不会放弃的，绝不！" |
| 8-11s | @林天 正在 骤然转身，衣摆甩起，迈开大步冲向画面右侧 | （无台词） |
```

**正确点**：
- 台词原文一字不差
- 时间点标注清晰（第1s）
- 动作与台词配合（握拳 + 说话 → 转身冲出）
