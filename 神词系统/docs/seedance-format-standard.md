# Seedance 格式标准

> Seedance 2.0 长版母稿的完整格式规范

---

## 基本结构

每个镜头包含：
1. 时间标记：`【起始时间–结束时间】`
2. 六个固定字段（按顺序）：主体 → 空间 → 光影 → 镜头 → 台词 → 音效

---

## 字段详解

### 1. 主体（Subject）

**格式**：
```
主体：@人物N（情绪状态）[朝向：面朝XX] 正在 [连续动作链] + [全身动态] + [表情变化]（与上镜衔接）；@人物M...
```

**必须包含**：
- **@标签**：`@人物1` / `@人物2` 等
- **情绪状态**：疲惫/兴奋/紧张/平静/愤怒/悲伤等
- **朝向**：面朝屏幕/面朝窗外/面朝镜头/背对镜头/侧身等
- **连续动作链**：至少 2-3 个连续动作，每个动作前必须有速度词
  - 速度词：猛然/缓缓/骤然/徐徐/渐渐/迅速/慢慢
- **全身动态**：重心转移/身体倾斜/衣物飘动/发丝摆动/呼吸起伏
- **表情变化**：从 X 转为 Y
- **衔接说明**：延续上镜的XX动作 / 转折为XX

**示例**：
```
主体：@人物1（疲惫）[朝向：面朝屏幕] 正在 缓缓揉太阳穴→目光从屏幕移开→身体渐渐靠向椅背，重心后移，肩膀微微下沉，表情从专注转为疲惫（延续上镜的工作状态）
```

**多人场景**：
```
主体：@人物1（愤怒）[朝向：面朝@人物2] 正在 猛然起身→大步冲向@人物2→右手指向对方，衣摆翻飞，表情从压抑转为爆发；@人物2（惊恐）[朝向：面朝@人物1] 正在 骤然后退→双手护在胸前→身体微微颤抖，表情从平静转为恐惧
```

---

### 2. 空间（Space）

**格式**：
```
空间：前景-[引导视线的元素] 中景-[叙事主体] 背景-[氛围元素]（多人站位关系）
```

**三层分离原则**：
- **前景**：引导视线、框架构图、增加层次
  - 示例：键盘、门框、玻璃、肩部、栏杆、树枝
- **中景**：叙事主体、核心动作
  - 示例：@人物1 的工位、@人物2 站立的位置
- **背景**：氛围营造、空间深度、情绪烘托
  - 示例：落地窗外的夜景、模糊的办公区、远处的城市灯火

**示例**：
```
空间：前景-键盘和鼠标 中景-@人物1 独自坐在工位前 背景-落地窗外的城市夜景，远处灯火稀落（@人物1 位于画面中央偏左）
```

**多人站位**：
```
空间：前景-会议桌边缘 中景-@人物1 站在画面左侧，@人物2 坐在画面右侧 背景-白板和投影屏幕（@人物1 与 @人物2 形成对峙关系，轴线：@人物1 在画左·@人物2 在画右）
```

---

### 3. 光影（Lighting）

**格式**：
```
光影：[光源方向+冷暖色调+明暗反差+情绪隐喻]
```

**必须包含**：
- **光源方向**：顶部/侧面/背后/正面/画面右上方 45°
- **色温**：冷白/暖黄/冷蓝/暖金/中性白
- **明暗比**：2:1 / 3:1 / 4:1 / 8:1（可选）
- **情绪隐喻**：孤独/温暖/冷峻/压抑/希望

**示例**：
```
光影：冷白荧光灯从顶部照亮@人物1 的面容，3:1 明暗比，半边脸隐入阴影，营造孤独疲惫的氛围
```

```
光影：暖金色夕阳从画面右侧斜射入室内，在地板上投下长长的影子，温暖而怀旧
```

```
光影：单侧剪影光从背后勾勒@人物1 的轮廓，面部隐入暗部，神秘而压抑
```

---

### 4. 镜头（Camera）

**格式**：
```
镜头：[景别，叙事性运镜描述，机位高度]（轴线）（结尾动势）
```

**景别**：
- ECU 极特写 / CU 特写 / MCU 中近景 / MS 中景 / FS 全景 / LS 远景 / ELS 极远景

**叙事性运镜**（禁止技术参数）：
- ✅ 正确："镜头从她颤抖的指尖缓缓上移到紧咬的嘴唇"
- ❌ 错误："推镜头，焦距 85mm，光圈 f/2.8"

**机位高度**：
- 平视 / 微仰 / 微俯 / 倾斜 / 顶拍 / 鸟瞰

**轴线**（首次双人场景必填）：
```
（轴线：@人物1 在画左·@人物2 在画右）
```

**结尾动势**（可选）：
```
（结尾动势：@人物1 向画面右侧出画）
```

**示例**：
```
镜头：中景，镜头从@人物1 的侧脸缓缓推向窗外夜色，平视（轴线：@人物1 在画面中央偏左）（结尾动势：镜头停在窗外夜景）
```

```
镜头：特写，镜头固定在@人物1 的面部，微微仰拍，捕捉她从疲惫到决然的表情变化
```

---

### 5. 台词（Dialogue）

**格式**：
```
台词：第Xs @人物N："台词原文"
```

**规则**：
- **相对时间**：X = 台词时刻 - 本镜起始时间
  - 示例：本镜 5s-10s，台词在 7s 出现 → `第2s @人物1："..."`
- **原文锁定**：台词必须一字不差，用中文引号 `""`
- **无台词省略**：如果本镜无台词，省略整个"台词："字段

**示例**：
```
台词：第2s @人物1："又是一个人。"
```

```
台词：第1s @人物1："你在说什么？" 第3s @人物2："我说，这一切都结束了。"
```

**无台词时**：
```
（省略"台词："字段，直接跳到"音效："）
```

---

### 6. 音效（Sound）

**格式**：
```
音效：环境层-[持续底噪] 动作层-[与画面同步的声响] 情绪层-[配乐调性+乐器] [禁BGM]/[禁字幕]
```

**三层结构**：
- **环境层**：持续底噪
  - 示例：空调嗡鸣、远处车流、风声、雨声、虫鸣
- **动作层**：与画面同步的声响
  - 示例：键盘声、脚步声、关门声、椅子吱呀声、呼吸声
- **情绪层**：配乐调性 + 乐器
  - 示例：低沉钢琴单音、紧张弦乐、温暖吉他、悲伤大提琴

**音频开关**：
- `[禁BGM]`：无背景音乐，仅保留环境音和动作音
- `[禁字幕]`：画面无文字叠加

**示例**：
```
音效：环境层-空调低鸣，远处车流声若隐若现 动作层-键盘声渐弱，椅子轻微吱呀声 情绪层-低沉钢琴单音渐入，营造孤独氛围
```

```
音效：环境层-雨声持续 动作层-脚步声踩在水洼中，溅起水花 情绪层-悲伤大提琴缓缓响起 [禁字幕]
```

```
音效：环境层-办公室环境音 动作层-键盘声、鼠标点击声 情绪层-无配乐 [禁BGM] [禁字幕]
```

## 完整示例

```
【5s–10s】
主体：@人物1（疲惫）[朝向：面朝屏幕] 正在 缓缓揉太阳穴→目光从屏幕移开→身体渐渐靠向椅背，重心后移，肩膀微微下沉，呼吸略显沉重，表情从专注转为疲惫（延续上镜的工作状态）
空间：前景-键盘和鼠标 中景-@人物1 独自坐在工位前 背景-落地窗外的城市夜景，远处灯火稀落（@人物1 位于画面中央偏左）
光影：冷白荧光灯从顶部照亮@人物1 的面容，3:1 明暗比，半边脸隐入阴影，营造孤独疲惫的氛围
镜头：中景，镜头从@人物1 的侧脸缓缓推向她的面部特写，平视（结尾动势：镜头停在面部特写）
台词：第3s @人物1："又是一个人。"
音效：环境层-空调低鸣，远处车流声若隐若现 动作层-键盘声渐弱，椅子轻微吱呀声 情绪层-低沉钢琴单音渐入，营造孤独氛围
```

## 六个固定段

每集末尾追加以下六个固定段：

```
━━━ 六个固定段 ━━━

【环境联动】
场景元素与角色动作的互动关系。示例：风吹乱@人物1 的头发，雨滴打在@人物2 的脸上，阳光穿过@人物1 的指缝，尘埃在光柱中飞舞。

【光线】
主光源方向、色温、明暗比、情绪隐喻。示例：冷白荧光灯从顶部照亮面容（4500K，3:1 明暗比），营造孤独疲惫的氛围。

【对白配音】
台词原文 + 语气指导。示例：
- @人物1："又是一个人。"（低声自语，带着疲惫和无奈）
- @人物2："你在说什么？"（惊讶，声音微微颤抖）

【音效设计】
- 环境层：空调嗡鸣、远处车流、风声、雨声
- 动作层：键盘声、脚步声、关门声、椅子吱呀声
- 情绪层：低沉钢琴单音、紧张弦乐、温暖吉他

【画质】
电影级画质，画面清晰流畅，色彩自然真实，细节丰富。

【负面提示词】
overlay text, caption, label, annotation, subtitle, heading, watermark, logo, signature, stamp, emblem, panel number, view label, measurement, HUD, multiple people (if solo scene), collage, split screen, border, frame, colored background (if neutral required)
```

## 质量检查清单

### 必检项

- [ ] 时间标记格式正确：`【Xs–Ys】`
- [ ] 六个字段顺序正确：主体 → 空间 → 光影 → 镜头 → 台词 → 音效
- [ ] 所有 @标签完整保留
- [ ] 主体字段包含：情绪状态 + 朝向 + 连续动作链 + 全身动态 + 表情变化
- [ ] 空间字段明确区分：前景 / 中景 / 背景
- [ ] 光影字段包含：光源方向 + 色温 + 情绪隐喻
- [ ] 镜头字段使用叙事性描述，无技术参数
- [ ] 台词原文一字不差，用中文引号
- [ ] 音效字段包含三层：环境层 + 动作层 + 情绪层
- [ ] 六个固定段完整追加在末尾

### 常见错误

❌ 字段名变体（动作/场景/环境/声音）
❌ @标签缺失或格式错误
❌ 主体字段缺少速度词
❌ 空间字段未区分三层
❌ 镜头字段使用技术参数（焦距/光圈）
❌ 台词改写或省略
❌ 音效字段缺少三层结构
❌ 使用否定句（"不要移动"）
