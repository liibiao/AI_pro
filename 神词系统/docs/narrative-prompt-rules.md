# 叙事性提示词规则

> 段落式叙事提示词的完整编写规范

---

## 核心理念

叙事性提示词是**电影脚本式的画面描述**，而非技术参数堆砌：
- 用完整段落描述画面，像写电影脚本
- 场景、动作、运镜、光影、声音自然融合
- 严禁出现字段标签（主体/空间/光影等）
- 保留 @标签引用，首次出现时说明用途

---

## 基本格式

### 单镜段（≤5秒）

```
【0s–5s】以@人物1为主角，场景参考@图片3的深夜办公室。中景，@人物1独自坐在工位前，冷白荧光灯照亮她疲惫的面容。她缓缓揉太阳穴，目光从屏幕移开，身体渐渐靠向椅背。键盘声渐弱，空调低鸣，整体氛围冷寂孤独，电影质感。
```

### 多镜段（>5秒，推荐分时段）

```
【0s–12s】以@人物1为主角，场景参考@图片3的深夜办公室。
0-4秒：远景建立，空旷的办公区只有角落一盏台灯亮着，@人物1的剪影映在落地窗上。空调嗡鸣，键盘声稀疏。
4-8秒：中景推近，@人物1揉太阳穴，目光从屏幕移开，身体缓缓靠向椅背，表情从专注转为疲惫。椅子轻微吱呀声。
8-12秒：特写她的侧脸，视线转向窗外，城市灯火稀落，轻声自语："又是一个人。"镜头缓慢拉远，她的身影在空旷办公区中越来越小，画面定格。远处车流声若隐若现，低沉钢琴单音渐入。
```

## 核心规则

### 1. 严禁字段标签

❌ **错误示例**：
```
主体：@人物1 正在揉太阳穴
空间：前景-键盘 中景-@人物1 背景-窗外夜景
光影：冷白荧光灯从顶部照亮
镜头：中景，缓慢推进
```

✅ **正确示例**：
```
中景，@人物1独自坐在工位前，冷白荧光灯从顶部照亮她疲惫的面容。她缓缓揉太阳穴，目光从屏幕移开。键盘在前景，背景是窗外的城市夜景。
```

### 2. @标签完整保留

**首次出现时说明用途**：
- `以@人物1为主角`
- `场景参考@图片3的深夜办公室`
- `@道具2（发光的灵纹手环）在她手腕上闪烁`

**后续直接使用**：
- `@人物1转身看向@人物2`
- `@道具2的光芒越来越强`

### 3. 分时段描述（多镜段推荐）

**时段划分原则**：
- 每个时段 3-5 秒
- 每个时段一个核心动作或情绪转折
- 时段之间自然衔接

**示例**：
```
【0s–15s】以@人物1和@人物2为主角，场景参考@图片5的会议室。
0-5秒：远景建立，@人物1站在画面左侧，@人物2坐在画面右侧，两人形成对峙关系。会议室灯光明亮，气氛紧张。
5-10秒：中景切到@人物1，她猛然起身，右手指向@人物2，愤怒地说："你在说什么？"衣摆翻飞，表情从压抑转为爆发。
10-15秒：反打到@人物2，他骤然后退，双手护在胸前，身体微微颤抖，惊恐地回应："我说，这一切都结束了。"镜头缓慢推近他的面部，捕捉恐惧的表情。
```

### 4. 融合叙述

**五大元素自然融合**：
1. **场景环境**：深夜办公室、空旷的办公区、落地窗
2. **人物动作**：揉太阳穴、目光移开、身体靠向椅背
3. **运镜方式**：中景推近、镜头缓慢拉远、固定特写
4. **光影氛围**：冷白荧光灯、台灯暖光、城市灯火稀落
5. **声音设计**：空调嗡鸣、键盘声、椅子吱呀声、钢琴单音

**示例**：
```
中景推近，@人物1独自坐在空旷的办公区，只有角落的台灯投下暖黄色光晕。她缓缓揉太阳穴，目光从屏幕移开，身体渐渐靠向椅背，表情从专注转为疲惫。空调低鸣，键盘声渐弱，远处传来稀疏的车流声。镜头从她的侧脸缓慢推向窗外的城市夜景，灯火稀落，低沉钢琴单音渐入，营造孤独而冷寂的氛围。
```

### 5. 台词原文保留

**台词必须用引号标注，一字不改**：

✅ **正确示例**：
```
@人物1轻声自语："又是一个人。"
```

```
@人物1愤怒地说："你在说什么？"@人物2惊恐地回应："我说，这一切都结束了。"
```

❌ **错误示例**：
```
@人物1说她又是一个人了  # 错误：改写了台词
@人物1问对方在说什么    # 错误：省略了台词原文
```

### 6. 禁止否定句

除音频/字幕开关外，严禁使用否定表达：

❌ **错误示例**：
```
@人物1不要移动，保持静止
画面中没有其他人物
不要有背景音乐
```

✅ **正确示例**：
```
@人物1保持静止，身体微微起伏呼吸
画面中只有@人物1独自一人
仅保留自然环境音效，无背景音乐
```

## 运镜描述

### 叙事性运镜（推荐）

用具体方向和动作描述镜头运动：

✅ **正确示例**：
- "镜头从她颤抖的指尖缓缓上移到紧咬的嘴唇"
- "镜头从@人物1的侧脸缓慢推向窗外夜色"
- "镜头环绕@人物1一周，展示她孤独的身影"
- "镜头从远景缓慢拉近到@人物1的面部特写"

❌ **错误示例**：
- "推镜头"（太简略）
- "Dolly In，焦距85mm"（技术参数）
- "使用斯坦尼康跟拍"（设备名称）

### 景别融入叙述

不要单独列出景别，而是融入描述：

✅ **正确示例**：
- "远景建立，空旷的办公区..."
- "中景推近，@人物1揉太阳穴..."
- "特写她的侧脸，视线转向窗外..."

❌ **错误示例**：
- "景别：中景"
- "使用特写镜头"

## 声音设计

### 三层结构融入叙述

**环境层 + 动作层 + 情绪层**：

✅ **正确示例**：
```
空调低鸣，键盘声渐弱，椅子轻微吱呀声。远处传来稀疏的车流声，低沉钢琴单音渐入，营造孤独而冷寂的氛围。
```

```
雨声持续，脚步声踩在水洼中溅起水花。悲伤大提琴缓缓响起，与画面情绪完美融合。
```

### 音频开关

**无背景音乐**：
```
仅保留自然环境音效和动作音，无背景音乐。
```

**无字幕**：
```
画面无文字叠加，纯视觉叙事。
```

## 质量检查清单

### 必检项

- [ ] 时间标记格式正确：`【Xs–Ys】`
- [ ] 首句说明 @标签用途：`以@人物1为主角，场景参考@图片3...`
- [ ] 无字段标签（主体/空间/光影/镜头/音效）
- [ ] 段落式叙述，自然流畅
- [ ] 多镜段使用分时段描述（0-4秒 / 4-8秒 / 8-12秒）
- [ ] 运镜描述叙事化，无技术参数
- [ ] 台词原文一字不差，用引号标注
- [ ] 声音设计融入叙述（环境层 + 动作层 + 情绪层）
- [ ] 无否定句（除音频/字幕开关）

### 常见错误

❌ 出现字段标签（主体：/空间：/光影：）
❌ @标签缺失或未说明用途
❌ 运镜使用技术参数（焦距/光圈/设备名）
❌ 台词改写或省略
❌ 声音设计单独列出，未融入叙述
❌ 使用否定句（"不要移动"）
❌ 多镜段未分时段，描述混乱
