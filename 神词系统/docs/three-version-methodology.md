# 灵境三版本提示词生成方法论

## 核心理念

灵境系统的核心是**一次分镜，三版输出**：
- 从剧本生成统一的分镜表
- 基于分镜表自动派生三个版本的提示词
- 每个版本针对不同平台和使用场景优化

---

## 三版本对比

| 特性 | Seedance 长版母稿 | 即梦精简版 | 叙事性提示词 |
|------|------------------|-----------|-------------|
| **目标平台** | Seedance 2.0 | 即梦 (JiMeng) | Seedance 2.0 / 可灵 / Wan |
| **格式** | 结构化字段 | 精简描述 | 段落式叙事 |
| **@标签** | ✅ 保留 | ❌ 去除 | ✅ 保留 |
| **字段结构** | 主体/空间/光影/镜头/台词/音效 | 自由描述 | 融合叙述 |
| **长度** | 详细完整 | 精简压缩 | 中等 |
| **适用场景** | 精确控制、资产引用 | 快速生成、无资产 | 自然叙事、情绪优先 |

## 版本 1：Seedance 长版母稿

### 格式标准

```
【0s–5s】
主体：@人物1（情绪状态）[朝向：面朝XX] 正在 [连续动作链（含速度节奏：猛然/缓缓/骤然）+全身动态（重心转移/身体倾斜/衣物飘动）+表情变化]（与上镜衔接：延续XX/转折为XX）；@人物2...（多人用；分隔）
空间：前景-[引导视线的元素] 中景-[叙事主体] 背景-[氛围元素]（多人站位关系）
光影：[光源方向+冷暖色调+明暗反差+情绪隐喻]
镜头：[景别，叙事性运镜描述（如"从颤抖的手缓缓上移到紧咬的嘴唇"），机位高度]（轴线：A在画左·B在画右，首次双人必填）（结尾动势：[出画方向或动作趋势]）
台词：第2s @人物1："台词原文"（无台词省略整段；X为本镜相对秒数=台词时刻-本镜起始时间）
音效：环境层-[持续底噪] 动作层-[与画面同步的声响] 情绪层-[配乐调性+乐器] [禁BGM]/[禁字幕]
```

### 六个固定段（每集末尾追加）

```
━━━ 六个固定段 ━━━

【环境联动】
场景元素与角色动作的互动关系，如风吹乱头发、雨滴打在脸上、阳光穿过指缝等。

【光线】
主光源方向、色温（如4500K暖金）、明暗比（如3:1）、情绪隐喻。

【对白配音】
台词原文 + 语气指导（如低声自语、怒吼、哽咽）。

【音效设计】
- 环境层：持续底噪（如空调嗡鸣、远处车流）
- 动作层：与画面同步的声响（如脚步声、关门声）
- 情绪层：配乐调性+乐器（如低沉钢琴单音、紧张弦乐）

【画质】
视觉风格 + 画面质感，如"电影级画质，画面清晰流畅"。

【负面提示词】
overlay text, caption, label, annotation, watermark, logo, signature, multiple people (if solo), collage, split screen, border, frame
```

### 核心规则

1. **@标签完整保留**：所有 @人物N、@图片N、@道具N 必须原样保留
2. **字段顺序固定**：主体 → 空间 → 光影 → 镜头 → 台词 → 音效
3. **动作连续化**：每个动作前必须有速度词（猛然/缓缓/骤然/渐渐）
4. **全身动态化**：人物永远有身体局部在运动，禁止完全静止
5. **空间三层分离**：前景/中景/背景必须明确区分
6. **台词原文锁定**：台词必须一字不差，用引号标注

## 版本 2：即梦精简版

### 转换规则

从 Seedance 长版母稿转换为即梦精简版：

1. **去除所有 @标签**
   - `@人物1` → `男主角` / `林天`
   - `@图片3` → `深夜办公室`
   - `@道具2` → `发光的灵纹手环`

2. **合并字段为自然描述**
   ```
   原：主体：@人物1（疲惫）[朝向：面朝屏幕] 正在 缓缓揉太阳穴
       空间：前景-键盘 中景-@人物1 背景-落地窗夜景
       光影：冷白荧光灯从顶部照亮面容，3:1明暗比
   
   转换后：
   中景，男主角独自坐在工位前，冷白荧光灯照亮他疲惫的面容。
   他缓缓揉太阳穴，目光从屏幕移开。键盘在前景，背景是落地窗外的夜景。
   ```

3. **精简描述**
   - 去除技术参数（如"3:1明暗比"）
   - 保留核心动作和情绪
   - 压缩到原长度的 60-70%

4. **保留台词原文**
   - 台词部分必须完整保留，不做任何改动

## 版本 3：叙事性提示词

### 格式标准

段落式叙事，融合所有元素：

```
【0s–12s】以@人物1为主角，场景参考@图片3的深夜办公室。
0-4秒：远景建立，空旷的办公区只有角落一盏台灯亮着，@人物1的剪影映在落地窗上。空调嗡鸣，键盘声稀疏。
4-8秒：中景推近，@人物1揉太阳穴，目光从屏幕移开，身体缓缓靠向椅背，表情从专注转为疲惫。椅子轻微吱呀声。
8-12秒：特写她的侧脸，视线转向窗外，城市灯火稀落，轻声自语："又是一个人。"镜头缓慢拉远，她的身影在空旷办公区中越来越小，画面定格。远处车流声若隐若现，低沉钢琴单音渐入。
```

### 核心规则

1. **叙事描述式**：用完整段落描述画面，像写电影脚本
2. **严禁字段标签**：不得出现"主体：""空间：""光影："等字段名
3. **@标签完整保留**：首次出现时说明用途（如"以@人物1为主角"）
4. **分时段描述**：多镜段推荐按时间顺序组织（0-4秒 / 4-8秒 / 8-12秒）
5. **融合叙述**：场景、动作、运镜、光影、声音自然融合
6. **台词原文保留**：台词用引号标注，一字不改

## 生成流程

```
剧本输入
    ↓
【步骤1】分析剧情 + 选择导演风格 + 视觉风格
    ↓
【步骤2】生成分镜表（时间轴 + 景别 + 运镜 + 画面描述 + 光影氛围）
    ↓
【步骤3】转换为 Seedance 长版母稿（六字段结构 + @标签）
    ↓
【步骤4】并行生成三版本
    ├─ 即梦精简版（去 @标签 + 精简描述）
    ├─ Seedance 长版母稿（完整字段 + @标签）
    └─ 叙事性提示词（段落式叙事 + @标签）
```

## 质量控制

### 必检项

1. **时间轴连续性**：所有镜头时长之和 = 总时长，无缝隙无重叠
2. **@标签一致性**：三版本中的 @标签引用必须一致（除即梦版去除）
3. **台词原文锁定**：所有版本的台词必须完全一致
4. **景别跳跃控制**：相邻镜头景别跳跃 ≤ 2 级
5. **动作连续性**：相邻镜头间角色位置、动作进度、朝向物理逻辑一致
6. **禁止否定句**：除音频/字幕开关外，严禁"不要""不能""禁止"等否定表达

### 常见错误

❌ **错误示例 1**：字段名变体
```
动作：@人物1 正在...  # 错误：应为"主体："
场景：前景-...        # 错误：应为"空间："
```

✅ **正确示例**：
```
主体：@人物1 正在...
空间：前景-...
```

❌ **错误示例 2**：否定句
```
@人物1 不要移动，保持静止  # 错误：AI 不理解否定
```

✅ **正确示例**：
```
@人物1 保持静止，身体微微起伏呼吸
```

## 平台适配

### Seedance 2.0
- 使用：Seedance 长版母稿 或 叙事性提示词
- 特点：支持 @标签引用、长提示词、复杂结构

### 即梦 (JiMeng)
- 使用：即梦精简版
- 特点：不支持 @标签、偏好精简描述、单镜生成

### 可灵 (Kling)
- 使用：叙事性提示词
- 特点：支持自然语言、情绪化描述

### Wan / Luma / Runway
- 使用：叙事性提示词 或 即梦精简版
- 特点：通用性强、自然语言优先

---

## 最佳实践

1. **先生成 Seedance 长版母稿**：作为标准版本，包含最完整信息
2. **从长版派生其他版本**：确保一致性和完整性
3. **保持台词原文不变**：所有版本的台词必须完全一致
4. **@标签统一管理**：在素材库中维护统一的资产引用
5. **分段生成长内容**：超过 60 秒的内容建议分段生成后合并
